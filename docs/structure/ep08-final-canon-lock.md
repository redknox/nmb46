## 人物留下了什么

- 飞鸟是唯一主推进。她从报名起就在认真，并主动调整跑序、私下练习；本番追过又被反超、完成交襷后，第一次没能隐藏自己有多在意。
- 她没有从此坦率、学会依赖、找到青春的答案，也没有提前完成 EP12 主动奔跑并亲口答“不知道”的变化。
- 南持续快乐而认真，本番缩距，结尾不哭；她不拆穿私练，也不负责治愈飞鸟。
- 深川先递毛巾、陪坐，再被当下带出眼泪。只有深川和飞鸟哭；万理华、若月、南坐着陪伴。
- 五人合作成功不升级既有关系等级。飞鸟—南仍 A，深川—飞鸟仍普通同班 C；不形成新的固定亲密小组。
- 万理华不是班级体育委员；松村做招集与比分答疑，不是放送委员。白石只作为 B 团高三第一棒完成者短暂入镜。
- C 团真夏、まあ亚、高山仅有相邻练习短段，没有计划崩溃、情绪救场或第二成长线。

## 本番与结尾事实

3-D 最终走順：**万理华→深川→南→飞鸟→若月**；此前临时顺序为万理华→深川→南→若月→飞鸟，S05 才调序。飞鸟第四区约380米，若月末棒250米。

练习解决的襷交接在比赛中继续成功。南缩短距离后，飞鸟突然想超过眼前的 C 团普通第四区跑者；她追过，对方以稳定配速重新超过她。此举不单独计分，也不是为了救全团排名。D 团在接力前已确定综合第四。

接力顺位 **B→A→C→D**；综合总分 **B218、A216、C173、D131**。比赛与颁奖运行继续，镜头停在恢复区，不转去冠军场面。

飞鸟哭问“到底为什么要跑啊……！”，江口认真回答“……不知道。”；深川后来答南“不知道。就是突然很想哭。”问答在跑完以后发生，不补再跑、奖励、演说、集体毕业感伤或全员大哭。
