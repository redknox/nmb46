# 伏笔与 Callback 总表

## 核心回声

### “为什么要跑？” / “不知道。”
- 第7集：飞鸟先轻度吐槽“为什么青春一定要跑步表达”。
- 第8集：飞鸟正式问江口“所以到底为什么要跑？”江口答“不知道。”
- 第12集：南问飞鸟“为什么跑？”飞鸟答“不知道。”随后不再分配解释性对白，所有人自然跟上。

### 新生进入 / 主角毕业离开
- 第1集：高一新生进入校门。
- 第12集：一期生离校，镜头留在空教室，门外传来新生声音。

### 生驹与制服
- 第1集：闪回第一次穿上制服，反复整理领结，不舍得脱。
- 第2集：她对原版制服有强烈感情，但逐渐理解别人不一定以同样方式珍惜。
- 第11–12集：最后一次穿/脱制服时，不再需要问自己“像不像乃木坂”。

### 樱井与领导位置
- 第1集：三年前坐在台下观察学生会长；现在站上同一位置。
- 中段：不断承担协调责任，暴露“想让所有人满意”的错误信念。
- 第10集：旧礼堂问题中做出不可能让所有人满意的决定，并承担。
- 第11集：把学生会交给下一届。

### 真夏与流程
- 第1集：迎新流程能力与“台阶解决不了但流程可以先改”。
- 第3–5集：文化祭达到控制力高峰。
- 第8集：接力赛被人的随机性彻底破坏。
- 第11集：学会不替下一届把所有事情做完。

### 飞鸟与纪念物
- 第1集：嘴上嫌弃入学第一天拍照。
- 第5集：留下文化祭小册子。
- 第6集：票根/书店小物等。
- 第8集：保留接力号码布。
- 第10集：旧礼堂变化时偷偷留下某样东西。
- 第11集：把这些“垃圾”装进包里。

### 高山笔记本
- 第2–3集：开始出现，记录同学与老师的奇怪句子。
- 全季持续。
- 第11集最后一页只写：“今天毕业。”不加笑话。

### 白石“永远准备好被看”
- 第1集：现在已习惯被看，闪回三年前第一次被注视时的不安。
- 第5集：文化祭前台维持学校形象、后台狼狈。
- 第7集：合宿后放下梳子。
- 第8集：接力赛跑得难看，却被学妹夸“超帅”。
- 第11集：接受笑崩的毕业宣传照。

### 生田与“正确”
- 第1集：闪回最初看到钢琴就想弹的纯粹快乐；现在听见乱音会想纠正。
- 第4–5集：Fukase / 松隆子推动“技巧与表达”冲突。
- 第12集：最后一次在音乐室无谱演奏，不问任何人评价。

### 桥本“提前准备离开”
- 第1集：第一次进入学校只看两秒再看表，没有仪式感。
- 第3、6集：逐渐出现与其他人不同的时间/生活节奏。
- 第9集：完整打开现实线，并允许朋友参与自己的选择。

### 旧礼堂
- 第1集：开学典礼中，轮椅新生因没有无障碍通道而需教职员协助抬入；不拍投诉。
- 前中期：礼堂持续作为学校真实空间存在，可承载小型排练、音乐与文化祭相关活动。
- 第10集：学校在收到正式意见并结合消防、疏散、无障碍、耐震等问题后委托专业评估；结论是不能再承担大量人员同时进入的集会功能。
- 第10集决策：重建新礼堂，同时保留旧舞台地板、木构件、后台门、座椅、校徽、钟、幕布轨道等部分真实材料。
- 新礼堂完成后：第一集的轮椅新生通过无障碍通道自然进入，并停在预留轮椅观众位置。无解释性对白。

### 旧舞台地板
- 前期：只是大家日常踩过的东西，不强调。
- 第10集：拆除/评估时才意识到它承载了大量真实记忆。
- 新礼堂：部分重新铺入新舞台，让下一届学生实际站在旧材料上。

### 佐藤二朗门卫
- 第1集：每天“早上好”。
- 全季：成为校门这一时间节点的固定见证者。
- 第12集：一期生最后离开时只说一句普通的“路上小心”。

### 松重丰“老样子”
- 前中期：食堂建立固定菜单与“老样子？”的日常关系。
- 第12集：最后一次“老样子？”成为日常告别。

### 南的“以后还有”感
- 前期：对“最后一次”没有敏感，总觉得以后还会再来。
- 第11集：突然通过“明天不用来学校了”这类实际事实意识到结束是真的。

### 裙摆齐线
- 第1集：新生努力整理制服；高三不必检查，走在一起时裙摆已自然齐线。
- 第2集：正式讨论制服与规则。
- 全季：作为乃木坂女学院视觉母题反复出现。
- 第12集：大家一起跑下坡，裙摆彻底失去齐线；但此时已经没人需要证明她们“像不像乃木坂”。
