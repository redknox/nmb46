# 伏笔与 Callback 总表

## 核心回声

### “为什么要跑？” / “不知道。”
- 第2集：飞鸟第一次因为“为什么必须这样”而从旁观吐槽走到真正提问 / 参与；她仍然需要理由。
- 第7集：不提前消费“为什么要跑”。飞鸟在合宿中只是正常参与、竞争、串寝、玩水，不承担 EP08 的意义问题。
- 第8集：飞鸟正式问江口“所以到底为什么要跑？”江口答“不知道。”
- 第12集：南问飞鸟“为什么跑？”飞鸟答“不知道。”随后不再分配解释性对白，所有人自然跟上。

### 新生进入 / 主角毕业离开
- 第1集：高一新生进入校门。
- 第12集：一期生离校，镜头留在空教室，门外传来新生声音。

### 生驹与制服 / 归属
- 第1集：三年前第一次进入乃木坂女学院时，反复确认领结、袖口和姿态，特别怕自己哪里做得不对；现在已经成为负责告诉学妹“怎么做”的高三学姐。
- 第2集：她准确说明现行裙长规则，但第一次把“学校怎么规定”与“我自己喜欢怎样穿”分开；面对同样喜欢制服却喜欢短一点的学妹，她停止把自己的归属经验扩展成对方唯一正确答案。
- 第11–12集：最后一次穿 / 脱制服时，不再需要问自己“像不像乃木坂”。

### 樱井与领导位置
- 第1集：三年前坐在台下观察学生会长；现在站上同一位置。
- 中段：不断承担协调责任，暴露“想让所有人满意”的错误信念。
- 第10集：旧礼堂问题中，代表学生会形成不可能让所有人满意的明确立场，并承担。
- 第11集：把学生会交给下一届。

### 真夏与流程
- 第1集：迎新流程能力；面对旧礼堂，学生会只承担自己真实拥有的流程职责，不替成人建筑系统解决问题。
- 第3集：面对榊陵风声，本能追问“谁说的 / 是不是执行委员”，确认两个来源都没有正式授权后只停止核验，不替大家宣布答案。
- 第5集：完整计划第一次无法覆盖现场；真夏从读取表转向读取报告、空间与人，以现有资源重组流程。她没有放弃系统，也没有提前学会离开系统。
- 第8集：接力赛被人的随机性彻底破坏。
- 第11集：学会不替下一届把所有事情做完。

### 飞鸟与“参与”
- 第2集：面对裙长规则，早上觉得“写了又怎样”而留空；下午真正问老师，听过部分答案后，把剩余问题写进学校生活调查。她仍然不认同，但第一次没有退出。
- 第6集：她判断展示已经赶不上、也不断质疑菜单与芭菲，却始终与南一起行动；本集只留行为事实，不让她承认闲逛的意义。
- 第7集：合宿里她继续以身体和生活方式参与，不替本集或 EP08 解释青春意义；她和南维持 A 关系，但不成为白石成长的观察员。
- 第8集：面对“为什么要跑”，意义问题进一步扩大到集体行为与青春仪式。
- 第12集：最终主动跑起来时，不再要求先获得一个可证明的理由。

### 飞鸟与纪念物
- 第1集：嘴上嫌弃高三第一天拍照，真正按快门时却自己站到画面边缘。
- 第8集：保留接力号码布。
- 第10集：旧礼堂变化时偷偷留下某样东西。
- 第11集：把这些“垃圾”装进包里。

### 高山笔记本
- 第2–3集：开始出现，记录同学与老师的奇怪句子。
- 全季持续。
- 第11集最后一页只写：“今天毕业。”不加笑话。

### 高山与“不必救的沉默”
- 前期：她习惯接住话头、把尴尬变成笑点，让现场保持轻一点。
- 第6集：文具店先让观众感到她持续接话的劳动；家庭餐厅里一句玩笑自然落下，她没有补第二句，桌子也没有散。饭后西野邀请她继续走，她只回答“嗯”。
- 第11集：才正面处理她为什么总在救气氛，以及是否能允许别人照顾她；EP06不能被回读成完成态。

### 西野与“改变方向”
- 前期：她本来就会独自离开人群、去看想看的东西；独自绕路不是成长。
- 第6集：她先为一张展示传单改变路线，饭后又主动邀请高山“再走一点”；第一次把无目的的私人时间递给别人。
- 第9集：面对已经准备好的升学道路，她把同一种主动性推进到真正的人生选择，并让在乎的人听见。

### 白石｜从“永远准备好补位”到“我想也可以先发生”
- 第1集：现在已习惯被看，闪回三年前第一次被注视时反而先检查“是不是哪里穿错了”。
- 第5集：在接待桌与小泉短暂相遇；她把印有自己照片的节目册压到下面，继续整理桌面。时间感进入她的公开形象，但她不承担后台主事故。
- 第7集 S06：南和另一名组长同时举手要她。白石基于自己的胜负判断选择另一组，不解释、不道歉、不修补；关系也没有因此坏掉。
- 第7集 S07：她真正想赢。沙滩抢旗时把软旗从对手手里拽回来并护在身下，最后拿第一。
- 第7集 S08：她原本坐在岸边看东西；南只把现实借口移开，说“来啊”就走。白石自己下水，并从被泼的人变成追人、反击、制造混乱的人之一。镜头最后不再追她。
- 第7集 S09：她仍会发现锅要糊、上手处理；负责人回来后把锅铲交回，只提醒“下面容易糊，记得一直搅”。可靠没有消失，但“看见问题”不再自动等于“必须由我做完”。
- 第8集以后：若再出现狼狈、竞争或被注视，只能作为现实验证，不再重复“接受不完美 / 被喜欢不需要完美”的同一人物课。
- 第11–12集：只做情绪回收，不重新开启白石成长线。

### 生田与“正确”
- 第1集：现在时进入音乐别馆时，她已经在精准、受控地按谱演奏；Flashback⑤中，一年级的她面对同一练习室没有谱，先听一个音、脚步和门声，再回应，甚至说不出自己刚才“弹的是什么”。两种音乐使用方式并置，但第一集不判断哪一种更好。
- 第3集：午饭尾声仍看谱，发现具体小节问题后做记号，随后利用午休去练习室只处理这一窄小段落；练习表现为反复停止、确认、写记号、重来，不让完整音乐成为观赏对象。
- 第4集：松下把现场长出的四拍写成正式谱面，生田一眼完成；她也能准确演奏另一种同样成立的版本。真正的新问题是：当两个方案都成立、选择者换成自己时，她不知道该用哪一个。
- 第4集：Fukase 让她看见作品形成以前可以没有完整判断条件，松隆子把第一次尝试限制为右手四小节。结尾相同第一个音以后，生田主动改变第二个音；不是学会 free，而是第一次进入。
- 第5集：新的工作方式只在文化祭现场被使用，不再次安排一场“证明她已经成长”的教学或总结。
- 第7集：面对まあ亚的身体直觉，她再次看见“正确判断可以先于解释”，但不重演 EP04 的 free 问题，也不完成新的人物弧。
- 第12集：最后一次无谱演奏可以成为更远回声，但不拍成“恢复成三年前的自己”；她已经带着后来的技术与关系走到新的使用方式。

### 中元与堀的不同位置
- 第4集：堀以不会等待 ensemble 先给位置的独立声音承担 optional first voice；中元以成熟 S2 声部长身份听实际效果、追问作品逻辑并组织自己的声部进入。不是竞争，也不是替代。
- 第5集：舞台条件变化时，堀的位置可以暂时取消再恢复；中元始终继续清点、整队与完成声部工作。岗位是否成立由作品与现场条件决定，不改写两人的能力评价。

### 松村与“知道发生了什么”
- 第3集：榊陵风声在排队和午饭中自然撞进她；后来她在保健室专心贴创可贴时又无意听见万里小路腿伤。她能记住事实碎片和“不确定”这个信息等级，却可能完全找不到来源。
- 第3集：别人把“文化祭前能否恢复尚未确定”升级成“不能参加”时，她立即纠正，固定她不是谣言制造者。
- 第5集：她只在食堂选择与后台一句旧消息中保持日常信息感；不承担主事故的信息因果，也不升级成主动搜集情报的人。

### 桥本“提前准备离开”
- 第1集：三年前第一次站在校门外，短暂停住看学校、看表、进去；现在在学校里面短暂停住看向门外，随后继续自己的时间。
- 第3集：飞鸟主动跨班来到3-B；桥本只用“你去年不是做了不少吗”这种事实回应她的嘴硬，随后还会真正重新判断。这个关系不靠安慰、拆穿或心理分析成立。
- 第6集：终礼后从容收好书包、独自离开；不看表、不匆忙、不解释原因，只让不同的时间 / 生活节奏成为 C 类背景信息。
- 第7集：只以既有 A 关系自然出现在白石身边，不承担“见证白石成长”或替观众解释变化的功能。
- 第9集：完整打开现实线，并允许朋友参与自己的选择。

### 旧礼堂 / 体育馆毕业典礼
- 第1集：学校事前知道一名轮椅新生将参加入学式，并为旧礼堂提前设置稳定模块化坡道。她正常随班进入；保护者只礼貌确认这是否属于常设设施。当天流程成功，但也让观众看到：旧建筑要实现现代公共使用，需要额外准备。
- 前中期：旧礼堂持续作为学校真实空间存在，承载排练、音乐与文化祭等活动；“还能用”与“适合继续这样用”之间的差异不断积累。
- 第10集：学校结合消防、疏散、无障碍、耐震等问题进行专业评估；旧礼堂不能再承担大型集会功能。
- 第10集决策：学生会形成支持真正重建、同时把旧舞台地板、木构件、后台门、部分座椅、校徽、钟、幕布轨道等真实材料重新纳入新建筑的学生侧立场；最终决定仍由正式学校 / 法人程序作出。
- 第11集：新礼堂尚未建成，毕业典礼改在现代体育馆举行。体育馆被布置得依然优雅、正式，但观众应感到一点轻微空间错位——这是重建决定的现实后果。
- 第12集：学校仍在继续推进礼堂工程；一期生离开时不需要看到完成结果。

### 轮椅新生
- 第1集：她使用事前准备的模块化坡道正常进入旧礼堂。真正可见的事实不是“她进不去”，而是这栋旧建筑需要额外设置才能让她和其他学生一样自然进入。
- 第11集：体育馆本身具备现代无障碍条件，她和其他一年级学生一样自然参加毕业典礼；不把这个动作拍成“问题已经解决”的总结。
- 新礼堂真正建成后的无障碍使用属于未来学校生活，可在更远时间跨度的尾声 / 后记中自然出现，但不是第一季必须兑现的 callback。

### 旧舞台地板
- 前期：只是大家日常踩过的东西，不强调。
- 第10集：评估 / 重建准备时才意识到它承载了大量真实身体记忆，并主张保留再利用。
- 第一季结束：材料进入编号、保护、保存或再利用准备阶段，不强行展示已经铺进新舞台。
- 未来新礼堂：部分重新铺入新舞台，让下一届学生实际站在旧材料上。

### 佐藤二朗门卫
- 第1集：每天“早上好”，同时轻声维护校门正常通行。
- 全季：成为校门这一时间节点的固定见证者。
- 第12集：一期生最后离开时只说一句普通的“路上小心”。

### 松重丰“老样子”
- 前中期：食堂建立固定菜单与“老样子？”的日常关系。
- 第12集：最后一次“老样子？”成为日常告别。

### 南的“以后还有”感
- 前期：对“最后一次”没有敏感，总觉得以后还会再来。
- 第7集：合宿结束仍按普通放学式解散，不产生“最后一个夏天”自觉；这条必须继续保留给后段。
- 第11集：突然通过“明天不用来学校了”这类实际事实意识到结束是真的。

### 裙摆齐线 / 裙摆规则
- 第1集：放学宽景里，高三女生因为三年的身体习惯偶然短暂齐线；摄影机不停，普通学生穿过后构图自然散掉。
- 第2集：制服从典礼表面变成日常规则。规则没有被推翻；生驹与飞鸟分别改变自己与规则发生关系的方式。
- 全季：齐线作为乃木坂女学院视觉母题可以反复出现，但不得每次都被拍成 callback。
- 第12集：大家一起跑下坡，裙摆彻底失去齐线；此时已经没人需要证明她们“像不像乃木坂”。
