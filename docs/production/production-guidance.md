# 一、既有作品进入正片的版权清理

当真实存在、仍受著作权保护的戏剧、小说、歌曲、影像、美术作品或其他表达进入正片时，必须区分两层事实：

1. **剧中世界的使用是否成立；**
2. **现实电视剧制作是否取得相应利用许可。**

剧中学校、社团或人物已经取得上演、演奏、展示等许可，不自动赋予现实制作方录音、录像、复制、广播、网络传播、翻译、剪辑或宣传使用的权利。

日本《著作权法》第 38 条对非营利、免费且出演者无报酬的现场上演等设有例外，但文化厅明确说明，该例外不包括复制与公众传播。商业电视剧拍摄剧中上演并用于电视播出、流媒体及宣传时，不得仅凭剧内活动属于免费文化祭而跳过权利清理。

同样，不因为只使用“几句”“十几秒”就自动视为合法引用。未经制片法务确认，不以引用例外、短句缺乏独创性或所谓行业惯例代替许可。

## 最低清理范围

涉及既有受保护作品时，制片团队至少书面确认：

- 权利人或合法管理窗口；
- 使用作品、版本及具体段落；
- 剧中上演 / 演奏或其他利用方式；
- 录音、录像与复制；
- 电视播出、网络流媒体、点播及重播；
- 使用地域、语言与期限；
- 字幕、配音、翻译、节选、剪辑及必要改编；
- 预告片、宣传片、花絮及其他营销素材；
- 剧本、制作资料或公开仓库中能否保存原文；
- 片头、片尾及宣传材料中的署名格式；
- 费用、使用次数与权利方提出的其他限制。

在许可完成前：

- 正片母稿只使用清楚的 `RIGHTS CLEARANCE PENDING` 占位；
- 不把受保护原文写入公开 Git 仓库；
- 不用编剧仿写台词冒充原作；
- 可以锁定需要的戏剧功能、时长、演员数量、发言交叠方式与剪辑位置；
- 获得书面许可后，才由指定版本替换占位，并记录来源页码 / 段落与许可编号。

如果许可最终未取得，必须回到主创讨论替代方案；不得由执行人员静默换词、拼接近似台词或把作品改成含混的影射版本。

# 二、EP04—EP05｜《12人の優しい日本人》

## 剧中事实

乃校与榊陵联合制作三谷幸喜《12人の優しい日本人》。剧中制作团队已在四月下旬至五月完成正式演出许可、选角与读本启动；该事实继续由 `docs/episodes/ep04/joint-play-production-lock.md` 管理。

剧内许可只证明学校项目现实成立，不代替现实电视剧的影视利用许可。

## S07 排练段落

EP04 S07 应最终落到原作中一个明确段落，而不是由编剧泛写“多人争论”。目标段落满足：

- 三至四名演员连续抢入或交叠；
- 当前论证仍在推进，不是独立名场面展示；
- 不使用著名金句；
- 不借原作台词影射、解释或总结 EP04 的人物主题；
- 正片预计使用约 12—20 秒、三至五句真实台词。该长度是戏剧与节奏选择，不是法律安全线；
- 榊陵学生演出在该段自然结束以后说“好，停在这里”，不为截取授权长度而打断表演。

在影视使用许可完成以前，`screenplay.md` 不写入原作台词，只标记：

> `[RIGHTS CLEARANCE PENDING｜《12人の優しい日本人》授权段落，约 12—20 秒]`

许可完成后，应使用权利方确认的正式版本逐字替换，并由制片法务复核实际拍摄、剪辑、字幕与成片使用没有超出范围。

## EP05 正式演出

EP05 如取得更长的正式演出画面或声音，同样单独核定使用范围；S07 的短段许可不得自动扩张为 EP05 全部演出许可。
