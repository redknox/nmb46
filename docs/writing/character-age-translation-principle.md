# 《乃木坂女学院》人物年龄转译原则

> 状态：**项目级 LOCKED 写作原则。**
>
> 本文件处理一个贯穿全剧的改编问题：现实中的乃木坂46一期生出生年份、入团年龄与公开成长素材并不相同，本作却把她们放进了同一套十七八岁的校园时间。编剧必须转译人物，不能只把成年成员换上高中制服。

---

# 一、核心定义

《乃木坂女学院》不是现实乃木坂某一年的校园复刻，也不是成员真实十七岁经历的传记重建。

本作采用：

> **剧内年龄服从本作 canon；人物性格可以参考其整个公开生涯；后来获得的完成度、地位与自我解释，必须重新翻译回十七八岁。**

可以从后来的影像辨认一个人长期稳定的性格倾向，但不能因此假定高中时期的她已经：

- 知道自己将成为怎样的人；
- 掌握后来形成的媒体表达、社交分寸与情绪处理能力；
- 拥有现实团体中的选拔位置、前后辈权力或公众形象；
- 能用成年后的语言准确解释自己的欲望、边界与困难；
- 知道任何现实生涯的结果。

> **后来的影像可以证明一种潜能长期存在，不能直接充当她十七岁时的行为说明书。**

---

# 二、为什么不能选择一个现实年龄切片

## 1. 不采用统一的现实年份

如果统一参考现实中的某一年，成员当时的年龄差、团内地位、选拔经历与前后辈关系会一起进入人物。现实中年长成员对年少成员形成的姐姐 / 妹妹感，不能自动成为本作同龄学生的关系。

任何亲近、照顾、距离或权威，都必须在乃校的班级、经历与人物选择中重新成立。

## 2. 不机械参考“每个人真实十七岁”

一期生的公开素材并不对称：有人十几岁入团，成长过程被长期记录；有人入团时已经成年，真正的少年时期几乎没有公开影像。

机械截取真实十七岁，会让素材丰富者显得拥有更真实的青春，让素材稀少者从登场起就像成熟成年人。那不是人物差异，而是档案差异。

> **飞鸟等年少入团成员不能垄断少年感；白石、桥本、卫藤等较晚进入公众视野的成员，也必须拥有尚未完成的时期。**

---

# 三、转译时保留、剥离与重新生长什么

| 层级 | 处理方式 | 例子 |
|---|---|---|
| 稳定倾向 | 可以保留 | 注意力方向、幽默方式、竞争欲、审美直觉、对秩序或亲密的基本反应 |
| 后天完成度 | 必须剥离或降级 | 镜头意识、成熟圆场、自我品牌、职业自信、成年后的关系分寸 |
| 现实身份 | 不得继承 | 选拔位置、中心成员地位、毕业叙事、现实团内年龄权威 |
| 少年状态 | 必须重新生长 | 误判、过度用力、尚未学会求助、不能命名自己的感受、正确欲望的不成熟表达 |

“降龄”不等于统一幼稚化，也不等于让所有人冲动、天真或词不达意。

人物可以因为家庭、能力或经历而早熟；但早熟不等于完成。她可能会解决实际问题，却不会解释别人为什么想靠近她；会照顾气氛，却不知道这种照顾正在消耗自己；清楚自己想被认可，却还不会体面地争取。

> **少年感不是可爱表演，而是人物尚不知道自己正在成为谁。**

---

# 四、每次写作必须追问的四件事

当一个主要人物在本集受力、改变或被重点照亮时，编剧至少要在行为判断中回答：

1. **她此刻还没学会什么？**
2. **她怎样误解自己，或暂时无法为自己命名？**
3. **她未来会成为优点的东西，现在以什么不成熟的形式出现？**
4. **这项能力来自剧内已经发生的经历，还是从成年影像里偷渡进来的？**

这些问题用于创作判断，不要求每集建立新的表格或让角色在对白中回答。

如果人物总能准确理解关系、妥善表达边界、及时照顾所有人的感受，并用最体面的方式完成选择，应进行一次**成年完成度泄漏检查**。

---

# 五、关系也需要年龄转译

现实团体中的关系可以提供化学反应参考，不能直接复制其成立条件。

- 现实年龄差造成的姐姐 / 妹妹位置，必须在本作重新获得；
- 后来形成的默契，不能成为开学时已经存在的默认亲密；
- 现实中的公众形象不能替代剧内同学对她的认识过程；
- 后来回望青春的感伤，不能提前进入仍身处其中的人物。

观众可以知道她们将来会走散；人物现在不需要知道。

EP06的家庭餐厅曾暴露过这一风险：当四个人太准确地理解沉默、太及时地照顾彼此，场景会像成年人回看青春。把注意力放回菜单、饮料、芭菲、争论与明天要交的练习册，人物才重新回到她们正在经历的年龄。

---

# 六、使用边界

本原则不是要求编剧为每名角色指定一个现实参考年份，也不是建立“真实成员性格考据”的唯一答案。

它只锁定以下边界：

> **辨认长期稳定的人，不继承后来完成的她。**

> **年龄可以在设定中被拉平，成长不能被直接跳过。**

如果某项成年时期的能力需要出现在高中人物身上，必须能从剧内家庭、训练、制度或既有经历中得到支持；否则，应把它退回仍在形成、偶尔失败、本人尚不能完全理解的状态。

本原则与 `mixed-gender-youth-scene-principles.md` 中的判断共同生效：

> **制度可以成熟，人仍然是十七八岁的。**
