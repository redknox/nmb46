## 第 1 页｜本集创作首页

填写：EP、集名、本任 Assistant 编剧、开工日期、目标时长、特殊形式。

主创手写区：

- Room Opening：此刻想看见谁、什么令人兴奋、编剧主动带来了什么；
- 感觉是否已经对齐；
- 主创确认：可以进入工作状态；
- 本集为什么存在；
- 表层发生什么；
- 本集真正改变什么；
- M / S / L / R；
- 禁止提前消费；
- 明确留给后续；
- 开场状态；
- 结尾状态 / 最后一幅画面；
- 非拍不可的三场戏；
- 当前最大的担心；
- 如果不好看，最可能死在哪里。

## 第 2 页｜STEP 0–8：故事形成

每一步记录日期、Gate / 状态、主创判断和必要备注。

0. 本集任务定义：为什么存在，什么绝不能提前消费。
1. 现实 / 制度压力测试：如果摄影机没来，世界本来怎样运转。
2. 人物行为引擎跑测：去掉剧情需要，她仍会这样做吗。
3. Beat Sheet：核心因果、转折和结尾。
4. Beat 压力测试：时长、假冲突、万能中枢与人物弧透支。
5. Scene List：事情怎样成为连续生活。
6. Scene List 压力测试：传送、荧光笔感、场次过碎与空间问题。
7. Treatment：演员和摄影机是否真的能够完成。
8. Treatment 压力测试：执行、专业、客串权重与时间成本。

## 第 3 页｜STEP 9–17：剧本形成与定稿

9. Screenplay：动作、对白、停顿、关系、喜剧与场景结尾。
10. 连续性审查：时间、位置、信息、道具、物理与因果。
11. 观众视角审查：A / B / C 与 GREEN / YELLOW / RED。
12. 逐场五层锁定：人物、常识、关系对白、解释减法、观众复核与 World Promotion。
13. 整集节奏 / 重复审查：同质、过长、重复动作、点名感与气口。
14. 表演 / 镜头 / 空间 / 声音审查：不要拍“这一刻很重要”。
15. 最终无工具通读：好看吗，人活着吗，会不会太正确。
16. FINAL：停止偏好型无限润色；只有硬伤允许重开。
17. Canon Propagation：Add + Remove + Reclassify；完成 Link / Status Audit。

## 第 5 页｜主创指令集

### 指令集

| 指令 | 默认含义 |
|---|---|
| 发散 | 给出不同可能性，不做决定、不落盘 |
| 进入工作状态 | Room Opening 对齐完成，允许进入 STEP 0 |
| 收束 | 停止扩展，形成当前方案 |
| 写一版看看 | 给完整草案，只展示 |
| 重构 | 保留目标，重新组织实现方式 |
| 磨 | 留在当前场景继续找准确状态 |
| 挑刺 | 主动寻找不真实、不好看、太像编剧的地方 |
| 压力测试 | 暂停推进，从反方攻击当前方案 |
| 查现实 | 先确认现实行业、制度、礼仪或空间怎样运作 |
| 只看观众 | 忘掉编剧知识，只承认正片可见信息 |
| 克制 | 减少作者与表演痕迹，不等于消灭情感 |
| 去解释 | 删除角色、画面或声音替观众总结意义的部分 |
| 先过 | 当前方向认可；结合上下文判断是否锁定 |
| 锁 | 写入权威文件、更新状态、commit 并 push |
| 推进 | 锁定已确认单元，进入下一项 |
| 继续 | 结合上一句，继续磨或锁后推进 |
| 完整推送 | 清点全部已确认未发布内容并完成传播 |
| 回到 STEP N | 因明确问题回退，不在后段补洞 |
| 先别落盘 | 所有内容留在编剧室 |

## 第 6 页｜术语速查

- **STEP / Gate**：流程节点 / 进入下一层前的通过条件。
- **ROOM OPEN / DEVELOPMENT / FINALIZATION / POST-FINAL**：编剧室发散 / 正式开发 / 定稿传播 / 交棒后非 canon 状态。
- **共同创作 / Assistant 先行检查**：必须共同判断 / Assistant 可先完成机械工作、发现取舍再返回编剧室。
- **DRAFT / REVIEW / LOCKED / CLOSED / FINAL**：文件或审查状态。
- **Beat / Scene / Sequence**：因果节拍 / 场景 / 连续段落。
- **Treatment / Screenplay**：可拍执行层 / 正片剧本母稿。
- **M / S / L / R**：主推进 / 次推进 / 被照亮 / 休息。
- **A / B / C**：必须明白 / 最好感觉到 / 只留潜意识。
- **GREEN / YELLOW / RED**：观众信息足够 / 依赖制作 / 必须修。
- **Canon**：后续可以引用的当前权威事实。
- **Canon Propagation**：把 FINAL 事实同步到全库。
- **Add / Remove / Reclassify**：新增 / 删除旧事实 / 调整事实等级。
- **Form Contract**：特殊形式集的时间与不可作弊合同。
- **Diegetic / Camera / Target Clock**：世界时间 / 摄影机时间 / 成片时长。
- **Scene → World Promotion**：局部发现经主创确认后升级为长期世界规则。
- **硬伤 / 偏好修改**：现实、连续性、人物、A 类信息或制作问题 / 只是另一种喜欢。
- **LOCK / FINAL**：锁定当前单元 / 停止整集偏好型无限润色。

固定护栏：

> 如果摄影机今天没来，这件事本来会发生吗？
>
> 不值得拍的，宁可不拍。
>
> 专业归专业，情感归情感。克制不是没有反应。
>
> 观众必须知道故事，不必知道我们的感悟。
>
> 文件回答“现在是什么”；Git 回答“以前是什么”。
