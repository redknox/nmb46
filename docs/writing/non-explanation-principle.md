# 《乃木坂女学院》编剧准则｜不解释

> 状态：**项目级 LOCKED 原则。**

# 本剧的主旨：不替观众解释意义

> **观众必须知道故事，不必知道我们的感悟。**

角色可以说明自己真实需要说明的事。场内的人可以解释事实、任务、作品、专业要求与真实困难；没有人负责替场外总结“这意味着什么”。

本剧默认拒绝“嘴替式解释”：人物不能因为编剧担心观众没懂，就突然替观众复述潜台词、总结人物关系、解释制度、翻译专业判断，或把刚刚已经通过行动 / 表演 / 空间 / 声音成立的东西再说一遍。

## 是否允许说明的核心判断

角色可以解释，而且有时可以解释得很长，但前提是：

> **场内的另一个人真实需要这段信息，才能继续做眼前的事。**

例如：作品负责人要求演唱者改变一个已经成熟的版本，就有责任把新的作品理解、声音要求、进入方式和具体工作条件讲清楚；演唱者也可以基于自己的专业位置继续追问。这里的解释服务于排练本身，不服务于观众补课。

动作、画面和声音并不天然比对白高级。如果一次凝视、停留、插镜或配乐只为了提醒观众“这里很重要”，它和嘴替式对白是同一种解释。

反过来，如果一段表达的真实功能只是：

- “怕观众没听懂”；
- “替上一句翻译”；
- “把人物心理或场景意义讲出来”；
- “把大家已经知道的共同背景再说一遍”；
- “替专业场面配一个外行入口”；
- “总结刚才那个动作意味着什么”；

则优先删除。

## 具体纪律

- **不安排嘴替。** 不为了观众理解，额外找一个角色问明显的问题或替另一个角色做白话总结。
- **不解释共同知识。** 长期同学、同事、教师之间已经知道的背景，不因观众第一次看到就重新互相说明。
- **不把潜台词说成台词。** 能由动作、停顿、位置、工作选择、声音变化、后果成立的内容，不再口头认证。
- **不要求当场懂。** 一个动作可以到下一场、下一集甚至重看时才完全显出意义；不必在发生当下立即给观众答案。
- **专业人物可以真的专业。** 允许真实术语、真实工作问答与真实的信息密度；不能为了“照顾观众”把专业角色降格成教程主持人。
- **提问必须属于提问者。** 角色提出问题，是因为她本人需要知道答案，而不是因为编剧需要借她问出观众 FAQ。
- **解释不能替代表演。** 如果角色已经通过表演做出了判断，就不要再追加一句“所以你其实是……”来确认。
- **画面不能替作者划重点。** 不因对白减少，就安排额外凝视、反应镜头、插镜、慢动作或配乐认证意义。

## EP04 的直接校准

松下洸平可以对高三 SSAA 详细阐述自己为什么要修改一个已经达到演出要求的版本，因为演唱者必须据此改变实际演唱；中元、生田等人也可以从自己的工作位置继续追问。

但松隆子不能站出来替观众翻译松下的艺术判断，也不能补一句“所以平时我们才……”来帮助观众理解堀的 ensemble 教育背景。她知道，学生也知道；除非当下工作真的需要她说，否则她坐着即可。

## 总结句

> **角色负责活在场里，也负责完成场内真实需要的沟通；她不负责把场解释给场外。**

> **可以让观众晚一点懂；不要让人物为了观众早一点懂而说假话。**
