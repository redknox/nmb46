# 《乃木坂女学院》男女学生同场青春基调

> 状态：**项目级 LOCKED 写作 / 表演基调。**
>
> 本文件用于补充 `docs/world/boys-school.md` 中“会注意，但不会失态”的原则。
>
> 这里的“不会失态”绝不等于无性别、无身体、无吸引力，也不等于把男女高中生写成成熟公司的合作人员。

## 一、内部口诀

> **男孔雀开屏，女孔雀欣赏。**

这是编剧室内部的观察模型，不是角色对白，也不是要求每个男生 / 女生都作出同一种反应。

## 二、核心理解

当 17—18 岁的男子校学生进入一所几乎全是女生的女校时，首先发生的往往是身体与自我意识变化，然后才是合作流程。

男生可能：

- 手心冒汗；
- 更注意头发、制服、站姿和声线；
- 不自觉挺直；
- 想显得更可靠、更有趣、更有力量或更帅；
- 原本普通的搬运、说话、开玩笑突然多了一点展示意味；
- 明明注意女生，却努力表现得自己没有在看。

这不是“所有男生都害羞”，而是进入高度异性化环境后自然提高的自我观看与肾上腺素。

## 三、女校主场的不对称

乃木坂女学院学生处在自己的学校、自己的熟人群体里，因此可以比外来的男生更松弛、更大胆。

一群女生在一起时，可以自然出现：

- 大大方方看男生；
- 直接讨论谁更帅；
- 音量并不一定压到“绝对不能被听见”；
- 发现男生听见以后站直、逞强、装没听见，反而更开心；
- 一边承认“确实挺帅”，一边觉得“他现在这样真的很好笑”。

这不是恶意羞辱，而是青春期里非常真实的观看、被观看与群体胆量。

## 四、吸引力不自动生成恋爱线

本剧明确：

> **不开爱情线，不等于消灭吸引力。**

> **不配对，不告白，不结算；但身体与性别必须存在。**

允许：

- 觉得对方好看；
- 多看一眼；
- 因为被看而改变一点姿态；
- 因为某个动作、声音、力量感、笑法、认真状态而产生短暂吸引；
- 某个人突然穿演出服 / 上舞台后，让熟悉的人重新意识到“原来他 / 她是这样的”。

不要求这些感觉必须：

- 发展成 CP；
- 被朋友起哄；
- 形成告白；
- 产生吃醋；
- 获得后续剧情回报。

青春里大量吸引本来就没有“后来”。

## 五、熟悉以后，性别意识降低但不消失

两校共同工作最初可能是：

> **男生来了 / 女生好多。**

合作增加后，称呼与注意力会逐渐变成：

> **榊陵的人 / 乃校的人。**

再后来：

> **那个舞台组的 / 拿卷尺那个 / 学生会长 / 总说“再左一点”的那个。**

共同劳动会降低最初高浓度的性别紧张，但不能把人物永久写成无性别同事。

偶尔新的身体条件、服装、舞台灯光、距离变化，仍然可以让性别意识突然回来一下。

## 六、与“没有坏人和笨蛋”的兼容

本剧坚持：

> **没有坏人和笨蛋。大家基于自己的职责做重要的事。**

这不意味着所有人都要像成熟成年人一样冷静专业。

更准确的是：

> **制度可以成熟，人仍然是十七八岁的。**

学生可以认真、安全、有责任感，同时也会：

- 逞强；
- 在异性面前突然注意形象；
- 被看以后多使一点力；
- 因为同伴的“开屏”觉得好笑；
- 做完重要工作以后只想赶紧吃东西；
- 一边解决真实问题，一边仍然是青春期的人。

青春感不能靠让人物犯低级错误获得。

## 七、场景执行纪律

男女校同场时，优先检查：

1. 这个场景如果全部改成同性，表演质感是否完全不变？如果完全不变，可能已经去性别化过度。
2. 谁是主场，谁是进入者？人数关系会如何改变胆量？
3. 人物有没有意识到自己正在被看？
4. 他 / 她是否会因为这种意识在动作、音量、姿态上轻微变化？
5. 这些变化是否仍然经过人物自身性格，而不是所有人统一“害羞 / 花痴”？
6. 吸引力能否只存在，不被强迫发展成故事？

## 八、禁止写法

禁止把男女学生同场写成：

- 两个公司部门开项目会；
- 所有人完全没有身体与性别意识；
- 男生出现就全班尖叫；
- 女生只有被看、没有主动观看欲；
- 一出现吸引力就必须建立恋爱候选关系；
- 用“青春悸动”作为拖慢正常工作能力的借口；
- 每次异性同场都安排同样的脸红、偷看、朋友坏笑。

## 九、最终基调

> **男孔雀会开屏；女孔雀会看，而且可能看得很大方。**
>
> **大家仍然会把该做的事做好。**

男女之间的吸引力是青春环境的一部分，不是剧情许可证。
