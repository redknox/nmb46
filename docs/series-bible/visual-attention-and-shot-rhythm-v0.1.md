# 视觉注意力与镜头节奏原则 V0.1

> 状态：**工作原则 / 系列级。**
>
> 目的：避免长对白、仪式、课堂、会议、排练等场景因为视觉输入长期不变而导致观众注意力下降。

## 一、核心原则

> **持续刷新观众的感知输入，而不是机械刷新镜头编号。**

“一个镜头不能超过三秒”可以作为电视导播训练中的强提醒，但本作不把 `3秒` 当成硬性科学阈值，也不把快速切镜头当成唯一解法。

真正需要防止的是：

- 同一构图长期不变；
- 同一景别长期不变；
- 同一人物持续占据画面中心；
- 同一种声音质地持续太久；
- 画面虽然切了，但观众接收到的信息其实没有变化。

换句话说：

> **“切了镜头”不等于“刷新了注意力”。**

## 二、两层刷新

### 1. 微观刷新｜几秒级

同一个场景、同一个讲话段落内部，也要持续给眼睛新的信息。

可用手段包括：

- 正面中景 → 侧面中景；
- 中景 → 宽景 → 细节；
- 说话者 → 听者反应；
- 单人 → 双人 / 群体；
- 人脸 → 手、稿纸、鞋、门、窗、校徽、旧木扶手等动作或物件；
- 固定构图 → 人物进入 / 离开画面；
- 镜头不切，但前景、焦点、身体动作或视线关系发生变化；
- 画面不变，但声音从讲话转成掌声、笑声、椅子声、呼名、歌声等。

这里不要求平均每3秒强制切一次。镜头时长应服从句子、动作和情绪。

但如果一个镜头明显变长，就必须有理由：

- 权威需要建立；
- 紧张需要持续；
- 观众需要观察某个细微动作；
- 静止本身正在产生新的意义。

### 2. 宏观刷新｜几十秒级

即使微观上一直切镜头，如果连续几分钟都在做“说话者 → 反应 → 说话者”，仍然会疲劳。

所以还需要定期改变整段的观看任务，例如：

- 从听讲话，变成看呼名；
- 从现实时间，进入闪回；
- 从个人声音，进入集体歌声；
- 从庄重仪式，落回后台工作；
- 从教室对白，切到走廊、食堂、操场、音乐室等不同空间；
- 从人物心理，切回制度 / 日常运转。

此前 EP01 入学式压力测试中提出的“每30–50秒更换一次视觉或声音语法”，指的是这一层；它不能替代几秒级的微观刷新。

## 三、长对白场景的默认处理

长对白不等于一直拍说话的人。

默认可以在以下元素之间建立节奏：

```text
说话者
→ 听者
→ 群体
→ 空间 / 物件
→ 说话者的新角度
→ 动作细节
→ 再回说话者
```

但不能机械套模板。

原则是：

> **每一次切换都应该让观众获得一点新的信息。**

如果只是为了“别闷”而切到一个没有任何意义的反应脸，反而会产生电视转播感。

## 四、反应镜头的使用边界

反应镜头不是填空。

优先使用三类反应：

1. **信息反应**：观众通过这个人第一次知道一句话产生了什么实际影响；
2. **关系反应**：一个眼神、动作能改变人物关系的理解；
3. **节奏反应**：例如普通在校生听到“食堂什么最先卖完”时轻轻一笑，让庄重空气松一下。

避免：

- 每一句主题台词都切主角；
- 为了提醒观众“这句话和桥本有关”就切桥本；
- 为了提醒观众“这句话很重要”就推近特写；
- 把主演脸当成维持注意力的通用素材。

## 五、长镜头不是禁区

本作不追求短视频式高频刺激。

一个10秒甚至更长的镜头完全可以成立，只要镜头内部仍在发生变化，例如：

- 人物正在走近或离开；
- 视线关系不断改变；
- 前景有人经过；
- 说话节奏发生停顿；
- 观众等待一个动作；
- 画面的意义随着声音逐渐变化。

真正危险的不是“镜头长”，而是：

> **观众在第4秒已经读完了画面，后面的时间却没有任何新东西。**

## 六、EP01 入学式的直接应用

天海校长式辞虽然约3分半，但不能理解为“3分半校长中景”。

推荐微观节奏：

- 开头先允许天海连续占据画面一小段时间，建立权威；
- 随后在校长、普通新生、高三群体、礼堂细节之间自然切换；
- 樱井闪回不仅是剧情内容，也是一次彻底的感知刷新；
- 回到现在以后，不立刻恢复同样的校长正面覆盖；
- 锁定句「そして、よく迷ってください。」可以故意稍微延长镜头，让短暂的“少切”本身变得有重量；
- 樱井欢迎词通过走台动作、食堂句轻笑、普通学生反应降低正式感；
- 新生代表通过略不熟练的身体节奏形成新的画面质地；
- 校歌让全场从“听”变成“共同发声”；
- 真夏的后台低语完成最后一次质地突变。

因此 EP01 入学式要同时满足两件事：

> **微观上，几秒级持续刷新视觉输入；宏观上，几十秒级持续改变观看任务。**

这两层一起工作，才能让八分钟以上的正式场景保持注意力，而不需要把它剪成综艺节目。

## 七、最终检查问题

每个长场景在分镜 / 剪辑前至少问：

- 观众现在在看什么？
- 这个画面她们已经“读完”了吗？
- 下一次刷新来自切镜头、动作、景别、声音，还是空间变化？
- 这个反应镜头有没有新信息？
- 这一分钟和上一分钟的观看任务一样吗？
- 如果故意不切，这个“不切”本身有没有价值？

核心理解：

> **节奏不是切得快，而是观众不断有新的东西可以看、听、理解。**
