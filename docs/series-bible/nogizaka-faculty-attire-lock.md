# 乃木坂女学院｜教职员仪容与工作服装锁定

> 状态：**已锁定 / 系列级视觉与机构礼仪规则。**
>
> 核心：乃木坂女学院没有“教师制服”，但有明确而严格的教职员仪容规范。教师个人审美必须在职业、场合与学院礼仪允许的范围内成立。

## 一、总原则

乃木坂女学院要求学生通过制服学习分寸与共同体意识，因此学校成年人不能以“学生要端正、教师可以随便”的方式生活。

固定理解：

> **如果学院把仪态视为对他人的尊重，那么成年人首先必须做到。**

教师不需要穿成统一复制品，但正常教学日应始终给人一种：

> **“如果现在有家长走进来，我不需要先去换衣服。”**

的准备状态。

服装不直接替人物说明性格，而首先说明：

> **这个成年人怎样工作。**

## 二、三个礼仪等级

### A. 正式仪式级

适用于入学式、毕业式、正式家长活动、校董或法人正式会议、代表学校参加外部活动等。

- 男教师以完整西装、衬衫、领带、正式皮鞋为基准；
- 女教师采用正式套装、结构清楚的连衣裙 / 裤装等；
- 色彩克制，不用夸张配饰抢夺学校仪式本身的视觉中心；
- 专业工作服、围裙、袖套、训练服等不得进入正式仪式状态。

### B. 普通教学级

- 男教师可根据季节与教学动作脱外套；Cool Biz 时期可无领带，但仍保留明确职业感；
- 女教师不要求统一套装，但轮廓、材质与鞋履应适合教学与家长接触；
- “没有领带”不等于“休闲装”；
- 放松采用减法，而不是把职业服装整体换成日常街头休闲装。

### C. 专业活动级

体育、实验、美术、家庭科、医务等工作可以覆盖普通礼仪服装：

- 体育教师换专业训练服；
- 美术教师加工作罩衣；
- 家庭科教师加围裙 / 必要工作装备；
- 保健室教师穿医务白衣；
- 其他职业活动按安全与实际需要处理。

专业状态结束、回到正式会议 / 家长场合后，应恢复相应礼仪等级。

## 三、角色造型锁定

### 天海祐希｜校长

关键词：**权威不需要提醒别人自己有权威。**

- 剪裁极好，但极少使用需要观众主动注意的设计；
- 深藏青、炭灰、深墨绿、象牙白内搭等克制色系；
- 裤装比例可略高于裙装；
- 首饰少，手表可靠但不做奢侈品展示；
- 正式度主要来自合身、洁净、准确，而不是华丽。

### 武田铁矢｜资深国语教师 / 3-C 担任

关键词：**旧式职业教师，而不是复古 cosplay。**

基础语言：

> 西装外套 + 马甲 + 衬衫 + 领带 + 西裤。

- 正式会议、家长、仪式：完整穿着；
- 进入 3-C 上课后，习惯把西装外套挂好；
- 日常授课标志状态为 **马甲 + 衬衫 + 领带**；
- 大量板书、批作文等具体工作时可加深藏青 / 炭灰 `袖カバー`；
- 袖套不套在西装外套外面；
- 马甲不必与西装完全同套，允许多年形成的稳定搭配；
- 领带可以有明显的长期使用习惯，但始终洁净、结打得认真。

固定理解：

> **他不是在“穿复古”；只是他的穿衣习惯形成得比学生年龄还早。**

### 江口洋介｜体育教师 / 户外活动顾问

撤销“靠穿着随意表现自由”的方向。

普通教学楼状态：

- 白 / 浅蓝等有领衬衫；
- 深色西裤；
- 合体外套；
- 根据季节与场合使用领带。

普通教学状态的放松上限：

> **外套脱下 + 无领带 + 衬衫最上一颗扣子解开。**

- 衬衫仍然整理好并塞入裤腰；
- 真正体育课、跑步、登山、海边训练等换专业训练服；
- 回到教师会议 / 家长场合重新恢复职业服装。

他的“学校之外的风”来自身体和行动，不来自违反学院仪容。

### 松隆子｜音乐教师

关键词：**精确本身就是工作状态。**

- 极简、线条干净；
- 黑、深蓝、石灰、米白等；
- 简洁衬衫 / 薄针织、直线长裤或过膝裙、短外套；
- 演奏时可脱外套，但袖口、手腕、裤脚始终利落；
- 不通过严肃服装把她写成“守旧教师”。

### 满岛光｜美术教师

关键词：**乃校允许的最大个人审美，但仍然属于乃校。**

- 剪裁仍然职业；
- 材质比其他教师更明显，可使用亚麻、羊毛、棉布与灰绿、泥土色、褪蓝等；
- 轮廓可稍宽松，但不能邋遢；
- 进入美术室后在正规服装外加真正使用过的工作罩衣；
- 工作罩衣可有无法完全清除的颜料痕迹，但不把污渍当造型装饰。

### 新垣结衣｜一年级班主任

关键词：**柔和不是邻家姐姐，而是低压的专业者。**

- 浅灰、沙色等低对比度；
- 短外套、干净衬衫、深色裤装或长裙；
- 材质可以柔和，但轮廓不能毛茸茸、松垮或过分少女化；
- 视觉上必须明确是教师，而不是学姐。

### 石原里美｜保健室教师

关键词：**身体空间里的职业边界。**

- 基础服装仍然端正：衬衫 / 薄针织、长裤、低跟鞋；
- 工作时加简洁、干净、真正像学校医务用品的白衣；
- 不采用时尚医生式夸张白大褂；
- 在适当的非诊疗时刻可脱下白衣填写记录，让学生短暂看到“职业外壳下面的普通成年人”。

### 安藤樱｜家庭科教师

关键词：**进入工作前的动作本身就是专业。**

普通状态不做“手作达人”卡通化打扮。

进入家庭科室：

> 外套脱下 → 围裙系好 → 袖子规范处理 → 手表取下放好 → 必要时整理头发。

工作状态的转换比服装本身更重要。

### 光石研｜事务长

关键词：**属于学校，但不属于教室。**

- 深色、耐穿、行政职员式西装；
- 不需要“教师上课后脱外套”的状态变化；
- 文件夹、钥匙、识别证、笔等工作物件自然进入造型；
- 鞋与服装要适合一天在办公室、礼堂、仓库与校门之间大量步行。

## 四、制作原则

1. 不用服装直接给性格贴标签；优先表现职业动作。
2. 同一套仪容规范之下允许个人差异，但差异不能破坏“乃木坂女学院成年人首先代表学校”的机构感。
3. 教师“脱外套、换工作服、系围裙、戴袖套”等动作可以成为状态转换语言。
4. 成人角色不能靠“比学生更随便”来体现自由。
5. 制服化的是行为标准，不是所有人的衣柜。

固定总结：

> **学生通过制服学习怎样成为乃木坂女学院的人；教师没有统一制服，因为学院默认他们已经知道怎样代表这里。**
