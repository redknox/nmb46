# 乃木坂女学院｜教职员仪容与工作服装锁定

> 状态：**已锁定 / 系列级视觉与机构礼仪规则。**
>
> 核心：乃木坂女学院没有“教师制服”，但有明确而严格的教职员仪容规范。教师个人审美必须在职业、场合与学院礼仪允许的范围内成立。

## 一、总原则

乃木坂女学院要求学生通过制服学习分寸与共同体意识，因此学校成年人不能以“学生要端正、教师可以随便”的方式生活。

固定理解：

> **如果学院把仪态视为对他人的尊重，那么成年人首先必须做到。**

教师不需要穿成统一复制品，但正常教学日应始终给人一种：

> **“如果现在有家长走进来，我不需要先去换衣服。”**

的准备状态。

服装不直接替人物说明性格，而首先说明：

> **这个成年人怎样工作。**

## 二、三个礼仪等级

### A. 正式仪式级

适用于入学式、毕业式、正式家长活动、校董或法人正式会议、代表学校参加外部活动等。

- 男教师以完整西装、衬衫、领带、正式皮鞋为基准；
- 女教师采用正式套装、结构清楚的连衣裙 / 裤装等；
- 色彩克制，不用夸张配饰抢夺学校仪式本身的视觉中心；
- 专业工作服、围裙、袖套、训练服等不得进入正式仪式状态。

### B. 普通教学级

- 男教师可根据季节与教学动作脱外套；Cool Biz 时期可无领带，但仍保留明确职业感；
- 女教师不要求统一套装，但轮廓、材质与鞋履应适合教学与家长接触；
- “没有领带”不等于“休闲装”；
- 放松采用减法，而不是把职业服装整体换成日常街头休闲装。

### C. 专业活动级

体育、实验、美术、家庭科、医务等工作可以覆盖普通礼仪服装：

- 体育教师换专业训练服；
- 美术教师加工作罩衣；
- 家庭科教师加围裙 / 必要工作装备；
- 養護教諭在保健室工作时可穿医务白衣；
- 其他职业活动按安全与实际需要处理。

专业状态结束、回到正式会议 / 家长场合后，应恢复相应礼仪等级。

外聘讲师、学校医、管理员、食堂与资料室等人员不强行套用任课教师西装规则；他们仍需符合学院的整洁、职业、场合意识。**专业工作服本身可以是礼仪的一部分。**

## 三、角色造型锁定

### 天海祐希｜校长

关键词：**权威不需要提醒别人自己有权威。**

- 剪裁极好，但极少使用需要观众主动注意的设计；
- 深藏青、炭灰、深墨绿、象牙白内搭等克制色系；
- 裤装比例可略高于裙装；
- 首饰少，手表可靠但不做奢侈品展示；
- 正式度主要来自合身、洁净、准确，而不是华丽。

### 武田铁矢｜资深国语教师 / 3-C 担任

关键词：**旧式职业教师，而不是复古 cosplay。**

基础语言：

> 西装外套 + 马甲 + 衬衫 + 领带 + 西裤。

- 正式会议、家长、仪式：完整穿着；
- 进入 3-C 上课后，习惯把西装外套挂好；
- 日常授课标志状态为 **马甲 + 衬衫 + 领带**；
- 大量板书、批作文等具体工作时可加深藏青 / 炭灰 `袖カバー`；
- 袖套不套在西装外套外面；
- 马甲不必与西装完全同套，允许多年形成的稳定搭配；
- 领带可以有明显的长期使用习惯，但始终洁净、结打得认真。

固定理解：

> **他不是在“穿复古”；只是他的穿衣习惯形成得比学生年龄还早。**

### 江口洋介｜体育教师 / 户外活动顾问

撤销“靠穿着随意表现自由”的方向。

普通教学楼状态：

- 白 / 浅蓝等有领衬衫；
- 深色西裤；
- 合体外套；
- 根据季节与场合使用领带。

普通教学状态的放松上限：

> **外套脱下 + 无领带 + 衬衫最上一颗扣子解开。**

- 衬衫仍然整理好并塞入裤腰；
- 真正体育课、跑步、登山、海边训练等换专业训练服；
- 回到教师会议 / 家长场合重新恢复职业服装。

他的“学校之外的风”来自身体和行动，不来自违反学院仪容。

### 松隆子｜音乐教师

关键词：**精确本身就是工作状态。**

- 极简、线条干净；
- 黑、深蓝、石灰、米白等；
- 简洁衬衫 / 薄针织、直线长裤或过膝裙、短外套；
- 演奏时可脱外套，但袖口、手腕、裤脚始终利落；
- 不通过严肃服装把她写成“守旧教师”。

### 满岛光｜美术教师

关键词：**乃校允许的最大个人审美，但仍然属于乃校。**

- 剪裁仍然职业；
- 材质比其他教师更明显，可使用亚麻、羊毛、棉布与灰绿、泥土色、褪蓝等；
- 轮廓可稍宽松，但不能邋遢；
- 进入美术室后在正规服装外加真正使用过的工作罩衣；
- 工作罩衣可有无法完全清除的颜料痕迹，但不把污渍当造型装饰。

### 新垣结衣｜一年级班主任

关键词：**柔和不是邻家姐姐，而是低压的专业者。**

- 浅灰、沙色等低对比度；
- 短外套、干净衬衫、深色裤装或长裙；
- 材质可以柔和，但轮廓不能毛茸茸、松垮或过分少女化；
- 视觉上必须明确是教师，而不是学姐。

### 石原里美｜養護教諭 / 保健室

关键词：**身体空间里的职业边界。**

- 正式职能按日本学校制度理解为 `養護教諭`，不是驻校医生；
- 基础服装仍然端正：衬衫 / 薄针织、长裤、低跟鞋；
- 保健室工作时可加简洁、干净、真正像学校医务用品的白衣；
- 不采用时尚医生式夸张白大褂；
- 在适当的非处置时刻可脱下白衣填写记录，让学生短暂看到“职业外壳下面的普通成年人”。

### 苍井优｜茶道部顾问

关键词：**教传统的人，不需要每天把自己穿成传统。**

普通教学日：

- 结构简单的衬衫 / 薄针织；
- 过膝长裙或活动方便的长裤；
- 轻而有结构的短外套；
- 低跟鞋；
- 墨绿、灰褐、米白、深蓝等安静色系。

进入茶室时真正重要的是：

> 外套脱下 → 手表与易碰器具的饰物处理好 → 袖口整理 → 以干净、安静、可工作的状态入席。

- 日常茶道指导不以和服为默认；
- 学校纪念茶席、正式茶会等场合可穿和服；
- 和服出现得少，反而能保留其正式意义；
- 不用“传统服装”证明她懂传统。

### 柄本佑｜世界史教师

关键词：**衣服正规，视线却总落到历史里的普通人。**

- 炭灰 / 深藏青西装或极克制的职业搭配；
- 普通衬衫与带一点暖色但不过分显眼的领带；
- 冬季可加很薄的 V 领针织，但不与武田的西装马甲撞轮廓；
- 皮鞋维护良好；
- 不做 tweed 教授、眼镜链、围巾等“历史老师 costume”。

他的个人辨识度主要来自动作和材料：地图、史料复制件、旧照片、统计表，而不是复古衣柜。

### 吉高由里子｜国语 / 现代文教师

关键词：**语言正在现在发生。**

- 比武田更现代，但不能靠“随性文艺”制造差异；
- 烟蓝、深绿、灰、米色、低饱和酒红等可作为个人长期偏好；
- 衬衫 / 薄针织 + 直线裤装或过膝裙 + 软结构短外套；
- 课堂动作大时可脱外套，袖口只做整齐、有限的调整；
- 不使用大围巾、夸张长裙、咖啡杯等“文学女教师”符号。

她与武田的差异不是“年轻 vs 老派”，而是：武田让语言带着很多届学生留下的时间，她更擅长把学生正在说的普通现代语言重新听一遍。

### 安田显｜理科教师

关键词：**安全程序本身必须被观众看见。**

普通教学楼状态保持乃校教师职业轮廓。进入实验室后：

> 外套挂好 → 领带按实验需要固定或取下 → 实验白衣 → 必要护目镜 / 手套 → 检查学生状态 → 开始实验。

- 白衣是安全工作服，不是“科学家造型”；
- 口袋可有白板笔、细记号笔、计时器等实际工作物；
- 不用试管、护目镜常驻等符号制造理科角色；
- 实验失败时服装与动作仍保持程序化，不把失败拍成戏剧事故。

固定工作气质：

> **先让共同实验可靠，再讨论哪里出了问题。**

### 小日向文世｜教务主任

关键词：**学校每天的课表真的需要有人让它成立。**

- 深藏青 / 炭灰完整西装为常态；
- 白或淡蓝衬衫、克制领带、正式但适合大量步行的皮鞋；
- 普通任课教师会因授课动作脱外套，他作为教务主任在校内公共区域保持外套在身上的时间更长；
- 不用袖套、钥匙串等抢占光石事务长的行政视觉语言；
- 手中的课表、教室变更表、教师会议资料比配饰重要。

与光石研的区别：

> **光石负责学校作为机构怎样运转；小日向负责“今天哪些老师在哪间教室给哪些学生上课”怎样真的发生。**

不把他拍成“爱抓纪律的教头”或副校长喜剧角色。

### 安藤樱｜家庭科教师

关键词：**进入工作前的动作本身就是专业。**

普通状态不做“手作达人”卡通化打扮。

进入家庭科室：

> 外套脱下 → 围裙系好 → 袖子规范处理 → 手表取下放好 → 必要时整理头发。

工作状态的转换比服装本身更重要。

### 池松壮亮｜摄影部外聘讲师

关键词：**摄影器材是工作物，不是造型配件。**

- 外聘身份允许比任课教师少一点成套感，但仍保持进入名门校园应有的专业完成度；
- 深色工作夹克 / 简洁单西、衬衫或干净薄针织、长裤、适合久站与移动的鞋；
- 拍摄时可以蹲、靠近地面、快速移动，因此服装必须真的允许工作；
- 相机背带、备用电池、存储卡等只按实际需要出现；
- 禁止贝雷帽、艺术围巾、故意旧衣等“摄影师”符号。

正式家长 / 校内公开活动若以讲师身份列席，则提高到完整职业状态。

### 松下洸平｜合唱指挥

关键词：**身体是指挥工具，但不是舞台明星。**

- 排练前可为简洁西装 / 单西 + 衬衫 + 长裤；
- 真正进入长时间排练时，外套脱下，保持手臂与肩部动作自由；
- 袖口处理整齐，鞋适合长时间站立；
- 正式演出回到深色完整 concert / formal suit 语言；
- 不用高领黑毛衣、长围巾等“艺术指挥家”刻板造型。

他的状态变化应让观众感到：

> **现在不是在“上课”，而是一群人的呼吸、声音与身体要被组织到一起。**

### 磯村勇斗｜学校医

关键词：**他是医生，但不是每天坐在乃校保健室里的年轻男老师。**

制度边界：

- `学校医` 与 `養護教諭` 分工不同；石原负责日常保健室经营、学生健康观察、应急处置与校内协调，磯村作为医师提供医学判断、健康诊断及专业指导；
- 不设定为每天常驻校园；具体来校频率按剧情和学校制度需要，不做无依据的固定值。

造型：

- 到校参加正式会议 / 专业协商时可为简洁职业西装或医生式专业着装；
- 健康诊断、医学检查或需要临床工作的场合使用真正的医用白衣及必要装备；
- 不把听诊器常年挂在脖子上；
- 不靠白大褂制造“年轻帅哥医生”出场。

他的服装首先告诉观众：**这次学校需要医学判断。**

### 宫崎葵｜校史资料室管理员

关键词：**旧的是她保管的东西，不是她本人。**

- 简洁衬衫 + 细针织 / 开衫 + 直线裤装或朴素长裙；
- 适合久站、搬档案盒与在资料架之间移动的鞋；
- 比任课教师少一点“随时进入课堂”的结构感，但仍整洁、安静、专业；
- 不使用复古眼镜、白手套常驻、古董裙装等档案馆 stereotype。

真正的职业造型来自动作：

> 处理资料前整理桌面 → 按资料类型采用合适的手部处理方式 → 原件旁只用安全的记录工具 → 饮料远离资料。

历史感属于档案，不属于管理员的 costume。

### 小林薰｜旧礼堂管理员

关键词：**专业工作服本身就是对建筑负责。**

- 深灰 / 藏青工作夹克；
- 同系耐用工作裤；
- 防滑、耐磨工作鞋；
- 手套按具体维护任务使用；
- 工作服整洁但允许真实使用痕迹。

随身物件只保留真实需要：钥匙、小手电、卷尺、简易记录本等。

禁止补丁老头、破毛衣、满腰工具等“守护旧建筑几十年”的表演性造型。

他是最常触摸旧礼堂的人，也应当是最少把旧礼堂浪漫化的人。

### 光石研｜事务长

关键词：**属于学校，但不属于教室。**

- 深色、耐穿、行政职员式西装；
- 不需要“教师上课后脱外套”的状态变化；
- 文件夹、钥匙、识别证、笔等工作物件自然进入造型；
- 鞋与服装要适合一天在办公室、礼堂、仓库与校门之间大量步行。

### 松重丰｜食堂负责人

关键词：**卫生流程比“大厨人格”重要。**

- 后厨使用清洁、规范的厨房工作服、围裙、必要头发卫生装备与防滑鞋；
- 售餐区继续保持同一套集体供餐职业语言，不用夸张厨师帽；
- 围裙不是人格，不用“温暖食堂大叔”造型替人物做情绪工作；
- 收餐后的归位、清洁、剩余数量记录、售罄牌收回等动作可成为他的时间感。

学生记得的是“今天还有没有布丁”；成年人记得的是今天如何把一整个食堂收回到明天还能继续运转的状态。

## 四、外聘与非教学人员的统一边界

1. 外聘讲师进入校园不等于可以完全按娱乐行业 / 艺术行业日常穿着；应尊重学校场合，但保留专业所需活动性。
2. 管理员、食堂、资料室、体育、实验等岗位若专业工作服更合理，则**正确的工作服比西装更符合乃校礼仪**。
3. 学校医不是保健室常驻教师；養護教諭也不是医生。两者在画面和职责上必须区分。
4. 锁定造型不等于锁定出场频率。成人角色继续遵守素材池密度原则：剧情需要才出现。

## 五、制作原则

1. 不用服装直接给性格贴标签；优先表现职业动作。
2. 同一套仪容规范之下允许个人差异，但差异不能破坏“乃木坂女学院成年人首先代表学校”的机构感。
3. 教师“脱外套、换工作服、系围裙、戴袖套”等动作可以成为状态转换语言。
4. 成人角色不能靠“比学生更随便”来体现自由。
5. 制服化的是行为标准，不是所有人的衣柜。
6. 同一种服装动作也要服务不同人物：江口脱外套是准备移动，武田脱外套是开始授课，安田脱外套是进入实验安全程序，苍井脱掉多余物件是进入茶席。
7. 不因为演员本人有强烈时尚形象，就让角色突破学校制度。

固定总结：

> **学生通过制服学习怎样成为乃木坂女学院的人；教师没有统一制服，因为学院默认他们已经知道怎样代表这里。**
