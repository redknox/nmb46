# 人物关系图 V1

核心原则不是“谁和谁关系好”，而是：

> 谁在谁面前会变。

同时，从高三日常关系设计开始，正式引入分层关系模型。完整操作版见：

- [`relationship-network-v0.2.md`](./relationship-network-v0.2.md)

## 关系网络基本规则

- A = 私人核心；通常 1—2 人。
- B = 稳定亲近；通常最多 2—3 人。
- C = 熟悉 / 场域关系；学校生活的大部分日常发生在这里。
- 亲密度与接触频率必须分开考虑。
- 关系允许不对称；跨班可以是 A，同班也可以只是 C。
- 普通学生可以进入主要人物的 A / B，避免 360 人的学校缩成主角内部循环。
- 动态关系必须克制；大多数关系整季等级不变。
- 人物成长优先写成主动性、依赖方式和表达方式变化，而不是机械 B→A。

最重要的编剧规则：

> **A 关系负责回答“这个人最终会回到哪里”；C 关系负责回答“今天为什么又出事了”。**

因此，A级关系并不承担全部冲突。白石×桥本、飞鸟×南等核心关系更多提供安全区；真夏×まあや、若月×飞鸟、若月×万理华、桥本×樱井、生田×万理华、真夏×西野等 C 层或场域关系反而更适合制造日常摩擦与剧情推进。

## 关键关系

- 白石麻衣 × 桥本奈奈未：象征之颜 / 现实清醒。桥本是白石的“卸妆区”。
- 白石麻衣 × 樱井玲香：非正式象征 / 正式制度代表。
- 白石麻衣 × 生驹里奈：生驹把白石当“乃木坂答案”，白石最终告诉她不需要变成自己。
- 白石麻衣 × 星野南：南完全不把“乃木坂之颜”当回事，让白石回到普通女孩。
- 桥本奈奈未 × 斋藤飞鸟：桥本不把飞鸟当小孩，也从不拆穿她的敏感。
- 桥本奈奈未 × 樱井玲香：桥本经常逼玲香回答“你自己怎么想”。
- 桥本奈奈未 × 生驹里奈：两种异质感——现实成本 vs 文化归属。
- 樱井玲香 × 秋元真夏：决定 / 执行；学生会与学校事务中属于“领域型 A”，私人关系保持 B。
- 樱井玲香 × 松村沙友理：正式系统 / 校园地下信息网。
- 秋元真夏 × 松村沙友理：制度型社交 / 有机日常社交。
- 秋元真夏 × 斋藤飞鸟：透明的算计与嘴硬的识破，天然喜剧关系。
- 斋藤飞鸟 × 星野南：意义 / 无意义。南天然活在飞鸟最后才抵达的位置；私人核心关系稳定不变。
- 斋藤飞鸟 × 高山一実：毒舌 / 笑。高山不怕飞鸟，但知道边界。
- 生田绘梨花 × 伊藤万理华：两种创作工作方式可能彼此照见，但不固定为技巧 / 直觉、正确 / 自由的二元冲突；EP05没有建立两人的正面冲突。
- 生田绘梨花 × 中元日芽香：不同音乐能力与工作位置。可以存在天赋 / 努力差异，但不能把中元缩成生田的比较对象；重要但不必升级成私人 A。
- 生田绘梨花 × 和田まあや：不同学习方式与不同类型的聪明。
- 生田绘梨花 × 星野南：过度认真 / 天然快乐。
- 高山一実 × 和田まあや：核心喜剧发动机——まあや制造事故，高山负责把事故扩大。
- 高山一実 × 深川麻衣：负责救气氛的人 / 允许气氛不被救的人。
- 松村沙友理 × 卫藤美彩：什么都想知道 / 看见但知道什么时候不问。
- 西野七濑 × 高山一実：高山不会替她讲话；西野可以在她旁边保持安静。
- 西野七濑 × 伊藤万理华：同属美术线，但万理华偏创作者意志，西野偏观察与判断；本季唯一明确锁定的等级变化为 B→A。

- 白石：必须配得上它。
- 樱井：必须对它负责。
- 真夏：必须让它运转。
- 桥本：知道自己必须离开它。
- 飞鸟：不愿承认它对自己很重要。
- 南：只是自然地生活在里面。
- 生田：训练、规则与舞台。
- 万理华：学校能不能容纳不像它的东西？
- 松村：她已经完全掌握的社会网络。
- 高山：她偷偷保存普通日子的地方。
- まあや：一大堆她不完全理解但仍能生活下去的规则。
- 生驹：努力得到的归属。
- 西野：让她第一次意识到“已经准备好的路也可以不走”。
