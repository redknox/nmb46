# 成人角色素材池｜使用规则

> 核心原则：**剧情需要演员，而不是演员需要剧情。**

当前成人角色卡数量很多，这不是承诺所有演员都必须在第一季正式登场，而是建立一个可以在设计桥段时调用的 Story / Casting Material Pool。

## 一、状态字段

后续每个成人角色可以标记以下状态之一：

### CORE

本季结构已经明确需要。

特征：

- 与主要人物弧直接相连；
- 已经存在明确集数或关键场景；
- 删除会影响季结构。

例如当前较接近 CORE 的角色包括：

- 天海祐希｜校长；
- 武田铁矢｜资深国语教师；
- 江口洋介｜体育教师 / 户外活动顾问；
- Fukase｜创作导师；
- 松隆子｜音乐教师；
- 阿部宽｜旧礼堂评估专家；
- 光石研｜事务长；
- 佐藤二朗｜门卫；
- 松重丰｜食堂负责人。

具体状态仍可随分集结构调整。

### LIKELY

已有很自然的使用场景，但还不是季结构不可替代。

例如某门选修课、文化祭、合唱、摄影、家庭科等场景一旦进入分场，角色很容易自然出现。

### POOL

人物与主题非常契合，角色卡保留，但第一季未必需要。

只有当某场戏真正需要这一尺度时才启用。

### HOLD

角色本身很好，但当前功能与其他角色重复，或会让某集过载。

不是删除，只是暂时不使用。

## 二、判断是否启用成人角色的五个问题

每次想加入一个成人角色时，先问：

1. 这场戏如果没有他 / 她，主角之间还能完成吗？
2. 他 / 她带来了什么女生群体内部没有的尺度？
3. 出场后有没有改变女生之间的关系，而不是把注意力吸走？
4. 是因为剧情需要，还是因为演员名字很诱人？
5. 删除这个角色以后，主题会更清楚还是更薄？

如果答案只是“这个演员来客串会很帅”，不要使用。

## 三、男性角色规则

> 男性角色像外界的风。

他们进入画面时，应当：

- 带来学校之外的职业、制度、身体或现实尺度；
- 让女生重新看彼此；
- 改变已有关系的温度；
- 之后退出。

严禁：

- 恋爱主线；
- “帅老师拯救少女”；
- 成人男性成为学生成长的唯一答案；
- 因演员咖位而抢走一期群像。

## 四、第一季密度控制

角色卡可以很多，真正具有明显戏份的成人应控制。

当前原则：

- 全季持续出现的核心成人：少量；
- 单集承担明确功能的成人：按需；
- 一两场客串 / 世界存在：可以更多；
- 只保留在素材池：完全正常。

目标不是“把豪华阵容全部塞进去”，而是让观众相信学校和校外世界真实存在。

## 五、与主题的总关系

一句最高原则：

> **乃木坂成员负责青春，外部演员负责时间。**

成年人负责提醒她们：

- 学校有历史；
- 建筑会老；
- 身体有边界；
- 技术有代价；
- 组织必须运转；
- 毕业以后世界还会继续。

但青春本身，必须由一期生自己完成。
