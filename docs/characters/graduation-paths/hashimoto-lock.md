## 最终去向

- 最终考入 **北海道大学**，采用一般选拔前期的**综合入试理系**路径。
- 入学后争取进入**工学部环境社会工学科建筑都市课程**。综合入试先接受一年综合教育，再依据志愿与成绩移行；考入北大不等于已经取得建筑都市课程席位。
- 具体理系选拔群尚待结合科目优势核实。
- 兴趣中心延续 EP09：**寒地、雪、风、地域条件怎样塑造建筑与城市**。现实成本需要计算，但不把选择改写为省钱、回故乡、就业稳定或友情推动。
- 对城市规划、建筑行政等工作有兴趣；高中毕业阶段不指定最终雇主、岗位或成年后的职业终点。

## 报考与结果

- 前期：北海道大学综合入试理系。
- 后期：东京都立大学都市环境学部建筑学科，提前完成出愿，作为认真准备的可行路线。
- 横滨国立大学在 EP09 是第三候选；最终出愿时未选用。不能把三校志愿排序写成三次可以依次参加的考试。
- 北大前期合格后，决定入学并完成手续，不再参加都立大后期考试。
- 后期**考试**在北大前期放榜之后，但后期**出愿**必须提前完成，不能等前期落榜才报名。

## 毕业典礼时的状态

- 桥本已参加北大前期考试，**尚未收到录取结果**，仍保留后期备考安排。
- 这规定的是她的毕业状态与事件先后关系；乃校典礼的具体日期、EP11—12 的分集边界与时长仍待主创决定。
- 因此后续安排典礼时，应使其发生在北大前期放榜之前；不得擅自把参考年份日期写成故事绝对日期。
- 编剧已经知道最终去向，不等于人物在典礼时已经知道，更不等于正片必须展示放榜或搬迁。

## 住宿与离开东京

- 延续 EP09 的策略：先申请学生寮，不行再外租。
- 最终获得学生寮名额；具体寮名、申请及通知日期、入住日尚待核实。
- **三月下旬离开东京、搬往札幌**，与实际入住及入学准备衔接。
- 受验交通、入学初期支出、资助到账与生活预算须形成可执行安排；不靠无限增加兼职解决，不默认乃校资助自动延续为大学资助。
- 具体资助组合、金额、受验住宿与搬家方式本轮不定。

## 一月至三月的行动骨架

| 时段 | 实际事项 |
|---|---|
| 一月 | 共通测试、估分、与老师核对出愿；检查受验旅行和住宿预算 |
| 二月上中旬 | 准备北大考试；与兼职店协商减少班次，保留必要收入安排 |
| 二月下旬 | 提前赴札幌应考，考完返回东京；继续准备可能参加的后期考试 |
| 三月初、前期放榜前 | 按学校安排返校、预演、毕业；不把考完当成已经录取 |
| 放榜后 | 办理入学与住宿相关手续，确认搬迁日期，向兼职店交代最后工作日 |
| 三月下旬 | 完成剩余工作与物品整理，搬往札幌；回校办事、见朋友均有具体安排 |

上述是生活顺序，不是已批准的场景清单。减班、最后工作日及寮手续的精确时点，须与既有店铺制度及实际学校要求对齐；需要提前申请的手续不得拖到放榜后才开始。
