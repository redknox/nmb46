# 樱井玲香｜毕业进路锁定

> 状态：**CHARACTER CANON / LOCKED**
>
> 2026-09-30 主创确认并授权落盘。
>
> 本文件为樱井玲香毕业进路的权威专项；与较早汇总冲突时，以本文件为准。

## 1. 明确进路与结果

毕业后进入**明治学院大学社会学部社会学科**，留在首都圈。
采用**一般选拔 A 日程・三教科型**，正常备考、应试并合格；三月初毕业时已确定去向、完成入学手续。
不另设落榜、补录悬念，也不要求她在毕业阶段再完成一轮成长。

## 2. 她自己想学什么

她对人的生活习惯、喜好与群体中默认的规矩感到好奇：同一件事，在不同家庭或朋友圈里，为什么会有不同理解？
这种兴趣足以让她愿意阅读课程介绍、选择社会学，但不把十八岁的她写成已有成熟研究议题的人。
入学时可对“文化与媒体”方向稍感兴趣；尚不确定课程分流、研究主题或职业细分。

这是本剧新增的人物设定，不宣称现实原型具有已获一手资料证实的同一学术志向或大学履历。
现实原型关于女子校朋友关系的观察仅供人物质感参考，不能替代角色的选择理由。

## 3. 家庭支持与未来家业

她来自高资产家族，是大型家族企业社长之女；母亲同时是乃校学校法人理事、重要校董与旧校友。
家庭承担正常升学成本，无经济减免；捐赠者身份不带来招生或校内制度特权。

未来大概率进入家族企业，承担继承或核心经营责任。她并不排斥这条路，也不认为自己被牺牲。
家庭支持她读社会学，既尊重她的兴趣，也认可它与未来工作的关联。

主创提出接班人重要的能力包括“观察、了解与操控人心”。本设定保留这层务实的家族视角：理解员工、合作方与不同利益方为什么这样行动，如何协调、说服并影响他们，确实与未来经营责任相关。
同时区分学科与运用：社会学涉及制度、群体、利益关系及调查方法，不等于教授拿捏人的技巧。对方不配合，有时是承担的代价不同，并非单纯说服不足。

**个人兴趣与家族支持可以同时成立。大学四年属于自己，不以远离家业或反抗家庭为前提。**
不必强设自主权争夺，也不要求她用成熟接班人的语言说明志愿。她觉得课程有意思，家里也认为选得不错，这种顺遂本身成立。
她将来怎样运用对人的理解，留给更远的生活，不在高中阶段预判为操纵型人物。

## 4. 人物连续性与大学生活

她原有的课题仍是：听完意见后形成自己的立场，并承担有人不满意。
选社会学不证明这项课题已完成，也不把大学变成保证培养成熟领导者的训练班。
她可以期待活动、新朋友和暂不接职务的生活；这些是可用的生活空间，不是必须拍摄的场景。

朋友留在首都圈可以影响她的地域偏好，但不能取代专业兴趣成为唯一理由。
EP09 十一月的正片状态不回写；后来的合格与手续不能提前成为当时已知事实，也不提前完成 EP10 的治理主线。

## 6. 居住与通学

- 横滨校区上课为主时，由家里在通学方便的位置租一套管理完善的校外公寓；平日独居，周末或有家庭安排时回家。
- 白金校区上课为主后，回家居住、从家通学，结束横滨租约。
- 两校区均有课的过渡期，按实际课表与通学负担决定搬家时点，不机械地按升年级切换。
- 采用家庭出资租房，不设为家族已有物业；具体地址、房型、租金和搬家日期尚未指定。

安排依据是通学便利、隐私与家庭条件，不宣称企业接班人必然不适合学生宿舍，也不增加安保排场。
她可以接受家庭帮助，同时自己面对买早餐、洗衣、收快递等生活事务。不要求通过拒绝帮助证明独立，不另设“大小姐学会自理”的成长线。
社会学科低年级涉及横滨校区，不能把白金写成四年唯一上课地点；实际年级与课程配置按对应年度核实。
