# 生驹里奈｜毕业进路锁定

> 状态：CHARACTER CANON / LOCKED

## 核心人物命题

生驹和桥本都属于“与乃校主流条件不完全相同”的学生，但差异来源不同。

- 桥本的差异主要来自现实成本与生活连续性；
- 生驹的差异更接近：**她一直在确认‘我到底怎样才算属于这里’。**

因此她毕业后的下一阶段，不应继续复制一个“更像乃校”的封闭、同质环境。

她更适合进入一个：

> **更开放、男女共学、地域来源更杂、价值观更多元的大学。**

这意味着她不再需要寻找“正确的乃木坂样子”，而是进入一个根本没有统一样子的环境。

## 升学方向

毕业后继续升学。

专业方向可落在：
- 教育；
- 社会学；
- 地域文化；
- 公共政策；
- 传播；
- 其他人文社会方向。

其中优先气质为：**教育 / 社会学 / 地域文化**。

她未必会用理论语言描述自己的兴趣，但她长期对“集体、规则、身份、地域、归属”这些问题有真实经验，因此进入一个不断接触不同背景、不同生活方式、不同地方文化的环境很自然。

## 地域选择

毕业后**不必锁在东京**。

她可以主动选择一个新的城市，也不一定回老家。

这条线的核心不是“终于融入东京以后留下来”，而是：

> **她学会了自己可以在不同地方重新建立归属。**

因此地域移动本身可以成为人物成长的自然延长线。

## 家庭条件

家庭为**地方普通稳定家庭**。

不是贫困，也不是东京中上层家庭。她来东京读乃校，本身已经是一种文化迁移与生活迁移。

家庭可以正常承担学费，但跨地域就学带来的额外成本更明显。

## 资助方式：地域就学支援

生驹不按“经济困难生”处理。

更合适的是由学校基金会提供独立的：

> **远距就学支援 / 地域就学支援**

原则：

> **地域不应成为入学后的隐性门槛。**

可覆盖：
- 学生宿舍或校外住宿补助；
- 定期券、长距离通学交通补助；
- 每年固定次数的归省交通费；
- 必要时的搬迁初期费用；
- 极少量生活费补贴。

生驹的具体状态锁定为：

> **学费基本由家庭正常承担，但因为从地方来东京就读，获得住宿 / 通勤类专项补助。**

这与桥本的经济型高额资助明确区分。

## 资助体系中的位置

当前编剧室内部可用的区分：

- 桥本：**家庭经济型高额资助**；
- 生驹：**地域成本型专项资助**；
- 高山 / まあや：**家庭负担型部分减免**。

不同资助都不构成学生社交身份。

## EP09 可见状态

如果进入进路指导群像，生驹不需要展开完整人物弧。

只需要让观众看到：
- 她看的学校并不都在东京；
- 她对“共学 / 地方来源 / 校园开放度”等条件真正有兴趣；
- 老师可以自然确认她是否愿意再次搬去一个陌生城市；
- 她不需要表现成逃离东京，而是把“重新建立生活”当成一个可行选项。

她和桥本都可能离开东京，但意义不同：

- 桥本是现实与未来规划共同把她带向北海道；
- 生驹是已经学会：**归属不是只能在一个地方获得。**
