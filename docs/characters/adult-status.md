## 状态定义

- **CORE**：从当前整季结构中拿掉，会直接伤到已经成立的主线、人物弧、callback 或空间逻辑。
- **LIKELY**：高度适配现有结构，预计会使用，但仍允许分场时根据密度删减。
- **POOL**：人物尺度成立，保留为可调用素材；没有自然场景就不出现。
- **HOLD**：设定保留，但第一季当前主动压住。除非后续出现明确且不可替代的剧情需求，否则不启用。

核心原则：

> **不能因为演员咖位而硬塞剧情。**

> **角色只有在真正服务主题、人物关系或现实结构时才启用。**

# 高三担任 / 学年主任制度层｜已锁定

乃木坂女学院高度学生自治，**不等于没有班主任制度**。

高三 3-A、3-B、3-C、3-D 各自都有正式担任老师，负责：

- 出勤与晨会；
- 家长联络；
- 進路希望調査；
- 推荐、成绩、面谈与毕业手续；
- 学校依法和制度上必须由成年人承担的责任。

但这些担任老师原则上**不明星化、不承担青春剧“灵魂班主任”功能**。他们可以有名字，也可以在具体分场需要时再决定；大多数时候只是让学校真实运转的成年人。

固定边界：

> **学生自治解决“学生自己的生活怎么运行”，不是把成人责任交给学生。**

> **老师负责安全、制度、审批与最终签字；学生有权在自己的范围内真正决定，并承担结果。**

## 武田铁矢的位置

武田铁矢正式承担：

> **高三学年主任 / 资深国语教师。**

这样他能自然认识并长期看着整个高三年级，而不是只属于某一个 Home Room。

他可以负责年级集会、毕业事务、進路流程协调，也会在不同班教授国语。四班各自仍有担任老师。

这使毕业时他的情感资格来自“三年来一直看着这一届”，同时避免让某一个单班班主任被写成全剧传统青春剧式导师。

# 调整规则

今后如果某一集的具体情节需要调整 CORE / LIKELY / POOL / HOLD，可以调整，但必须回答：

> **没有这个角色，这个场景缺失的到底是什么？**
