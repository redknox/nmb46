## 2. 高三人物关系与日常动线

分班已经锁定，下一步需要决定的是：

- 各班主要人物的座位距离；
- 谁只是“同班所以熟”，谁会主动跨班找对方；
- 午休时谁留在教室、谁去食堂、谁去别班、谁会独自消失；
- 放学后哪些人会自然一起走；
- 哪些跨班关系主要通过学生会、选修课、社团或固定路线维持；
- 哪些人物虽然同班两年，却实际上并不特别亲近；
- 各主要人物的高三选修路线。

这一阶段的核心问题不是简单的“谁和谁关系好”，而是：

> 谁在一天里的什么时刻，会主动走向谁。

## 3. 成人角色状态标记

素材池使用原则已定：CORE / LIKELY / POOL / HOLD。

仍需在逐集结构进一步细化后，为所有成人角色正式标记状态。

原则：不能因为演员咖位而硬塞剧情；角色只有在真正服务主题和主角关系时才启用。
