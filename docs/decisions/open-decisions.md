# 编剧室未决事项

> 这里只记录会明显影响后续分场、人物关系或世界观一致性的事项。已经定稿的内容不要重复放进来。

## 1. 高三班级分配

已确定：

- 乃木坂女学院高等科每年级固定 4 个 Home Room；
- 每班 30 人；
- 每年级 120 人；
- 高等科总计 360 人；
- 高一在主教学楼 1F、高二在 2F、高三在 3F；
- 一期主要成员不能全部塞在同一个班级；
- 第一集结尾要从多个高三教室交叉剪辑《第一回進路希望調査》，再让她们在走廊汇合。

课程制度也已确定为：统一高等科 + Home Room + 高二、高三选修 / 履修系列，不设置彼此隔离的音乐科、美术科。

现在真正需要决定的是：

- 哪些主要成员进入 3-A / 3-B / 3-C / 3-D；
- 哪些关系应该依靠“跨班主动寻找”而不是天然同桌来体现；
- 每个主要人物主要走哪条选修路线；
- 各班班级气质是否需要有轻微差异。

此决定会直接影响午休、上课、值日、考试、班级活动和毕业场景。

## 2. 主教学楼内部简图 / 平面关系图

Campus Map V1 与主教学楼楼层结构已经完成。

仍需细化：

- 3F 四个高三 Home Room 的左右顺序；
- 進路指导室、自习室、面谈室与四个班之间的位置；
- 中央楼梯、东西安全楼梯与电梯的具体关系；
- 主要走廊长度与窗线；
- 2F 东端通往学生会室连廊的位置；
- 雨天路线与可视关系。

## 3. 隔壁男子名门校的名字与距离

已确定其功能：不是恋爱剧来源，而是学校之外的风；通过英语、国文、文化祭联合项目等方式进入。

尚未确定：

- 正式校名；
- 与乃木坂女学院步行距离；
- 两校历史关系（兄妹校、长期交流校、普通邻校等）。

这会影响第3—5集文化祭线。

## 4. 秋叶原女子学院 / 欅坂对应学校的使用程度

概念映射已确定：

- AKB48 → 秋叶原女子学院，自由、吵闹、选举激烈；
- 欅坂46 → 新成立、校规少、理念激进的新学校；平手代表个人对传统的反抗。

尚未决定：

- 是否在第一季真实登场；
- 还是只作为世界观彩蛋、台词和传闻存在。

建议第一季谨慎使用，避免世界观抢走毕业主线。

## 5. 第一集 Flashback 数量最终锁定

当前版本控制在约 5 次：

- 生驹：制服与归属；
- 樱井：台下看学生会长 → 台上讲话；
- 白石：第一次意识到被注视；
- 生田：第一次看到钢琴就坐下弹；
- 桥本：从车站来、看校门两秒、看表进入。

需要在分场阶段确认是否全部保留，尤其白石和桥本是否都需要在 EP01 使用。

## 6. 旧礼堂改建的时间可行性

主题方案已定，但如果新礼堂在毕业阶段已经建成，需要决定剧内时间与工程表现：

- 是第10集决定后立即进入快速施工，并在毕业前完成；
- 还是第10集之前其实已有前期评估 / 设计准备；
- 或者最终回出现的是“改造后部分启用 / 新礼堂先行开放”。

这是现实逻辑问题，建议在写第10集前锁定。

## 7. 后辈世代具体使用名单

原则已经确定：可以用乃木坂二期、三期成员作为一年级学生原型 / 演员来源，二期与三期不必按现实加入顺序严格分年级；她们不承担独立人物弧，也不抢一期主线。

仍需在正式 casting / 分场时决定：

- 哪 3—4 张脸作为反复出现的熟面孔；
- 堀未央奈是否作为其中最容易被观众记住的一人；
- 哪些场景需要给极短台词，哪些只需存在。

轮椅新生继续保持“不作为正式配角”的原则。

## 8. 成人角色状态标记

素材池使用原则已定：CORE / LIKELY / POOL / HOLD。

仍需在逐集结构进一步细化后，为所有成人角色正式标记状态。

原则：不能因为演员咖位而硬塞剧情；角色只有在真正服务主题和主角关系时才启用。

## 9. 主教学楼地下层是否进入剧情

当前建议：**不设置对学生日常开放的地下层。**

机房、设备、储藏空间可以存在，但不作为常规剧情场所。

这样可以继续保持旧礼堂地下音乐室的独特性。

如未来出现明确剧情需求，再单独调整。

## 10. 项目命名

当前两个名称同时保留：

- 《乃木坂女学院》：项目 / 世界观名，直接、清楚；
- 《放学后，坡道之上》：更像正式剧名或副标题。

尚未最终决定正式播出名与项目代号之间的关系。
