> 这里只记录会明显影响后续分场、人物关系或世界观一致性的**真正未决事项**。已经定稿或已被正片推翻的内容不要继续留在这里。

Campus Map V1、主教学楼楼层结构与高三分班已经完成。

高三正式分班见：`docs/world/high3-home-rooms.md`。

## 2. 高三人物关系与日常动线

分班已经锁定，下一步需要决定的是：

- 各班主要人物的座位距离；
- 谁只是“同班所以熟”，谁会主动跨班找对方；
- 午休时谁留在教室、谁去食堂、谁去别班、谁会独自消失；
- 放学后哪些人会自然一起走；
- 哪些跨班关系主要通过学生会、选修课、社团或固定路线维持；
- 哪些人物虽然同班两年，却实际上并不特别亲近；
- 各主要人物的高三选修路线。

这一阶段的核心问题不是简单的“谁和谁关系好”，而是：

> 谁在一天里的什么时刻，会主动走向谁。

## 3. 旧礼堂改建的时间可行性

主题方案已定，但如果新礼堂在毕业阶段已经建成，需要决定剧内时间与工程表现：

- 是第10集决定后立即进入快速施工，并在毕业前完成；
- 还是第10集之前其实已有前期评估 / 设计准备；
- 或者最终回出现的是“改造后部分启用 / 新礼堂先行开放”。

这是现实逻辑问题，建议在写第10集前锁定。

## 4. 后辈世代其余熟脸名单

原则已经确定：可以用乃木坂二期、三期成员作为一年级学生原型 / 演员来源，二期与三期不必按现实加入顺序严格分年级；她们不承担独立人物弧，也不抢一期主线。

**堀未央奈已经正式确定为最容易被观众记住的一张一年级熟脸，EP05 使用方式以最终剧本为准。**

仍需在后续 casting / 分场时决定：

- 另外哪 2—3 张脸作为反复出现的熟面孔；
- 哪些场景需要给极短台词，哪些只需存在；
- 她们是否分别与某些高三角色形成稳定但很轻的日常接口。

轮椅新生继续保持“不作为正式配角”的原则。

## 5. 成人角色状态标记

素材池使用原则已定：CORE / LIKELY / POOL / HOLD。

仍需在逐集结构进一步细化后，为所有成人角色正式标记状态。

原则：不能因为演员咖位而硬塞剧情；角色只有在真正服务主题和主角关系时才启用。
