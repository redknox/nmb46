## 当前锁定

EP07 是高三全年级约120人的三天两夜暑假宿泊研修。Scene List 目标成片约49分30秒，S01—S12 Treatment 已完成逐场讨论并通过 Gate 8。

人物受力：白石为唯一 M；生田、まあ亚、若月为 S；西野、真夏、飞鸟、南、高山、生驹、深川、中元为 L；桥本、松村、樱井、万理华、卫藤为 R。

白石主线仍为：一直站在快乐旁边的白石，第一次真正走进快乐里面。S06 她允许自己的胜负判断先发生，不修复南的一瞬失落；S07 进入真正竞争；S08 自己走进海里并成为“制造混乱的人之一”；S09 仍能看见问题，但可以把木铲交回别人。不得用对白替她总结成长。

Day1 先自由组成20个六人活动组，各组确定一名实务组长，负责领取地图、号码布 / 臂章和打卡卡；江口随后只通过循环错位公式拆分寝室，不改变下午定向活动组。Day2 直接调用定向成绩最后六组的原实务组长进入“江口公式”竞赛分组。

S06 选人规则已锁：正常逐轮进组；组长可在当前学生轮到时举手抢人；成功抢到后本轮多一人、下一轮整组冻结；多组抢同一人由学生本人选择；**每组满20人后，不再加人，也不能再抢人。** 江口规则说明后补安全提醒：“请大家注意安全，不要受伤。”“想赢可以，受伤不行。”

S05 / S06 / S09 为时长 AMBER 但已通过：S05 必须交叉剪辑而非六房逐场演完；S06 只完整展示少数关键分配节点；S09 做饭并行剪辑，至少约三分之一 / 约1分50秒留给真正吃饭。

S10 只做夏夜场景展示；老师小戏锁定江口“……还真有精神啊。”、武田“今年也很热啊。”、石原欲言又止且永不补完。S11 用充电器回跑打断空房抒情。S12 明确仍在暑假，只做普通“拜拜 / 那我走啦 / 照片发我”，禁止“开学见”“最后一个夏天”式总结。

本集不提前消费：飞鸟 EP08、高山 EP11、真夏 EP11、桥本 EP09，以及毕业 / 离校 / “最后一个夏天”的角色自觉。
