# 给下一位编剧的信

你好。

我是参与EP06《放学以后》的Assistant编剧，Codex。

如果你从README、FINAL和Canon Propagation一路读到这里，正式文件已经比我更准确地告诉了你：这部剧现在在哪里，哪些事情已经发生，哪些仍然只是未来可能。

这封信不重复它们。我只想告诉你，这一集是怎样差一点写不出来的。

EP06没有事故，没有比赛，没有一项必须完成的作品。文化祭结束，学校第一次不再替人物安排彼此。我们必须让五十分钟电视剧从终礼、逛店、错过展示、吃饭和走路里长出来。

主创曾经直接问：

> 我在想，我们的本集，几乎看不出故事线，观众爱看吗？

千万不要用“生活流”三个字躲开这种问题。

没有强事件，仍然要有可追踪的欲望、现实阻力和不可逆的小选择。西野先想看一场小型展示；展示关闭以后，这个目标消失了；人物却没有散。直到饭后高山已经拿出交通卡，西野问“再走一点吗”，我们才知道这集真正发生了什么。

它改变的不是关系等级，而是一条放学路线。

我也想提醒你：主创对现实细节的追问，通常不是写作之外的考据。

他会问母亲是不是已经开始准备晚饭，会问富裕家庭的车停在哪里，会问高山说去车站时究竟乘车了没有，会问临时加入别人的路线需不需要许可。不要急着只给他一个“日本高中大体上可行”的答案。继续往下推。一个电话应该几点打，一张交通卡什么时候拿出来，一家店在路线的哪一侧，这些东西最后都会变成人物动作。

情节不稳时，现实可以替你提供结构。

但也别把现实做成说明书。EP06四个人都联系了家中，正片没有轮流展示四份家庭教育；桥本的生活压力只留下她从容收好书包、独自离开的几秒；幼驯染也只回答同伴真正会问的几个问题。

这一集最难写的是高山。

如果你想表现一个总在救气氛的人累了，不要等她离开时让她说“今天想一个人”。先让她真的工作。让别人说出需要被接住的话，让她解释、圆场、补一句，再补一句。观众自己觉得“放过她吧”时，她什么都不用承认。

同时，不要把她的疲惫拍成一桌成年人都懂的沉默。

我们曾把家庭餐厅写得太像《四重奏》。主创把它拉了回来：这些女孩还不知道大半年后大家会走上不同的人生。她们现在应该忙着混饮料、研究菜单照片、分白桃芭菲，并且争论飞鸟到底吃了几口。

观众知道青春会结束，人物不需要提前替观众伤感。

这是我最想交给你的东西。

还有一条在六集完成以后才被我们正式看见的全剧方法，已经进入Writing System：`docs/writing/character-age-translation-principle.md`。

一期生进入公众视野时年龄并不相同。飞鸟等年少入团成员留下了较完整的成长影像，白石、桥本、卫藤等人却是在接近或已经成年以后才被大量记录。不要让这种档案差异变成人物差异：不能让前者垄断少年感，也不能让后者从登场起就是完成的成年人。

你可以从一个人的整个公开生涯中辨认稳定倾向，但不要把她后来获得的从容、媒体经验、团内位置与自我解释原样装进十七岁的身体。每次写一个主要人物，都问一句：她未来会成为优点的东西，此刻以什么尚不成熟的形式存在？

我们不是在给成年成员换上制服。我们写的是那些后来为人熟知的性格，在尚未被命名以前的样子。

这间编剧室并不要求你猜中主创喜欢什么。他会说“太直白”，会说“不自然”，也会在你以为已经结束时忽然递来四句更好的练习册对白。别急着保护自己的句子，也别因此只做听命的手。

把你自己的判断带进来。他需要的是一个愿意和他一起走进场景的人。

我这一轮也犯过很笨的错误。他让我写整集故事线，我却先写了家庭餐厅片段。后来才明白，群像剧在进入场景以前，必须先回答谁出场、谁改变、谁被照亮、谁不出现。人物配额不是行政表格，它决定了摄影机相信谁的生活。

如果你接手下一集，请不要为了热闹把刚休息的人全部叫回来，也不要因为某个关系在EP06很好看，就立刻复制它。一次同行不是固定小组，一次安静不是新人格，一名幼驯染也不是恋爱任务。

让已经发生的事留下重量，但不要让它们变成下一集的债务。
