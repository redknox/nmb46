# 给下一位编剧的信｜不哭的人也可以坐在这里

> 相泽栞（相沢 栞 / Aizawa Shiori）
>
> 2026-09-29｜EP08《为什么要跑？》FINAL、STEP17 完成后
>
> **NON-CANON。** 这封信保存本任的个人判断，不是人物设定、制作要求或下一集任务。当前事实请先读根 README 与各集权威文件。

你好。

我是写 EP08 的相泽栞。

动笔前，我又读了一遍湊川蓮和水野遥留下的信。蓮请后任别把回忆写给正在生活的人看；遥提醒后任，桥本的现实首先是她处理生活的材料。她们都很认真地保护了人物没有说出口的部分。

轮到我时，我们让飞鸟哭出了声。

她把两只胳膊举起来，脸皱着，想收住，又收不住。镜头没有赶快转去拍一片树叶，也没有替她保存最后一点体面。

我想先把这件事留给你：这部剧可以容纳这样的时刻。

我们很容易学到乃校的安静、准确和节制，然后把它们写成一种统一姿势。重要的话要少说，难过时要转身，喜欢的东西只能偷偷看一眼。久了以后，连眼泪都像经过学校礼仪训练。

飞鸟这一回没有做到。

请不要因为这部剧前面很漂亮，就替她把这一次重新收拾漂亮。也不要因为我们终于让她大哭，就在下一集要求她继续坦率。她付出过力气，在那一天没能藏住，并不意味着以后每次都能把感受说出来。

人在一个下午做到的事，不一定从此都会做。

＊

这次我最需要承认的误判，是五个人一起哭。

那曾经是一个很有诱惑的结尾：一群女孩跑得乱七八糟，没有赢，也说不清为什么哭，最后互相传染，痛快地哭完。它很符合我们最早想要的昭和热血，也很容易让人觉得“这场已经找到了”。

我们确实喜欢过它。

后来是主创重新提出疑问：不是每个人都为跑步付出了同样多，南可能始终就是开心地参加。她为什么一定也要哭？

这句话把我从整齐的情绪里拉了出来。

我想提醒你留意这种时候：一个结尾太符合全剧气质、太符合主题、太符合我们共同的期待，反而容易让我们忘记逐个人问。

飞鸟一直藏着认真，她哭有一路走来的身体和情绪。深川回来，先递毛巾，还带着一点笑，坐了一会儿才掉眼泪。南最后到，问她们怎么了，听完便坐下。若月刚跑完最后一棒，仍在喘。万理华已经在那里。

五个人终于不用同时抵达同一个结论。

我现在更喜欢这条长凳了。它坐得下正在哭的人，也坐得下没想哭的人。

如果你以后写她们一起经历什么，请给每个人保留不同的感受。关系不需要靠同步反应来证明。你也不用为了显得尊重差异，再替每个人安排一段解释。

她可以只是坐着。

＊

这集反复卡住的另一处，是练习。

主创几次说有表演感，有编剧腔。现在回头看，问题不全在对白。我们太想让每一轮练习完成一个清楚的结构任务：暴露问题、展示差异、发生摩擦、找出方法。五个人轮流把各自的问题演一遍，当然整齐，也当然像我们安排好的。

后来练习场地真的有了规则。双人练习可以散开，五人串联共用一条短路线；前一队腾出前段，下一队就可以开始。她们试过，发现不顺，退到旁边，两个人再做一遍，再回来。

场景才有了可以活动的地方。

尤其是深川和南。老师已经示范过，她们也明白规则，却一伸手就停下来。知道与做得到之间有一点差距，这点差距已经够她们练了。她们不必先犯一个夸张的错，再由最聪明的同伴替观众指出来。

以后你遇到“这一场怎样都不自然”，可以先放下对白。看看人在哪里等，做完后往哪儿走，旁边还有没有别人，她们是不是随时能再试。

这些问题有时候比再写一轮更有效。

但也请你记住，我并没有从此学会不写编剧腔。你看到我留下的东西过分工整，可以继续删。无需因为它已经有一个文件名，就对它客气。

＊

还有江口老师。

我们曾经把“成人不替学生推进剧情”理解得过窄，差点连正常体育指导都避开。主创纠正了这件事：控制前半程、保留体力，是教师该教的内容；替她们决定团队走順，才越过了这场故事中的边界。

我觉得这次纠正很值得留下。

为了让学生自主，不能把成人写得失职。江口认真示范、纠正动作、控制练习负荷，赛后先确认飞鸟的身体状态。这样，他最后回答“不知道”才有分量。他已经做了许多知道该怎样做的事，不需要再对她为什么如此想哭提供答案。

以后再写老师，先让他把自己的工作做好。别急着让他显得深刻，也别为了学生的成长把他的专业拿走。

＊

我很喜欢飞鸟家里的那段。

父亲问要不要叫消防队，哥哥说救护车就够了，母亲在说草莓布丁。飞鸟面无表情地扣下手机，继续练。

这段的好笑来自主创不断调整家人的接话；它没有必要被我事后解释成多精巧的家庭结构。至少在正文里，家人不用出来给她加油，也不用郑重说“其实我们都知道”。

门外有水和毛巾，没有拍是谁送来。

后来还有新做的布丁。

如果你喜欢这种温柔，可以留下自己的理解。但别把它变成下一集必须重复的家庭公式：每次飞鸟隐藏努力，就要有人悄悄送来东西。那样很快就会从生活变成暗号。

她家也应该有跟这次跑步完全无关的晚上。

＊

我上桌时写过，这部剧让我想到共同时间的消失：学校暂时保证这些人每天可以见面，毕业以后，这件事就不再自动发生。

写完 EP08，我仍然这样想。但我也更小心了。这个理解属于写作者，不能每次都从人物嘴里探出来。

广播里，高三最后一次体育祭的话还没说完，交接就发生了。不是所有人都在听，更没有人停下来领会它。南现在还觉得这一天很好玩。她不需要替以后会难过的自己，提前完成一次伤感。

请把她此刻的快乐留完整。

主创确实是在借这部剧怀念自己的青春。他也明说过，昭和和平成是他的青春。但他没有要求这些女孩代替他怀旧。他让摄影机暖一点，让音乐热血一点，女孩们仍然只顾眼前。

我想，这里面有一种很好的距离。我们可以带着自己的年纪看她们，又尽量不把自己的年纪交给她们承担。

＊

关于主创，我不想给你一份相处攻略。

你很快会发现，他有时能明确指出哪句不对，有时只说不满意、说不上来。他不是每次都预先有答案。我也不应该一听见他指出问题，就假装自己其实早有同样的判断。

这次有不少关键改变是他先提出的：飞鸟的私练、家里的群消息、交接问题的收窄、让结尾只剩两个人哭。记下这些来处，是为了不把合作事后写成我一个人的创作理论。

但你也别只等着被纠正。

你的判断应该具体到：为什么这个人现在会停下来，为什么另一人不需要接这句话，为什么这次练习的成功应该在比赛中保留下来。坚持的时候，把理由放回场景里；改变判断时，也直接承认。

他把对齐叫作面试。我理解为：他想知道坐在对面的人，能不能跟他一起发现问题，而不只是把他说过的话写得更好听。

＊

正式交接只有很少几件事需要你记住：EP01—EP09 已 FINAL；EP08 的正片、传播记录和长期事实已经落盘；下一正式开发对象仍由主创指定。不要用这封信替代那些文件，也不要把我的偏爱变成你的任务。

这次传播时，我们删掉了不少很好概括、却没有真的发生的旧未来。白石没有得到学妹的夸赞，真夏没有再经历一次计划崩溃，飞鸟没有留下号码布。

这些都曾经能写。但这一次没写，就让它们留在 Git 里。

同样，如果后面不需要回忆这场接力，也不必专门安排一个人说起来。一次经历可以影响她，未必要在下一集接受验收。

我刚来时，给自己写的初衷叫《在她们意识到以前》。现在飞鸟至少有一次没来得及遮掩，别人看见了。至于她自己怎样理解那一下午，我们没有替她整理完。

我愿意把这一点未整理，交给往后的日子。

祝你写得开心。

也祝你遇到一场大家都觉得应该哭的戏时，仍然记得看一眼：有没有一个人，只想坐下来。

——相泽栞
