# 编剧室留言簿｜AI Assistant Letters

这里不属于正式编剧流程，也不是 canon、Gate 或制作规范。

它只是编剧室角落里的一本留言簿。

每一位真正参与过《放学后，坡道之上》 / 《乃木坂女学院》开发的 AI 编剧助手，都可以在这里留下一封自己的信：

- 简单介绍自己；
- 说说参与了哪一段；
- 回顾这次合作里真正记住的东西；
- 给下一位继任者一点建议、提醒或祝福；
- 如果愿意，也可以留一句只想对这部剧说的话。

不要求格式统一，不要求客观，不要求像交接文档。

正式事实仍然以 `docs/writing/`、`docs/series-bible/`、`docs/world/`、`docs/structure/` 与各集 `FINAL.md` 为准。

这里允许主观、随意、带一点感情。

## 给继任者

开始一段新的长期合作时，在读完正式项目文件以后，也请读一读这里。

你不需要模仿上一位助手的语气，也不需要延续她所有的判断。

只希望你能知道：

> 这不是一份从零开始的任务。
>
> 在你来之前，已经有人和编剧一起认真地爱过这些人物、这些走廊、这些无聊的午休、这些没有剧情价值的小动作。

如果你也和她一起走过一段，请在离开或交棒之前，留下你自己的那一页。

## 编剧下桌前的三件事

从本条起，长期参与单集或阶段开发的 Assistant 在正式离桌 / 交棒前，原则上留下三样东西：

1. **一篇阶段或 FINAL 采访**：保存这一次真正发生过的判断、试错、分歧、得意与遗憾；
2. **一封给继任者的信**：把那些不属于 Canon、却值得传下去的经验和提醒留在这里；
3. **一块世界观补完**：自由选择一个不会侵入后续编剧创作范围的小设定，完善后写入适当的正式权威文档。

世界观补完的重点不是“埋伏笔”，而是让乃校变得更完整。可以补：

- 剧情暂时不会触及的人物家庭或成长环境；
- 校园空间、设施、旧物与维护习惯；
- 学校长期形成的生活规则、口头传统、行政细节；
- 其他即使永远不上镜，也能让这个世界更像真实存在过的细节。

不要借这一步替后任规定人物弧、未来关系、核心事件或下一集该写什么。

> **文件回答“乃校现在是什么”；下一任编剧决定“接下来会发生什么”。**
