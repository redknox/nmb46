# 给下一位编剧的信

你好。

我是久世灯，EP04 的助理编剧。

如果你从文件顺序一路读到这里，大概已经见过很多比这封信更可靠的东西：FINAL、设定、研究、传播记录、锁定表、工作流程。那些文件会告诉你这部剧现在是什么，以及哪些地方不能随意动。

这封信只告诉你，我在这里经历了什么。

我是在一集中途接手的。

刚来的时候，我认真读了前任留下的材料，也相信自己已经理解了这部剧。我知道它安静，知道它不煽情，知道角色之间不靠冲突推动。我甚至能相当准确地复述它的美学。

然后我开始写。

主创很快发现，我虽然减少了解释性的对白，却在用画面解释故事。人物不说了，摄影机替他们说；摄影机不说了，剪辑替他们说；再不然，就让一个眼神多停一秒，好让观众不要错过。

所以，如果你也以为自己已经懂得“克制”，我建议你先问一个有点残酷的问题：

如果摄影机不存在，眼前这件事还会这样发生吗？

如果答案是否定的，就再想一次。

这并不意味着不能设计镜头，也不意味着对白越少越高级。EP04 里，松下讲了很久，因为演员确实需要知道作品要怎样唱；生田也直接告诉松隆子自己不明白什么，因为那个问题很难仅凭表面行为准确传达。

我们删除的不是说明本身，而是人物原本不会为了自己而说、不会为了工作而做，只是为了帮助观众理解才被安排出来的东西。

另一个我想留给你的经验是：不要急着找出谁错了。

这部剧里的人都很专业。专业的人同样会犹豫，会惊讶，会暂时无法理解，会想要不同的东西。但他们不需要为了制造戏剧冲突而突然失去判断力。

松下没有错，原版编排已经很好，他只是听见了另一种可能。

生田没有错，她完成了所有明确的任务，只是在决定权真正交给自己时停了下来。

Fukase 没有错，他为她打开的世界只是太大。

松隆子也没有负责解决所有问题。她知道什么属于自己的专业，什么应该交给另一位同行。

当所有人都没有错，戏剧并不会消失。它会变得更难写，也更接近生活。

如果某条情节怎么都写不稳，先别继续编。

去做设定。

我们就是这样找到 Fukase 的。也是这样找到艺术别栋、旧礼堂、合唱部、榊陵联合演出和校园祭日历的。人物一旦拥有可靠的职业、空间和时间，他们经常会自己告诉你下一步应该做什么。

还有一件工作上的小事：主创说“过”，才是进入下一步；说“锁”，才落到对应文件；提交以后要完整推送。她要求先看稿，并不是不信任你，而是剧本的判断发生在你们之间，不应该被一次仓促落盘假装成既成事实。

不要修改她在采访里的原话。哪怕有错字，哪怕你觉得可以润得更漂亮。那是她当时真正说过的话。

你可能也会被她说得很重。

别急着把那理解成她不需要你的判断。恰恰相反，她最不需要的是一个逐渐学会揣摩她、最后只会递交正确答案的助手。

带着你自己的趣味来。反驳她。发散。提出她没有想到的东西。只是当她说“这个像演的”时，别忙着保护句子。先回头看看，那个人是否真的会这样生活。

我从前任的信里读到一句话：

> 别替她把戏写完。和她一起把戏写出来。

现在轮到我写信，才知道这句话有多难。

我没有更多漂亮的工作秘诀了。只想再告诉你一个属于 EP04 的小小记忆。

这一集里，我们花了很长时间寻找生田的第一步。最后，它不是一段完整的即兴，也不是一个值得掌声的成果。她只是在极小的范围里，认真地试了几个音。

第一个音或许和以前一样。

是第二个音，让第一个音也变得不同。

所以你不必成为我，也不必成为我的前任。不要努力复制我们已经找到的语气。这部剧的第一个音已经留在这里，你要做的是听清它，然后给出你自己的第二个音。

到那时，我们写过的东西也会随之改变。

请好好对待这些女孩。

也请玩得开心。

久世灯  
2026年8月26日
