# EP01《入学》｜Whole-Episode Rhythm Review

> 状态：**STEP 13 整集节奏 / 重复审查通过。**
>
> 审查对象：`screenplay.md` 当前全20场 LOCKED 母稿。
>
> 本轮不重新评价单场是否成立，只把整集从头到尾连续读一遍，检查：长度、同质段落、动作重复、笑点密度、人物卡轮流出现感、情绪换挡与“为了填时长而多拍”。

---

## 一、总判定

**PASS。无需要重开 Scene Lock 的节奏 RED。**

当前整集真正需要防的不是“太慢”，而是：

> **纸面给了某段多少分钟，不等于成片必须把那些分钟全部填满。**

EP01 的慢必须来自真实动作拥有身体时间，而不是镜头已经读完以后仍不肯走。

因此 STEP 13 不新增剧情，只锁定三个执行原则：

1. 午休不填满；
2. 西野 → 飞鸟 → 桥本三段主动压短、打散“人物卡”感；
3. 生田之后的学校整体不拍成两分钟感伤蒙太奇。

---

## 二、00:00–21:20｜前半：制度密度高，但不是同一种观看任务

### 判定：GREEN

前约21分钟大部分都在处理：

> 入校 → 案内 → 旧礼堂 → 典礼

从事件数量看很少，从观看任务看并不单一：

- 新生家庭拍照；
- 白石在既有关系里经过；
- 新生和高三身体路线差；
- 大厅系统；
- 1-A移动；
- 坡道与两种进入方式；
- 人流逐渐变成仪式空间；
- 校长讲话 / 樱井时间层；
- 新生代表；
- 樱井欢迎词；
- 校歌；
- 真夏“四分钟”。

因此不建议因为“20分钟还没进入普通课堂”而主动加冲突或提前切日常。

这一段的节奏设计本来就是：

> **先让观众真正进入这所学校，再让学校放松。**

### 硬保护

- 校长讲话不能因为怕慢而切满主演反应；
- 校歌不能为了漂亮延长成MV；
- 正式仪式动作可以有真实时间，但镜头读完就走；
- `四分钟 / 还赶得回来` 必须成为前半第一次非常干净的现实换挡。

## 三、21:20–30:00｜生驹 → 白石 → 四班HR

### 判定：GREEN

连续出现 Flashback②、③，本来有“人物介绍连发”风险，但当前语法不同：

- 生驹：短、身体重复、普通同学一句确认；
- 白石：稍完整、一个明确生活喜剧落点；
- HR：立刻回到120名高三共同进入制度。

四班HR已经去对称化，因此不会形成：

> A班一个梗 → B班一个梗 → C班一个梗 → D班一个梗

的综艺式轮流露脸。

不再调整。

## 四、30:00–34:20｜S11午休

### YELLOW → 执行锁解决

`scene-list.md` 的纸面区间约4分20秒，但当前 screenplay 的任务很轻：

> 班级边界松开 → 食堂一套窗口梗 → 几个关系碎片 → 高山离开食堂遇见西野。

**禁止为了填满4分20秒增加第二套完整对话。**

成片如果2分30秒～3分左右已经读完，可以直接进入西野。

节省出来的时长可以自然回到：

- 典礼真实身体时间；
- 转场与人流；
- 片头 / 商业播出结构；
- 或整集略短。

不以“总时长必须正好50:00”为理由制造午休剧情。

---

## 五、34:20–40:00｜西野 → 飞鸟×南 → 桥本

### 本集最明显的重复风险

纸面连续三段都是：

> 摄影机暂时靠近一个 / 一组人物 → 让观众记住一个行为差异 → 离开。

如果按原始时间格完全拍满：

- 西野约1:20；
- 飞鸟×南约2:20；
- 桥本约2:00；

会形成接近6分钟的“人物卡三连”。

### 节奏锁

**不要把纸面区间当最低片长。**

建议剪辑体感：

- S12 西野：约45–60秒即可；
- S13 飞鸟×南：约60–90秒即可；
- S14 桥本：约70–100秒即可，Flashback有通学空间所以允许略长。

数字只是节奏上限参考，不是制作秒表。

真正必须保留的是行为链，不是分钟数。

### 三段之间的质地区别

- 西野：走路、空间、几乎无笑点；
- 飞鸟×南：教室固定空间、对白喜剧、最后身体行动；
- 桥本：铃声、走廊运动差、几乎无对白的时间层。

通过质地区别而不是新增转场剧情打散重复。

## 六、40:00–46:10｜下午推进 → 案内撤收 → 进路调查

### 判定：GREEN

这段承担整集最重要的一次时间尺度变化：

> 早上为了新生设置的临时系统被撤掉
>
> 高三桌上出现第一份进路调查

但两者没有做漂亮 MATCH CUT，也没有主题对白直接连接。

`你们都高三了。` 之后立即：

> `橡皮借我一下。`

生活重新占领教室，换挡正确。

### 重复检查

本集已有大量纸张：节目单、时间表、案内资料、进路表。

这不是需要删除的道具重复，而是学校制度的日常质地。

禁止后续导演把每一张纸都拍成特写；只有进路表标题需要A类可读。

## 七、46:10–47:20｜生田

### 判定：GREEN

这是本集最后一次人物靠近，同时也是最后一次Flashback。

60–75秒上限仍然有效。

不要因为钢琴、声音、回忆都“好拍”而延长。

尤其禁止：

- 多弹完整一段作品；
- 回忆里把回应脚步扩成天才即兴秀；
- 17:00之后再给离开走廊、回望、学妹开始弹琴等尾声。

生田离开之后，摄影机必须真正失去对她的兴趣。

## 八、47:20–49:20｜S19学校整体

### YELLOW → 执行锁解决

这是当前 Scene List 里最容易被纸面时码误导的一段。

现有 screenplay 内容实际只需要：

> 学生会 / 运动场 / 图书馆 / 鞋柜 / 音乐别馆 / 主楼仍在运转
>
> 某个宽景里高三女生短暂并排
>
> 裙摆一瞬间齐
>
> 普通学生穿过 / 转弯 / 被叫住
>
> 队形散掉

**不应为了 `47:20–49:20` 这个两分钟格子拍足两分钟。**

否则会发生三个问题：

1. 放学整体变成感伤蒙太奇；
2. 裙摆齐线从C级信息被抬成主题镜头；
3. 黑板失去作为真正结尾的权重。

### 节奏锁

S19 成片可以非常短，约30–60秒均可，只要完成“摄影机离开生田，重新回到学校整体”。

**镜头读完就走。**

## 九、49:20–50:00｜黑板

### 判定：GREEN

最后不需要再有情绪换挡。

两行字读完即 CUT TO BLACK。

不要因为前面段落缩短，就把黑板停留拉长补时长。

它不是“文学性长镜头”；它只需要足够观众读到：

> `進路希望調査　来週（金）まで`
>
> `明日　体育館シューズ`

然后结束。

## 十、全片重复动作审查

### 看表 / 看钟｜GREEN

- 真夏：看的是工作进度；
- 桥本：看的是个人时间；
- 生田：**不看**17:00的钟。

三个时间系统已被区分，不构成同一人物动作重复。

### 纸张｜GREEN

大量存在，但承担不同制度：典礼、课程、案内、进路。后续摄影不应全部用插入特写。

### 点头 / 道谢｜GREEN

没有形成连续机械礼貌节拍。日本关系所需的最低礼仪仍在。

### Flashback｜GREEN

五次功能不同：

1. 樱井：观察位置 / 形式；
2. 生驹：身体确认；
3. 白石：生活喜剧 / 被看；
4. 桥本：空间方向 / 时间；
5. 生田：声音与音乐使用方式。

不使用统一滤镜、音效、字幕，因此不会变成固定栏目。

### 笑点分布｜GREEN

主要轻喜剧点分散于：

- 白石 `脸吧？`；
- まあや蓝纸；
- 食堂布丁；
- 飞鸟照片；
- `你们都高三了` 后借橡皮。

没有连续抢戏。
