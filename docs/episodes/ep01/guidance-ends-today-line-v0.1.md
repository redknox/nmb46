## 一、现实基线｜入学日的“案内”本来就是临时系统

现实日本高校的入学 / 新生说明流程中，常见：

- 在生徒玄关等位置公布班级 / 集合信息；
- 由係、生徒会或在校生承担诱导、校舍案内；
- 活动结束后由学生会 / 工作人员负责撤收当天使用的诱导物、班级标识、会场用品等。

因此乃木坂女学院在入学日临时设置：

- `新入生はこちら`；
- `1-A →` / `1-B →`；
- 楼梯方向箭头；
- 临时集合点 / 鞋柜区提示；

并在当天主要新生流程结束后撤收，是非常自然的学校运营动作。

本段不需要锁定这些标识的全年视觉规范。它们只是开学日临时案内物。

## 二、本段为什么比“已经习惯了吗？”更适合现在的第一集

旧版可以安排新生问：

> “学姐们现在已经完全习惯这里了吗？”

然后让飞鸟、生驹、南等给出不同回答。

但现在不采用。

原因不是台词不好，而是它开始暴露编剧意图：

1. 新生像在替观众采访主要人物；
2. 需要再次把新生送到主演身边；
3. “习惯学校”被说成主题，而不是先作为生活发生；
4. 前面已经用了大量普通同学建立真实学校，这里突然回到“配角问、主角答”会稍微退步。

因此改为：

> **早上，学校告诉新生每一步往哪里走；下午，这些箭头被收起来。**

没人总结“以后要靠自己”。

学校只是到了该收东西的时候。

## 三、42:30–42:45｜允许一个极小的时间推进

桥本回到 3-B。

老师开始上课 / 黑板出现新的板书。

不用完整拍一节课。

用两三个现实碎片让观众接受：时间继续往后走了一点。

例如：

- 粉笔落到黑板；
- 课本翻页；
- 一名普通学生记笔记；
- 窗外光线和上午已有细微变化。

然后切主教学楼一楼 / 生徒昇降口附近。

一年级自己的说明、Home Room 等流程也已经接近尾声，部分新生开始离校。

这样**不需要让新生继续在高三三楼游荡**。

## 四、42:45–43:20｜普通学生开始收掉早上的箭头

生徒昇降口 / 主楼入口附近。

两三名普通在校生正在撤收今天早上使用的临时案内物。

她们可以是普通 `新入生案内係` / 学生会协助人员，不需要再引入命名角色。

动作非常具体：

- 从墙边揭下一张低粘胶固定的 `1-A →`；
- 把立式 `新入生はこちら` 小牌转过来；
- 收起鞋柜区方向提示；
- 将几块牌按大小叠在一起；
- 有人拿胶带，有人抱牌子。

不要拍成学生会高效 montage。

也会发生很普通的小麻烦：

> 「テープ、そこ残ってる。」
>
> “那边胶带还没撕干净。”

另一个人回去抠一下。

世界继续有摩擦。

### 一个新生停下来

一个准备离校的一年级女生看见她们正在收牌子。

不是我们必须追踪过的新生，不需要和任何主角绑定。

她很自然地问：

> 「これ、明日はないんですか？」

普通案内係一边折 / 收东西：

> 「うん。今日だけ。」

新生：

> 「まだ全然覚えてなくて。」

普通案内係：

> 「分かんなくなったら、近くの先輩に聞けばいいよ。」

新生：

> 「はい。」

就结束。

中文字幕：

> “这个明天就没有了吗？”
>
> “嗯，就今天。”
>
> “我还完全没记住。”
>
> “不知道怎么走了，就问附近的学姐。”
>
> “嗯。”

这句同时第一次让乃木坂女学院的“前辈帮助后辈”传统在生活里自然出现。

它不是在宣布：

> “学姐会替你把所有事情做好。”

而只是告诉新生：

> **临时箭头可以撤掉，但学校里仍然有人可以问。**

不补：

> “很快你就会习惯的。”

不补：

> “我们当年也一样。”

因为那会再次开始替主题讲话。

## 五、43:20–43:40｜她第一次经过“没有箭头”的同一块地方

新生穿好外鞋 / 拿好东西，随其他一年级学生离开。

镜头不用追她很久。

只需要一个极轻的视觉回收：

早上这里有：

> `新入生はこちら →`

现在牌子已经被拿走。

墙面 / 立柱恢复成普通状态。

新生经过时，可能本能地看一下原来牌子的位置。

然后她看到自己的同班同学在前面，跟上去。

她没有完成“独立成长”。

她明天也可能继续迷路，也完全可以真的去问某位路过的学姐。

这里只表达：

> **迎新是一套临时系统；学校生活不是。**

## 六、43:40–44:00｜最重要的视觉押韵：箭头收走，另一张“方向纸”出现

普通学生把最后几块案内牌叠起来。

画面中最上面一块可以是：

> `→`

切。

高三某个 Home Room 的讲台。

担任把一叠新纸放下。

纸张顶部第一次清楚出现：

> **第一回　進路希望調査**

不要立刻配主题音乐。

老师还没开始解释。

先让这个标题自己停一拍。

然后进入下一场四个高三 Home Room 的 Ending。

### 这一剪的真正意义

早上：

> **学校用箭头告诉刚进来的人“现在往哪里走”。**

下午 / 本集结尾：

> **学校把一张空白表格交给快离开的人，问“以后你想往哪里走”。**

这句话只存在于编剧室与剪辑逻辑里。

**剧中任何人都不说。**

## 七、为什么这里最好没有命名主角

这 90 秒如果完全由普通学生完成，反而会让第一集的群像结构更完整。

前面我们已经看到：

- 生驹做过新入生案内；
- 樱井与真夏运行典礼；
- 白石、生田、西野、飞鸟、南、桥本分别获得人物入口。

到这里，不需要再让某个主要人物“负责收尾”。

学校自己可以收尾。

甚至生驹早在 3-A Home Room 就已经把腕章交回去了。

现在撤牌子的，是另一些今天同样工作过、但观众不知道名字的学生。

这会继续证明：

> **今天的入学式不是17个人办的。**

## 八、与樱井欢迎词及《生徒心得》的轻微回声

樱井上午欢迎词里说过：

> 「困ったときは、近くにいる人に聞いてください。」

本段普通案内係说：

> 「分かんなくなったら、近くの先輩に聞けばいいよ。」

两句不要求完全一致。

恰恰应该像同一所学校里很普通的生活常识，用更口语的方式再次出现。

更深一层，它也自然符合乃木坂女学院已经锁定的学生礼法：

> **上級生は下級生の模範となり、必要な助言と援助を惜しまない。**

不是“主角金句被配角引用”。

而是：

> **樱井在台上说的东西、学院写在《生徒心得》里的东西，台下的人本来就这样生活。**

后续剧情再逐渐展示这条规则真正困难的部分：学姐不只要学会帮，也要学会什么时候**忍住不要替后辈做**。

## 九、视觉注意力节奏

```text
桥本回到3-B
→ 黑板 / 课本 / 时间向后走一点
→ 一楼开始撤案内牌
→ 胶带没撕干净
→ 普通新生问“明天没有了吗？”
→ “不知道就问附近的学姐”
→ 新生穿鞋离校
→ 原来有箭头的位置变空
→ 最后一块箭头叠上去
→ CUT
→ 《第一回 進路希望調査》落到讲台
```

宏观观看任务：

> **人物记忆 → 学校运营收尾 → 新生失去临时指引 → 高三收到新的“方向问题”。**

这一段既是呼吸，也是 Ending 的起跑线。

## 十、必须避免

### 1. 不让新生问人生问题

不要：

> “学姐，你们什么时候才觉得自己属于这里？”

### 2. 不让普通案内係突然变成人生导师

她只说：

> “不知道就问附近的学姐。”

### 3. 不让“学姐帮助”变成“学姐接管”

这里的帮助是可求助性，不是宣布高年级生天然拥有指挥低年级生的权力。

### 4. 不让新生一秒学会学校

明天还可能迷路。

### 5. 不让主角负责每项收尾工作

真夏不必出现拿着 checklist；生驹不必再次回来撤牌；樱井不必巡场。

### 6. 不把箭头 → 进路调查拍得太广告化

可以有构图押韵，但不要：慢动作、响亮音乐、字幕金句。

越平常，越有力。

---

## 十一、当前推荐保留的核心瞬间

如果最终只能留 45–60 秒：

1. 普通学生撤 `新入生はこちら →`；
2. 新生：`「これ、明日はないんですか？」`；
3. 普通案内係：`「うん。今日だけ。」` / `「分かんなくなったら、近くの先輩に聞けばいいよ。」`；
4. 原来有箭头的位置恢复成普通墙面；
5. 最后一块 `→` 被叠起，CUT 到《第一回 進路希望調査》。

本段最小世界句子：

> **入学第一天，学校可以告诉你下一间教室往哪里走；高三以后，它开始把“往哪里走”这个问题还给你自己。**
