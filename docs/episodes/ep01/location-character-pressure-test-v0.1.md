# EP01《入学》｜逐场位置与人物功能压力测试 V0.1

> 状态：**工作稿 / 非锁定。**
>
> 目的不是重写对白，而是检查 EP01 V3 在已经锁定的分班、座位、关系主动性、校园空间与高三课程制度下，是否仍能成立。

本轮只问四件事：

1. 这个人为什么在这里？
2. 普通学生是否继续构成学校主体？
3. 关系是否靠现实机制成立，而不是“主演自动聚集”？
4. 这场戏是否真的推进第一集，而不是人物轮流出厂？

核心原则：

> **第一集不是把17个人介绍完，而是让观众第一次相信：这120名高三学生本来就在这里生活，我们只是开始跟拍其中17个。**

## 0:00–3:00｜Cold Open：校门 / 樱花道 / 鞋柜入口

### 在场主要人物

不做同框集合，采用碎片式进入：

- 星野南：打哈欠进门；
- 松村沙友理：边走边吃最后一口东西；

- 其余一期生可以在远景 / 走廊 / 换鞋流中出现，但不强制给行为标签。

### 为什么在这里

全部是最普通的“来上学”。只有真夏因学生会迎新事务提前进入工作状态。

### 普通学生负载

画面主体必须仍然是：

- 大量第一次穿制服的新生；
- 家长；
- 普通高二 / 高三学生；
- 教职员；
- 鞋袋、校内鞋、领结、校门合影等普通开学动作。

### 本场完成的信息

- 学校漂亮，但不是宣传片；
- 高三成员已经对这里熟得不再需要“进入学校”的表演；
- 白石的被观看、南的松弛、真夏的流程感、飞鸟的边缘位置先作为行为印象出现。

### 压力判断

**通过。**

禁止17人逐个给特写。第一集的可信度来自“漏看几个人也没关系”。

## 6:30–10:00｜旧礼堂入口：台阶

### 核心在场

- 生驹：带一小组新生到礼堂；
- 使用轮椅的新生：只作为新一届学生之一；
- 桥本奈奈未：随3-B / 高三学生进入礼堂的人流经过附近；
- 教职员 / 事务人员：随后处理实际协助。

### 桥本为什么能在这里

不是“她正好来提供正确答案”。

高三学生本来也在进入礼堂。生驹看向侧门时，桥本在同一人流里看见这个动作，只用一句：

> “那边也有台阶。”

然后继续自己的动线。

这是**被动相遇 + 事实判断**，不构成桥本主动介入。

### 轮椅协助

- 必须先征得本人同意；
- 由教职员 / 事务人员负责，不让学生英雄式抬人；
- 不用煽情音乐；
- 镜头重点是轮椅金属与旧石阶之间非常普通、非常不匹配的现实声音。

### 普通学生负载

其他新生会犹豫、等候、让路、继续聊天；不是全场突然安静围观。

### 本场完成的信息

- 旧礼堂的问题第一次从“建筑设定”变成真实使用后果；
- 生驹第一次在自己极珍惜的学校里撞见“不适合所有人”的部分；
- 桥本的现实尺度只露一刀。

### 压力判断

**通过。**

桥本的后续学生会午餐戏应删除；这一句已经完成她在事件中的功能。

## 46:00–47:30｜“已经习惯了吗？”：不要让一个新生巡回采访17人

### V3风险

如果同一个一年级女生分别问多名学姐，会变成编剧问卷。

把同一句问题拆成两个自然碎片即可：

- 新生在迎新过程中问生驹 / 真夏：“多久会习惯？”
- 另一名新生在3-D附近随口问南 / 飞鸟：“你们现在是不是完全习惯了？”

回答都很轻。

不需要让每个人表态。

主题问题第一次被说出来，但主要人物没有把它当主题。

### 老师共同句

不同班可以不必每个老师都说同样一句。只需其中一班有人抱怨：

> “这么快？”

老师：

> “什么这么快？你们高三了。”

然后跨四班切到其他人手里的同一张纸，让这句话覆盖整个年级。

### 终镜

终礼结束后，四个班学生从不同教室出来。

不是17个人自动汇成主角团。

应该先是：

- 各班自己的普通同学流；
- 楼梯、走廊逐渐叠加；
- 某些一期生在其中自然碰到；
- 有人一起走，有人不同方向离开。

“裙摆齐线”如果保留，应出现在一个很短的群体流动瞬间，而不是17人列队式英雄镜头。

最后回到一间已经空下来的高三教室，桌上留下《進路希望調査》。

### 本场完成的信息

第一集真正的结论不是“我们认识她们了”，而是：

> **她们自己还把今天当普通开学日，学校已经开始要求她们回答离开以后去哪。**

### 压力判断

**强通过，必须成为 V4 最大结构升级点。**

## 本轮最重要的新理解

> **EP01 最值得让观众记住的，不是17个人分别是谁，而是她们已经拥有了三年不需要解释的生活。**

第一集应该让新生不断问“这里是什么地方”，而高三生的行为不断回答：

> **我们已经在这里太久，所以很多事情甚至不会再解释。**

直到最后学校把《進路希望調査》放到她们桌上，才第一次反过来问这些高三生：

> **那你们接下来要去哪里？**
