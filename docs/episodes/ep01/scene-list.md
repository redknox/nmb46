# EP01《入学》｜Scene List

> 状态：**FINAL STRUCTURE / Canon Propagation 完成版。**
>
> 本文件回答“第一集由哪些可感知场景 / sequence 组成，以及它们怎样连续发生”。
>
> `screenplay.md` 是正片逐句权威文本；本文件负责结构、场次与时间地图。下列时间是开发阶段的**目标区间，不是必须拍满的镜头配额**。实际成片必须服从 `rhythm-review.md` 的“读完就走”原则。

## 总体原则

> **先让学校正常运转，再让人物从同一个现实里显出不同。**

> **第一集不是17个人轮流登场，而是一所已经正常运行的学校，摄影机从今天开始跟上了其中一些人。**

五次 Flashback 顺序锁定：

1. 樱井｜形式 / 位置
2. 生驹｜“自己这样对不对”
3. 白石｜被看见
4. 桥本｜时间 / 第一次进这扇门
5. 生田｜音乐最初的使用方式

Flashback⑤结束以后不再回忆；最终主体必须回到学校。

## S01｜00:00–02:10｜正门 → 鞋柜

普通新生家庭拍入学第一天照片；白石从同一扇门自然经过，后辈叫她 `白石前辈`，同级叫她 `白石`。

新生还在看指示，高三已经用身体记住路线。

**功能：**先建立“第一次 / 第三年”的身体差，不做成员点名 montage。

详见：`cold-open-gate-v0.1.md`。

## S02｜02:10–03:00｜大厅 / 案内系统已经在工作

鞋柜之后进入主楼大厅。临时箭头、资料桌、普通案内係、教师与学生会已经运转。

片名压在工作中的大厅上；剧情不为片名停下。

樱井去承担台前代表位置；真夏继续处理流程；生驹接到1-A案内任务。

## S03｜03:00–06:30｜新生案内 / 1-A去旧礼堂

生驹与普通案内係共同带1-A，不包办迎新。

早上反复确认领结的新生只得到一句确认，不被主角替她整理。

抵达旧礼堂时，摄影机先读到三级台阶，随后自然读到旁边**事前已经安装好的稳定模块坡道**。

禁止恢复“临时发现进不去 / 最后一人未入场 / 樱井决定延迟开式”的旧因果。

详见：`new-student-guidance-v0.1.md`、`old-auditorium-accessibility-v0.1.md`。

## S04｜06:30–10:00｜旧礼堂 / 两条进入方式

新生流与保护者流分开，在旧礼堂入口附近短暂交汇。

使用轮椅的新生随班沿坡道正常进入；保护者在自己的入场流线上轻问坡道是否常设，工作人员回答活动时会提前设置。

问题不是当天救援事故，而是老建筑长期依赖额外准备才能继续公共使用。

## S05｜10:00–13:00｜礼堂从人流变成仪式空间

空间持续收束：

> 通行空间 → 座席空间 → 仪式空间

樱井从后台工作人员切换到台前学生代表；真夏留在后台继续执行；是否按时开式由成人会场负责人确认。

详见：`ceremony-prep-transition-v0.1.md`。

## S06｜13:00–21:00｜入学式・第一学期始业式 / Flashback①

正式仪式。普通学生、保护者、来宾与礼堂空间承担大量画面，不做主演反应大会。

校长大部分发言保持真实典礼场面话，只允许少数句子抬高：

> `好好学习。`
>
> `也请好好迷茫。`

Flashback①：三年前的樱井坐在新生席，观察当时学生会长怎样站、拿纸、翻页、退步、鞠躬；现在她已经非常会完成这套形式。

第一次 Flashback 的时间识别必须同时靠：

- 不同年级领巾；
- 樱井所处位置变化；
- 台上另有前任代表。

不加“三年前”字幕、滤镜或记忆音效。

新生代表正常优秀；榊陵只作为祝电中的校名出现；校歌属于整个学校。

详见：`entrance-ceremony-v0.1.md`。

## S07｜21:00–21:20｜后台 coda

> `现在比表上晚几分钟？`
>
> 真夏：`四分钟。`
>
> `四分钟。`
>
> 真夏：`还赶得回来。`

说完继续工作，不增加总指挥式命令。

## S08｜21:20–24:30｜生驹 / Flashback②

闭式以后按年级 / 座区分批退场；高二、高三也已经按各自路线返回主楼。

1-A是**一年级首批返回教室的班级之一**。生驹因案内职责继续陪它走第一次返程，因此比其他高三学生晚回自己班。

Flashback②只让观众看到：三年前的生驹反复确认领结、袖口、坐姿；普通同学只说：

> `没歪。`
>
> 生驹：`真的？`

回现在，案内係提醒：

> `生驹，你们班要开始了。`

她边走边摘下袖标、折好收起，因为下午仍有案内任务。

详见：`ikoma-flashback-guidance-v0.1.md`。

## S09｜24:30–26:50｜白石 / 3-B / Flashback③

3-B已经正常运转。同班女生：

> `白石，头发。`

顺手整理后继续自己的事。

Flashback③：三年前的白石把别人多看她几眼理解成“是不是哪里穿错了”；普通同学最后：

> `脸吧？`

回现在立即重新进入传纸、数材料等班级事务。

详见：`shiraishi-gaze-flashback-v0.1.md`。

## S10｜26:50–30:00｜四个高三HR并行

**一个制度 sequence，故意去对称化。**

- 3-A：松村先翻到文化祭只作为背景可读动作；
- 3-B：生田、桥本、白石的纸张习惯存在，但不逐项 CUT IN；
- 3-C：まあや `蓝色的呢？` 完整小节拍；
- 3-D：飞鸟 `背面。` / 敲纸 / 南 `啊。` 完整小节拍。

四班不追求同等长度、同等笑点、同等结束镜头。

详见：`four-homerooms-parallel-v0.1.md`。

## S11｜30:00–34:20｜午休 / 食堂 / 关系重新混流

四班一散，学生按真实关系重新组合。

食堂只打一套松重窗口梗，其余是便当、找座、别班门口、短互动与普通学生流动。

> **EP1只证明这些关系存在；EP3才真正坐下来拍午休。**

**时间锁：**不为原始4分20秒区间填剧情；2分30秒～3分钟左右已经读完就可以进入下一段。

详见：`lunch-flow-v0.1.md`。

## S12｜34:20–35:40｜西野 / 绕路

高山：

> `你从那边回来的？`
>
> `不远吗？`

西野：

> `嗯。`
>
> `有点。`

她随后自然偏出去看一眼普通校园，再自己跟上高山。

不解释“人少”、怕人或绕路意义。

详见：`nishino-detour-v0.1.md`。

## S13｜35:40–38:00｜飞鸟 × 南 / 高三第一天照片

普通同学临时想拍照。飞鸟说不要，没人继续劝；真正要拍时，她自己站起来，只站在画面边缘。

> **嘴比身体后退一步。**

不看成片，不让南揭穿。

**时间锁：**60–90秒已经成立就离开，不填满原始2分20秒。

详见：`asuka-minami-photo-v0.1.md`。

## S14｜38:00–40:00｜桥本 / Flashback④ / 时间

同一个预铃从3-D交给走廊里的桥本。

现在：她行走中看一次腕表，被正门方向带住视线，短暂停住。

Flashback④：三年前从车站来到校门外，看学校，很快看表，进去。

> **三年前在外面看里面；现在在里面看外面。**

不追求两个精确“两秒”或完美MATCH构图。

同学：`桥本？`；桥本：`马上来。`

详见：`hashimoto-first-gate-line-v0.1.md`。

## S15｜40:00–41:30｜下午继续 / 案内是今天限定

课堂碎片让时间真正过去。下午案内工作结束，袖标统一归还，普通学生撤收临时箭头。

普通新生：

> `这个明天就没有了吗？`

案内係：

> `嗯。只有今天。`
>
> `要是找不到，就问附近的学姐。`
>
> `这种事，本来就是学姐要告诉你们的。`

这句属于乃木坂女学院先后辈制度传统；随后立刻回到胶带清理，不做主题停顿。

详见：`guidance-ends-today-line-v0.1.md`。

## S16｜41:30–44:30｜第一回 進路希望調査

同一份调查表进入四个高三班。

学校只要求现阶段希望；未定可以写未定；下周五截止。

まあや问真实信息缺口。

普通学生：

> `这个是不是有点早？`

武田：

> `什么？`

> `进路。`

武田：

> **`你们都高三了。`**

不到一秒，现实马上回来：

> `橡皮借我一下。`

## S17｜44:30–46:10｜进路调查迅速输给今天 / 四班释放

放学去哪、部活、值日、清扫、学生会、图书馆、鞋柜以不同速度开始。

不做四班同步起立，不逐班展示主演去向。

高三楼层的柜门、椅子、脚步继续。

CUT。

钢琴已经在响。

## S18｜46:10–47:20｜生田 / 音乐别馆 / Flashback⑤

摄影机进入时，生田**已经在演奏**。乐谱、铅笔、标记早已存在。

Flashback⑤：三年前同一练习室。没有谱。她按一个音、听、回应脚步 / 门声。

普通学姐：

> `你刚才弹的是什么？`

生田：

> `……不知道。`

回现在时演奏没有停，直接进入下一乐句。

最后和弦、踏板、余响；稍宽画面里普通墙钟自然可读：

> `17:00`

不做秒针特写，不让生田看表确认。

下一时段低年级敲门：

> `打扰了。`

生田已经合谱、收笔、复位琴凳、拿包；经过时轻点头离开。

详见：`ikuta-music-room-flashback-v0.1.md`。

## S19｜47:20–49:20｜学校重新成为整体 / 偶然齐线

学生会、运动场、图书馆、音乐别馆、鞋柜与主楼仍在继续放学后的生活。

某个宽景里几个高三学生碰巧并排，裙摆一瞬间显得整齐；摄影机不停，普通学生穿过 / 转弯 / 被叫住，队形自然散掉。

裙摆齐线是**C级背景事实**，不是终盘第二个句号。

**时间锁：**30–60秒已经足够，不为原始两分钟区间拍感伤蒙太奇。

## S20｜49:20–50:00｜黑板 / 明天还要来

高三教室已被整理到明天可继续使用的状态。

调查表全部被学生带走。

黑板擦净，只留下：

> `進路希望調査　来週（金）まで`
>
> `明日　体育館シューズ`

无第三条板书，无 `待ってー！`，无夕阳 / 樱花 / 煽情钢琴。

两条信息视觉权重相同；极少普通学校环境声；足够读完以后 CUT TO BLACK。

> **第一集不以“毕业”为结尾，而以“高三开始了”为结尾。**

## FINAL Scene List 锁定规则

- S03–S05必须是一口气的现实收束，不是“无障碍议题场 + 后台介绍场”。
- S10与S16都是并行制度 sequence，不拆成主演小场。
- 五次Flashback不用统一滤镜、提示音或字幕；时间识别依靠服装、位置、空间与剪辑共同成立。
- S11 / S12–14 / S19不以原始时间格作为最低片长。
- 生田Flashback⑤保持60–75秒级别，不恢复“八分钟”机制；17:00是B/C级信息。
- 音乐空间固定在音乐・美术别馆。
- S20黑板只保留“进路表截止日期 / 明日体育馆鞋”两条通知。
- 正片逐句内容以 FINAL / LOCKED `screenplay.md` 为最高权威。
