## 核心

> **她不是不给自己时间看；她只是知道自己能看多久。**

> **别人都在流动，桥本短暂地静止。**

## 同一个铃声，从3-D切到桥本

飞鸟 / 南照片段结束，预铃响。

CUT到主教学楼走廊。

桥本和一名普通3-B同学一起往教室方向走。周围高三生都熟悉学校节奏。

同学：

> `「戻ろ。」`

桥本：

> `「うん。」`

桥本在行走中下意识看一眼腕表。

人物特质来自她**多做一个动作**，不是别人少知道一个常识。

## 现在｜学校里面看向门外

经过能读到校园主轴与正门方向的楼梯平台 / 走廊窗时，同学继续往前。

桥本被正门方向带住视线，停约两秒。

不使用伤感BGM和超级特写。让走廊人流继续经过，运动差本身成为记忆点。

CUT Flashback④。

## Flashback④｜三年前：门的另一侧

不写“三年前”，不使用怀旧滤镜。高一颜色领巾承担主要时间标记。

电车门开、普通通勤人流、IC改札 `ピッ`，一年级桥本在其中。

她来到乃木坂女学院正门外。

前面有其他新生：拍照、整理领巾、确认通知、直接进去。

桥本停下，看校门和里面的学校约两秒。

然后看表。

再抬头，走进去。

没有台词。

空间押韵：

```text
现在：学校里面 / 高三颜色 / 看门外 / 两秒
三年前：学校外面 / 高一颜色 / 看门内 / 两秒
```

不解释象征。

## 回现在

同学已经走出几步：

> `「橋本？」`

桥本：

> `「今行く。」`

她重新迈步，不再看第二次表。

记忆来了，现实叫她，她回去。

她回到3-B，重新淹没在30人的普通课堂里。
