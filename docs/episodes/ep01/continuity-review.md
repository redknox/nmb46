# EP01《入学》｜Continuity Review

> 状态：**STEP 10 首轮完整连续性审查。**
>
> 审查对象：`screenplay.md` 当前 S01–S20 完整第一版。
>
> 本轮只检查客观世界是否成立：时间、地点、人物位置、信息拥有关系、道具 / 设施状态、空间、物理动作、前后因果与恢复条件。**不评价主题是否动人，不评价台词是否漂亮。**

核心问题：

> **如果把这一集当成真实发生的一天，它能不能按这个顺序真的发生？**

---

## 一、总判定

**SCREENPLAY：PASS / 无结构性 RED。**

当前 S01–S20 可以作为同一个开学日连续发生。

当前有一项制作 / 表述层 YELLOW：

1. **典礼后退场顺序需要在下一轮正文修订时稍微写清。** S08 的 `1-A是第一批离开的班级之一` 与 S09 `3-B已经在教室正常运转` 本身可以成立，但前提是：1-A指一年级首批返回 HR；高二 / 高三已按另一批次或另一出口开始回主楼。不能让画面被理解成“1-A是全礼堂第一个离开，下一秒3-B却已经到三楼”。

旧礼堂容量旧 YELLOW 已解决：当前空间锁定约560席，可容纳360名学生、约120名新生保护者、教职员与来宾，并保留轮椅位置和少量运营余量。详见 `docs/world/old-auditorium-space-lock.md`。

原有一项**仓库文档 RED**，现已解决：

- `docs/world/old-auditorium.md` 已删除“现场抬轮椅 → 樱井自责 → 桥本 / 真夏事后处理”旧因果，并与事前模块化坡道及当前旧礼堂空间锁同步。

## 二、S01–S05｜入校 → 旧礼堂

### GREEN｜正门 → 鞋柜 → 大厅

- 正门、主轴、主楼关系成立；
- 新生需要看临时指示，高三依靠身体记忆进入，空间逻辑成立；
- 主楼1F承担新生、家长、来宾与行政接口，符合当前主楼锁定；
- 鞋柜 / 上履转换后进入大厅，没有空间瞬移。

### GREEN｜新生与保护者分流

当前执行：

> 新生先到班级集合 → 1-A由案内係带往旧礼堂
>
> 保护者走独立案内流 → 直接前往礼堂保护者席
>
> 两股人流在礼堂入口附近短暂交汇

成立。

轮椅新生不必为了家长提问停下来。她继续随班进入；家长在自己的流线上看见女儿使用坡道，再向工作人员轻问长期使用条件。

### GREEN｜坡道状态

坡道在学生到达前已安装：

- 稳定；
- 模块化 / 可拆卸；
- 非临时木板；
- 有基本防滑、边缘保护与可信坡度；
- 工作人员已在对应位置。

因此当天流程成功；第10集承接的是长期公共使用成本，不是EP01事故。

### GREEN｜轮椅新生进入后的状态

进入礼堂后，她回到普通新生席 / 事前安排位置，不再成为画面事件中心。书包、节目单、班级入席均正常。

## 三、S05–S08｜典礼切换、典礼、退场

### GREEN｜礼堂从人流变成仪式空间

`通行 → 入席 → 工作交接 → 后台收束 → 代表待机 → 开式` 连续成立。

成人责任边界正确：

- 真夏负责学生工作流；
- 是否按原定时间开式由会场负责教师确认；
- 樱井进入代表者位置以后不再同时持有后台任务。

### GREEN｜真夏“四分钟”

闭式后后台发现相较运行表晚4分钟：

> `四分钟。`
>
> `还赶得回来。`

没有反向改变已经发生的典礼，也没有让高中生取得成人调度权。

后续剧情也没有建立一个必须精确追回这四分钟的硬时钟，因此不存在恢复条件漏洞。

### YELLOW｜退场批次措辞

当前连续性需要这样理解：

1. 典礼闭式；
2. 在校生与一年级按不同区块 / 路线开始退场；
3. 1-A是较早返回HR的一年级班级；
4. 生驹因案内职责继续陪1-A走第一次返程；
5. 其他高三学生不承担这一职责，因此可以更早 / 更直接回到3F；
6. 到S09时3-B已经在教室运转；
7. 生驹随后赶回3-A。

这在物理上成立，但下一轮 screenplay 应把 `1-A是第一批离开的班级之一` 改成更不易误读的“一年级首批之一”，或在前面轻轻出现“在校生也已开始退场”的动作。

不需要新增对白。

只要按上面的退场批次理解，白石、桥本、生田、卫藤在3-B正常处理材料成立；生驹因额外案内职责晚回3-A成立。

### GREEN｜四班位置

高三四班均在主楼3F，当前锁定为：

> 3-A｜3-B｜中央楼梯厅｜3-C｜3-D

S10并行剪辑不需要人物跨空间，因此没有传送问题。

## 五、S11–S15｜午休 → 下午

### GREEN｜午休重新混流

四班HR结束后：

- 留教室吃便当；
- 去食堂；
- 去别班门口；
- 跨班汇合；

均符合主楼 / 食堂距离与关系网络。

松村与南只是在人流中自然并到一起，不需要跨校园主动找人。

### GREEN｜西野绕路

西野从较远但所有高三都知道的路线回来；高山只是对“今天为什么从这边回来”感到一点意外。

当前已删除“人少”动机解释，因此不产生她必须事先避开某处人流的隐藏因果。

### GREEN｜飞鸟×南照片 → 桥本预铃

3-D照片发生在午休后半；同一个预铃结束照片段并切到正在回3-B的桥本。

这两个空间都在3F，时间同步成立。

### GREEN｜桥本三楼高窗视线

主楼中央楼梯厅南侧高窗已锁定可沿校园主轴看到中庭、樱花步道并最终落到正门。桥本在校内看向正门方向成立。

### GREEN｜下午时间推进

课堂碎片承担真实时间流逝，不要求完整拍每节课。

S15案内撤收发生在当天新生说明 / 校内引导结束以后；袖标回收、箭头撤收与胶带清理均属于正常收尾工作。

## 六、S16–S20｜进路调查 → 17:00 → 黑板

### GREEN｜进路调查流程

同一份 `第一回　進路希望調査` 进入四个高三班：

- 现阶段希望即可；
- 未定可以写未定；
- 下周五截止；
- 学生把表带走。

S20黑板仍写 `来週（金）まで`，信息一致。

### GREEN｜放学不是一个瞬间

不同班级、值日、清扫、学生会、部活、图书馆、艺术别馆、鞋柜以不同速度释放。

这与学校日直 / 清扫制度一致：学生负责把自己使用的教室恢复到可继续使用状态，专业后勤负责深度清洁。

### GREEN｜生田切入

不跟拍生田从3-B一路走到东南音乐・美术别馆，而从高三楼层放学声直接CUT到已经响着的钢琴。

这不是人物传送：艺术别馆本来就是她正常会去的地方；剪辑只省略了无剧情价值的步行时间。

### GREEN｜17:00交接

当前动作链成立：

> 摄影机进入时已经在练习
>
> Flashback⑤由声音切入
>
> 回现在时演奏持续
>
> 最后和弦 / 踏板 / 余响
>
> 普通墙钟已到17:00
>
> 下一时段学生敲门进入
>
> 生田收谱、收铅笔、复位琴凳、拿包、让出空间

没有“17:00:00命中”或二次看钟，因此不是超能力计时。

具体练习室预约表、单次使用时长属于制作道具细节，不影响当前因果。

### GREEN｜最终教室状态

学生值日 / 清扫制度允许放学后：

- 课桌归位；
- 讲台整理；
- 黑板擦净；
- 日直保留必要通知。

因此最终黑板在清扫后只剩：

> `進路希望調査　来週（金）まで`
>
> `明日　体育館シューズ`

成立。

“体育馆鞋”不要求在前一场再次口头宣布；它可以是某一高三班第二天的普通携带提醒。最终教室不必在本集明确是哪一班，只需后续如复用该教室连续性时保持一致。

调查表全部被学生带走，因此桌面无遗留也成立。

## 七、世界设定同步问题

### RED｜`docs/world/old-auditorium.md` 已过期

该世界文档仍写：

> 轮椅新生到台阶前才发现无法进入
>
> 教职员在本人同意下抬轮椅进入
>
> 樱井事后自责
>
> 桥本 / 真夏围绕这次事故讨论

这些内容已被当前EP01明确废弃。

当前权威应统一为：

> 学校事前知道使用需求
>
> 活动当天提前安装稳定模块坡道
>
> 新生正常进入
>
> 生驹只看到“同一栋楼存在两条进入方式”
>
> 保护者在自己的入场流线上轻问坡道是否常设
>
> 当天不发生事故 / 不产生樱井自责戏
>
> 后续正式意见与消防、疏散、老化、无障碍等长期问题共同积累到EP10

该文档必须同步，否则未来写EP10会重新导入已废弃因果。

### YELLOW｜旧礼堂容量需进入制作锁

现有世界文档只锁定“第一集仍可承担开学典礼、EP10后停止大型使用”，没有给当前具体座席数。

制作阶段必须把以下同时放入平面：

- 360名学生；
- 新生保护者席；
- 教职员；
- 来宾；
- 轮椅观众位置与对应通道；
- 当时仍被学校接受的疏散条件。

不需要现在编一个整数，但不能把座席规模留到拍摄当天才发现不成立。
