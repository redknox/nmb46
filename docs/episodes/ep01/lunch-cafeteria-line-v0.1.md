## 一、现实基线

日本高校设置食堂 / カフェテリア、提供日替定食、丼、面类、咖喱、甜点或便当等非常常见；不同学校使用食券、学生证 / IC 卡或其他校内支付方式。热门菜单可能在午休中卖完。

可参考：

- 山手学院中学校・高等学校：カフェテリア有日替ランチ、丼、面、カレー等，并使用事前食券；
  https://www.yamate-gakuin.ac.jp/cafe/
- 中村学園女子中学校・高等学校：カフェテリア提供日替一汁三菜、面、丼、便当，官方直接说明人气担担面会出现 `即売り切れ`；
  https://www.nakamura-njh.ed.jp/junior/life/facilities.html
- 中村学園 2026：完全 cashless、支持事前购买，说明现代私校食堂支付方式可以非常多样；
  https://www.nakamura-njh.ed.jp/news/20610/
- 慶應義塾女子高等学校：正式设施介绍中将食堂ホール列为学校生活空间；
  https://www.gshs.keio.ac.jp/information/shisetsu.html

本剧此处不需要锁死支付系统。观众只要看到：

> **这是学生已经使用很多年的午饭系统，有固定菜单、热门品项、熟客与高峰人流。**

## 二、本段真正任务

这一段不是“终于让17个人聚在一起吃饭”。

真正任务是：

1. **视觉换气。** 从礼堂、木走廊、教室纸张切到蒸汽、金属餐盘、食物、窗口、排队声；
2. **第一次让跨班关系自然发生。** 食堂是公共空间，不需要角色为了见对方专门跨班；
3. **建立松重丰的成人锚点。** 他不是人生导师，只是每天把饭打出来、记得谁常吃什么的人；
4. **证明午休不只有食堂。** 有人吃食堂、有人留班吃便当、有人因为今天真有学生会善后才去学生会室；
5. **为下一段西野的小偏航留下出口。**

核心：

> **Home Room 告诉观众“她们平时被分在哪里”；午休开始告诉观众“她们今天怎样重新混在一起”。**

## 三、32:30–33:05｜铃一响，学校的声音和颜色都变了

上一场最后一句：

> 「はい、昼休み。」

不要马上切主演。

先跟普通学生的人流下楼。

视觉 / 声音快速变化：

- 楼梯上几十双室内鞋；
- 某人边走边把便当袋从包里拿出来；
- 食堂入口菜单板；
- 厨房蒸汽；
- 碗碰台面的声音；
- 排队学生从画面前景横穿；
- 一张小纸牌：某日替品项 `残りわずか` 或已经售罄。

不要用“欢乐午休BGM”替换现场声。前半分钟让食堂本身成为刺激。

镜头从高三人流里自然认出松村、南等人，但不立刻给英雄式中景。

## 四、33:05–33:55｜窗口：南的问题与松重丰的宇宙真理

南排到窗口。

她先往甜点区域看。

> 南：「今日、プリンある？」

松重丰甚至不需要抬头太久：

> 松重：「ない。」

南：

> 「なんで？」

松重：

> 「ないから。」

南认真接受两秒。

后面的松村探头：

> 「昨日あったやん。」

松重：

> 「昨日は昨日。」

不要笑点音效。

旁边普通学生继续报菜单，工作人员继续盛饭。

南拿走自己的餐盘。

### 松村与松重｜第一次“老样子”

轮到松村。

松重看她一眼：

> 「いつもの？」

松村很自然：

> 「うん。」

不解释“いつもの”是什么，也不让她回头告诉别人。

工作人员按熟悉流程给她准备。

这一句不是为了马上催泪，而是建立一个以后可以反复出现的极普通习惯：

> **食堂负责人记得一个经常来吃饭的学生通常吃什么。**

最终毕业段如果再次出现：

> 「いつもの？」

它才会因为重复本身变重。

第一集必须轻。

### 中文字幕

> 「いつもの？」
>
> **“老样子？”**

> 「うん。」
>
> **“嗯。”**

中日两边都直接成立，不需要文化注释。

## 五、33:55–34:55｜食堂不是主演大桌

给一个真正能读出容量的食堂宽景。

主要人物分散在不同区域，普通学生占绝大多数。

不要逐个交代17个人，只抓三四个足够说明生态的点。

### A｜松村仍然首先属于 3-A 的日常

松村端着“老样子”坐到几名普通 3-A 女生已经占好的位置。

她和南刚才一起排队，不代表两人自动一起吃饭。

松村坐下第一句话可以完全没剧情价值：

> 「それ一口ちょうだい。」

普通同学：

> 「やだ。」

松村：

> 「まだ何も言ってないやん。」

普通同学：

> 「言った。」

继续吃。

这比让她开始播报校园八卦更好：第一集先让观众知道她真的有普通同学生活。

### B｜南会流动，但不是为了拼主演桌

南端盘找位置。

看见普通 3-D 同学招手，直接过去。

她没有因为飞鸟没来就站在原地等。

飞鸟此刻可以在 3-D 教室吃自带便当 / 面包，和附近普通同学共享同一空间，不必给对白。

这同时保护：

> 南喜欢找飞鸟 ≠ 南只能和飞鸟生活。

### C｜3-C 的午饭不自动形成喜剧四人组

可以很短地看到：

- まあや和普通同学 Y 已经坐下；
- 高山在隔壁另一桌，与自己周围的人说话；
- 真夏没有出现，因为她今天确实有学生会善后；
- 西野可以和普通同学 X 吃完一部分午饭，话很少也很正常。

不要把 `真夏 + 高山 + まあや + 西野` 拼成固定一桌。

### D｜3-B 不需要再追白石

极短切回 3-B：

- 桥本留在教室吃自己带的东西 / 简单午饭；
- 普通同学 X 在附近；
- 白石和自己的普通女生圈正常吃饭；
- 生田可能边吃边看早上发的课程表，但不要重新进入音乐剧情。

这一镜的意义只有：

> **食堂很热闹，但不是所有人都必须去食堂。**

## 六、34:55–35:45｜学生会室：今天有理由，所以今天才在这里

今天上午发生了两个真实运营问题：

- 旧礼堂轮椅入场临时协助；
- 典礼整体晚了约四分钟。

因此樱井与真夏午休短暂进学生会室做最基础的当天记录，是合理的**制度相遇**。

必须明确：

> **她们不是每天午饭都在学生会室。今天是因为真的有事。**

桌上不是豪华会议：

- 两个人各自简单午饭；
- 典礼流程表；
- 一张手写 / 打印的 `当日確認事項`；
- 真夏在其中两行旁边做记号。

可读到：

> `旧講堂 入場導線`
>
> `式次第 4分押し`

真夏一边吃一边写：

> 「四分は戻せた。」

樱井：

> 「うん。」

她看着 `旧講堂 入場導線` 那一行。

很轻地：

> 「あれ、準備したつもりだったんだけどな。」

不要给真夏正确人生回答。

真夏只说工作层面的：

> 「次は、最初から入れとく。」

把那一项圈起来。

樱井点头，继续吃饭。

这一场不完成樱井关于“有没有漏掉谁”的情绪，也不提前进入第10集。它只让同一个问题留下组织记忆：

> **发生过，所以有人把它写进下一次流程。**

## 七、35:45–36:25｜回食堂：午休真正进入中段

再回食堂，时间已经过去一会儿。

这次不要再拍窗口主对白，而拍使用痕迹：

- 某个热门日替菜单牌被翻到 `売り切れ`；
- 学生端着空盘回收；
- 水杯；
- 椅子挪动；
- 一桌人笑，但我们听不清原因；
- 松重丰在窗口后补下一批餐具 / 和工作人员确认数量。

这会很轻地兑现樱井欢迎词：

> 食堂里，什么东西会最先卖完。

不需要角色指出“你看，真的卖完了”。

学校自己把台词变成现实。

松村那桌继续说自己的话，镜头不必听清。

南已经吃到别的东西，完全忘记刚才没有布丁。

## 八、36:25–36:50｜从“大家都在吃饭”里，让西野轻轻离开

这一段不提前完成下一场，只做交棒。

3-C / 食堂某处。

西野已经吃完大半。

普通同学 X 还在吃，可能正在看手机 / 说一件普通事。

西野拿起自己的饮料 / 空包装，起身。

X 很随意：

> 「どこ行くの？」

西野：

> 「ちょっと。」

X：

> 「うん。」

没有“等等我”、没有“她又神秘消失了”。

西野把垃圾 / 餐具处理掉，跟着一股学生人流出去。

走到本应回主楼的分叉处时，她看了一眼另一边。

镜头先不要跟过去。

切掉。

下一段再回答：她为什么去了那边。

这让她的“偏航”首先像一个普通午休动作，而不是人物登场机关。

## 九、松重丰在第一集的尺度

他不能成为“治愈系食堂大叔”。

第一集只需要让观众记住：

- 他一直在这里；
- 他知道今天有没有布丁；
- 他不打算为“为什么没有”写一篇人生哲学；
- 他记得松村的“老样子”；
- 学生说完话，饭还是要继续打。

他的成人功能不是教育，而是**重复**。

学生一年一年换，他每天仍然问：

> 「いつもの？」

这就是“外部演员负责时间”在食堂里的版本。

## 十、视觉注意力节奏

四分多钟绝不能拍成连续饭桌对话。

感知输入建议：

```text
四班午休同时松开
→ 楼梯人流
→ 菜单板 / 蒸汽 / 金属餐具
→ 南 × 松重窗口短喜剧
→ 松村“老样子”
→ 食堂大宽景
→ 不同普通同学桌
→ 3-B教室便当一闪
→ 学生会室安静、纸张与午饭
→ 回食堂时菜单已经售罄
→ 回收餐盘 / 椅子 / 人声
→ 西野起身离开
→ 走廊分叉
```

宏观观看任务变化：

> **看食物 → 看关系 → 看学校工作残留 → 再看食物已经被吃掉 → 看一个人离开人群。**

## 十一、必须避免

### 1. 不做17人食堂会师

食堂是跨班公共空间，不是编剧的集合大厅。

### 2. 不把松重丰写成金句机器

`没有。因为没有。昨天是昨天。` 已经足够。

### 3. 不用“主演反应镜头”解释轻笑

南问布丁、松村被认出“老样子”，附近学生该吃就吃。

### 4. 不把学生会午饭写成常态

今天有真实流程善后，所以樱井 × 真夏在这里；下一次午休完全可以各自回自己班 / 去别处。

### 5. 不让西野的离开马上神秘化

她只是站起来走了。

观众到下一段才逐渐发现：她没有走最通常的那条路。

---

## 十二、当前推荐保留的核心瞬间

如果最终必须压时长，优先保留：

1. **南：**`「今日、プリンある？」` → `「ない。」` → `「なんで？」` → `「ないから。」`；
2. **松村 × 松重：**`「いつもの？」` → `「うん。」`；
3. **食堂宽景：**主要人物分散在普通学生之间，没有主演大桌；
4. **学生会室：**`旧講堂 入場導線` 被真夏写进下一次确认事项；
5. **回食堂：**热门菜单牌已经变成 `売り切れ`，没人解释；
6. **西野：**`「どこ行くの？」` → `「ちょっと。」`，然后在走廊分叉处看向另一边。

本段最小人物 / 世界句子：

> **学校最像学校的时候，往往不是有人在讲学校，而是所有人终于开始吃午饭。**
