# EP01《入学》｜06:30–10:00「旧礼堂的三级台阶」V0.2

> 状态：**工作稿 / 非锁定。**
>
> 上一棒：`03:00–06:30` 新生案内已确认。1-A与其他班一起前往旧礼堂。
>
> 下一棒：`10:00–13:00` 典礼前最后准备；本版删除“因轮椅新生尚未入场而临时决定延迟开式”的旧冲突。
>
> 本段目标：旧礼堂第一次不作为“漂亮传统建筑”被观看，而作为**正在被学生使用的建筑**暴露现实限制。学校当天准备充分，但临时准备本身反而证明：建筑并没有让所有学生获得同样自然、随时的使用权。

## 一、核心修正｜不是“今天进不去”，而是“今天必须专门准备才能进去”

乃木坂女学院事前知道一名新生使用轮椅。

因此本段固定：

- 一年级担任、事务部门和礼堂负责教师事前知道；
- 学校已经与本人 / 家庭确认入学式当天的进入方式；
- 学生到达以前，旧礼堂入口已经设置好**正式、稳定的可拆卸 / 临时模块化坡道**；
- 这不是临时拿一块板搭在三级台阶上的应急处理；
- 坡道的长度、坡度、防滑、边缘保护等应由制作设计按真实安全尺度解决，画面上不能显得陡峭危险；
- 学生会不需要得到该生完整个人资料，因此樱井、真夏、生驹此前不知道具体个案也不矛盾。

本场真正的不适感不是：

> “学校没有准备。”

而是：

> **学校已经准备得很好；但别人每天抬脚就能进去的地方，她仍然需要学校先为她安装一条特别路径。**

问题属于旧礼堂，不属于学生本人，也不属于某位失职的老师。

---

## 二、06:30–07:10｜队伍来到旧礼堂：三级台阶旁边已经有坡道

1-A与其他一年级班级按正常路线抵达旧礼堂。

第一眼仍然先读到旧建筑：石阶、旧门、木结构、长期使用痕迹。

前面的新生自然从三级台阶进入。

镜头随后才自然读到：

> **台阶一侧，今天已经设置好一条明显属于“临时加设”的坡道。**

它应当稳固、整洁、与学校整体管理水平一致，但视觉上仍能看出：

> 这不是建筑原本的一部分。

不要给坡道英雄式特写。

它只是今天现场的一项准备。

---

## 三、07:10–07:45｜她不需要停下来等“救援”

使用轮椅的新生跟着本班继续前进。

负责入口的教职员已经在坡道附近。

可以非常普通地确认：

> 「こちらからどうぞ。」
>
> “从这边请。”

如果事前约定需要工作人员在坡道旁确保安全，可以问本人：

> 「横、つきますね。大丈夫ですか？」
>
> “我在旁边跟着，可以吗？”

学生：

> 「はい。」

不要替她推，除非人物设定或具体坡度确实需要、且本人同意。

最理想的视觉是：

> **她自己沿已经准备好的坡道进入；成年人只是让这条路径安全、顺畅地存在。**

这比“把她搬进去”更符合本剧希望给予这个人物的主体性。

---

## 四、07:45–08:15｜生驹只看见一个差别，不负责解决

生驹继续承担1-A案内。

她可以在走台阶进入时，很短地看一眼旁边的坡道。

不需要停下来，也不需要被教师提醒“班上那边拜托你”。

因为此时并没有事故发生，也没有需要她克制冲动去救人的情况。

她只是第一次在自己非常熟悉的旧礼堂入口，看见两条不同的进入方式：

```text
大多数学生
三级台阶
→ 直接进入

使用轮椅的新生
当天事前设置的坡道
→ 正常进入
```

生驹没有必要立刻理解这意味着什么。

她继续工作。

## 五、08:15–08:50｜不要把“顺利进入”拍成成功

没有：

- 掌声；
- “太好了”；
- 同学集体关注；
- 感动BGM；
- 新生本人感谢学校照顾；
- 老师松一口气。

她进入礼堂以后，就和其他一年级学生一样继续找座位、放好东西、等待典礼。

真正留下来的只是一个非常普通的事实：

> **今天这件事被学校处理得很好。**

而观众同时可以看见另一个事实：

> **如果今天没有这条专门安装的坡道，她就不能用同样的方式进入。**

## 六、08:50–09:30｜家长看到的不是“学校失职”，而是“这只是今天的办法”

入学式当天家长也在礼堂区域。

不需要安排当场激烈投诉。

推荐只给一个非常轻的观察。

家长看见女儿已经正常进入。

她的目光随后落在：

- 旧礼堂原本的三级台阶；
- 旁边明显是当天临时设置的坡道；
- 工作人员仍在维持入口。

如果需要一句现实问题，可以由家长很平静地问附近工作人员：

> 「これは、普段も設置されているんですか？」
>
> “这个平时也会一直设置吗？”

工作人员按事实回答即可，例如：

> 「行事の際には、事前に設置しています。」
>
> “有活动的时候，我们会事先设置。”

不要让工作人员说错话，也不要把家长立刻写成愤怒状态。

这个回答本身已经足够。

家长意识到的问题是：

> **女儿今天参加入学式没有被排除；但她以后想在普通日子临时进入旧礼堂，并不拥有与其他学生一样自然的条件。**

## 七、家长后续不是“闹事”，而是通过正式渠道提出设施使用上的咨询 / 要望

第一集不必完整演投诉过程。

可以只在后续学校记录中留下：

> 使用轮椅的新生家庭就旧礼堂的日常无障碍使用条件，向学校正式提出咨询 / 改善要望。

语气不需要是：

> “学校怎么能这样！”

而更接近：

> **“入学式当天学校准备得很周到，我们也很感谢。但她今后三年如果想参加礼堂里的普通活动，是否每一次都必须提前申请、等待临时设施？”**

这才是第10集真正值得回答的问题。

学校也不防御：

- 记录意见；
- 由事务 / 设施系统继续确认旧礼堂使用条件；
- 在后续整体安全、消防、疏散、无障碍评估中成为已有事实材料之一。

因此第10集不是“学校终于因为投诉被迫改造”。

而是多年来累积的建筑使用现实，在这一届学生身上再次变得具体。

## 八、09:30–10:00｜删除“还有一名正在入场 / 要不要延迟开式”

因为坡道事前已经设置，学生按计划正常入场。

因此旧版以下链条删除：

> `一年生、あと一人入場中です。`
>
> → 真夏看时间
>
> → “要不要先开始？”
>
> → 樱井决定等她

保留它反而会重新制造冲突。

新的结尾应当回到**正常的典礼准备**：

- 新生席逐渐坐满；
- 家长席入座；
- 礼堂门口完成最后引导；
- 工作人员确认通道；
- 后台收到“新生入场基本完成”的普通信息；
- 真夏按正常流程继续看淡红色进度表；
- 樱井已经处于舞台侧候场位置。

这一场不需要制造戏剧事件来结束。

真正的戏已经存在于一个观众可以自己读懂的画面里：

> **三级石阶旁边，多了一条只在需要时才出现的坡道。**

## 九、现实制作提醒｜坡道不能拍成一块短板

日本现行建筑无障碍设计的正式诱导标准中，作为楼梯替代 / 并设的坡道通常以不超过约 `1/12` 的坡度作为重要基准之一；因此三级台阶如果有正常高度，真正安全的坡道在画面里会有明显长度，而不会是一块很陡的短板。

本剧不需要在对白中讲规范数字，但美术 / 场景设计必须避免：

> “为了剧情方便，在三阶楼梯上随便架一块板。”

推荐视觉：

- 可拆卸模块化结构；
- 足够长度；
- 防滑面；
- 明确边缘保护；
- 如实际设计需要，可带扶手 / 平台；
- 与旧建筑并存，但一眼看得出属于后加设施。

具体尺寸在制作阶段按旧礼堂入口实际高差与可用前场空间计算。

## 十、这版为什么更适合整季

旧版结构是：

```text
建筑有问题
→ 今天出事故
→ 临时解决
→ 家长投诉
→ 第10集修复
```

很容易给观众“编剧为了第10集硬造第一集事故”的感觉。

新版是：

```text
学校知道建筑有局限
→ 入学式当天事前做好临时措施
→ 新生正常参加
→ 家长因此更清楚地看到：这是临时措施，不是平等的日常使用条件
→ 正式提出长期使用上的疑问 / 改善要望
→ 学校把它记录进真实存在的设施问题
→ 第10集与消防、疏散、建筑老化、历史价值一起进入整体判断
```

这让旧礼堂不存在一个单独的“罪状”。

它的问题是：

> **一个被很多人珍惜、仍然可以被精心维护和临时补救的老建筑，已经越来越难承担现代学校希望所有学生自然使用的公共礼堂功能。**

这正好服务第10集最终的重建逻辑。
