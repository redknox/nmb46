# EP01《入学》｜Cold Open「同一扇校门」

> 状态：**本段设计已确认 / 台词、秒点与具体分镜细节非锁定。**
>
> 目标区间：`00:00–03:00`。
>
> 核心：开场不从任何一期生的脸开始，也不从航拍、樱花慢动作、豪车或“明星登场”开始。先看一个普通新生家庭试图把“入学第一天”留下来，再让已经生活在这里三年的高三学生从同一扇门继续往里走。

## 一、开场最高原则

> **有人今天第一次来到这里，所以想停下来拍一张；有人已经走过这里三年，所以根本不会停。**

这不是主题台词，只是同一画面里的两种身体状态。

禁止把前三分钟拍成17人点名 montage。

## 二、00:00–00:30｜第一张照片

第一画不是无人学校大全景。

镜头在校门内侧偏一边的普通人眼高度，能同时看见：

- 校门 / 校名牌的一部分；
- 一名新生和家长；
- 后方仍在进入的学生人流；
- 学校已预留、不妨碍主通行线的入学纪念拍照位置。

环境声先行：鞋底、远处说话、手机快门、春天普通的校园声。

家长刚拍完一张，低头看一下手机，又抬起来：

> 「あ、もう一枚だけ。」
>
> “啊，再拍一张。”

可以顺手补一句非常生活的：

> 「ちょっと待って、髪。」
>
> “等一下，头发。”

女儿嫌麻烦也可以轻轻回一句：

> 「もういいよ。」
>
> “已经可以了啦。”

不要把“再拍一张”演成主题句。

母女为了把校名牌也完整放进画面，不自觉往通行线挪了半步。

门卫佐藤二朗从画外或侧面轻声提醒：

> 「もう少しだけ、こちらでお願いします。」
>
> “再往这边一点就好。”

他不训人，也不发表校规；学校既允许家长纪念第一天，也必须让后面的人继续通过。

第一组关系成立：

> **照片想让时间停一下；学校的运行不会停。**

## 三、00:30–01:00｜白石第一次出现：不是“大家都看她”，而是“很多人本来就认识她”

几名高三学生自然从背景人流经过。

白石在其中，但不给专属慢镜、正脸定场或BGM变化。

先从画外 / 后方听见两名高二女生很自然地：

> 「白石先輩、おはようございます。」

白石看向她们，正常回应：

> 「おはよう。」

不停步。

再往前几步，一个同级普通女生从另一侧：

> 「白石、おはよ。」

白石：

> 「おはよ。」

可以只是抬一下手，也不停下来。

正在拍照的一年级女生先是因为听见“白石先輩”而自然往声音方向看，正好看见白石回应别人。

她的视线多停半秒。

家长：

> 「ほら、こっち見て。」
>
> “看这边。”

新生重新看镜头。

白石已经继续往里走。

这段不表达“全校都为美女停下”，而表达：

> **她很显眼，也很容易被接近；在这所学校里，她已经有三年的熟人关系。**

控制数量：一组后辈 + 一名同级即可。禁止变成连续多人排队问候的“白石巡游”。

## 四、01:00–01:35｜第一次与第三年的身体差

镜头跟随整体入校人流往主楼移动，不固定追任何主角。

普通新生：

- 看临时案内牌；
- 再看手里的班级 / 集合资料；
- 对建筑与路线仍需要视觉确认。

同一画面里的高三学生：

- 不看箭头；
- 自然选择自己的路线；
- 走路速度与转弯都没有犹豫。

飞鸟、南等命名人物可以在这一段作为普通人流经过，但**不安排人物专属台词或萌点**。

原定“门卫问南醒没醒 / 南回答还没”的梗从EP01删除，保留给后续更适合的普通上学日使用。

同时禁止为了人物卡提前安排：

- 桥本看表；
- 生田敲节奏；
- 生驹整理制服；
- 松村吃东西；
- 高山 / まあや完整段子。

前三分钟只需要让观众感觉：

> **高三已经会使用这所学校。**

## 五、01:35–02:10｜鞋柜 / 上履き：真正进入学校

从室外鞋换成上履き，是开场第一次明确的空间转换。

普通新生寻找自己的位置，动作稍慢：确认编号、放鞋、拿上履き。

旁边高三学生几乎不用看，动作已经形成习惯。

不要让主角示范给新生看。

如果出现小摩擦，只给普通生活：

- 新生一时挡住通道；
- 后面的人等半秒或自然绕过；
- 没有人发表教育观点。

学校允许这种很小的停顿，不拍成无摩擦宣传片。

## 六、02:10–03:00｜进入大厅；片名压在已经开始的工作上

镜头从鞋柜进入主教学楼大厅。

观众可以自然看见今天临时设置的：

> `新入生はこちら →`

但箭头不成为构图中心，也不与片名字体做设计性对齐。

更里面：普通案内係、学生会人员、教师、资料桌已经在工作。

不要拍安装牌子。学生到达时系统本来就已经准备好。

片名在**正在运转的大厅宽景**上轻轻出现：

> 剧名
>
> 第一话《入学》

不黑屏，不砸音乐，不要求所有动作等标题结束。

推荐前三分钟继续不使用非画内配乐；片名仍在时，下一场工作已经可以开始。

教师声音直接进入：

> 「一年A組、お願いします。」

生驹：

> 「はい。」

她把有些转偏的深蓝 `新入生案内` 腕章转正，继续工作。

片名随后自然淡出。

也就是说：

> **剧情不为片名停下来。**

## 七、为什么删除“豪车 / 消防通道”作为开场主动作

不是因为名门家庭不会坐车，而是这会引入不必要的信息负担：家长能否驾车入校、停车规则、财富编码、门卫为何主要管车辆等。

阶层感以后应由学校资源、家庭道路、礼法、空间与现实选择体现，不靠校门口豪车队列。

## 八、前三分钟命名角色使用上限

第一遍观众真正需要明确注意到的命名人物最多：

- 佐藤二朗：门卫 / 边界；
- 白石麻衣：通过别人自然叫她“白石先輩 / 白石”进入学校关系网。

其他一期生即使已经在背景出现，也不要求观众认出。

樱井、真夏、生驹的制度功能留给03:00以后。

固定理解：

> **第一集开场先让观众记住这是一所学校，而不是先确认自己认出了多少成员。**

## 九、压力测试后的固定边界

### 1. `「あ、もう一枚だけ。」`不能成为“第一句主题金句”

必须被看手机、整理头发、女儿嫌麻烦等生活噪音包住。第一遍观众可以完全忘掉它。

### 2. 白石的存在感来自关系，不来自群体失态

不能摄影机追拍、音乐变化、集体转头。她首先是很多人本来就认识、敢于打招呼的学姐；新生只是因此注意到她，再多看半秒。

### 3. 删除EP01“南没睡醒”梗

这个梗本身保留，但不在Cold Open使用，避免白石之后立刻进入“下一个成员介绍”。

### 4. 箭头不能过早被拍成象征

前三分钟只是学校案内的一部分；真正的视觉回收留到42:30以后撤收案内牌时。

### 5. 开场节奏宁可短，不为凑满3分钟延长已读完的画面

推荐：

```text
00:00–00:30  入学纪念照 / “啊，再拍一张”
00:30–01:00  白石 / 学妹问候 / 新生被声音吸引
01:00–01:35  新生看指示，高三不看
01:35–02:10  鞋柜 / 上履き
02:10–02:35  进入大厅，案内系统已经运转
02:35–03:00  片名仍在时下一场工作直接开始
```

## 十、当前最小节奏

```text
手机快门
→ 家长：“啊，再拍一张。”
→ 为通行轻轻让位
→ “白石先輩、おはようございます。”
→ 白石回应，继续走
→ 新生因声音看过去半秒
→ “看这边。”
→ 新生看案内，高三直接转弯
→ 鞋柜：新生确认编号，高三熟练换鞋
→ 大厅 / 案内系统已经运转
→ 片名
→ 教师：“一年A組、お願いします。”
→ 生驹：“はい。”
```

本段真正的结构句仍然只属于编剧室：

> **有人今天第一次进来，所以想停一下；有人已经在这里三年，所以继续往前走。**
