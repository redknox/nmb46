# EP01《入学》｜Cold Open「同一扇校门」V0.1

> 状态：**工作稿 / 非锁定。**
>
> 目标区间：`00:00–03:00`。
>
> 核心：开场不从任何一期生的脸开始，也不从航拍、樱花慢动作或豪车开始。先看一个普通新生家庭试图把“入学第一天”留下来，再让已经生活在这里三年的高三学生从同一扇门继续往里走。

## 一、开场最高原则

> **有人今天第一次来到这里，所以想停下来拍一张；有人已经走过这里三年，所以根本不会停。**

这不是主题台词，只是同一画面里两种身体状态。

禁止把前三分钟拍成17人点名 montage。

## 二、00:00–00:35｜第一张照片

第一画不是无人学校大全景。

镜头在校门内侧偏一边的普通人眼高度，能同时看见：

- 校门 / 校名牌的一部分；
- 一名新生和家长；
- 后方仍在进入的学生人流。

环境声先行：鞋底、远处说话、手机快门、春天普通的校园声。

第一句对白来自不具名家长：

> 「もう一枚だけ。」
>
> “再拍一张。”

不是主题句，就是家长最普通的要求。

新生稍显僵硬地重新站好。

这时后面的学生需要经过。

门卫佐藤二朗从画外或侧面：

> 「すみません、少しだけ左に寄ってください。後ろ通ります。」
>
> “不好意思，往左一点。后面还要过人。”

家长和新生立刻往旁边让。

门卫不训人，也不发表校规，只是在维持通行。

**第一组关系已经成立：照片想让时间停一下，学校运行要求人流继续。**

## 三、00:35–01:10｜白石只被看一眼

几名高三学生自然穿过镜头。

白石可以在其中，但不给专属慢镜、正脸定场、BGM变化。

正在拍照的新生视线无意识跟着她偏过去半秒。

家长：

> 「ほら、こっち見て。」
>
> “看这边。”

新生重新看镜头。

白石已经走出画面。

这就是她在前三分钟的全部功能。

观众不需要知道名字，只需要知道：

> **这个学姐容易让人多看一眼。**

## 四、01:10–01:35｜南与门卫：三年日常只用五秒

星野南跟着普通高三人流进来，明显还没完全醒。

佐藤不是专程等她，只是在她经过时：

> 「おはよう。起きてる？」
>
> “早。醒着吗？”

南：

> 「まだ。」
>
> “还没。”

两个人都不停。

不要给反应特写，不要等笑点落地。

这句的功能不是介绍“南很可爱”，而是让观众第一次感觉：

> **门卫和这些学生已经这样见了很多个早晨。**

## 五、01:35–02:05｜从校门到主楼：第一次与第三年的身体差

镜头跟着整体人流进入校园，不固定追某个主角。

一个新生：

- 看临时案内牌；
- 再看自己手上的班级 / 集合资料；
- 对建筑与路线仍需要视觉确认。

同一画面里，高三学生：

- 不看箭头；
- 自然选择自己的路线；
- 走路速度与转弯都没有犹豫。

可以让飞鸟从一个正在补拍照片的家庭旁边自然侧身绕过去，但不给台词。

不要安排桥本看表、生田敲节奏、生驹整理制服等人物卡式动作。前三分钟不抢后续已经确认的角色入口。

## 六、02:05–02:40｜鞋柜 / 上履き：真正进入学校

从室外鞋进入上履き，是开场第一次明确的空间转换。

普通新生寻找自己的位置，动作慢一点：确认编号、放鞋、拿上履き。

旁边的高三学生几乎不需要看，动作已经形成习惯。

不要让主角示范给新生看。

如果需要一个极小摩擦，只给普通学生：

- 新生一时挡住通道；
- 后面的人自然等半秒或从旁边过去；
- 没有人因此发表教育观点。

学校不是高效宣传片，它允许这种很小的停顿。

## 七、02:40–03:00｜片名落在“案内系统已经存在”之后

镜头从鞋柜 / 入口进入主教学楼。

第一次清楚看见今天临时设置的：

> `新入生はこちら →`

以及更里面正在工作的普通案内係、学生会人员与教师。

不要拍“安装牌子”；学生到达时系统本来就应该已经准备好。

人流持续沿箭头进入。

片名在这个普通运行画面上短暂出现：

> 剧名
>
> 第一话《入学》

不需要黑屏砸标题，不需要强音乐停顿。

推荐：前三分钟不使用非画内配乐；第一处音乐若需要，可从片名后 / 进入03:00新生案内段时再开始。

片名淡出以后，直接进入下一棒：

> 教师：`「一年A組、お願いします。」`
>
> 生驹：`「はい。」`

生驹把转偏的深蓝 `新入生案内` 腕章转正，继续工作。

这样片名不是“主角登场”，而是：

> **学校已经开始工作了。**

## 八、为什么删掉“豪车 / 消防通道”作为开场主动作

不是因为名门家庭不会坐车，而是因为它对本场没有必要，而且会引入额外解释：

- 家长能否驾车入校；
- 校门周边停车规定；
- 是否在用财富视觉编码学生阶层；
- 门卫为何主要在处理车辆而不是入校人流。

这些都不是前三分钟真正需要的信息。

校门拍照、家长与新生、普通入校人流已经足够建立“入学第一天”。

阶层感以后应主要由学校资源、家族路径、行为礼法和现实选择体现，而不是靠门口豪车。

## 九、前三分钟命名角色使用上限

推荐真正能被第一遍观众明确注意到的命名人物最多三名：

- 佐藤二朗：门卫 / 边界；
- 白石麻衣：只被新生自然多看一眼；
- 星野南：与门卫有五秒旧日常。

飞鸟等人可以只是经过，不要求观众认出。

樱井、真夏、生驹的制度功能留给03:00以后。

核心：

> **第一集开场先让观众记住这是一所学校，而不是先确认自己认出了多少成员。**

## 十、压力测试

### 1. 第一台词会不会太主题化？

`「もう一枚だけ。」` 本身是普通家长拍照语言。只有整季看完回头，它才可能获得“还想再留一下”的第二层意思。第一遍不应被表演成金句。

### 2. 白石会不会又被做成校花登场？

如果摄影机追她、音乐变化、其他人集体转头，就失败。必须只有一个新生短暂分神，随后马上被家长叫回镜头。

### 3. 南与门卫是不是太像专门安排的萌点？

关键是两人都不停步，台词不需要反应镜头。它应该像他们过去三年已经发生很多次的早晨。

### 4. 为什么前三分钟没有樱井 / 真夏 / 生驹？

她们可以在背景存在，但制度人物正式进入03:00以后。开场如果同时把学生会、迎新职责、主角关系全部解释，会让观看任务过载。

### 5. 片名落在箭头上会不会太“设计”？

不要做箭头特写对齐片名字体。只是一个入口宽景里自然能看到临时牌，片名叠在画面其他区域。真正的箭头主题回收留到42:30撤牌时才被观众重新读到。

## 十一、目前最推荐的前三分钟节奏

```text
手机快门
→ 家长：“再拍一张。”
→ 门卫让出通道
→ 高三人流从新生身后继续进入
→ 白石经过，新生多看半秒
→ “看这边。”
→ 南与门卫五秒旧日常
→ 新生看箭头，高三不看
→ 鞋柜：新生确认编号，高三熟练换鞋
→ 主楼入口 / 新入生はこちら →
→ 片名 / 第一话《入学》
→ 教师：“一年A組、お願いします。”
→ 生驹：“はい。”
```

这三分钟的真正句子只存在于结构里：

> **有人今天第一次进来，所以想停一下；有人已经在这里三年，所以继续往前走。**
