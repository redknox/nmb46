# 二、00:00–03:00｜Cold Open：同一扇校门

春天，乃木坂女学院校门。

新生与家长第一次进入；高三学生则以已经形成三年的身体习惯进校。

画面可以先短暂接近“名门女校宣传片”，再由真实运营细节把它拉回学校生活：车辆、消防通道、鞋袋、门卫、家长拍照、迟到边缘、普通学生人流。

佐藤二朗作为第一成人锚点，功能只有一个：

> **校门不是象征先发生，而是边界先发生。**

不做17人点名 montage。允许主要人物只是从画面里经过。

### 本段最终压力测试重点

- 不给白石“全场静止看美女”的偶像式出场；最多是新生自然多看一眼；
- 不让松村 / 高山 / まあや为了第一分钟介绍性格而连续制造段子；
- 门卫的现实动作优先于明星亮相。

# 三、03:00–06:30｜新生案内系统

主楼入口、鞋柜区、临时案内牌、学生会、普通案内係共同形成一套已经运行起来的系统。

樱井负责需要代表学生会形成判断的事项；真夏负责名单、物资、时间与执行。

生驹可以在画面中作为高三 `新入生案内係` 出现，但此处不完成她的人物介绍。腕章规则已经锁定：深藏青布、白字 `新入生案内`，所有当值高三统一使用，不是生驹专属主角道具。

可保留极轻动作：

> 教师：`「一年A組、お願いします。」`
>
> 生驹：`「はい。」`

她把有些转位的腕章转正，让字重新朝外，继续工作。

大量普通高二 / 高三学生必须同时工作。

### 禁止

- 生驹一个人包办新生案内；
- 若月、深川、松村等命名角色为了证明存在而轮流经过；
- 把迎新总台拍成学生会主演办公室。

# 四、06:30–10:00｜旧礼堂：漂亮建筑第一次遇到使用现实

一名使用轮椅的新生到达旧礼堂入口，面对现存台阶与缺乏无障碍通道的事实。

核心处理已经确定：

- 不把她发展成“议题角色”；
- 不让学生英雄式抬轮椅；
- 教职员先确认可行方式，并征得本人同意；
- 由成年人按安全方式协助进入；
- 不放煽情音乐；
- 周围学校生活继续发生。

### V4 修正

**不需要桥本路过提供“侧门也有台阶”的事实。**

这类建筑信息应由负责场地 / 事务的成年人本来就知道。删除该动作，避免为了显示桥本现实敏锐而让她成为所有现实问题的自动顾问。

光石研在这里负责的是：

> **学校遇到现实问题时，成年人承担责任。**

他不需要演成第一次发现建筑有问题，也不需要现场讨论第10集结论。今天只解决“这名学生现在怎样安全进去”。

旧礼堂问题随后通过校内记录、正式渠道与长期设施判断继续存在，而不是由这一场当场解决。

# 五、10:00–13:00｜等她进去再开始

典礼开始前，现场因为入场协助产生几分钟延迟。

樱井得知情况后可以做一个低难度、但真实需要负责人判断的决定：

> 等新生全部正常入席再开始。

这不能拍成她第10集式的领导成长。

真夏立刻处理时间表、主持提示、后台信号与学生会人员。

普通学生会成员继续工作。

该段必须让观众理解：

> **樱井不是不会决定；她真正的困难，是以后面对“双方都有道理”的决定。**
