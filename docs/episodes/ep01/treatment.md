- 逻辑重量 ≠ 镜头重量；
- 普通学生、教师、工作人员必须继续正常生活；

- 不靠持续“调戏观众预期”制造聪明感；类型意识只能偶尔出现，不能成为重复手法。

## S03–S04｜1-A去旧礼堂 / 两条进入方式

### 已解决 YELLOW｜保护者动线

**新生流与保护者流分开。**

- 新生先完成班级集合，由生驹与普通案内係带 1-A 前往旧礼堂；
- 保护者按另一套案内路线直接前往礼堂 / 保护者席；
- 两股人流在旧礼堂入口附近短暂交汇；
- 使用轮椅的新生继续跟着自己的班，不因“问题场景”停下；
- 她的保护者已经在入口附近，因此自然看见：大多数新生走三级石阶，女儿沿学校事前设置的稳定临时坡道进入；
- 保护者只向现场工作人员轻问：`「これは、普段も設置されているんですか？」`；
- 工作人员如实回答活动时会提前设置；
- 不争执，不形成投诉戏，不让学生本人承担解释功能。

同一入口短暂出现三种现实流线：

> 新生流 → 新生席
>
> 保护者流 → 保护者席
>
> 使用轮椅的新生 → 同一礼堂，但通过另一条进入路径

临时 / 模块化坡道继续成立，但必须稳定、防滑、坡度与边缘安全可信；不是临时拿木板应急。画面能看出它是额外设置，而非建筑原生路径。

结构含义仍保持：

> 今天准备得很好；长期问题恰恰是“正常使用”依赖额外准备。

## S05｜礼堂切换到典礼状态

### GREEN

这三分钟不是另一场冲突，而是一次持续收束：

> 通行空间 → 座席空间 → 仪式空间

### Treatment 保护

不能按文档逻辑标题切成多个独立小场。通过动作与声音连续连接：新生落座 → 案内係退出 → 后台工作 → 真夏进度表 → 资料交接 → 舞台侧樱井 → 礼堂逐渐安静 → 司会开口。

核心要求：

> **文件里有多个逻辑步骤，画面只能感觉是一口气。**

# 第二批｜S06–S10｜入学式 → 樱井 → 生驹 → 白石 → 四班 HR

## 总结论

**整体：GREEN / YELLOW。无结构性 RED。**

真正风险不是“拍不出来”，而是**设计痕迹过密**：如果把现有各独立文档里的所有“观众以为套路要来、结果没来”都认真执行，八分钟入学式会显得导演持续在向观众眨眼；随后生驹、白石又连续获得完整人物小段，容易从“学校生活”滑向“人物卡发放”。

Treatment 层解决方向：**保留事件，减少导演显摆；保留人物差异，减少每班 / 每人都必须得到一个完整 beat。**

## S06｜入学式・第一学期始业式 / Flashback①樱井

### GREEN｜时长与现实执行

当前 13:00–21:00 的程序在目标时长内基本成立：开式 / 入学许可、校长式辞、Flashback①、新生代表、樱井欢迎词、来宾 / 祝电、校歌 / 闭式都可以被压进八分钟；Flashback①发生在校长声音继续覆盖时，不额外占一整场时间。

但 Treatment 不把每个秒点当硬时码；正式仪式需要真实的走台、鞠躬、坐下、掌声与余响，不能为了守表把身体时间剪掉。

### YELLOW 1｜“类型错觉”使用过量

当前独立文档里同时存在多次主动设计：入学许可“似乎找到新女主”、新生代表“重要角色出场语法”、樱井上台“似乎要发生事故”、校歌“似乎要变主演 MV”。单独都成立，连续使用则会让观众感到导演一直在展示“我知道你以为我要拍什么”。

### Treatment 解决方向

不删事件，只删“主动诱骗”的表演欲：

- 入学许可正常形成制度节拍，不专门多停一名普通新生来假装女主；
- 新生代表因为制度位置自然获得镜头，不额外套“重要角色出场语法”；
- 樱井上台不故意制造事故悬念，她只是熟练完成；
- 校歌可以很漂亮，但不把“像 MV / 拒绝 MV”作为导演笑话，摄影机只正常穿过不同年级与空间。

核心：

> **观众后来发现“原来刚才那个人不是主角”即可，不需要摄影机先提醒她自己正在被误导。**

### YELLOW 2｜校长式辞接近直接说出全剧感悟

当前式辞中的：

> `「伝統というものは、昔と同じことを繰り返すことではありません。」`
>
> `「受け継いだものを大切にしながら、その時々に必要なことを考え、次にここで学ぶ人たちへ渡していく。」`
>
> `「そうして学校は続いていくのだと思います。」`

本身像一篇合理的学校式辞，但从全剧角度看，已经非常接近直接说出第10集旧礼堂线与整部剧的核心感悟。

Treatment 暂不直接删改锁定台词，但把它标为后续对白 / 观众视角审查的重点 YELLOW：是否需要把这一段降回更普通的“学校有被继承下来的东西 / 你们也会慢慢学会使用这里”，把“传统不是重复过去”留给第10集由行动真正完成。

`「よく学んでください。」「そして、よく迷ってください。」` 可独立保留，因为它更像校长对学生的现实祝愿，不直接替整季总结主题。

### Flashback①｜GREEN

樱井的过去嵌在校长声音里，视觉上不是“人物按按钮进入回忆”。过去看的是形式：站位、纸张、翻页、鞠躬；回现在，她已经会了。

## S07｜后台 coda

### GREEN

> `「次、何分押しですか？」`
>
> 真夏：`「四分。」`
>
> `「四分。」`
>
> `「まだ戻せる。」`

成立。说完立即工作，不给“真夏好厉害”的反应镜头。

## S08｜生驹 / Flashback②

### GREEN / 轻 YELLOW

现实流线成立。需要压轻的是 Flashback② 的完整度。

Treatment 倾向压成：

> 普通同学看她又摸领结：`「曲がってないよ。」`
>
> 生驹：`「ほんと？」`

对方已经转去处理自己的事。

这样保留人物信息，但让 Flashback② 比 Flashback③ 更轻、更身体化。

## S09｜白石 / Flashback③

### GREEN

这段可以比生驹更完整，因为 `「顔じゃない？」` 是真正有角色差异和喜剧效率的落点。

Treatment 保护：现在时先是 3-B 已经正常运转；`「白石、髪。」` 后立刻继续原来的事；Flashback 中别人看白石是自然视线；笑点之后不追加第二个笑点；回现在立即重新进入传纸 / 少一张资料等班级事务。

## S08 → S09｜连续 Flashback 风险

### GREEN，但必须使用不同语法

- 樱井：校长声音覆盖过去，时间层嵌在仪式中；
- 生驹：极短、以手反复碰领结为主；
- 白石：完整一点的生活喜剧小场。

靠场景长度、声音结构、对白密度区分，而不是统一滤镜 / 音效。

## S10｜四个高三 HR 并行

### YELLOW｜命名角色密度过高

当前独立文件为四班都安排了命名角色 micro-beat，容易重新变成逐班发人物卡。

### Treatment 解决方向

**制度必须比角色更稳定。**

- 3-A / 3-B 主要承担纸张、人流、老师口吻与普通学生动作；命名角色可以在画面里，但不要求各自完成一个可记忆 beat；
- 3-C保留まあや `青は？`；
- 3-D保留飞鸟敲纸、`「裏。」`；
- 3-A文化祭梗与3-B三人纸张行为如影响节奏，优先降为背景或删除。

最终观看任务：

> **同一种制度同时进入四个班，然后学校在午休铃声里重新散开。**

# 第三批｜S11–S15｜午休 → 西野 → 飞鸟 × 南 → 桥本 → 案内撤收

## 总结论

**整体：GREEN / YELLOW。无结构性 RED。**

主要风险不是现实不可执行，而是日常场景被赋予过多“人物说明功能”或“主题回声功能”。

## S11｜午休 / 食堂 / 关系重新混流

### GREEN

HR结束后，四个班级结构暂时松开，学生按朋友、食堂、便当、别班门口等生活关系重新流动。松重窗口只打一套梗即可。

### Treatment 保护

- 除窗口梗外，不再建立第二个完整对话场；
- 松村去另一桌、高山 / まあや经过、别班门口找人等只作为关系存在的证据；
- 如果实际剪辑 3分多钟已经读完“关系重新混流”，允许本段比纸面分配更短，不为守时码强行填镜头。

## S12｜西野 / 绕路

### YELLOW｜`「人、少なかった。」` 把人物解释窄了

当前前半已经足够：

> `「そっちから来たの？」`
>
> `「うん。」`
>
> `「遠くない？」`
>
> `「ちょっと。」`

之后再说 `「人、少なかった。」` 会把绕路解释成避开人群，提前把西野收窄成“安静、怕人多的女生”。

### Treatment 解决方向

停在 `「ちょっと。」`。两人继续走；西野经过中庭 / 楼下视野时自然偏出去两步，看一眼没有剧情意义的日常，再跟回来；高山不问。

第一集只留下：

> **她会自己改变路线。**

## S13｜飞鸟 × 南 / 高三第一天照片

### GREEN

> 说不拍 → 没人逼 → 真要拍了 → 自己站起来 → 只站边缘

成立。关键保护：没人追着劝；南不拆穿；飞鸟不看成片；不说 `あとで送って`。

### 轻 YELLOW｜镜头重量

如果 60–90 秒已经成立，就结束；不为纸面 2分20秒强行拍满。

## S14｜桥本 / Flashback④ / 时间

### GREEN / 轻 YELLOW

核心成立：别人继续走，桥本多看一次表并短暂停下；过去也曾在校门外短暂停住，再看表进去。

### Treatment 保护

不要把“现在两秒 / 过去两秒”拍成可测量的形式对称，也不要追求完美 MATCH COMPOSITION。观众感觉到空间押韵即可。

## S15｜下午继续 / `案内は今日まで`

### YELLOW｜主题回声过于工整

撤箭头、归还袖标、胶带没撕干净全部成立。问题是普通案内係再次说：

> `「分かんなくなったら、近くの先輩に聞けばいいよ。」`

它几乎是在生活里验证樱井欢迎词同一句价值观。

### Treatment 解决方向

倾向只保留：

> 新生：`「これ、明日はないんですか？」`
>
> 案内係：`「うん。今日だけ。」`

最多：`「そっか。」`

然后旁边：`「テープ、そこ残ってる。」`，案内係回去继续收。

> **不说出来，学校反而更像真的学校。**

# 第四批｜S16–S20｜进路调查 → 放学释放 → 生田 → 学校 → 黑板

## 总结论

**整体：GREEN。**

这一批的大结构已经很强，尤其新版生田与最终黑板形成了非常干净的终盘。主要工作是继续把“漂亮设计”降级成自然发生的背景事实。

## S16｜第一回 進路希望調査

### GREEN

`「君ら、三年だぞ。」` 已经足够承担本集终盘唯一一次明确的“你们现在是高三”提醒。

不到一秒，现实声音和动作马上回来，这个节拍正确。

### Treatment 保护

- 四班继续以纸张、手、文件夹、普通学生为主；
- まあや真实问信息缺口可以保留；
- 不需要再给南、飞鸟、桥本、白石等命名角色逐个“如何面对进路表”的小反应；
- `未定` 是正常可填项，不拍成谁的人生危机；
- 武田不觉得自己说了金句。

> **本场只让未来第一次进入桌面，不让未来接管教室。**

## S17｜进路调查迅速输给今天 / 四班释放

### GREEN / 轻 YELLOW

“不同速度释放”是对的，但独立 ending 文件仍写了若干分班角色 micro-beat，并让摄影机跟生田从 3-B 走向音乐别馆。

这与当前最新设计略有偏差。

### Treatment 解决方向

- 不逐班展示主演放学去向；
- 普通学生承担大部分值日、部活、鞋柜、图书馆、别班找人等释放动作；
- 命名角色只在自然经过时存在；
- **不跟生田走进音乐别馆。**

更好的切法：

> 高三楼层放学声 / 柜门 / 椅子 / 脚步
>
> CUT
>
> 钢琴已经在响
>
> 摄影机进入音乐别馆

这样不是“现在轮到生田”，而是学校放学后很多生活已经同时开始，我们只是此刻走进这一间房。

## S18｜生田 / 音乐别馆 / Flashback⑤

### GREEN

新版在 60–75 秒内可拍：

1. 进入时她已经在演奏；
2. 乐谱、铅笔、标记已存在；
3. 声音 / 余响进入三年前；
4. 高一生田听脚步、门声并回应；
5. `「何弾いてたの？」` / `「……分かんないです。」`；
6. CUT 回现在，演奏没有停；
7. 最后和弦、踏板、余响；
8. 普通墙钟自然已经 17:00；
9. 敲门，下一时段学妹进入；
10. 生田熟练收好东西、复位、让出房间。

### 17:00 保护

- 不拍秒针最后一格；
- 不做 `17:00:00` 特写；
- 不让她再次看钟；
- 不让学妹赞叹她时间精准；
- 可以理解为最后余响 / 收尾动作跨过 17:00，而不是“最后一个音精确命中整点”。

> **时间没有给她造成麻烦，不等于她在展示超能力。**

学妹首先只是 17:00 本来就轮到这里的人，不承担“下一代”解释功能。

## S19｜学校重新成为整体 / 偶然齐线

### YELLOW｜母题可以留，但不应再作为一个独立 beat

“裙摆偶然齐线”是有价值的系列视觉母题：EP01 可以自然建立，EP02 才讨论制服 / 裙摆规则，EP12 跑起来时队形彻底散掉。

问题在当前写法把它单独端出来：

> 几名熟悉高三女生并排 → 裙摆齐线 → 留两三秒 → 普通学生穿过 → 队形散掉。

在生田之后、黑板之前，这已经有一点“导演知道自己正在制造回声”的味道。

### Treatment 解决方向

**不删母题，降级它。**

把“齐线”从一个 beat 降成一个画面事实：

- 摄影机回到整体放学流；
- 某个宽景 / 行进镜头中，几个高三学生恰好并排；
- 裙摆短暂显得整齐，但镜头不停、人物也不停；
- 下一秒自然被其他人流打散。

不要专门停两三秒等观众看懂。

> **它是 C 级视觉信息，不是终盘第二个句号。**

## S20｜黑板 / 明天还要来

### GREEN｜并建议进一步做减法

最终主体必须重新交回学校，而不是任何一个人物。

教室已经被日直 / 清扫当番恢复到明天可以继续使用的状态；调查表全部被学生带走，不留“遗物”。

黑板擦干净。

**只留下两条通知：**

> `進路希望調査　来週（金）まで`
>
> `明日　体育館シューズ`

没有晨读、小测、值日名字、古文页码等额外信息。

### Treatment 保护

- 不推近 `進路希望調査`；
- 两条信息同等级书写，不给进路一行特殊框线 / 字体 / 构图重量；
- 不在桌上再放进路表；
- 不用夕阳、樱花、煽情钢琴解释离别；
- 不需要画外 `「待ってー！」` 再给一个可爱的尾音；
- 环境声可以只剩很远、很普通的一点放学后学校声音，甚至更少；
- 镜头停留只需要足够观众读到两行，然后 CUT TO BLACK。

两条信息并排已经完成全部结尾工作：

> 一条开始要求她们考虑离开学校之后。
>
> 一条只提醒她们明天别忘了带体育鞋。

**不要再补第三句话。**

# STEP 7–8 全集阶段结论（当前）

## 结构判断

EP01 当前没有需要推翻大结构的 RED。

真正的问题集中在一种共同倾向：

> **很多单独很聪明、很准确的设计叠在一起以后，会让观众看见“编剧在设计”。**

因此 Treatment 的总修正不是加信息，而是持续降级：

- 类型错觉从“导演手法”降成观众自然误判；
- 人物卡从完整小场降成一个动作 / 一句有效对白；
- 主题回声从重复台词降成生活事实；
- 视觉母题从专门镜头降成构图中的偶然；
- 结尾从“还有一个漂亮尾音”降成两条干净通知。
