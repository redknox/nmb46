## S01–S02｜正门 → 鞋柜 → 大厅

### GREEN

- 普通新生家庭在校门附近拍照成立；
- 白石通过“别人本来就认识她”进入关系网，不需要专属登场；
- 新生看临时指示、高三凭身体记忆走路的差异可通过同一画面完成；
- 鞋柜 / 上履き构成自然空间转换；
- 大厅案内系统在学生到达时已经运转，片名压在工作中的空间上。

### Treatment 保护

- 校门拍照位置只是自然可停留、且不阻塞主通行线的位置，不拍成主题乐园式 Photo Spot；
- 白石第一次出现不追加正脸定场、慢镜、BGM变化；
- 镜头先属于学校与人流，再属于被观众认出的角色。

## S03–S04｜1-A去旧礼堂 / 两条进入方式

### 原 YELLOW

旧文本若不补执行细节，容易让人误以为：

> 1-A在教室集合 → 生驹带班去礼堂 → 使用轮椅新生的家长也跟着班级一路同行 → 在入口发现坡道并提问。

这会产生“为了让家长看到问题而跟拍孩子”的编剧便利感。

### 解决方案｜锁定为 Treatment 级执行

**新生流与保护者流分开。**

- 新生先完成班级集合，由生驹与普通案内係带 1-A 前往旧礼堂；
- 保护者按另一套案内路线直接前往礼堂 / 保护者席；
- 两股人流在旧礼堂入口附近短暂交汇；
- 使用轮椅的新生继续跟着自己的班，不因“问题场景”停下；
- 她的保护者已经在入口附近，因此自然看见：大多数新生走三级石阶，女儿沿学校事前设置的稳定临时坡道进入；
- 保护者只向现场工作人员轻问：`「これは、普段も設置されているんですか？」`；
- 工作人员如实回答活动时会提前设置；
- 不争执，不形成投诉戏，不让学生本人承担解释功能。

### 观看效果

同一入口短暂出现三种现实流线：

> 新生流 → 新生席
>
> 保护者流 → 保护者席
>
> 使用轮椅的新生 → 同一礼堂，但通过另一条进入路径

这不是“议题构图”，只是学校当天真实运行的一个交叉点。

### GREEN

临时 / 模块化坡道继续成立，但必须：

- 稳定；
- 防滑；
- 坡度与边缘安全在制作设计中可信；
- 不是临时拿木板应急；
- 画面能看出它是额外设置，而非建筑原生路径。

结构含义仍保持：

> 今天准备得很好；长期问题恰恰是“正常使用”依赖额外准备。

## S05｜礼堂切换到典礼状态

### GREEN

这三分钟不是另一场冲突，而是一次持续收束：

> 通行空间 → 座席空间 → 仪式空间

### Treatment 保护

不能按文档逻辑标题切成五个独立小场。

建议通过动作与声音连续连接：

1. 前景新生落座，背景案内係退出；
2. 跟一名交还袖标 / 夹板的普通案内係进入后台；
3. 后台工作自然带到真夏的进度表；
4. 一份资料经过，把摄影机带到舞台侧樱井；
5. 樱井把后台事项交出，只剩欢迎词；
6. 礼堂内最后的小动作逐渐减少；
7. 司会开口，正式进入典礼。

核心要求：

> **文件里有多个逻辑步骤，画面只能感觉是一口气。**
