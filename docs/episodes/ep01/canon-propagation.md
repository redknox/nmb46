## 一、旧礼堂线｜EP01 → EP10 / EP11 / EP12

### EP01 已发生的事实

- 学校事前知道轮椅新生的使用需求；
- 旧礼堂入口提前安装稳定模块坡道；
- 新生当天正常进入；
- 没有现场抬轮椅、没有最后一人入场、没有延迟开式；
- 生驹只看到同一栋楼存在两种进入方式；
- 保护者在自己的入场流线上轻问“平时是否常设”；
- 工作人员回答活动时会提前设置；
- 校歌让观众同时感到旧礼堂真实、漂亮、值得被爱。

### EP10 必须承接

不能写成：

> EP01学校犯错 → 家长投诉 → EP10整改。

必须是：

> 学校长期用专业临时措施维持使用
>
> 保护者的正式意见进入学校记录
>
> 消防 / 疏散 / 老化 / 无障碍 / 现代使用需求继续累积
>
> EP10专业评估确认“还能想办法用”不等于“适合继续承担大型公共礼堂功能”。

樱井不能因EP01事故产生罪疚驱动；她EP10的核心仍是形成学生会立场并承担选择。

### EP11 / EP12

- 新礼堂不会在一期生毕业前建成；
- EP11毕业典礼在现代体育馆；
- 轮椅新生自然使用现代无障碍空间，不拍成“问题已经解决”；
- EP12旧礼堂仍处于封闭 / 拆解 / 材料编号保存 / 施工准备等现实阶段；
- 不出现已经建好的新礼堂作为第一季大团圆回收。

世界圣经 `docs/world/old-auditorium.md` 已同步到以上事实。

## 二、生田线｜EP01 → EP04 / EP05 / EP12

### EP01 已发生的事实

现在时：

- 摄影机进入时她已经在演奏；
- 乐谱、铅笔、密集标记已经存在；
- 她现在明显更成熟、更强、更专业；
- 时间没有给她造成现实麻烦；
- 17:00自然完成练习室交接；
- 她没有看钟确认，也没有展示“精确到秒”的能力。

过去：

- 同一练习室；
- 没有谱；
- 先按一个音；
- 听脚步、门声与房间余响；
- 自然回应；
- `你刚才弹的是什么？`
- `……不知道。`

### 后续解释边界

EP01 **没有** 宣判：

> 过去自由 = 好；现在技术 = 坏。

EP04以后才能逐渐发现：她的天赋、技巧、准确与完成度也可能形成一道墙，让她越来越习惯先把音乐“做对”。

因此EP04不是修复一个EP01已经明说的创伤，而是让观众重新理解EP01看过的优秀。

### EP05

文化祭正式演出仍可展示：

- 她的专业能力是真实优势；
- 自由回应和正式完成并不互相否定；
- 她可以让自由和技巧重新连接。

### EP12

最终自由演奏 callback 不能写成“终于抛弃技术”。

正确方向：

> 她仍然拥有三年来的技巧，但再次允许音乐从听见、回应和不知道会去哪里开始。

并且不需要别人评价她弹得好不好。

## 三、樱井线｜EP01 → EP10

### EP01 已发生的事实

- 樱井很会完成既有学生会长位置；
- 三年前她认真观察前任怎样站、拿纸、翻页、停顿、鞠躬；
- 现在她已经把这些形式学得非常熟；
- 她的欢迎词相信：不知道就问旁边的人；旁边的人也不知道，就一起去找知道的人；
- EP01不把这种倾听 / 连接拍成缺陷。

### EP10 承接

真正的边界是：

> 当所有人都知道、所有人都有道理，仍然必须形成一个立场。

她不是从“不会领导”成长成“会领导”，而是从：

> 很会听、很会协调、很会把位置做正确

进入：

> 听完以后形成自己的判断，并接受有人不满意。

## 四、生驹线｜EP01前置锁

EP01 已建立：

- 她主动承担班级 / 新生案内这种集体层面的琐碎职责；
- 她很快认得“我这样是不是已经可以了”的不安；
- 三年前她自己就曾反复确认领结、袖口和坐姿；
- 她珍惜制服 / 学校归属，但第一集不命名“归属焦虑”。

后续不能把她改写成风纪委员式“检查别人是否符合学校规范”。

她帮助学妹的基础是：

> **我知道刚进来时会担心自己是不是哪里做错了。**

不是：

> **我代表学校判断你哪里做错了。**

---

## 五、白石线｜EP01前置锁

EP01 已建立：

- 她就是学校里明显会被多看的人；
- 同级 / 后辈本来就认识她；
- 三年前她曾把视线误解成“是不是我哪里穿错了”；
- 班里同学已经和她生活到可以一句 `白石，头发。` 直接替她整理；
- `脸吧？` 是对过去错误因果的朴素拆解。

后续“乃木坂之颜”压力不能回写成：她从一开始就享受被仰望或高度自恋。

她后来的责任压力来自“被看见以后要不要永远维持正确”，而不是第一集的虚荣。

---

## 六、桥本线｜EP01 → EP09

EP01 只建立：

- 她会比别人多确认一次具体时间；
- 她允许自己短暂停下来，但知道什么时候继续走；
- 三年前在校门外看里面；现在在学校里面看门外。

不在EP01解释家庭、成本、通勤与现实责任。

EP09以后可以让观众发现：

> 这不是冷淡的形式习惯，而是她长期用来管理现实的方法。

## 七、西野 / 飞鸟 / 松村等中段人物笔触

### 西野

EP01没有“人少所以绕路”。

只建立：她未必按最快路线走，会自己偏出去看看，再回来。

后续不能把这个笔触简化成社恐 / 怕人多。

### 飞鸟

EP01固定：

> 说不要 → 没人逼 → 自己走进合照 → 站边缘。

后续“嘴比身体后退一步”从这里开始，不需要每集重复一次完整公式。

### 松村

EP01四班HR中，她先翻到文化祭只作为背景可读动作，不是文化祭主线启动。

## 八、学校先后辈传统

EP01 已明确：

> 临时案内箭头只存在今天；以后迷路可以问附近学姐；帮助刚入学的学妹属于学姐应承担的正常职责。

这不是樱井个人价值观，也不是某个温柔角色的特殊善意，而是学校长期形成的先后辈生活规则。

后续使用时应保持：

- 普通学生也会这样做；
- 不把每次帮助都拍成主角高光；
- 学妹逐渐熟悉学校以后，不再需要同等程度的案内。

## 九、视觉 callback｜裙摆

EP01：

> 放学宽景里，几名高三学生因为三年身体习惯短暂并排，裙摆一瞬间显得整齐；普通人流马上打散。

这是C级事实。

EP02：裙摆 / 制服规则可以第一次被明确讨论。

EP12：最终跑步时身体自然破坏整齐队形。

不能把EP01齐线拍成“我们最后一年”的主题镜头，否则后续空间被提前消费。
