## 2. SNS 跑测共识

不见面不等于不沟通。主创补充：大部分人会自然在班级群发布录取与去向消息，进路通常不是秘密；考试前，朋友与部分同班同学已聊过志愿、专业和日程。录取消息往往是对已有计划的更新，不是第一次揭晓学校。各人的知情范围仍不同，不能推定全班知道全部併愿与私人顾虑。

私聊、小圈子与班级群可以并行，谁先知道由当天情境决定，不统一规定先私聊、再群发。持续通信的人可以知道对方怎样经历考试，不能预设数字沟通必然浅于见面。班级群正常报喜与正片不逐人拍摄报喜大会可以同时成立。飞鸟对未定之事少说是个人习惯，不推广为全体礼仪，合格后也不必一直保密。

每次消息至少检查：此前谁知道她在考；是谁先开口；对方此刻在备考、等待还是已经结束；这条消息允许传到哪里。另分清考试结束、合格、决定入学、手续办妥、有空见面，不能相互替代。

- 亲近且此前参与过备考话题的人，可以直接问“怎么样”“看了吗”；不让所有高中生使用咨询师式话术。
- 说半句不自动等于体贴。共同背景让省略成立；对方不接话时是否停止追问，比句尾是否含蓄更重要。
- 已读、晚回、短句、贴图都不能单独证明冷淡、落榜或关系变化；不设计统一回复时限。
- 提前合格的人可以快乐，仍备考的人可以真心庆祝。没有“所有人考完之前谁都不能出去玩”的共同义务。
- 私聊得知不等于可转发；推测报考不等于知道录取。已公开的好消息也不必由某人统一统计广播。
- 记得朋友的日期可以表现关心，但不要求每个人记住所有人的放榜时刻。
- 既有17名主角不因被摄影机选择，就自动组成固定社交团体。

## 8. SNS 研究依据｜参考，非统一礼法

- [学生关于提前合格后相处的经验](https://labo.dormy-ac.com/senpai34/)：存在仍备考者与先合格朋友共同高兴的经验；不把等待所有人考完才能娱乐的个体选择提升为友谊义务。
