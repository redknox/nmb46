4. 白石回到座席旁，桥本站起来，两人一边谈稿中提起的校园小事，一边走回教室取各自的包，随后离校。具体回忆内容随答辞另定，不为走到校门另起一场。白石与桥本的短留与之后桥本赴飞鸟的约，是两件各自成立的事。

## S17a｜飞鸟与桥本在站前坐一会儿

3月2日预行放学后，站前普通咖啡馆。接S15a已经交代的邀约。桥本听完白石试读、两人回班取包离校后，单独来赴飞鸟的约。两杯饮料足够，让两个人有一段能坐着慢慢讲话的时间。

1. 飞鸟直接问桥本在札幌的感受：有过哪一刻，觉得自己可能会在这里过日子。她好奇的是桥本在那里的亲身经历，不催问成绩。桥本讲一件考试之外的小事，谈到自己还没收到结果，却已经偶尔想过日常会怎么过。允许桥本讲开、自己也笑起来。
2. 飞鸟接着说到自己，亲口告诉桥本已经确定去立教，再聊起通学、课程和在那里会认识的人。真夏也在让她高兴，但未来的日常仍有许多想不出来。录取消息随聊天自然带出，不另设报喜场，也不默认3-B的桥本看过3-D班群。桥本听她说完，再顺着问有没有去过校园，有自己的看法，不评价飞鸟开口的动机，也不替她解决。
3. 起初想问的札幌已经聊完，她们还坐着。话题从某个细节自然岔开，接出与大学无关的闲话；两人都愿意继续听、继续讲。后来照常散，第二天仍随各自班级参加典礼。

关系基调：飞鸟在桥本面前有不掩藏动机的安心，也可以自然开玩笑；桥本有自己的好奇与欢快，不只承担倾听或安慰。场面既能有笑声，也能自在地说未想明白的事情。具体札幌轶事、饮料和对白留后续；不增设白石到场、北大结果或私人告别，也不改两人的关系等级。

## S19｜开式与逐人授证

3月3日上午，体育馆。入场掌声落下，江口简短开场，接国歌。学生坐下，各班担任按既定顺序唱名。

4. 最后一位学生回座，进入天海式辞。试听和走位已由S17交代，这里多停留在等候、听见名字和手里接到证书的时刻。
