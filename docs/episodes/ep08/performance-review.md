## 3. 空间、轴线与视线

### S01／S03／S06｜教室与日常移动

- 固定座位按高三座位锁。S01 报名借用 R3/C4，飞鸟坐 R4/C4；万理华已离开自己的座位，站到报名桌旁向后递笔。至少在场内关系中看清这段距离，不用特写掩盖不成立的跨桌动作。
- S03 午饭是临时聚桌，不把南与深川拍成固定邻座。飞鸟制服折返使用室外鞋和正鞄，沿校内第五区步行；不剪出她在未控制公路上试跑的印象。
- S06 飞鸟在开放校内第四区练习。南抱ビブス经过，有自己的方向与目的；问完继续走，不停在远处观察她，不增加“我替你保密”的表情。

### S02／S04／S05／S07｜交接方法要能比较

第一次示范建立来棒方向、中継線、有效区域与退出方向。后续失败或成功尽量保留可比较的侧向空间关系，不用只有手部特写的剪法掩盖两人速度差。

S02B 深川与南停下、若月展开时变慢，是不同错误。S04 飞鸟确实等到较近才带出，随后仍被迫减速；否则她说“今天已经等了”会失去画面证据。S05 接手侧与起步时机靠两人位置调整成立，不改变为盲接或口令启动。

20 米是有效交接区域，不是两人可以相隔20米伸手传递。取下、展开、递出与接稳要在可执行的距离内连续发生；具体 mark 留给实际场地排练。安全退出可与对白、背景工作同时呈现，不把每次退出都拍成完整教学段。

### S08—S11｜分流与追赶

五块引导牌按地点分组，各团颜色混入同一地点队列；地点、年级与团别是不同层级。S09 翻轮次牌表示剪辑省略的时间经过，不表示四团同时换年级。

S10 白石是 B 团第一棒的完成者，出现在深川等待的第二中継所退出侧；C 接完才轮到 D。她的短镜头不改变深川面向万理华来路的视线。

S11 在转角换方向前后保留路线建立，避免反打把 C 跑者拍成迎面跑来。两人相对顺序依次为：C 在前→并肩→飞鸟领先→再并肩→C 在前；不靠不同焦段的孤立特写虚构缩距。超越沿既定宽侧，不给 C 跑者阻挡、回头挑衅等额外动作。

### S12｜离开跑线，再聚齐

交襷至恢复区沿用约40—60米单向退出路线；末棒终点在同一运动场侧区域。镜头可省略部分行走，但须让人知道飞鸟已经离开比赛动线，不能剪成她交完就原地堵住赛道哭。

返回次序保持万理华→深川→若月→南。若月带襷回来放筐，南从指定安全返回路线抵达，不逆穿仍在使用的第四区。三次轻微时间省略与持续现场声承接约五六分钟世界时间，不要求五人实时在同一分钟到齐。

恢复区须容纳五人自然坐下、物品筐、通行与教师工作位置；尚未指定真实场地，不能宣称座椅尺度与返回距离已实测。取景后按已定关系安排，不为方便机位改变回来顺序。

## 4. 表演与重复动作

| 对象／场面 | 保留的动作任务 | 避免的额外表演 |
|---|---|---|
| 飞鸟报名与练习 | 看完说明、观察慢在哪里、提出换序、自己准备路线 | 每次嘴硬都用同一套翻白眼或冷笑；提前演成知道自己将成长 |
| 若月 S04—S05 | 承认没展开、检查布环、听飞鸟指出位置，再尝试 | 生气退出、训斥飞鸟、以道歉独自承担全部错误 |
| 深川的疲劳与建议 | 自己喘、自己不想继续跑、可以走着练 | 每次开口都先看两人的脸，演成全天调解员 |
| 南 | 乐意报名、主动分练、认真跑、看到哭泣便问 | 将快乐演成全程无负荷，把未哭演成不懂别人 |
| 万理华 | 看路线、记录、递笔、参加接口、在恢复区陪着 | 扩成队长指挥或给所有人确认表情 |
| 家庭群 | 消息可读，父兄接话略快；飞鸟看完扣手机就练 | 家人真人或画外台词、飞鸟对镜头的喜剧反应、水和毛巾的温情认证 |
| 江口 | 示范、看记录、基础指导、赛后确认身体状态 | 替全团做战术、在高潮讲人生道理、把“不知道”抖成包袱 |
| S12 两人哭泣 | 飞鸟想收住又哭；深川陪坐后自己的眼泪出现 | 按台词同步落泪、逐项完成擦脸吸鼻、等演员彻底平复才切黑 |

点头、“嗯”、喝水、看图可以与别的动作同时发生，不一律加半拍反应镜头。保留真正需要的停顿：若月被再次指出已知失误、飞鸟跑完身体还没平稳、深川陪着坐了一会儿。它们的时间原因不同。

## 5. 声音与形式的连续变化

| 段落 | 声音关系 |
|---|---|
| 前半段练习 | 现场脚步、部活、交接呼名和普通事务为主。不把每次练习提前铺成 S10 同强度的热血片段 |
| S03／S04 气口 | 已定四至五秒环境声与空镜保留，字幕可叠画面；不额外延长成音乐过场 |
| S06 家庭群 | 消息提示与远处电视声即可承接居家氛围。扣手机后继续训练，不用温柔音乐解释水和毛巾 |
| S08—S09 放送 | S08 计分板与广播留可读听的时间；S09 校外消息明确经过无线电。广播被欢呼或交接打断，但关键信息可辨 |
| S10 | 音乐从万理华跑动逐渐进入，现场声仍在；南缩距时鼓点抬起，交接可极短重放 |
| S11 追过至失速 | 领先时旋律充分展开；身体掉速后音乐继续，喘息渐渐盖过。心跳为主观声音，不配合晕眩黑视等新增医疗情节 |
| S11 交襷以后 | 交接保持常速，音乐在完成后退去，喘息、鞋底和远处喊声留住空间 |
| S12 | B/A 冲线与胜利存在于远处广播及欢呼，摄影机不转去；器具车、记录席通知等表明活动继续。不给江口“不知道”或深川第一滴泪加主题性音乐重音 |

S10 的过曝保留亮度质感，不淹没号码布、襷和交接手部。重放只重复同一瞬间；不能按银幕重复时长推算真实跑程。以上沿用本集特许形式，不照搬 EP09 的全面克制手法。
