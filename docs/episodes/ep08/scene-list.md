# 第一段｜结成与第一次失败｜约 12 分钟

## S01｜五个名字进入同一张表

**时间 / 空间：**D-20，放学前，3-D 教室。

体育委员把压轴接力的五区、兼项与练习条件放进普通班级程序。五个人的同意在同一段行动中完成，不拆成五场报名戏：南直接觉得可以；若月先看时间与责任；深川确认身体和安排；万理华先看路线；飞鸟把愿意包装成“还缺人的话”。

其他班的项目协调只通过门外经过的体育委员、同时分发的表格和走廊声音存在。S01 不为了证明全校正在准备而切去樱井、松村或其他班级。

**场尾：**五个名字被写在同一张正式表格上。没有命运感，只有一项即将开始占用她们放学时间的学校任务。

**连续功能：**完成事件启动、本人同意与五种语气；直接把观众送进第一次身体实践。

## S02｜每个人都会跑，但接不起来

**时间 / 空间：**D-17 至 D-14，体育课场地进入第一次放学后校内合练。

开头只保留江口说明襷、有效交接区、安全退出和基础热身的必要动作。体育课中的短跑 / 节奏记录证明五个人都能跑完全区；用时间省略进入第一次正式合练。

合练是本集第一场完整群戏。问题连续具体出现：来棒者提前减速、接棒者启动过早或过晚、喊声撞在一起、接襷后整理时挡住跑线。失败来自五个人都在修正自己认为的问题，不把任何人拍成笨拙笑料。

若月试图固定等待位和提示；万理华坚持真实到达速度每天不同；南必须先跑一次才知道；深川不断调整自己的部分；飞鸟准确发现棒次与递出端的问题，却把意见说成旁观式毒舌。

若月不追问态度，只追问：既然看见了，准备让大家怎么改。飞鸟暂时没有可供别人使用的答案。

**场尾：**五个人仍留下来收拾标志物和襷，没有人退出；但第一次练习结束时，她们连一次稳定连续交接都没有完成。

**连续功能：**把喜剧、人物差异与第一段转折放在同一场；不另开“队内争吵”场。

# 第二段｜身体、摩擦与练成｜约 21 分钟

## S03｜路线进入身体

**时间 / 空间：**D-9，放学后，正式路线踏勘。

江口与体育科教师带队步行确认坡度、弯道、路口、中继点和退出方向，只处理安全与负荷。五个人第一次发现纸上的 250—380 米不是五段相似直线。

万理华用身体和地形说明固定起跑点为什么不够；若月听得懂问题，却仍需要可重复的共同提示。两个人的判断都成立。

集体结束后，飞鸟穿校服独自折回第 4 区，再走一遍转弯、距离和最后中继点。她不跑，也不发表决心；摄影机只看见她处理一件其他人以为已经结束的事。

**连续功能：**改变训练输入，并第一次让观众单独看到飞鸟的投入超过语言。

## S04｜每个人更努力，还是接不起来

**时间 / 空间：**D-7，放学后，教师陪同的正式分区试走。

五个人分别跑真实区间，再尝试连续交接。个人完成度都比第一次高，但真实坡度、疲劳和不同到达速度把旧问题重新放大。

若月增加说明仍不能预写每一种速度；万理华能调整却无法让别人直接复制；南身体学会得快但重复值不稳定；深川继续吸收误差，自己的区间反而被拖乱；飞鸟批评仍准，却没有把判断交给团队。

教师只确认完成状态、恢复与安全，不评价谁更适合哪一棒，也不介入她们的方法分歧。

**场尾：**她们第一次明确知道：“每个人各自再认真一点”不会自动解决接力。

**连续功能：**中段低点；与 S02 的差别不是再演一次失败，而是证明个人进步仍不足以形成共同方法。

## S05｜把感觉翻译成别人能用的动作

**时间 / 空间：**D-7，试走后，运动场侧恢复区及相邻练习区。

五个人在疲劳状态下整理刚才的问题。深川停止无限换位和吸收误差，要求确定一种所有人下一次都能使用的方法。

若月再次要求飞鸟把看见的问题说具体。飞鸟不承认自己负责，只把递出前减速、等待位置、起动提示和棒次适配说清；“递出端不稳定的人放最后”使若月第 5 区配置成立。万理华把身体感觉翻译成可观察线索；南实际走 / 跑一次到达过程，让提示重新校准。

相邻区域短暂经过 C 团：真夏的简单约定有效；まあ亚没有按术语行动，却根据真实来速接对；高山把错位说成笑话，让队伍愿意立刻再来。这个片段不触发 D 团顿悟，也不离开当前训练空间。

**场尾：**D 团不是统一意见，而是第一次拥有一组可以一起试的动作。

**连续功能：**完成方法互译；不靠和解大会或成年人答案。

## S06｜飞鸟把训练带回没有观众的地方

**时间 / 空间：**D-7 至 D-5，校内第 4 区与飞鸟家，短段 sequence。

飞鸟在获准开放的校内时段换运动服重跑自己的区间。南偶然遇见，只接受“回来拿东西”一类蹩脚解释；她可以替飞鸟看一次时间或陪一小段，不拆穿，也不谈心。

夜里，飞鸟在家庭群提前说房间可能有奇怪声音，让父亲和哥哥不要进来。搞怪回复之后，家人真的不打扰。她完成短时腿部与核心训练；第二天的酸痛以一个生活动作留下，不另建“努力被大家发现”的场面。

**连续功能：**把暗线从观察升级为实际投入；两处空间合计仍是短段，不剪成英雄训练 MV。

## S07｜她们真的练成了

**时间 / 空间：**D-6 至 D-2，跨年级接口与校内模拟路线，练习收束 sequence。

开头用极短接口段确认：万理华与 2-D 最后一棒练习年级边界；其他色团边界跑者也在自己的标记位工作。场面只说明十二班不必全部集合，接口仍被真实练过。

D-4 进入本 sequence 的主体。四团分组 / 错峰，不记录正式成绩。D 团按锁定跑序第一次顺畅完成内部四次交接：若月的约定仍在，万理华的线索能够被别人读懂，南通过重复获得稳定，深川不再承担全部误差，飞鸟会在问题发生前给出信息。

五个人跑完后停在同一空间喘气。她们确认襷确实到达若月手中，没有庆祝夺冠，也没有人想哭。飞鸟最先用一句普通话降低重要性，却没有提前离开。

D-2 只留南与飞鸟一次干净交接。它不是新的训练场，而是把身体记忆直接送往本番。

**场尾：**观众有充分理由相信，第三段只需兑现她们已经练成的 happy ending。

**连续功能：**完成第二段假胜利，并与结尾“同样五个人、同样喘气、却再也收不住”建立回声。

# 第三段｜本番、完成与哭泣｜约 17 分钟

## S08｜这一天已经过去了大半

**时间 / 空间：**D-Day 早晨开幕式台前，硬切至 14:10 团席 / 检录区。

早晨只保留天海校长开幕致辞结尾约 20 秒。她完成校长礼仪职责，画面不借她巡视主角或布置比赛。

硬切到下午：灰尘、汗湿的鉢巻、空水瓶、毛巾、沙哑声音和更新中的成绩板证明上午已经真实发生。D 团在总分上已无缘冠军，这个事实留在成绩板与现场状态，不由人物讨论。

五人完成第二次健康确认、整理鞋带和襷，被分别送往五个中继点。江口、教师、学生工作人员与普通跑者都在执行岗位；其余主要人物只在 D 团移动经过时短暂存在。

**场尾：**五个人从最后一次共享空间中分开，进入无法再互相确认的五个位置。

**连续功能：**用最小篇幅建立完整体育祭日和赛事规模，不恢复全景式项目展示。

## S09｜前十棒留下真实差距

**时间 / 空间：**14:30 后，各中继点、团席与放送席的压缩 sequence。

高一、高二两轮不逐棒报道。少量起跑、中继、颜色顺位、团席反应和广播建立十棒时间经过；各团差距真实累积，不为高三清零。

放送席按准备稿说：“对于高三的学姐们来说，这也是最后一次体育祭——”跑者正在看路线、确认鞋带、襷和来棒方向，无人回应；后半句被检录或现场呼喊部分盖住。

**场尾：**2-D 最后一棒进入视线，万理华开始根据真实来速移动。

**连续功能：**建立高三继承的局面与“最后一次”的背景潜流，不在主角上场前拍完另一场比赛。

## S10｜前三棒：练习没有骗人

**时间 / 空间：**高三第 1—3 区，运动场侧接口、校外路段与正门。

万理华接住 2-D 交来的襷与前两轮差距，在接口和转弯中按现场找到路线；深川用稳定配速守住位置，不试图一棒偿还全部差距；南在缓坡段按自己的节奏跑，并在接近正门时寻找飞鸟。

其他团只通过 D 团必须辨认的对手与顺位进入。真夏 / まあ亚的方法验证、白石认真而不漂亮的普通区间，都必须寄生在既有交接视线或同一段路线里，不另开比赛场。

南与飞鸟完成一次真正干净的交接。此前所有练习在本番获得明确回报。

**场尾：**飞鸟接襷时，前方有一名普通学生领先约 5—10 米。

**连续功能：**证明团队问题已经解决，把剩余悬念从“会不会交接”转移到飞鸟本人。

## S11｜她只是突然非常想超过那个人

**时间 / 空间：**高三第 4 区，正门进入校园，经主轴与校内路线至运动场侧。

中途超越不计分，D 团也不再争夺总冠军。飞鸟看见前面的人，没有积分计算，也没有战术提示；她只是突然非常想超过那个人。

她以近似百米冲刺的主观用力跑掉前半段，追近并完成反超。昭和 / 平成青春片形式可以在这里逐步接管：音乐、慢动作、呼吸、心跳、正反打与适度重放共同制造“经典回报正在发生”的相信。

现实身体逐渐耗尽形式承诺。呼吸先乱，抬腿、步幅和摆臂依次衰减；前半段抢来的距离被一点点拿回，她在最后约 100 米被重新超过。

她仍然保持清醒、跑线和方向，在有效区内把襷完整交给若月。

**连续功能：**完成飞鸟的欲望、反超、配速崩塌与无胜负回报；不把对手拍成反派或胜者主角。

## S12｜完成以后，没有下一件事可做

**时间 / 空间：**高三第 5 区、退出通道与运动场侧恢复区，相邻空间连续行动。

若月接襷进入最后 250 米。她不替飞鸟夺回英雄回报，只把五个人已经完成的东西带到终点；精确名次不在本阶段锁定，但 D 团不获得接力第一。

飞鸟沿退出通道离开比赛通道。江口只做本职判断：她清醒、能回应，没有医疗急症。远处若月完成冲线，广播继续工作，比赛世界没有围着飞鸟停下。

飞鸟已经交完襷，不能补跑，也没有下一项可以修正。此前藏在练习、借口和身体里的投入失去遮挡。她慢慢举起胳膊，大哭着问为什么要跑；江口只能诚实回答“不知道”。

万理华、深川、南与完成冷却后的若月在数分钟内陆续进入恢复区，不瞬间传送。南最直接被感染；万理华不替它命名；深川递毛巾时自己也哭；若月确认该完成的都完成以后，失去下一项可执行的事。

飞鸟问她们哭什么。南说“不知道……就是很想哭”，大家哭得更凶。

远处仍在报告名次和准备闭幕流程。本集不去领奖、不发精神奖、不补全班拥抱，也不让其他主要人物赶来见证。

**场尾：**五个认真完成、没有得到胜负回报、也说不清为什么要哭的女孩子。CUT。

**连续功能：**把终点、医疗常识、飞鸟公开失守与集体哭泣放在同一相邻空间链中，不追加第二结尾。

## STEP5 当前审视点

1. S02 是否能在约 9 分钟内同时承担基础规则、第一次失败与飞鸟—若月碰撞，而不显得像两场硬拼；
2. S05 的 C 团短对照是否确实能寄生在相邻练习空间，不产生荧光笔式切线；
3. S06 校内偷练与家庭训练是否应作为同一短 sequence，还是把家庭片段吸收进前后转场；
4. S07 三个日期的收束 sequence 是否仍保持清楚，不成为训练 montage 过量；
5. S09 前十棒压缩后，观众能否清楚理解万理华接的是高二留下的襷与差距；
6. S12 需要在 Scene List 压力测试中继续核对四人返回恢复区的先后、冷却时间与哭泣扩散节奏。
