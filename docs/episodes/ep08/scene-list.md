# 第一段｜结成与第一次失败｜约 12 分钟

## S01｜五个名字进入同一张表

**时间 / 空间：**D-20，放学前，3-D 教室。

班主任先在短 SHR 中正式说明压轴接力的五区、兼项、本人同意与报名期限，随后由一名普通 3-D 体育委员接手希望调查、缺额协调和表格回收。五个人的同意在同一段班级程序中完成，不拆成五场报名戏：南直接觉得可以；若月先看时间与责任；深川确认身体和安排；万理华从附件中抽出路线图；飞鸟把愿意包装成“还缺人的话”，同时吐槽这种事最后总会变成“认真过头的人替所有人收拾”。

其他班的项目协调只通过门外经过的体育委员、同时分发的表格和走廊声音存在。S01 不为了证明全校正在准备而切去樱井、松村或其他班级。

**场尾：**五个名字被写在同一张正式表格上。没有命运感，只有一项即将开始占用她们放学时间的学校任务。

**连续功能：**完成事件启动、本人同意与五种语气；直接把观众送进第一次身体实践。

## S02｜每个人都会跑，但接不起来

**时间 / 空间：**D-17 至 D-14，体育课场地进入第一次放学后校内合练。

开头给江口约两分钟完整而克制的职业说明。他自己佩好襷，借地面标志与锥桶示范取下、递出、接过和重新佩戴；说明有效交接区、来棒者不要提前刹停、接棒者必须按真实来速启动，以及交接完成后立即沿标示方向退出跑线。示范只校正距离、路线和动作，不以触碰学生身体制造笑料；先全员步行走一遍，再进入慢跑和接近真实来速的分级交接练习。

他同时明确负荷与停止条件：不安排反复全力跑完整区间；疼痛、眩晕、恶心或异常疲劳必须停下报告，学校保留替补程序。说明以“想赢可以，受伤不行”结束——沿用 EP07 中他说过的话，但这一次由完整、可靠的教师行动证明它不是一句套话。

五个人随后各完成一次约 300 米的控制跑，教师按每 100 米记录分段，不公开排成速度榜，也不重新淘汰已经确认的正式跑者。江口指出启动、后程稳定、疲劳后动作和前后段速度差等身体事实；看着飞鸟明显前快后慢的分段，只提醒“前半程压住，给后半程留一点”。教师负责教授标准技术、纠正危险或无效动作并提供客观记录，但不替五个人决定最终棒次、专属提示或彼此怎样适配。

用时间省略进入 D-14 第一次正式五人合练。

合练是本集第一场完整群戏。问题连续具体出现：南听见来棒者叫名便过早起跑，前一棒追不上；她回头确认又突然减速，两人差点撞在一起。下一次接棒者吸取教训等得过久，前一棒已经把襷递到肩边；再下一次双方提示同时出口。另有来棒者提前减速、接襷后整理时挡住跑线等一两步的具体损失。失败来自五个人都在修正自己认为的问题，不把任何人拍成笨拙笑料。

若月试图固定等待位和提示；万理华坚持真实到达速度每天不同；南必须先跑一次才知道；深川不断调整自己的部分；飞鸟准确发现棒次与递出端的问题，却把意见说成旁观式毒舌。

若月不追问态度，只追问：既然看见了，准备让大家怎么改。飞鸟暂时没有可供别人使用的答案。

**场尾：**五个人仍留下来收拾标志物和襷，没有人退出；但第一次练习结束时，她们连一次稳定连续交接都没有完成。

**连续功能：**先把江口重新落回可信的体育教师，再把喜剧、人物差异与第一段转折放在同一场；不另开“队内争吵”场，也不让成人的专业性变成替学生解决剧情。

# 第二段｜身体、摩擦与练成｜约 21 分钟

## S03｜路线进入身体

**时间 / 空间：**D-9，放学后，正式路线踏勘。

江口与体育科教师带队沿人行道和普通行人路线步行确认坡度、弯道、路口、中继点、比赛日跑行线和退出方向；过路仍服从信号，不进入本番才会受控使用的车行区域，因此本次踏勘不实施交通封控。五个人第一次发现纸上的 250—380 米不是五段相似直线。

万理华留意人行道砖石接缝和硬地反馈，在路线图上记下“底太薄，后半震脚”，但还没有把感觉交给别人。若月把坡度和转弯转化为节点，仍需要可重复的共同提示。两个人的判断都成立。

集体结束后，飞鸟穿校服独自折回第 4 区，再走一遍转弯、距离和最后中继点。她用步数、官方总长和树木、校门、围栏等固定标志，偷偷在路线图背面标出“压住”“允许加速”和最后冲刺的节点。她不跑，也不发表决心；摄影机只看见她处理一件其他人以为已经结束的事。

**连续功能：**改变训练输入，并第一次让观众单独看到飞鸟的投入超过语言。

## S04｜每个人更努力，还是接不起来

**时间 / 空间：**D-7，放学后，教师陪同的正式分区试走。

学校已把本次试走的日期、时段与本番一并纳入道路许可和沿线协商。低车流时段实施分路段、短时的滚动交通控制，成人负责人、锥桶与警备人员只在跑者经过时暂时控制跑行区域，不把整个街区长时间封闭。四团错峰、无计时排名，每团只连续通过一次真实五区；出现问题也不能停下来反复重跑。D-4 校内模拟承担的不是“第一次跑完整”，而是“第一次顺畅跑完整”。

五个人分别跑真实区间，并在各自实际中继点尝试交接。个人完成度都比第一次高，但真实坡度、疲劳和不同到达速度把旧问题重新放大。

若月增加说明仍不能预写每一种速度；万理华能调整却无法让别人直接复制；南身体学会得快但重复值不稳定；深川继续吸收误差，自己的区间反而被拖乱；飞鸟批评仍准，却没有把判断交给团队。

教师只确认完成状态、恢复与安全，不评价谁更适合哪一棒，也不介入她们的方法分歧。

**场尾：**她们第一次明确知道：“每个人各自再认真一点”不会自动解决接力。

**连续功能：**中段低点；与 S02 的差别不是再演一次失败，而是证明个人进步仍不足以形成共同方法。

## S05｜把感觉翻译成别人能用的动作

**时间 / 空间：**D-7，试走后，运动场侧恢复区及相邻练习区。

交通控制解除、器材归位，各中继点跑者沿安全返回路线重新聚到运动场侧。五个人在疲劳状态下整理刚才的问题。深川停止无限换位和吸收误差，要求确定一种所有人下一次都能使用的方法。

若月再次要求飞鸟把看见的问题说具体。飞鸟不承认自己负责，只把递出前减速、等待位置、起动提示和棒次适配说清；“递出端不稳定的人放最后”使若月第 5 区配置成立。万理华把鞋底和路面感觉翻译成别人能采用的提示；南实际走 / 跑一次到达过程，让提示重新校准。

五人把交接方法缩成两段：接棒者先侧身确认真实来速；来棒者第一次叫名字，接棒者转身起跑；追到约定距离后再喊“手”，接棒者不再回头，只向后伸出约定的手。它不是从头到尾的专业盲接，而是“先看真实速度，启动以后相信提示”。

相邻区域短暂经过 C 团：真夏的简单约定有效；まあ亚没有按术语行动，却根据真实来速接对；高山把错位说成笑话，让队伍愿意立刻再来。C 团一名负责第 4 区的 3-C 普通学生也在其中；她只以稳定配速和正常交接存在，不给姓名、对白或提示性特写。这个片段不触发 D 团顿悟，也不离开当前训练空间。

**场尾：**D 团不是统一意见，而是第一次拥有一组可以一起试的动作。

**连续功能：**完成方法互译；不靠和解大会或成年人答案。

## S06｜飞鸟把训练带回没有观众的地方

**时间 / 空间：**D-7 至 D-5，普通课堂、校内第 4 区与飞鸟家，短段 sequence。

先让学校生活与接力暂时失去关系：第二天普通课堂发回小测、收作业、擦黑板，五个人分散在各自座位，没有围在一起继续研究跑步。飞鸟起身时因肌肉酸痛停了半拍，发现有人看过来，立刻装作在找东西。器材室里叠起的锥桶、渐空的走廊等数个短转场不承担象征或新情节，只让训练之间真的经过普通日子。

飞鸟在获准开放的校内时段换运动服重跑自己的区间。南偶然遇见，只接受“回来拿东西”一类蹩脚解释；她可以替飞鸟看一次时间或陪一小段，不拆穿，也不谈心。

夜里从校外训练声突然降到住宅里的地板声、呼吸和手机震动。飞鸟在家庭群提前说房间可能有奇怪声音，让父亲和哥哥不要进来。一个搞怪回复之后，家人真的不打扰；可以只用门外变轻的脚步、被放下的水或毛巾表达温柔，不把父兄请进房间演一场家庭戏。她完成短时腿部与核心训练；第二天的酸痛以一个生活动作留下，不另建“努力被大家发现”的场面。

家庭部分控制在约 45—60 秒。它是第二段持续奔跑与争论之间唯一真正降低声压的气口，但仍然推进“飞鸟在没有观众时投入更多”，不是可以独立存在的温馨花絮。

**连续功能：**把暗线从观察升级为实际投入；两处空间合计仍是短段，不剪成英雄训练 MV。

## S07｜她们真的练成了

**时间 / 空间：**D-6 至 D-2，跨年级接口与校内模拟路线，练习收束 sequence。

开头用极短接口段确认：万理华与 2-D 最后一棒练习年级边界；其他色团边界跑者也在自己的标记位工作。场面只说明十二班不必全部集合，接口仍被真实练过。

D-4 进入本 sequence 的主体。四团分组 / 错峰，不记录正式成绩。D 团按锁定跑序第一次顺畅完成内部四次交接：若月的约定仍在，万理华的线索能够被别人读懂，南通过重复获得稳定，深川不再承担全部误差，飞鸟会在问题发生前给出信息。

五个人跑完后停在同一空间喘气。她们确认襷确实到达若月手中，没有庆祝夺冠，也没有人想哭。飞鸟最先用一句普通话降低重要性，却没有提前离开。

D-2 只留南与飞鸟一次干净交接。它不是新的训练场，而是把身体记忆直接送往本番。

**场尾：**观众有充分理由相信，第三段只需兑现她们已经练成的 happy ending。

**连续功能：**完成第二段假胜利，并与结尾“同样五个人、同样喘气、却再也收不住”建立回声。

# 第三段｜本番、完成与哭泣｜约 17 分钟

## S08｜这一天已经过去了大半

**时间 / 空间：**D-Day 早晨开幕式台前，硬切至 14:10 团席 / 检录区。

早晨只保留天海校长开幕致辞结尾约 20 秒。她完成校长礼仪职责，画面不借她巡视主角或布置比赛。

硬切到下午：灰尘、汗湿的鉢巻、空水瓶、毛巾、沙哑声音和更新中的成绩板证明上午已经真实发生。放送席由两名普通高二放送委员轮值：一人播报，一人接收无线电、整理纸条与更新顺位。她们公布大球运送后的暂定总分：A 团 186、B 团 178、C 团 153、D 团 121；并重申压轴接力按最终顺位计 40、30、20、10 分。

松村正在 A 团团席传递召集信息。有人顺口问 D 团拿第一会怎样，她边写边算：D 团最高 161，C 团即使第四也有 163，D 团仍然是第四。她随即转去处理 A、B 团真正可能被接力改变的争冠关系，不同情，也不点题。D 团五人不围绕这件事讨论。

开赛前约 20—25 分钟，全部正式跑者先在校内检录区完成点名、号码、健康和鞋带确认，再按中继地点而非团色重新编组。五块地点引导牌依次举起；同一地点的四团、三个年级跑者按年级顺序进入等待队列。校外组由学生召集员和成人负责人沿普通人行路线提前带往中继点，高二、高三接棒者留在后方遮阳等待区；已经跑完的人须等工作人员放行，再沿指定单向路线返回，不得逆行比赛路线。江口、教师、学生工作人员与普通跑者都在执行岗位；其余主要人物只在 D 团移动经过时短暂存在。

**场尾：**五个人从最后一次共享空间中分开，进入无法再互相确认的五个位置。

**连续功能：**用最小篇幅建立完整体育祭日和赛事规模，不恢复全景式项目展示。

## S09｜前十棒留下真实差距

**时间 / 空间：**14:30 后，各中继点、团席与放送席的压缩 sequence。

高一、高二两轮不逐棒报道。少量起跑、中继、颜色顺位、团席反应和广播建立十棒时间经过；各团差距真实累积，不为高三清零。运动场侧的轮次牌由学生工作人员从“一年级”翻到“二年级”，再翻到“三年级”，让观众不靠说明理解同一条五区路线由三个年级依次完成。放送席只直接解说能够看到的运动场、校内路线与年级接口；校外部分最多根据工作人员无线电通报简单报告某中继点的通过顺序，不拥有电视直播式全程视野。

放送席在能够直接看见的运动场侧二年级→三年级接口建立年级轮换：“A 团高二最后一棒已经进入运动场。接下来就要进入三年级轮——对于三年级的学姐们来说，这也是最后一次体——”话还没说完，A 团已经完成交接，学生播音员立刻改报实际赛况。B 团随后进入，A、B 的争冠继续；C 团第三、D 团第四。跑者正在看路线、确认鞋带、襷和来棒方向，无人回应那句没说完的煽情。

进入高三轮时，A 团第一、B 团紧随其后，C 团第三、D 团第四；两组竞争都是真实的，但只有 A、B 团的顺位会决定总冠军。**场尾：**2-D 最后一棒进入视线，万理华开始根据真实来速移动。

**连续功能：**建立高三继承的局面与“最后一次”的背景潜流，不在主角上场前拍完另一场比赛。

## S10｜前三棒：练习没有骗人

**时间 / 空间：**高三第 1—3 区，运动场侧接口、校外路段与正门。

万理华接住 2-D 交来的襷与前两轮差距，在接口和转弯中按现场找到路线；深川用稳定配速守住位置，不试图一棒偿还全部差距；南在缓坡段按自己的节奏跑，并在接近正门时寻找飞鸟。

三个人都可以各自获得一次很短的昭和 / 平成青春片“特权镜头”：万理华是接襷与转弯时身体先于语言的判断；深川是稳定呼吸和不慌着追回全部差距；南是缓坡上真心快乐、却也确实认真用力的脸。每个人只取得一组短促形式，不分别扩成三段 MV；音乐和慢动作逐步累积，到飞鸟第 4 区才完整接管。

南接襷时，D 团与第三位 C 团约相差 15 米。她不进行战术冲刺，只保持自己的稳定节奏；前方 C 团第 3 区跑者在坡段稍有掉速，南把差距自然压缩到约 5—10 米。C 团先完成交接，那名普通第 4 区跑者按稳定配速出发；南随后与飞鸟完成干净交接，不用说“追得上”，已经用身体把一个看起来可以追到的人送到飞鸟眼前。

其他团只通过 D 团必须辨认的对手与顺位进入。真夏 / まあ亚的方法验证、白石认真而不漂亮的普通区间，都必须寄生在既有交接视线或同一段路线里，不另开比赛场。

南与飞鸟完成一次真正干净的交接。此前所有练习在本番获得明确回报；南缩短的差距同时给了飞鸟“现在真的追得到”的信念。

**场尾：**飞鸟接襷时，前方那名曾在 C 团练习边缘出现过的普通学生领先约 5—10 米。

**连续功能：**证明团队问题已经解决，把剩余悬念从“会不会交接”转移到飞鸟本人。

## S11｜她只是突然非常想超过那个人

**时间 / 空间：**高三第 4 区，正门进入校园，经主轴与校内路线至运动场侧。

中途超越不计分，D 团总排名也已固定第四。南刚刚把原本更远的差距带到 5—10 米，飞鸟看见前面的人，没有积分计算，也没有新的战术提示；她只是突然非常想超过那个人。

她以近似百米冲刺的主观用力跑掉前约 120—170 米，追近并完成反超，最多领先约 3—5 米。昭和 / 平成青春片形式可以在这里逐步接管：音乐、慢动作、呼吸、心跳、正反打与适度重放共同制造“经典回报正在发生”的相信。

那名 C 团普通学生没有回头、加戏或把飞鸟当成自己的对手，只继续维持原有配速。约 280 米以后，现实身体逐渐耗尽形式承诺：飞鸟呼吸先乱，抬腿、步幅和摆臂依次衰减；前半段抢来的距离被一点点拿回，她在最后约 100 米被重新超过。

她仍然保持清醒、跑线和方向，在有效区内把襷完整交给若月；C 团此时领先约 5—8 米。

**连续功能：**完成飞鸟的欲望、反超、配速崩塌与无胜负回报；不把对手拍成反派或胜者主角。

## S12｜完成以后，没有下一件事可做

**时间 / 空间：**高三第 5 区、退出通道与运动场侧恢复区，相邻空间连续行动。

第 4→5 区交接点设在运动场侧入口外缘。20 米有效交接区之后，来棒者必须沿单向退出通道再走约 25—35 米；D 团恢复区设在通道外侧约 15—25 米处。因此从交襷点到恢复区合计约 40—60 米，飞鸟以力竭后的步速约 45—75 秒能够到达，既不堵塞比赛，也没有远到切断情绪。

若月接襷进入最后 250 米训练环道。终点绕回同一运动场侧区域，距 D 团恢复区约 30—50 米。她不替飞鸟夺回英雄回报，只把五个人已经完成的东西带到终点；C 团最后一棒同样稳定，最终领先 D 团约 2—3 秒、约 10 米完成。

飞鸟沿退出通道离开比赛通道时，真正决定冠军的比赛在另一边完成：B 团第一冲线，A 团第二；B 团凭本项 40 分以总分 218 比 216 反超 A 团夺冠。全场爆发本集最大的欢呼，摄影机不切过去，只让声音穿过飞鸟越来越慢的脚步。随后 C 团第三、D 团第四，最终总分依次为 B218、A216、C173、D131。

江口只做本职判断：飞鸟清醒、能回应，没有医疗急症。远处若月完成第四名冲线，广播与团席仍在另一场胜利里工作，比赛世界没有围着飞鸟停下。

飞鸟已经交完襷，不能补跑，也没有下一项可以修正。此前藏在练习、借口和身体里的投入失去遮挡。她慢慢举起胳膊，大哭着问为什么要跑；江口只能诚实回答“不知道”。

其他四人的返回按真实距离逐渐发生：

- 万理华在飞鸟交襷前已有约 4—5 分钟回程时间，可以最早到达或与飞鸟前后脚进入恢复区；
- 深川从校外中继点沿安全短路线返回，可在飞鸟到达后约 1—2 分钟出现；
- 若月用约 60—100 秒完成最后 250 米，再退出、确认身体并短暂冷却，可在交襷后约 3—4 分钟回来；
- 南从正门中继点退出后不能逆行于仍在使用的第 4 区，只能沿安全返回路线步行，约在交襷后 4—6 分钟最后或接近最后抵达。

因此本场世界时间允许经过约 5—6 分钟，正片用持续广播、人物陆续进入和极轻的时间省略保持连续。南最直接被感染；万理华不替它命名；深川递毛巾时自己也哭；若月确认该完成的都完成以后，失去下一项可执行的事。

南抵达以后，飞鸟问她们哭什么。南说“不知道……就是很想哭”，大家哭得更凶。她最后回来不是为了制造台词入场，而是由第 3 区终点的真实距离决定；这句回答发生在五个人终于重新聚齐时。

远处仍在报告名次和准备闭幕流程。本集不去领奖、不发精神奖、不补全班拥抱，也不让其他主要人物赶来见证。

**场尾：**五个认真完成、没有得到胜负回报、也说不清为什么要哭的女孩子。CUT。

**连续功能：**把终点、医疗常识、飞鸟公开失守与集体哭泣放在同一相邻空间链中，不追加第二结尾。
