## 3. B 类｜能感觉即可

- 飞鸟很在意，却不愿把在意公开交给别人判断；观众看见私下投入与最后无法藏住的眼泪即可，不必听见人物弧的命名。
- 若月的认真、飞鸟的不耐烦、深川的身体反馈都各有依据；S05 的改变来自相互观察，不需要一个人认错来认证成长。
- 南始终快乐，也认真跑。她不哭不等于她没有投入，镜头不需要替她补一份遗憾。
- 深川可以被当下触动，不必和飞鸟拥有同等训练量、同一种失败或一段新创伤。
- 家庭群的荒唐笑话、水和毛巾、布丁能让观众感到她熟悉的家庭氛围；不需要家人出镜解释关爱。
- 飞鸟哭过并不等于从此不再遮掩，也不提前给后续人物变化下结论。

## 4. C 类｜保持不说破

“青春”是整段行动与感受形成的答案，不补在“为什么要跑”之后。高三最后一次体育祭的广播被眼前交接打断，已经足够；不补全员感伤反应。远处 B 团的胜利与近处 D 团的眼泪可以并存，不需要一句“胜负不重要”。

本集经主创确认的暖色、过曝、慢镜头、热血音乐与极短重放属于有意的形式选择，保留。审查重点是它们有没有遮住事实、替人物宣布意义；不以一般克制原则取消本集已定形式。S11 音乐退去、S12 留在恢复区，使这份热血能够落回她的身体。

## 5. YELLOW｜需要拍清的三处

### Y11-01｜C、D 团与追赶对象的识别

观众必须认得飞鸟追过和后来超过她的是同一个人，并分清这不是 A/B 的冠军之争。保留团色号码布、襷与相对位置的连续性；脚步特写之间仍须能回到两人的共同空间。S10 南缩距已经有同框与同一标志物可供比较，不用再加报米数的广播。无需认出 C 跑者在 S05 出现过，更不要求知道她的姓名。

交 STEP12 / STEP14 核查构图与剪辑连续性；不增加解说对白。

### Y11-02｜私下配速计划与本番失控的比较

S06 的树、建筑转角与 S11 应能被认作同一处。正文“这里原来准备加速”本身不是观众收到的信息，要靠前次笔记和空间建立、此次到达时已经加不动的身体完成比较。

“前快后慢”这一 A 类事实已有 S02 与 S11 支持；观众漏掉具体哪棵树仍能理解比赛。精确感到她连自己准备好的办法都没守住，属于值得保留的 B 类。优先保留可比较画面，不补闪回、旁白或老师提醒。

### Y11-03｜深川从陪伴到自己落泪

保留递毛巾、坐下、看着飞鸟之后的时间，让笑意退去、自己的眼泪慢慢出现。不要剪成她刚进场便哭，也不要让一句台词或煽情音乐成为统一哭泣指令。

她不必给出完整理由；“不知道。就是突然很想哭”已经足够。核查重点是表演与停顿，不是再写一段付出史。其他三人保持各自的陪伴状态。
