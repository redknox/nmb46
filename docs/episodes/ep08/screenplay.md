第一名，B 团！紧接着 A 团冲线！

摄影机跟着飞鸟，没有转向终点。

她走到恢复区边缘，双手撑住膝盖。

江口在旁边等着。

万理华沿安全返回路线走来。她看见飞鸟，走近，在她旁边停下。

飞鸟喘了一会儿，慢慢直起身。

她抿住嘴。

鼻翼动了一下。

她低头，用手背擦过脸颊。

再抬起来时，脸已经皱了。

两只胳膊慢慢举起，弯在脸前。

她从胳膊后面吸气，声音忽然变了。

万理华看着她。

飞鸟哭出了声。

**飞鸟**
到底为什么要跑啊……！

江口看了她一眼。

认真地回答。

**江口**
……不知道。

飞鸟张着嘴，哭得更厉害了。

万理华没有接话，在旁边陪着。

远处，广播继续。

**放送委员（远处广播）**
C 团冲线。紧接着，D 团也完成比赛！

飞鸟把胳膊放低一些。

眼泪仍不停往下掉。

江口留意了一会儿她的呼吸，往通道旁让开，转向另一名刚跑完的学生。

**轻微时间省略。**

恢复区。

飞鸟已经坐在长凳上。

万理华在旁边喝水。飞鸟的哭声小了一阵，又断断续续地出来。

深川沿返回通道走近。

她额角的汗还没干。

看见飞鸟，她停了一下，然后从物品筐里拿起毛巾。

**深川**
给，毛巾。

飞鸟抬头，伸手接过。

她用毛巾按住脸，深吸一口气。

像是终于要收住了。

下一声却哭得更响。

深川原本带着一点笑，弯下身看她。

没有接着说话。

她在飞鸟旁边坐下。

飞鸟把毛巾拿下来，吸了吸鼻子。脸擦干了一点，眼泪又流出来。

飞鸟重新捂住脸。

镜头停一会儿。

深川低下头。

过了片刻，她抬手擦了一下眼角。

再抬眼时，眼睛已经湿了。

她轻轻吸了吸鼻子，自己也笑了一下。

眼泪掉下来。

三个人坐着。

远处有人拖动器具车。轮子经过接缝，响了两声。

**轻微时间省略。**

若月沿终点退出路线走回来。

襷已经取下，攥在手里。

她还在喘，看见飞鸟和深川，脚步慢下来。

万理华往旁边挪了一点。

若月把襷放进筐里，坐下，手肘撑在膝上。

她转头看飞鸟。

飞鸟的脸还埋在毛巾后面。

若月没有问，低头缓着呼吸。

深川擦了一下鼻子。

哭声断断续续。

操场上的广播通知各团负责人到记录席确认成绩。

**轻微时间省略。**

安全返回路线那头，南跟着几名学生走进来。

她看见长凳上的四个人，抬起手。

走近，才看清飞鸟的脸。

又看见深川在擦眼睛。

**南**
诶，你们两个怎么了？

深川抬头看她。

张了张嘴，没有马上答出来。

她擦掉脸颊上的眼泪，笑了一下。

**深川**
不知道。就是突然很想哭。

南看看她，又看看飞鸟。

**南**
……哦。

南在长凳边上的空位坐下。

飞鸟从毛巾后面露出眼睛，看着她们。

一声很短的笑漏出来。

随即又哭了。

深川被她带得也笑了一下，边笑边擦眼泪。

万理华、若月和南坐着，陪着她们。

**放送委员（远处广播）**
综合优胜是——二百一十八分，B 团！

远处再次响起欢呼。

广播接着报出 A 团二百一十六分、C 团一百七十三分、D 团一百三十一分。

飞鸟把毛巾拿下来，长长地呼出一口气。

眼泪还在掉。

深川坐在她旁边，低头擦脸。

其他三个人也坐着。

镜头留在五个人身上。

**切黑。**

**本集结束。**
