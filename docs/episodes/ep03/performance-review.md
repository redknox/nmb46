# EP03《午休》｜Performance / Camera / Space / Sound Review

> 状态：**LOCKED｜STEP 14 PASS。**
>
> 本文件只处理表演、摄影、空间轴、声音与制作硬约束。它不能反向新增解释对白，也不能用“拍得漂亮”修补剧本因果。

---

# 一、结论

**PASS。**

当前正片最大的制作风险不是“观众看不懂”，而是导演 / 表演为了强调关系、意义或文化祭气氛，把本来成立的生活拍得太像“这一刻很重要”。

固定总原则：

> **把空间、动作、视线和声音拍清楚，不替观众划重点。**

---

# 二、一镜到底摄影原则

摄影机不是全知视角，也不是主角雷达。

它的移动逻辑必须始终是：

> **有人真的走了 → 摄影机有条件跟。**

禁止：

- 上一段“演完”后摄影机主动寻找下一主角；
- 普通学生突然停在镜头前等待接棒；
- 角色为了摄影机改变路线；
- 通过明显摇镜 / 推镜告诉观众“现在请注意这个人”。

---

# 三、S01｜课堂松开

## 表演

铃前几十秒的“快下课”只能是微动作：

- 橡皮进入笔袋；
- 看一眼钟；
- 手碰便当袋。

不能全班同步表现“终于下课了”。

## 声音

铃响以后，教室声音层次应自然突然增加：

- 拉链；
- 椅脚；
- 书本合起；
- 同学小声讲话。

老师的文化祭班务不需要压低全班声音形成公告会。

---

# 四、S02｜食品購買

摄影机优先感受真实队伍推进，不用把“榊陵”对话拍成秘密情报交换。

松村挑面包必须是真在挑，不为镜头演“可爱纠结”。

商品环境保持学校生活区尺度，不拍便利店广告式货架展示。

---

# 五、S03｜3-C

## 空间

禁止“主角圆桌”。

松村、高山、まあ亚、真夏、西野附近必须仍有普通学生与午饭生活。

## 武田马甲

高山 / 松村要像认真讨论普通废话，不要互相等包袱节奏。

“……终于有第二件了”可以好笑，但不能表演成综艺落点后全桌停顿。

## 真夏

核验来源语速可以稍快但自然；不拍成审讯式正反打。

---

# 六、S04｜3-B

## 3-B必须是完整班级

摄影机不能为了看清飞鸟 / 桥本 / 白石清空前景与背景。

至少允许：

- 人经过；
- 其他桌讲话；
- 同学吃饭；
- 有人转身 / 起身。

## 飞鸟

她已经在那里。

不得使用：

- “发现飞鸟”的强调推镜；
- 其他人看她的确认反应；
- 关系意味深长音乐。

## 桥本

“也是”必须是真的判断。

不能：

- 冷笑；
- 故意逗飞鸟；
- 用眼神告诉观众“我早就知道她嘴硬”。

## 白石

笑是身体先出卖她：

> 噗嗤 → 忍 → 对视后更不行 → 低头笑 → “对不起……”

允许它成为本集清楚峰值。

禁止削成礼貌微笑，也禁止演成大型爆笑段落。

## 生田

她的谱面行为可在同一完整3-B空间里逐渐进入观众注意，不需要先给她专门“现在轮到生田”的构图。

---

# 七、S05｜同行路线

这是全片最容易被拍成青春MV的一段。

硬禁：

- 抒情BGM；
- 慢动作；
- 正面退拍两名少女并肩走完整段；
- 发丝逆光；
- 刻意对称；
- 文化祭通知插入特写；
- “两个人很有默契”的展示动作。

正确感受：

> **她们只是刚好同路。**

迎面有人时正常让路，之后自然走回相近位置即可。

校园视觉可以美，但美来自学校本来如此。

---

# 八、S06｜观察窗 / 琴声

## 摄影机

留在防音练习室外。

观察窗是功能性的，不是审美画框。

允许：

- 窗框挡住人物局部；
- 摄影机位置并不完美；
- 生田某些动作只能看见一部分。

禁止：

- 玻璃反射双层人物；
- 柔光侧脸；
- 对称琴房构图；
- “天才少女独处”海报感。

## 声音

门外琴声：

- 极轻；
- 断裂；
- 重复；
- 不可拼成完整旋律。

后期不得把多个碎片重组为好听音乐。

## 表演

生田重点是工作程序，不是痛苦或灵感。

表情不需要“大问题终于解决”的完成感，因为摄影机先走。

---

# 九、S07｜万理华

## 身体顺序

“一人也可以”出现后：

> **身体先停，半拍后才转回去。**

这比立刻大反应更重要。

## 满岛

语气对普通女生和万理华保持同一重量。

禁止：

- 教师意味深长微笑；
- 盯着万理华看；
- “你终于发现了”式表演。

## 万理华看空间

不能拍成灵感蒙太奇。

不做：

- 入口 / 出口反打；
- 视线扫描动线；
- 空墙“命运位置”特写。

## 抱材料女生

她说“借过一下”时只是正常通行请求，不承担喜剧演员式吐槽。

## 回头

只一眼。

不配乐，不停很久，不让满岛同时回看。

---

# 十、S08｜保健室

## 石原

必须避免“冷淡保健老师”误读。

正确表演链：

> 抬头 → 看松村本人 → 看手指 → 判断小伤 → 自然示意用品。

这几个动作不能省到只剩“眼神指一下创可贴”。

## 松村贴创可贴

这是摄影机真正认真看的动作。

贴歪以后调整可以有一点生活喜感，但不能为了笑点反复三四次。

## 万里小路台词

摄影 / 声音禁止提示重要性：

- 不rack focus到松村；
- 不突然压低环境声；
- 不提高画外对白音量；
- 不给松村眼神；
- 不暂停创可贴动作。

观众自己听见即可。

---

# 十一、S09｜班级恢复与课前礼

## 松村

“……不知道”是真搜索失败，不是准备好的综艺包袱。

说完以后不需要尴尬反应镜头。

## 摄影机逐渐失去主角

最后两分多钟，摄影机不再把松村维持在中心。

应该逐渐看到：

- 普通学生回位；
- 桌椅方向统一；
- 下午教材替代饭盒；
- 人流减少。

## 13:20铃声

铃声是制度声音，不做音乐高潮。

## “起立—礼”

这是日常熟练程序，不是毕业典礼。

表演允许轻微现实差异：

- 椅脚声音并非一声；
- 有人动作快半拍；
- 有人刚把书摆好才起身。

但总体形成明确班级共同动作。

最后老师回礼后立即CUT。

不等“着席”。

不加配乐。

---

# 十二、空间轴与可追踪性

观众不需要记校园地图，但需要方向感不被破坏：

- S02明确从高三西侧往生活区；
- S05明确向东 / 下楼 / 出主楼 / 去东南别馆；
- S08从别馆短路回主楼东翼；
- S09从1F东翼回3F西翼。

摄影机可以流动，但不能通过隐藏切换让人物突然跨越这些已承担真实时间的空间。

**PASS。**

---

# 十三、STEP 14结论

**PASS / LOCKED。**

当前没有需要以新增对白修复的表演 / 镜头 / 空间问题。

制作阶段最高优先级警告：

> **不要拍“这一刻很重要”。**

尤其不要把飞鸟跨班、生田练琴、万理华回头、万里小路信息、课前行礼拍成作者划重点。
