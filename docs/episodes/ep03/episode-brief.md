# 一、本集为什么存在

EP01 让乃木坂女学院作为一套真实制度成立；EP02 让学生真正住进这套制度，经历学习、纪律与普通学校生活。

EP03第一次把课堂暂时放到背景，让观众看见：

> **当没有人规定她们必须和谁待在一起时，她们自己会走向谁。**

表层事件非常简单：

> **12:30—13:20，一次完整午休。**

真正改变的是：

> **观众第一次形成一张“她们平时怎样一起生活”的关系地图；与此同时，文化祭开始从学校事务变成接下来几周会实际改变人物行动的东西。**

本集核心观看欲望：

> **谁跟谁好？**

但关系不能被主持、介绍或总结，只能被观众撞见。

### Gate 0 一句话

> **一顿午饭里，我们第一次看清她们平时会走向谁；与此同时，文化祭开始让这些原本自由的关系，慢慢获得下一步。**

# 二、形式锁｜严格50分钟近实时一镜到底

本集形式固定为：

> **12:30 第四节结束 → 13:20 第五节开始，约50分钟真实流逝；主体以严格一镜到底的连续摄影机逻辑成立。**

“一镜到底”不是炫技目标，而是让观众像一个真实存在于校园中的人一样，连续经历午休状态从散开到重新归位。

骨架不是传统事件型 A Plot，而是：

> **时间流动 + 人的移动 + 关系接力 + 文化祭引力。**

每次摄影机换人，都必须因为有人本来就要起身、离开、还东西、练习、去保健室或回班，而不能因为上一段“演完了”。

固定纪律：

> **如果摄影机今天没来，这些人仍然会这样移动。**

> **如果某次接力只因为编剧需要去下一个地方，就必须判错。**

S01—S09的时间分配与物理路线以 `realtime-timing-lock.md` 为权威。

# 三、空间与制度状态

午休不是“学校暂停”，而是课堂统一秩序暂时松开。

学生仍然处在学校规则中：

- 主楼内手机不能替代人物移动；
- 食品購買位于主楼西侧食堂棟入口区域；
- 音乐练习室按利用表确认 / 登记；
- 音乐・美术别馆仍是教学 / 练习空间，不是自由娱乐场所；
- 保健室位于主楼1F东翼，入口先进入工作 / 简单处置区；
- 13:20下一节课开始，学生重新回到班级与课前礼仪。

因此本集所谓“自由”是：

> **学校之内的自由。**

它与后续EP06“学校之外的自由”明确区分。

# 四、人物压力等级｜M / S / L / R

本集不是单主角集。等级表示本集镜头 / 结构压力，不表示人物重要性。

## M｜松村沙友理

松村是**群像导航员 / 信息粒子**，不是传统主角。

她负责让观众自然经过：

- 3-A；
- 食品購買；
- 3-C；
- 保健室；
- 最后回到3-A。

她的功能必须来自既有行为：爱串班、认识人、顺手听见很多东西、记得事实碎片，却未必记得来源。

本集不能把她写成调查员或校园情报机关。

## S｜飞鸟 / 桥本 / 万理华 / 生田

- **飞鸟 × 桥本**：本集最重要的关系发现。飞鸟已经在3-B；没有人解释她为什么来。她嘴硬，桥本只用事实纠正，关系重量来自飞鸟主动跨班本身。
- **万理华**：只推进到“原来一个人也可以 / 我也许想做”，兴趣出现，不形成作品方案。
- **生田**：把“我本来就会”写成具体生活程序。她在午饭桌上发现谱面问题，去练习室处理一个窄小段落；不提前进入EP04的创作观冲突。

## L｜白石 / 真夏 / 高山 / まあ亚 / 卫藤

- **白石**：在飞鸟与桥本对话中出现一次无法忍住的真实笑，不抢成情感场。
- **真夏**：展示她对信息来源、身份、授权等级的本能核验；不承担正式解释。
- **高山 × まあ亚**：提供高频生活喜剧与普通同学感；武田老师马甲属于无剧情价值但有共同生活价值的细节。
- **卫藤**：以成熟、低调的普通高三女生社交状态存在；关于低年级合唱的评价只是学校背景，不是剧情说明。

## R｜其余主要成员

允许低量、背景或整集不出现。

群像不等于点名册。本集禁止为了“主要成员都要露脸”破坏午休真实关系网络。

# 五、四组优先关系

## 1. 飞鸟 × 桥本｜低频、高重量主动移动

摄影机进入3-B时，飞鸟已经在那里。

任何角色都不问“你怎么在这里”，也不解释她是否来找桥本。

固定关系语法：

> **飞鸟先否定意义 → 桥本只指出她真实做过什么 → 飞鸟补一个更具体的理由 → 桥本真的思考。**

桥本不是姐姐，不安慰、不心理分析、不拆穿飞鸟的敏感。

## 2. 白石 × 桥本｜默认安全区

关系不另做展示场。白石在这一区域可以暂时少一点“学校之颜”的公共控制。

## 3. 高山 × まあ亚｜高频生活搭档

まあ亚会问别人跳过的基础问题；高山会自然接住现场喜剧，但不把她写成“什么都不懂”。

## 4. 松村 × 真夏｜流通系统 vs 核验系统

- 松村：知道“大家正在说什么”；
- 真夏：先问“谁说的 / 是不是负责的人 / 到什么确认等级”。

两人没有谁负责给观众标准答案。

# 六、文化祭在本集的准确推进量

EP03是EP03—05文化祭三集结构的第一章。

坡度固定为：

> **EP03：动心 / 被卷入 → EP04：动手 / 摩擦 → EP05：上场 / 汇流。**

本集文化祭必须已经进入学校日常，但仍不能成为“大事件”。

可见层包括：

- 3-A继续募集文化祭执行委员；
- 校内已有文化祭相关基础通知与材料；
- 榊陵可能参与联合项目的风声在人际网络中传播，但本集不验证；
- 低年级合唱能力已经成为高三学生能随口讨论的共同背景；
- 万理华第一次知道“一人参加展示也可以”；
- 万里小路的腿伤是否会影响文化祭仍未确定。

固定原则：

> **文化祭不是逐人发任务，而是同一件学校活动开始在不同人的生活边缘产生不同重力。**

# 七、本集允许存在的明确峰值

克制不等于削平所有峰值。

本集允许一个很明确的表演峰值：

> **白石听完飞鸟“因为她们做得太丑了，那个更不行”以及桥本认真判断后的“也是”，一下没忍住笑出来。**

该峰值来自关系与当下反应，不允许通过清空普通同学、三人展示构图、配乐或追加解释台词放大成“请嗑这里”的名场面。

---

# 八、学校生活颗粒｜允许没有剧情价值

本集必须保留不能被“剧情效率”删除的生活内容：

- 松村排队买面包时挑来挑去，最后拿回第一个；
- 高山与松村认真讨论武田老师是否换了几乎一样的马甲，并记得旧马甲左侧的磨损；
- まあ亚问“你们为什么知道？”却没人回答；
- 普通学生跨班只为一起吃饭；
- 生田不是演奏，而是碎裂地处理一个小节；
- 万理华想事情挡住通道，被一句“借过一下”拉回现实；
- 松村贴创可贴贴歪后重新压正；
- 保健室三张床当天都在使用；
- 午休最后两分钟主要是收便当、转椅子、借修正带、问下一节课。

固定原则：

> **可以好笑，但不要为了笑点把生活组织成段子。**

# 十、结尾锁

S09回到3-A后，午休不是因为剧情得出结论而结束。

13:20到了。

学生回座、椅子转正、饮料收起、下午教材打开。老师进入教室，残余午休声音自然消失。

负责号令的学生：

> **“起立。”**
>
> **“礼。”**

全班行礼，老师回礼。

**CUT。**

不等“着席”，不加配乐，不加文化祭总结，不给松村或任何主角最后一个感悟镜头。

本集最终运动：

> **课堂统一秩序 → 午休自由流动 → 关系自然散开 → 学校通过日常课前礼仪重新把所有人收回一个班级整体。**

仪式感来自学校长期存在的形式，不来自作者宣布“这一刻很重要”。

---

# 十一、结尾时观众应该多知道 / 多感觉到什么

观众不必能复述一条强情节，但应该确信：

> **她们真的在这里一起读书、吃饭、串班、聊老师、练琴、还东西、去保健室。**

以及：

> **文化祭已经开始改变她们接下来几周会去哪里、和谁一起做事、会对什么产生兴趣。**

同时仍然不能知道：

- 榊陵联合安排的正式答案；
- 万理华最终会做什么；
- 生田的创作冲突会如何爆发；
- 万里小路的腿究竟如何；
- 这些日常关系未来会被毕业怎样改变。
