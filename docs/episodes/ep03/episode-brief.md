# EP03《午休》（暂名）｜Episode Brief

> 状态：**DRAFT｜STEP 0 编剧室讨论中，尚未 Gate 0。**
>
> 本文件只记录当前共同确认的创作方向；不代表结构、Beat Sheet 或剧本已经锁定。

---

# 一、本集最初冲动

《乃木坂女学院》的重要企划初衷之一，是满足乃木坂46粉丝的一种幻想：

> **如果她们真的一起在这所名门女子学院里上学，她们每天会怎样生活、谁会和谁自然待在一起？**

EP01 让学校作为系统成立；EP02 让学生真正过了一天普通学校生活。

EP03 第一次开始兑现前两集为“现实感”支付的成本：

> **观众不再主要认识学校，而是开始偷看到她们怎样一起生活。**

核心观看欲望：

> **谁跟谁好？**

同时，EP03 不是孤立的纯日常特别篇，而是 EP03–05 文化祭三集小高潮的第一章：

> **EP03：文化祭开始进入每个人的生活 / 有人开始动心。**
>
> **EP04：真正动手以后，创作与关系开始摩擦。**
>
> **EP05：所有准备、关系与系统在文化祭当天全面汇流。**

---

# 二、当前形式决定｜大胆尝试一镜到底

当前主创共同决定：

> **EP03 尝试把主体做成一次接近真实时长、连续发生的午休，并采用“一镜到底”的形式假设。**

因为项目目前以创作为目的、不受真实拍摄执行限制，可以把形式实验推到底。

但“一镜到底”不是炫技目标。

它存在的唯一理由是：

> **让观众像一个真的在乃木坂女学院里的人一样，连续跟着她们过完一段午休。**

因此禁止为了展示镜头技巧而安排不自然的接棒、巧合、调度或台词。

真正的骨架不是传统“起承转合”，而是：

> **时间流动 + 人的移动 + 关系接力 + 文化祭引力逐渐进入不同人物的生活。**

午休铃响之后，统一的课堂秩序暂时松开。学生自己决定去哪、找谁、吃什么、做什么。预备铃 / 上课铃临近时，这些自由形成的小群体再自然散开。

# 三、本集的关系原则

午休特别重要，因为课堂、班级、职位暂时退到背景：

> **没有人规定你必须和谁待在一起时，你自己会走向谁？**

关系不应被“呈现”，而应被观众撞见。

优先通过：

- 谁已经自然坐在谁旁边；
- 谁串班时没人觉得奇怪；
- 谁可以直接拿谁的东西；
- 谁会互相拆台；
- 谁能安静地待在一起；
- 谁只说两句，却明显知道对方很多事；
- 谁问完事情真的走，谁问完以后仍自然留在那里。

形式 RED：

> **一旦一个动作漂亮、完整到明显在告诉粉丝“这里请嗑”，就有 MV 感，必须重新生活化。**

# 四、当前四组优先关系观察对象

## 1. 斋藤飞鸟 × 桥本奈奈未｜本集第一关系发现

当前锁定：

> **画面进入 3-B 午休现场时，飞鸟已经自然坐在桥本和白石旁边。**

观众可能想：

> “诶？飞鸟怎么会在这里？”

但剧中没有任何角色觉得奇怪，也没人解释。

午饭聊天中，飞鸟可以照常毒舌 / 嘴硬；桥本用事实和她对飞鸟行为的了解，非常平静地点她一下。周围人笑，飞鸟继续嘴硬，话题马上流走。

桥本不是姐姐式照顾，也不教育飞鸟。她只是足够熟，因此能很准确地指出：

> **飞鸟嘴上说的，和她真正做的，常常不是一回事。**

禁止专门拍“飞鸟如何从 3-D 走到 3-B”、邀请落座、安静双人特写、第三人解释关系等动作。

## 2. 白石麻衣 × 桥本奈奈未

默认安全区。

白石在桥本旁边可以少一点“白石麻衣”的公共意识。关系通过极普通的共同生活习惯存在，不另做展示场。

## 3. 高山一実 × 和田まあや

高频生活搭档 / 喜剧发动机。

まあ亚制造误解或事故，高山往往不是站在旁边评论，而是很自然地一起卷进去。熟悉感来自动作、接梗和现场节奏。

## 4. 松村沙友理 × 秋元真夏

两种社交系统：

- 松村先知道“大家正在传什么”；
- 真夏本能区分“传闻 / 确认 / 谁负责 / 什么流程”。

不要求她们承担深情关系戏，但她们很适合共同展示校园人际网络如何运转。

# 五、文化祭｜已经进入学校日常，但还没有变成“大事件”

EP03 必须完成 EP03–05 三集篇章的第一步。

因此文化祭不能只剩一句孤立的小道消息；但也不拍“正式宣布文化祭开始”的剧情按钮。

更自然的状态是：

> **学校层面的文化祭准备已经开始。**

它可以作为背景事实存在：班级正在募集执行委员、公告栏出现基础日程、学生会已经开始处理初期材料、有人谈班级项目意向。

这些内容不承担戏剧高潮，也不需要解释。

松村的小道消息是另一层：

> **她从第三方关系链听到隔壁榊陵学院今年可能会参与某些联合项目 / 联动安排。**

当前纪律：

- 松村并不掌握机密，只是比正式系统早听到人群中的风声；
- 消息可以半真半假、细节模糊；
- 真夏可以追问信息来源和确认程度；
- 话题可以被武田老师马甲、食堂、别人的午饭等完全无关内容打断；
- **EP03 可以从头到尾都不验证榊陵这一条消息。**

文化祭在本集真正推进的不是“通知到了”，而是：

> **同一件学校活动开始在不同人身上产生不同反应。**

# 六、伊藤万理华｜只需要让观众看见“她动心了”

EP03 需要给万理华一笔很轻但明确的文化祭前置。

目标不是让她在这一集决定作品、讨论完整展示方案或进入创作冲突；那些属于 EP04–05。

本集只需要完成：

> **她原本把文化祭当作普通学校活动；某个瞬间，她第一次表现出“也许我想在这里做点什么”的兴趣。**

可以考虑让满岛光饰演的美术教师自然参与，但教师的功能不是启发、劝说或解释“艺术是什么”。

更合适的机制是：

- 满岛光在美术相关空间处理文化祭展示准备 / 参加意向；
- 她面向一小群学生随口提到“想参加展示的人可以报名”之类的信息；
- 万理华原本没有明显参与，听到以后产生一点停顿、回头、追问或明显兴趣；
- 只要观众看懂“她动心了”即可，不必让她纠结尺寸、墙面、灯光等大量细节；
- 她可以问一句“个人也可以吗？”或同等重量的问题，然后把情绪留住。

这一笔的尺度：

> **兴趣出现，而不是作品出现。**

---

# 七、生田绘梨花｜文化祭对她几乎只是熟悉的日程信息

当前锁定生活逻辑：

> **生田会把午休的一部分自然拿去练琴。**

不是“突然被音乐召唤”，也不是剧情安排。

她可能简单解决午饭，发现还有十几二十分钟，就自己去琴房；周围同学对此也不觉得是新闻。

文化祭如果擦过她，应保持非常淡定：

> **表演、合唱、上台这些事情对生田而言已经很熟，她不会因为“今年又要演出”就改变练习节奏或突然兴奋。**

她最多确认一个非常现实的日程信息，然后继续练。

这与万理华形成明确差异：

- 万理华：第一次被“可以做自己的东西”吸引；
- 生田：早就活在音乐与表演里，文化祭只是即将进入她既有生活的一项安排。

禁止把这一段拍成夕阳、长发、琴键特写式 MV，也不要提前制造 EP04 的技术 / 表达冲突。

---

# 八、高三合唱｜轻轻建立“下一届也不能小看”

当前新增方向：

> **高三生在文化祭相关安排中需要参加合唱。**

EP03 可以用非常轻的同学闲聊，把“高一新生里也有很厉害的人”作为校园内部口碑种下去。

例如高三女生在聊合唱、声部、排练或今年新生时，随口出现类似：

> “现在的高一真的不能小看。”
>
> “有几个声音很厉害。”

不需要马上把镜头切去解释是谁，也不需要正式介绍堀。

这条只承担极轻的未来感：

> **这一届高三不是学校里唯一耀眼的一代；新的学生已经开始在下面长出来。**

它可以为后续“堀”的再次登场留下一个非常轻的先声。

当前 repo 尚未检索到“堀 / 高三合唱”的既定 canon 条目，因此这条仍作为 EP03 DRAFT 种子，不向季级 canon 外扩，待后续人物与年级设定共同确认。

# 九、学校生活颗粒｜允许没有剧情价值

本集需要保留一些“完全不推进剧情”的东西，因为它们证明这些人真的已经共同生活了很久。

当前候选包括：

### 武田铁矢老师的马甲多久一换

松村或高山可能认真讨论：

> **武田老师那件马甲到底多久换一次？**

有人坚持昨天不是这一件；有人开始研究纽扣、口袋、毛球位置；まあ亚可能认真问“那怎么判断他换了？”

不需要答案，不需要武田突然出现配合 punchline，甚至可以聊到一半就被别的话题打断。

### 保健室三张床全满

某个角色因为非常普通的小事去保健室，发现：

> **三张床居然全有人。**

不同人可能分别因为低血糖、体育课不舒服、经期不适、单纯需要躺一下等普通原因在休息。

重点不是制造“保健室剧情”，而是让保健室成为真的每天有人使用的学校空间。

这些颗粒都必须遵守：

> **可以好笑，但不要为了笑点把生活组织成段子。**

# 十、一镜到底真正需要解决的问题

接下来不先设计传统 A Plot，而先设计一次完整午休的“空间—时间路线”。

需要回答：

1. 镜头从午休铃响时具体在哪里开始？
2. 第一个自然跟随对象是谁？
3. 通过什么现实动作从一个人换到另一个人？
4. 哪些地方热闹，哪些地方必须安静？
5. 如何经过 3-A / 3-B / 3-C / 3-D、食堂、走廊、琴房、保健室、美术相关空间等而不显得在“校园导览”？
6. 哪些人物整个午休都不必出现？群像不等于点名册。
7. 如何让观众感到时间真的在减少？
8. 文化祭如何像引力一样多次擦过人物，却不形成“编剧在逐人发任务”的机械感？
9. 最后的铃声到来时，镜头停在哪里最自然？

重要：

> **如果某次人物接力只因为“编剧需要镜头去下一个地方”，就必须重做。**

每一次移动都先服从学生真实的午休行为，再考虑摄影机能否跟过去。

# 十一、与整季的连续关系

EP01：

> 学校作为系统第一次被看见。

EP02：

> 学生身体真正住进这个系统的一天。

EP03：

> **制度暂时松开以后，她们自己会走向谁；同时文化祭开始从“学校事务”变成“某些人自己的事”。**

EP04：

> **真正动手以后，兴趣、能力、标准与表达开始发生摩擦。**

EP05：

> **人物关系、作品、场地、时间、信息在文化祭当天全面汇流。**

因此 EP03–05 的坡度应保持为：

> **动心 / 被卷入 → 动手 / 摩擦 → 上场 / 全面爆发。**

本集如果成功，观众在结束时不一定能复述“发生了什么大事”，但会同时确信两件事：

> **她们真的在这里一起读书、吃饭、串班、偷懒、练琴、聊老师、听八卦。**
>
> **而文化祭已经悄悄开始改变她们接下来几周会做什么。**

# 十二、当前尚未锁定

以下继续由 writers' room 共同讨论：

- 一镜到底从哪里开始、在哪里结束；
- 午休真实时长在剧中是否 1:1 呈现，还是近似连续；
- 镜头的第一条完整空间路线；
- 松村具体通过谁听到榊陵消息；
- 哪些人物成为主要接力节点；
- 万理华与满岛光这一笔具体发生在哪里、以多轻的方式完成“动心”；
- 生田练琴怎样被镜头自然碰到；
- 高三合唱闲聊如何自然出现，以及后续“堀”的年级 / 出场 canon 如何正式接入；
- 保健室由谁进入最自然；
- 武田马甲话题由谁发动；
- 本集 M / S / L / R 是否维持松村为“群像导航员型 M”；
- 一镜到底结束时是否只用铃声收束，不另加事件性结尾。

**当前状态：STEP 0 DRAFT，等待继续 writers' room 讨论。**
