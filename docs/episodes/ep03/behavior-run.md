# 一、本集真正的行为压力

本集没有一个需要全员解决的中心事件。

共同条件只有：

> **课堂结束了；午休开始；每个人暂时可以自己决定去哪、找谁、吃什么、做什么。**

因此最重要的问题不是：

> “谁来推动剧情？”

而是：

> **“没有剧情任务时，她本来会怎么生活？”**

Gate 2 的核心检查句：

> **去掉摄影机和文化祭主题以后，她今天仍然会不会做这个动作？**

当前答案为：会。

# 二、松村沙友理｜M｜关系网络型流动

## 默认算法

```text
午休开始
→ 先处理自己的吃饭 / 购买
→ 路上遇到人就自然聊两句
→ 听见有趣或有用碎片会记住
→ 不一定追问来源
→ 去熟人班里吃饭 / 串班
→ 又在别的日常动作中撞到下一条信息
```

她不是主动“搜集情报”。

她真正稳定的是：

> **人际接触面很广，信息会自己经过她。**

因此：

- S01她只听到“榊陵”半句就被筷子事故打断；
- S02在购买队伍中又听到“好像要一起弄什么”；
- S03把这个不完整信息自然带到3-C；
- S08去保健室的真实目的只是处理手指；万里小路信息在她贴创可贴时自己进入；
- S09她能复述事实碎片，却真的记不起是谁说的。

## 禁止误写

```text
听到半句
→ 好奇
→ 主动查证
→ 找人确认
→ 拼出真相
```

这会把她变成校园记者 / 情报机关，与既定人物不符。

然后继续吃。

# 五、斋藤飞鸟｜S｜主动跨班的高心理成本

