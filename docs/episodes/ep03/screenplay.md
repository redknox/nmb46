# EP03《午休》｜Screenplay

> 状态：**DRAFT / 当前权威母稿。**
>
> 本稿已吸收当前编剧室确认的 S01—S09、对白修订、人物关系调度、保健室信息链、万里小路、S06门外短练习，以及50分钟近实时结构。
>
> 本集仍未 FINAL。后续只允许因连续性硬伤、人物硬伤、观众理解 RED、制作不可执行或最终无工具通读发现的问题重新打开对应场次；不再因“想到更漂亮的写法”无限润色。

> 形式基线：12:30 午休开始 → 13:20 第五节开始，约50分钟真实流逝。摄影机跟随真实行动，不允许用剪辑压缩人物实际需要走完的空间。

## S01｜3-A教室｜12:30頃

有人已经把橡皮推进笔袋。

**老师**  
还有，文化祭执行委员，3-A还差一个人。

**松村**

摄影机也不再特别跟她。

后排走廊侧，卫藤和两个普通女生的话题已经进行到一半。

**普通女生D**  
这个谁做的？

生田往东走。

万理华刚从里面出来，手里拿着要送回美术侧的东西。

她看见生田。

**万理华**  
练习？

**生田**  
嗯。

万理华轻轻晃一下手里的东西。

**万理华**  
我也去那边。

自然跟上。

没有聊天。

迎面有人过来，两人稍微让开。

人过去以后，又自然并回去。

下楼。

出主楼。

沿校园东南侧去音乐・美术别馆。

途中有人抱着文化祭材料经过。

布告栏上也比平时多了几张文化祭相关通知。规格统一，颜色克制，版式整齐。

两人都没有特别看。

进入别馆。

到了内部走廊分岔。

生田往音乐侧。

万理华往美术侧。

视线短暂碰一下。

分开。

## S06｜音乐练习室走廊｜13:02:30頃

走廊墙上是普通的练习室利用表。

生田看一眼。

确认空档。

简单登记。

进入小型防音练习室。

摄影机**不跟进去**。

防音门关上。

摄影机留在走廊侧，通过门上 / 墙面的正常观察窗看她。

不使用配乐。

不把琴声作为观赏对象。门外最多只有非常轻、不可组成完整旋律的闷响；观看重点全部落在生田的动作。

她先看一眼墙钟。

没有焦虑。

放下东西。

打开谱夹。

不是从曲子开头开始。

直接翻到已有标记的一页。

谱摆好。

铅笔放到手边。

调一下琴凳。

坐下。

手落下。

几秒。

停。

看谱。

铅笔做一个很小的记号。

再来。

这次更短。

停。

确认两个位置。

单独试。

重新从同一小段前一点开始。

十几秒。

又停。

擦掉刚才一个记号，重新写。

再来。

形成清楚的短练习节奏：

> 弹 → 停 → 看 / 写 → 再弹 → 再停。

她不是来完成一首曲子，只是在午休剩下的碎片时间里解决一个很窄的小段落。

摄影机没有等待她练完。

她进入下一次重复时，美术侧走廊出现正常人流。

万理华从美术空间出来。

玻璃后的生田仍在继续练。

摄影机自然离开观察窗，跟上万理华。

## S08｜别馆外～主楼1F东翼～保健室｜13:09頃

抱材料女生离开别馆。

不是长途移动。

她到一个路口，往自己的方向转。

与此同时，松村从另一边进入画面。

一根手指稍微举着。

两条真实路线交叉。

有一点歪。

揭起一点。

就两句。

结束。

松村没有停手。

没有抬头。

没有侧耳。

她只是把创可贴最后一个角认真压好。

看一下。

这次正了。

包装扔掉。

**松村**  
谢谢——

轻轻会釈。

石原自然应一声。

松村离开。
