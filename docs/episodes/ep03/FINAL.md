# 本集最终 canon

## 形式

EP03采用连续一镜到底逻辑。摄影机只因人物真实行动换跟随对象，不因上一段戏份“演完”而换人。

## 校园关系

午休建立“学校之内的自由”：课堂统一秩序暂时松开后，学生会自然跨班、吃饭、聊天、练习、还东西、去保健室；13:20后由学校日常课前礼仪重新收回班级秩序。

## 飞鸟 / 桥本 / 白石

飞鸟在午休主动跨班到3-B；剧中不解释原因。她与桥本的关系通过事实纠正和低对白熟悉感成立，白石一次真实失笑构成本集明确表演峰值，但不得被拍成固定三人关系展示。

## 松村 / 真夏

松村负责信息流通而非情报调查；真夏负责来源、身份与授权等级核验。榊陵联合安排在本集始终只是未经正式确认的风声。

## 生田

生田在午饭尾声看谱，发现具体小节问题并做记号；随后利用剩余午休去练习室只处理该窄小段落。EP03只建立她的技术 / 正确 / 程序化工作方式，不提前消费EP04的创作冲突。

## 万理华

万理华只在美术侧偶然听见“一人也可以”，产生“我也可以一个人做”的兴趣。她尚未形成展陈路线、作品方案或完整艺术命题。

## 万里小路信息

松村在保健室处理小伤时无意听见：万里小路腿伤，文化祭前能否恢复尚未确定。她未看见本人、不知道诊断，也不记得信息来源；同时会主动纠正别人把“不确定”说成“不能参加”。

## 校园视觉

文化祭相关公共通知继续服从低饱和、统一规格、大留白、整齐版式的校园视觉传达规则；文化祭升温不等于公共空间变成高饱和海报墙。

## 结尾

13:20铃响后，老师进入3-A；号令学生发出 `起立`、`礼`，全班行礼、老师回礼后直接 CUT，不等 `着席`，不加配乐、不加主题总结。
