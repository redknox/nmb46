# EP03《午休》｜Rhythm Review

> 状态：**LOCKED｜STEP 13 PASS。**
>
> 本文件只查整集节奏、重复、气口、注意力刷新与群像点名感；不重新评价单场人物逻辑。

---

# 一、结论

**PASS。**

当前九场的最大优势不是“事件很多”，而是观看任务不断变化：

> 课堂松开 → 排队 → 吃饭 → 关系笑点 → 安静走路 → 门外碎裂练习 → 美术空间停顿 → 保健室小事 → 班级恢复。

因此即使是连续长镜头，也没有连续多段都要求观众处理同一种信息。

---

# 二、时长压力

## S03 / S04｜各9分钟

这是全片最容易纸面短、实拍长的两场。

当前解决方式正确：

- 不加新剧情；
- 不拖慢对白；
- 由真实午饭、旁桌、饮料、包装、座位变化与话题自然冷却承担时间。

判定：**PASS / 制作持续关注。**

## S05｜约4分30秒

几乎无对白，但空间移动本身足够刷新画面：

- 3F向东；
- 楼梯；
- 主楼出口；
- 校园东南侧；
- 别馆进入；
- 内部分岔。

只要正常步速，不会形成“空镜拖时长”。

判定：**PASS。**

## S09｜约7分钟 + 极短铃后书挡

前半还有信息传播；约13:17以后主动降剧情，让学校状态本身成为观看内容。

这不是“没戏了”，而是整集需要的减速。

判定：**PASS。**

# 三、情绪换挡

1. **S01**：秩序松开；
2. **S02**：轻松生活流；
3. **S03**：无用细节喜剧 + 轻信息核验；
4. **S04**：本集最大笑点峰值；
5. **S05**：突然安静；
6. **S06**：工作性、碎裂；
7. **S07**：极轻“动心”；
8. **S08**：创可贴喜剧与画外不确定信息；
9. **S09**：信息又轻轻扩散，随后整体减速回到课堂。

没有连续两段都在情绪上升，也没有“文化祭越来越重要”被做成机械递增。

**PASS。**

# 四、重复动作审查

## 看 / 停

本集大量使用人物“看一下”，但功能不同：

- 松村看面包：消费选择；
- 真夏看纸：信息等级；
- 生田看谱：工作；
- 万理华看空间：可能性改变；
- 石原看手指：专业判断。

未形成同一表演语法的重复。

## 起身 / 离开

因为一镜到底，多个接力都需要人物起身。

当前每次离开的动力不同：

- 买午饭；
- 跨班找朋友；
- 去练习；
- 还物；
- 回主楼；
- 去保健室；
- 回班。

因此不是机械“一个人站起来，镜头换一个人”。

**PASS。**

## 回头

万理华S07只保留一次轻回头。

其他主要人物不重复同样的“离开又回看”动作。

**PASS。**

# 五、笑点密度与类型

主要喜剧：

- 筷子拿错；
- 松村挑面包又拿回第一个；
- 武田老师马甲磨损争论；
- まあ亚“你们为什么知道？”；
- 真夏发现松村的来源一个执行委员都没有；
- 白石真的笑崩；
- 万理华想事情挡路；
- 松村创可贴贴歪；
- “就这个？” / “会痛啊”；
- “谁说的？” / “……不知道。”

类型分散：物件、信息、人物反应、空间、身体、小尴尬。

没有连续使用同一种 punchline。

尤其：

> 白石笑崩允许成为明确峰值；后续没有立刻再安排同等级笑点竞争。

**PASS。**

# 六、文化祭信息重复审查

文化祭多次出现，但每次功能不同：

- S01：学校行政背景；
- S02：人群传闻；
- S03：信息确认等级；
- S04：装饰态度 / 合唱背景；
- S05：校园环境变化；
- S07：万理华个人可能性；
- S08：伤势与未来安排的不确定；
- S09：信息传播。

并非重复提醒“文化祭要来了”。

**PASS。**

# 七、人物露脸均衡审查

本集没有试图让一期主要成员全员出现。

这对节奏是正确的：

- 人物出现由班级、路线、午休习惯与当下事务决定；
- 西野等角色可以只留极低量存在；
- 没有自然理由的人允许休息。

因此没有“每隔几分钟切到另一个成员完成点名”的综艺结构。

**PASS。**

# 八、气口审查

## S05

两人不聊天是有效气口，因为空间、脚步、人流、路线持续变化。

## S06

没有完整音乐，但“弹—停—写—再弹”的工作节奏持续刷新注意力。

## S09后段

没有新剧情，但班级状态不断变化：桌椅、垃圾、教材、人回座。

三处均符合：

> **气口不是没有东西，而是暂时不用处理新剧情。**

**PASS。**

# 九、整集唯一节奏风险

当前最大风险不是剧本，而是实拍时“怕无聊”而过度补东西：

- S05补闲聊；
- S06把琴声做漂亮；
- S07拉长万理华回头；
- S09给松村最后一个主题反应。

这些都会破坏已经成立的换挡。

固定制作原则：

> **不要用额外剧情填满已经被生活承担的时间。**
