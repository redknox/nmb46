## S03｜3-C教室｜LOCKED

**锁定状态：PASS / CLOSED**

### 锁定内容

- 松村进入3-C时，3-C已经自然处于午饭状态；没人停下来欢迎她，她自己找到空隙加入。不得拍成“主角圆桌集合”。
- 武田老师马甲段原样保留为低剧情重量的共同生活证明：高山和松村会注意到口袋位置与旧马甲左侧的**磨损**，但并不因此被写成观察力展示。
- “起球”已永久改为“磨损”。该词强调长期穿用痕迹，而非邋遢，也自然支持武田老师终于换一件近似新马甲的生活理由。
- まあ亚问“你们为什么知道？”后无人回答；不得补解释台词。
- 高山随后重新怀疑“颜色一样吧”，保持她不是第二个松村式信息库，而只是与松村共同记住无用生活细节。
- 西野在本场只以低量存在，不因主要角色身份额外增加评论或点名式对白。
- 松村与真夏的信息处理差异固定：松村知道“大家在说什么”；真夏先核验来源、身份与授权等级。
- 榊陵信息在本场仍不得升级成正式结论。真夏确认两个来源都不是执行委员后只结束核验，不提供正确答案。
- まあ亚必须保留“那榊陵的人以前不能来吗？”与“那哪里不一样？”这一基础逻辑追问。她不是故意装笨，而是在问其他人已经跳过的前提。
- 真夏只回答“正式的还没下来”，不借机向观众解释联合文化祭制度。
- 主楼手机禁用规则与本场完全兼容；“3-A听到半句、食品購買又听到一条”的口耳传播属于学校正常信息生态，不允许用LINE/群聊替代。
- 目标实长约9分钟，属于 TIME LOAD-BEARING 场次。时长必须来自真实吃饭、咀嚼、喝水、拆包装、别桌同时讲话、座位变化、停顿、收拾等午休生活，不得靠演员拖慢对白。
- 普通女生B吃完后只说“我去3-B那边”，同桌只“嗯”。不解释她去找谁；摄影机跟随她，是因为她真的起身跨班。
- 摄影机离开时，高山和松村仍在争马甲颜色，证明摄影机离开不等于3-C生活停止。

## S04｜中央楼梯厅～3-B｜LOCKED

**锁定状态：PASS / CLOSED**

### 锁定内容

- 普通3-C女生因自己的日常关系真实进入3-B，找到普通3-B朋友；“你吃什么？” / “不给。” / “谁要了。”保留。摄影机进入后不再把她当作接力工具。
- 3-B必须始终是完整的三十人教室，普通学生持续吃饭、讲话、换位置；不得为了主要人物关系清空周围环境。
- 卫藤与普通女生关于低年级合唱的对话只作为共同学校生活背景存在：“Alto挺稳的”“合起来也没怎么散”等信息不安排画面证明；随后以“这个谁做的？”自然结束话题。
- 飞鸟已经自然在3-B。没有人问她为什么来，也不解释她是否专门找桥本；观众自行发现这条关系。主楼手机禁用进一步保证跨班移动本身是真实关系行为，但镜头不得因此强调或“请嗑”。
- 白石 / 桥本 / 飞鸟不摆成漂亮三人组。普通同学仍在附近，各自吃自己的。
- 飞鸟关于文化祭装饰的抱怨、桥本“你去年不是做了不少吗”、飞鸟“因为她们做得太丑了”、桥本认真判断后说“也是”，全部原样保留。
- 白石的笑是本段唯一峰值：先噗嗤，飞鸟转头，白石试图忍住却因对上视线更忍不住，只说“对不起……”。不得给飞鸟补“笑什么”，不得让桥本解释或露出洞察式表演。
- 笑过去以后午饭继续，不让周围人为这一刻停下来。
- 生田在S04后段已经接近吃完便当；她自己的座位上，便当袋放在一边，面前摊着谱子。她一边处理最后几口午饭，一边看谱。
- 生田在某个具体小节旁用铅笔做一个很小的记号，再确认一次；不看钟，不说“我要去练琴”。
- 她随后合上谱夹、收好便当，将铅笔随手夹入 / 与谱夹一起拿走，起身离开3-B。其离场因果固定为：**在午饭桌上发现一个需要解决的位置 → 去练习室处理。**
- S06进入练习室后应与此行为连续：直接翻到已有标记的那一页，处理该狭窄段落；不是从曲子开头开始，也不是抽象“利用碎片时间弹琴”。
- 摄影机跟随生田离开，是因为她真的起身去解决谱面问题，不是因为白石 / 飞鸟段落已经“演完”。
- 目标实长约9分钟，属于 TIME LOAD-BEARING 场次。九分钟来自真实午饭、同时发生的班级生活、话题之间的空隙和人物自然动作，不得把卫藤 / 飞鸟 / 生田拍成三段连续展示，也不得靠放慢对白撑时长。
