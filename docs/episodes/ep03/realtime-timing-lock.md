## 3. 时间承重场

### S03 / S04｜TIME LOAD-BEARING

两场各约9分钟，但不得靠演员故意放慢对白完成时长。

时长必须来自：

- 真正吃午饭；
- 咀嚼、喝水、拆包装；
- 普通同学同时讲话；
- 人的座位与身体方向变化；
- 镜头在30人教室里自然失去一个话题、撞上另一个话题；
- 话题结束以后生活继续，而不是立刻切换下一段台词。

固定警告：

> **S03不能拍成综艺圆桌；S04不能拍成主角展示柜。**

若将来实拍 / 桌读后两场仍明显短，优先补本来就会发生的午休生活，不新增剧情任务。

## 4. S05｜真实空间时间

高三教室关系：

> 西 ← 3-A | 3-B | 中央楼梯厅 | 3-C | 3-D → 东

生田从3-B向东，经过3-D附近遇万理华，再使用东端楼梯下楼，离开主楼，经校园东南侧到音乐・美术别馆。

目标约4分30秒。

不得：

- 把3F到别馆压成数秒蒙太奇；
- 用慢动作或配乐把普通走路拍成青春MV；
- 为了填时间安排两人无必要的谈心。

## 5. S06｜门外短练习锁

生田到练习室时，午休只剩约17分30秒；她还必须在13:20前返回3-B，所以可实际用于练琴的时间只剩十来分钟。

因此这不是完整练习，而是：

> **只处理一个狭窄段落的短时高密度练习。**

动作语法：

> 弹几秒 → 停 → 看 / 标 → 再来 → 更短地停 → 单独确认局部 → 重来。

不得从曲首完整演奏。

摄影机留在防音练习室外，通过正常观察窗观看。

声音锁：

- 无额外配乐；
- 不把钢琴声作为可欣赏的音乐素材；
- 门外最多只允许极弱、不可形成完整旋律的闷响；
- 观众的注意力集中在身体、谱、铅笔、停止与重启。

内部理解：

> 她现在练的东西本来就“不好听”——重复、断裂、局部、工作性很强。因此门外观看既解决一镜到底的物理接棒，也避免把短练习错误美化成演奏场。

摄影机不等她练完。万理华从美术侧重新进入走廊生活时，摄影机自然离开观察窗；生田继续在玻璃后练。

## 6. S08｜别馆→主楼时间校准

艺术别馆位于校园东南侧；保健室位于主楼1F东翼E2，因此两者本来就是近邻方向。

固定理解：

> **从美术侧离开到进入主楼东翼约1分30秒上下，不是5分钟长途移动。**

S08整场约4分钟，其中真正的连接移动只占约1分多钟；其余时间来自路线交叉与松村在保健室自行处理轻伤。

## 7. S09｜午休如何结束

S09约13:13开始。

松村从1F东翼返回位于3F西翼的3-A，本身需要真实跨楼层、跨楼翼时间。

约13:15左右回班后：

- 创可贴闲聊；
- 万里小路信息传播；
- 约13:17后剧情主动减弱；
- 最后两分多钟主要看3-A从午休状态重新恢复为课堂状态。

允许存在没有新剧情任务的时间，但画面必须仍有生活输入：

- 人从别班回来；
- 最后吃两口；
- 丢垃圾；
- 桌椅转正；
- 借文具；
- 拿下一节教材；
- 站在别人座位的人让开；
- 最后聊天的人各自归位。

13:20铃响。

固定理解：

> **午休不是被剧情结束的，是被学校结束的。**

## 8. 当前不加戏原则

当前九场在真实移动、真实吃饭节奏和班级生活成立的前提下，可以承担完整50分钟。

因此现阶段：

> **不为“保险”新增剧情场。**

只有未来桌读 / blocking rehearsal 证明自然表演仍有明确时长缺口时，才重新评估；届时优先补真实校园生活，不新增冲突或人物弧。
