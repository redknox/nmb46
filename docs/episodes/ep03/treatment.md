# 一、全局执行原则

## 1. 时间

12:30—13:20连续50分钟。

演员不机械踩秒，但每一段必须能在真实时间里成立。

## 2. 摄影机

摄影机永远跟随**真实行动**，不跟随“戏份结束”。

固定：

> **行为先发生，摄影机才有理由移动。**

## 3. 群像

主要角色周围不得清空普通同学。

3-C / 3-B尤其必须保持30人班级午休的生活密度。

## 4. 声音

现实声优先：

- 椅脚；
- 饭盒；
- 包装；
- 咀嚼 / 喝水；
- 走廊人声；
- 楼梯脚步；
- 门；
- 防音门外轻微琴声；
- 保健室用品；
- 13:20铃声。

S05 / S06 / S07 / S09结尾不靠配乐制造意义。

## 5. 视觉

校园可以漂亮，但普通行动不包装成MV。

文化祭公共通知遵守 `docs/world/campus-visual-communication-lock.md`。

# 二、S01｜3-A｜约3:00

### 空间状态

第四节最后几十秒仍是课堂朝向。

### 动作层

- 老师仍在黑板前；
- 学生已经出现“快下课”的微动作：笔袋、钟、便当袋；
- 铃响后才真正松开；
- 老师边收教材边补执行委员班务；
- 主要角色不抢反应；
- 筷子拿错必须像真正的小事故，不演完整段子；
- 松村等一下发现话题没回来，就自然拿钱包离开。

### 道具

- 黑板 / 教材；
- 笔袋；
- 便当袋；
- 筷子盒；
- 松村钱包。

### 声音

铃声后立刻出现拉链、书本、椅脚等课堂散开声。

### 接力

松村真实起身去买午饭。

# 三、S02｜食品購買｜约7:00

### 路线

3-A → 西端路线 → 食堂棟入口。

### 动作层

- 真实午休队伍逐步移动；
- 松村至少有一次“拿起—看—放回—换一个—最后拿回第一个”的选择过程；
- 榊陵对话发生在排队过程中，不为对话停止队伍；
- 女生C轮到结账以后，话题就结束；
- 松村付款后立即回主楼。

### 人群

队伍里其他学生必须真的购买、结账、让位，不做静态背景。

### 道具

面包 / 饭团 / 饮料等普通轻食；不需要品牌展示。

### 时间承重

主要由步行、排队、商品选择与结账承担，不靠延长榊陵对话。

# 四、S03｜3-C｜约9:00｜TIME LOAD-BEARING

### 空间状态

摄影机进入时午饭已经开始一段时间：

- 椅子方向不统一；
- 有人挪到朋友旁边；
- 有人仍在自己的位置；
- 真夏桌上同时有午饭与几张纸。

### 松村进入

没人停下来迎接。她自己找空隙放东西、开始吃。

### 武田马甲段

表演重点是两人真把它当普通话题，而不是“设计好的笑点”。

旧马甲关键词固定：

> **左边那块以前有点磨损。**

不使用“起球”。

### まあ亚

她问“你们为什么知道？”后，真的等了一会儿；别人已经回到争论，不专门给她答案。

### 真夏信息核验

纸张必须离食物保持自然距离；松村靠近时真夏可以把纸往自己方向挪一点防止碰到面包。

核验顺序清楚但语速正常，不拍成审问。

### 时间承重动作

对白之间允许：

- 真吃；
- 咀嚼；
- 拿饮料；
- 擦手；
- 包装声；
- 旁桌插话；
- 人经过；
- 短暂无主要对白。

禁止通过演员慢念台词制造9分钟。

### 接力

普通女生B已经吃完，拿饮料说去3-B。她离开时不解释找谁。

摄影机跟走；身后高山 / 松村仍继续马甲争论。

# 五、S04｜3-B｜约9:00｜TIME LOAD-BEARING

### 入场

普通3-C女生进入后，直接找到自己的3-B朋友。

“你吃什么 / 不给 / 谁要了”之后她留下，但摄影机不再把她当中心。

### 班级层

至少同时保持：

- 普通学生吃饭；
- 有人换座；
- 有人站着说话；
- 卫藤一带话题；
- 飞鸟 / 桥本 / 白石一带；
- 生田自己处理午饭和谱面。

### 卫藤层

低年级合唱只通过已有话题碎片出现。

不得切入低年级排练画面，也不得让卫藤解释制度背景。

### 飞鸟 / 桥本 / 白石

不得摆成正面三角构图。

桥本的“也是”必须像真的重新判断，不是反讽。

白石笑的动作顺序：

> 先噗嗤 → 想忍 → 对上飞鸟视线 → 更忍不住 → 低头笑 → “对不起……”

不追加飞鸟“笑什么”、桥本懂王反应或周围同学停下来。

### 生田层

便当已经到尾声。

谱夹在桌上，便当袋在旁。

她吃完最后几口时仍看谱；视线停住后：

> 铅笔小记号 → 再确认 → 合谱夹 → 收便当 → 铅笔夹入 / 与谱夹一起拿起 → 起身。

不看钟，不说自己去哪。

### 接力

摄影机跟生田离开。

# 六、S05｜去音乐・美术别馆｜约4:30

### 行走速度

正常学生赶一个午休目的地的速度，不散步、不小跑。

### 万理华进入

她从3-D出来时已经拿着要还到美术侧的东西。

不明确物件类型，避免道具变成剧情机关。

### 同行

只保留：

> “练习？” / “嗯。” / “我也去那边。”

之后原则上无对话。

### 路上

- 迎面学生需要正常避让；
- 开门 / 下楼 / 转弯按真实空间完成；
- 可以经过文化祭材料；
- 公共通知低饱和、整齐、统一；
- 人物不驻足看公告栏。

### 摄影纪律

禁止：

- 慢动作；
- 正面长距离美少女行走；
- 逆光发丝；
- 抒情BGM；
- 公告栏文化祭特写蒙太奇。

### 分流

别馆内部音乐 / 美术分岔时，只轻微视线 / 身体回应，不说拜拜。

# 七、S06｜音乐练习室走廊｜约3:30

### 制度动作

利用表必须可见为日常设施，不做说明镜头。

生田：

> 看 → 确认空档 → 简单登记 → 进房。

### 摄影机位置

防音门关闭后，摄影机留走廊，通过功能性观察窗看。

观察窗不得成为漂亮画框；人物被窗框部分遮挡也可以。

### 生田练习程序

- 看一次墙钟，非特写；
- 放东西；
- 打开谱夹；
- 直接翻到已标记页；
- 调琴凳；
- 开始短段练习。

节奏：

> **弹 → 停 → 看 / 写 → 再弹 → 更短 → 停 → 单独确认 → 重来。**

### 声音

无配乐。

门外钢琴只能是轻微闷响，永远不能形成一段完整可欣赏旋律。

### 接力

摄影机离开时生田仍练，不给她“完成”动作。

# 八、S07｜美术侧｜约3:00

### 起点

万理华已还完东西，转身要走。

### 规则信息

普通女生与满岛对话已经发生在她身后。

满岛一边整理材料一边回答，不正对万理华主持信息。

万理华听见“一人也可以”时：

> 身体先停 → 半拍 → 才转回去。

她只复述关键词。

### 看空间

允许她看：

- 墙；
- 展示板；
- 空位置；
- 材料。

但动作不能像：

- 测量；
- 规划路线；
- 看入口 / 出口；
- 安排作品顺序。

### 现实打断

抱材料女生此前已经属于空间人流。她来到通道，只说“借过一下”。

万理华立刻让开。

回头只一眼，不配乐、不反打命运空墙。

### 接力

摄影机跟抱材料女生走。

# 九、S08｜回主楼＋保健室｜约4:00

### 路线

抱材料女生正常返回主楼东翼，在自己的路线处分开。

松村从另一方向进入。

交叉不能演成接棒：不对视、不停顿。

### 松村手指

一根手指略微抬着即可，不夸张捂手。

不解释伤口来源。

### 保健室进入

入口先到工作 / 处置区。

松村轻会釈，“老师……”

石原：看人 → 看手指 → 确认小伤 → 眼神示意用品。

松村再往里一两步，才有条件看到三个床位帘子都拉着。

### 创可贴动作

必须完整：

> 消毒 → 缩一下 → 撕包装 → 对准 → 贴 → 看 → 有点歪 → 揭一点 → 重新压 → 最后压角 → 确认正了。

### 万里小路信息

声音在画面边缘 / 画外发生。

松村：

- 不停；
- 不抬头；
- 不侧耳；
- 不眼神变化。

摄影机也不rack focus提示重要性。

石原只说尚不确定、等磯村老师看过。

### 接力

松村处理完手指、道谢、会釈，离开回班。

# 十、S09｜回3-A＋午休结束｜约7:00

### 路线状态

松村上楼时，人流方向与开场相反。

视觉上逐渐出现：

- 空饭盒；
- 下午教材；
- 跨班学生回流；
- 教室桌椅复位。

### 信息段

松村回班后：

1. 先处理自己的手指话题；
2. 再提三床都满；
3. 才想起万里小路；
4. 对“不能参加”立即纠正；
5. 被问来源后真实搜索失败。

“……不知道”不演成预备好的笑点。

### 最后两分多钟

摄影机逐渐失去松村，观察整个3-A恢复：

- 回座；
- 转椅子；
- 最后吃两口；
- 扔垃圾；
- 借修正带；
- 问下一节；
- 拿教材。

### 13:20

铃响后不是立刻军训式齐刷刷静止。

老师进入，残余午休声自然落下。

负责号令学生看老师，正常发令：

> “起立。”
>
> “礼。”

三十把椅子产生真实椅脚声。

学生行礼，老师回礼。

**CUT。**

不等“着席”。
