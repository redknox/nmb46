# 一、结论

**PASS。无结构性现实 / 制度 RED。**

EP03可以被理解为乃木坂女学院某个普通上课日真实发生的一次完整午休：

> **12:30 第四节结束 → 13:20 第五节开始。**

人物在50分钟内完成的吃饭、跨班、下楼、购买、跨建筑、练习、还物、去保健室与回班动作，在当前校园空间与制度中均有足够时间与真实目的。

本集不存在必须依赖：

- 手机瞬时通信；
- 人物传送；
- 校方为主角临时开放特权；
- 不合理的医疗判断；
- 为了剧情临时出现的校园设施；
- 不符合既定公共视觉规则的文化祭宣传环境

才能成立的因果。

# 二、午休制度与50分钟时间轴

权威时间文件：

- `docs/episodes/ep03/realtime-timing-lock.md`

固定：

- 12:30 第四节结束 / 午休开始；
- 13:20 第五节开始；
- 午休共50分钟；
- 不设置额外预备铃。

九场目标时长合计50:00：

| 场次 | 时段 | 时长 |
|---|---|---:|
| S01 | 12:30–12:33 | 3:00 |
| S02 | 12:33–12:40 | 7:00 |
| S03 | 12:40–12:49 | 9:00 |
| S04 | 12:49–12:58 | 9:00 |

### 判断

成立。

### 制作边界

不得在后期通过传统蒙太奇压缩这些已被时间轴承担的实际移动，否则会破坏本集“50分钟真实流逝”的制度基础。

上位世界文件：

# 四、食品購買

上位世界文件：

- `docs/world/cafeteria-food-shop-lock.md`

食品購買正式定位：

> **食堂棟附属・食品購買。**

它位于主楼西侧邻近食堂棟入口区域，不在主教学楼内部。

S02因此必须真实包含：

> 3-A / 3F西翼 → 西侧楼梯 → 主楼生活侧出口 → 食堂棟入口 → 食品購買。

午休最初数分钟形成队列符合既定运营逻辑。松村买面包后可以直接返回主楼，不必进入食堂正餐区。

### 判断

成立。

7分钟足以覆盖短距离跨建筑、排队、挑选、结账与返回高三楼层；同时不应把食堂棟夸张成远距离校园穿越。

# 六、音乐・美术别馆与练习室使用

本集既定制度：

- 音乐练习室属于教学 / 练习空间；
- 使用前查看 `練習室利用表`；
- 确认空档并做简单登记；
- 生田不是因为身份特殊而免程序；
- 别馆属于私人手机严格限制区域。

S06生田：

> 看利用表 → 确认空档 → 简单登记 → 进入小型防音练习室。

此流程与项目一贯的“资源充足但制度真实”一致。

生田只处理一个窄小段落，不进行整首演奏；她在摄影机离开后继续练习，因此画面观察3分30秒不等于她实际只练3分30秒。

### 判断

成立。

不存在“午休剩余时间不够却完成一整套正式练习”的时间夸张。

# 七、主楼1F保健室与医疗职责

上位世界文件：

- `docs/world/main-building-1f-infirmary-lock.md`

保健室固定于主楼1F东翼E2，内部包括：

- 養護教諭工作 / 简单处置区；
- 约3床休息区；
- 小型诊察 / 健康咨询空间；
- 日常健康用品与简单处置用品。

入口首先到达工作 / 处置区，不直接暴露床位。

因此S08：

> 松村入室 → 石原先看到她与手指 → 松村再往里一两步看到三个床位帘子都拉着

空间成立。

### 石原里美｜養護教諭

她可以：

- 观察学生状态；
- 判断小伤可由学生按熟悉流程自行消毒 / 贴创可贴；
- 管理休息床位与日常记录；
- 对更具体医学判断保持边界。

她看到松村手指后示意用品位置，不是冷淡，而是在完成专业观察后让熟悉流程的高三学生自行处理极小伤口。

### 磯村勇斗｜学校医

关于万里小路：

> “现在还不知道。等磯村老师看过再说。”

这一句合理保持职责边界：養護教諭不在信息不足时承诺恢复日期，需要进一步医学判断时等待学校医。

### 判断

成立。

剧本没有诊断万里小路具体伤情，也没有让松村看到本人或获得超出现场可听范围的信息。

# 八、公共通知与文化祭视觉环境

上位世界文件：

- `docs/world/campus-visual-communication-lock.md`

文化祭临近不等于校园公共信息系统变成高饱和海报墙。

S05只允许：

- 通知数量比平时略多；
- 规格统一；
- 低饱和；
- 版式克制；
- 排列整齐；
- 学生抱着文化祭材料正常经过。

摄影机不为公告栏停留，也不需要观众读清具体内容。

### 判断

成立。

文化祭的升温通过“信息更多 / 人更忙”表现，而不是让学校突然失去长期视觉秩序。

# 十、一镜到底的物理可执行性

本集连续路线：

> 3-A → 西侧食品購買 → 3-C → 3-B → 3F东翼 / 东端楼梯 → 校园东南侧 → 音乐・美术别馆 → 音乐侧 → 美术侧 → 主楼1F东翼保健室 → 3-A。

关键接力均有独立行为理由：

- 松村去买午饭；
- 普通3-C女生去3-B找普通朋友；
- 生田去解决谱面问题；
- 万理华去美术侧还东西；

- 松村因手指小伤去保健室；
- 午休末尾松村回3-A。

### 判断

**物理与行为双重成立。**

不存在需要角色为了摄影机折返、等待或无理由改变目的地的接棒。
