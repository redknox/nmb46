# 五、EP03 新增 / 固化的项目级事实

EP03 FINAL 后，以下事实可以被后续剧集直接引用：

1. **午休关系原则**：没有制度指定对象时，人物的主动移动本身可以成为关系信息。
2. **主楼手机规则的剧作结果**：人物需要实际去找人；手机不能替代跨班 / 等待 / 问人。
3. **飞鸟 → 桥本**：已实际使用一次高心理成本主动跨班，但关系没有被解释或升级。
4. **松村信息机制**：事实碎片保存能力高、来源记忆可以低；不会故意把不确定说成确定。
5. **真夏信息机制**：来源 → 身份 → 授权等级 → 信息等级。
6. **生田 EP04 前置**：技术 / 谱面 / 局部纠错 / 程序化练习已经可见。
7. **万理华 EP04 前置**：个人展示兴趣已经出现，但未形成方案。
8. **校园视觉传达**：公共通知低饱和、整齐、克制；文化祭升温不等于公共信息系统失序。
9. **EP03 结尾语法**：学校可以用每天重复的日常制度产生仪式感，不需要主题台词或配乐替作者划重点。
