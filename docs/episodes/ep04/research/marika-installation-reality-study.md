# EP04｜万理华大型装置现实化研究

> 状态：**REFERENCE。**
>
> 用途：为 EP04 伊藤万理华的文化祭大型装置提供现实尺寸、材料、制作与安装基线。本文不是 Beat Sheet，也不锁场次顺序；具体剧情以 `episode-brief.md` 及后续权威文件为准。

## 一、现实参考的共同结论

高校级别的大型 installation 完全可以达到“人能进入 / 穿行”的尺度，而不需要把学生写成重工业技师。

现实高中艺术项目常见的可行策略包括：

- 轻型框架；
- 木材、塑料瓦楞板、薄膜、布、线材等低重量材料；
- 模块化制作；
- 现场组装；
- 承重 / 固定部分由教师、设施人员或专业人员确认；
- 视觉尺度大于单件构件的物理重量。

因此“视觉上很大、工程上很轻”是最适合本剧的现实方向。

## 二、现实艺术语言参考

### Do Ho Suh｜空间 / 半透明 / 可穿行

参考点不是作品主题，而是空间语法：

- 半透明材料；
- 轻型结构；
- 人可以进入空间内部；
- 身体、前后层与其他观众会透过材料叠在一起。

不复制其“家 / 记忆”等主题。

参考：Smithsonian American Art Museum, *Do Ho Suh: Almost Home*。

### Felice Varini｜特定视点 / 离开视点后碎裂

参考点：

- 一个完整形状分布在多个空间表面；
- 站在特定位置时突然拼成完整图形；
- 离开该位置以后，图形重新变成散落碎片；
- 非理想视点也仍然构成观看的一部分。

不复制具体圆形、色彩或墙面绘画形式。

## 三、万理华装置 V0｜当前现实基线

### 空间尺度

建议展示区域约一个小教室 / 独立展区尺度，例如约 6m × 4m 量级；实际后续按乃校美术展示空间校核。

### 构件

约 8—10 个竖向框架：

- 高约 2.0—2.2m；
- 宽约 70—100cm；
- 木框或轻型金属框；
- 中间蒙半透明薄纱、网布、磨砂薄膜等；
- 前后错位、角度略有差异；
- 采用低矮稳定底座 / 隐藏配重；
- 拆成可通过普通门洞的模块，在展示空间内完成最终组装。

不需要由万理华本人进行焊接或驾驶叉车。

### 视觉机关

每层半透明表面只承载完整图形的一小块碎片。

从设定的入口 / 理想观看点看：

> 多层碎片叠成一个完整、安静、非具象或弱具象的形。

向前移动一步以后：

> 完整形迅速破碎。

观众进入层与层之间后：

- 只剩局部线、面、透明层；
- 其他观众的身体也会隔着多层材料进入画面；
- “看作品”变成“身体进入作品”。

## 四、作品核心与可修改项

### 当前认为不能丢的核心

> **在一个位置上，碎片成为一个整体；身体移动以后，它又重新碎掉。**

### 可以修改的实现方法

- 具体框架距离；
- 每层角度；
- 每块碎片的形状；
- 框架是否上下拆分；
- 底座形式；
- 配重方式；
- 材料具体品类；
- 安装顺序。

这使 EP04 的制作冲突可以落到：

> **保护作品核心，不等于保护第一版施工方案。**

## 五、1:1 放样时自然出现的现实问题

小比例模型里没有真实观众，因此第一版很可能过于紧密。

放到 1:1 尺寸后，自然出现：

- 单人能过，不代表背书包的人能舒适通过；
- 双向人流可能互相堵住；
- 观众停留观看会影响后续通过；
- 衣物 / 包容易擦碰作品；
- 疏散与可达性需要更合理净宽；
- 框架过高 / 过长后整件无法通过门洞或转角；
- 独立框架需要稳定底座和配重；
- 半透明薄膜会起皱、拉不平或在施工中损坏；
- 理想视觉位置与现实人流需要重新协调。

这些问题不需要设置“不懂艺术”的老师。

## 六、建议保留的普通制作麻烦

为了避免万理华线成为“主题闯关”，至少保留一类纯倒霉、无人生寓意的问题，例如：

> 框架整体钉好后发现搬不进门，只能重新拆成上下模块，在展区内组装。

这类麻烦只负责证明：

> **做大型东西本来就很麻烦。**

## 七、制作技能现实边界

万理华可以合理亲手完成 / 参与：

- 测量与放样；
- 木材切割（在学校设备与指导范围内）；
- 钻孔；
- 螺栓连接；
- 薄膜 / 布料安装；
- 表面处理；
- 模块拼装；
- 视点定位；
- 反复调整框架位置；
- 轻型构件搬运。

需要成人 / 设施人员介入确认的部分：

- 高处吊挂；
- 关键承重点；
- 大型钢制底座；
- 结构稳定性；
- 消防 / 疏散 / 无障碍硬要求；
- 专业焊接或其他高风险作业。

叉车如世界里出现，只应由受训后勤 / 专业人员驾驶，不需要让万理华本人操作。

## 八、西野与 EP05 接口硬约束

EP04 制作阶段：

- 西野可以帮万理华扶框、搬动、等待；
- 她不负责解释作品；
- 她不提前发现“出口方向也成立”；
- 她甚至可以一直处在框架旁边，所以根本没机会站到万理华的理想观看点完整看作品。

EP05 必须保留新的发现：

- 一年级观众从原本“出口”进入；
- 万理华第一次主动绕到那个方向重新看；
- 西野经过后才第一次与她共享这个反向视点；
- “从这边也看得见呢”仍然是当下新发生的观看经验。

## 九、写作纪律

不要让作品变成一份作者已经解释完毕的艺术论文。

万理华当前完全可以只知道：

> **“站在这里是一个东西，走过去就不是了，我觉得这样很好。”**

观众可以从后续作品、身体、空间与观看方式里长出更多意义，但人物不需要提前替作品完成策展文字。
