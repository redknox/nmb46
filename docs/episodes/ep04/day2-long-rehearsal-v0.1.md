## DAY 2｜音乐与美术别馆・合唱排练室｜AFTER SCHOOL

钢琴已经打开。

高三部员按 S1、S2、A1、A2 的位置站好。

松隆子坐在排练室一侧。腿上有自己的总谱和铅笔。她不在指挥位置。

昨天旁听的低年级部员仍然坐在后方。

堀也在那里。

她手里多了一份谱。

正式合练开始前十几分钟，松下本人已经把这张短谱直接交给她，只说让她先看一下。这件事不进入正片；短谱只包含她完成试唱所需的材料，不包含稍后在排练中才长出来的四拍连接。

谱不是全新的。几个位置已经有铅笔括号。

没有人介绍她。

松下站在谱架前，翻到第一页。

**松下**
从开头走一次。

生田把手放上琴键。

松下抬手。

### 原版通奏

钢琴 opening 开始。

昨天已经确认过的声音。

节奏、和声方向、空间里的第一层共鸣都很清楚。

松下给出进入。

高三 SSAA 一起开口。

四个声部没有抢着寻找彼此。第一个和弦出现时，彼此的位置已经在里面。

音乐继续。

中元唱自己的 S2 线。S1 的旋律从她上方经过，她没有跟过去。

A1 接住中间的重量。

A2 在下方保持住和弦的底部，不额外加重。

走到松下事前指定的位置。

他收手。

声音停下。

钢琴余音过去。

松下看了一眼谱。

**松下**
好。

有人轻轻换一口气。

松下没有马上翻到下一段。

**松下**
昨天这个版本已经可以演。

他重新翻回第一页。

**松下**
我想改一下开头。

排练室里没有议论。

几支铅笔从谱页上抬起来。

**松下**
昨天听下来，前面太快完整了。

他看向生田。

**松下**
生田一开始。然后你们进去。声音马上就成立了。

停一下。

**松下**
这没有问题。

他看着谱上合唱第一次进入的位置。

**松下**
但我想让它晚一点成立。

一名高三 S1 部员低头确认小节。

**S1部员**
晚多少？

松下也低头看谱。

**松下**
不是时间上的晚。

他说完，又停住。

翻回前一页。

**松下**
结果可能会晚几拍。但我说的不是拍数。

他抬头看四个声部。

**松下**
你们现在一开口，就会马上听见旁边，然后调整。

手指很轻地在谱架边缘点了一下。

**松下**
音准、元音、谁出来一点、谁退回去。很快。

**松下**
所以第一个和弦一出来，就已经是你们的声音了。

几个人低头看自己刚才标过的 balance 记号。

**松下**
这次我想让前面先不要到那里。

他转向后方。

**松下**
堀。拿谱过来。

堀已经拿着谱起身。

她从旁听区域出来，走到钢琴和 S1 之间。

松下指向谱上已经画过括号的一小段。

**松下**
从这里。

手指往下移。

**松下**
唱到这里以后，不停。把最后一个元音留到我收。

**堀**
到这里吗？

她指的位置早了两拍。

**松下**
再两拍。

堀把括号延长。

**松下**
不要自己拉速度。看我的手。

堀点头。

生田看着自己的谱。

**生田**
我前面照原来的？

**松下**
对。opening 不改。

他转向高三。

**松下**
堀结束以后，S1 从原来的进入处接。其他声部跟我的手。

中元在 S2 的进入位置做记号。

**中元**
S2 还是这里？

**松下**
先照原来的。

松下环视一遍。

**松下**
先试一次。

### 第一次试唱｜先听见变化

生田重新开始正式 opening。

没有为了堀把它弹薄，也没有加提示性的停顿。

原来的最后一个钢琴音留在房间里。

松下给堀。

堀进入。

第一声很快出来。

音准进入以后，她的声音没有先去找后面的 S1，也没有为了融进去改变轮廓。

她唱完短句。

最后一个元音延长。

松下的左手让她留住，右手给 S1。

S1 接进来。

随后 S2、A1、A2 依次进入。

成熟的 SSAA 从她身后形成。

音乐继续了几个乐句。

松下收手。

所有人停下。

堀仍然站在 S1 前侧一点的位置，等下一项指示。

中元先看一眼自己的谱，又看向松下。

**中元**
为什么是堀？

她的手指仍停在 S2 刚才的进入处。

松下看了一眼堀，又看回高三四个声部。

**松下**
昨天她唱练习的时候，第一声出来得很快。

他重新找了一下说法。

**松下**
不是抢。也不是起得重。

**松下**
她不等旁边有人先给她位置。

堀低头看自己的谱。

松下继续。

**松下**
音准进去以后，声音还是单独站着。

他转向高三。

**松下**
你们不会这样。

短暂停顿。

**松下**
你们一开口就会互相调整。很快。

又停一下。

**松下**
太快了。

几个高三部员看着他。

松下手指落回原版合唱第一次进入的位置。

**松下**
所以原来的开头，进来以后马上就已经是你们了。

手指再移到堀的括号。

**松下**
我现在想让前面先不是。

中元看向刚才的 S2 进入位置。

**中元**
那我们进去以后，要跟她的声音吗？

**松下**
不跟。

他指 S2。

**松下**
你们照原来的位置。第一个音不要往上找 S1，也不要把元音做得像她。

中元点头，在谱上补记。

**松下**
只是别一下全给出来。

他转向 S1。

**松下**
S1 接到以后，旋律先不要做成完成句。线往前，音量留着。

再转向 A1。

**松下**
A1 第一口气不要加厚。等 S2 进去以后再把中间连起来。

最后是 A2。

**松下**
A2 不要急着把底下坐实。第一个和弦只给音高，不给重量。

A2 部员在谱上做记号。

松下看向堀。

**松下**
你唱完以后，下一处并进 S1。

**堀**
这里进去？

**松下**
对。先听 S1 的呼吸，再进。

堀把位置圈出来，退到 S1 外侧的临时位置。

**松下**
再来。

### 第二次试唱｜作品出现新的问题

钢琴 opening。

堀的第一声。

这一次，高三没有在第一口气里把所有声音都给出来。

S1 接住线，却没有马上把它唱成完整旋律。

S2 守住自己的音。

四声部逐渐形成。

松下让她们继续。

几个小节以后，他收手。

### 第三次试唱｜新版本开始成立

## 本稿当前音乐设计逻辑

本稿暂用以下进入顺序证明排练因果，待剧内作品创作后再换成精确音符：

1. 原版：`钢琴 opening → 高三 SSAA 同时进入`；已经成熟、可以正式演出。
2. 松下最初修改：`钢琴 opening → 堀短 first voice → S1 接句 → S2 / A1 / A2 形成`。
3. 实际排练发现：S1 直接接句会过快把堀的独立轮廓收入成熟 ensemble。
4. 现场新修改：`堀结束 → 生田四拍连接 → S2 先进入 → S1 → A1 → A2 → 堀并入 S1`。
5. 生田四拍经历三次真实迭代：
   - 第一次：只收到“接一下”，准确接住和声后停止；
   - 第二次：增加“四拍”，完成清楚而稳定的 voice leading；
   - 第三次：增加“不完全落地 / 保留上方音 / S2 cue”，立即完成新版本。
6. 松下决定把四拍正式写入谱面，是因为该版本需要在正式演出中稳定复现；不是因为他判断生田能力不足。

## 后续音乐设计必须回答

- 剧内作品的拍号、速度与调性；
- 生田 opening 的实际长度与 harmonic identity；
- 堀短句的歌词、音域、起音、尾音与呼吸位置；
- 为什么她的尾音可以同时成为钢琴四拍连接的上方保留音；
- S2 新进入音在和声中的功能，以及为什么它能够先于 S1 独立出现；
- A1 / A2 后续进入怎样补全和弦而不显得是机械叠罗汉；
- 四拍连接如何无缝回到原作正式伴奏；
- 无堀版本如何直接恢复原版，且不留下结构缺口。

## 表演与剪辑硬约束

- 松下说得较长，是因为所有人要据此改变唱法；不给演讲式正面中心构图。
- 他的语言允许停顿、翻谱、改口和边听边修正；不提前准备主题金句。
- “为什么是堀？”发生在中元已经亲自唱过、听到差异以后。
- 中元问完即继续处理 S2 工作；不拍竞争、委屈或自我安慰反应。
- 堀只问自己的长度、进入、呼吸与并部位置；不解释自己为什么特别。
- 生田第一次停止时，不给卡壳特写、环境抽空、紧张配乐或他人交换眼神。
- 每增加一个条件，生田都在下一遍立即做到；剪辑必须保留这个连续证据。
- 松隆子全程可以听、记、观察作品，但不替松下翻译，也不在本场发现或诊断生田的问题。
- 休息前的空气是“今天做出了更好的版本”，不是“大家隐约察觉生田出事了”。

> **音乐本身在工作，剧情从工作里面长出来。**
