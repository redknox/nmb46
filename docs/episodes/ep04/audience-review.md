# 十三、关键误读测试

## 误读 1｜生田不会即兴，所以被送去补课

正片持续证明她技术、听觉与 ensemble 配合都很强，正式演出也完全不受影响。Fukase 的到来不是补救失败，而是让她接触学校既有专业教育之外的工作方式。

**GREEN。**

## 误读 2｜中元因为堀加入而受到威胁

观众会感到她对位置变化格外敏感，但她随即进入声音、balance 与 S2 的具体工作。正确的不完整是：她意识到位置发生变化，并认真确认自己的角色；此时不必命名“定位问题”。

**GREEN，依赖克制表演。**

## 误读 3｜Fukase 的方法无效，最后由松隆子解决

剧本因果不是如此，但表演层级与剪辑强调可能制造错误理解。Fukase 所说的每件事都真实、准确；正因为生田听懂了，世界才突然大得无法进入。松隆子提供的是第一次尝试的容器，不是对 Fukase 的修正。

**制作 YELLOW，不补对白。**

## 误读 4｜万理华因为模型被名人看中而得到肯定

万理华没有惊喜、解释作品或因请求改变工作；Fukase 被拒绝后也不以夸奖补偿。模型请求不是人物认证。

**GREEN。**

# 十四、重复与观看节奏

opening 的累计重复尚未构成听觉疲劳：

- S01 完整听见原版一次；
- S04 再完整进入一次，后续主要反复局部连接；
- S05 用正式替换页作一次短确认。

每次重复承担不同观看任务：先证明原版成立，再看作品改变，最后确认正式版本。后续局部反复必须依靠真实音乐差异刷新观看，不为避重复而删除排练劳动。
