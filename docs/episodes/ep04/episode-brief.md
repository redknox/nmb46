# EP04《音乐室》｜Episode Brief

> 状态：**LOCKED / Gate 0 PASS。**
>
> 本文件只记录编剧室已经确认的 STEP 0 成果与明确保留项；尚未进入 Beat Sheet，不把示例对白、具体场次顺序或未讨论完成的桥段视为锁定。

## 一、本集为什么存在

EP04 让 EP03 已经成立的人进入文化祭准备这一组新的现实条件，观察她们原本很好用的生活方式，第一次在哪里不够用了。

当前母命题：

> **有些问题有正确答案。**
>
> **有些问题没有。**
>
> **真正困难的是分辨自己现在面对的是哪一种。**

补充约束：

> **正确有它真正负责的事情；但有些事情，正确没有权限替你决定。**

禁止把本集写成“技术 / 规则不好，自由 / 感觉才好”。

## 二、表层事件

文化祭从 EP03 午休里被谈论的事情，逐渐成为真实的制作劳动：音乐排练、装置制作、联合舞台项目、尺寸确认、搬运、场地与流程协调开始占据校园空间。

本集不追求“大事件”。重点是：很多东西第一次真的被做出来。

## 三、生田绘梨花｜当前主推进线

### 起点

松下在成熟高三 SSAA 原版上加入堀的 optional first voice 后，需要重新处理“堀唱完以后，怎样把音乐交回高三 ensemble”这一真实编排问题。

排练中，他以专业指挥面对成熟演奏者时本来就会使用的简短工作语言，要求生田在堀之后先连接一段，再由自己把 S2 带进来。具体术语和台词留到场景 / 拉片阶段确认。

生田不会突然慌张，也不会表现成弹不出来。她会立刻做出一个音乐上完全正确的连接，例如准确接住堀最后声音的和弦，然后停止，等待下一项明确条件。

第一次出现的新问题不是“我不会弹”，而是：

> **当别人没有把选择写完时，我到底应该根据什么继续？**

### 松下第一次碰到生田的开放段落｜LOCKED CAUSAL MECHANISM

当前锁定以下因果，不锁最终对白：

1. **松下先把它当作自己的指挥信息不够。** 生田在一个正确和弦后停住时，他不会立刻判断“这个学生不会 free”，也不会把它心理化；他会自然补充拍数、和声边界、回到哪里、由哪个 cue 接回 S2 等工作条件。
2. **条件一旦补足，生田可以立即高质量完成。** 这证明她的技术、听觉、和声理解和 ensemble 配合都没有问题。排练因此可以正常继续，不制造“松下与生田没有默契”的关系戏。
3. **松下回去解决作品本身。** 他重新检查总谱与新 opening 的需要，并基于正式演出的可复现性、排练效率和作品责任，把原本开放的连接整理 / 写成明确谱面。这个决定是正确的专业工作，不是对自由的退让。
4. **新谱一出现，作品问题彻底解决。** 生田看见写下来的版本后几乎立刻就能弹，而且可以弹得非常漂亮、非常准确；从松下的职责视角，这件事已经处理完，可以继续排作品。
5. **正因为作品问题被正确解决，生田才真正看见自己的问题。** 她发现谱面上的和声、voice leading、节奏和连接方式自己全部懂，甚至并不困难；于是问题变成：

> **为什么写出来我就会，没写出来的时候，我却不知道自己要选哪一个？**

6. **这不是松下负责解决的问题。** 松下可以和松隆子极轻地交换工作事实，例如确认生田过去是否习惯即兴 / 开放处理；但不能写成两位老师给学生做心理会诊。松下提供一个稳定版本，就是他对作品应尽的职责。
7. **松隆子后来才发现生田出现了和平时不同的行为。** 正式连接已经写好、生田也完全能够完成；Day 3 稍后，松隆子从演奏室外看见她放学后仍在独自处理另一个版本。她不能靠几秒观察看穿问题，因此会进入并作一次极短的事实确认：正式谱面没有问题，生田仍在继续。她不当场解释或处理。经过其他文化祭场面以后，她在下班前联系多年合作的熟人 Fukase，约他周四下午来学校。具体对白留到 Scene / Screenplay 阶段。

### Day 3 新谱与单次专业追问｜LOCKED

- 松下带来的正式连接优先作为单页替换谱进入，不重新制造隆重揭晓；
- 生田第一次看见并演奏新谱时一遍完成，松下立即确认开头采用该版，排练继续处理其他段落；
- 排练后，生田只主动提出一个同样可行的替代连接；松下承认其可行性，只说明它与谱面版本在和声预示等声音结果上的不同；
- 松下最终选择当前版本，因为它同时满足声音条件与他自己的作品判断；“正式演出用写下来的版本”是可复现性责任，不是宣布唯一正确答案；
- 问答结束后，松下自然回到中元和 S2 的下一项工作；Day 3 不再用 A / B / C、条件列表、空白 D、节拍器或额外练习证明生田如何处理开放选择；
- 正式排练场景本身不追加松隆子观察或电话；经过其他文化祭场面以后，Day 3 才出现生田唯一一次私人练习、松隆子发现异常后进入作极短事实确认，以及更晚的单端电话。没有成年人分析生田。

核心定义：

> **正确答案解决了作品的问题，没有解决生田的问题。**

以及：

> **松下不是发现了生田的心结；他只是先把自己的作品做好。**

### Day 3 的推进边界

生田不会因为一次问答立刻转向“感受”，但 Day 3 也不再替观众完整证明她会怎样继续分析、分类或训练。

这一日先让她明确遇见：两个版本都可以成立，而作品仍然需要创作者作出选择。经过其他文化祭场面以后，她才在 Day 3 放学后进行本集唯一一次私人练习；松隆子从演奏室外看见她和平时不同，进入作一次极短的事实确认，知道正式谱面已经没有问题，却不替生田命名她正在追的东西。询问与电话之间继续穿插其他人的工作，不剪成即时求援。

### 松隆子 / Fukase 的功能边界

- 松隆子不是守旧教师；技术、纪律、准确与正式完成度始终是正价值。
- 她拥有一流职业演奏团体核心席位量级的能力；生田虽是乃校学生中音乐能力最强的一层，仍离成熟职业演奏家有距离，也仍在学校强大的音乐教育体系能够有效覆盖的范围内。
- Fukase 首先是成名的乐队主唱、词曲作者及唱片制作人，也是学校旧礼堂地下音乐室的长期外部创作协力者；他不是定期授课或负责学生评价的“创作导师”。
- 他的专业工作常发生在作品尚未存在的阶段：先让声音材料出现，再听、选择，并把最终选择做得准确。他不是自由艺术圣人，也不提供另一套“正确答案”。
- 松隆子足够了解自己的专业边界，因此知道这不是“再上两节技术课”就能解决的问题，并联系多年合作的熟人 Fukase 于周四下午来校。
- 这次联系不启动乃校的“个别艺术研究指导制度”，也不把 Fukase 追认为生田的专属导师；它只是松隆子针对一个具体学生、一个具体工作问题作出的专业安排。
- Fukase 的作用不是教会生田，而是拒绝替她终止“不知道”。
- 第一轮 Fukase 接触只负责打开问题，不能在一场戏内完成成长。
- Day 4 同一场接触中，由松隆子给一个极小容器：**右手，四小节。** 她降低进入未知领域的门槛，但不替生田决定内容。

完整职业身份、关系与表演边界见：[`fukase-role-lock.md`](fukase-role-lock.md)。

Day 4 第一次接触的场景机制见：[`day4-fukase-first-session-v0.1.md`](day4-fukase-first-session-v0.1.md)。当前已锁完整推进与三人权限，不锁最终对白及具体音乐材料。

内部关系定义：

> **Fukase 打开门；松隆子把门槛降到生田能迈进去。**

### EP04 终点

生田没有“学会自由”。

她只是开始在原本“发现不对 → 立即修正”的行为顺序中，多出一个很小的新分支：

> **等等 → 听一下 → 试一个没计划的东西 → 再看看。**

情绪落点优先是“玩”，不是“悟”。她可能第一次觉得：

> **这个很好玩。**

这为 EP05 她能在谱面尾奏后停下来听空间、再多待一会儿提供行为前史；正式演出时仍服从谱面与专业责任。

Day 5 收束场景机制见：[`day5-ikuta-first-step-v0.1.md`](day5-ikuta-first-step-v0.1.md)。当前锁定她以右手完成第一次四小节尝试、听完声音并主动开始第二次；具体音乐材料与场景最终位置未锁。

## 四、伊藤万理华｜本集完成一件事，不完成人物弧

### 装置已经现实化

当前作品方向已确认：

- 约 8—10 个可拆装的轻型竖向框架；
- 高约 2.0—2.2m，单块宽约 70—100cm；
- 木 / 轻型金属框架 + 半透明薄纱、网布或磨砂薄膜；
- 多层前后错位，观众可以从中穿行；
- 每层只有一个碎片图形；
- 从万理华设定的入口 / 理想观看点看，多层碎片叠成一个完整、安静、非具象或弱具象的形；
- 人向前移动后，完整图形立刻破碎，身体进入层与层之间；
- 视觉上是“大型空间装置”，工程上保持轻量、模块化、可由学生在教师 / 设施人员监督下制作与安装。

作品的简单动机即可成立：

> **站在这里明明是一个东西，走过去以后就不是了，很有意思。**

不替 17—18 岁的她提前写策展人式主题说明。

### 制作五段式｜LOCKED REALITY DISCIPLINE

1. **EP04 开始前，第一版模型已经成立。** 小比例模型、基本材料方向、框架尺寸草案等已有前期积累；本集不从“灵感诞生”或当天刚做出模型开始。模型里很漂亮，因为模型里没有真实的人流。
2. **正式批量制作前，先做 1:1 放样 / 局部样件。** 用地面放样、临时杆件或一两块试制框架把模型放进中央公共区旁的原定高人流候选位置，让拎指定正鞄的学生、真实人流、停留观看与可达性条件进入。第一版约 850—900mm 的穿行净宽使携包通行需要调整；学校据此给出两个都合规的方案：修改作品尺度后留在原位，或作品不改、移动到偏离主要动线的东翼第二展示室。
3. **作品不改，承担更少人看见。** 万理华不重新切分图形，也不用扩大观众量交换作品修改。她先确认第二展示室仍会在文化祭导览册与楼层地图中正式标记，然后选择移动过去，接受偶然进入、看见它的人更少。这不是对安全条件的拒绝，而是在两个可执行方案中承担自己选择的代价。
4. **数日模块化制作。** 选择成立以后，木料 / 轻型构件进入批量下料、钻孔、组框、蒙布 / 薄膜、模块拼装等制作；框架搬不进门、薄膜起皱、定位反复、固定方式不好看等普通麻烦可以在这一阶段发生。制作过程应跨多个制作日，不把大型装置写成一个下午从模型直接变成实景。
5. **最终现场组装与定位。** 最后进入展区的主要工作是把已经制作好的模块搬入、拼装、配重、安全确认、拉平材料与调整视点，不把“安装完成”误写成“当天才开始造作品”。她仍会认真规定入口、出口和理想观看点。

内部纪律：

> **万理华没有在 EP04 完成人物弧。她完成了一件作品。**

> **万理华不会在完整制作后才发现最基础的空间问题；她会在正式批量制作前通过 1:1 放样 / 局部样件把问题暴露出来。她可以倔，但不能因为剧情需要显得没做功课。**

### 西野七濑的使用边界

西野与万理华本来就是美术同学，可以自然帮忙扶框、搬动、等待，形成共同制作的生活感，不需要另设剧情动机；但绝对不能在 EP04 提前发现“反方向 / 出口也可以看”。

她在制作期甚至可以一直站在框边，因此根本看不到万理华的最终理想视点。

### Fukase 与模型｜DAY 4 OPENING LOCKED

Fukase 到校后先在音乐与美术别馆一层 Open Studio / 共同制作室自己看见万理华的模型。他不由松隆子带领参观，也不听万理华解释作品；他自己改变位置并找到模型图形成立的角度。

他直接说：

> **这个给我吧。**

万理华直接回答：

> **不行。**

不增加“为什么 / 因为这是我的”。Fukase 接受拒绝，不夸奖、不说服。松隆子随后带生田来找他，以双方名字完成最低限度介绍，再转去演奏室。

请求对象明确是可保存、可携带的模型，不是已经完成的大型装置。该场使 Fukase 在见生田以前先作为有自身观看、兴趣与欲望的创作者存在，也把万理华的核心拒绝放回她承担人物重量的 EP04。EP05 不再使用 Fukase 认证万理华完整作品。

EP05 的“从这边也看得见呢”必须仍然是新的发现。

## 五、榊陵 / 山下智久｜只做文化祭准备的边角料

这条线不独立成 B 线，不承担“介绍榊陵学校文化”的任务；优先作为万理华 / 文化祭制作环境的边角切面存在。

### 舞台布景测试

- 不提前搬真实大型主景；
- 榊陵学生使用卷尺、木棍、简易木架等 dummy，模拟关键宽高与运输包络；
- 路线测试本身应当顺利、正确；
- 乃校舞台人员与榊陵学生都基于自己的职责认真确认，不设置笨蛋或漏检者；
- 主景到预定位置后，乃校舞台人员与榊陵学生自然确认：若主景不靠墙独立站立，需要增加支撑 / 固定方案；
- 这是正确、安全、正常的制作深化，不作为“危险伏笔”拍摄。

当前倾向：**不重做主景。**

另一块侧景 / 门景片可以因实际舞台视觉、演员出入口或其他正常制作理由调整 / 重做，并可与 EP05 开场出现的“新加景片”形成低调连续性；这一点仍保留讨论空间，不锁死具体原因。

### 流程确认

最后只需极轻地让樱井与山下确认联合项目的基本工作时间：

> 上午完成联合舞台演出；
>
> **下午 13:30 开始拆景 / changeover。**

不拍成项目经理会议。确认可以发生在收东西、准备离场、有人叫樱井去处理下一件事的过程中。

EP05 开场已经存在的工作记忆——“那块到了？ / 昨晚的尺寸。 / 下午还是原路线？ / 原路线。”——应当让观众感觉两人已经共同处理这件事一段时间，而不是在给观众复述设定。

### 关键克制

观众在 EP04 结束时不应该看出：“这里在给 EP05 舞台事故埋雷。”

理想回看效果是：

> **原来该检查的，他们都认真检查过。**

## 六、男女校同场的青春基调

EP04 首次正式让较多榊陵男生进入乃校工作空间时，不能把两校学生拍成两个合作公司的专业人员。

本集使用全剧长期基调：

> **男孔雀开屏，女孔雀欣赏。**

含义不是恋爱配对，而是承认 17—18 岁男女在彼此空间里的身体、自我意识、吸引力与被观看感。

- 男生进入一所几乎全是女生的学校，可能手心出汗、注意头发 / 制服 / 站姿 / 声线，不自觉增加自己的“可靠、好笑、有力量、很帅”的展示；
- 女生处在自己的主场、又以熟人群体出现，胆子反而会更大：可以大大方方看、讨论谁更帅，甚至不特别怕被听到；
- 女生发现男生因为“被看”而站直、逞强、装没听见，会觉得更好笑，也更开心；
- “觉得他挺帅”与“觉得他现在很好笑”可以同时成立；
- 男生也会看女生，只是作为进入者，早期通常更努力装作自己没在看；
- 随共同劳动增加，最初高浓度的性别紧张会逐渐被熟悉覆盖，但不会被消灭。

禁止：

- 因为没有爱情线，就把学生写成无性别同事；
- 因为存在吸引力，就自动发展 CP、告白、吃醋或恋爱结算；
- 用全班尖叫、集体花痴等夸张反应代替真实身体感。

## 七、其他人物当前重量

### 文化祭高三 SSAA 节目｜LOCKED MUSIC FACTS

当前锁定：

- EP05 15:00 的旗舰合唱节目本体是**高三部员的成熟女声 SSAA ensemble**，不是普通“高校三声部”课堂合唱；整体训练与完成度按全国强校 / 青年专业 ensemble 邻近水准处理，必要时可以出现 divisi、细密弱音、独立内声部与高级 balance 要求。
- 这支 ensemble 的**原版已经很好**。松下洸平不是来修一个“不够好的高中合唱团”；正因为原版已经高度成熟、能够承受改变，他才产生重新设计开头的艺术冲动。
- 原版正式结构的第一音乐行为属于**生田绘梨花的正式钢琴 opening**。它不是临时垫场，而是作品本身的 harmonic / rhythmic identity 与正式入口。
- EP05 生田从 free 延展回到正式演出时，必须回到这个已经被观众和 ensemble 熟悉的钢琴 opening；其意义是“她可以走出去，也准确知道怎样回来”，不是临时救场。
- 堀未央奈平时是一年级合唱成员，当前按 **S1** 理解；她并不属于这支原始高三节目编制。
- 松下是在正常合唱部活动 / 全体训练中**偶然听见**堀，而不是组织试唱、选拔赛或公平竞争。他随后基于作品判断，直接把她加入这一版文化祭编排。
- 松下版在原版结构中加入一个 **optional first voice**：`生田正式钢琴 opening → 堀单独第一声 / 短句 → 高三 SSAA ensemble`。堀唱完这段后，在采用特殊版本时可以并入 S1 继续完成整首；她不是站在前方持续承担“主唱”。
- Day 2 排练长出的新连接架构锁定为：`堀短句 → 生田四拍连接 → S2 先进入 → S1 → A1 → A2 → 堀并入 S1`。S2 是连接后第一个出现的高三声部；具体音高、和弦、歌词、呼吸与声部间隔拍数留待音乐设计。
- 选择堀的理由不是“她唱得最好”或“她比高三更强”。松下清楚她在 blend、稳定性、训练成熟度上仍不如高三 ensemble；他选择的是她**单独起音时还不会本能地先寻找周围 ensemble、声音更直、更保留个人轮廓**这一具体声音状态。
- 松下要的是：在高度成熟的共同体声音真正出现以前，先有一个尚未被它完全吸收的人的声音。这个判断是具体的编曲 / 音色决定，不是代际象征对白，也不需要堀本人理解其“意义”。
- 该决定允许带有艺术家的武断：**艺术判断不按年级、资历、努力程度或人情顺位分配位置。** 松下有义务说明专业理由，但不需要为了照顾人情建立试听、候补或补偿机制。
- 如果堀不能完成这个特殊 first voice 的必要舞台确认 / 条件不成立，节目直接恢复原始高三版本：`生田正式钢琴 opening → 高三 SSAA ensemble`。**没有堀，不换第二个人；没有这个声音，就不要这个设计。**

### 中元日芽香｜S2 声部长

当前锁定：中元担任乃校女声合唱 **Soprano 2（S2）的声部长 / パートリーダー**，不担任学生指挥。

这个位置的重量刚好：

- 她有真实、持续的音乐责任；
- 分声部练习时需要带音准、节奏、进入、咬字和统一处理；
- S2 作为典型内声部，常处在更显眼的 S1 与 A1 之间，必须在旋律、邻近声部和完整和声都对自己形成牵引时仍然守住自己的音；
- 本曲应持续利用这一真实困难：S1 的旋律越完整、越好听，S2 越容易在听见它的同时被提前带走；中元和她的声部必须做到“听见，但不追过去”；
- 她的努力、重复训练和“再做好一点”的人格可以直接进入工作本身；
- 她需要听见别人、帮助别人一起变稳，而不是只证明自己唱得好；
- 她不会因此成为全团第二中心，也不会自然制造大量与堀的对手戏。

人物与音乐的共同定义：

> **她要跟旋律搏斗，仍然保持住自己的音。**

这不是把 S2 象征化，而是以真实的内声部工作承载她已有的人物逻辑：位置不是“最显眼的地方”，而是在其他声音不断影响自己的时候，仍然知道自己该唱什么，并让同声部的人一起站住。

中元与堀不是竞争对手。面对松下突然选择堀，她首先应当表现出的是**专业追问**，而不是替观众进行胜负比较。

核心问句方向：

> **为什么是堀？**

这句话成立的前提恰恰是：中元作为声部长清楚堀目前的技术状态，也知道她在稳定性和 ensemble 训练上还没有高三成熟。因此她真正问的是：

> **在这些技术事实都成立的情况下，为什么这个声音仍然是你要的？**

禁止把这句降格为“是因为她唱得比较好吗？”之类替外行观众发问的台词。需要给普通观众补充的音乐知识，由松下以指挥在排练中本来就会使用的专业说明完成。

中元之后可以真实产生“这个决定对我意味着什么”的个人感受，但禁止把这条线写成嫉妒、选拔赛或“努力家输给天才”。

### 堀未央奈｜一种存在，不扩成配角

堀在 EP04 的人物重量继续保持 EP05 的克制：

> **她是一种存在，而不是被扩写出来的配角。**

她是一年级合唱成员；松下因这一次具体音乐编排把她临时加入高三节目，让她承担短暂的 first voice / opening voice。

当前硬锁：

> **没有堀，不是换另一个人唱；而是退回没有这个首唱设计的成熟高三合唱版本。**

因此“首唱”不是部内第一名的奖励，也不存在“第二顺位自动替补”。她的存在是作品需要某一种具体声音质地时产生的编排决定。

禁止：

- 让堀与中元形成大量对手戏；
- 把她写成“后辈挑战前辈”；
- 让她解释自己的天赋或得到完整人物弧；
- 用胜负证明她为什么值得这个位置。

### 和田まあ亚｜锁重量，不锁桥段

当前锁定：まあ亚在 EP04 **不是独立故事线，也不承担独立人物推进**。她只作为生田主线中的一次极轻触发存在，屏幕重量控制在一两个短瞬间即可，不为她单独开完整场次。

她在本集的功能是让生田亲眼遇到一种与自己不同、但确实有效的学习入口：

> **“我会”不等于“我知道别人怎么学会。”**

まあ亚可以对复杂的语言 / 技术说明反应迟钝，却在节奏、动作、模仿、身体路径一旦被直接示范后迅速理解。这个差异不是隐藏天才反转，而是她已经成立的身体学习方式。

当前只锁以下边界：

- 她的出现应嵌在生田本来就会经历的工作 / 排练环境里，不另起一条支线；
- 重点不是“まあ亚终于学会”，而是让生田第一次看到：更精确的说明并不总是更有效的入口；
- 不让まあ亚总结主题，不给她“其实我很聪明”的自觉台词；
- 不把这段拍成 EP05 双转方案的明显伏笔；EP04 只需要让观众自然知道她有“身体先懂”的学习方式；
- 具体发生在哪一场、她为什么来到音乐空间、谁做身体示范、喜剧落点和对白，**全部留到整集主要流程整理完成以后再插入**。

## 八、人物压力等级｜M / S / L / R

本集等级表示人物承受的结构压力与变化幅度，不表示角色的重要性或音乐能力。

### M｜生田绘梨花

生田是本集唯一主推进人物。

她原有的工作方式没有错误：

- 能迅速理解谱面；
- 能准确完成明确任务；
- 能在复杂 ensemble 中承担正式演奏责任；
- 每获得一个具体条件，都能立即作出高质量回应。

本集改变的不是她的专业能力，而是她第一次遇见一个不由“正确”替自己结束的问题。

她的推进终点不是学会 free，也不是理解一套新的创作理论，而是：

> **她愿意在没有现成答案的地方，先试一次。**

### S｜伊藤万理华 / 中元日芽香

#### 伊藤万理华

万理华不完成大型人物弧。她完成一件作品。

她接受真实空间、通行、安全与制作条件，也接受不同展示方式带来的观众数量差异。她没有修改作品，而是选择较少人看见，并承担这个结果。

她在 EP04 的推进是：

> **模型里的作品，第一次成为现实空间里能够被人进入的东西。**

EP05 才保留出口反向视点与西野的发现。

#### 中元日芽香

中元线解决的是位置，不是输赢。

她知道堀在稳定性、blend 与 ensemble 训练上仍不如成熟的高三成员，因此会真实地问：

> **为什么是堀？**

这个问题不是质疑资格，也不是替观众发动竞争。她需要理解的是：在这些技术事实都成立的情况下，松下为什么仍然需要这一个声音。

得到作品层面的回答后，她不需要接受安慰，也不需要重新评价自己。她立即回到 S2 声部长的工作：

- 确认进入；
- 处理 balance；
- 让 S2 不被上方旋律带走；
- 带着自己的声部站住。

她与堀承担的不是同一个角色。

> **位置不同，不等于一个人替代了另一个人。**

### L｜堀未央奈 / 松下洸平 / 松隆子 / Fukase / 西野七濑 / 榊陵联合项目相关人物

- **堀未央奈**：作为作品需要的一种具体声音存在，不获得独立人物弧，不被写成获胜者。

## 十二、Gate 0 结论

### 本集为什么存在

EP04 让一群原本已经很强、而且都没有做错的人，进入真正的创作劳动。

有些问题可以通过专业知识、规则、谱面、制作条件与明确分工得到正确答案；这些答案真实有效，也必须被尊重。

但有些选择即使存在多个正确方案，仍然需要一个人说：

> **我想要这个。**

本集不贬低正确，也不神化自由。

它只让生田第一次发现：

> **正确可以告诉她什么能够成立，却不能替她决定自己想让什么出现。**

### 表层事件

文化祭准备进入真实制作阶段：

- 松下重新设计高三合唱开头；
- 生田完成四拍连接并遇见开放选择；
- 万理华把模型推进为可以现实制作的装置；
- 榊陵联合项目完成正常的舞台与流程准备；
- 松隆子邀请 Fukase 来校；
- 生田在“右手，四小节”的范围内开始第一次尝试。

### 本集真正改变什么

生田没有获得答案。

她只是从：

> **没有条件，所以暂时不动**

走到：

> **没有答案，也可以先听一个声音。**

### 本集结束时，观众多知道什么

- 生田的困难从来不是能力不足；
- 松下写成谱是正确的作品决定；
- Fukase 展示的不是另一套答案，而是答案出现以前的世界；
- 松隆子的作用不是解释，而是把第一次尝试缩小到生田能够进入；
- 中元与堀不是竞争者，而是在同一作品里承担不同角色；
- 万理华的倔强不是拒绝现实，而是知道什么可以改、什么不能丢。

### 本集终点

Day 5，生田独自在演奏室里完成第一次右手四小节。

她认真听完最后留下的声音。
