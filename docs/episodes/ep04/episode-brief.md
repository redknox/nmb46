# EP04《音乐室》｜Episode Brief

> 状态：**DRAFT / Gate 0 IN PROGRESS。**
>
> 本文件只记录编剧室已经确认的 STEP 0 成果与明确保留项；尚未进入 Beat Sheet，不把示例对白、具体场次顺序或未讨论完成的桥段视为锁定。

## 一、本集为什么存在

EP04 让 EP03 已经成立的人进入文化祭准备这一组新的现实条件，观察她们原本很好用的生活方式，第一次在哪里不够用了。

当前母命题：

> **有些问题有正确答案。**
>
> **有些问题没有。**
>
> **真正困难的是分辨自己现在面对的是哪一种。**

补充约束：

> **正确有它真正负责的事情；但有些事情，正确没有权限替你决定。**

禁止把本集写成“技术 / 规则不好，自由 / 感觉才好”。

## 二、表层事件

文化祭从 EP03 午休里被谈论的事情，逐渐成为真实的制作劳动：音乐排练、装置制作、联合舞台项目、尺寸确认、搬运、场地与流程协调开始占据校园空间。

本集不追求“大事件”。重点是：很多东西第一次真的被做出来。

## 三、生田绘梨花｜当前主推进线

### 起点

生田第一次在正常排练 / 工作中被要求“随便弹一点 / free 一点”，却发现自己无法真正选择。

她会本能地追问：调性、拍数、速度、和后段关系、左手方式等参数。即使能弹出技术上很好的方案，也更接近“这个可以吗”，而不是“我想弹这个”。

第一次出现的新问题：

> **为什么我不会 free？**

### 旧算法继续有效

她不会立刻转向“感受”，而是用自己一直有效的方式解决：继续练、分析、学习和声 / 音阶 / fill / pattern，甚至把即兴本身变成训练项目。

结果：她会变得更会“即兴技术”，但仍然觉得自己不会 free。

问题推进为：

> **为什么我已经会了，可我还是觉得自己不会？**

### 松隆子 / Fukase 的功能边界

- 松隆子不是守旧教师；技术、纪律、准确与正式完成度始终是正价值。
- Fukase 不是自由艺术圣人，也不提供另一套“正确答案”。
- 松隆子足够了解自己的专业边界，因此知道这不是“再上两节技术课”就能解决的问题，并由她把 Fukase 带进来。
- Fukase 的作用不是教会生田，而是拒绝替她终止“不知道”。
- 第一轮 Fukase 接触只负责打开问题，不能在一场戏内完成成长。
- 后段由松隆子给一个极小容器，例如“四拍 / 右手就好”，降低进入未知领域的门槛，但不替她决定内容。

内部关系定义：

> **Fukase 打开门；松隆子把门槛降到生田能迈进去。**

### EP04 终点

生田没有“学会自由”。

她只是开始在原本“发现不对 → 立即修正”的行为顺序中，多出一个很小的新分支：

> **等等 → 听一下 → 试一个没计划的东西 → 再看看。**

情绪落点优先是“玩”，不是“悟”。她可能第一次觉得：

> **这个很好玩。**

这为 EP05 她能在谱面尾奏后停下来听空间、再多待一会儿提供行为前史；正式演出时仍服从谱面与专业责任。

## 四、伊藤万理华｜本集完成一件事，不完成人物弧

### 装置已经现实化

当前作品方向已确认：

- 约 8—10 个可拆装的轻型竖向框架；
- 高约 2.0—2.2m，单块宽约 70—100cm；
- 木 / 轻型金属框架 + 半透明薄纱、网布或磨砂薄膜；
- 多层前后错位，观众可以从中穿行；
- 每层只有一个碎片图形；
- 从万理华设定的入口 / 理想观看点看，多层碎片叠成一个完整、安静、非具象或弱具象的形；
- 人向前移动后，完整图形立刻破碎，身体进入层与层之间；
- 视觉上是“大型空间装置”，工程上保持轻量、模块化、可由学生在教师 / 设施人员监督下制作与安装。

作品的简单动机即可成立：

> **站在这里明明是一个东西，走过去以后就不是了，很有意思。**

不替 17—18 岁的她提前写策展人式主题说明。

### 制作五段式｜当前确认骨架

1. **第一版模型成立。** 小比例模型里很漂亮，因为模型里没有真实的人流。
2. **1:1 放样撞上现实。** 通道太窄；书包、双向人流、停留观看与可达性要求使原空间方案不能原样使用。要求合理，不设置“不懂艺术”的反派。
3. **重做图形，而不是守住第一版尺寸。** 她第一次分辨“作品核心”与“第一版施工方案”：通道变宽后，重新计算 / 投影 / 切分各层图形，保住“一个位置完整、移动后破碎”的核心。
4. **普通制作麻烦真实发生。** 框架搬不进门、必须拆成模块、薄膜起皱、定位反复、固定方式不好看等。部分只是大型制作的倒霉事，不承担人物寓意。
5. **安装完成。** 她没有学会“随便别人怎么看”，反而会认真规定入口、出口和理想观看点。她只是已经知道：很多实现方式可以改，但她必须知道什么东西一旦改掉就不再是自己的作品。

内部纪律：

> **万理华没有在 EP04 完成人物弧。她完成了一件作品。**

### 西野七濑的使用边界

西野可以自然帮忙扶框、搬动、等待，形成共同制作的生活感；但绝对不能在 EP04 提前发现“反方向 / 出口也可以看”。

她在制作期甚至可以一直站在框边，因此根本看不到万理华的最终理想视点。

EP05 的“从这边也看得见呢”必须仍然是新的发现。

## 五、榊陵 / 山下智久｜只做文化祭准备的边角料

这条线不独立成 B 线，不承担“介绍榊陵学校文化”的任务；优先作为万理华 / 文化祭制作环境的边角切面存在。

### 舞台布景测试

- 不提前搬真实大型主景；
- 榊陵学生使用卷尺、木棍、简易木架等 dummy，模拟关键宽高与运输包络；
- 路线测试本身应当顺利、正确；
- 乃校舞台人员与榊陵学生都基于自己的职责认真确认，不设置笨蛋或漏检者；
- 主景到预定位置后，乃校舞台人员与榊陵学生自然确认：若主景不靠墙独立站立，需要增加支撑 / 固定方案；
- 这是正确、安全、正常的制作深化，不作为“危险伏笔”拍摄。

当前倾向：**不重做主景。**

另一块侧景 / 门景片可以因实际舞台视觉、演员出入口或其他正常制作理由调整 / 重做，并可与 EP05 开场出现的“新加景片”形成低调连续性；这一点仍保留讨论空间，不锁死具体原因。

### 流程确认

最后只需极轻地让樱井与山下确认联合项目的基本工作时间：

> 上午完成联合舞台演出；
>
> **下午 13:30 开始拆景 / changeover。**

不拍成项目经理会议。确认可以发生在收东西、准备离场、有人叫樱井去处理下一件事的过程中。

EP05 开场已经存在的工作记忆——“那块到了？ / 昨晚的尺寸。 / 下午还是原路线？ / 原路线。”——应当让观众感觉两人已经共同处理这件事一段时间，而不是在给观众复述设定。

### 关键克制

观众在 EP04 结束时不应该看出：“这里在给 EP05 舞台事故埋雷。”

理想回看效果是：

> **原来该检查的，他们都认真检查过。**

## 六、男女校同场的青春基调

EP04 首次正式让较多榊陵男生进入乃校工作空间时，不能把两校学生拍成两个合作公司的专业人员。

本集使用全剧长期基调：

> **男孔雀开屏，女孔雀欣赏。**

含义不是恋爱配对，而是承认 17—18 岁男女在彼此空间里的身体、自我意识、吸引力与被观看感。

- 男生进入一所几乎全是女生的学校，可能手心出汗、注意头发 / 制服 / 站姿 / 声线，不自觉增加自己的“可靠、好笑、有力量、很帅”的展示；
- 女生处在自己的主场、又以熟人群体出现，胆子反而会更大：可以大大方方看、讨论谁更帅，甚至不特别怕被听到；
- 女生发现男生因为“被看”而站直、逞强、装没听见，会觉得更好笑，也更开心；
- “觉得他挺帅”与“觉得他现在很好笑”可以同时成立；
- 男生也会看女生，只是作为进入者，早期通常更努力装作自己没在看；
- 随共同劳动增加，最初高浓度的性别紧张会逐渐被熟悉覆盖，但不会被消灭。

禁止：

- 因为没有爱情线，就把学生写成无性别同事；
- 因为存在吸引力，就自动发展 CP、告白、吃醋或恋爱结算；
- 用全班尖叫、集体花痴等夸张反应代替真实身体感。

## 七、其他人物当前重量

### 中元日芽香｜S2 声部长

当前锁定：中元担任乃校女声合唱 **Soprano 2（S2）的声部长 / パートリーダー**，不担任学生指挥。

这个位置的重量刚好：

- 她有真实、持续的音乐责任；
- 分声部练习时需要带音准、节奏、进入、咬字和统一处理；
- S2 作为典型内声部，常处在更显眼的 S1 与 A1 之间，必须在旋律、邻近声部和完整和声都对自己形成牵引时仍然守住自己的音；
- 她的努力、重复训练和“再做好一点”的人格可以直接进入工作本身；
- 她需要听见别人、帮助别人一起变稳，而不是只证明自己唱得好；
- 她不会因此成为全团第二中心，也不会自然制造大量与堀的对手戏。

人物与音乐的共同定义：

> **她要跟旋律搏斗，仍然保持住自己的音。**

这不是把 S2 象征化，而是以真实的内声部工作承载她已有的人物逻辑：位置不是“最显眼的地方”，而是在其他声音不断影响自己的时候，仍然知道自己该唱什么，并让同声部的人一起站住。

她与堀未央奈不是竞争对手。堀更准确地是她理解“位置不是排名”的**参照系**。

中元可能真实产生“为什么是她 / 我还差什么”的感受，但禁止把这条线写成嫉妒、选拔赛或“努力家输给天才”。

### 堀未央奈｜一种存在，不扩成配角

堀在 EP04 的人物重量继续保持 EP05 的克制：

> **她是一种存在，而不是被扩写出来的配角。**

她是一年级合唱成员，并因这一次具体音乐编排获得短暂的首唱 / opening voice。

当前硬锁：

> **没有堀，不是换另一个人唱；而是退回没有这个首唱设计的成熟合唱版本。**

因此“首唱”不是部内第一名的奖励，也不存在“第二顺位自动替补”。为什么这首作品需要这一声、为什么偏偏是堀，留给下一轮音乐事实继续建立。

禁止：

- 让堀与中元形成大量对手戏；
- 把她写成“后辈挑战前辈”；
- 让她解释自己的天赋或得到完整人物弧；
- 用胜负证明她为什么值得这个位置。

### 和田まあ亚

适合用一个非常轻的学习方式差异，触碰生田的盲点：

> **“我会”不等于“我知道别人怎么学会。”**

不让她突然成为隐藏天才，也不让她承担主题总结。

## 八、本集结尾当前倾向

不以文化祭倒计时、正式通知或大事件收尾。

更倾向学校逐渐安静后，生田仍在音乐空间里尝试极小的自由片段：几个音、停、再试、某次奇怪但有趣。

落点不是“我懂了”，而是：

> **她愿意继续玩。**

- 西野第一次真正站到那个反向视点；
- 联合舞台项目文化祭当天的正常运行与下午 changeover；
- 大型后部主景在真实 changeover 条件下出现新的运输包络冲突；
- 生田把“停下来听”带入正式排练 / 演出环境；
- 正式演出责任仍由规则、谱面与专业边界兜住；
- 堀的特殊 opening 在条件不成立时直接撤回成熟合唱版本，而不是启动替补首唱。
