# 本集最终定义

EP04 发生在校园祭前一周的五个正常上课日。故事不以危机推动，而让观众看见一群已经很强、且没有人做错的人如何在各自专业边界内工作。

## 生田绘梨花

生田能准确演奏、听辨并理解多个同样成立的音乐方案。她的问题不是能力不足，而是当充分判断条件消失、选择必须由自己作出时，她不知道从哪里开始。

Fukase 没有教会她 free，只让她看见作品出现以前庞大、开放、可能没有成果的世界。松隆子没有替她决定第一个音，只把第一次尝试限制为：

> **只用右手。四小节。**

结尾，生田完成第一次四小节，随后保留相同的第一个音，主动改变第二个音。她没有完成成长，只打开了一片新天地。

## 中元日芽香与堀未央奈

两人不是竞争或替代关系。堀以仍能单独站立的声音承担 optional first voice；中元以成熟 ensemble 的 S2 声部长身份追问作品逻辑、组织声部进入。她们在同一作品中承担不同角色。

## 伊藤万理华

万理华没有修改作品。她选择放弃主要动线上的偶然人流，把作品移到较冷清但仍进入导览册与展示编号系统的第二展示室。

Fukase 自己看见她的模型并直接索要；万理华直接拒绝。该场不承担名艺术家认证学生作品的奖励功能。

## 专业权限

- 松下洸平对作品负责，不对生田的长期教育成长负责；
- 松隆子持有长期教育关系，并准确识别自己的专业边界；
- Fukase 是学校长期外部创作协力者，不是生田的专属导师；
- 山下是榊陵带队教师，联合戏剧的具体创作与舞台工作仍由学生主导。
