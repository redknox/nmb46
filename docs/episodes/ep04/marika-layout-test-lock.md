# EP04｜万理华 1:1 放样与展示选择现实锁

> 状态：**LOCKED / 已传播到 Episode Brief 与艺术别馆空间锁。**
>
> 本文件锁定万理华大型装置在正式批量制作前的 1:1 放样测试方式、展示条件与由此产生的选择。最终对白留到后续场景设计时确认。

## 一、单人测试即可暴露问题

正式批量制作前，万理华先以地面放样、临时杆件或局部样件把模型放进真实空间。

测试不需要安排两人迎面会车，也不需要夸张成“完全过不去”。优先使用一个学生按日常状态正常通过：

- 乃木坂女学院的日常主包优先按传统私立女校气质理解为指定正鞄 / 手提或肩挎 school bag，而非默认所有高中生背双肩包；具体制服附件资料后续统一补全；
- 学生正常拎包进入放样通道；
- 身体本身可以通过，但需要不自然地侧身，或正鞄轻擦临时框架 / 样件，或需要把包从身体侧边提到前方才能继续；
- 不摔倒，不制造事故，不把测试拍成喜剧闯关。

这个程度已经足够让万理华看见：

> **模型里的“能通过”，不等于真人可以自然、稳定地通过。**

问题首先由真实身体暴露，而不是由老师先宣布“你的设计不合规”。

## 二、场地老师不临场发明法规数字

负责场地 / 美术 / 设施确认的成人随后只确认早已存在的展示条件。

当前锁定：

- 学校对文化祭公开展示空间本来就有内部场地 / 安全基准；
- 该基准由建筑本身的避难条件、消防要求、公开日外来访客、无障碍考虑和学校历年场地管理经验共同形成；
- 老师不是以“艺术指导者”身份要求万理华改作品，而是在说明不同展示方式各自必须满足的现实边界；
- 场景里不需要展开消防法、バリアフリー法等法规讲座，也不让老师用一句“法律规定必须 X 厘米”把复杂法规错误简化；
- 万理华只问执行选择真正需要的事实：留在原位最低要改到什么程度，以及第二展示室是否仍会在文化祭导览册正式标记。老师只给可执行的校内条件，不替她判断作品。

学校给出的不是一道只有“修改作品”才能通过的题，而是两个都可以执行的展示方案：

- 若保留原定的中央公共区旁高人流位置，就必须扩大内部通行尺度、修改作品，使其可以承担连续开放的人流；
- 若保持当前尺度与观看方式，则把完整作品移到东翼较安静、偏离主要动线的正式美术展示室。该室具备独立出入口、外围绕行与必要的人数管理条件，作品可以不改，但偶然经过并进入的人会显著减少。

核心关系：

> **规则不给万理华作品答案，只把两种真实代价摆在她面前。**

万理华在选择前只确认一项与观众真实可达有关的事实：较安静的展示室仍会在文化祭导览册的楼层地图上正式标记，并拥有展示编号。确认以后，她选择搬到该展示室，保持作品不改；她不用“被更多人看见”交换修改，也不把选择包装成对学校规则的反抗。

### 当前场地与可执行数字｜已锁定

- 1:1 放样发生在音乐与美术别馆一层中央公共区旁的原定高人流候选位置；
- 最终采用的东翼美术展示室在文化祭导览中标作“第二展示室”，约 8.4m × 6.3m，具有两个正常公共出入口和作品外围绕行路线；
- 第一版穿行净宽可约为 850—900mm，人体能过，但携带指定正鞄时需要不自然调整；
- 乃校对连续开放、高人流的展示方式要求主要穿行路径至少约 1.2m 净宽，入口、出口及转向位置约 1.5m；
- 以上是该校根据本建筑与公开展示形成的内部场地条件，不在对白里表述成全国统一法律数字。

当前同时锁定：若作品保持第一版尺度，则不得留在原定高人流位置，也不得把作品内部当作连续通行或必要疏散路线；它必须移动到偏离主要动线、另有外围绕行、能够管理同时进入人数的东翼美术展示室。该室仍进入官方导览册和楼层地图，不是惩罚性、临时性或“不让人看”的空间。

## 三、写作纪律

- 禁止用两个学生迎面堵死来人为放大问题，除非后续真实空间计算证明确有必要；当前优先单人正常通过测试。
- 禁止默认“高中女生都背双肩书包”；乃校包型以后按制服世界观统一设计。
- 禁止把老师写成临场凭感觉决定通道宽度的人。
- 禁止随口把某一个数字说成日本法律对所有学校文化祭展览内部通道的一刀切要求。
- 禁止让万理华和老师争论“艺术为什么要服从规定”；她会确认边界，然后自己解决作品。
- 禁止把她的选择写成“聪明地改了实现方式”；本场真正的选择是作品不改，并承担更少人看见的结果。
- 禁止把较少观众拍成学校惩罚她或故意把作品藏起来；这是她在两个合规方案中选择的现实代价。
- 禁止把选择改写成“作品留在原场地，只限制同时进入人数”；原场地与第二展示室之间的移动是本场真实代价。
- 禁止删掉文化祭导览册确认；它证明万理华不是拒绝观众，而是确认作品仍可被主动找到以后，接受更少的偶然人流。

内部现实纪律：

> **身体先证明差异存在，制度再给出两种可执行条件，艺术家决定自己愿意承担哪一种代价。**
