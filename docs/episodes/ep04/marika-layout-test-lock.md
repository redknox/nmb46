# EP04｜万理华 1:1 放样测试现实锁

> 状态：**LOCKED / 后续需传播到 Episode Brief、Scene Lock 与 Reality Review。**
>
> 本文件锁定万理华大型装置在正式批量制作前的 1:1 放样测试方式，以及场地尺寸约束的来源。具体净宽数字与最终对白留到后续场景设计和法规/校内基准校核时确认。

## 一、单人测试即可暴露问题

正式批量制作前，万理华先以地面放样、临时杆件或局部样件把模型放进真实空间。

测试不需要安排两人迎面会车，也不需要夸张成“完全过不去”。优先使用一个学生按日常状态正常通过：

- 乃木坂女学院的日常主包优先按传统私立女校气质理解为指定正鞄 / 手提或肩挎 school bag，而非默认所有高中生背双肩包；具体制服附件资料后续统一补全；
- 学生正常拎包进入放样通道；
- 身体本身可以通过，但需要不自然地侧身，或正鞄轻擦临时框架 / 样件，或需要把包从身体侧边提到前方才能继续；
- 不摔倒，不制造事故，不把测试拍成喜剧闯关。

这个程度已经足够让万理华看见：

> **模型里的“能通过”，不等于真人可以自然、稳定地通过。**

问题首先由真实身体暴露，而不是由老师先宣布“你的设计不合规”。

## 二、场地老师不临场发明法规数字

负责场地 / 美术 / 设施确认的成人随后只确认一个早已存在的制作条件。

当前锁定：

- 学校对文化祭公开展示空间本来就有内部场地 / 安全基准；
- 该基准由建筑本身的避难条件、消防要求、公开日外来访客、无障碍考虑和学校历年场地管理经验共同形成；
- 老师不是以“艺术指导者”身份要求万理华改作品，而是在说明这个展区作为公开展示空间必须满足的现实边界；
- 场景里不需要展开消防法、バリアフリー法等法规讲座，也不让老师用一句“法律规定必须 X 厘米”把复杂法规错误简化；
- 万理华最自然的工作性问题可以是“最低要多少？”之类，老师只给她可执行的校内条件；具体数值后续依据最终展区性质与现实规范再锁。

核心关系：

> **规则不给万理华作品答案，只给她一个现实边界。**

得到边界以后，怎样重排框架、重新切分图形、怎样保住“一个位置完整、移动后破碎”的作品核心，仍然完全是万理华自己的艺术问题。

## 三、写作纪律

- 禁止用两个学生迎面堵死来人为放大问题，除非后续真实空间计算证明确有必要；当前优先单人正常通过测试。
- 禁止默认“高中女生都背双肩书包”；乃校包型以后按制服世界观统一设计。
- 禁止把老师写成临场凭感觉决定通道宽度的人。
- 禁止随口把某一个数字说成日本法律对所有学校文化祭展览内部通道的一刀切要求。
- 禁止让万理华和老师争论“艺术为什么要服从规定”；她会确认边界，然后自己解决作品。

内部现实纪律：

> **身体先证明问题存在，制度再给出边界，艺术家自己决定怎样继续。**
