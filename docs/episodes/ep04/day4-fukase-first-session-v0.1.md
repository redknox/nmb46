## DAY 4｜音乐与美术别馆・Open Studio / 共同制作室｜周四下午

工作室的门开着。万理华和西野在里面做事，模型放在正在使用的工作桌一端。

松隆子带 Fukase 从中央公共区过来，沿走廊前往演奏室。

经过门口时，Fukase 慢下来。

松隆子向前走了两步，回头。

**松隆子**

我去叫她。

她继续向演奏室方向走。

Fukase 留在门口看了一会儿，随后走进敞开的工作室。他换了几个位置，最后俯下身，从一个角度看进去。摄影机不替他取得该视点。

万理华继续处理手里的材料。

Fukase 看了一会儿。

**Fukase**

**万理华**

门外传来脚步声。松隆子带着生田回来。Fukase 回过头。

**松隆子**

又向生田。

**松隆子**

Fukase さん。

**生田**

初次见面，我是生田绘梨花。请多关照。

她鞠躬。

**Fukase**

初次见面。请多关照。

松隆子看向走廊另一侧。

**松隆子**

去演奏室吧。

万理华和西野继续工作。

模型留在桌上。

生田回到钢琴前。总谱与松下写好的正式替换页已经放在谱架上。Fukase 在钢琴侧面坐下，可以同时看见谱和键盘。松隆子坐在稍后的位置。

## 本稿锁定的场景机制

### 1. Fukase 先作为创作者自己看见模型

- Fukase 按电话中明确的时间与来校地点到达；完整访客登记不在本场展示，松隆子从中央入口接到他；
- Open Studio / 共同制作室在文化祭制作中正常开门，模型位于正在使用的工作桌上，不为他的到来专门陈列；
- Fukase 原本由松隆子带往演奏室，只在正常动线上被模型截停；他不是在 Open Studio 等候，也没有独自在校园内闲逛；
- 生田已经按约在十几秒外的演奏室等候。松隆子说“我去叫她”后带她回来，没有任何人迟到；
- 没有人带他参观、介绍作品或指出理想观看点；他自己看见模型、改变位置并找到图形成立的角度；
- 他直接说“这个给我吧”，万理华直接回答“不行”；
- 不增加“为什么”“因为这是我的”、作品解释、名人认可反应或西野旁观反应；
- Fukase 接受拒绝，不追问、不说服，也不以夸奖补偿万理华。

### 2. 初次见面是寻找 Fukase 以后发生的普通礼仪

- 松隆子从演奏室带已经等候的生田回到 Open Studio / 共同制作室找 Fukase，不让三个人预先站在演奏室里举行介绍；
- 松隆子只说双方名字，生田完整自报姓名并问候，Fukase 正常回礼；
- 不设置客串明星揭晓、仰慕反应或“老师登场”仪式；
- 随后直接转去演奏室工作，万理华与西野继续原来的制作。

### 3. Fukase 先面对一个真实音乐问题

- 松隆子不替生田做人物说明或问题诊断，只说“昨天那两个四拍，弹一下”；
- Fukase 不对脱离上下文的四拍立即发表看法，而先要求“从前面一点”，确认它们从哪里来、到哪里去；
- 他先问正式演出使用哪个版本、为什么使用，确认松下的作品选择已经完整成立；
- 他不否定松下，也不把另一个版本包装成更自由、更真实的答案。

### 4. 生田的问题从已解决的作品工作中自然出现

- “那这首已经定了”明确区分作品问题与她仍在追的创作问题；
- 生田不是被 Fukase 一眼看穿，而是在具体音乐问答里自己把问题继续问下去；
- 她关心的是：当多个版本都可以，又没有作品条件或作者意愿替自己决定时，选择根据什么结束。

### 5. Fukase 打开的世界必须属于真实职业创作

- 他谈歌词、节奏、录到的声音、前后关系、演唱者与交稿时间等具体工作事实；
- 他承认材料可以暂时保留、长期不选，最终进入作品时仍然必须作出决定；
- 他不是鼓励“随便”，而是让生田看见作品形成以前，材料如何先存在、再被听见与选择；
- 音乐与创作段落允许繁琐、专业和较长，不为照顾观众而删成主题句；
- 后续精修可以继续增加真实音乐制作与录音工作的准确度，但不能把专业谈话改成创作哲理演讲。

### 6. 两位成人在同一场里完成不同工作

- Fukase 面对生田的停顿，不急着填满沉默，也不把暂时做不到命名为失败；
- “什么都可以”对他是真实的创作起点，不是故意为学生设置测试；
- 当这个真实尺度对生田仍然过大时，松隆子才给出“右手，四小节”；
- 这不是松隆子修正 Fukase，而是长期教育者为具体学生提供第一次可以进入的容器；
- Fukase 不替容器填写内容，松隆子不替生田发出第一个声音。

## 后续音乐设计 / Screenplay 事项

- 两个四拍版本的具体和声、音高、声部还原方式及现场演奏长度；
- 当前中文对白机制已锁；最终日语措辞可以在不改变信息量、人物关系与停顿功能的前提下自然化；
- 场景最终时长与音乐段落的完整演奏比例留待音乐设计与拉片；
- Day 5 生田如何在“右手，四小节”的容器里迈出第一步。
