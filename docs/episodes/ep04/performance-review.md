---

# 一、结论

**PASS。**

无剧本级 RED，不增加对白、不删场。唯一正文修正是把 S03 错误的“西侧台”拆成舞台左右侧台与西侧装卸轴，保证旧礼堂物理关系可执行。

本集最大的制作风险不是观众看不懂，而是导演、表演和后期为了确保观众看懂，替已经成立的工作过程划重点。

固定总原则：

> **把专业工作拍清楚，不拍“这件事意味着什么”。**

---

# 二、S01｜原版已经成立

- 松下点堀以前，不提前用特写寻找她；完整合唱中没有待揭晓的对象。
- 生田给出的单一参考音必须完全消失，堀才无伴奏进入。声音关系由真实衰减建立，不靠剪辑制造。
- 松下转头点堀只是工作中临时起意，不使用选拔、揭晓或命运时刻的镜头语法。

# 三、S02｜模型里没有真实的人

- 平板是美术工作工具，不给屏幕解释性特写，不展示“修改前 / 修改后”对照。
- 万理华看、试改、撤销与询问发生在同一段连续劳动里，不剪成抉择蒙太奇。
- 西野扶框、推车与收材料是真实协作，不以反应表情评价万理华的选择。

# 四、S03｜场地是第一次

## 空间轴

稳定关系为：

> **舞台右侧台：合唱台待机与进入｜舞台左侧台：确认框撤出｜后部横向通道：物流协调｜西侧装卸口：大型构件离馆。**

至少保留一个能同时辨认舞台、左右侧台与后台转角的母镜头。不得用连续手、脚、脚轮和脸部特写代替空间运动。

## 表演

- 榊陵男生整理头发与制服只是进入异校环境后的下意识动作，不做恋爱或喜剧落点。
- 低年级女生看入校证再看人，只是校园里出现陌生制服后的普通注意。
- 歪掉的衣领不需要乃校女生提醒，也不形成关系暗示。
- 工作声承担场景节奏：椅脚、脚轮、连接件、口令与短暂停止。不使用危险蒙太奇。

# 五、S04｜作品重新长出来

这是全片表演与声音风险最高的一场。

## 人物反应

- 松下叫堀时允许真实的惊讶、好奇与视线变化，但不得剪成逐人反应蒙太奇。
- 中元的“为什么是堀？”是专业追问。禁止竞争性受伤、强忍不满或被替代感。
- 生田在“接一下”以后完成唯一明确的任务并等待，不给诊断式特写，不暗示她此刻已经出现问题。

## 声音

观众必须从音乐本身听见：

1. 堀的声音单独站在前面；
2. 成熟 ensemble 第一次进入时过快完整；
3. 第二次各声部没有一次给满；
4. 四拍连接以后 S2、S1、A1、A2 逐层形成。

后期不能用人物表情、音量夸张或额外配乐证明这些变化。每次重唱的起止范围与聆听任务必须不同，避免形成同一 opening 的机械重复。

# 六、S05｜正确答案出现

- “还有我想听这个”保持普通工作回答，不停顿成主题句。
- 生田回答“好”以后没有失落、领悟或被说服的表情任务。
- 中元带着四十一小节自然进入下一项工作，S1 音取り担当到琴边完成场景换手；不再补一次起音证明分声部练习开始。

# 七、S06｜生田直接说出问题

- 观察窗是功能设施，不使用玻璃倒影、人物套框、柔光侧脸或“天才少女独处”的构图。
- 生田已经通过对白说清具体困难，不再以谱面、琴键、闪回或两种和弦的解释性插入图解。
- 松隆子只确认事实，不演成已经知道答案，也不在离开时留下意味深长的回望。
- 松隆子离开，摄影机也离开；不留下来观察生田是否继续练习。

# 八、S07｜今天到这里

- 授权剧目片段以约十二至二十秒的连续真实排练呈现，具体使用以制片版权确认版本为准。
- 榊陵学生演出的停止口令是普通收工，不做“排练成果展示”。
- “你们两个都早了”不等待笑声，不设计周围人的喜剧反应。
- 山下始终处在带队教师的背景位置，不替学生导演或学生舞台组接管项目。

# 九、S08｜电话

- 车站人流和环境声保持正常，不在接通电话后突然压成秘密空间。
- 只保留松隆子一端；不出现 Fukase 的声音、姓名 / 联系人屏幕、字幕或补完镜头。
- 不使用嘉宾预告配乐，不给挂断后的意味深长停顿。松隆子收起手机，随人流进站。

# 十、S09｜这个给我吧

- 摄影机留在开放工作室的公共视角，不切 Fukase 主观镜头，不用模型特写解释他看见了什么。
- “这个给我吧 / 不行”不是包袱，也不是名艺术家认证学生作品的奖励场面。
- 松隆子带生田回来以后，初次见面按普通工作礼仪完成，不使用明星嘉宾式揭晓。
- 场景末尾回到万理华与西野原本的劳动，不以模型插入镜头替拒绝加重。

# 十一、S10｜世界过大

## 空间

避免“治疗三角”。稳定位置为：

- 生田在钢琴前；
- Fukase 在侧面能同时看见琴键与谱；
- 松隆子略退后，但仍是共同在场的人。

## 音乐与表演

- 两组四拍使用可比较的速度、力度与残响；观众可以听见差异，不靠图示或谱面插入。
- Fukase 始终是普通创作者工作语气，不把“一天什么也没有完成”“第二天再来”表演成金句。
- 生田连续追问是在寻找可执行条件，不是焦虑、顶撞或哲学辩论。
- Fukase 不设置测试，不等待正确反应，也不替沉默填答案。
- 松隆子的“只用右手 / 四小节”不是纠正 Fukase 或英雄式救场。镜头不把她拍成早已掌握答案的人。
- 生田回答“好”以后直接结束，不给释然、顿悟或重新获得信心的反应镜头。

# 十二、S11｜第二个音

- 全段不用非源音乐。声音按普通班级生活、艺术制作劳动与演奏室真实琴声依次换挡。
- 第一次四小节连续发生，不做尝试蒙太奇。
- 生田落手前已经知道声音关系；表演不是误触、弹错、害怕或试探，而是清醒地把平时会提前排除的声音留下来听完。
- 第二次保留相同第一个音、改变第二个音。这个区别必须可听，不以键盘、手指或表情特写解释。
- 不拍见证者，不看钟，不给“成了”的脸。新的音程仍在衰减时 CUT TO BLACK。
