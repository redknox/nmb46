# EP04｜时间结构锁

> 状态：**LOCKED / Gate 0 structural timing.**
>
> 本文件只锁定已经由编剧室确认的时间因果与人物推进顺序；不是 Beat Sheet，不锁具体场次长度、对白或逐镜调度。

## Day 1｜松下只确认堀的声音，不当场完成作品判断

EP04 冷开场先让高三 SSAA 成熟原版成立：生田正式钢琴 opening → 高三 SSAA ensemble。松下已经在工作，通过对作品的实际判断权建立身份，不做名人登场仪式。

原版的专业结论必须明确：**已经达到正式演出要求。** 松下后续产生修改冲动，不是因为现版不合格，也不是为了修复缺陷。

当天不参加这首高三节目、但属于合唱部的其他年级部员，在排练空间一侧 / 后方整齐坐着观摩。堀未央奈就在其中；她不是为了剧情专门被安排来旁观。

高三原版完成、排练进入正常转换状态后，松下视线扫到旁听部员中的堀。由于他与乃校长期合作，本来就认识她、也早已听过她唱，因此可以直接叫她名字。

这里的触发首先是**视觉上的重新联想**，不是“第一次偶然听见一个陌生好声音”。松下只需要确认这副自己已经认识的声音当前是什么状态。

因此 Day 1 不使用生田的正式 opening，也不让堀直接试唱文化祭作品。松下优先让她唱合唱部长期熟悉的编号式基础无伴奏声乐 / 视唱练习；例如“练习二，C 大调”这一类工作语言，但具体教材、编号与调性后续再定。

堀从整齐旁听席中被突然点名，出现很轻的学生式慌乱后起立；随后按要求唱两三小节即可。松下听够音色、起音、音准、呼吸、线条与她当前尚未完全被 ensemble 吸收的个人轮廓后，普通地结束：**“好，谢谢。”** 堀重新坐回旁听部员中，摄影机也放掉她。

发现 / 确认机制必须满足：

- 不是 audition、选拔赛、solo 征集或专门为剧情搭出的展示机会；
- 松下本来就知道堀是谁，也听过她的声音；
- 视觉触发让他重新把注意力放到这副声音上，基础无伴奏练习只负责最小确认；
- 两三小节已经足够，不需要完整演唱；
- 不把这一刻拍成“发现天才新人”；
- 不解释“你的声音很特别”，也不宣布新编排；
- 不让观众在 Day 1 确认松下已经决定怎样把她放进作品；
- Day 1 到此只锁定一个事实：**松下重新听清了这副声音。**

核心时间纪律：

> **听清声音，与决定怎样使用这个声音，不发生在同一个瞬间。**

松下作为对作品负责的成名艺术家，可以在原版已经达到要求以后，因为看见一个自己熟悉的学生而重新想到一种声音材料；经过时间后，再决定是否把它带进作品。

开场音乐段结束后，摄影机可以离开音乐空间，进入万理华 1:1 放样、校园文化祭准备与榊陵首次进入等现实劳动。Day 1 不需要再为了“发现堀”第二次返回音乐室。

## Day 2｜完整排练中，作品自己长出新问题

Day 2 松下才把前一天重新确认过的堀之声带入文化祭作品。堀可以已经正常出现在排练空间并拿到必要材料，但不设置“宣布加入高三节目”的仪式。

这一天允许、并且需要有一场较长的完整音乐排练。松下可以较充分地阐明自己为什么要修改一个前一天已经达到正式演出要求的版本，因为演唱者和伴奏者必须据此改变实际表演；这不是替观众解释主题。

排练必须遵守项目级原则：**本剧的主旨：不解释。** 因此：

- 松下只解释演唱者 / 演奏者真正需要知道的作品判断、声音目标与工作要求；
- 参与者只提出自己在实际执行中真的会问的问题；
- 不安排任何人把松下的话翻译成“个人与集体”“成长”“自由”等主题总结；
- 松隆子不充当观众嘴替，也不替松下补充教育意义。

### 作品修改的进入顺序

松下先明确：前一天原版已经可以演，不是因为“不够好”才修改。随后可以通过较长的作品说明、试唱、停下、重新措辞与具体声部要求，让演唱者逐渐理解他想改变的是开头声音形成的方式。

关键不是预先给出漂亮主题句，而是让作品理解在排练里通过工作语言逐渐准确：原版中生田 opening 之后，高三成熟 ensemble 很快形成完整整体；松下现在希望这个“整体已经成立”的时刻再晚一点，在此前先保留一个更独立的单一人声。

第一次不必先回答“为什么是堀”。可以先试，让所有参与者实际听见：

> 生田正式钢琴 opening → 堀 first voice → 高三 SSAA ensemble

中元日芽香在亲自参与并听过结果以后，再提出：

> **为什么是堀？**

这仍然是专业追问，不是程序质疑或胜负比较。松下的回答可以比此前预想更充分，但必须停留在真实音乐工作：昨天基础练习里听到的起音、线条、音色、尚未本能寻找 ensemble 的个人轮廓，以及高三成员已经高度成熟、会很快互相调整形成整体的差异。

中元若继续问，只问 S2 声部长真正需要执行的问题，例如进入点、balance、是否追随堀的音色、怎样避免过早把和声坐实等。她一旦理解，立即把判断转化为 S2 工作，而不是承担情绪解释。

生田同样可以提出 opening 是否改动、从哪里开始改变等实际伴奏问题；松下应明确她原先完成正确的部分仍然正确。

### 开放连接问题必须从实际排练中长出来

松下最初可以以为 `piano → Hori → SSAA` 的新结构已经足够；真正试起来以后才发现，堀的独立声音一旦成立，成熟 ensemble 直接进入会过快把这份单独轮廓收掉，因此作品现场自然长出一个新的连接需求。

这个问题不是为了测试生田而预设的考题，而是松下自己的艺术修改制造出的真实编排工作。

松下于是让生田在堀结束后先“接一下”，再由自己带 S2 / ensemble 进入。具体术语后续确认。

当前进入架构已锁定：

> **堀短句 → 生田四拍连接 → S2 先进入 → S1 → A1 → A2 → 堀并入 S1。**

S2 是四拍连接以后第一个出现的高三声部。这样新的合唱声音先从内声部形成，不由更显眼的 S1 立即把堀的短句接成完整旋律；随后 S1、A1、A2 依次补全，堀再按指定位置并入 S1。这里锁定的是声部进入顺序与排练因果，不锁具体音高、和弦、歌词、呼吸位置或各声部之间相隔的实际拍数。

生田立即给出音乐上完全正确、漂亮而合理的连接，然后在没有足够终止条件时停住。这个停顿不拍成失败、慌乱或戏剧性卡壳；她只是完成了当前明确任务，然后等待尚未给出的下一项条件。

松下首先把它理解为自己的排练信息不够，而不是发现生田的心理问题。他可以在真实排练迭代里逐步补条件，例如长度、和声边界、landing、cue；每增加一个明确条件，生田都立即高质量做到。松下也可根据实际声音继续微调这些条件，直到新结构成立。

因此 Day 2 的专业结论必须是：**排练进展很好。**

- 松下得到一个更有兴趣、且已经开始成立的新版本；
- 堀完成了作品需要的短 first voice；
- 中元与 S2 得到清晰的工作要求；
- 生田把所有明确要求全部高质量完成；
- 没有人带着“今天暴露了一个问题”的结论离场。

观众只被允许看见一个尚未被角色命名的小事实：

> **当任务从明确的音乐条件变成“你自己决定一下”时，生田会停下来等条件。**

这个事实要到 Day 3 才真正获得重量。

## Day 3｜新谱解决作品，一次专业追问留下新的工作问题

松下把 Day 2 排练中确认过的四拍连接写成正式替换页。新谱第一次进入合练时，生田必须一遍完成；松下随即确认开头采用该版本，并把排练转向第二段、A1 / A2、咬字、换气等其他正常工作。不得让全场继续围绕生田的四拍反复检查，也不得制造“终于弹出来”的庆祝。

排练后，生田基于同一组声音边界，只主动弹出一个同样可行的替代连接。松下承认它在音乐上可以成立，并只从作品角度说明它与谱面版本在和声预示等声音结果上的不同。他最终选择写下来的版本，因为它满足当前声音条件，也因为这是他想听的版本；正式演出必须使用已经写定、可以稳定复现的连接。

当前问答方向锁定，但不锁最终逐字对白：

> 生田：都可以的话，最后怎么定？
>
> 松下：说明具体声音条件；承认创作者选择；正式演出使用写下来的版本。

松下不把回答扩展成“创作是什么”，也不分析生田。作品问题到这里已经完全解决。

问答结束以后，松下自然回到中元和 S2 的下一项工作。这场正式排练到此结束，不在同一场里追加生田独处、重复演奏、整理 A / B / C、面对空白 D 或拿来节拍器。

经过其他文化祭场面以后，Day 3 稍后才回到生田本集唯一一次私人练习。场面不使用条件表、连续失败或重复证据；松隆子从演奏室外看见几秒，生田不知道她在。松隆子不进去、不询问，也不当场作任何处理。

摄影机随后再次离开音乐线，经过其他文化祭工作。到 Day 3 下班前，松隆子才普通地给多年合作的熟人 Fukase 打电话，约他周四下午来学校。电话只保留松隆子一端；听筒另一端的回答由她后续的话自然成立，不作为悬念隐藏，也不让电话承担学生分析。

Day 4 周四下午，Fukase 按约来到学校。学生不被带出校园。他先在音乐与美术别馆自己看见万理华的模型，直接索要，万理华直接拒绝；松隆子随后带生田来找他，以最低限度礼仪完成第一次介绍。三人再转入演奏室，从两个四拍版本的真实上下文开始，确认正式演出问题已经解决，再由生田继续追问作品形成以前如何开始与选择；Fukase 打开真实职业创作的尺度，松隆子以“右手，四小节”提供第一次可进入的容器。模型请求与首次见面开场已锁，后续音乐对白与细节仍未锁。

- **Day 1：** 高三原版达到演出要求；松下看见堀并用短基础无伴奏练习确认她当前声音；万理华 1:1 放样；榊陵进入。Day 1 不把堀直接放进作品。
- **Day 2：** 松下完整解释并排练新的作品理解；先实际听见堀版，再由中元进行专业追问；新结构在现场长出连接需求；生田每得到一个明确条件都立即完成，所有人都认为排练正常且成功推进。
- **Day 3：** 松下带来正式替换页；生田一遍完成，作品转入其他正常排练；她随后只确认一个替代版本也可成立，并问清作品最终怎样决定。经过其他文化祭场面以后，才出现唯一一次私人练习、松隆子门外观察，以及更晚的单端电话。
- **Day 4：** 周四下午，Fukase 按约来到学校；他先自己看见万理华模型并被直接拒绝，松隆子随后带生田来找，以最小介绍转入演奏室。之后从两个四拍进入真实音乐问答、Fukase 打开创作尺度及松隆子给出“右手，四小节”的场景机制已经锁定。开场最小对白已锁，音乐对白与细节仍按 Gate 0 继续讨论。
- **Day 5：** 排练开始前，生田独自在演奏室内以右手完成第一次四小节尝试；她认真听完最后留下的声音，看见还有时间后主动开始第二次，并改变第二个音。没有教学、验收或旁人确认。具体音高、和声、时值及场景最终位置未锁。
- 本文件锁定五日推进，不因此自动判定整个 Gate 0 已通过；仍需按工作流检查本集其他人物线、现实因果与整体结构。

## 写作纪律

- 不把艺术判断压缩成“发现新人 → 当场灵光一闪 → 立刻改编”。
- 不为了制造主线速度，让 Day 1 必须出现生田问题。
- Day 1 可以只让一个艺术家重新听清一副自己本来就认识的声音；Day 2 才让他决定拿它做什么。
- 同一种声音状态在不同任务里的价值可以不同：普通 ensemble 教育会要求一年级逐渐学会听周围、融合与调整；松下在这一次具体作品里却可能正需要堀当前尚未完全被共同体声音吸收的轮廓。两者不矛盾，也不被写成“教育压制艺术”。
- 松下允许在排练中说得较长，但长是因为作品需要被共同执行，不是因为观众需要被教育。
- **音乐本身在工作，剧情从工作里面长出来。**
