# EP04《音乐室》｜Reality / Institution Review

> 状态：**LOCKED｜STEP 1 / Gate 1 PASS。**
>
> 本文件只检查 EP04 的时间、制度、空间、权限与专业流程是否允许这些事情真实发生；不评价人物弧、戏剧效果或最终对白。

# 一、结论

**PASS。无结构性现实 / 制度 RED。**

EP04 可以被理解为文化祭前一周五个正常授课日里，一组已经进入正式准备阶段的音乐、美术与联合项目工作。课堂照常，主要准备发生在放学后；周末承担全天搬入、安装、彩排与安全确认；文化祭于下一周周一举行。

本集不依赖：

- 为主角临时开放的学校特权；
- 不合理的跨专业指挥或成人越权；
- 一天内完成大型作品制作；
- 尚未存在的校园空间；
- 人物犯错后由另一人物完成主题教育；
- 摄影机出现才会发生的行为。

# 三、音乐工作的专业合理性

权威文件：

合唱部是乃校具有传统与声望的旗舰社团，但本集不是竞赛叙事。高三文化祭节目处于校内正式制作状态。

松下作为既有合唱作品及本次特殊版本的创作者，可以：

- 修改作品开头；
- 解释演员必须知道的作品要求；
- 指定进入、长度、呼吸、声部、balance 与 cue；
- 在排练中发现新问题并继续改写；

# 四、美术制作与一比一放样

权威文件：

- [`marika-layout-test-lock.md`](marika-layout-test-lock.md)
- [`../../world/music-and-art-annex-lock.md`](../../world/music-and-art-annex-lock.md)

万理华并非在本集临时产生完整作品。她带着已经存在的模型进入 Day 1 放样，将模型比例转换为真实行走尺度，以检查观看路径、转身空间、出口与装置边界。

学校可以提供两个都合规的展示方案：修改作品尺度后留在中央公共区旁的原定高人流位置，或保持作品并移动到偏离主要动线、具备独立出入口与外围绕行的东翼第二展示室。万理华确认第二展示室仍会在文化祭导览册和楼层地图中正式标记以后选择后者；她不修改作品，并承担偶然看见它的人更少。后续切割、结构、材料与安全工作由适当空间、设备和成人监管承接；学生不被写成可以无监管完成所有重型技术工作的万能制作人。

精确基座、连接件、阻燃、配重、运输分段和施工图属于美术及技术制作阶段的交付，不阻塞本集结构成立。

# 五、成人角色的权限边界

本集三位成人的专业责任不同：

| 人物 | 本集专业范围 | 不承担的工作 |
|---|---|---|
| 松下 | 自己作品的创作、改写与合唱排练 | 对学生作心理诊断；替生田解释成长主题 |
| 松隆子 | 校内音乐教育、学生安全、资源与人员协调 | 替松下决定作品；把自己的演奏方法冒充唯一答案 |
| Fukase | 前工作阶段的创作方法、聆听与开放尝试 | 接管校内合唱作品；给出一套可复制的“free 正解” |

Fukase 是学校多年合作的外部专业人士。松隆子自然看见生田和平时不同后，先进入作极短询问，只确认正式谱面已经没有问题而生田仍在继续；她不据此完成心理诊断。到自己日常工作结束前，她才联系熟人，请他次日下午到校见一名学生，时间和关系都成立。来访登记、空间预约及校内陪同可以按正常行政流程在画外完成，不需要把手续写成剧情。

松隆子把学生交给更合适的专业者，不是推卸教育责任；Fukase 打开过大的创作空间之后，她再把尝试限制为右手、四小节，也不是修正 Fukase 的错误，而是在自己的教育专业内为学生提供可进入的尺度。

### 判断

成立，且没有权限重叠。

# 七、无摄影机检查

### Q1｜如果摄影机不存在，学校这周会怎样运行？

正常上课；各项目在放学后准备；周末全天安装和彩排；周一举行文化祭。摄影机不改变制度日程。

### Q2｜人物为什么会额外停留、观察或作出选择？

松下因作品继续改写；中元因声部长职责追问进入和 balance；堀因获得具体演唱任务参与排练；生田因尚未得到可执行条件继续处理音乐；松隆子因看见长期熟悉的学生出现不同而先询问，取得有限事实后才联系适合处理作品形成前阶段的合作者；Fukase因自己的创作兴趣注意到万理华的模型；万理华面对真实的展示代价选择作品不改、观众更少。它们都来自人物与工作，不来自“这一集需要一个转折”。

### Q3｜摄影机是否触发或解释了任何事件？

否。摄影机只进入已经有人工作的合唱室、演奏室、Open Studio 与教师工作区。它不要求人物复述前情，也不要求角色把观察所得说出来。
