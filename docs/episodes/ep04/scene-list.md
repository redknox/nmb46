# 二、逐场结构

## S01｜原版已经成立

**Day 1／合唱排练室**

从生田正式钢琴 opening 开始。高三 SSAA 完整进入，松下正常工作，原版达到演出要求。

演唱结束后，房间进入普通转换：翻谱、喝水、声部移动。松下看见旁听区里的堀，让她唱两三小节合唱部熟悉的基础练习。他听够以后普通结束，堀坐回旁听区域，排练继续。

场景不留堀的反应，不暗示松下已经想好新版本。

## S02｜模型里没有真实的人

**Day 1／美术展示区**

万理华已经完成地面放样和一两块临时框架，西野扶着其中一处。一名按日常状态拎指定正鞄的学生通过；身体能过，包需要移到前面或轻擦临时构件。

负责成人只确认学校已经存在的两种运行条件：扩大尺度，可连续开放、让更多人经过；保持尺度，则改用可控制人数的方式，实际看见的人更少。

万理华确认必要条件，选择保持作品。她和西野立即拆放样材料、取用正式制作材料，工作从放样自然转入模块制作；不留她独自在空场里凝望作品。

## S03｜榊陵进入工作

**Day 1／旧礼堂侧门、舞台与后台动线**

约一分钟的桥段，不是榊陵介绍场。

樱井与山下带着两校参与者确认工作区。男生拿卷尺、木棍和简易框架进入女子学校，身体上仍有初次进入对方空间的自觉；女生在自己的主场正常观看和工作。

dummy 开始通过既定路线。有人去处理下一段尺寸，摄影机不等待他们开会或阶段汇报。

## S04｜作品重新长出来

**Day 2／合唱排练室**

本集最长场景，保持为一条连续工作链：

1. 原版开头短走一次；
2. 松下提出修改；
3. 堀进入 first voice；
4. 高三 SSAA 直接接入；
5. 众人实际听见变化；
6. 中元问为什么是堀；
7. 松下回答声音与作品；
8. 中元回到 S2 进入及 balance；
9. 再试以后，松下发现独立声音被 ensemble 收得太快；
10. 他让生田接一下；
11. 生田完成明确任务后等待；
12. 松下逐项补足四拍、和声边界、landing 与 cue；
13. 每次条件改变，生田立即做到；
14. `Hori → Ikuta → S2 → S1 → A1 → A2` 开始成立。

场内允许喝水、翻谱、换位置与创作者寻找准确语言。场景结束时，排练正常继续或收尾；没有人认为生田发生了问题。

## S05｜正确答案出现

**Day 3／合唱排练室**

松下发正式替换页。生田看一遍，一次完成。松下确认采用，随即转向其他声部工作。

排练后，生田弹出另一个同样成立的连接，向松下作一次专业追问。松下说明两种结果的声音差异及自己的作品选择。生田得到完整、合理的作品答案。

松下转回中元和 S2。摄影机随排练继续片刻再离开，不留生田独自思考的强调镜头。

## S06｜生田直接说出问题

**Day 3／演奏室**

生田进行本集唯一一次私人练习。

松隆子从二层教师准备室下楼准备离馆，正常经过观察窗。她看见生田仍在这里，停几秒后进入，问怎么了。

生田直接说明：新谱没有问题；她知道松下为什么选择这个版本；另一个版本也可以；如果由自己决定，她不知道该选哪一个。

松隆子通过几句事实确认听懂问题，但不总结、不提 Fukase，也不承诺安排。她只确认生田是否还要继续，然后离开；生田留下。

## S07｜另一处工作收尾

**Day 3／旧礼堂后台与侧台**

榊陵的 dummy 路线测试正常完成。主景模拟物到达位置后，双方确认独立站立时需要增加支撑 / 固定深化；这是正常制作判断，不作为坏消息。

收卷尺、拆简易框架时，樱井与山下顺手确认周一上午联合演出及下午 `13:30 changeover`。有人叫樱井处理别的事，确认自然结束。

## S08｜电话

**Day 3／傍晚／车站入口附近**

松隆子已经离开学校，随下班与放学人流走到车站前，在不妨碍通行的位置停下，给多年合作的 Fukase 打电话。只保留她这一端，只完成次日下午来校见一个学生的约定。

挂断以后，她把手机收回包里，进入车站。电话不制造悬念，不拍联系人、手机屏幕或 Fukase 另一端。

## S09｜这个给我吧

**Day 4／Open Studio / 共同制作室**

Fukase 已经正常进入别馆。Open Studio 里已有编号框架、构件、材料与正在继续的共同劳动；这些状态吸收原独立制作场的信息，不另作进度展示。

他在等待时看见工作桌上的模型，自己移动位置，找到图形成立的角度，直接提出请求；万理华直接拒绝，他接受拒绝。

松隆子带生田出现，只介绍名字。双方完成第一次见面的必要礼仪，随后转去演奏室。万理华与西野继续工作，模型不再进入后续谈话。

## S10｜世界过大

**Day 4／演奏室**

本集第二个长场景，保持为真实音乐工作的连续行动：

1. 生田先弹正式四拍版本；
2. 再弹自己保留的另一个版本；
3. Fukase 确认前后音乐、堀的结束位置及 S2 进入；
4. 三人从真实声音讨论两个版本；
5. 生田追问作品形成以前怎样开始；
6. Fukase 让她接触聆听一个音、一个和弦、不同组合与下一步的真实工作尺度；
7. 生田听得懂每一步，却仍无法从庞大的可能性中找到自己的第一步；
8. 松隆子依据现场工作，才把第一次尝试限制为右手、四小节。

不要求生田当场完成。Fukase 不留下总结、评价、励志金句或作业。场景结束在具体边界已经出现、内容仍然空着。

## S11｜第二个音

**Day 5／演奏室／正式排练前**

不再单独展示全校各线进度。

生田提前来到之后本来就要使用的演奏室，拥有一小段正常空档。她以右手完成第一次四小节，听最后的声音消失。

她看见还有时间，重新开始。第二个音与第一次不同。

全集结束。

# 三、Scene List 执行边界

- 11 项是场景 / 连续段落，不因内部 Beat 较多再次拆碎；
- Day 2 与 Day 4 的内部变化依靠真实工作刷新观看任务，不机械切成多场；
- Day 1 的 S03 始终作为进入既有工作的短桥段，不拍成榊陵登场仪式；
- Day 3 的 S07、S08 保持环境与时间重量，不升级为独立支线；
- Day 5 不替其他人物或项目收尾；
- 具体转场、场内走位、普通学生密度、道具状态与最终对白进入 STEP 7 Treatment 处理。
