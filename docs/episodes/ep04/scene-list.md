# 二、逐场结构

## S01｜原版已经成立

**Day 1／合唱排练室**

从生田正式钢琴 opening 开始。高三 SSAA 完整进入，松下正常工作，原版达到演出要求。

演唱结束后，房间进入普通转换：翻谱、喝水、声部移动。松下看见旁听区里的堀，让她唱两三小节合唱部熟悉的基础练习。他听够以后普通结束，堀坐回旁听区域，排练继续。

场景不留堀的反应，不暗示松下已经想好新版本。

## S02｜模型里没有真实的人

**Day 1／中央公共区旁的原定高人流候选位置**

万理华已经完成地面放样和一两块临时框架，西野扶着其中一处。一名按日常状态拎指定正鞄的学生通过；身体能过，包需要移到前面或轻擦临时构件。

满岛只确认学校已经存在的两种运行条件：扩大尺度，可以留在原定高人流位置；保持尺度，则把作品移动到偏离主要动线的东翼第二展示室，实际看见的人更少。

万理华确认第二展示室仍会在文化祭导览册与楼层地图中正式标记以后，选择作品不改、移动展室。她和西野立即拆放样材料、取用正式制作材料，工作从放样自然转入模块制作；不留她独自在空场里凝望作品。

## S03｜场地是第一次

**Day 1／旧礼堂舞台、侧台与后台动线**

联合制作已经在榊陵合排数月。演员彼此熟悉，乃校旧礼堂则是第一次由完整工作组进入。

舞台上只有排练椅、位置线、按当时方案制作的实寸确认框及合唱台模块。榊陵学生演出只处理场地走位；乃校学生舞台监督组织撤景与合唱台并行的一小时转场演练。山下承担引率与离校责任，不参与学生艺术及技术指挥；樱井不在场。

演练正常完成。场景不强调最窄处、上沿或最高层合唱台，也不解释未来因果。男生进入女子学校仍有普通青春自觉，但熟悉的演员之间已经能够直接工作。

## S04｜作品重新长出来

**Day 2／合唱排练室**

本集最长场景，保持为一条连续工作链：

1. 原版开头短走一次；
2. 松下提出修改；
3. 堀进入 first voice；
4. 高三 SSAA 直接接入；
5. 众人实际听见变化；
6. 中元问为什么是堀；
7. 松下回答声音与作品；
8. 中元回到 S2 进入及 balance；
9. 再试以后，松下发现独立声音被 ensemble 收得太快；
10. 他让生田接一下；
11. 生田完成明确任务后等待；
12. 松下逐项补足四拍、和声边界、landing 与 cue；
13. 每次条件改变，生田立即做到；
14. `Hori → Ikuta → S2 → S1 → A1 → A2` 开始成立。

场内允许喝水、翻谱、换位置与创作者寻找准确语言。场景结束时，排练正常继续或收尾；没有人认为生田发生了问题。

## S05｜正确答案出现

**Day 3／合唱排练室**

松下发正式替换页。生田看一遍，一次完成。松下确认采用，随即转向其他声部工作。

排练后，生田弹出另一个同样成立的连接，向松下作一次专业追问。松下说明两种结果的声音差异及自己的作品选择。生田得到完整、合理的作品答案。

松下转回中元和 S2。摄影机随排练继续片刻再离开，不留生田独自思考的强调镜头。

## S06｜生田直接说出问题

**Day 3／演奏室**

生田进行本集唯一一次私人练习。

松隆子结束别馆内的工作，从二层音乐教师准备室下楼，准备返回主楼一层主职员室完成下班前收尾；正常路线经过演奏室观察窗。她看见生田仍在这里，停几秒后进入，问怎么了。

生田直接说明：新谱没有问题；她知道松下为什么选择这个版本；另一个版本也可以；如果由自己决定，她不知道该选哪一个。

松隆子通过几句事实确认听懂问题，但不总结、不提 Fukase，也不承诺安排。她只确认生田是否还要继续，提醒统一离校时间将近，然后离开别馆返回主楼；生田留下。

## S07｜今天到这里

**Day 3／旧礼堂舞台**

舞台只使用排练桌椅、位置线与必要的实寸确认框。摄影机从一段多人语言交错的尾声进入；榊陵学生演出让当前段落走完，才正常结束当天工作。两校演员收剧本、喝水、继续争刚才谁抢了谁的句子，谈话不重新分成两校。

乃校学生舞台监督只处理位置线、椅子与确认框，不再进行一小时搭拆演练。山下等待并清点榊陵学生，不作艺术笔记。本场保持为生田询问与松隆子电话之间的另一处正常工作。

## S08｜电话

**Day 3／傍晚／车站入口附近**

松隆子已经离开学校，随下班与放学人流走到车站前，在不妨碍通行的位置停下，给多年合作的 Fukase 打电话。只保留她这一端，只完成次日下午来校见一个学生的约定。

她明确问第二天下午三点半能否来学校，再说有个学生想让他见见。听筒另一端只通过她的“嗯，我也在”获得最低限度的存在；两人随即约定明天见。熟悉允许省略学生说明，不省略实际工作需要的时间与地点。

挂断以后，她把手机收回包里，进入车站。电话不制造悬念，不拍联系人、手机屏幕或 Fukase 另一端。

## S09｜这个给我吧

**Day 4／Open Studio / 共同制作室**

Fukase 按约到校，由松隆子从中央入口沿正常动线带往演奏室。两人经过正常开门的 Open Studio 时，他自己被工作桌上的模型截停；松隆子只说“我去叫她”，继续去十几秒外的演奏室。生田已经按约在那里等候。

Fukase 走进共同制作室，自己移动位置并找到图形成立的角度；摄影机不替他取得该视点。他直接提出请求，万理华直接拒绝，他接受拒绝。

松隆子带生田回来，只介绍名字。双方完成第一次见面的必要礼仪，随后一起返回演奏室。没有人迟到，也没有人被安排在 Open Studio 等候或在校内闲逛。万理华与西野继续工作，模型不再进入后续谈话。

## S10｜世界过大

**Day 4／演奏室**

本集第二个长场景，保持为真实音乐工作的连续行动：

1. 生田先弹正式四拍版本；
2. 再弹自己保留的另一个版本；
3. Fukase 确认前后音乐、堀的结束位置及 S2 进入；
4. 三人从真实声音讨论两个版本；
5. 生田追问作品形成以前怎样开始；
6. Fukase 让她接触聆听一个音、一个和弦、不同组合与下一步的真实工作尺度；
7. 生田听得懂每一步，却仍无法从庞大的可能性中找到自己的第一步；
8. 松隆子依据现场工作，才把第一次尝试限制为右手、四小节。

松隆子只说“昨天那两个四拍，弹一下”。Fukase 先要求从堀最后一个音开始，确认正式演出版本及松下的作品选择已经成立；未采用版本因此可以“现在不用选”。生田继续追到材料尚未形成作品以前的工作，Fukase 只谈前后、演唱者、歌词、交付、录音与可以没有成果的普通工作日，不整理创作哲理。最后他让生田现在先有一点声音，仍不给起音、去向与长度；松隆子才给出“只用右手。四小节”。

不要求生田当场完成。Fukase 不留下总结、评价、励志金句或作业。场景结束在具体边界已经出现、内容仍然空着。

## S11｜第二个音

**Day 5／3-B → Open Studio → 演奏室／终礼后、正式排练前**

不再单独展示全校各线进度。

3-B 终礼结束，生田随正常放学人流离开；摄影机不跟她穿过校园。Open Studio 里，万理华与西野把当天最后一件编号构件固定到周转架，锁住脚轮，再转身收工具。该段不宣布作品完成，也不解释周末搬入；戏剧线不重复收束。

生田随后提前来到本来就要使用的演奏室，拥有一小段正常空档。她以右手完成第一次连续四小节，听最后的声音消失；不使用看钟证明“还有时间”。

她自己重新开始。第一个音与第一次相同，第二个音改变。新的音程仍在衰减时，全剧结束。

全集结束。

# 三、Scene List 执行边界

- 11 项是场景 / 连续段落，不因内部 Beat 较多再次拆碎；
- Day 2 与 Day 4 的内部变化依靠真实工作刷新观看任务，不机械切成多场；
- Day 1 的 S03 是一次真实、成功的技术转场演练，不拍成榊陵登场仪式或 EP05 事故预告；
- Day 3 的 S07、S08 保持环境与时间重量，不升级为独立支线；
- Day 5 不替其他人物或项目收尾；
- 具体转场、场内走位、普通学生密度、道具状态与最终对白进入 STEP 7 Treatment 处理。

# 四、STEP 6 压力测试结论

- 原独立万理华制作场只承担“她还在做”的提醒功能，已删除；制作状态吸收进 S02 结尾与 S09 Open Studio。
- 松隆子从二层下楼、经过演奏室并离开别馆以后，不再返回别馆二层；她先回主楼一层主职员室完成收尾并取私人物品，电话再移至正式离校后的车站入口附近。
- 车厢内通话不符合日本铁路日常礼仪，因此不使用电车车厢；下班移动仍然成立。
- S03 完成当时条件下的一次正确转场演练；S07 只承担演员合排收尾，不重复路线测试，也不为 EP05 制造事故伏笔。
- S04、S10 的内部观看任务持续变化，保持专业长场，不机械拆分。
- 五日时间、空间使用、普通学生存在与人物相遇来源均成立。

Scene List 的观看体验可以作为连续生活进入 Treatment。
