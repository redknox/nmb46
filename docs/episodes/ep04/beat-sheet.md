# EP04《音乐室》Beat Sheet

> 状态：**LOCKED / STEP 3 PASS。**
>
> 本文件冻结 EP04 的五日大型因果、人物推进级别、情绪换挡与结尾。具体场次边界、最终对白、音乐材料和镜头组织留给后续步骤。

# 一、本集成立的核心因果

一份原本已经达到演出要求的作品，被创作者重新打开。松下在真实排练中逐步形成新版本；生田能够高质量完成每一项明确条件，却第一次发现：当多个方案都可以成立时，正确不能替她决定自己想要哪一个。

松下正确地完成作品，Fukase 打开作品形成以前庞大而未决定的世界，松隆子再把第一次尝试缩小为“右手，四小节”。没有人修正另一个人的错误，也没有人替生田完成选择。

万理华同时把已经成立的模型推进到现实空间。她接受制度提供的两个可执行方案，选择不改作品、承担更少人看见，并继续制作。她与生田不互相教育，也不在对白中形成主题对应。

---

# 二、五日 Beat

## Day 1｜一切原本已经成立

1. 高三合唱原版从正式钢琴 opening 开始完整走一次，已经达到演出要求。没有人因能力不足而需要被纠正。
2. 堀本来就在合唱部空间里。松下听见她的声音，只用最小的无伴奏基础练习确认材料，不当场宣布新设计。
3. 万理华把已有模型推进到 1:1 放样。真实书包、人流、停留与通行条件进入作品。
4. 学校提供两个都合规、都能执行的展示方案。万理华不改作品，选择较低人流、可控制进入人数的方式，并承担更少人看见。
5. 西野作为美术同学自然参与收放样材料与后续制作。榊陵联合项目也按既定安排进入校园准备。

**情绪换挡：** 完成 → 现实材料进入 → 有代价的选择。

## Day 2｜作品在排练中重新长出来

6. 松下在原版已经成立的前提下提出修改开头：他想让 ensemble 晚一点成立。
7. 他把堀作为 optional first voice 放入开头，只说明演唱所需的音、文本、长度、呼吸与进入位置。众人先唱、先听。
8. 中元在亲自参与以后才问为什么是堀。松下只回答自己听见的作品差异；中元随即回到 S2 声部长的进入与 balance 工作。她与堀承担不同角色，不形成竞争或替代关系。
9. 排练进一步发现 `Hori → SSAA` 会过快收掉独立声音，连接需求从音乐本身长出来。
10. 松下让生田先接一下。生田先完成唯一明确的事并等待；随着松下逐项补足长度、和声边界、landing 与 cue，她每次都立即高质量完成。
11. 新结构成立。所有人都认为排练进展很好，没有人带着“今天发生了问题”的判断离开。

**情绪换挡：** 好版本 → 被重新打开 → 新版本在共同工作中成立。

## Day 3｜作品的问题解决了

12. 松下带来正式替换谱。生田一遍完成，作品采用该版，排练继续处理其他段落。
13. 生田只作一次专业追问：另一个版本同样成立，为什么最终采用谱面版本。松下说明两者的声音结果与自己的作品选择，然后回到中元和 S2。
14. 万理华进入模块化制作。组框、定位与材料处理作为持续劳动存在，不另造戏剧危机。
15. 放学后，生田进行本集唯一一次私人练习。松隆子看见她和平时不同，进来问“怎么了”。
16. 生田直接说明：新谱没有问题；她理解松下为什么这样写；另一个版本也可以；但如果由自己决定，她不知道该选哪一个。松隆子通过几句事实确认听清问题，不总结、不诊断，也不承诺安排任何人。
17. 榊陵完成当天正常的路线、dummy 与支撑确认，并在收东西时极轻地确认周一上午演出及 `13:30 changeover`。这段工作隔开询问与电话。
18. 临近下班，松隆子才联系多年合作的 Fukase，只询问他次日下午是否有空，并约定来校见一个学生。

**情绪换挡：** 正确答案完成作品 → 生田准确说出仍未完成的部分 → 学校照常工作 → 一项普通安排。

## Day 4｜门被打开，但里面太大

19. Fukase 按约到校，在熟悉的艺术别馆等待时自己看见万理华的模型。他移动位置找到图形成立的角度，直接索要模型；万理华直接拒绝，他接受拒绝。
20. 松隆子带生田来找他，只完成最低限度的初次介绍，随后进入演奏室。模型不被带入后续谈话，也不承担解释生田线的功能。
21. Fukase 先听生田演奏正式版本、另一版本及其音乐上下文，再从真实材料进入工作。
22. 他让生田接触作品形成以前的工作尺度：聆听一个声音、和弦、组合与下一步，但不把开放创作整理成另一套标准答案。
23. 生田能够理解他正在做什么，却一时无法进入如此庞大的未决定空间。她没有当场完成成熟即兴，也没有获得答案。
24. 同一场工作中，松隆子依据长期教育关系给出最小容器：右手，四小节。她只降低进入门槛，不决定内容。

**情绪换挡：** 创作者的日常欲望 → 真实音乐材料 → 世界突然变大 → 第一步被缩小。

## Day 5｜第一次落手

25. 星期五的文化祭准备继续。万理华的模块进入可供周末搬入、组装的状态；联合项目按自己的进度推进。学校不需要在 Day 5 全部 ready。
26. 排练前，生田独自在演奏室里，以右手完成第一次四小节尝试。
27. 她听完声音，不寻求评价，也不等待别人填写下一步。
28. 她看见还有时间，重新把手放回琴键，主动改变第二个音，开始第二次。

**情绪换挡：** 正常准备 → 安静开始 → 自己再来一次。

# 三、人物推进级别

## M｜生田绘梨花

本集唯一主推进人物。她没有学会 free，也没有放弃准确。她从“没有条件，所以暂时不动”走到“没有答案，也可以先听一个声音”。

## S｜伊藤万理华 / 中元日芽香

- 万理华不完成大型人物弧；她完成从模型、1:1 放样、选择到持续制作的现实推进，并承担作品更少被看见。
- 中元通过实际排练确认自己与堀承担不同位置，随后继续完成 S2 声部长的工作，不获得安慰戏或竞争戏。

## L｜堀 / 松下 / 松隆子 / Fukase / 西野 / 榊陵相关人物

各自只承担已有专业关系中的必要工作，不被抬成万能中枢。

## R｜其余人物

当前五日因果不需要まあ亚才能成立，因此 Beat Sheet 不为人物对照强设入口。若后续 Scene 阶段没有自然的既有工作相遇，本集不使用她。

---

# 四、结构重量

- Day 2 是全集最长、最完整的专业工作段落；
- Day 4 是第二个大段，重量来自真实音乐工作，不来自“名人到访”；
- Day 1 承担作品与现实条件的建立；
- Day 3 是因果铰链，允许信息较密，但不同工作不能全部扩张成独立完整场景；
- Day 5 极短，只完成第一次行为顺序变化。

五天不平均分配场数或时长。

---

# 五、必要回声与禁止解释

- 万理华已经能够在两个成立方案中承担自己的选择；生田刚刚发现“成立”不会自动生成“我要”。这是整集结构关系，不进入人物对白，不做对照剪辑说明。
- Fukase 索要模型与后来听生田都来自同一种日常创作者行为，但任何人都不总结这项相似。
- Day 3 必须让观众准确知道生田碰到了什么问题；人物可以谈事实与真实困惑，但没有人解释“这场戏意味着什么”。
- Day 5 不使用成功确认、教学验收、他人旁观或总结性对白。

---

# 六、结尾

生田第一次四小节不是练习成果展示，而是她第一次在只有边界、没有内容时自己开始。

全集结束在她主动开始第二次，并改变第二个音。

> **她没有学会 free。她打开了一片新天地。**
