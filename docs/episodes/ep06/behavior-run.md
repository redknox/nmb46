## 一、桥本奈奈未｜BKG / C类信息

终礼后，她确认自己的日程，从容收好书包，独自离开。

- 不看钟特写；
- 不表现焦急；
- 不由别人评论；
- 摄影机不跟随；
- 不解释车次、通勤、成本与家庭责任。

她不是为EP09埋伏笔才离开；即使摄影机不在，她也会这样使用时间。

## 二、伊藤万理华｜S

万理华直接邀请西野去旧书店，不使用“归还美术资料”等制度任务。

她们可以安静地各自翻书。西野看到一项16:30结束的小型展示信息后，万理华只提供更近的出口或路线；她按自己的日程回家，不鼓励、不陪同，也不解释西野的兴趣。

这继续建立二人的稳定审美接口，但不完成西野对万理华的双向A。

## 三、西野七濑｜M

西野看到展示信息后，独自改变路线。展示是否赶得上构成前半集清楚但低重量的微型目标。

独自绕路仍是她的默认行为，不构成变化。本集真正的新动作只发生在结尾：

> 她把原本属于自己的无目的时间，主动邀请高山进入。

她不解释展示的意义；展示关闭也不被拍成挫折。

## 四、和田まあ亚｜L

まあ亚与高山及普通同学共同离校。她从一开始就在找家里要买的东西；逛文具店时，她因为天然几次把普通谈话推到微妙停顿，却没有恶意，也不承担“麻烦制造者”功能。

高山总比别人更快接住这些停顿。第一次化解顺利，后来一次救场只得到很轻的反应，她仍本能补上第二句。观众因此先于高山感觉到这种日常劳动；人物不以对白解释。

到分路口，まあ亚转向另一间店并自然问高山是否一起。高山选择去车站；まあ亚普通接受。她不察觉高山“落单”，不因分别受伤，也不承担把高山送往西野路线的功能。

## 五、高山一実｜M

高山在有人时自然接话、维持轻松，并在文具店数次替まあ亚与普通同学接住将要落空的话。她不把这理解成负担，也不表现不耐烦；同伴离开后，表情只是恢复普通，不表现失落，也不寻找需要陪伴的人。

她沿正常通学主路，在小路出口遇见西野。高山不进入陌生小路“找到她”。

她说去车站时尚未乘车。西野从站侧向展示反向行走，高山从住宅区侧向车站行走，两人在进站前相遇；高山随后清楚偏离原定归家方向，但不以解释性对白说明。

进入家庭餐厅后，高山仍然自然说话、制造笑点。变化只表现为：一次话头落下后，桌子并没有散，她下一次没有立刻补第二句。

她不能理解或说出自己的长期机制；EP11仍保留正面处理权。

## 六、星野南｜S

南因一个普通、无象征意义的购买欲望邀请飞鸟去商业街。途中遇见西野与高山后，她自然加入去看展示；展示关闭后，她最自然地说饿或注意到餐厅。

南不为共同活动寻找意义，也不承担组织四人的功能。

## 七、斋藤飞鸟｜S

飞鸟先质疑必要性，身体仍然参与：

- 跟南去商业街；
- 说买完就回去，却继续等；
- 明知展示快关闭，仍一起走；
- 对突然共同吃饭提出疑问，最终仍进入餐厅；
- 不害怕饭桌沉默，也不替高山救场。

家庭联络是四人的分散个人动作，不固定由飞鸟提醒所有人。

## 九、微型目标与无目的时间

前半集的展示负责提供可追踪的运动方向：

> 想去看 → 途中自然汇合 → 到达时刚刚关闭。

展示关闭后，四人在16:35—16:40决定去家庭餐厅，并在进入前分别联系家里；17:00前后点餐。

核心四人本集均以电车为主要归家方式。南、飞鸟饭后先入站；西野、高山主动暂缓进站，再走一段以后仍会折返公共交通节点，但正片不补拍返程物流。

真正的关系测试从目标消失以后开始：

> 已经没有共同事情，她们是否仍然愿意留下。
