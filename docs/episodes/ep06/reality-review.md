## 一、日历

跨集日历已经锁定：

| 日期 | 学校状态 |
|---|---|
| 周一・海の日 | EP05文化祭 |
| 周二 | 撤收、清扫、复原，提前放学 |
| 周三 | 振替休日 |
| 周四 | 恢复正常授课 |

EP06发生在周四，即文化祭后第一个正常授课日。

周二仍属于文化祭工作的尾声；周三没有“放学”这一动作。周四第一次恢复正常终礼、清扫与离校，学生才真正面对“接下来没有共同任务”。

**结论：GREEN。**

## 二、放学与离校时间

日本高中没有全国统一的完全下校时间，各校自行管理。公开学校规则可见普通下校约17:00、经许可的部活动可延长至18:00等做法。

EP06采用以下可执行时间：

| 节点 | 时间边界 |
|---|---:|
| 最后一节课、终礼与清扫结束 | 15:40—15:50 |
| 学生离校、进入站前商业区 | 16:10—16:30 |
| 看到16:30结束的小型展示信息 | 16:15左右 |
| 展示关闭，临时决定吃饭并联系家中 | 16:35—16:40 |
| 进入家庭餐厅 | 17:00前后 |
| 榊陵运动部学生进入 | 17:30以后 |
| 四人离开餐厅 | 18:15—18:30 |
| 西野、高山继续步行 | 约19:00前结束 |

七月天黑较晚，结尾可以亮起路灯，但不拍成深夜逗留。

**结论：GREEN。**

## 三、放学后进入家庭餐厅

学生穿制服或部活服在放学后进入普通餐饮店，不构成现实禁区。学校之间规则不同：部分学校要求不要“无故”进入饮食店，但仍允许合理进入并要求保持符合学生身份的行为。

EP06采用的工作边界：

> 乃校不禁止学生放学后进入普通餐饮店、书店与商业设施；学生须合理归宅、让家中知晓去向，并维持校外礼仪。

该规则不在正片中由对白解释。四人在餐厅门口或点餐前完成最低限度的家庭联络即可。

**结论：GREEN。**

## 四、临时改变家庭晚餐安排

如果17:30—18:00才通知家里不回去吃饭，家中可能已经开始准备晚餐；不满通常来自“为什么不早点说”和已经准备好的份量，而不是外出吃饭本身。

因此四人在约16:40作出决定，并在进入餐厅前联系家里。此时临时调整仍然成立。

执行约束：

- 不拍四个人依次请示；
- 不逐一介绍家庭回复；
- 只需一个或两个背景动作让家庭世界存在；
- 不把外出吃饭写成违纪或家庭冲突。

**结论：GREEN。**

## 五、家用车辆接送

富裕家庭拥有司机或家用车辆，不等于学校允许车辆在正门聚集。城市学校常因道路安全、学生人流、停车空间和邻里关系，限制家长车辆驶入或在校门附近等待；伤病、恶劣天气、安保或特殊家庭条件可以例外。

EP06采用的工作边界：

> 家庭车辆可以在校外合规地点接送；原则上不在乃校正门及周边道路形成日常等待。学生可步行至固定接送点后上车。

车辆接送可以作为背景分流方式存在，但核心四人本集不使用固定车辆，以免司机等待、联络和接送安排重新把“无安排的时间”变成任务。

**结论：GREEN。**

## 六、共享站前商业区

当前世界设定未锁定城市、最近车站与各人物家庭位置。EP06只建立最低限度地理条件：

> 乃校主要通学路线经过一个未命名的站前商业区，包含旧书店、小型展示空间、普通商店、家庭餐厅、公交站与电车入口。

这里是交通分流节点，不是所有人物住在同一街区：

- 有人乘电车；
- 有人换乘公交；
- 有人步行去另一方向；
- 家庭车辆可以在更远的合规接送点等待。

不在本集锁具体城市、线路和家庭住址。

**结论：GREEN。**

## 七、相遇次数

相遇来源限定为：

1. 西野与万理华共同离校，不算偶遇；

3. 南与飞鸟作为既有同行组整体进入；

不再加入第五组人物，不把EP06写成EP03的校外关系巡游。

**结论：GREEN。**

## 八、万理华提前回家

万理华只看时间并说明自己今天要回去。西野不追问。

不新建补习、家中管束或升学安排。她的具体原因不是本集A类信息。

**结论：GREEN。**

## 九、小型展示

西野注意到的是旧书店或小型文化空间中的低重量展示信息，不建立需要完整交代的大型动物标本展。展示当日16:30结束；西野在16:15左右看到信息，仍有可能赶上。

它构成前半集可追踪的微型目标。四人到达时展示刚刚关闭；关闭不归咎于任何人的耽搁，也不发展成挫折线。目标消失后，她们仍决定共同吃饭，才进入真正的无目的时间。

**结论：GREEN。**

## 十、榊陵幼驯染

榊陵运动部训练约17:30—18:00结束后，几名学生进入同一家庭餐厅成立。他们必须晚于乃校四人进入。

幼驯染不通过母亲转述掌握高山“昨晚回家就睡了”等实时家庭信息，避免无意中建立两个家庭至今仍高频往来的关系。他只凭旧日熟悉或眼前事实与高山交换极短对话。

**结论：GREEN。**

## 十一、桥本的背景动作

终礼后，其他学生仍慢慢收拾、聊天或停留。桥本从容收好书包，独自离开。

约束：

- 不看钟特写；
- 不表现焦急；
- 不由别人评论她总是早走；
- 摄影机不跟随；
- 不解释车次、成本、家庭责任或EP09内容。

当下只让观众看见她对放学后时间已有明确安排；原因留到EP09。

**结论：GREEN / C类信息。**
