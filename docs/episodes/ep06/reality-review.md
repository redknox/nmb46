|---|---|

周二仍属于文化祭工作的尾声；周三没有“放学”这一动作。周四第一次恢复正常终礼、清扫与离校，学生才真正面对“接下来没有共同任务”。

**结论：GREEN。**

## 二、放学与离校时间

日本高中没有全国统一的完全下校时间，各校自行管理。公开学校规则可见普通下校约17:00、经许可的部活动可延长至18:00等做法。

EP06采用以下可执行时间：

| 节点 | 时间边界 |
|---|---:|
| 最后一节课、终礼与必要的班级收尾结束 | 15:40—15:50 |
| 学生离校、进入站前商业区 | 16:10—16:30 |
| 看到16:30结束的小型展示信息 | 16:15左右 |
| 展示关闭，临时决定吃饭并联系家中 | 16:35—16:40 |
| 进入家庭餐厅、完成点餐 | 16:50—17:00 |
| 四人离开餐厅 | 18:15—18:30 |
| 西野、高山继续步行 | 约19:00前结束 |

七月天黑较晚，结尾可以亮起路灯，但不拍成深夜逗留。

**结论：GREEN。**

## 三、放学后进入家庭餐厅

学生穿制服或部活服在放学后进入普通餐饮店，不构成现实禁区。学校之间规则不同：部分学校要求不要“无故”进入饮食店，但仍允许合理进入并要求保持符合学生身份的行为。

EP06采用的工作边界：

> 乃校不禁止学生放学后进入普通餐饮店、书店与商业设施；学生须合理归宅、让家中知晓去向，并维持校外礼仪。

该规则不在正片中由对白解释。四人在餐厅门口或点餐前完成最低限度的家庭联络即可。

**结论：GREEN。**

## 四、临时改变家庭晚餐安排

如果17:30—18:00才通知家里不回去吃饭，家中可能已经开始准备晚餐；不满通常来自“为什么不早点说”和已经准备好的份量，而不是外出吃饭本身。

因此四人在约16:40作出决定，并在进入餐厅前联系家里。此时临时调整仍然成立。

执行约束：

- 不拍四个人依次请示；
- 不逐一介绍家庭回复；
- 只需一个或两个背景动作让家庭世界存在；
- 不把外出吃饭写成违纪或家庭冲突。

**结论：GREEN。**

## 五、家用车辆接送

富裕家庭拥有司机或家用车辆，不等于学校允许车辆在正门聚集。城市学校常因道路安全、学生人流、停车空间和邻里关系，限制家长车辆驶入或在校门附近等待；伤病、恶劣天气、安保或特殊家庭条件可以例外。

EP06采用的工作边界：

> 家庭车辆可以在校外合规地点接送；原则上不在乃校正门及周边道路形成日常等待。学生可步行至固定接送点后上车。

车辆接送可以作为背景分流方式存在，但核心四人本集不使用固定车辆，以免司机等待、联络和接送安排重新把“无安排的时间”变成任务。

**结论：GREEN。**

## 六、共享站前商业区

当前世界设定未锁定城市、最近车站与各人物家庭位置。EP06采用“田园调布—九品佛—自由之丘”式空间作为制作参照，但不在正片点明真实地名，也不据此锁人物住址。

最低限度地理条件为：

> 乃校位于主要车站西南方向的安静住宅区；学校到站约15—20分钟步行。站侧有旧书店与普通商业设施，商业区向住宅区过渡处有小型展示空间，车站附近有家庭餐厅。

自由之丘—九品佛之间不到一公里的绿道及其“热闹商业区逐渐进入安静住宅街”的空间变化，证明这种连续步行动线可以成立。现实中的田园调布双叶距离九品佛站步行10分钟、田园调布站15分钟，可作为豪门私校位于住宅区、学生步行至公共交通节点的尺度参考；两者均只作制作参照，不进入剧中名称。

这里是交通分流节点，不是所有人物住在同一街区：

- 核心四人本集均乘电车回家；
- 有人换乘公交；
- 有人步行去另一方向；
- 家庭车辆可以在更远的合规接送点等待。

高山说去车站时尚未乘车。她从住宅区一侧向车站走，西野从站侧旧书店反向走向展示，两人在进站前自然相遇。饭后南、飞鸟先入站；西野、高山主动延迟进站，结尾步行以后仍会折返公共交通节点。正片不补拍返程，也不把散步写成通往另一车站的交通方案。

不在本集锁具体城市、线路和家庭住址。

**结论：GREEN。**

## 九、小型展示

西野注意到的是旧书店或小型文化空间中的低重量展示信息，不建立需要完整交代的大型动物标本展。展示当日16:30结束；西野在16:15左右看到信息，仍有可能赶上。

它构成前半集可追踪的微型目标。四人到达时展示刚刚关闭；关闭不归咎于任何人的耽搁，也不发展成挫折线。目标消失后，她们仍决定共同吃饭，才进入真正的无目的时间。

**结论：GREEN。**

## 十、榊陵幼驯染｜缩减采用路线

榊陵运动部训练约17:30—18:00结束后进入同一家庭餐厅，在现实上成立。

STEP 4曾因功能重复删除“训练后进入餐厅、在饭桌附近停留”的版本。Treatment阶段重新确认采用更轻的现实路线：约16:45，一名正常放学后沿商业区前往车站的榊陵学生在餐厅门前认出高山，短暂打招呼后继续离开。他不需要刚结束运动部训练，也不进入餐厅。

同伴在他离开后短暂询问。高山明确否认恋爱关系，只说明两人从小住得近；话题在进店时自然结束。该人物不解释高山的过去，不承担新因果，也不进入饭桌。

**现实结论：GREEN；创作结论：REDUCED CAMEO。**

## 十一、桥本的背景动作

- 不看钟特写；
- 不表现焦急；
