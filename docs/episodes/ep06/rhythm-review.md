# EP06《放学以后》｜Rhythm Review

> 状态：**PASS / CLOSED｜STEP 13 整集节奏与重复审查通过。**
>
> 审查对象：当前 `screenplay.md` S01—S10完整母稿。
>
> 本轮只检查连续观看时的长度、重复动作、笑点结构、气口、情绪换挡与群像点名感；不因偏好型润色重开已经锁定的场景。

## 一、总判定

**PASS。无需重开场景。**

当前预计成片约49—52分钟，符合本集约50分钟的目标。场景表中的分钟数是表演与剪辑预算，不要求每场机械命中秒数。

本集没有依靠大事件保持注意力，而是通过三种持续变化承重：

1. 人物组合不断改变；
2. 空间从教室、人流、店铺转入饭桌，再重新走回街道；
3. 高山说话的密度与责任感先累积、后降低、再以不同方式恢复。

无节奏RED。保留两项粗剪关注点：

- S08制作目标约13分钟，粗剪硬上限建议不超过15分钟；
- S02与S07的纸面预算偏紧，不得为了命中2分钟上下而赶掉换鞋、家庭联络与入口客流等现实动作。

## 二、整集温度与换挡｜PASS

| 段落 | 观看状态 | 节奏作用 |
|---|---|---|
| S01 | 教室余留的轻微迟缓 | 共同任务消失，个人路线尚未形成 |
| S02 | 人流与空间持续移动 | 多组关系同时分流，不建立独立人物小传 |
| S03前半 | 安静、分开翻阅 | 第一次降噪，让西野兴趣自行出现 |
| S04 | 喜剧逐步累积 | 先让观众笑，再让“高山仍在接”变得可感 |
| S03后半 | 安静选择 | 从群体笑声切回西野独自改道 |
| S05 | 两人稍快步行 | 关系形成，但仍由普通问答维持 |
| S06 | 四人汇入、微型目标消失 | 先聚拢，再用闭馆短暂停顿清空目的 |
| S07 | 决定、联络、短暂外界经过 | 快速完成现实转换，不让停顿变沉 |
| S08 | 热闹长场中的一次小空白 | 全集情感主体；生活始终大于人物领悟 |
| S09 | 重新移动与拆组 | 饭后余兴延续，四人恢复通勤路线 |
| S10 | 两人无目的步行 | 降噪收尾，但由练习册笑点保持普通明天 |

全片不是一直安静，也不是一直热闹。安静段前后都有真实动作，喜剧段后也会回到移动与空间选择。

## 三、高山笑点密度｜PASS / 禁止新增

高山确实多次使用“给物品以意志”的说法：

- 有自信的蓝色；
- 让便笺自己提醒；
- 盘子输掉或配合照片；
- 两个味道都很努力；
- 纸花自己毕业。

连续观看后，这一重复属于可识别的个人语言，而不是多个角色共享的编剧腔，原因有三：

1. 主要集中在高山需要维持话题的场合；
2. 南与飞鸟主要从字面继续追问，西野更多指出具体事实，四人笑法不同；
3. 高山的密度经历清楚换挡：S01—S04高密度，S05—S07显著降低，S08回到群体笑谈但不再独占，S09—S10只保留普通短问答。

不需要删除现有句子，但锁定：拍摄与排练不得再为高山增加同结构即兴包袱。S04若再增加一句，会越过“观众感到她多接了一次”与“编剧强迫她一直说”的边界。

## 四、饭桌长场｜PASS / 粗剪护栏

S08虽然纸面显著长于其他场，但内部持续发生状态变化：

```text
入座与菜单
→ 第一轮饮料
→ 混合饮料
→ 不同步上菜
→ 分食与调味料
→ 教室遗留物话题
→ 一句话落下
→ 生活自行恢复
→ 追加芭菲
→ 吃完仍继续聊天
→ 看时间与起身
```

因此它不是一场静态坐谈，也没有连续两段承担相同功能。

粗剪如超过15分钟，优先压缩：

- 服务员往返的完整路程；
- 饮料机接取过程中的重复等待；
- 菜品放桌后的纯操作时长；
- 已经由前一个镜头建立过的菜单翻页。

不得优先删除：

- 不同步上菜；
- 南与飞鸟未经确认的递物动作；
- 高山那句落下及生活从南那里恢复；
- 白桃芭菲及飞鸟第二口；
- 吃完以后仍继续说话的一小段。

这些是场景关系结构，不是可互换填充。

## 五、重复动作｜PASS

全稿出现较多“看一眼、停一下、继续走、打开或收起书包”。这些动作与本集的路线母题及放学物流一致，且功能不同：

- 看一眼可能确认商品、时间、方向、菜单或同行者；
- 停下可能来自人流、路线选择、闭馆、闸机或红绿灯；
- 书包承担离校、家庭联络、发圈、传单、零钱和练习册的真实道具链。

它们不需要文字层机械替换成更多近义词。制作端应通过空间、景别和演员速度区分，而不是把每次“看”都拍成反应特写。

全稿约21次单句“嗯”，分布在电话应答、熟人许可、关系省略与普通确认中。不同关系下功能明确，不构成统一短句机器。表演不得把所有“嗯”做成同一停顿与同一语气。

## 六、群像与人物配额｜PASS

- S01—S02中的桥本、万理华、まあ亚、南、飞鸟均由同一离校人流产生，不是轮流点名；
- 桥本在离校后退出，まあ亚在文具店后退出，万理华在旧书店后退出；
- 幼驯染只在S07门外经过，不进入主餐桌；
- S08只保留核心四人，不为人气或群像完整度新增角色；
- S09自然拆掉临时四人组，S10只留下西野与高山。

人物数量随场景推进持续收束，没有“每个人都要被交代去了哪里”的清单感。

## 七、结尾节奏｜PASS

S10没有一路保持纯抒情：

- 焗烤温度先回收饭桌；
- 练习册确认回收S01并带回明天的普通学校生活；
- 打烊小店只造成同步放慢，不承担象征；
- 最终陌生路口不使用主题句，两人等待下一次绿灯后继续走。

结尾因此属于今天仍未结束的一小段生活，不提前替半年后的分别伤感。
