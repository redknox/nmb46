## 1. STEP12 五层标准

每场均复核：

- **A｜人物行为引擎**：去掉剧情功能，人物仍会这样做；无临时技能；无强行露脸；行为顺序与人物变化一致。
- **B｜普通人常识保护**：没有为了突出主角而让普通人失去常识；制度、学校、职场与生活环境中的其他人保持正常能力。
- **C｜日式关系对白**：关系距离、身份接口与场合成立；中文自然，不用统一客气腔覆盖人物差异。
- **D｜作者解释减法**：没有为了说明主题而补总结；可删的解释在 STEP9 已处理。
- **E｜观众视角复核**：删去解释后，A 类必要信息仍然 GREEN；STEP11 无 RED。

## 2. 逐场复核结果

### S01｜早晨 / 3-B 教室 — LOCK VALID

五层均 PASS。

功能成立在普通班级噪音与进路资料自然侵入日常；“比昨天少”同时建立桥本长期调查和白石对此并不陌生，不需追加解释。

### S02｜课间 / 事务室 — LOCK VALID

五层均 PASS。

事务老师只做制度性核对；桥本没有被写成唯一理解制度的人。高中支援与定期券收尾信息足够，不追加大学资助说明。

### S03｜午休 / 3-B — LOCK VALID

五层均 PASS。

同学对北海道的闲聊提供生活温度；“你猜”保持桥本的轻微幽默，不把北大提前写成“返乡决定”。白石只多看一眼，属于 B 层感觉，不需要反应特写强化。

### S04｜放学前 / 进路指导室 — LOCK VALID

五层均 PASS。

老师从“主要在看什么”进入专业兴趣，不替桥本制造地域动机；专业与职业映射属于真实进路指导职责。场尾“先把学校看明白”保留未决状态。

### S05｜傍晚 / ミモザ — LOCK VALID

五层均 PASS。

桥本的能力来自正确工作顺序，不来自同事失常；删去“我去一下”后更符合共同前厅工作。兼职场没有英雄化或贫困励志化。

### S06｜第二天放学前 / 3-B — LOCK VALID

五层均 PASS。

白石的焦虑不是普通选校困难，而是第一次面对“想过什么样的生活 / 想变成什么样”；桥本只提供排除法，不替她决定价值。

### S07｜数日间 / 进路指导室 — LOCK VALID

五层均 PASS。

各人物的进路状态来自既有人物算法，普通学生也拥有正常进路问题，避免主要角色垄断高三现实。走廊收尾不替观众总结主题。

执行提醒：群像切换必须让观众清楚当前是谁；具体时长与删减只在 STEP13 处理，不在本步重写。

### S08｜放学 / 3-B — LOCK VALID

五层均 PASS。

对白中的错位成立：白石第一次把“北海道”理解成共同日常可能结束；桥本仍把它理解为排班与现实安排。结尾“明天一起走？”把情绪送回当下，不增加承诺。

### S09｜已吸收 — NO INDEPENDENT SCENE

原功能已进入 S07，不重复建立独立 Scene Lock。

### S10｜放学后 / 校外茶房 — LOCK VALID

五层均 PASS。

白石的不安准确落在“原来我不知道”，不是阻止桥本去北海道；桥本的变化是意识到“先处理完再通知”会让亲近的人感觉被排除。后半住宿对话完成行为上的首次改变：分享未完成问题，但不交出决定权。

执行提醒：桥本长段自我解释必须靠停顿、喝东西、视线变化等表演拆开，避免被演成作者陈述；不改对白，留给 STEP14。

### S11｜夜 / 桥本住处 — LOCK VALID

五层均 PASS。

生活动作、资料调查与 LINE 都是桥本真实处理现实的方式。STEP10 已修复“想学什么”重复：该行只在场尾新增。北大 / 都立没有提前决出胜负。

执行提醒：网页与表格是人物行为证据，不要求观众逐字读屏；信息层级与观看负担留给 STEP13–14。

### S12｜放学后 / 进路指导室 — LOCK VALID

五层均 PASS。

老师把硬条件核清以后才问“想研究什么问题”；决定由桥本自己完成。北大胜出的原因是她更想研究寒地 / 风雪 / 地域条件如何进入建筑与城市，而不是费用、就业或返乡情绪。

### S13｜第二天 / 午休 / 3-B — LOCK VALID

五层均 PASS。

桥本主动告知第一志愿，兑现本集关系变化；白石“大学生活会很寂寞”只轻触离别，不扩写毕业伤感。最后去买饭并 CUT，保持日常。
