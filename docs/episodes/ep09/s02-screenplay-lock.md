# EP09 S02｜事务室手续场

> 状态：LOCKED
>
> 位置：EP09 STEP9 Screenplay / S02
>
> 本场锁定目标：以极短、普通的事务窗口节奏，呈现桥本当前支援体系如何正常运行。不是贫困揭示，也不提前引入大学申请材料。通学补助沿用既有登记路线与区间，毕业前最后一期定期券需凭证核销。

## S02｜课间 / 事务室

事务老师核对资料。

“住宿支援是毕业时结束，这边不用另外办手续。”

桥本：

“好。”

“通学路线没变？”

“没。”

“区间也一样？”

“嗯。”

“那就按原登记。毕业前最后一期定期券记得把凭证交回来核销。”

桥本：

“知道了。”

老师把资料合上，又看她一眼：

“还有，打工别排太密。”

桥本：

“嗯。”

老师：

“考试前尤其是。”

桥本：

“好。”

下一个学生已经在门口等。

桥本拿着资料离开。

---

## 锁定要点

- 住宿支援在毕业时自动结束，不要求桥本额外办理终止手续。
- 通学支援按既有登记路线与区间继续执行；本场只确认路线 / 区间是否变化。
- 使用“定期券”，不使用中国式“月票”表述。
- 毕业前最后一期定期券需将购买 / 支出凭证交回学校核销。
- 不在本场提前出现“大学指定格式证明”“大学奖学金申请材料”等信息；这些留到后续第二次进路指导。
- 事务老师提醒兼职不要排太密，是基于她熟悉桥本现实状态的普通行政 / 教师关照，不升级成关怀戏。
- 整场保持短促，让下一位学生已经在门口等，强化“学校正常运行”。
