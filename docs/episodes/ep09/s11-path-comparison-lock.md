## 核心原则

桥本的北海道大学方向不是唯一现实可行解，也不是因为东京没有适合她的学校而被迫选择北海道。

她必须拥有至少一个**真正成立、她也认真考虑过的东京圈选择**。当前主对照校锁定为：

- 北海道大学
- 东京都立大学

横滨国立大学保留为第三候选，但不承担主要戏剧比较功能。

因此桥本最终选择北大的意义必须是：

> **两条路都走得通以后，她仍然更想走北海道大学这一条。**

而不是因为北大明显更便宜、就业更好、东京没有对应专业、家庭条件迫使她回北海道，或她先决定回北海道再倒推理由。

## 进路指导与桥本自查的边界

进路老师负责：

- 把她对城市、建筑、公共空间与长期使用的模糊兴趣翻译成建筑都市 / 城市规划 / 景观 / 地域设计 / 环境社会工学等现实专业方向；
- 告诉她这些方向存在设计、建设、咨询、地方自治体建筑 / 土木 / 造园等真实职业出口；
- 确认北大、东京都立、横国等都存在现实可行路径；
- 帮她核入试科目、专业移行、课程与执行条件。

桥本自己继续查深：

- 北大综合入试与后续专业移行；
- 北大建筑都市 / 寒地 / 风雪 / 城市环境相关内容；
- 东京都立建筑 / 都市环境方向；
- 两校课程差异；
- 学费、住宿、交通、暖气、支援、兼职等生活条件；
- 地方自治体技术职、建设、咨询等职业出口；
- 札幌市建筑职等具体案例，同时确认东京及其他地区也有同类出口。

一句话边界：

> **老师告诉她“有这样一条路”；桥本自己把这条路从大学一年级查到了第一份工资。**

## S11 比较表：必须同时出现硬条件与软条件

桥本一开始仍按自己最熟悉的方法，把可计算的现实条件放进表里。

### 硬条件

| 维度 | 北海道大学 | 东京都立大学 |
|---|---|---|
| 专业 | 建筑都市 / 环境社会工学方向成立 | 建筑 / 都市环境方向同样成立 |
| 入试 | 理系综合入试；后续专业移行需继续确认与准备 | 当前科目体系可直接衔接 |
| 学费 | 国立体系；可结合奖助与减免申请 | 公立体系；现实上同样可承受，不能写成“贵所以放弃” |
| 住宿 | 需要重新安排；学生寮 / 民间租房均需调查 | 现有东京生活可延续，通学方案更熟悉 |
| 通学 / 生活 | 冬季步行、积雪、暖气等是实际成本 | 日常摩擦较小 |
| 支援 | 需确认大学制度；乃校可提供本校正式证明材料 | 同样按学校制度申请 |
| 课程 | 寒地、雪、风、地域环境对建筑与城市的影响具有额外吸引力 | 大都市中的建筑、公共设施、都市更新同样与兴趣匹配 |
| 毕业后 | 自治体、建设、咨询、公共建筑等均成立 | 同类出口同样成立 |

### 软条件

随着比较继续，表里必须出现一些不能真正换算成分数的生活问题。

可使用克制、桥本式的词，而不是情绪日记：

- **离家里近 / 离家里远**；
- **现在的人际关系 / 生活圈**；
- **熟悉的生活能否延续**；
- **需要重新建立多少生活**；
- **真正想学什么**；
- **对城市 / 环境问题的兴趣**；
- **想过怎样的生活**。

对应到两边：

**北海道大学**可以意味着：
- 离北海道家人更近；
- 进入新的札幌生活；
- 需要重新建立日常与社交圈；
- 对寒地、雪、风、城市与环境适应问题的兴趣更强；
- 生活变化更大。

**东京都立大学**可以意味着：
- 留在东京；
- 当前朋友与人际圈继续存在；
- 熟悉生活大部分可以延续；
- 专业本身也确实适合她；
- 不需要大规模重建生活。

这里不写“舍不得白石”之类直白句子。白石与乃校朋友自然存在于“现在的人际关系 / 生活圈”中。

**不打分，不计算总分，不让任何一边靠表格自动获胜。**

这张表的戏剧作用是：

> **桥本从最擅长的“把条件算清楚”出发，最后发现有些条件根本不能被算成同一种单位。**

## 职业出口的呈现

S11 不得只出现“北大 + 札幌”。

桥本会同时看到：

- 东京地区自治体技术职；
- 札幌市 / 北海道方向自治体技术职；
- 建设公司；
- 咨询公司；
- 公共建筑 / 城市管理相关工作。

可以重点停留在札幌市“建筑”职类，但笔记必须让观众知道：

> 建筑都市方向的职业路径不是北海道限定。

因此“札幌也有”不能成为北大胜出的职业理由。

## S11 的终点

S11 不能决定北大。

它要让观众看见：

1. 她认真比较过东京与北海道；
2. 东京不是假选项；
3. 两边在现实与就业上都走得通；
4. 北大对寒地、风雪、地域与城市形成的研究开始让她反复停留；
5. 家人、朋友、熟悉生活、独立生活等因素也真实存在，但无法替她作答；
6. 最终真正剩下的问题不是“哪边更划算”，而是“我到底想学什么、想进入怎样的生活”。

因此 S11 最后一行仍锁定为：

> **想学什么**

两边暂时不做结论。

S12 才由专业进路指导帮助她把课程差异说清，最终由桥本本人确认：

> 东京都立是“很适合我”；北海道大学逐渐变成“我想去看看”。
