## 核心原则

桥本的北海道大学方向不是唯一现实可行解，也不是因为东京没有适合她的学校而被迫选择北海道。

她必须拥有至少一个**真正成立、她也认真考虑过的东京圈选择**。当前主对照校锁定为：

- 北海道大学
- 东京都立大学

必要时可以在资料中轻带横滨国立大学等其他候选，但不承担主要戏剧比较功能。

因此桥本最终若选择北大，其意义必须是：

> **两条路都走得通以后，她仍然更想走北海道大学这一条。**

而不是：

- 北大明显更便宜；
- 北大就业明显更好；
- 东京没有对应专业；
- 家庭条件迫使她回北海道；
- 她先决定回北海道，再倒推专业和职业。

## 进路指导与桥本自查的边界

进路老师负责告诉她：

- 她的成绩、理科能力与兴趣适合建筑 / 都市 / 城市规划 / 景观 / 地域设计 / 社会基础设施等方向；
- 这类专业的就业不只有设计事务所，也包括建设、咨询、地方自治体等；
- 地方自治体存在建筑、土木、造园等技术职；
- 北海道大学与东京圈都存在现实可行的学习路径；
- 具体入试科目、专业移行、课程与就业信息需要继续确认。

桥本自己继续查深：

- 北大入试与综合入试后的专业移行；
- 建筑都市 / 城市规划相关课程；
- 寒冷地区、风雪、建筑布局、街道与城市生活之间的关系；
- 东京都立大学对应的建筑 / 都市环境方向；
- 两校课程差异；
- 学费、住宿、交通、暖气、支援、兼职等生活成本；
- 地方自治体技术职的真实招聘与工作内容；
- 札幌市建筑职只是其中一个重点实例；
- 同类职业在东京及其他地区同样存在，不把职业出口限定在北海道。

一句话边界：

> **老师告诉她“有这样一条路”；桥本自己把这条路从大学一年级查到了第一份工资。**

## S11 电脑与笔记必须出现的内容

S11 不得只出现“北大 + 札幌”。

电脑标签页 / 纸面资料至少应形成以下三组：

### 1. 北海道大学

- 入试 / 综合入试
- 建筑都市相关课程
- 专业移行条件
- 寒地 / 风雪 / 城市与建筑环境相关研究
- 住宿、通学与生活成本

### 2. 东京都立大学

- 建筑 / 都市环境相关课程
- 入试与就读条件
- 留在东京圈的现实优势
- 对应就业与地方自治体技术职出口

### 3. 职业出口

重点可以停留在：

- 札幌市职员採用——建築

但浏览器或笔记中需要轻带其他地域 / 自治体的同类技术职资料，使观众知道：

> 建筑都市方向的职业路径不是北海道限定。

不需要逐页展示其他地区，只需让它们真实存在于桥本的资料体系里。

## 桥本的比较表

桥本可以制作一个朴素的优缺点比较表。它不是为了展示“聪明”，而是她确实需要把生活算清楚。

比较维度可以包括：

| 维度 | 北海道大学 | 东京都立大学 |
|---|---|---|
| 专业兴趣 | 建筑都市 / 城市规划；寒地、风雪、地域环境问题对她有额外吸引力 | 建筑 / 都市环境方向同样成立，且大都市议题与现实项目丰富 |
| 入试 | 需确认普通选拔 / 综合入试及之后专业移行 | 需确认对应学科入试与选拔条件 |
| 学费 | 国立大学体系，费用可预估；可结合既有支援体系 | 公立大学体系，现实上同样可承受，不能写成“明显更贵所以放弃” |
| 住宿 | 需要在札幌独立生活；宿舍 / 民间租房 / 冬季管理需继续比较 | 留东京圈的居住与生活安排更熟悉，现实摩擦更低 |
| 通学 / 生活 | 冬季通学、暖气、积雪、除雪等是实际成本 | 通学环境熟悉，生活变化较小 |
| 就业 | 札幌市、北海道厅等只是具体实例；建筑 / 都市相关出口成立 | 东京及其他自治体、建设、咨询等出口同样成立 |
| 对桥本的吸引力 | “有我想继续看下去的东西”——尤其是寒地城市如何被环境塑造 | “很适合我”——专业、城市、就业都成立 |

注意：不要把表做成过度完整的成年人职业规划。它仍然是一个 17 岁高中生为了做选择而建立的工作表。

## 戏剧意义

S11 的任务不是让桥本决定北大。

它要让观众看见：

1. 她确实认真比较过东京与北海道；
2. 东京不是假选项；
3. 北大不是成本或就业上的简单最优解；
4. 她对北大的兴趣开始超过“做选择所必需的信息量”；
5. 她不断回到寒地、风雪、建筑与城市关系这些内容，本身已经暴露了偏好。

因此后续 S12 的进路辅导才有成立空间：老师不是替她解释北大为什么好，而是帮助她意识到——

> **东京都立大是“很适合我”；北大逐渐变成“我想去看看”。**

这个差异最终应由桥本自己确认。
