# EP09《选择》｜Behavior Run

> 状态：**PASS / CLOSED**

>
> 本文件记录 STEP 2 人物行为引擎跑测。它不规定具体场景，只确认当“11 月进路分流、桥本未来逐渐具体化”这一真实事件进入人物生活后，各主要人物会自然如何反应。

---

## 1. 事件输入

11 月，高三进入进路具体化阶段。桥本奈奈未已经把自己的未来逐渐研究成一套现实方案：北大理系、入学后争取进入工学部环境社会工学科・建築都市コース、住宿、学费与奖助、搬迁、生活成本、以及毕业后回北海道工作的可能性。

她同时需要处理高中阶段奖助终止、现有住宿与通学安排结束、餐饮兼职何时停止等现实事项。

---

## 2. 桥本奈奈未｜M

### 第一理解

桥本不会先把这理解为“我要离开朋友”，而会理解为一组现实问题：考试路径、费用、住宿、搬迁、奖学金、生活成本、兼职终止时间、未来职业等。

### 默认行为顺序

> 收集资料 → 列条件 → 比路线 → 算时间与钱 → 形成方案。

她不会觉得自己在“瞒着白石”。她更接近：

> “还没决定的东西，有什么好说的？”

因此她的问题不是不信任朋友，而是习惯等事情变成结论以后才告知别人。

### 求助阈值

很高。

- 老师可以提供制度信息；
- 事务室可以处理奖助与手续；
- 家庭可以讨论现实条件；
- 但对白石反而最容易晚说，因为桥本长期把“现实问题”视为自己应先处理的事务。

### 本集允许发生的行为变化

不是主动倾诉，而是：

> 白石已经看见问题以后，桥本本来可以用一句“没什么”关门，这一次没有。

她允许白石看到“尚未算完”的现实。

---

## 3. 白石麻衣｜S

### 第一理解

白石首先会注意桥本的行为变化，而不是立刻把事情理解成“她要离开我”。

她会发现桥本越来越按北海道生活去安排现实：大学资料、住宿、交通、奖学金、甚至毕业后的职业信息。

### 默认行为顺序

> 先观察 → 给空间 → 等桥本自己说。

问题恰好由此产生：

- 桥本认为：“你没问，所以不需要说。”
- 白石认为：“我不问，是因为我在等你告诉我。”

两边逻辑都成立。

### 冲突核心

白石真正难受的不是“北海道太远”，而是发现桥本并非刚开始想，而是已经把人生排到了很后面。

因此本集冲突应指向：

> **“你什么时候已经把这些都决定到这里了？”**

而不是：

> “你为什么要回北海道？”

白石要求的不是决策权，而是参与未完成过程的资格。

---

## 4. 西野七濑｜L偏S

面对同样的进路分流，西野的自然路径与桥本相反。

她可能先形成清晰但难以解释的判断：

> “那个推荐……我不想要。”

别人问为什么，她未必能完整说明。

对照关系：

- 桥本：理由不断累积后形成决定；
- 西野：决定先形成，理由之后慢慢长出来。

本集只允许极轻伏线，不形成第二条完整人物主线，也不要求与桥本发生直接因果。

## 5. 其他人物的自然反应

### 高山一実｜L

会本能维持轻松气氛，但不进入毕业伤感。若一句玩笑没有被接住，她可以停下，不补第二句。只做长期弧的轻微连续，不完成 EP11 课题。

### 秋元真夏｜L

会自然把进路季理解为流程与截止日期，知道材料、时间、手续，但不能成为全年级“升学总管”。她自己的更深课题留给后续。

### 生田绘梨花｜L

方向早已相对明确，会把未来理解为考试要求、曲目和技术准备。她证明“不是所有人都在 11 月第一次决定方向”。

### 斋藤飞鸟｜R/L

可以嘴上说“还没定”“差不多”，实际已查过资料。只允许低重量露出，不主动倾诉，不连续消费 EP08 后的人物推进。

### 生驹里奈｜L

与桥本同样面对地域问题，但不共享同一种经济结构。她对住宿、搬迁、归省等问题的自然处理，可以帮助观众理解“离开东京”本身并不是悲剧。

### 樱井玲香｜R

本集极淡。可以让观众感到她比许多人更早知道人生大方向，但不得提前消费 EP10 的制度与继承主题。

## 6. 本集行为核心

EP09 最好的关系冲突不是：

> “你要回北海道？”

而是：

> **“你什么时候已经把这些都决定到这里了？”**

前者反对桥本的选择；后者质疑桥本处理关系的方式。

这保证：

- 白石不会变成劝朋友留东京的人；
- 桥本回北海道仍然是正确选择；
- 冲突发生在关系边界，而不是人生路线对错。

桥本真正的变化也必须很小：

前半段：

> 被问 → 封口 → 给结论。

后半段：

> 被问 → 仍想封口 → 停一下 → 给出尚未完成的真实情况。

例如，她可以开始说：

- 奖学金还没确定；
- 住宿有两个方案；
- 总合入试进去以后也不一定能直接进建筑都市；
- 所以还没完全定。

对白石而言，这已经是桥本第一次把“没算完的东西”拿出来给她看。
