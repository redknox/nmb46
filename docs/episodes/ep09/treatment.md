# S02｜课间 / 事务室

课间。

桥本去事务室办理一项她已经熟悉的手续。

窗口内的老师调出她的在校支援记录。

学费减免。

住宿 / 通学支援。

毕业前最后阶段需要补的证明。

双方没有寒暄式安慰。

老师确认：

- 本学期继续按现在方案；
- 哪些材料需要补；
- 哪些支援持续到毕业；
- 哪些手续在毕业时自然终止；
- 学校能出具哪些正式证明。

桥本关心的也是具体事项。

“这个要什么时候交？”

“毕业以后这项就结束？”

“如果大学那边有指定格式，可以拿回来开吗？”

老师正常回答。

“可以。格式拿回来就行。”

桥本记下。

后面还有学生在等。

她把资料收好，道谢，离开。

### 执行原则

- 这是普通行政流程，不是“揭露桥本家境”。
- 乃校成熟的支援制度通过办事效率呈现。
- 桥本对这些流程熟悉，是她现实生活的一部分。

# S04｜放学前 / 第一次进路指导

放学前。

桥本进入进路指导室。

她已经看过北海道大学资料；这不是老师第一次把北大摆到她面前。

老师从进路调查、成绩和科目开始。

桥本的数学、物理没有问题。

真正需要谈的是“她到底对什么有兴趣”。

桥本能说出来的仍然是生活语言。

她会注意城市为什么变成现在这样。

街道怎么走。

建筑怎么摆。

公共空间为什么这样组织。

同一个地方为什么几十年以后还会继续被人使用。

比起“设计一栋漂亮建筑”，她更容易被这些问题吸引。

老师听完，把这些兴趣翻译成更正式的方向：

建筑都市。

城市规划。

景观。

地域设计。

环境社会工学。

社会基础设施。

然后顺着桥本已经在看的北海道大学，告诉她应该具体看哪些内容：理系综合入试、之后的专业移行、工学 / 环境社会工学 / 建筑都市相关方向。

老师明确：北大与她的兴趣确实匹配。

但不是唯一答案。

“如果考虑第二志愿，或者也想看看东京圈，相近的还有东京都立、横国。”

“你回去把课程和入试条件一起看看。”

桥本点头。

老师再很短地补职业出口。

设计。

建设。

咨询。

地方自治体的建筑、土木、造园等技术职。

公共建筑、都市管理、地域规划。

老师不替她规划一生。

只让她知道：这个兴趣有现实专业，也有现实工作。

面谈结束。

桥本把几个学校名字记进自己的资料里。

### 执行原则

- 本场不宣布北大第一志愿。
- 老师负责“翻译兴趣、补地图”；学生自己继续查。
- 北海道大学、东京都立大学、横滨国立大学在此时都是真实候选。
- 权威细节：`s04-career-guidance-revision-lock.md`。

# S05｜傍晚 / 洋食レストラン「ミモザ」

傍晚。

桥本穿着乃校制服从员工入口进店。

书包在肩上，手里另拎一个低调布袋。

她和后场的人自然打招呼，换上工作服，整理头发，打卡。

晚餐时段逐渐起来。

不做“勤劳蒙太奇”。

只是正常跟她工作一会儿。

她手里正在撤盘，门响了；另一名空手员工自然去接客，桥本继续把餐具送回后场。

呼叫铃亮起，她看桌号，拿手持点单机过去。

一桌家庭客追加儿童果汁和布丁。

她正常录入、复述确认。

另一桌孩子把勺子碰到地上。

桥本先拿干净勺子给客人，再把旧勺子带走，并处理地上的一点食物。

另一桌还缺一份焗饭。

客人询问。

桥本不猜时间，先去出菜口确认。

“三分钟。”

她回去准确告诉客人。

焗饭出来后正常送上，提醒盘子很烫。

没有人夸她能干。

这就是她平时会做的工作。

晚餐高峰稍松。

店长经过：

“桥本，方便问一下排班吗？”

“嗯。”

“二十三号现在有点缺人。你能不能来？”

桥本去柜子拿手账。

看二十二、二十四号的学校与考试安排。

“二十三号的话，可以。”

“到九点也可以？”

“可以。”

店长又问二十六号。

桥本多看一会儿。

“不好意思，二十六号有点困难。”

“考试？”

“嗯。那几天比较集中。”

店长点头，去找别人。

21 点前后。

桥本完成自己这一班最后该做的整理。

餐厅仍在营业。

她换回简单私服，把乃校制服整齐装进布袋，打卡离开。

### 执行原则

- 不写苦情，也不写“天才打工人”。
- 她的熟练来自正确的工作顺序。
- 排班是她“现实必须自己排”的生活之一。
- 23 日可追加，26 日因考试拒绝。
- 服装与布袋 continuity 参见 `docs/world/hashimoto-parttime-restaurant-lock.md`。

- 白石的不安开始形成，但还没有命名成“为什么不告诉我”。
- 桥本给白石的是方法，不是答案。

# S07｜数日间 / 进路指导室

同一张桌子。

同一把学生椅子。

十一月几个不同下午。

窗外的光一次比一次早暗。

学生不断换。

生田来谈东京音乐大学的实技、乐典、听音与模拟考试。老师提醒别再加练，先保睡眠。

普通学生来确认推荐与英语外部成绩期限。

まあや带着几所实践型学校资料。她对工作室、木工房、空间制作、展示设计最有反应。老师把“真的把东西搭出来”对应到展示制作、店铺空间、产品制作、舞台现场等现实职业。

松村看商学、消费文化、媒体，也真的找到可辅修烹饪的学校。谈完行业，她仍认真考虑“学校附近吃的很多”，因为四年都要在那里生活。

飞鸟资料查得很细，嘴上仍然淡淡。老师不拆穿。

南已经能决定学校与专业，但二十二岁以后做什么还不知道。老师接受这一点，不逼她编答案。

西野面对一条顺利推荐路线，条件都够，却说“不想去”。另一所学校她现实条件也查过，真正让她停下来的却是图书馆旁边那个很安静的院子。老师确认可行，就按她的选择重新排。

白石原本四所，现在三所。被删的一所不是坏学校，只是她重看课程后发现“有几门课好像没有那么想学”。

生驹候选分散在东京、仙台、横滨。她在意不同地方、不同出身的人，也要继续补住宿、费用与入试。

走廊仍然普通。

有人抱着招生资料。

有人背单词。

有人盯“主要就职去向”看半天，只看懂“公司好多”。

有人拍自动贩卖机，把被吞的奶茶拍下来。

铃响。

刚才坐过同一把椅子的人又混回同一条走廊。

一起下楼。

一起换鞋。

明天也一起上课。

### 执行原则

- 不是逐人汇报志愿。
- 同一套专业进路指导面对不同学生，会呈现不同生活。
- 原独立 S09 西野短场已经吸收于此，不再另设。
- 权威细节：`s07-career-guidance-montage-lock.md`。

# S10｜放学后 / 校外茶房

放学后。

桥本和白石一起从学校出来。

到车站附近，桥本忽然说：

“要不要去喝点东西？”

安静的老式茶房。

两人点完东西。

桥本等店员走远。

“昨天你是不是生气了？”

白石：

“没有啊？”

桥本：

“那个……我能感觉到一点。”

白石笑。

“所以你今天请我喝东西？”

“嗯。”

“那好吧，我原谅你了。”

桥本也笑。

然后认真起来。

“可是我困扰的是——我没太明白为什么。”

白石想了一会儿。

她说自己一直觉得娜娜敏是一个让她很安心的人。

很多事情跟别人说之前会想怎么说、对方怎么想；跟娜娜敏却会觉得说出来没关系。

因为桥本会认真听，也不会为了让她高兴就随便说什么。

“所以我一直觉得，我们应该是很近的。”

桥本：

“嗯。”

白石说，看到她已经查到住宿、支援、兼职这些，第一反应不是北海道，而是：

“原来我不知道。”

她有事情会很自然地跟娜娜敏说，可娜娜敏有事情时，好像并不会想到她。

“可能我也有点贪心。”

因为已经习惯桥本什么都自己处理，所以有时会想：

“那我到底能帮你什么。”

桥本轻轻笑。

“我也没想过一定要你帮什么。”

白石：

“我知道。”

“但有时候被需要一点，会比较安心。”

她甚至会怀疑，是不是只有自己觉得两人很近。

桥本马上否认。

“不是。我一直觉得很近。真的。”

然后她解释自己。

学校。

钱怎么花。

什么时候打工。

住哪里。

怎么去学校。

以后去哪边。

这些事情最后都还是得自己决定。

所以她习惯先弄清楚、处理掉，等真的有结果再告诉别人。

不是因为不想让白石知道，也不是觉得这些事跟她没关系。

“所以我没意识到……这样看起来，会像是把你放在外面。”

“我不是那个意思。从来都不是。”

白石理解。

桥本也承认，自己过去总觉得“能处理的事情就不要让别人一起操心”。

白石：

“可是我不一定会觉得是操心。”

桥本：

“嗯。现在知道了。”

短暂安静。

桥本低头看咖啡。

“那个……”

“嗯？”

“我现在其实就在为住宿的事情烦恼。”

这是变化真正发生的地方。

桥本把仍没解决的札幌住宿问题摆出来：离学校近但贵、便宜一点但冬季生活道路麻烦、学生宿舍条件还没完全看完。

白石问她比较想哪个。

“还不知道。”

白石只说：

“那就还不知道。”

桥本甚至有点意外她不立刻给答案。

“你不说哪个好？”

“你想听吗？”

桥本想想。

“现在不想。”

“那我就不说。”

桥本笑。

“原来可以这样。”

白石：

“本来就可以。”

### 执行原则

- 关系确认，不写成争吵。
- 白石想要的是偶尔“被需要 / 在里面”，不是决定权。
- 桥本不是天生超然独立，而是长期生活训练出“先处理再告知”的习惯。
- 关系变化立即通过“分享未解决住宿问题”落实。
- 分享不等于交出决定权。
- 场尾不总结关系。

# S12｜放学后 / 第二次进路指导

放学后。

前一个学生刚离开。

老师把资料收好。

桥本进来。

文件夹已经按学校分好：

北海道大学。

东京都立大学。

后面还有横滨国立大学。

老师先快速核硬条件。

北大理系综合入试。

现在成绩可以报。

之后想进环境社会工学 / 建筑都市，需要继续注意专业移行，不是进综合入试就自动进去。

数学、物理继续当前状态。

英语不能掉。

东京都立的科目和日程也能接上；作为第二志愿不需要另换一套完全不同的准备。

支援方面，各大学按自己的制度申请减免与奖学金。

老师翻到桥本在乃校的支援记录。

“本校的减免证明可以一起放进申请材料。”

桥本抬头。

“可以？”

“可以。如果对方有指定格式，把格式拿回来。”

“学校能开的，我们这边开。”

住宿仍没定。

老师只说可以继续查，不影响现在排志愿。

然后桌上只剩北大与东京都立两叠。

老师把真正的专业差异摆清。

东京都立：建筑学完整，建筑、都市计划、公共设施、更新都会碰到；它面对的是东京这种成熟大城市的问题。设计、建设、住宅、基础设施、自治体等出口都清楚。

北大：也是建筑都市，但学校很强调北方环境。寒冷、积雪、气候、地域条件不是附加条件，而会直接进入建筑和城市怎么成立的问题。

老师明确：如果只问以后能不能做城市、建筑、自治体，两边都可以。就业上没有哪个把路堵死。

都立与首都圈设计、建设、自治体联系直接。

北大读研比例高，建筑都市可以继续往深处走。

“但这个差别还不够替你选。”

老师问：

“最后还是要看，你想研究什么问题。”

她看桥本自己的笔记。

东京都立：建筑计划、都市计划、公共设施、城市更新。

北大：寒地、雪、风、建筑与城市环境、地域条件。

“这两个方向，你觉得差别在哪里？”

桥本想很久。

“都立……比较像是在一个已经很大的城市里，怎么把它继续做好。”

再看北大。

“北大……比较像先问，这个地方为什么会长成这样。”

她继续：

“雪、风、气候这些，本来就不是建筑以外的东西。”

“会影响路怎么走。”

“人怎么生活。”

“建筑怎么摆。”

停一下。

“我比较想知道这个。”

老师只说：

“那差别已经很清楚了。”

然后问志愿顺序。

桥本没有停很久。

“第一志愿，北海道大学。”

老师写下。

“第二？”

“东京都立大学。”

横国保留第三候选。

接下来立刻回到现实。

共通测试。

北大二次。

东京都立。

出愿节点。

成绩确认。

数学物理继续。

英语保持。

北大移行以后再说。

“现阶段先按入试准备。”

桥本离开。

第一志愿：北海道大学。

第二志愿：东京都立大学。

# STEP8｜Treatment 压力测试结论

## 1｜主因果链

**PASS。**

当前主链为：

> **S04 兴趣获得专业语言 → S06 白石看见桥本把未来算得很远 → S08 未来已经开始改变今天 → S10 两人说清关系边界，桥本第一次分享未完成问题 → S11 两条人生都现实成立 → S12 桥本自己作出选择 → S13 主动告诉白石。**

没有依赖“友情替她选北大”或“老师替她发现梦想”。

## 2｜桥本人物弧

**PASS。**

她没有从独立变成依赖，也没有变成倾诉型人物。

变化严格限定为：

> **从“我自己决定 → 结果出来后告诉你”，变成“决定仍然是我的，但你可以在决定尚未完成时待在这里”。**

## 3｜白石副线权重

**PASS。**

白石拥有自己的进路状态，但不形成第二主轴。她的功能不是劝留东京，而是让桥本第一次看见“关系也需要过程”。

## 4｜其他成员群像

**PASS。**

主要集中于 S07。原独立 S09 已吸收，不再额外占用时长。

## 5｜现实与制度

**PASS。**

- 北大为真实候选而非教师突然推荐；
- 综合入试后专业移行不写成自动；
- 奖助与乃校证明不构成神奇保证；
- 宿舍在录取前只做申请策略和条件研究，不提前租房；
- 餐厅排班、考试季减班、离职均按当前阶段处理；
- 自治体技术职不是北海道限定职业出口。

## 6｜时序

**PASS。**

S12 放学后完成志愿排序；S13 放到第二天午休，避免白石无理由久留学校等待。
