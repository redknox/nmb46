# EP09 S04｜第一次进路指导修订锁定

> 状态：LOCKED / supersedes old S04 in `scene-list.md`
>
> 目的：修复此前“桥本已基本确定北海道大学”为前提造成的后续因果冲突。此版本作为 S04 当前权威逻辑，后续 Treatment / Screenplay 均以本文件为准。

## 核心修订

S04 不再是“确认第一志愿北海道大学”的面谈。

它改为：**老师第一次把桥本模糊的空间 / 城市兴趣翻译成现实专业与可执行进路。**

此时桥本尚未决定一定回北海道，也尚未把北海道大学确定为第一志愿。

---

## S04｜放学前 / 进路指导短面谈

本场允许稍长，是全集中少数可以完整谈进路的场景之一。

老师先从桥本已经填写的进路调查、成绩和科目情况谈起。

桥本并没有明确写下“建筑都市”或“地方公务员”。她能够说出来的，只是自己对这类东西有兴趣：

- 城市为什么会变成现在这样；
- 街道、建筑、空间怎么影响人的生活；
- 公共空间为什么这样组织；
- 比起单独设计一栋漂亮建筑，她更在意空间长期怎样被人使用。

老师据此把这种兴趣翻译成更正式的专业方向：

- 建筑都市；
- 城市规划；
- 景观；
- 地域设计；
- 社会基础设施 / 环境社会工学相关方向。

老师告诉她：这不是一个空泛兴趣，是有对应专业和现实职业出口的。

可以举北海道大学作为匹配度很高的候选，让她去看工学、环境社会工学、建筑都市相关方向，以及理系综合入试后再根据成绩与志愿移行的制度。

但北大不是唯一答案。

老师顺手补一句即可：

> “如果考虑第二志愿，或者也想看看东京圈，相近的还有东京都立、横国。你回去把课程和入试条件一起看看。”

这里不展开三校比较，也不替她排序。

随后老师再补职业出口：

- 设计事务所；
- 建设公司；
- 咨询公司；
- 地方自治体的建筑 / 土木 / 造园等技术职；
- 公共建筑、都市管理、地域规划相关工作。

老师只负责告诉桥本：**“有这样一条路。”**

不替她把职业规划做完。

北大综合入试、数学 / 物理科目配置、后续专业移行等，可以作为“回去需要继续确认的现实问题”提出，但本场不能表现为桥本已经全部查完。

面谈结束时，桥本应处在：

> **“北大值得认真看；东京圈也有真实候选；这个模糊兴趣原来真的可以变成一条专业路径。”**

而不是：

> “第一志愿北大已经确定。”

---

## 与后续场次的因果

S04 之后，桥本才开始自己深挖：

- 北大怎么考；
- 综合入试后怎样移行；
- 东京都立 / 横国的课程与入试；
- 学费、住宿、支援、生活成本；
- 就业出口；
- 自治体技术职；
- 札幌市建筑职等具体案例。

因此后续白石看到桥本已经查到住宿、就业、打工与生活安排时，成立的是：

**桥本正在把多个候选未来越查越具体，而不是已经决定去北海道却没有告诉白石。**

这也是 S10 白石关系不安能够成立的前提：桥本确实仍在“未完成的决定过程”里。

---

## 执行原则

- S04 不宣布北海道大学为第一志愿。
- 不把桥本写成已经完成职业规划的成年人。
- 老师负责翻译兴趣、补信息、给候选路径；不替学生决定。
- 北海道大学、东京都立大学、横滨国立大学都只是本阶段真实候选。
- 职业出口由老师点到为止；具体岗位、工资、地域与长期生活由桥本之后自己查。
- “专业的人做专业的事”：老师提供地图，桥本自己走路。
