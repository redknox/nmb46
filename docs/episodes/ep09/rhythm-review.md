## 1. 总结论

EP09 当前整集节奏成立。

- 未发现必须通过删场、并场或重写对白才能解决的节奏硬伤；

本集的主要节奏结构为：

> **共同日常 → 桥本个人现实 → 白石开始察觉 → 全年级分流 → 关系摩擦 → 关系说开 → 独处比较 → 做出选择 → 普通午休收尾。**

它不是事件型高低起伏，而是现实逐渐变具体、人物之间的距离因此被重新感知。

## 2. S01–S04｜开场：从“环境变化”进入桥本个人路径

### PASS

S01 先建立全年级桌面上出现越来越多进路资料；S02 进入桥本自己的学校支援与打工现实；S03 用午饭把“北大”放进朋友视野；S04 才正式进入专业方向。

这四场虽然都围绕进路，但观看任务逐步收窄：

- S01：环境；
- S02：现实条件；
- S03：朋友第一次看到；
- S04：兴趣被翻译成专业路径。

没有重复解释同一件事。

S03 的轻笑与北海道冬天闲聊也有效阻止开场过早变成严肃升学剧。

## 3. S05–S06｜生活换挡：让“未来”进入今天

### PASS

S05 完整离开学校，进入ミモザ。它不是支线，而是把桥本的时间、钱、排班与未来准备落实到身体劳动中。

S06 回到教室后，白石看到住宿、支援、通学、兼职环境等资料，观众已经有 S05 的生活经验作为底，因此不会只把这些理解成一堆纸。

S05 的餐厅动作较多，但其节奏价值在于：

> **让观众先看桥本怎么过日子，再听她们谈未来。**

不建议因主线压力而压缩成一句“桥本去打工”。

## 4. S07｜进路指导群像蒙太奇

### PASS｜保留完整人物顺序，不做文本删减

S07 是全篇最容易在纸面上显得长的一场，但当前不建议删 まあや / 松村等段落。

原因：

- 生田：明确方向 / 执行压力；
- 普通学生：证明进路季是全年级日常，不是主角专属事件；
- まあや：实践 / 空间感；
- 松村：聪明但生活化的选择维度，提供轻喜剧气口；
- 飞鸟：研究充分但表达收缩；
- 南：先定学校 / 专业，职业以后再说；
- 西野：决定先发生、理由后长出来；
- 白石：S06 的“排除法”已经开始产生行为结果；
- 生驹：地域 / 归属维度；
- 走廊：把刚才坐过同一把椅子的人重新混回同一条学校日常。

如果删掉 まあや / 松村，S07 会更短，但也更容易变成连续的严肃升学问答，反而失去节奏起伏。

### STEP13 执行要求

S07 必须按“蒙太奇”处理，而不是九个完整面谈场：

- 不为每个人重新做完整进门 / 坐下 / 离开建立镜头；
- 用门、纸张、窗外光线、老师翻页、下一位学生等连续动作切换；
- まあや / 松村的轻笑点落完即走，不追加反应镜头；
- 西野与白石可以比其他段稍多半拍，但不能突然变成两条完整副线；
- 走廊收束必须留气口，不能为了赶时长剪掉“重新混回同一条走廊”的感觉。

结论：**保留文字，靠剪辑节奏完成长度控制。**

## 5. S08｜短场缓冲

### PASS

S08 很重要，因为它位于 S07 大蒙太奇之后、S10 长关系场之前。

它只做一件事：

> 桥本已经开始按未来调整今天的排班；白石第一次把“北海道”与“东京生活会结束”连接起来。

场尾“明天一起走？”把潜在离别感重新压回普通明天，是有效降压。

不建议扩写。

## 6. S10｜茶房关系场

### PASS｜本集允许最慢的一场

S10 是全篇唯一需要真正停下来谈关系的长场，长度有结构理由。

它内部并不是一条长情绪直线，而有清楚换挡：

1. 桥本试探“你是不是生气了”；
2. 白石先用玩笑缓冲；
3. 白石说明“原来我不知道”；
4. 桥本解释自己的处理现实方式；
5. 两人不做关系宣誓；
6. 桥本立刻拿一个尚未解决的住宿问题实践新的关系方式；
7. 以“你想听吗 / 现在不想 / 那我就不说”收束。

因此无需因对白量而主动压短。

STEP13 只锁一条：

> **不要用剪辑或配乐把 S10 推成越来越大的“友情告白”。**

它应该有停顿、有笑、有想词的时间，也允许两人暂时不说话。

具体表演呼吸进入 STEP14。

## 7. S11｜夜 / 桥本住处

### PASS｜信息密度高，但观看方式应低密度

S11 纸面信息很多，但不应被执行成“观众读完所有网页和表格”。

它在整集中的节奏功能是 S10 后的**静默降档**：

- 洗澡；
- 微波炉；
- 晾衣服；
- 吃东西；
- 翻页面；
- 回 LINE；
- 忘了吹头发；
- 最后新增“想学什么”。

观众只需要抓到少数清晰锚点：

- 北大 / 都立都在认真比较；
- 北大出现寒地、雪、风、城市环境；
- 东京与札幌的就业路都成立；
- 宿舍仍没决定；
- 最后真正没法靠表格回答的是“想学什么”。

其余页面属于质感，不要求逐字读取。

因此本场不删信息文本；具体镜头停留长度、读屏层级进入 STEP14。

## 9. S13｜午休收尾

### PASS

S13 不继续抬情绪。

第一志愿确认后，白石说“我的大学生活会很寂寞”，但场景马上回到：

- 宿舍怎么处理；
- 去买饭；
- 再晚就没了。

最后一句“不过我还是会寂寞”允许感情存在，但桥本不做安慰承诺，只笑。

这使整集以**日常仍在继续**结束，而不是以“毕业预告片”结束。

不建议增加尾声或音乐性总结。
