# EP09 S07｜进路指导室群像蒙太奇

> 状态：LOCKED / Treatment structural decision
>
> 本文件锁定 S07 的场景形式与执行原则。具体人物对白仍在 STEP7 Treatment 逐场打磨。

## 核心决定

S07 不再采用“音乐室 / 走廊 / 办公室等多个地点分别展示人物进路”的拼盘结构。

改为：**大大方方把镜头留在进路指导室，用同一场所、同一套高三进路面谈流程，通过蒙太奇展示不同学生正在走向不同的未来。**

S04 的桥本面谈仍保留为较完整、较长的一场；S07 回到同一间进路指导室，看见其他人的面谈片段。效果应是：观众先完整经历桥本的一次指导，随后才意识到，同一天 / 同一时期，每个人都坐过这张椅子。

## 视觉与剪辑原则

- 不剪成 MV 或“角色介绍短片”。
- 仍保持“看不见的摄制组”：学校本来就在集中进行高三进路指导，我们只是从正常流程里抽取不同人的几分钟。
- 可以通过同一空间的重复元素建立节奏：同一把学生椅、同一张桌子、老师翻资料、学生进出；窗外光线、桌上文件、茶水等可随时间自然变化。
- 可以让老师重复相同或相近的问题，例如“第一志愿呢？”“家里怎么说？”“现在最担心什么？”，然后用不同人物的回答形成差异。
- 重复本身不是问题；本场的形式价值恰恰来自“同一个问题，不同的人有完全不同的答案”。

## 人物颜色

### 生田绘梨花

她的方向已经相对明确。进路指导不承担“发现音乐道路”的功能，而是进入执行层：学校 / 考试方式 / 实技 / 曲目 / 学科准备等。

她的状态：**知道大致要去哪，因此面对的是标准和执行。**

### 西野七濑

她面对一条现实上很顺、条件也不错的推荐路线，但已经倾向于不走。

她可以明确说“不申请”或“不想去”，但尚不能完整解释为什么。

她的状态：**决定先形成，理由还在后面长出来。**

本场只做轻回声，不把西野发展成第二主轴。

### 白石麻衣

指导老师面前的白石仍然是体面、正常、没有撒谎的白石：

- 家里让她自己决定；
- 有几个学校 / 方向都有兴趣；
- 仍在考虑。

她不会在老师面前完整展开“我不知道自己想过什么样的人生”的内部状态。

这与 S06 形成对照：回到桥本这个“卸妆区”以后，她才会承认选择太多、既期待又害怕，并说出父母让她从“自己想过什么样的人生”出发选择，而她尚不知道答案。

### 普通学生

可有极短片段，证明这不是主角专属的戏剧装置，而是整个高三年级正在经历的正常进路季。

普通学生的选择可以非常日常：本地 / 外地、家里意见、第二志愿、推荐 / 一般入试等。不要承担评价主角人生的旁白功能。

## 与桥本主线的关系

S07 的目的不是再次解释桥本，而是防止 EP09 变成“桥本之外所有人都是工具人”。

本场要真正建立：

> **同一个高三十一月，每个人已经开始按不同的未来生活。**

桥本只是其中最早、最系统地把未来落实到现实安排里的人。

## 禁止事项

- 不逐人报志愿表。
- 不让人物为了观众解释自己的整套人生规划。
- 不把老师写成替学生发现梦想的人。
- 不用普通学生议论“某某肯定不用烦”“某某人生已经写好”来代替人物自身生活。
- 不因为使用蒙太奇就牺牲人物行为的现实因果。
- 不在本场提前消费毕业伤感。
