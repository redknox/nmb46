### 本场删除

删除 V0.4：

- `没有主持人解释节目调整。`
- `不是上午正式总谱里的开头，也不是完全陌生的东西。`
- `没有人解释为什么刚才一定要把它装回来。`

- 正片没有主持人，本身已经是事实，不必写“没有解释”；

- 最高一级真实站满后排高三就是视觉答案；
- まあ亚在S14已经完成她唯一需要明确承担的空间发现，不再把她延伸成舞台技术检查者。

# 本轮锁定候选原则

1. **15:00开始由生田按钟自行开始**，继续继承S17锁定，不增加真夏开始cue。
2. **最高一级的必要性只用“站满后排高三”表达。**
3. **未央奈恢复不得增加解释台词。**
4. 恢复链必须保持：
   > 舞台/队伍条件已恢复 → 松下亲自看见条件成立 → `堀。原来的位置。` → 回mark → 无声起手cue → 未央奈吸气但不唱 → 松下确认 → 后续正式恢复。
5. まあ亚不再承担技术复检；高山不再被重复指定为未央奈情绪接口。
6. 真夏在S20末端只做运营Ready的现场读取，并取得对生田的视线；音乐判断仍留给后续生田与松下。
