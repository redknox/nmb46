### 本场删除 / 收口

删除 V0.4：

- `音乐判断已经不是她的工作。`
- `不是突然切进正式曲目。`
- `现在只听生田。`
- `松下判断入口正在成立。`

这些关系由动作本身成立：

> 真夏cue生田 → 确认收到 → 立即cue松下 → 不再干预音乐 → 生田自己回正式和声 → 松下自己听到入口 → 松下决定升幕。

### 双cue视觉要求

两个信号必须清楚地有**不同接收者和不同视线方向**：

1. 第一个：真夏 → 幕前生田；
2. 第二个：真夏转身 → 指挥位松下。

不需要设计两套夸张手势。区别来自接收者、视线和剪辑方向，而不是手势编码。

### 本场删除 / 修正

删除 V0.4：

- 合唱台模块搬运到`右边`的错误路线；
- `啊，不是那边。今天放右边。 / 右边？ / 嗯，右边。`；
- `没有音乐。没有慢镜头。只是普通换台。`等作者说明。

右侧已经在S22被真夏明确指定为**下一项讲台入口**，因此撤下的最高一级先去舞台后区预定临时位，不与讲台物流打架。

### 正常换场时间逻辑

本TAG不需要角色报时。

事故中的`约40分钟`是：整组拆除 + 清出景片轨迹 + 主景通过 + 精确复原 + 重新固定与安全确认。

本场是预定的单向换场：

> 合唱成员下台 / 拿走个人物品 → 台阶按顺序拆除 → 模块送入预定临时位 → 讲台从右侧进入。

不需要重新搭回合唱台，也不需要再次为合唱对mark和复检，因此约10分钟量级与此前40分钟不冲突。

正片不解释这个区别。

# 本轮锁定候选原则

1. 真夏第一个视觉信号只给生田，含义只对应S15约定的`回正式曲目`。
2. 真夏第二个视觉信号给松下，只完成运营交接；松下仍要自己听音乐、决定升幕时机。
3. 固定高潮顺序：
   > 生田回正式音乐 → 松下听见 → 松下cue升幕 → 鞋 → 一条线裙摆 → 紫色 + 唯一一年级色 → 松下cue未央奈 → 未央奈第一声 → 高三合唱进入。
4. 幕升前不切观众成功反应；未央奈第一声之前不以掌声、笑容等替观众宣布成功。
5. 真夏在第一段进入后立即转去处理下一项；S22对白锁为`结束后，改从右边进。`
6. TAG最高一级立即再拆，不设置任何“刚装好又拆”的吐槽或感悟台词。
7. 下一项讲台从右侧进入；撤下台阶先放舞台后区临时位，避免物流冲突。
8. 正常单向strike约10分钟与事故整拆复原约40分钟属于不同工作量，不在正片解释。
