# S18｜15:00钢琴先开始

## 1. 人物行为引擎｜GREEN

### 生田

15:00按已经约好的时间自己开始，符合S15/S17锁定。

她从上午已经出现过的自由和声进入，不需要真夏再发一个“开始”信号。她此时做的是：在松隆子的专业边界内提供一个可伸缩的音乐缓冲。

### 中元

她无声组织队伍、数人数，属于既有人物功能：认真、准备、群体执行。

### 生驹

继续做最后的小件整理，符合她“先行动”的稳定行为，不需要额外对白。

### 若月

只沿台阶做现场目视与执行边界确认，不承担技术发现。

### まあ亚

删除再次蹲下检查顶层。她的S14空间贡献已经完整成立；重复会把人物能力变成标签。

**判定：GREEN。**

现在画面让顶层站满后排高三，足以回答“为什么必须装回来”。

不需要任何角色说明站位、视线或合唱编制。

**判定：GREEN。**

# S19｜后台入位 / 松下重新读取现场

## 1. 人物行为引擎｜GREEN

### 松村

保留她回来、看一圈、不说话、直接去帮另一边。

删除`终于看见当前状态而不是五分钟前状态`。她不需要完成一个作者总结式的小弧；信息已经过期这件事此前已经发生过，现在她只要正常重新进入现场即可。

### 真夏

她手里仍有表，但`14:30 舞台Ready`没有被追补勾掉。

这不是她突然不做记录，而是该时间节点事实上没有按时完成。她此刻把纸收一点、抬头读现场，符合本集已经建立的行为变化。

### 松下

他不因为“大家努力了”恢复未央奈，而是依次读取：

- 台阶已恢复；
- 队伍已站定；
- 若月给出现场可用接口；
- 中元给出人员到位接口；
- 原开场mark仍空；
- 未央奈就在侧边。

因此`堀。原来的位置。`来自专业条件变化，而不是情绪补偿。

### 高山

不再指定她第二次给未央奈让路。S13的关系动作已经足够；这里由队伍自然收半步，更符合群体现场。

**判定：GREEN。**

---

## 2. 日式关系对白｜GREEN

锁定候选：

**松下**  
堀。

**未央奈**  
是。

**松下**  
原来的位置。

**未央奈**  
……是。

这里不加：

- `刚才没确认，现在再来一次`；
- `还是让你上`；
- `准备好了吗`；
- `可以吗`。

松下作为负责开场安排的人，对已经接受过该岗位训练的未央奈，用极短的专业指示就够。

未央奈也不需要问`真的可以吗？`。她是一年级，对前辈/老师的正式指示先执行。

**判定：GREEN。**

---

## 3. 作者解释减法｜GREEN

删除：

> `这一次，松村终于看见的是当前状态，而不是五分钟前的状态。`

并把高山让路去命名化。

保留真夏表上空着的14:30格，因为这是可以拍到的物件状态，不是作者评价。

**判定：GREEN。**

## 4. 观众视角｜GREEN

第一次观看者此时会看到：

1. 15:00钢琴已经开始；
2. 后台因此还拥有一段可用时间；
3. 刚才没Ready的台阶现在已经站满人；
4. 若月、中元都给松下微小确认；
5. 松下看见原来未央奈的位置空着；
6. 再看侧边未央奈；
7. `原来的位置。`

这已经足以让观众理解：**刚才导致她被拿下的条件正在消失。**

但这一步仍不能直接跳到正式开唱，因此需要S20的无声确认。

**判定：GREEN。**

# S20｜原来的位置 / 无声最低确认

## 1. 人物行为引擎｜GREEN

### 未央奈

她回mark，不跑；低头确认脚下；不再碰已经正确的领巾；抬头跟松下视线。

这不是“突然变自信”的表演，而是具体任务重新开始以后，她把注意力从自我检查转回现场接口。

### 松下

他不安慰、不鼓励、不解释取消与恢复。

只完成工作所需的最小动作：站到指挥位 → 起手cue → 看未央奈跟上 → 她吸气但不唱 → 微小确认。

### 真夏

她只确认运营条件已经到位，并取得对幕前生田的视线。下一步怎么把音乐收回来，不由她判断。

**判定：GREEN。**

---

## 2. 日式关系对白｜GREEN

S20不新增一句对白。

这是最合适的关系表达：刚刚S19已经有`原来的位置`，之后的确认本来就属于排练/演出身体语言。

如果再说`看得到吗 / 再来一次 / 好，可以了`，都会把专业动作翻译成观众说明。

**判定：GREEN。**

---

## 3. 作者解释减法｜GREEN after revision

删除：

- `上午同样的位置……这一次没有`的文字复述；
- `确认她看得到自己，位置也成立`；
- `这就是14:35没能完成的最低限度确认`；
- `没有人说明它是什么`；
- 真夏逐项列名式`最后一圈`。

保留的全部是可拍动作。

**判定：GREEN。**

---

## 4. 观众视角｜GREEN / CAMERA YELLOW

剧本层面已经建立完整A类桥梁：

> 午间说`舞台好了以后再确认一次` → 14:35舞台没好，未央奈只能继续等 → 14:44取消特殊开场 → 15:00舞台与队伍终于恢复 → 松下重新叫她回原位 → 回mark → 松下给开头起手 → 未央奈吸气但不唱 → 松下确认。

普通观众不需要知道这叫position/cue check。

他们只需要感觉：

> **刚才没来得及做的那一下，现在补上了。**

### 拍摄硬要求｜YELLOW

这一段不能被快速交叉剪辑拆碎。

至少让以下动作形成连续观看链：

1. 松下看见空mark；
2. 看未央奈；
3. `原来的位置`；
4. 未央奈走回mark；
5. 松下到指挥位；
6. 抬手；
7. 未央奈吸气但不唱；
8. 松下小幅确认。

如果中间插太多生田、真夏、观众席反应，观众会把它看成“松下突然改主意”，而不是“条件重新成立”。

处理方式：**不加对白，只保证动作链不断。**

# 本组最终结论

**S18—S20可锁。**

锁定时应同时固定以下三条：

1. まあ亚S14之后不再承担任何舞台技术复检高光；
2. 高山S13以后不再被重复指定为未央奈的安慰/恢复接口；
3. 未央奈恢复的解释只存在于可见条件变化与无声cue，不增加说明台词。

下一组S21—S23需重点检查：

- 真夏→生田→松下的双cue是否一眼能分清；
- 幕升顺序是否有任何抢拍；
- `结束后，改从右边进`是否真正回收；
- TAG刚装回的最高一级再次拆除是否足够自然、且不被台词总结。
