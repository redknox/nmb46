## S02 锁定原则

- 松重丰不负责抖包袱；现实条件只是“文化祭当天换了临时菜单”。
- 笑点来自松村长期依赖“老样子”，突然需要自己点菜时短暂失去能力。
- 山田孝之不做“怪咖导演”的额外刻画；演员自身辨识度已经足够。
- 学生对白中不提山田名字，也不把他当兴趣对象。
- 山田相关对白到此为止；EP05后续只允许背景存在。
- 不写“尴尬”“只好”等心理解释；用“把嘴里的胶带换到另一边”呈现反应。
- S02尾声的跑动学生只是校园信息流，不锁定为后续那名传令后辈。

## S03 锁定原则

- 前15分钟没有混乱种子萌芽；文化祭此刻运行良好。
- 真夏不是“表演忙”，也不是在现场救火。她已经提前安排好一切，现在是在等待现实按时刻表兑现。
- 本场核心节奏是：**时间到了 → 人来报 Done → 勾掉 → 等下一项。**
- 她的能力通过“无需忙碌”来表现：整个校园忙，只有总控点处于从容的验收状态。
- 不安排“今天很开心吧”等替观众总结人物的对白。
- 不用掉便签、头也不抬找文件盘等动作刻意证明她熟悉系统。
- 不在此场引入具体传令后辈；信息系统正常存在即可。
- S03不预演后半集的故障，也不让真夏提前焦虑。
- 真夏此刻的默认信念是：**我已经安排好了，所以事情当然会按安排发生。**
- 她本集后续的变化，应该由这一套稳定节奏逐渐失效来呈现，而不是靠解释性台词。
- 旧版“旧礼堂上午合唱彩排”连续性失效：旧礼堂上午用于联合舞台剧，合唱排练在音乐与美术别馆完成。

## S04 锁定原则

- 旧礼堂上午用于联合舞台剧；本场合唱排练固定在音乐与美术别馆的音乐教室 / 合唱排练室。
- 未央奈在上午就通过视觉和音乐位置建立特殊性：**一片三年级紫色中唯一的一年级色，并承担全场第一声。**不靠对白解释“她是唯一一年级”。
- 生田的free不是事故起因，也不是有意识地“表演即兴”；她第一次开始真正听空间、残响和下一句之间的关系。
- Fukase的轻笑发生在音乐变化当下。他负责感受、free、表达出现的那一侧，但不变成神秘艺术圣人。
- **松隆子的角色轴是规则、纪律、技巧与专业边界。**她严肃而正确，不负责补一句“我其实也认可你的探索”。因此本场只说“正式按谱”。
- Fukase与松隆子不是“自由艺术家对守旧老师”的价值对决，而是职责不同：Fukase让生田听见感受，松隆子确保正式演出可完成、可重复、可交付。
- 真夏问的是演出时长是否可预测；松隆子给出“正式按谱”后，运营上的不确定性当场消失，因此真夏**不修改时间表**。
- 这场的关键不是“计划第一次出现偏差”，而是一个人物发现被成熟的专业系统正常容纳。
- 下午条件改变后，松隆子可以重新判断“生田能solo”。这不是态度软化，也不是被Fukase说服，而是专业条件已经变化。
- 未央奈结尾再次确认脚下位置、碰一下本来已经正的领巾，表现的是新人压力，不是学姐们比较随便。所有人都自然整齐。
- 呼应优先用动作，不优先用复述。

## S05｜REOPENED

> 先前锁定版本中的“用孩子/观众热度证明万理华装置成功，从而为后续坚持提供合理性”的处理作废。
>
> 原因：这会把万理华从主动创作者写成被观众反馈推动的人，与人物卡和行为引擎冲突。

### 暂时保留的S05骨架

- S04中生田的free已被“正式按谱”正常收住；真夏不修改正式节目时间。
- 万理华 / 西野关系线独立于主事故因果，不再承担后续舞台物流功能。
- 小泉今日子 × 白石麻衣段保留既定方向：
  - “你就是今年站这里的人啊。”
  - “我以前也拍过这种东西。”
  - “我那本早就找不到了。”
  - “今年也很热闹啊。”
- 家长对具体纸袋/垫纸准备说“真周到。谢谢。”的因果型称赞保留。
- 山田孝之不再获得明确中心镜头或学生对白。
- 12:30旧礼堂联合舞台剧正常结束、谢幕、关幕；所有人去午休，不制造事故预兆。

### 必须重构的万理华段

- 不再用“孩子舍不得走”“作品很受欢迎”“观众认可”替万理华提供坚持的正当性。
- 一个观众可以从作品原本的“出口”方向进入；工作人员想纠正，万理华只说“没事”。
- 之后万理华自己去那个角度看；西野自然站过去。
- 西野不替万理华解释，也不把她的选择变成集体讨论。
- 这条关系线到人物变化为止，不再接入景片、撤场、路线或通知事故。

### 重构纪律

**剧情机关服务人物，不允许为了后续事故因果，反过来把万理华改写成被动、心软或需要观众认可的人。**
