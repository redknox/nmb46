# 一、全局原则

## 1. 上午真的成功

前半段不能拍成“暴风雨前的宁静”。

文化祭就是顺利、热闹、好看。系统工作正常，学生和成年人都在做普通而具体的事。

事故不是某个早晨错误终于爆炸，而是下午 changeover 中原本存在的物理余量消失。

## 2. 没有人做错

- 景片正面尺寸正确；
- 新背撑更厚，是合理结构修改；
- 合唱台按原计划在已释放区域搭建；
- 真夏用五分钟 buffer 吸收局部偏差是正确判断；
- 若月先尝试不返工方案、避免随便拆已固定舞台结构是正确判断；
- 14:40 开门是正确判断；
- 松下取消未完成独立开场确认的新人领唱是正确判断；
- まあ亚拆最高一级是最小物理解；
- 真夏使用钢琴 solo 守住 15:00 是正确判断。

事故来自多个正确选择同时占据同一个物理现实。

## 3. まあ亚方案前的硬规则

> **在まあ亚提出方案以前，不拆已经完成并固定的合唱台。**

前期只能：

- 暂停尚未安装的后续模块；
- 清开可移动设备和杂物；
- 调整景片姿态、方向、pivot；
- 检查其他路线；
- 确认不能现场轻易拆掉景片固定背撑。

这保证まあ亚后面的贡献不是“大家早就拆了一部分以后她又多拆一点”，而是第一次准确指出：

> **真正挡住运输包络的只有最高一级。**

## 4. 未央奈的取消必须先建立流程原因

未央奈不是因为后台有危机就突然被拿掉。

她的正式开场岗位比高三合唱多一个独立步骤：

> **14:35 左右的开场位置 / 入口 / cue 确认。**

她是唯一一年级、不是高三常规声部成员，承担正式演出第一声。

舞台原定 14:30 Ready，随后才有这个单独确认窗口。

舞台没有在 14:30 Ready，于是 14:35 到点时她已经准备好，但舞台仍属于 changeover，确认无法进行。

14:40 House Open 后，完整空台确认窗口进一步消失。

松下到 14:44—14:46 才做降风险决定：取消未完成舞台确认的独立开场，回到已经成熟排练的高三完整合唱版本。

因此观众能直接理解：

> **被拿掉的不是“小姑娘”，而是那个没有完成必要舞台确认的额外开场环节。**

## 5. 对白后置

本版不再以中文完整句去追求最终对白质感。

逐场 screenplay 回写以后统一做一轮：

- 日语现场思维；
- 主语省略；
- 短句；
- 含混但可被动作补完；
- 少解释因果；
- 人物职业 / 年龄 / 前后辈口气区别。

# ACT 3｜25—35分钟｜一个物理事实拒绝配合

## S08｜旧礼堂舞台 / 侧台｜13:55—14:10

最后一块大型景片拆下。

前面其他景片都已沿同一路线正常出去，因此第一反应只是“角度问题”。

依次尝试：

- 退；
- 换另一端先走；
- 稍微立 / 抬；
- 改 pivot；
- 再来一次。

每次都比上次多一点，因此不断强化：

> **就差一点。**

若月加入后确认新版景片的关键事实：

- 正面宽高没有改变；
- 背部固定支撑更厚；
- 舞台尺寸没错；
- 运输包络变了。

此时仍然**不拆已完成合唱台**。

若月让现场继续尝试所有不需要返工的办法，再派人向总控报告。

未央奈一直在正确位置，没有迟到、迷路或漏通知。

约14:27—14:29，最后几种不返工方案基本耗尽。

现场第一次承认：

# ACT 4｜35—43分钟｜两个正确系统开始正面冲突

## S12｜旧礼堂后台 / 合唱准备区 / 前厅接口｜14:30—14:40

真夏进入现场后仍然首先试图**恢复原计划**。

若月守住安全边界；所有最后的景片姿态 / 空间尝试继续，但不危险蛮干。

松村进入口头信息网络：她没有传错，而是第一次遇到“刚才是真的、现在已经变了”的状态。

### 14:35｜未央奈原定开场位置确认失败

时间到了。

未央奈已经 Ready。

但主舞台仍处于 changeover，不能交给演出部门完成她的开场位置 / 入口 / cue 确认。

### 前厅

没有躁动、催促、投诉。

后台盯的是“景片什么时候能出去”；前厅盯的是“14:40什么时候开门”。

两个原本互不冲突的正确系统逼近同一个时间点。

## S14｜14:40—14:47｜取消未央奈独立开场

House Open 后，松下不立刻取消未央奈。

这不是责怪新人，也不是因为“后台乱所以随机砍一个人”。

未央奈不是常规高三声部成员，因此短领唱取消后，她当天的正式舞台任务暂时归零。

未央奈在后台边缘告诉高山自己上不了了，并先说“对不起”。

高山接受现实，不进行励志安慰；功能落点仍是：

> **那就不上。**

若南在场，可以自然分一颗自己正在吃的糖，不拍成“安慰道具”。

# ACT 5｜43—48分钟｜まあ亚把问题变成可计算工时

## S15｜14:47—14:50｜まあ亚找到最小物理解

到这里，所有不返工的常规方案已经试过。

まあ亚一直在现场做实际劳动。

她从低处看景片转向与合唱台真实碰撞关系，第一次把抽象问题：

> 景片 vs 合唱台

看成具体关系：

> **景片这一角只撞最高一级。**

她提出：

> 只拆最上面这一层。

这不是“发现合唱台能拆”，而是发现**最小充分干预**。

若月随后：

- 沿运输路径验证；
- 检查连接 / 支撑；
- 确认拆除可安全执行。

生驹听懂怎么做以后已经准备上手，但由若月要求按正确顺序、两侧同时执行。

角色功能固定：

> **まあ亚：看见。**
>
> **若月：确认。**
>
> **生驹：做。**

真夏获得关键决策信息：

- 景片能出去；
- 但最高一级拆掉以后必须装回、重新连接、重新检查；
- 所以“景片问题解决”不等于“舞台Ready”。

# 三、进入对白轮以前仍需做的最后一步

先进行一次**纯流程压力测试**，不讨论对白好不好听：

1. 每个人是否在需要出现之前已经自然存在于现场；
2. 每个专业人员有没有一个更早、更简单、明显应该采取的办法；
3. 每个时间节点是否有真实的步行 / 搬运 / 检查成本；
4. 主幕、观众、后台和声音规则是否连续；
5. 未央奈被取消 / 恢复是否都由可见条件变化触发；
6. まあ亚是否保有唯一且不可替代的“最小物理解”贡献；
7. TAG是否把高潮落回普通生活，而不否定刚才的认真。

压力测试通过后，再进入逐场 screenplay 回写与最终日系对白轮。
