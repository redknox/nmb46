# S18｜LOCKED｜15:00钢琴先开始

锁定动作：

- 15:00由生田按已知开演时间自行开始，不接受真夏额外开始cue；
- 主幕关闭，幕前钢琴单独开始；
- 生田从上午尾声已经出现过的自由和声出发；
- 琴声进入后台后，所有操作自然转入静音模式；
- 中元组织三排合唱入位；
- 刚复原的最高一级真实站满一整排高三，下面两级也填满；
- 生驹继续做最后小件整理；
- 若月只做现场安全/入位目视；
- まあ亚不再承担顶层技术检查。

锁定原则：

> **最高一级为什么必须拼命装回来，只让观众看见它真的有人要站。**

不出现：

- 主持人解释调整；
- 角色说明“这是为了拖时间”；
- 角色解释“刚才为什么一定要装回顶层”。

# S19｜LOCKED｜后台入位 / 松下重新读取现场

锁定动作：

- 生田继续自由延展，尚未回正式开头；
- 高三合唱继续安静站定；
- 中元无声数人数；
- 松村回来，看一圈，不报告、不复述旧信息，直接去帮另一边；
- 真夏手里的`14:30 舞台Ready`仍空着，她不追补勾，转而抬头读现场；
- 松下到场后先看三层台阶和队伍；
- 若月小幅点头，提供现场可用接口；
- 中元小幅点头，提供人员到位接口；

- 队伍自然收半步让出通路，不再指定高山承担第二次情绪动作。

# S20｜LOCKED｜原来的位置 / 无声最低确认

锁定动作顺序：

1. 未央奈走回开场mark，不跑；
2. 低头确认脚下mark；
3. **不碰领巾**；
4. 抬头；
5. 松下走到指挥位置；
6. 松下抬手，停在开头起手位置；
7. 未央奈视线跟上；
8. 手势到开口位置；
9. 未央奈吸气；
10. **不唱**；
11. 松下保持视线，小幅点头；
12. 未央奈留在mark；
13. 真夏扫过实际已Ready的后台：顶层站满、通道净空、拉幕侧在位、松下和未央奈在位；
14. 真夏侧过半步，取得对幕前生田的视线；
15. CUT TO S21。

本场不增加对白。

锁定删除：

- `这就是14:35没能完成的最低限度确认`；
- `没有人说明它是什么`；
- `确认她看得到自己，位置也成立`；
- 对上午摸领巾动作的文字复述；
- 真夏逐项点名式的`最后一圈`说明。

## 未央奈恢复桥梁｜LOCKED

必须让第一次观看者看见以下连续因果：

> **舞台/队伍条件恢复 → 松下亲自确认 → `原来的位置` → 未央奈回mark → 无声开头cue → 未央奈吸气但不唱 → 松下确认。**

禁止补：

- `刚才没确认，现在再来一次`；
- `还是让你上`；
- `准备好了吗`；
- `可以了`；
- 任何解释“为什么恢复”的台词。

## 镜头空间要求｜LOCKED NOTE

从松下看空mark开始，到松下点头确认结束，尽量保持为一条连续可读动作链。

可以有必要的空间切换，但不能插入足以打断因果理解的观众反应、真夏表情或生田特写。

目标不是让观众理解专业术语，而是让他们自然看懂：

> **刚才没机会做的准备，现在做成了。**

这句话只作为编剧/导演审查标准，不进入正片对白。
