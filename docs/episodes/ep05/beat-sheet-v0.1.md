# EP05《文化祭》｜Beat Sheet V0.1

> 目标：把 V2.0 的“钟 / 路 / 人”三条观众明线翻译成真正可拍的时间轴。
>
> 本版重点不是台词精修，而是控制：
>
> - 观众什么时候知道什么；
> - 哪个问题先被看见；
> - 哪个因果只需要二刷才能意识到；
> - 后半段空间如何收束；
> - 真夏如何从“总控表上的学校”进入“眼前真正的学校”。

暂按常规约 50 分钟正片估算，可在后续分场时微调。

> “3-C 开始了。”
>

>

> **今天虽然复杂，但这个学校运转得非常好。**

### 功能

必须先让“秩序”成立，后面的混乱才有价值。

# 观众知情度曲线

## 前段 0—17分钟

观众与真夏知道得差不多。

感觉：

> **复杂，但可控。**

## 中段 17—31分钟

观众开始看到一些真夏尚未完整意识到的潜在因果：

- 万理华的路；
- 被塞进口袋的纸；
- 未央奈反复等待。

感觉：

> **好像有些地方要撞上了。**

## 31—40分钟

观众已经知道系统正在失控，但不知道下一处会从哪里冒出来。

感觉：

> **越来越不妙。**

## 40—42分钟

真夏仍试图在纸上恢复系统。

观众已经基本不相信那张表还能救回来。

## 42分钟后

真夏放下夹板，进入后台。

人物与观众重新拥有同一个现实。

从此不再靠解释，而靠：

> **钟 / 路 / 人。**

## 44:30以后

钢琴开始。

时间从“越来越少”变成“暂时不知道还有多少”。

这是全集唯一真正的呼吸口。

随后镜头与行为一起收紧，直到幕布打开。

# Beat Sheet V0.1 的五条硬规则

1. **前半段真夏必须多次成功解决问题。**否则她的系统崩塌没有落差。
2. **被塞进口袋的通知纸不能强调。**允许第一次观看忘记。
3. **15:00以后逐渐减少地点，15:15以后尽量只剩礼堂走廊 / 后台 / 舞台。**
4. **真夏放下夹板以后，说明性对白必须显著减少。**
5. **最后两分钟主要靠动作、眼神、声音与空间完成，不靠人物总结。**

# 下一轮压力测试

Beat Sheet V0.2 前应检查：

- 50分钟内是否塞入过多信息；
- 前半段是否“太顺”导致文化祭缺少趣味；
- 未央奈出现次数是否刚好，不形成副主角错觉；
- 万理华 × 西野是否过于显眼；
- 真夏是否仍然抢走群像所有能动性；
- 生田即兴作为高潮缓冲是否在音乐逻辑上成立；
- 旧礼堂后台 / 走廊的实际空间是否能容纳高潮动线；
- 最后15分钟是否真的越来越少对白、越来越多身体行动；
- 观众即使忘掉一半前因，是否仍能享受高潮。
