# 1. 旧礼堂空间轴｜LOCKED

从S07正常换台开始，必须建立稳定、可重复的旧礼堂空间方向。

普通观众需要始终能大致追踪：

> 主景 → 原定出口 → 合唱台 → 后来清出的横向空位 → 主幕线 → 幕前钢琴 → 左右后台通道。

后续S08—S16不允许通过频繁翻轴或大量局部特写破坏这一空间记忆。

事故必须被拍成**具体物理问题**，而不是抽象混乱。

---

# 2. S14双转可读性｜LOCKED

S14开场旧单转与随后双转验证必须处在可比较的空间关系中。

必须让观众看见：

> 旧单转：持续旋转 → 合唱台进入扫掠空间 → 停。

以及：

> 新动作：第一转 → 横移 → 第二转。

双转模拟中必须视觉成立：

> 下层避开 → 中层避开 → 最高一级仍挡。

まあ亚不演成工程师或“天才解题者”；她用身体和手势提出动作，语气保持自然试探。

禁止用示意图、字幕、解释台词或“灵光一现”视听效果替代空间呈现。

---

# 3. S16兑现速度｜LOCKED

S14负责让观众看懂，S16负责让观众看到真的通过。

S16沿用同一空间轴，但屏幕节奏必须明显更快：

> 第一转 → 横移 → 第二转 → `……过了` → `先别松` → 景片继续出去。

S16不得再次拍成完整技术教学。

---

# 4. 钢琴 / 真夏 / 松下视线｜LOCKED

幕前钢琴从S07固定时就必须具备后续S21的真实视线条件。

生田坐在钢琴位置后，应能自然抬眼看到指定幕侧位置，不需要大幅扭身。

S20末真夏取得的站位必须同时满足：

- 一个方向看得到幕前生田；
- 转身 / 换视线后看得到主幕后松下；
- 不挡人员通道和拉幕工作。

这套空间关系必须物理成立，不能依赖剪辑假造。

---

# 5. S21双cue｜LOCKED

第一个视觉信号：

> 真夏 → 生田。

含义只对应：**回正式曲目。**

生田轻点头，手不停。

随后观众必须看见真夏完成一次明确的**转身 / 换视线方向**。

第二个视觉信号：

> 真夏 → 松下。

含义只对应：**后台运营Ready交接。**

两个cue的区别来自：

> 接收者 + 空间方向 + 真夏转身。

不靠两套夸张手势编码。

禁止剪成两个无接收者的孤立手势特写。

---

# 6. S19—S20未央奈恢复链｜LOCKED

从松下重新读取现场到无声确认结束，必须保持连续因果可读：

> 台阶可用 → 若月退开工作面 → 中元数完人 / 队伍站齐 → 松下看到空mark → 看到未央奈 → `原来的位置` → 未央奈回mark → 松下起手cue → 未央奈吸气但不唱 → 松下确认。

该链中禁止插入：

- 观众席反应；
- 真夏欣慰表情；
- 生田演奏美化特写；
- 高山“看到她回来”的情绪镜头；
- 任何成功反应。

未央奈听到`原来的位置`后只停半拍，不演明显惊喜。

回mark不跑。

她看脚下mark，但不碰领巾。

**不碰领巾不得用手部特写强调。**

---

# 7. S22幕升视觉顺序｜LOCKED

高潮揭示顺序固定：

> 正式音乐回来 → 松下决定升幕 → 鞋 → 裙摆一条线 → 紫色领巾 → 完整三层人群 / 最高一级后排 → 最前方唯一一年级色未央奈 → 松下cue → 未央奈第一声 → 高三合唱进入。

主幕升起时优先保持能让“从下往上揭示”成立的观众侧 / 正面构图。

不得一开始就切脸部特写。

最高一级必须在正式画面中真实站满后排，作为此前复原工作的视觉答案。

---

# 8. S22高潮声音｜LOCKED

未央奈第一声之前不得用任何声音替观众宣布成功：

- 无掌声；
- 无观众欢呼 / 笑声；
- 无额外成功配乐；
- 无角色松气声被刻意放大。

核心声音顺序：

> 生田正式和声 → 极轻舞台环境 / 幕升 → 松下cue → 未央奈呼吸 → **第一声人声。**

之后高三合唱进入。

---

# 9. S22 `改从右边进`｜LOCKED

低年级学生递下一项流程纸后，真夏只极短地看一次左侧环境。

左墙工具箱存在于正常空间中即可。

禁止：

- 工具箱插入特写；
- rack focus式“伏笔揭晓”；
- 低年级学生追随视线；
- 解释原因。

锁定对白继续为：

> **真夏：结束后，改从右边进。**

# 10. S23 TAG镜头纪律｜LOCKED

撤台安全顺序继续继承 `screenplay-scene-locks-v1.0.md`：

> 下层 / 前侧 → 第二层 → 最高一级最后。

尽量保持一个观众能认出“仍是刚才那个舞台”的较宽构图，让完整三层结构逐层消失。

最高一级最后离开时：

- 不慢动作；
- 不切任何人物感慨反应；
- 不加伤感配乐；
- 不强调“刚装回来”。

模块离开后，下一项讲台从右侧进入同一空间。

余韵由**同一个空间被下一项覆盖**产生。

# 12. 表演总纪律｜LOCKED

## 真夏

前半不演焦虑；后半不演救世主。

她的变化只通过读取对象变化呈现：

> 表 → 报告 → 现场 → 人。

## 若月

安全通过动作表现，不靠大声命令。

停、等、双侧确认、挡住提前踩台阶的人，比“专业脸”重要。

## まあ亚

S14以前正常劳动；S14用身体提出新搬法；此后重新回到普通劳动者。

不要演“灵光一现”。

## 生驹

行动先于解释，不追加热血表情。

## 松下

14:44取消未央奈与15:02恢复未央奈使用同一种专业工作基调；条件不同，所以判断不同。

## 未央奈

不演“被选中的主角”。紧张和变化主要落在小动作、关系语言和执行速度里。

## 高山 / 南

S13不演安慰戏。

高山真的继续找水；南真的继续给下一人分糖。

# 14. 声音总纪律｜LOCKED

后半集优先依赖现场声音完成节奏变化：

> 文化祭环境 → 搬景 / 金属 / 脚步 → 14:40幕后压低 → 15:00钢琴 → 后台静音工作 → 正式音乐 → 未央奈第一声 → 高三合唱 → 掌声 → 幕落 → 撤台工作声。

禁止用额外情绪配乐覆盖关键劳动节点。

尤其不为以下动作加“意义音乐”：

- まあ亚发现双转；
- 景片通过；
- 未央奈被叫回；
- TAG最高一级撤走。
