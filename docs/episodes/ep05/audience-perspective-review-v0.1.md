# EP05《文化祭》｜观众视角审查 V0.1

> 审查对象：`screenplay-draft-v0.4.md` + `screenplay-revision-v0.5.md` + `screenplay-revision-v0.6.md`
>
> 方法：`docs/writing/audience-perspective-review.md`
>
> 审查时不使用人物卡、因果模型、编剧注释、创作会议结论或“这个动作象征什么”的说明。
>
> 只承认第一次观看者能从正片获得的：**画面、对白、声音、剪辑顺序和此前正片信息。**
>
> 核心标准：**观众可以不知道我们的感悟，但不能不知道我们的故事。传达感受，不传达感悟。**

# 总结

当前版本：**无 RED。**

主故事已经可以在不读取任何幕后资料的情况下被第一次观看者跟上。

发现 2 个 YELLOW，均不是补对白问题，而是**视觉呈现 / 场面调度依赖**：

1. まあ亚“双转”必须让观众真正看见它与此前“单转”的区别；如果剪得太碎，纸面成立的因果可能在屏幕上消失。
2. S22 真夏“结束后，改从右边进”与14:54左侧工具箱的关系最好让镜头轻轻成立；即使观众没接上也不影响故事，但接上以后真夏的现场指挥感会更强。

除这两项外，关键 A 类信息均已建立。

# S05—S06｜进入文化祭的一天

## 万理华展示区

**GREEN / C类。**

观众看见：

- 一年级学生从标着“出口”的门走进去；
- 工作人员想纠正；

他们只需要感到：她没有急着纠正那个错误入口，后来自己也去那里看了一次。

不补解释。

白石最后拿另一本册子压住自己的照片、继续工作，保持原样。

# S08—S10｜最后主景卡住

## 为什么突然出不去

**GREEN / A类。**

观众看见前面景片能出去，最后主景却在转向时被合唱台占据的空间截住。

随后听见：

> 正面尺寸一样。后面厚了一点。

足够。

观众无需知道“运输包络”这个概念，只会自然理解：

> 看起来尺寸没变，但背后加固以后，转弯需要的空间变大了。

## 为什么不直接拆合唱台

**GREEN / A类。**

新版明确给出：

> 退一点没用。  
> 这里也在里面。  
> 这里也是。  
> 要清就得全清。  
> 恢复到能上人的状态，四十分钟左右。

然后若月：

> 那就不动。

第一次观看者完全能跟上：

> **不是没人想到拆，而是当前正常走法如果靠拆台解决，就得把整套拆掉，时间上不可执行。**

这里不需要再补“因为15:00要演出所以40分钟来不及”。钟、流程和此前15:00准备已经足够。

## 五分钟 → 说不好 → 不知道

**GREEN。**

14:11现场仍相信是普通角度问题，所以报“五分钟”。

随后备用路线、支撑、整拆方案都被排除，14:26变成“现在还说不好”，14:30变成“……不知道”。

观众无需理解“可估时性”这个抽象概念，也会感觉到：

> 五分钟还能安排；不知道才是真的坏了。

不解释。

**GREEN / B类。**

> 那边也停了。

因此即使完全不懂剧场运营，也能理解：

不要增加解释广播。

## 14:44未央奈为什么被拿下

**GREEN / A类。**

观众已经知道：

## 高山与南

**GREEN。**

观众感受到的是：她失去了一个机会，但世界没有因此停下来举行安慰仪式。

不需要角色告诉观众如何正确理解这件事。

# S14｜まあ亚“双转”

## 因果理解

**YELLOW（拍法依赖），剧本信息本身足够。**

这是当前整集最依赖视觉呈现的 A 类机关。

纸面上观众得到的链条是：

- 前面所有尝试都在同一区域用一把大转向解决；
- 大家不断清走箱子、谱架、小设备；
- 侧边因此出现一块可供横向送入的空间；
- まあ亚没有继续研究“碰哪里”，而是看这块东西“刚才怎么走”；
- 她提出：先转到这里 → 往旁边一点 → 再转一次；
- 舞台技术学生不相信也不否定，先让大家慢速走一遍；
- 第一次转；
- 横移；
- 第二次转；
- 下两层真的避开；
- 只有最高一级还挡；
- 技术学生因此确认“只拆最上面就够”。

只要这些空间关系被观众真正看见，因果是 **GREEN**。

### 风险

如果拍摄时把此前多次尝试都剪成手、脚、表情、特写，而没有让观众建立“大家一直是一把转过去”的整体动作，那么到まあ亚说“再转一次呢？”时，观众可能只得到：

> 她突然有了一个办法。

而不是：

> **她改变了大家默认的搬法。**

### 修复要求：不用加对白

必须至少保留一种稳定的空间观看方式：

- 此前单转至少有一次较完整的中 / 全景；
- まあ亚提出方案后，第一转 → 横移 → 第二转尽量在相近轴线 / 可比较构图中呈现；
- 让观众肉眼看见“下两层这次真的不在轨迹里”。

不要用工程示意图，不要补角色解释“双转为什么改变扫掠范围”。

**结论：剧本不改；作为后续表演 / 镜头空间审查的硬要求保留。**

# S14—S17｜40分钟变成10分钟

**GREEN / A类。**

此前观众听过整拆约40分钟。

双转慢速验证以后，技术学生说：

> 只拆最上面就够。

随后：

> 拆、让景片出去、再装回来。  
> 十分钟左右。

观众完全能理解为什么这个方案现在可做、之前不可做：

> **不是突然拆得更快，而是新的走法把需要拆掉的范围从整套缩到了最高一级。**

这就是必须传达的故事层。

至于“这说明不同思考方式有价值”之类的意义，完全不说。

## 为什么最高一级要马上装回来

**GREEN，采用延迟视觉回答。**

景片出去后，大家立刻把最高一级装回。

此时少数观众可能短暂想：

> 不装不行吗？

但15:00以后，最高一级真实站满一整排高三学生。

答案由画面补上。

不需要提前解释“这里是完整后排站位”。

# S17—S20｜舞台Ready与未央奈恢复

## 15:00为什么仍然先钢琴，而不是直接合唱

**GREEN。**

14:49时“十分钟左右”只是物理恢复估时。

观众随后实际看见：

- 最高一级还要回装和复检；
- 合唱成员还要无声进入；
- 中元还要点人数；
- 松下还要确认状态；
- 未央奈此前又已经被取消。

所以即使14:58左右物理台阶恢复，15:00仍让钢琴先开始非常自然。

无需解释“物理Ready不等于演出Ready”。

## 未央奈恢复

**GREEN / A类。**

这是此前最大的观众漏洞，当前已经闭合。

松下：

> 堀。原来的位置。

未央奈回 mark。

松下去指挥位，抬手。

未央奈看 cue，吸气，但不唱。

松下确认，轻轻点头。

第一次观看者不需要知道“position / cue handoff”这些词。

他们只需要自然得到：

> **刚才没能做的准备，现在终于做了。**

于是她后来重新承担第一声不会产生“不是刚取消了吗？”的跳跃。

# S22｜“结束后，改从右边进”

**YELLOW（非故事理解问题，属于视觉收益）。**

即使观众完全没记住14:54工具箱被放到左侧，他们仍然能理解：

> 真夏看了一眼现场，把下一场讲台路线改成右边。

所以这不是 A 类漏洞。

但如果镜头能让她的视线落到左侧墙边工具箱，再回到流程纸，这个小因果会把她此刻的变化表现得更漂亮：

> 她不是照着表读，而是在读现场。

### 修复要求：不加对白

建议只保留：

- 真夏接纸；
- 一个极短视线到左侧；
- 左侧工具箱在画面里可辨；
- 回来；
- “结束后，改从右边进。”

不要切工具箱特写，不要让低年级问“因为左边吗？”。

**结论：对白不改，留到镜头空间审查落实。**

# A / B / C 最终判定

## A类｜必须明白

当前全部通过：

- 下午旧礼堂正在从舞台剧转换成合唱；
- 最后主景为什么突然出不去；
- 为什么不能直接整拆合唱台；
- 为什么“五分钟”后来变成“不知道”；
- 为什么14:40仍能先开门；
- 未央奈为什么被取消；
- まあ亚的新路径为什么让问题从整拆缩小到只拆顶层；
- 为什么10分钟方案现在可执行；
- 为什么真夏想到钢琴；
- 为什么15:00仍先钢琴；
- 未央奈为什么后来又能恢复；
- 为什么最终能够升幕进入正式合唱。

**A类：全GREEN。**

## B类｜感觉到即可

当前成立：

- 真夏从看表逐渐转成看现场；
- 现场正确行动比中央表更新得更快；
- 松村的信息会自然过期；
- 松隆子没有放弃规则，只允许可控例外；
- 真夏在双 cue 后退出音乐判断；
- まあ亚靠身体和空间直觉改变默认动作。

其中“双转空间”和“右侧讲台”两项对镜头呈现有要求，列为 YELLOW，但不需要补对白。

## C类｜只进入潜意识

保持不解释：

- 小泉旧节目册与白石；
- 紫色高三与唯一一年级颜色；
- 高山“那就不上了”；
- 南的糖；
- 一条线的裙摆；
- 最高一级刚装回去又被拆；
- 真夏演出一开始就继续处理下一项。

**C类不得升级成解释台词。**

# 审查结论

> **EP05 当前版本已经通过第一次完整“去编剧知识”测试。**

没有需要增加说明台词的 RED。

后续不应再为了“让观众更懂”主动补解释。

下一步进入逐场锁定时，只保留两个视觉检查项：

1. S08—S16 的空间调度要让“单转”和“双转”在屏幕上可以比较；
2. S22 真夏改右侧路线时，让左侧工具箱在视线关系里轻轻存在。

除此之外，当前更重要的任务已经不是“解释清楚”，而是继续删掉可能替观众总结意义的东西。
