# EP05《文化祭》｜Beat Sheet 压力测试 V0.1

> 测试对象：`beat-sheet-v0.1.md`
>
> 测试目标：不再检查“因果是否聪明”，而检查它是否真的能被观众在约50分钟内看懂、感到、记住，并能在旧礼堂空间中被演员和镜头自然完成。

---

# 一、总体判定

**故事骨架通过，不需要重写。**

V0.1 最大优点仍然成立：

> 多点小问题 → 彼此改变条件 → 三条明线“钟 / 路 / 人”逐步亮红 → 真夏的纸面系统失效 → 所有线物理汇流到旧礼堂 → 生田即兴提供弹性时间 → 幕布打开。

真正需要调整的是：

- 部分段落过于“专门为一条线停下来”；
- 真夏前中段仍有成为万能中枢的风险；
- 高潮后台人数过多会造成空间与镜头拥挤；
- 一些对白虽然概念漂亮，却会抢走整季其他母题；
- 舞台 / 钢琴 / 幕布之间的物理关系需要提前为拍摄成立。

因此 V0.2 应坚持：

> **不换故事，只减解释、减停顿、减角色抢戏，并让空间与声音承担更多信息。**

---

# 二、压力项1｜50分钟内是否塞入过多信息？

## 判定：黄色，需轻度压缩

信息总量本身并未超标，因为观众最终只追“钟 / 路 / 人”。

问题在于 V0.1 中有几段被写成了相对完整的小场：

- 23:00—25:30 未央奈等待；
- 31:30—34:00 万理华 × 西野；
- 38:30—40:30 未央奈“我上不了了”。

如果三段都按足时长拍，观众会感觉主线连续三次为了人物支线踩刹车。

### V0.2 调整

- 未央奈前期等待从“完整场”改为散落在其他场景边缘的3—10秒重复镜头；
- 万理华 × 西野压到约45—75秒，并让拆除动作与“路恢复”同时发生；
- 未央奈崩溃控制在约60—75秒，不让整个后台停下来陪她。

结论：

> **不是删信息，而是避免每条信息都拥有自己的完整场景。**

---

# 三、压力项2｜前半段会不会太顺，导致文化祭缺少趣味？

## 判定：绿色，但必须保留“文化祭真的很好玩”

前半段真夏持续解决问题是必要的，否则后面“系统死亡”没有落差。

但如果前17分钟全部围着总控桌与调整流程，观众会觉得自己在看活动执行纪录片。

### V0.2 调整

前17分钟继续保留若干纯粹成功 / 快乐的文化祭碎片：

- 普通学生摊位忙得很开心；
- 松村穿梭多个圈层；
- 高山临时救一个小场子的气氛；
- 白石承担“文化祭对外的脸”；
- 新生第一次参加学校文化祭的兴奋；
- 西野安静看万理华作品真的被人使用。

这些片段不新增故事线。

功能只是不断提醒：

> **今天首先是她们期待了很久的文化祭，其次才是一场系统灾难。**

---

# 四、压力项3｜堀未央奈出现次数是否刚好？

## 判定：V0.1略偏多镜头意识，V0.2需降级

目前她在：

- 冷开；
- 第一次等待；
- 第二 / 三次等待；
- “我上不了了”；
- 最终自己回来。

结构是对的，但如果每次都独立切她近景，她会开始像本集B线主角。

### V0.2 规则

1. 冷开只作为一年级群体中的一张熟脸；
2. 前两次等待尽量发生在其他场景的边缘，不给“现在我们来看未央奈”的提示；
3. 真正第一次拥有完整镜头权，只在“我上不了了”；
4. 重新站起来仍然极短；
5. 全集不需要一期生集体围着她；
6. 陪她的人控制在高山 + 南即可，深川可以不加入这条线。

她的全集功能仍然是：

> **有脸、有尊严、有一个很小的完整瞬间，但不能让观众开始期待“下一集她怎么样”。**

---

# 五、压力项4｜万理华 × 西野是否过于显眼？

## 判定：故事正确，时长过重

这一场是当前全季关系网中少数明确允许发生 B→A 变化的节点，因此不能删。

但 V0.1 给到约2分30秒，在全剧已经进入连锁危机以后会显得过于“珍贵”。

### V0.2 调整

压缩为：

> 若月：“真的要撤。”
>
> 西野摸外围：“这个也是吗？”
>
> 万理华：“什么？”
>
> 西野：“这个也一定要在吗？”

万理华看一眼。

直接动手拆：

> “这个不是。”

西野接住拆下来的部分。

结束。

关系变化和道路恢复在同一个身体动作里完成。

### 更准确的关系判定

本场优先视为：

> **万理华一侧的 B→A 凝结点。**

西野一侧是否完全进入 A，可继续留到之后她自己的选择线再完成，符合关系变化允许不同步的原则。

---

# 六、压力项5｜真夏是否仍然抢走群像所有能动性？

## 判定：黄色，是 V0.2 最重要修正之一

V0.1 已经通过“真夏前半段固定在总控点”解决很多问题，但仍存在：

> 每个问题 → 汇报真夏 → 真夏给答案。

如果反复如此，其他人物会变成她的执行器。

### V0.2 原则

**真夏只处理跨系统约束，不处理所有局部问题。**

局部人物自己行动：

- 若月自己和万理华谈撤场；
- 松村听见“少人”后可先自然开始找，不必等真夏派任务；
- 桥本主动算“还剩多少现实时间”，不是受命做计算；
- 白石自己维护前台体面；
- 生驹看到需要搬就直接搬；
- まあ亚看到现场有更好方法就直接指出；
- 卫藤等人处理普通学生的现场迷茫，不进入总控系统。

真夏真正负责的是：

> **当A的解决方案会影响B时，决定整个系统怎么重新接。**

这样 EP05 的主题才不是：

> “真夏一个人救了大家。”

而是：

> **一群人各自在动，真夏逐渐学会系统不是只有她的表。**

---

# 七、压力项6｜生田即兴作为高潮缓冲，在音乐逻辑上成立吗？

## 判定：成立，但舞台设计必须支持

逻辑上完全可以成立：

- 生田足够专业；
- EP04 已完成“离开谱面 / 听现场”的铺垫；
- 即兴独奏天然可以延长或收束；
- 真夏需要的正是一段可伸缩的时间。

但拍摄前必须解决一个物理问题：

> **钢琴在哪里？幕布在哪里？观众是否能在完整舞台尚未揭示时听见 / 看见生田？**

### 推荐舞台方案

最终舞台原本就包含生田钢琴段。

钢琴位于：

> **舞台最前沿 / 前台口可独立使用的位置**

而合唱升台、其他成员与最终画面位于其后，由主幕或灯光区隔。

这样可以做到：

1. 生田先开始演奏；
2. 后台继续无声调整；
3. 一切准备好后，后方幕布 / 灯光揭示完整群像；
4. 生田从即兴自然转入正式作品。

如果旧礼堂具体舞台格局未来证明不支持“前台口钢琴”，则必须在舞台布局设计时提供等价方案。

### 音乐收束方式

不要让工作人员用“停”的手势粗暴打断。

更合理的是：

- 松下进入生田视野；
- 生田读到准备信号；
- 她把即兴逐渐引向正式曲目的调性 / 和声入口；
- 松下识别到入口；
- 合唱加入。

这既专业，也真正落实“听与回应”。

---

# 八、压力项7｜一句必须修改的对白：“不知道”

## 判定：必须改

V1/V2 中：

> 生田：“弹多久？”
>
> 真夏：“不知道。”

作为真夏本集成长表达非常漂亮。

但整季已经锁定：

- EP08 飞鸟：“为什么要跑？”
- 江口：“不知道。”
- EP12 南：“为什么跑？”
- 飞鸟：“不知道。”

“为什么跑 / 不知道”是飞鸟整季最重要的专属回声之一。

如果 EP05 提前让真夏用同样的“接受不知道”完成明显人物节点，会稀释这个母题。

### V0.2 推荐

> 生田：“弹多久？”
>
> 真夏：“**能弹多久就弹多久。**”

或：

> “**先别管时间。看我信号。**”

前者更能表现真夏已经放弃固定时长；后者更自然、执行感更强。

当前推荐第一句作为概念，最终对白阶段再决定口气。

原则：

> **真夏可以接受不确定性，但不要抢飞鸟的“不知道”。**

---

# 九、压力项8｜旧礼堂后台 / 走廊真的容得下高潮吗？

## 判定：可以，但不能把17个主要人物全塞进同一个后台镜头

Campus Map 已确定：旧礼堂位于校园西南生活区，后勤入口在西侧；艺术别馆位于东南。文化祭本来就会形成艺术别馆 / 后勤入口 / 旧礼堂之间的跨校园物流。

这使“路线问题”总体成立。

但旧礼堂又是老建筑，后来正因为动线、疏散、无障碍等限制被正式评估。

因此高潮如果拍成：

> 17名主要演员 + 一大群普通学生 + 大型布景 + 升台 + 器材全部挤在同一个狭窄后台

会同时产生两个问题：

1. 镜头不可读；
2. 学校看起来已经明显违规到不可能没人发现。

### V0.2 空间分层

#### Z1｜舞台 / 侧台

- 生田；
- 松下；
- 中元与合唱成员；
- 堀未央奈等最终舞台成员。

#### Z2｜后台主通道

- 真夏；
- 樱井；
- 若月；
- 松村；
- 生驹；
- まあ亚；
- 必要工作人员。

#### Z3｜后台边缘 / 小等候区

- 高山；
- 南；
- 未央奈短暂停留。

#### 其他人物

- 白石主要承担前台 / 侧台转换；
- 西野 / 万理华完成道路节点后不必一直留在后台中央；
- 飞鸟只需一个非常短的身体动作；
- 卫藤、深川、桥本等不必为了“群像高潮”强行全员集合。

硬规则：

> **EP05高潮不欠17个人每人一个镜头。**

群像感来自不同人已经在前40分钟构成系统，不来自高潮点名。

### 安全表现规则

道路堵塞必须主要发生在**物资转运路线**，不能表现成观众入场后的消防疏散出口被大型器材长期堵死。

否则会破坏第10集“后来经专业评估才正式停止大型使用”的可信度。

# 十、压力项9｜最后15分钟是否真的越来越少对白？

## 判定：V0.1 后5分钟很好，但36—44分钟仍偏多

目前真正明显进入身体叙事是在44:30以后。

如果我们声称“最后15分钟逐渐减少对白”，需要更早开始降语言密度。

### V0.2 建议

#### 35分钟左右开始

对白从完整解释句改成短命令 / 状态词：

> “少两个。”
>
> “找到了。”
>
> “这边。”
>
> “先别动。”

#### 未央奈段

控制在极少句子，不让其他人分析她。

#### 40分钟后

禁止长汇报。

#### 42分钟后

仅保留少数必要锚点：

- 真夏：“现在能先上什么？”
- 生田关于时长的一句；
- 樱井取消 / 后移的局部决定。

#### 最后约3分钟

几乎没有完整对白。

结论：

> **不是突然在47分钟“安静下来”，而是从35分钟开始，语言一层层被现场挤掉。**

# 十一、压力项10｜观众忘掉一半前因，高潮还成立吗？

## 判定：通过

这是 V2 结构最成功的地方。

即使观众完全忘记：

- 生田为什么最初造成时间漂移；
- 通知纸什么时候被塞进口袋；
- 大布景为什么改走另一条路；

到了28—30分钟，只要看懂：

- 钟快到了；
- 东西堵着；
- 人没齐；

就能够继续享受高潮。

### V0.2 再强化三个视觉“复位点”

#### 钟

反复使用同一只旧礼堂墙钟，但不要过量。

#### 路

同一个宽景：

> 堵住 → 松动 → 最后通畅。

#### 人

合唱等候区用简单站位 / 地面标记形成：

> 三个空位 → 两个空位 → 全部站回。

这样观众无需回忆因果，只看现状即可重新进入剧情。

# 十二、额外发现1｜白石的后台动作需要调整

V0.1 中白石“刚从台前微笑回来，一过幕布立刻进入真实后台”非常好。

但如果她也是最终舞台成员，就不能在最后几分钟还大量搬运或处理脏乱工作，否则服装 / 准备逻辑不成立。

### V0.2

白石的功能改成：

- 前台维持来宾体验；
- 早已完成个人舞台准备；
- 回侧台后快速读懂情况；
- 帮忙稳定人、传递简短信息、补一个公开形象缺口；
- 不承担大型搬运。

她的“台前 / 台后瞬间换脸”保留即可。

---

# 十三、额外发现2｜樱井为什么不在总控桌？

需要给观众一个自然答案，否则学生会长长期不在核心控制点会显得奇怪。

### V0.2定位

EP05里：

- 真夏负责**运营中枢**；
- 樱井负责**正式对外 / 教师 / 校方协调与需要身份背书的决定**。

因此樱井会偶尔经过总控点，但不会坐在那里替真夏管理细节。

这恰好表现两人的互补：

> 樱井决定学校此刻允许什么；真夏决定具体怎么做到。

EP05樱井仍只是 S，不提前完成 EP10。

---

# 十四、额外发现3｜文化祭高潮不能强制全员“贡献价值”

V0.1 的行为蒙太奇已经非常接近正确，但仍需防止写作时出现：

> “还有卫藤没做事，给她一句。”
>
> “深川也得有镜头。”
>
> “中元也得帮个忙。”

这是群像剧最危险的平均主义。

### V0.2硬规则

- 中元如果本来就在最终合唱中，站在舞台队伍里就是她的真实存在；
- 卫藤可以在本集前段已有被照亮，不必高潮再打卡；
- 深川无需加入未央奈线；
- 桥本负责现实时间判断后，可以自然退到侧边；
- 飞鸟一个搬箱子的动作已经足够。

> **群像不是每个人在高潮都做一件有用的事，而是观众相信所有人此刻都在这个学校里。**

# 十五、V0.2 修改清单

保留故事骨架，只做以下调整：

1. 未央奈前期出现碎片化，不再单独占完整2分半场景；
2. 未央奈崩溃缩短，只由高山 + 南承接；
3. 万理华 × 西野压缩到45—75秒并与拆路同步；
4. 真夏只处理跨系统问题，其他角色主动解决局部问题；
5. 删除真夏的“**不知道**”，保护 EP08→EP12 飞鸟母题；
6. 预设钢琴 / 幕布空间必须支持“可延展钢琴前奏”；
7. 高潮分三个物理区域，不强行17人挤后台；
8. 堵路必须是后勤路线问题，不制造明显消防出口违规；
9. 从约35分钟开始逐层减少对白；
10. 用“同一只钟 / 同一条路 / 空位数量”作为观众记忆复位器；
11. 白石不做脏重搬运，保持其前台 / 侧台角色逻辑；
12. 明确樱井承担正式协调、真夏承担运营中枢；
13. 高潮不欠每位主要角色一个功能性镜头。

---

# 十六、最终结论

Beat Sheet V0.1 **通过压力测试，进入局部修订，不需要结构重写。**

V0.2 最重要的方向不是让剧情更聪明，而是让它更自然：

> **角色不再轮流展示功能；事情继续发生，她们只是按照自己本来就会有的方式去动。**

当观众不再意识到“现在轮到谁发挥”，EP05 才真正从精密设计变成一场看起来自己发生的文化祭。
