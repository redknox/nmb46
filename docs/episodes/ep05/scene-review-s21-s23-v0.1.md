# S21｜两个信号

## 1. 人物行为引擎｜GREEN

### 真夏

成立。

她只做两次运营接口动作：

1. 确认生田可以开始把音乐收回正式轨道；
2. 把后台Ready状态交给松下。

之后她不继续判断音乐何时真正适合升幕。

这符合她此刻从“抓住所有流程”转向“把正确部分交给正确的人”的行为变化，但正片不需要说出这个成长。

### 生田

成立。

她收到信号以后并不机械切歌，而是在当前乐句中把自由和声收回正式和声。决定“音乐怎么回去”的仍然是她。

### 松下

成立。

他收到真夏的运营信号后仍然自己听音乐，自己决定什么时候给升幕cue。没有被真夏变成遥控执行者。

## 2. 日式关系对白｜GREEN

本场无新增对白。

依靠视线、点头、工作位置完成交接，比补`准备好了`、`可以开始了`更符合已经建立的现场关系。

## 3. 作者解释减法｜GREEN

删除：

- `音乐判断已经不是她的工作`；
- `现在只听生田`；
- `松下判断入口正在成立`。

动作已经说明权限如何转移。

## 4. 观众视角｜YELLOW（镜头依赖）

A类信息本身完整：

> 真夏先给生田信号 → 生田收到 → 真夏转向松下给第二个信号 → 生田逐渐回正式音乐 → 松下听 → 松下决定升幕。

风险只在拍法：若两个信号剪得太近、方向不清，观众可能把它们看成“同一个人连续打两个手势”。

### 拍摄要求

- 第一个信号明确有生田作为接收者；
- 真夏必须完成一次可见的转身/换视线；
- 第二个信号明确落到松下；
- 不靠不同手势编码含义，靠空间关系区分。

不补对白。

# S22｜一条线的裙摆

## 1. 人物行为引擎｜GREEN

### 松下

先听到正式音乐真正回来，再给升幕cue；幕升后再给未央奈开口cue。两次音乐判断都属于他。

### 未央奈

不因为“恢复”获得额外情绪表演。她只按刚确认过的mark、视线和cue唱出第一声，然后退回原位。

### 真夏

第一段一进去就转身处理下一项。她不需要看完整首歌，也不需要给自己一个“终于成功”的反应镜头。

`结束后，改从右边进。` 是现场指挥，不是流程说明。

## 2. 日式关系对白｜GREEN

**低年级学生**：`副会长，下一场的讲台——`

是很自然的工作接口省略句：对方不必把完整问题说完，真夏已经知道需要确认什么。

**真夏**：`结束后，改从右边进。`

对本校低年级执行人员而言，简洁、明确、职位关系成立。

`改`是关键：表明她在修改已有计划，而不是给观众介绍既定路线。

## 3. 作者解释减法｜GREEN

删除：

- `上午S04的声音回来`，改成可听事实`唱出上午同一段开头的第一声`；
- `一片紫色把她接进去`；
- `不给欣慰反应镜头`；
- `两个人已经在处理下一件事`。

高潮只保留声音、身体、幕和工作动作。

## 4. 观众视角｜GREEN / 轻微镜头YELLOW

高潮A类顺序完整：

> 正式音乐回来 → 松下cue升幕 → 鞋 → 裙摆 → 紫色 + 唯一一年级色 → 未央奈第一声 → 高三合唱进入。

不需要观众先理解主题。

左侧工具箱 → `改从右边进`属于B类增强信息。即使观众没接上，也完全理解真夏做了一次现场路线调整。

### 镜头要求

真夏看左侧只能是一眼，不做工具箱插入特写，不让低年级追问原因。

# S23｜TAG

## 1. 人物行为引擎｜GREEN

### 若月

演出结束立即回到现场执行：`最上面先下来。`

没有发表“刚才那么辛苦才装回去”的感想。

### 生驹

`好。` 然后动手。符合她行动先于解释。

### まあ亚

喝水 → 拧瓶盖 → 放下 → 走过去 → `这边先松？`

她没有再次提出空间答案，只作为已经熟悉这项劳动的人回去继续做事。

### 真夏

继续处理校友等待与下一项，不停下来回顾刚才的危机。

## 2. 日式关系对白｜GREEN

`不好意思，这边什么时候可以进去？`：下一项学生面对舞台工作组，礼貌请求而非催促。

`稍微等一下。先把这边撤开。`：现场执行回复自然。

`这边先松？ / 嗯。不过另一边先别抬。 / 好。`：熟悉现场劳动中的短确认成立。

真夏对低年级工作人员：

> `那先请她们到休息室等一下。这边好了再去叫。`

属于组织内部对外宾接待安排，关系语气成立。

## 3. 作者解释减法｜GREEN

删除：

- `没有音乐`；
- `没有慢镜头`；
- `只是普通换台`；
- 所有“刚装回去又拆”的意义总结。

真正的TAG是动作本身：

> 刚才站满高三的最高一级 → 幕落 → `最上面先下来` → 模块被抬走 → 讲台进来。

## 4. 观众视角｜GREEN

观众不需要知道完整物流模型，也能明白：演出结束了，下一项需要不同舞台，所以大家立即换场。

右侧讲台路线与此前S22明确呼应；撤下的合唱台模块去舞台后区临时位，不再与右侧入口打架。

此前事故`40分钟`与这里正常约10分钟换场不会构成观众矛盾：正片中已经看见事故方案包含“拆掉以后还要装回来、重新确认”，而TAG显然只是单向撤走。

不需要任何角色解释两者区别。
