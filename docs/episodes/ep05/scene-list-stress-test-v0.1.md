# EP05《文化祭》｜Scene List 压力测试 V0.1

> 测试对象：`scene-list-v0.1.md`
>
> 本轮不再检查故事骨架，而检查它作为“真正可拍的场景集合”是否成立。
>
> 核心问题：
>
> - 场次是否过碎；
> - 镜头是否在替编剧解释结构；
> - 人物是否会为了功能突然出现在不自然的位置；
> - 旧礼堂空间是否支持高潮；
> - 几乎没有对白的最后几分钟，观众是否仍然完全看得懂。

---

# 一、总体判定

**Scene List V0.1 通过，不需要结构重写。**

但进入正式分场稿前，建议做一次 V0.2 局部整形。

最大的风险已经不是“观众看不懂”，反而是：

> **观众太容易看出编剧正在帮助他们看懂。**

也就是说，V0.1 的逻辑已经足够清楚，现在需要进一步把“钟 / 路 / 人”的结构痕迹藏起来。

V0.2 的主要任务应是：

> **合并若干场次、减少刻意复位、让人物位置更自然、让高潮的空间调度真正可执行。**

---

# 二、压力项1｜33场是否过碎？

## 判定：纸面偏碎，实际拍摄可以成立，但需要把“场”重新理解成“连续调度单元”

33场并不是33个完整对话场。

其中很多本质上是：

- 插镜；
- montage；
- 同一行动链上的位置变化；
- 观众状态复位镜头。

因此50分钟内并不天然过量。

真正的问题是：如果剧本格式也机械地把每个插镜都做成独立 Scene Heading，节奏会看起来像：

> 切。切。切。切。

文化祭会失去“整个校园同时活着”的连续感。

### V0.2建议

以下场次在正式分场稿中可以保持编号意义，但拍摄 / 剧本层面尽量合并成连续序列：

- S01 + S02：文化祭开放 → 总控点，作为一个流动冷开；
- S08 + S09 + S10：布景遇阻 → 消息回总控 → 借人 → 通知纸被忘，形成一条连续因果链；
- S14 + S15 + S16：不要真拆成三个“展示场”，改成一次交叉升级序列；
- S17 + S18：万理华拆掉外围 → 同一动作直接释放路线；
- S30 + S31 + S32：最后两分钟必须感觉是一条完整呼吸，不能靠场号切碎。

### 目标

Scene List可以保留约30个逻辑节点，但真正观看体验最好接近：

> **22—26个可感知场景单元。**

# 三、压力项2｜S03 与高潮钢琴是否形成足够强的视觉回声？

## 判定：逻辑回声很强，视觉回声还可以进一步设计

目前结构已经非常漂亮：

### S03

生田即兴太长。

真夏：看时间。

### S27以后

生田再次即兴。

真夏：不再要求固定时长，而是给现场信号。

如果只靠剧情内容，已经成立。

但这一回声值得让镜头也帮忙。

### V0.2建议

S03 和 S27 可以共享一个非常轻的构图母题：

- 同一架钢琴；
- 相近的舞台角度；
- 生田开始弹时相似的第一组镜头；
- S03切到真夏看手表 / 总控表；
- S27同样有机会切真夏，但她此时看的是后台现场与舞台侧翼。

关键不是做“前后对比MV”，而是让观众潜意识感觉：

> **还是这架琴，还是这个人，真夏看东西的对象已经变了。**

# 四、压力项3｜S06 → S08，观众真的记得住万理华的装置吗？

## 判定：可以，但装置必须拥有非常明确的视觉身份

S06与S08之间隔了数场。

观众无需记住“美术别馆东侧半室外连廊”这个地理名词。

他们只需要认出：

> **就是刚才万理华不肯撤的那个东西。**

### 风险

如果装置只是一些普通展板 / 桌椅，S08观众不会自动产生“啊，是那个”。

### V0.2建议

装置必须拥有一眼可识别的形状或材质语言，例如：

- 有明显的半透明悬挂结构；
- 必须穿过的一组狭长框架；
- 某个侵入通道边界的独特结构。

S06不解释它以后会挡路。

但摄影要建立它与“通行”之间的身体关系：

> 观众正在穿过它。

到了S08，大型布景停住，远处再次出现同一结构。

不用台词。

因果自然完成。

# 五、压力项4｜S10通知纸是否“轻到能忘，重到二刷认出来”？

## 判定：方向正确，但需要一个持续存在的普通学生面孔

如果S10只是“一名学生干部”突然出现，到了S20再次摸出口袋，第一次观看会完全不认识这个人。

二刷也未必能建立联系。

### V0.2建议

把她固定为：

> **执行委员A｜普通学生，无独立人物弧。**

她可以从S02总控点背景里就存在。

S10她拿着通知纸离开。

S20她回来摸到纸。

不命名，不给人物戏，但让脸与岗位连续。

### 通知纸本身

第一次不能做悬疑式大特写。

但可以让观众短暂看见它是一张明显的“集合时间变更”小纸张。

第二次同样的折法 / 纸张从口袋出现。

理想效果：

第一次：

> “哦，她有张纸。”

第二次：

> “啊！”

忘了也完全不影响剧情。

# 六、压力项5｜S14—S16“三连：钟 / 路 / 人”会不会太刻意？

## 判定：会。这是当前Scene List最需要修改的表现问题之一。

Scene List写成三个独立节点非常清楚：

- S14：钟；
- S15：路；
- S16：人。

但如果成片真的连续：

> 墙钟特写 → 布景卡住 → 点人数“少三个”

会有一种编剧拿荧光笔对观众说：

> “各位，现在三条线同时危险了哦。”

这正是我们一直想避免的“结构被看见”。

### V0.2建议

把S14—S16合成一段约45—75秒的**自然交叉升级序列**。

例如：

- 礼堂工作人员从墙钟下经过，顺手确认时间；
- 声音桥切到西侧：“右边没位置！”；
- 回礼堂有人开始点位；
- 镜头不为墙钟单独停留；
- 最后一句“少三个”才真正结束这段。

观众会自然感到三件事同时变坏，而不是被教会“三条明线”。

# 七、压力项6｜S21未央奈是否仍然抢节奏？

## 判定：时长已经合适，但真夏不应该亲自进入这一场

V0.1已经把未央奈大幅压缩，这是正确的。

但S21仍设计：真夏若经过，会本能问“哪里不舒服？”

这会产生两个问题：

1. 又把真夏变成“所有问题最终都来到她面前”；
2. 给未央奈的场景增加主角认证感。

### V0.2建议

**真夏完全不要进入S21。**

处理应留给局部现场：

工作人员 / 普通学生先问：

> “不舒服吗？”

未央奈：

> “不是……我就是上不了了。”

高山：

> “好，那不上。”

南递糖。

结束。

真夏最多在之后收到一句极短状态：

> “一年级有一个不上了。”

她不去处理人。

这会更准确地体现EP05的成长方向：

> **不是每个问题都需要进入真夏的系统。**

同时也让未央奈真正拥有普通学生的尺度。

# 八、压力项7｜未央奈到底承担多重要的舞台位置？

## 判定：需要现在锁一个“重要但不抢戏”的位置

如果她只是合唱30人中的一人：

> 她不上也完全可以继续。

那“我上不了了”对系统没有任何压力，只剩人物小插曲。

但如果她是唯一开场独唱：

> 她又会变成整个最终舞台的关键人物，过于抢戏。

### 推荐定位

> **一年级三人起句 / 三人小组中的一人。**

也就是说：

- 她不上，节目不是不能演；
- 但开场声音与站位需要临时重排；
- 对后台来说确实是一个需要处理的新变量；
- 对观众来说，她仍然只是普通一年级成员之一。

这是“工具人功能”和“角色尊严”最平衡的位置。

# 九、压力项8｜S23真夏放下夹板的时机是否正确？

## 判定：时机正确，但现在的“这是谁写的？！”笑点应该前移

约40分钟进入“总控表死亡”是合理的。

前面已经有足够时间证明：

- 真夏能处理；
- 她不断修改；
- 修改开始制造新的条件；
- 人们逐渐自行行动；
- 纸面终于跟不上现场。

问题在于S23目前还有：

> 看到まあ亚的无关记号。
>
> “这是谁写的？！”

这个笑点本身很好。

但如果它紧贴“放下夹板”这个真正人物转折，会稍微削弱动作重量。

### V0.2建议

把“まあ亚在表上乱写 / 真夏崩溃”的笑点提前到S19附近。

到了S23：

真夏只低头看表。

看一会。

不说话。

有人叫：

> “真夏！”

她把夹板放下。

> “走。”

越简单越强。

# 十、压力项9｜S24“跑向旧礼堂”会不会太英雄化？

## 判定：空间节点非常好，但不能拍成主角冲锋

S24是整集空间结构最重要的转换之一：

> 从整个校园 → 旧礼堂。

必须保留。

但如果配激昂音乐、真夏一个人奔跑，会突然变成体育电影 / 救灾片。

### V0.2建议

真夏是**快速走 / 小跑**，但镜头重点不是她的英雄速度，而是她沿途看到：

- 人正在往旧礼堂汇聚；
- 器材往同一个方向移动；
- 松村带着人从另一侧经过；
- 普通学生在给来宾指路；
- 每个人已经在做事。

S24真正应该让真夏第一次身体上感受到：

> **学校并不是从总控桌向外运行。它此刻正在自己朝同一个地方流动。**

# 十一、压力项10｜S25—S29后台空间真的可拍吗？

## 判定：三层分区正确，但需要更严格控制人数

现有Z1 / Z2 / Z3是正确方向。

### 建议进一步锁定

#### Z1｜前台 / 侧台

- 生田；
- 松下；
- 中元；
- 最终合唱 / 一年级舞台成员；
- 舞台监督。

#### Z2｜后台主通道

- 真夏；
- 樱井；
- 若月；
- 松村；
- 生驹；
- まあ亚；
- 少量实际搬运人员。

#### Z3｜小等候角

- 高山；
- 南；
- 未央奈。

### 其他主要人物

不欠出场：

- 西野 / 万理华在S17完成任务后可以不再回来；
- 白石只从前台经过侧台完成一次转换；
- 飞鸟只有一个短动作；
- 桥本只需要在关键时刻出现一次现实判断 / 手势；
- 深川、卫藤等完全可以不进入高潮中心。

### 硬规则

> **一张后台宽镜中，具有台词 / 任务的主要角色最好不超过6—8人。**

否则群像不是丰富，而是视觉噪音。

# 十二、压力项11｜桥本为什么会突然出现在S19 / S26？

## 判定：目前略有“需要现实判断，所以召唤桥本”的工具感

桥本说“差不多”“如果后面一个问题都不出”非常像她。

问题不是对白，而是：

> 她为什么此刻自然在这里？

### V0.2建议

给桥本一个非常轻的、无需发展成剧情的当天任务：

> **最终舞台后台资料 / 人员表 / 图书文化展示结束后的支援岗位**

更推荐直接与最终舞台有关：

她负责一份后台人员 / 进出确认资料，或临时协助旧礼堂一侧的进度确认。

因此：

- S19她从礼堂回来，顺手看真夏的表；
- S26她本来就在侧台附近；
- 最后可以用手势给出“还有一点窗口”。

这样她不是“被编剧召唤来当现实人”。

她只是刚好在自己的工作位置上。

# 十三、压力项12｜真夏“先别管时间，等我信号”之后，信号到底怎么给？

## 判定：对白已锁得很好，但空间视线必须成立

这是正式分场前必须解决的舞台blocking问题。

如果生田坐在舞台前沿，而真夏在完全看不见的后台：

> “等我信号”没有意义。

### V0.2舞台锁定建议

旧礼堂舞台采用传统镜框式舞台逻辑，并保留一个可使用的**台口 / apron区域**。

- 钢琴放在台口偏侧；
- 生田从座位可以看到侧台翼口；
- 真夏 / 舞台监督可在翼口进入她的视线；
- 后方完整合唱区域由主幕 / 后幕 / 灯光隐藏；
- 真夏最终信号可以是一个清楚但不戏剧化的点头 / 手势；
- 松下同时进入准备位置。

于是：

> “等我信号”

在物理上真实成立。

# 十四、压力项13｜生田即兴时，观众为什么不会觉得“节目事故了”？

## 判定：需要舞台管理上的一层包装

如果观众刚坐好，幕布一直关着，突然一个学生在台前无限弹琴，现实中未必所有人都会自然认为这是节目。

### V0.2建议

让这段看起来像**原本就存在的钢琴Prelude / 入场前奏**。

即：

- 最终舞台本来就有生田的钢琴开场；
- 原计划时长较短；
- 真夏临时把它提前、拉长；
- 礼堂灯光进入演出状态；
- 观众自然认为正式节目已经开始。

这样不是“临时编一个节目骗观众”，而是：

> **把原节目中本来存在的一段，变成一个可以伸缩的开场。**

这是最可信的方案。

# 十五、压力项14｜S30—S32无对白高潮，观众看得懂吗？

## 判定：能，但不要变成“符号特写大礼包”

目前设计有：

- 钟；
- 路；
- 空位；
- 锁扣；
- 鞋；
- 手；
- 乐谱；
- 裙摆。

单个都有效。

如果全部依次特写，会再次出现“编剧在总结三条线”的感觉。

### V0.2建议

最后两分钟主要追**行动连续性**，三个复位器只自然嵌入：

- 一辆刚才卡住的推车终于从画面后方顺畅通过；
- 某人回到原本空着的位置，镜头并不特写“空位”；
- 墙钟只在真夏抬眼时进入构图一次。

之后真正重要的视觉链应是：

> 人到位 → 松下准备 → 真夏确认 → 信号 → 生田听见 / 看见 → 音乐找到入口 → 呼吸 → 幕布开。

只要这一链清楚，观众完全能够理解。

# 十六、压力项15｜真夏的人物变化是否被“放下夹板”一场包办？

## 判定：需要在高潮再给一个极小行为验证

S23放下夹板是认知转折。

但人物弧最好不是：

> 放下纸 = 突然学会一切。

### V0.2建议

在S28人物自动运转蒙太奇里加入一个非常小的真夏动作：

她看到一个局部问题，本能准备开口：

> “那边——”

但まあ亚 / 若月 / 生驹已经自己把它解决了。

真夏停住。

不说。

转去看下一个真正需要跨系统判断的地方。

这一下比任何成长台词都重要。

它证明：

> **她开始允许系统里的人自己成为系统。**

而且仍然没有提前完成EP11的“我可以离开”。

# 十七、压力项16｜文化祭会不会从校园喜剧过早变成物流惊悚片？

## 判定：存在轻微风险

从S08以后，连续因果开始变紧。

如果音乐、剪辑、演员都马上进入“出大事了”，整集会在20分钟左右过早失去文化祭的快乐。

### V0.2节奏规则

- S08布景过不去：仍然可以好笑；
- S09真夏改道：干净、利落；
- S10通知纸：普通；
- S11—S13：文化祭环境音仍然热闹；
- 真正危机音乐 / 剪辑速度提升，最好到S14—S16合并序列后才开始。

这样节奏是：

> **好玩 → 有点麻烦 → 麻烦开始相互认识 → 糟了。**

而不是：

> **文化祭开始十几分钟就进入灾难片。**

# 十八、压力项17｜TAG是否拖尾？

## 判定：内容好，建议控制约30—45秒

高潮已经在幕布打开时完成。

TAG只能负责：

- 放掉压力；
- 回到人物日常；
- 留下飞鸟小册子的长期行为线；
- 确认“文化祭成功，计划失败”。

### 建议

松村与真夏只保留最短交换：

> “结果不是挺好的吗？”
>
> “哪里好？”
>
> “演完了啊。”

飞鸟报时间。

真夏禁止她再报。

飞鸟回来拿小册子。

结束。

不要让真夏开始完整列举“开场视频、第三段、外校……”的损失。

损失观众已经看见。

# 十九、建议进入Scene List V0.2的修改清单

1. Scene List继续保留逻辑编号，但实际观看单元从33场压到约22—26个连续场景 / 序列感。
2. 合并S14—S16，不再逐条展示“钟 / 路 / 人”。
3. S03与S27使用轻微视觉构图回声：前者真夏看时间，后者真夏看现场。

# 二十、最终结论

Scene List V0.1 的核心机械结构已经足够稳定。

这一轮压力测试没有发现需要推翻的故事问题。

真正需要做的是最后一次“去编剧痕迹”：

> **观众可以感受到结构，但不能看见结构在向他们解释自己。**

V0.2 应该比V0.1更少“场”，但并不少发生事情；

更少解释，但更容易看懂；

更少人物逐个展示功能，但更像一整所学校真的在同时运转。

当这一版完成以后，EP05就可以从结构开发阶段正式进入：

> **Detailed Scene Treatment / 分场稿 V0.1**

也就是第一次开始写每场真正发生的动作、节奏、转场、对白骨架与镜头重点。
