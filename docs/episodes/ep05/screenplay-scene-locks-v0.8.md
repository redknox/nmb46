# S21｜LOCKED｜两个信号

锁定动作顺序：

1. 生田继续弹当前自由延展；
2. 一个乐句收住，生田抬眼看见幕侧真夏；
3. 真夏给生田第一个视觉信号；
4. 生田极轻点头，手不停；
5. 真夏确认收到后立刻转向另一侧；
6. 真夏给松下第二个视觉信号；
7. 松下收到；
8. 真夏不再参与音乐判断，转去看幕侧现场；
9. 生田在音乐内部把自由和声逐渐收回正式和声；
10. 松下自己听；
11. 正式开头回来；
12. 松下抬手收住合唱团身体；
13. 松下再听半拍；
14. 松下给拉幕侧示意；
15. 主幕开始升起。

## Cue唯一性｜LOCKED

- 真夏 → 生田：只表示S15约定的**回正式曲目**；
- 真夏 → 松下：只完成**后台运营Ready交接**；
- 松下收到以后仍然自己听音乐，自己决定升幕；
- 不增加`准备好了 / 可以开始 / 回去吧`等对白。

## 镜头空间｜LOCKED NOTE

两个信号靠**接收者 + 视线方向 + 真夏的转身**区分，不靠设计两套夸张手势。

# S22｜LOCKED｜一条线的裙摆

锁定高潮顺序：

> 生田回正式音乐 → 松下听见 → 松下cue升幕 → 鞋 → 一条线裙摆 → 紫色领巾 → 最高一级完整后排 → 最前方唯一一年级色未央奈 → 松下cue → 未央奈第一声 → 最后一个音交出去 → 高三合唱进入 → 未央奈退回原走位。

锁定原则：

- 幕升前不切观众成功反应；
- 未央奈第一声之前不以掌声、笑容或真夏反应替观众宣布成功；
- `最高一级为什么必须装回来`继续只由真实后排站位回答；
- 未央奈唱出上午同一段开头，不增加`声音回来了`式主题说明。

## TAG原则｜LOCKED

- 不说`刚才不是才装好吗`；
- 不说`刚才那么重要现在又没用了`；
- 不用慢镜头、台词或角色反应替观众总结余韵；
- まあ亚此处只是继续做事，不再解题；
- 正常预定换场是单向strike，约10分钟量级；事故中的约40分钟包含整拆、让主景通过、重新搭回与复检，两者不冲突；正片不解释这个差别；
- 删除旧版合唱台模块`今天放右边`的物流梗，右侧明确留给下一项讲台。
