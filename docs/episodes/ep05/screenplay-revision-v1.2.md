# 修正说明

## 删除

删除 V1.1 / Scene Locks V0.8 中：

> **若月**  
> 最上面先下来。

以及“先撤最高一级、再继续撤其余台阶”的动作顺序。

## 新锁定顺序

> **合唱成员离开台阶 → 下层/前侧先拆 → 第二层 → 最高一级最后拆 → 台阶区完全清开 → 讲台从右侧完整进入。**

理由不是为了剧情，而是现场操作本身必须成立：

- 先清低处与前侧，给搬运者建立可站立、可转身、可接模块的工作空间；
- 避免在下层结构和操作空间仍拥挤时直接处理高处模块；
- 每一级都在对应下方/前方空间清开后再撤，动作关系更安全、更容易让观众相信。

## TAG余韵的处理

不再为了强调“刚装回又拆”而让最高一级第一个离场。

改为：

> 观众先看见合唱台按正常顺序一层层消失；**最后才轮到那块刚才费力重新装回、演出时真正站满后排的最高一级。**

角色不对此发表评论。

这比不安全地让它第一个被拆，更符合本集原则：

> 所有人只是继续做下一件正确的事；意义留给观众自己感受。
