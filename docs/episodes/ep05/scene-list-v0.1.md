# EP05《文化祭》｜Scene List V0.1

> 本文件将 `beat-sheet-v0.2.md` 翻译成真正可进入剧本阶段的分场表。
>
> 本版仍不是完整剧本，不追求对白定稿。每场只要求明确五件事：
>
> 1. **我们在哪里？**
> 2. **谁自然会在这里？**
> 3. **这一场开始时，局面是什么？**
> 4. **观众这一场只需要知道什么？**
> 5. **离开这一场时，什么发生了不可逆的小变化？**

暂按约50分钟正片、32场左右设计。

核心观众明线仍只有：

> **钟 / 路 / 人**

核心人物主推进：

> **秋元真夏**

完整关系推进：

> **伊藤万理华 → 西野七濑（B向A凝结）**

其余人物原则上只按照行为引擎自然行动，不争抢人物弧。

# ACT 1｜文化祭真的运转起来了

## S01｜EXT. 正门—樱花步道—中庭｜上午

### 人物

学生群像、来宾、家长、外校学生、白石、松村、生驹、高山、若干一年级生；堀未央奈只作为一年级群体中的一张熟脸。

### 场景进入状态

文化祭正式开放。

前几集所有准备第一次完整进入“实际使用”。

### 观众只需要知道

> **今天首先是一场很好看的文化祭。**

### 场景动作

- 校门接待顺畅；
- 白石自然成为来宾视线焦点；
- 松村从一个圈层滑进另一个圈层；
- 高山在一个小摊位临时接住气氛；
- 一年级生兴奋地进入自己的第一个文化祭；
- 远景里能看到此前已经铺过的隔壁学校大型舞台布景。

### 场景退出状态

观众先相信乃木坂女学院的秩序与漂亮。

## 真夏

贯穿，但前半段尽量固定在总控点。

她只处理跨系统约束。

真正人物转折：S23放下夹板。

真正新行为：S26“先别管时间，等我信号。”

## 生田

S03制造“钟”的第一处偏差。

S27—S31成为高潮弹性时间。

她在本集不是再次成长，而是在兑现EP04已经获得的能力。

## 万理华 / 西野

只有S06铺设、S17关键动作。

关系推进不获得额外总结场。

## 堀未央奈

- S01：群体熟脸；
- S05 / S11 / S13：边缘等待；
- S21：唯一完整镜头；
- S29：极短自主回归。

## 樱井

主要在S02 / S07 / S28出现。

功能是正式协调和局部决定，不与真夏争运营中枢，也不提前完成EP10。

前半集承担“文化祭对外的脸”。

高潮只需要完成台前→幕后瞬间切换，不做重搬运。

信息网络贯穿，但不拥有成长弧。

她既让信息混乱更像真实学校，也在后半段成为自然寻人器。

## 飞鸟

只需少量动作和尾声。

绝不在EP05消费“为什么 / 不知道”母题。

# 下一步建议｜Scene List Stress Test V0.1

进入正式分场稿前，建议最后做一轮针对 Scene List 本身的压力测试：

1. 33场是否过碎；
2. 哪些 montage 应合并成真正连续调度；
3. S03 生田sound check 与最终S27钢琴是否形成足够清楚的视觉回声；
4. S06→S08之间观众是否能记住万理华装置的位置；
5. S10通知纸是否“轻到能忘，但重到二刷认出来”；
6. S14—S16三连是否太像刻意展示“钟 / 路 / 人”；
7. S21未央奈是否仍然抢节奏；
8. S23真夏放夹板是否来得太晚 / 太早；
9. S24从总控点跑向旧礼堂是否能成为空间收束的强视觉节点；
10. S27钢琴的舞台物理设计是否真正可执行；
11. S30—S32是否能在极少对白下保持观众完全看懂；
12. TAG是否需要控制在30秒左右，避免高潮后拖尾。

目标：

> **不是再让故事更复杂，而是删掉任何让观众感觉“编剧正在解释自己设计”的瞬间。**
