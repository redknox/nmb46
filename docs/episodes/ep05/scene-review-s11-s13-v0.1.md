# S11｜14:30 没有 Done

## 1. 人物行为引擎｜GREEN

### 真夏

成立。

14:14她得到的是`五分钟左右`，因此继续留在总控；14:26变成`说不好`，她提高报告频率；14:30终于得到`……不知道`，才放下红笔去现场。

她到现场后的第一反应仍然是检查系统接口：合唱、设备、路线、景片支撑、合唱台恢复时间。

重要的是，她没有一到现场就“接管一切”。她发现：

- 合唱已经被挡在外面；
- 设备已经暂停；
- 支撑没有被乱拆；
- 完整合唱台也没有被冲动返工。

所以她只接受现实并继续问下一项。

`嗯。`足够，不需要“你们已经处理得很好”之类评价。

### 若月

成立。

她仍然只负责：

- 已确认路线情况；
- 安全边界；
- 是否可以再试；
- 控制搬运速度。

关于景片支撑能否拆、合唱台恢复多久，都由舞台学生给技术事实。

### 舞台学生

成立。

`要让开的话，得全拆。`与`四十分钟左右。装回来以后还得重新确认。`都是专业接口信息，不是角色替编剧炫耀知识。

## 2. 日式关系对白｜GREEN

真夏与若月、现场学生属于本校内部执行关系，因此句子可以直接，不需要每句礼貌缓冲。

本轮将：

> `全部？`

删除。

真夏真正需要的不是再确认“全拆”这个名词，而是运营数字，因此直接问：

> `多久能恢复？`

更符合她的职位语言，也减少观众说明感。

`那不动。`是内部现场决策，可以保持直接。

## 3. 作者解释减法｜GREEN

删除/不再继承：

- `看到的不是混乱。`
- `人都在做自己的事。`之后的任何价值判断解释；
- 老版本完整描写`下方通过 / 中段通过 / 上部停住`。

现场秩序直接由谱架靠墙、三层台完整、景片安全停放、人员继续工作来表现。

最后一次失败尝试缩成：

> 起 → 转 → 停 → 退。

## 4. 观众视角｜GREEN

观众已经在S07看着合唱台从13:30搭到13:54完成，因此S11听到：

> `四十分钟左右。装回来以后还得重新确认。`

会自然理解这是“全拆、主景通过、精确复原与复检”的应急总时间，不需要角色再解释搭台花了多久。

`40分钟`在事故链中只明确出现一次，不产生重复说明。

# S12｜原计划还没有死

## 1. 人物行为引擎｜GREEN

真夏在14:34仍然问：

> `如果现在出去，后面还要多少？`

成立。她不是乐观主义，而是在持续尝试把偏差重新装回可估时流程。

得到：

> `设备归位，再做最后确认。`
> `十分钟？`
> `顺利的话。`

以后，她仍认为如果景片立刻出去，正式开演可能被保住。

14:40她做出的不是“舞台Ready”决定，而是把前台观众流与后台施工暂时解耦：先落幕、照原定开门、里面继续。

这与她从“看表”逐渐变成“读现场”的行为弧一致，但不需要任何人说明这一点。

### 松村

成立。

她带来的信息不是解决方案，只是：

> `刚才有人跟我说，好像快出去了。`

随后眼前现实立刻证明这条信息已经过期。

她自己补：

> `……刚才是这么说的。`

真夏：

> `我知道。`

没有责怪，也没有把松村写成错误传播者。

### まあ亚

成立。

14:38—14:39只看：

- 景片退回后留下的空地；
- 景片一端；
- 出口；
- 清开的横向空间。

还没有答案。

## 2. 日式关系对白｜GREEN after one key revision

旧版：

> `四十分呢？`

存在双重问题：

1. 中文听觉上容易与三分钟前刚出现的`四十分钟左右`混淆；
2. 过度依赖编剧知道这里的“四十分”是14:40这个分钟点。

改为：

> **真夏：** `开门前能出去吗？`
> **若月：** `……再给我一点。`

双方是熟悉的同级执行者，句子可以直接；同时观众刚刚听见前厅问“14:40是否照原定开门”，上下文自然闭合。

前厅学生的：

> `两点四十，还是照原定开门吗？`

保留正式确认感。

14:40真夏改为：

> `幕先落下来。`
> `照原定开门。`
> `嗯。里面继续做。前面照常。`

比`前面不要等`更像内部接口调整，而不是向观众解释“前台不用等后台”。

## 3. 作者解释减法｜GREEN

删除：

- `真夏仍然相信：如果景片很快出去，原计划还有机会。`
- `14:35原定的开场位置确认没有发生。`
- まあ亚观察时任何“她是在研究路线”的解释。

这些都由下一步行动证明。

## 4. 观众视角｜GREEN

14:35未央奈段落已经足够让第一次观看者理解：

- 她提前站起来；
- 联系学生说旧礼堂还没准备好；
- 松下确认`舞台还不能进？`；
- 松下让她`先等一下`。

观众无需知道专业术语，只会自然理解：她原本现在要去完成那件下午开场准备，但没做成。

14:40开门同样成立：主幕把后台遮住，钢琴已经在幕前，前厅正常排队，因此“照原定开门”是可见的空间判断。

# S13｜开门以后

## 1. 人物行为引擎｜GREEN

### 松下

14:41再来确认一次现场；14:44仍未恢复，于是回到成熟的原始开场版本。

他不是为了安慰或打击未央奈，而是在做合唱指挥的专业取舍。

`开头回原来的版本。` → `开头改了。今天先不用。`

足够。

### 未央奈

`……是。`之后站一秒再坐下，成立。

她后来对高山说：

> `对不起。`
> `我上不了了。`

保留。

这里的`对不起`是低年级面对高年级前辈时的关系润滑，不是理性承认事故责任。

### 高山

`嗯？`先拆掉未央奈的“我给大家添麻烦了”前提。

随后：

> `啊。`
> `那就不上了。`

再继续找水。

完全符合她把过重气氛重新放回日常大小的方式。不能加安慰台词。

### 星野南

分糖本来就已经在进行，只是自然轮到未央奈。

成立，不构成“专门治愈新人”的剧情动作。

## 2. 日式关系对白｜GREEN

松下对学生、未央奈对前辈、高山对后辈、南对周围人的语言距离均成立。

没有必要再润色成更“日系”的翻译腔。

## 3. 作者解释减法｜GREEN

删除：

- `没有延迟广播。`
- `没有道歉。`
- `14:35特殊开场位置确认已经没有发生。`
- 段尾`结束。`

正片只需要让观众看到：观众按原定时间进场，主幕落着；14:44松下自己改回原开头。

## 4. 观众视角｜GREEN

未央奈被拿下的A类信息已经完整：

- 上午她是特殊开场第一声；
- 午间明确说下午还要再确认；
- 14:35确认没做成；
- 14:40观众已经入场；
- 14:44松下回到原版本。

不需要补一句`因为没有确认，所以今天先不用`。

高山与南的后续则属于感受，不承担因果说明。

# 本组结论

S11—S13：**四项审查全部通过，可锁。**

本轮最重要的减法：

> 观众已经经历过的事实，不再由人物复述；编剧知道的流程节点，不再写成屏幕上的解释句。

本轮最重要的对白修正：

> `四十分呢？` → `开门前能出去吗？`

避免“14:40分钟点”与“40分钟工时”在听觉上打架。

本轮不改变：

- 14:30 `……不知道`；
- 40分钟只明确出现一次；
- 14:40照原定开门；
- 松村信息过期；
- 未央奈14:35失败、14:44被拿下；
- 高山`那就不上了。`；
- 南自然分糖。
