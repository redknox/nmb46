# EP05《文化祭》｜Performance / Camera-Space Review V0.1

> 审查对象：S02—S23当前全部scene locks，含 `screenplay-scene-locks-v1.0.md` 的整集节奏修正。
>
> 审查目标：不再修改剧情因果和对白，而检查**表演、调度、空间轴线、视线、声音与剪辑**是否会让已经成立的故事在拍摄时失效。
>
> 结论：**无剧本级RED。** 当前剧情可以拍懂；但有6项必须作为拍摄硬要求保留的YELLOW。它们都不需要补对白。

---

# 一、旧礼堂空间必须先让观众“住进去”｜YELLOW / HARD REQUIREMENT

事故线能不能成立，取决于观众是否一直知道以下几个东西大概在哪里：

- 主舞台；
- 后部主景；
- 合唱台；
- 主景原定出口；
- 后来清出来的横向空位；
- 主幕线；
- 幕前钢琴；
- 左右后台通道。

如果S07—S16主要由手、脚、连接件、人物脸部特写组成，观众会知道“他们很忙”，但不知道“为什么过不去 / 为什么双转能过”。

## 锁定要求

旧礼堂在S07正常换台阶段就要建立一到两个可重复使用的**空间母镜头 / 主轴方向**。

后续事故不要随场景不断翻轴。

尤其需要让观众形成稳定关系：

> 主景在这里 → 出口在那里 → 合唱台占了这块空间 → 横向空位后来被清出来。

镜头不需要像建筑图一样解释，但空间方向必须始终可追踪。

## 禁止

- 为了制造紧张大量手持晃动；
- 连续切特写让景片“凭剪辑移动”；
- S14突然换一个此前没见过的机位，导致双转像从另一个空间凭空成立。

事故不是混乱灾难，而是**一个非常具体、非常固执的物理问题**。

# 二、S14双转必须用“同一空间里的不同动作”拍懂｜YELLOW / HARD REQUIREMENT

这是全集最依赖镜头空间的一处。

观众需要真正看懂的不是几何术语，而是：

> **之前：大家一直想一把转完。**
>
> **现在：转一次 → 横着送进去 → 换另一端再转一次。**

## 最低拍摄条件

### A｜旧单转

S14开场那次失败旧单转，必须至少有一个中/全景让观众看到：

- 景片从原位开始；
- 它试图持续旋转；
- 合唱台进入它的扫掠空间；
- 停；
- 退。

不要只拍“碰近了的角”和人物表情。

### B｜まあ亚提出方案

まあ亚不是工程师式讲解。

她的表演应该是身体性的：

- 站到景片一端；
- 用手比“先到这里”；
- 手不继续转到底；
- 横着挪；
- 换到另一端；
- `再转一次呢？`

语气可以带一点“这样不行吗”的自然试探，不要演成发现数学定理。

### C｜模拟验证

`第一转 → 横移 → 第二转`尽量保持可比较空间，不要用蒙太奇把三步拆散。

观众必须亲眼看到：

> 下层没碰 → 中层没碰 → 只有最高一级仍然挡。

这是40分钟第一次变成10分钟的视觉证据。

# 三、S16真正通过要比S14更快，但轴线必须一致｜GREEN + LOCK NOTE

S14负责“看懂”。

S16负责“兑现”。

因此S16不能再完整教学一次双转。

建议节奏：

> 第一转 → 停一下 → 横移 → 停一下 → 第二转 → 上部斜撑扫过空出来的位置 → `……过了`。

可以比S14明显更短、更有连续性。

但**不能为了加速换一套完全不同的剪辑轴线**。

观众的满足来自：

> 我刚才学会了这个动作，现在我认得它真的成功了。

不是来自快切。

若月的 `先别松` 要落在“大家刚以为终于过了”的瞬间，但表演保持工作语气，不做英雄式喝止。

# 四、S15—S21的视线系统必须物理成立｜YELLOW / HARD REQUIREMENT

这一段后半高潮依赖大量无对白交接，所以**视线不是装饰，是剧情接口。**

## 1. 钢琴位置

S07钢琴固定到幕前时，除了“在主幕前”，还必须确保生田坐下后能够自然地、只用一次抬眼看见指定幕侧位置。

不能到S21才发现她必须大幅扭头、回身才能看到真夏。

钢琴朝向和真夏站位应在场景设计阶段就确认。

## 2. 真夏的交接点

S20末端真夏取得的站位必须同时满足：

- 向一个方向能看到幕前生田；
- 转身 / 换视线以后能看到主幕后松下；
- 自己不挡通道、不挡拉幕工作。

这样S21的两个cue才是真正的现场交接，而不是剪辑制造的“神奇视线”。

## 3. 双cue拍法

第一个cue：

> 生田抬眼 → 看见真夏 → 真夏小信号 → 生田轻点头，手不停。

随后必须让观众**看见真夏完成一次明确的转身 / 换视线方向**。

第二个cue再落到松下。

两个cue不需要不同手势。

区别必须来自：

> **不同接收者 + 不同空间方向 + 真夏真实转身。**

若剪成两个孤立手势特写，这条因果会坏。

# 五、S19—S20未央奈恢复必须是一条连续动作链｜YELLOW / HARD REQUIREMENT

这一段已经没有解释对白，所以剪辑一旦打断，观众会重新产生：

> “她刚才不是被取消了吗，怎么突然又上了？”

## 必须让观众连续看见

> 松下到场 → 三层台阶已可用 → 若月完成工作后退开 → 中元数完人 → 队伍站齐 → 松下看到空mark → 看到侧边未央奈 → `堀。原来的位置。` → 未央奈回mark → 松下到指挥位 → 起手cue → 未央奈吸气但不唱 → 松下确认。

可以有必要切换，但这一段不要插入：

- 观众席反应；
- 真夏欣慰表情；
- 生田漂亮弹琴特写；
- 高山看未央奈回来；
- 任何“大家注意到她恢复了”的镜头。

恢复不是情绪奖励，而是**条件重新成立以后，工作岗位重新成立。**

## 未央奈表演

`原来的位置`后不要演“惊喜”。

停半拍更接近：

> 她需要确认自己有没有听错，然后马上执行。

回mark不跑。

她低头看mark，但**不碰领巾**。

这里不要给“手没有抬起来”的特写；缺席动作必须留在正常中景里自然发生，否则会变成导演替观众划重点。

# 六、S22幕升是视觉高潮，不要用反应镜头帮助它｜YELLOW / HARD REQUIREMENT

这一段的成立方式已经非常明确：

> 正式音乐回来 → 松下决定升幕 → 鞋 → 裙摆一条线 → 紫色领巾 → 后排完整站位 → 唯一一年级色 → 未央奈第一声 → 高三进入。

## 镜头核心

主幕真正升起时，建议从观众侧 / 正面保持一个能够让“从下往上揭示”成立的构图。

不要一开始就切到脸。

让幕本身完成揭示：

1. 鞋；
2. 裙摆；
3. 一条整齐横线；
4. 紫色；
5. 人群结构；
6. 最前方未央奈不同颜色。

最高一级的整排人必须在这个正式画面里真实存在，作为此前复原工作的视觉回收。

## 声音硬要求

未央奈唱出第一声之前：

- 不给观众笑声 / 掌声；
- 不用额外配乐告诉观众“成功了”；
- 不用角色吸气式松懈反应替观众下结论。

此时最重要的声音关系是：

> 生田正式和声 → 幕机械声 / 极轻舞台环境 → 松下cue → 未央奈呼吸 → **第一声人声。**

第一声之后，高三合唱才真正把画面填满。

# 七、S22真夏“改从右边进”不能拍成伏笔回收题｜GREEN + LOCK NOTE

真夏接到下一项流程纸后，只很短地看左侧一次。

左墙工具箱最好已经存在于她所在空间的正常景深 / 环境里。

不要：

- CUT TO 工具箱特写；
- rack focus从真夏眼睛拉到工具箱；
- 低年级学生顺着她视线看；
- 任何“原来如此”的表情。

她只是读现场，然后：

> `结束后，改从右边进。`

这一笔的价值恰恰在于它没有被拍成价值。

---

# 八、S23 TAG应与S18—S22形成“同一个舞台”的反向变化｜GREEN + LOCK NOTE

TAG最好的余味不是给最高一级一个纪念镜头，而是让观众继续认得同一个空间。

演出时：

> 三层站满 → 最高一级是一整排高三 → 完整画面成立。

幕落后：

> 人离开 → 下层先撤 → 第二层撤 → 最高一级最后撤 → 右侧讲台进来。

## 建议

尽量保留一个可以反复回到的较宽舞台后区构图，让观众看着完整结构逐层变少。

最高一级最后离开时：

- 不慢动作；
- 不切未央奈 / まあ亚 / 真夏反应；
- 不给音乐提示“这一刻很有意义”。

它就是被抬走。

随后讲台进入同一空间。

这才是TAG真正的笑和伤感：

> 角色没有停下来理解刚才发生了什么，学校已经进入下一项。

该理解不进入正片台词。

# 九、人物表演纪律｜GREEN / GLOBAL

## 真夏

前半集不要演成焦虑型总控。

S03的力量来自她**没事可做**：别人跑，她坐着等；时间到，人来，勾掉。

14:30以后也不要突然变成“指挥官英雄”。她到现场以后站在不挡人的位置，问正确问题，接受别人已经做完的安全措施。

她真正的变化是读取对象改变：

> 表 → 报告 → 现场 → 人。

演员不需要表现“我成长了”。

## 若月

动作优先于表情。

她的安全感来自：

- 让人先停；
- 确认两边；
- 手挡住提前踩台阶的人；
- 等技术学生确认。

不要把她演成专业工程师，也不要变成不断大声下命令的人。

## まあ亚

S14以前她就是在做实际劳动。

双转发现时不要突然聪明脸、停音乐、全场看她。

她的优势是：**身体先理解物体怎么走。**

S23再回去拆台时，她重新只是一个干活的人。

## 生驹

始终行动比解释快。

别人说可以以后，她马上找人、抬、做。

不用给“热血担当”额外夸张反应。

## 松下

他的决定都是专业判断，不是情绪转向。

14:44拿掉未央奈时不冷酷；15:02叫她回来时也不温柔化。

同一种工作语气，条件不同，决定不同。

## 未央奈

避免把她演成“被选中的小主角”。

她的紧张主要在身体小动作和关系反应里：

- 已经正确还会确认；
- 对前辈先说`对不起`；
- 被叫回时只停半拍；
- 正式第一声按照已经确认过的工作完成。

## 高山 / 南

S13绝对不要演成“我们正在治愈未央奈”。

高山说完`那就不上了`就真的继续找水。

南的糖必须是连续分给一圈人，未央奈只是其中一个。

如果镜头只切一颗糖递给未央奈，这场会从日常经过变成精心安慰。

# 十、早段几个容易被拍“太有意义”的场景｜GREEN / RESTRAINT NOTES

## S04 Fukase

Fukase看见生田离谱面后很轻地笑一下即可。

最好仍处在群体空间里，不做神秘导师式特写、逆光或音乐提示。

松隆子的`正式按谱`也不要配价值判断镜头；她只是做专业老师该做的事。

## S05 万理华 × 西野

两人站到“出口”侧看作品时，镜头重点是**观看位置发生变化**。

不要给作品本身过度漂亮的验证镜头，也不要拍成两人相视一笑。

## S05 小泉 × 白石

保持接待桌的工作空间。

小泉的过去不是庄重揭晓；她说`我那本早就不知道去哪了`应该像真的只是随口想起来。

白石最后盖住自己照片、继续整理册子，不要给手部慢特写做象征收尾。

## S07 飞鸟

箱子挡住半张脸、通道里等半拍、`不好意思，借过一下`。

最好让她把整段路真的走完，不要切成“飞鸟其实很体贴”的人物小品。

# 十一、声音设计总纪律｜GREEN / GLOBAL

本集后半段真正的节奏变化很大程度靠声音，而不是配乐：

> 文化祭环境声 → 搬景 / 金属 / 脚步 → 14:40主幕后主动压低 → 15:00第一声钢琴 → 后台所有动作进入静音模式 → 正式和声回来 → 未央奈第一声 → 高三合唱 → 掌声 → 幕落以后马上回到拆台工作声。

建议不要用额外情绪配乐覆盖这条声音结构。

尤其：

- まあ亚发现双转，不需要“灵光一现”音效；
- 景片通过，不需要成功音乐；
- 未央奈被叫回，不需要温柔配乐；
- TAG最高一级离开，不需要伤感音乐。

本集的情绪应该来自：**工作声音本身不断改变。**

# 最终判定

## 剧本级

**GREEN。无RED。无需解锁对白或重构场次。**

## 拍摄硬YELLOW

1. 旧礼堂空间母轴必须稳定；
2. S14旧单转 / 双转必须在可比较空间里拍懂；
3. S15—S21钢琴、真夏、松下视线必须物理成立；
4. S19—S20未央奈恢复链不能被情绪反应切断；
5. S21双cue必须靠接收者与转身区分；
6. S22幕升必须让鞋→裙摆→紫色→未央奈→第一声自己完成高潮。

## 全局表演原则

> **不要演“这一刻很重要”。让人物把正在做的事做好，重要性由观众自己感到。**

下一步建议：把上述6项硬YELLOW与全局表演纪律整理成独立的 `performance-camera-space-locks-v0.1.md`，作为EP05后续任何分镜 / storyboard / 拍摄设计的硬约束。
