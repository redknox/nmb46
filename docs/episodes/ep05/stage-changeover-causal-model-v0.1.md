# EP05《文化祭》｜舞台转场因果模型 V0.1

> 状态：工作基线。不是逐场锁定文本。
>
> 目的：把 12:30—15:00 旧礼堂从上午联合舞台剧切换到下午合唱最终舞台的真实运营逻辑先跑通，再据此重写 S05 之后的场次。
>
> 核心原则：**不是谁犯了错，而是多个正确决定在同一个物理空间里发生冲突。**

---

## 一、当前主因果

上午旧礼堂上演乃木坂女学院与临校合作的舞台剧。

因此，上午合唱排练不占用旧礼堂，统一改在**音乐与美术别馆的音乐教室 / 合唱排练室**进行。生田第一次尝到 free / 即兴乐趣、Fukase 微笑、松隆子要求正式演出按谱，都发生在音乐教室。这一修正同时意味着：此前 S04 若写成“旧礼堂合唱彩排”，其地点设定由本工作基线 supersede，后续回写 screenplay 时统一迁移。

EP04 Day 1 已使用按当时批准方案制作的实寸确认框，正确验证主景外轮廓、门洞、背部支撑以及撤景与合唱台并行的路线。正式景片随后继续在榊陵制作；考虑到作品将在乃校与榊陵进行两次公演、需要反复运输并在不同礼堂独立站立，制作后期正常加强了背部 / 上部支撑。景片正面宽高与确认框一致，但实际运输扫掠包络小幅增大。

因此：

> **舞台尺寸没有错，但运输包络发生了变化。**

这不是制作失误，也不是测量失误。新版景片在舞台上完全正确，只有到了撤台、转向、穿过侧台与后台通道时，额外的厚度才改变了它需要的转向空间。

下午合唱舞台的原计划采用并行转场：舞台剧组从已经释放的区域开始拆景，合唱组同时从另一侧搭合唱台、摆设备。按旧景片的搬运条件，这套计划可以成立。

真正的问题发生在最后一块大型景片：等它被拆下来准备运出时，合唱台已经按计划搭到相应区域。新版景片因为背部更厚，无法像旧版一样利用原本预留的转向空间通过。

景片组没有迟到。

合唱组没有提前。

合唱台没有搭错地方。

重做景片也没有尺寸错误。

**所有人都在按照正确计划工作，但最后一块景片出不去了。**

## 二、旧礼堂的舞台空间假设

本模型暂时采用以下舞台结构，后续可再画平面图确认：

- 旧礼堂为传统镜框式舞台；
- 主幕之后为正式舞台区；
- 舞台左右有有限侧台空间；
- 大型布景主要从一侧后台 / 装卸通道撤出；
- 最后一块大景片需要在侧台先完成一次转向，才能进入后台出口；
- 合唱台为若干模块化台阶，13:30 起从已经释放的舞台区域逐步安装；
- 按旧景片厚度，即使合唱台已经安装到计划进度，大景片仍有足够的转向余量；
- 新景片背部支撑更厚，导致转向时的实际扫掠范围扩大，最后差一点无法通过。

关键不是“门明显太窄”，而是：

> **原本存在余量，现在余量消失了。**

所以问题直到真正搬运时才暴露。

### 钢琴位置

上午合唱排练使用的是**音乐教室的排练钢琴**，不是旧礼堂下午正式演出的那一架。

旧礼堂另有正式演出用的 house grand / 舞台三角钢琴。13:30 changeover 开始后，它优先被移到主幕线前方的浅前台 / apron 位置并固定，之后不再参与主幕后方的撤装冲突。

因此最终高潮不依赖“上午同一架琴一直放在礼堂”这个不成立的前提。真正的回收是：

> **同一种刚刚被生田发现的演奏方式，从上午音乐教室带到了下午旧礼堂。**

这也使最终高潮具有明确的物理逻辑：

> 当主幕后方仍无法完成正式舞台 preset 时，幕前唯一已经 Ready 的完整表演资源，就是生田和已经就位的正式演出钢琴。

## 三、正式时间基线

### 12:30｜上午联合舞台剧结束

- 舞台剧正常演完、谢幕；
- 文化祭上午部分保持成功、完整的观感；
- 不在这里提前制造事故气氛。

### 12:30—13:30｜午休 / 轮班休息

- 上午演出人员吃饭、休息；
- 大型景片暂时保留在舞台 / 侧台；
- 下午合唱组也进入正常休息与准备状态；
- 所有人都相信 13:30—14:30 的一小时足以完成转场。

这一小时必须让观众感到从容，避免“从中午开始就一直救火”。

### 13:30—14:30｜并行大型 Changeover

原计划：

1. 舞台剧组从一侧逐步拆景、撤景；
2. 旧礼堂正式演出钢琴优先移到幕前 / apron 并固定；
3. 已释放的主幕后舞台区域立即交给合唱技术组；
4. 合唱台、谱架、相关设备同步安装；
5. 合唱团按照既定流程进入附近准备区；
6. 14:30 舞台整体 Ready；
7. 14:30—15:00 用于最终站位、确认、候场和开演准备；
8. 15:00 正式演出开始。

这是一份合理且留有余量的计划，不把事故归因于真夏把时间压得过紧。

## 四、分钟级事故推进

> 以下时间用于因果测试，不等同于最终成片必须显示的字幕时间。

### 13:30—13:55｜一切顺利

- 小件景物开始撤出；
- 前几块景片正常通过；
- 正式演出钢琴已经在幕前位置固定；
- 合唱台从已经释放的主幕后区域开始搭建；
- 两组工作真的能够并行；
- 真夏收到的仍然是正常的 `Done → 勾`；
- 现场甚至可以显得比预想更顺。

事故不能在这里显形。

### 13:55—14:05｜最后大景片被释放

- 舞台剧组拆到最后一块大型景片；
- 合唱台已经按计划推进到一定程度；
- 景片脱离固定点；
- 几个人开始按预定动作把它转向后台出口。

第一次停住。

没有人认为“出事了”。

正常反应是：

- 往回一点；
- 再立一点；
- 换一个角度；
- 另一端先走。

仍然像一个几十秒可以解决的普通搬运问题。

### 14:05—14:15｜确认不是操作问题

多次尝试后发现：

- 景片正面尺寸没变；
- 但背部支撑比原来厚；
- 原本能够利用的转向余量已经被吃掉；
- 合唱台恰好占据了那一小块原计划允许景片扫过的空间。

这时才出现第一句真正有用的信息：

> “这个是不是比原来的厚？”

临校 / 制作侧可以回答：

> “正面尺寸一样。”

没有人说错。

### 14:15 左右｜第一次上报真夏

真夏首先问的不是“谁的错”，而是：

> “多久？”

现场最初仍会给出乐观估计，例如“五分钟”。

她的行为引擎会让她先吸收局部偏差：

- 吃掉 buffer；
- 调整个别准备顺序；
- 让尚未需要进入舞台的人员继续在原准备区等待。

她此时仍相信系统可以把变化重新包进去。

### 14:20—14:30｜正确的自救开始互相改变现场

现场不会等真夏逐项遥控，而会自行尝试解法：

- 景片组尝试不同角度；
- 有人提出先退一部分合唱台；
- 有人检查其他出口 / 转向方法；
- 合唱技术组暂停继续向内搭建；
- 为了给大景片腾空间，原本的候场区域和通道开始临时改变用途。

每个决定单独看都合理。

但从这里开始，舞台的实际状态开始快速偏离原始总表。

### 14:30｜第一个真正的硬节点失败

原计划：

> **14:30 舞台 Ready。**

现实：

> 最后一块景片仍未撤出；合唱台也不能完成最终状态。

这是 S03 `时间到了 → Done → 勾` 的第一次正式失效：

> **时间到了，但 Done 没有来。**

从这一刻开始，事故不再只是“搬运问题”，而变成正式演出流程问题。

### 14:30—14:45｜空间冲突转化为信息冲突

因为后台 / 侧台不断被临时释放、再占用，工作人员会连续发出当时正确、随后过期的指令：

- “合唱先不要进后台。”
- “先去左侧等。”
- “左侧也要清，改去前厅。”
- “设备先停。”
- “这一段先退。”
- “先别退，景片再试一次。”

这些不是愚蠢的误传。

它们是在快速变化的现场里产生的**版本漂移**。

松村可以在这里自然进入：她仍然是全校最灵活的口头信息节点，但第一次遇到“我知道的两分钟前是真话，现在未必还是”的局面。

未央奈线也应从这种不断变化的有效指令中生长，而不是“她没赶到学校 / 没有候场”。她一直在认真执行自己最后收到的正确指令。

其具体人物场次暂不锁，等后续逐场行为测试。

### 14:40—14:50｜身体解题进入核心

事故不应靠教师或外部专业人士解决。

学生开始真正从物理空间入手。

建议的人物功能：

- **和田まあや**：最快看懂“物体怎样移动”，不是靠术语，而是靠身体和空间直觉；
- **生驹里奈**：行动先于解释，直接进入搬、抬、扶的执行；
- **若月佑美**：守住安全和执行边界，不允许为了赶时间采用明显不稳妥的硬抬方式。

まあや不必成为神奇工程师。

她的价值应是发现一个别人一直用“整个景片 / 整个合唱台”思考时没有看到的局部动作，例如：

- 先折 / 退一个特定的合唱台模块；
- 释放一个关键转角；
- 一端先进入，再转另一端；
- 利用物体真实的重心和身体动作完成转向。

若月确认可安全执行，生驹与其他学生马上动手。

这是“不同人的正确能力在同一个问题上接起来”，不是一个人突然开挂。

### 14:50—14:55｜景片终于撤出

最后一角通过。

一句即可：

> “过了！”

不要拍成大型胜利。

因为景片一离开，后台立刻反向启动：

- 合唱台重新推进；
- 锁轮 / 固定；
- 设备归位；
- 合唱成员开始进入；
- 站位重新压缩确认；
- 刚才被临时改变的候场信息需要重新统一。

**解决景片，只是释放了资源。原本一个小时完成的最后部分，现在只剩几分钟。**

### 14:55—15:00｜从“恢复原计划”切换到“保证正式开始”

到这里，真夏必须承认：

> 原来的 running order 已经不可能完整恢复。

但 15:00 是对外公开的正式开演时间。

因此她的行为变化不是“把所有东西重新算回原表”，而是第一次直接问现场：

> **“现在能先上什么？”**

答案来自物理现实：

> **幕前钢琴已经 Ready。**

它位于主幕之前，不依赖主幕后方仍在进行的合唱台最终 setup。

松隆子确认生田可以上。

上午她已经明确要求：正式演出按谱，不允许把自由尾奏直接当成不可控的正式版本。

现在现实反过来需要那段自由演奏。

这不是生田造成事故，而是她上午发现的能力在下午突然成为资源。

## 五、15:00 开场高潮

### 幕前

15:00。

生田在幕前正式演出钢琴开始 solo。

正式演出因此**准时开始**。

她演奏的是上午在音乐教室刚刚发现的那种自由方式 / 尾奏材料，而不是原定的正式开场。

### 幕后

主幕仍然关闭。

琴声之下：

- 合唱台最后归位；
- 若月确认固定；
- まあ亚从地上 / 台下出来继续帮下一件事；
- 生驹把最后一个物件送到位置；
- 中元确认合唱站位；
- 松村把最新版本的信息真正统一到人；
- 未央奈回到属于自己的位置；
- 真夏不再盯着那张已经失效的表，而开始直接看舞台、人和幕。

后台必须忙，但不能把安全写成儿戏。笑来自“漂亮学校幕后原来是这样”，不是来自危险动作。

### 音乐交接

等后台真正 Ready：

- 真夏给物理信号；
- 生田收到；
- 她把自由演奏逐渐带回正式合唱作品的主题 / 和声材料；
- 松下听出交接点；
- 合唱进入正式状态。

### 大幕

幕拉开。

刚才幕后的学生还在：

- 蹲；
- 跑；
- 搬；
- 扶；
- 找位置。

幕一开：

> **一条线的裙摆。**

核心效果：

> 她们不是因为准备得完美，所以站成了一条线。
>
> **准备已经完全不完美了，她们还是站成了一条线。**

这应成为 EP05 最重要的视觉兑现之一。

## 六、生田线与事故线正式拆开

### 生田上午

- 地点：**音乐与美术别馆的音乐教室 / 合唱排练室**，不是旧礼堂；
- 彩排时第一次真正尝到 free / 即兴的乐趣；
- Fukase 听见她不再只是“正确完成”的变化，轻轻微笑；
- 真夏只确认正式演出时长是否可预测；
- 松隆子从专业边界明确要求：**正式演出按谱。**
- 这件事当时被正常解决，不成为事故起因。

### 生田下午

- 舞台事故由物理转场冲突产生；
- 到 15:00，只有幕前正式演出钢琴能够立即开始；
- 上午“不允许进入正式演出”的 free，反而成为保证正式开场的唯一可用资源；
- 她第一次 free 时别人必须等她；
- 最后一次 free 时，她是在替别人争取时间；
- 回收的是**演奏方式和人物变化**，不是“同一架钢琴”。

这个反差比“生田超时导致文化祭失控”更符合人物弧，也更尊重正式音乐演出的专业逻辑。

## 七、人物功能校验

### 秋元真夏

前段：

> 时间到了 → Done → 勾。

事故初期：

> 偏差出现 → 问“多久” → 吃 buffer → 重排。

中段：

> 现场局部变化速度开始超过总表更新速度。

高潮：

> 不再问“原来现在应该发生什么”，而问“现在实际能发生什么”。

最终动作仍应保留：放下 / 停止依赖那张已经无法描述现实的表，直接看现场。

### 伊藤万理华 / 西野七濑

退出主事故链。

她们的 EP05 关系线只负责人物本身，不承担布景物流原因。

当前最有潜力的行为：观众从作品“错误方向”进入，万理华不纠正，反而自己去那个方向看看；西野自然跟过去。

核心不是“作品受欢迎”，而是：

> **我决定作品是什么，但不决定你应该怎么看。**

### 松村沙友理

不再承担“找最后两个人”的搜索机关。

她承担的是快速变化现场里的**口头信息网络**：

> 她仍然很会知道人和事情在哪里，但第一次遭遇“信息本身过期得比她跑得还快”。

### 和田まあや

身体 / 空间直觉正式进入主事故解决链。

不能写成突然懂复杂工程，而是让她看见别人忽略的真实运动方式。

### 生驹里奈

把“知道怎么做”立刻变成“我来做”的行动者。

### 若月佑美

在赶时间时仍守住安全与执行边界。

她不是阻碍效率，而是防止现场因为焦虑产生真正危险的错误。

### 堀未央奈

不再依赖“没有赶到候场”这种不可信起因。

她的困境来自：后台空间不断改变后，她连续收到多个在当时都正确、之后又过期的指令。

具体如何落到“我上不了了 / 我再试一次”，下一轮再单独跑行为与流程，不在本版强锁。
