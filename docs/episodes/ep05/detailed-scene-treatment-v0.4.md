# 全集执行原则

## 1. 前十五分钟真的要成功

不能让观众提前闻到“马上要出事”。

上午的文化祭就是顺利、热闹、好看。工作人员偶尔有普通劳动的小麻烦，但所有系统都在正常运转。

事故不是伏笔兑现式的“报应”，而是下午 changeover 中一个原本存在的物理余量消失。

## 2. 合唱与旧礼堂上午分开

旧礼堂上午用于乃木坂女学院 × 临校联合舞台剧。

合唱排练统一在音乐与美术别馆的音乐教室 / 合唱排练室完成。

上午生田的 free 是人物发现，并被松隆子以“正式演出按谱”正常收住，不造成任何后续时间事故。

## 3. 事故只从物理现实长出来

新版大型景片：

- 舞台正面宽高正确；
- 背部为了强度增加更厚的固定支撑；
- 在上午舞台剧中完全正常；
- 下午撤景时才发现运输包络变大。

同时，合唱台按原计划在已经释放的舞台区域逐步搭建。

按照旧景片的厚度，两件事可以并行；按照新版景片的背撑厚度，最后一块景片失去原有的转向余量。

因此：

> 景片没做错。
>
> 合唱台没搭错。
>
> 时间表也不是烂计划。
>
> **只是“还能过”的那一点余量没有了。**

## 4. 真夏不是从会计划变成不会计划

本集推进：

> 时间到了 → Done → 勾。
>
> 小偏差 → 问“多久？” → 吃 buffer。
>
> 14:30 → Done 没来。
>
> 14:40 → 必须“落幕 / 开门”。
>
> 14:50 → 根据まあ亚给出的真实工时放弃原定开场。
>
> 最后 → 不再问“表上现在应该是什么”，而问“幕前现在能上什么”。

她最终仍然是那个擅长执行的人，只是开始直接读取现实。

## 5. 幕前与幕后的声音规则

15:00 生田 solo 开始以前，必须结束明显会穿透主幕的重型搭建噪音。

solo 期间后台可以：快走、站位、无声确认、最后检查、传递谱夹、整理队形。

不能继续敲金属、拖大型台阶、重推布景。

最终高潮的后台是：

> **安静的疯狂。**

## 秋元真夏

最后仍然是她做出Plan B并让系统继续。

她依旧聪明、会跑、会问人；只是“我知道刚才发生什么”第一次不等于“我知道现在发生什么”。
