# EP05《文化祭》｜Whole-Episode Rhythm / Repetition Review V0.1

> 审查对象：S02—S23 当前逐场锁定文本，含 `screenplay-scene-locks-v0.9.md` 的 S23 安全修正。
>
> 审查目标：不再检查单场对白“对不对”，而把整集当成一次连续观看，检查节奏、重复动作、时间镜头密度、程序性劳动的屏幕占比，以及高潮前后呼吸。
>
> 结论：**无结构性 RED。** 整体节奏成立；发现 3 个应当直接修正的 YELLOW，以及 3 个进入表演 / 镜头空间阶段的全局纪律。

# 一、整集节奏主线｜GREEN

整集当前节奏弧成立：

> 上午正常运转 / 喜剧与日常 → 午休松弛 → 13:30换台开始 → 13:55事故出现 → 五分钟 → 说不好 → 14:30计划失效 → 14:40观众照常进场 → 14:44未央奈被拿下 → 14:47双转被发现 → 14:49 Plan B → 15:00钢琴先开始 → 后台从噪音切到静音 → 未央奈恢复 → 正式开头回来 → 演出成立 → 下一项立即开始。

重要的是，事故不是从“灾难”直接跳到“成功”，中间有几个明确的节奏换挡：

1. S02—S07：学校真的在过文化祭；
2. S08—S10：问题仍像普通工作故障；
3. S11：`不知道`第一次击穿总控系统；
4. S12—S13：真夏开始改流程，同时未央奈线出现代价；
5. S14—S17：解决方案出现，但仍然只是劳动；
6. S18以后：声音从后台噪音切成钢琴，节奏真正松开；
7. S23：刚完成的舞台立即被下一项覆盖。

该大弧不建议重构。

# 二、时间 / 看钟 / 看表｜YELLOW，但主要是镜头纪律

## 现状

本集时间信息很多，而且这是成立的：

- S03用准时 Done 建立真夏的系统；
- S07换台精确推进；
- S09—S14靠时间压力推动决策；
- S17—S18逼近15:00；
- S22以后时间不再需要成为主角。

问题不在“剧本里有很多时间”，而在于如果每一个 `看钟 / 钟：14:xx / 时间点` 都拍成插入特写，本集会变成钟表广告，时间的力量反而递减。

## 锁定拍摄纪律

剧本文字里的时间戳分成两类：

### A｜建议真正让普通观众明显看见的时间节点

- S03：早晨准时系统的建立（可保留一到两个明确钟点）；
- 12:30：上午联合舞台剧正常结束；
- 13:30：换台正式开始；
- **14:30：舞台Ready没有Done；**
- **14:40：House Open；**
- **15:00：钢琴开始。**

这几个节点承担结构功能。

### B｜主要供剧本 / 执行掌握，不必每次做钟表特写

如14:14、14:26、14:34、14:35、14:41、14:44、14:47、14:49、14:57、14:58、14:59等。

人物可以自然瞥时间，剪辑也可以让观众通过场景顺序理解，但不要每次都切钟面。

尤其：

> **14:30 → 14:40 → 15:00**

应成为后半集真正能被观众记住的三个大时间门槛。

# 三、S03的 `Done → 勾 → 等` 重复｜GREEN，必须保留

S03本身就是故意重复。

三次左右的：

> 时间到 → 人来 → Done → 真夏勾掉 → 等下一项

不是冗余，而是后半集的节奏基准。

后面真正有价值的不是继续重复这个动作，而是让它逐渐失效：

- S07仍能勾；
- S09“五分钟”还能写进系统；
- S10“说不好”开始无法落笔；
- S11 14:30那一格空着；
- S19她不再追补那一勾，而是抬头读现场；
- S22她根据现场直接改下一项路线。

因此S03不能为了“减少重复”而削薄。

---

# 四、S07的换台流程｜GREEN，但不要把所有 Done 都剪成总控回报

13:30—13:54搭合唱台约24分钟必须有身体感，否则后面`全拆恢复约40分钟`会失去可信度。

但拍摄时不需要把13:38、13:47、13:54每一次都做成同等重量的：

> 切总控 → 报告 → 真夏勾 → 切回舞台。

建议：

- 13:38钢琴Done保留明确总控接口，因为它是后面Plan B资源；
- 中段合唱台进度可更多留在舞台连续动作里；
- 13:54完整合唱台Done再次明确回到总控。

这样既保留24分钟搭建感，也避免和S03的检查节奏完全复制。

此项作为剪辑 / 场面调度要求，不主动解锁S07对白。

# 五、S08—S14失败搬景密度｜YELLOW → 本轮直接修

## 前半段已经足够

S08—S10已锁定：完整展示最多两次失败，其他用短动作、停、退、报告和清空间推进。这个原则正确。

## 新问题出现在14:30以后

当前连续观看会出现：

1. S11真夏到现场后亲眼看一次 `起 → 转 → 停 → 退`；
2. S12 14:36—14:37又一次；
3. S12 14:38—14:39又一次；
4. S14开场还要再来一次旧单转，才进入まあ亚方案。

单场看都合理，连起来就开始让观众第三、第四次确认“还是不行”。

## 修正

保留：

- S11：真夏必须亲眼看一次失败，成立她的现场判断；
- S12 14:36—14:37：作为前厅来问是否开门时的后台压力背景；
- S14：解决方案出现前，再给一次完整、可与双转比较的旧单转。

删除：

> **S12 14:38—14:39的额外一次完整尝试。**

改成：景片已经退回安全位置，现场暂时重新找路线 / 整理空间；まあ亚在这个停顿里看景片、出口和已经清出来的横向空位。

好处：

- 给14:40 House Open前一个短暂“没人知道下一步”的停顿；
- まあ亚的观察不需要建立在第N次失败上；
- S14开头那次旧单转重新获得比较价值。

# 六、S13情绪换挡｜GREEN，必须保留现在的轻

`今天先不用`之后，不立刻解决事故，而是进入：

> 未央奈：对不起。  
> 高山：嗯？  
> 未央奈：我上不了了。  
> 高山：啊。  
> 那就不上了。  
> 我的水去哪了……

再接南本来就在分的糖。

这段是事故长流程里非常重要的呼吸。

不能为了“主线紧张”删掉，也不能为了“情绪价值”拉长。

它的功能恰好是：**事情很重要，但生活没有因此暂停。**

# 七、S14模拟 vs S16实际通过｜GREEN，但两次速度必须不同

这两段表面上都是：

> 第一转 → 横移 → 第二转

但不能剪成两次同长度的技术演示。

锁定节奏区别：

### S14｜解释空间

慢。

需要让普通观众看懂：

> 原来大家以前都想一把转完；现在多了横移和第二次转向。

可以停，可以观察，可以让技术学生确认。

### S16｜兑现

快。

最高一级已经拆掉后，动作应该更像一口气完成：

> 转 → 送 → 再转 → `……过了` → `先别松` → 继续出去。

S16不是再次教学，而是让观众得到“这次真的过去了”的身体满足。

不新增对白。

# 八、S17复原｜GREEN，但屏幕时间应压缩

不需要第二次学习合唱台安装方法。

# 九、S18—S21“微小点头接力”｜YELLOW → 本轮直接修S19

## 风险

S18以后进入安静段落，大量交流自然会变成非语言。

但当前连续排列是：

- S19若月对松下点头；
- S19中元对松下点头；
- S20松下对未央奈小幅点头；
- S21生田对真夏极轻点头；
- 真夏再用两个视觉信号交接。

单个都好，连续几分钟里会变成“所有人都用小点头传递状态”。

## 修正

S20和S21的两个点头有明确不可替代含义：

- 松下 → 未央奈：无声确认完成；
- 生田 → 真夏：收到“回正式曲目”信号。

保留。

S19改成**让工作完成本身成为信号**：

- 若月不专门对松下点头；她完成最后目视后退到侧面，把通道和台阶交出来；
- 中元不专门对松下点头；她数到最后一人，手指停下，名单 / 手放低，队伍已经完整站定；
- 松下自己看见这两个事实。

这样15:00后的非语言仍然丰富，但不是“点头密码系统”。

# 十、未央奈领巾动作｜GREEN，保留现在的“两次做 / 最后不做”

当前成立的是：

- S04：正式排练前，碰一下本来就正的领巾；
- S06：下午前已经准备好，又碰一次；
- S20：回到mark后，**不碰。**

这不是把同一个漂亮动作重复三次；第三次恰恰是动作缺席。

两次前置足以建立“她会过度确认已经正确的细节”，最后一次不做才有身体层面的变化。

不再增加第四次领巾动作。

# 十一、真夏的“看表”不是全部删除，而要形成四阶段｜GREEN

整集最好让她的读取方式形成四个阶段：

1. **S03：表告诉她现实应该是什么；**
2. **S09—S11：现实开始无法被表吸收；**
3. **S19：那一格仍空着，她不补，抬头看现场；**
4. **S22：看现场后直接改下一项路线。**

因此不要为了减少`看表`而把所有动作拿掉。

真正需要减少的是阶段之间无功能的钟表插入，而不是这个人物结构。

# 十二、S23安全撤台对白密度｜YELLOW → 本轮直接修

S23安全顺序修正为从下往上完全正确。

但V0.9又加入了较密的第二层确认：

> `这边好了。`  
> `那边也好了？`  
> `好了。`  
> `那下来。`

安全逻辑没错，但放在TAG里会突然像施工教学片。

## 修正原则

保留三处真正有节奏价值的语言：

1. 开始撤台：`先从下面来。`
2. 第一层让まあ亚参与普通劳动：`这边先松？ / 嗯。不过另一边先别抬。 / 好。`
3. 最后最高一级：`最后这层。 / 好。`

第二层改为纯动作：

> 第一层清开 → 大家自然换到第二层 → 技术学生看两边连接 → 若月等两边都准备好后用手示意 → 同步抬下。

这样安全顺序仍然清楚，而TAG的声音不会被程序性确认填满。
