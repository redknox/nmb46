# 本轮修改原则

- “40分钟”只在S11真夏因现场决策需要时明确出现一次；S12不再出现容易与之混淆的`四十分呢？`。
- 真夏在S11首先发出的两条指令已经被现场先行执行，她不重复强调，也不因此做情绪反应；只用一个`嗯。`接受当前状态。
- S11最后一次失败尝试压成`起 → 转 → 停 → 退`，避免S08—S10后继续重复完整搬运过程。
- 14:35未央奈确认失败只通过动作和对话呈现，不写`14:35确认没有发生`。
- S12まあ亚观察继续沿用“双转”新版方向：看路线与横向空位，不提前看出最高一级答案。
- 14:40开门只表现正常入场，不写`没有延迟广播 / 没有道歉`这类负形解释。
- 未央奈对高山说`对不起`保留：这是低年级面对前辈时的关系润滑，不是承认事故责任。
- 高山`那就不上了。`与南的自然分糖保持原样，不升级为安慰戏。
