# 二、旧礼堂物理冻结

## 1. 最后一块大景片为什么最后撤

它是联合舞台剧的后部主景 / 基础景片。

前景、小景、道具与附属件没有撤完以前，它不能安全释放，因此天然接近最后拆。

它进入旧礼堂时舞台基本为空，同一条物流路线完全可用；下午撤出时，合唱台已经按正确并行计划搭到相应区域，环境已经改变。

## 2. 景片为什么不能“先靠边放着演”

它卡住的位置正处于主舞台与侧后台之间的有效出入 / crossover 路线。

景片可以暂时安全停在那里处理问题，但不能成为正式演出状态的一部分，因为：

- 合唱成员需要这条路进入 / 撤出；
- 演出结束后旧礼堂马上还有下一项；
- House Open 后不能再把大型景片从观众侧随意绕行。

因此最终必须把它撤出。

## 3. 景片结构

新版景片：

- 正面宽高与原版本一致；
- 为了强度与稳定性，背部增加更厚的固定斜撑 / 上部支撑框架；
- 在舞台上完全正确；
- 运输时真正改变的是转向扫掠包络。

冲突必须设计成：

> 下部其实够；中部也够；只有景片上部后角在某个转向姿态下扫到合唱台最高一级。

这样まあ亚必须在物体真正转到那个姿态以后，才有机会看出局部关系。

## 4. 合唱台

合唱台为模块化固定台阶，不是整座带轮平台。

在まあ亚提出方案以前：

> **任何人都不拆已经完成并固定的合唱台。**

前期只做非返工动作：暂停后续模块、清杂物、换景片角度、换 pivot、检查其他路线、确认景片背撑不能现场随手安全拆除。

## 5. 为什么最高一级拆掉以后必须装回来

不是“少一层就绝对不能唱”，而是：

- 最高一级原本有一整排已排练好的合唱成员；
- 永久少一层意味着临时重排整排站位、前后间距、声部位置、指挥视线与舞台 mark；
- 这个工作量和风险不可预测；
- 把刚拆下来的模块按原固定点装回、连接、锁定、检查，是可预测工时。

因此：

> **确定性复原优于未知的临时重排。**

まあ亚真正提供的价值，不只是“让景片出去”，而是让一个“不知道还要多久”的问题重新变成可以估时的工作。

# 四、未央奈流程冻结

未央奈是最终舞台唯一被特别选入的一年级生，不属于高三常规合唱声部。

她承担的是正式节目最前面的短领唱，即全场第一个人声。

上午 S04 已建立原版音乐结构：

> 未央奈第一声 → 高三合唱进入。

下午她比别人更早 Ready，但比普通合唱成员多一个独立流程：

> 14:35 左右开场位置 / 入口 / 松下 cue 的短确认。

这个确认不是完整彩排，只是特殊开场岗位所需的最低限度舞台确认。

14:35舞台未 Ready，因此这一步没有发生。

14:40 House Open 后完整空台确认窗口消失。

14:44—14:46松下因此取消这个未完成确认的额外开场环节。

这不是因为她表现不好，也不是因为后台危机随机牺牲新人。

生田 solo 开始后：

- 舞台主要物理状态已经稳定；
- 她不再需要在15:00整冷启动全场第一声；
- 幕后获得一段真实、安静的确认窗口。

所以松下恢复她原本的位置。

动作呼应：

- 上午：看脚下 → 碰一下已经正的领巾；
- 下午：看脚下 → 抬头；
- 不再碰领巾。

# 六、15:00以后最终音乐交接冻结

这里不依赖“生田与松下超级默契”或真夏判断专业乐句。

最终使用**双视觉 cue + 专业接管**。

## 1. 真夏确认运营 Ready

她确认：

- 合唱台安全；
- 人员已站位；
- 未央奈已回原位；
- 幕可以升；
- 若月 / 舞台侧没有剩余硬性阻塞。

## 2. 第一个 cue：真夏 → 生田

真夏从侧边给生田视觉信号。

意思只有：

> **后台已经 Ready，可以开始往正式曲目回。**

生田看见并以很小的视觉回应确认收到。

真夏不需要听懂她已经进入哪个和弦 / 哪一段。

## 3. 第二个 cue：真夏 → 松下

真夏一确认生田**收到信号**，立即把第二个视觉信号给松下。

意思：

> **运营侧已经交给你。**

随后真夏退出音乐判断，转去管幕与舞台状态。

## 4. 生田负责“怎么回”

生田继续弹，从 free 自己找到回到正式作品的音乐路径。

她不负责判断后台是否 Ready。

## 5. 松下负责“什么时候接”

松下从此只听生田实际演奏。

什么时候音乐已经走到可以让正式合唱进入的位置，由他作为合唱指挥专业判断。

不是固定第几小节，也不是等真夏第三次命令。

## 6. 最终顺序

冻结为：

> 真夏确认后台 Ready
> → cue 生田
> → 看见生田收到
> → 立即 cue 松下
> → 生田开始从 free 往正式曲目回
> → 松下自行判断音乐入口正在成立
> → 大幕升起
> → **一条线的裙摆**
> → 松下给未央奈正式起唱 cue
> → **未央奈开唱**
> → 高三合唱进入

幕在未央奈开唱之前已经升起，避免关闭大幕后的独唱声学问题。

这也让视觉高潮先于第一声出现：

> 大家刚才还在幕后狼狈工作，现在观众先看到她们已经站成一条线；然后未央奈才唱出第一声。

# 九、逐场 screenplay 写作纪律

从 S05 起进入正式逐场重写。

1. 先写动作和空间，再写台词。
2. 对白采用日语现场逻辑，不为观众完整解释因果。
3. 能用视线、停顿、身体让位、接物、递物、确认解决的信息，不说出来。
4. 不提前给事故配 ominous 镜头。
5. 不为了突出“名门女校”让角色谈教养；教养从忙时仍自然做出的动作里出现。
6. 不把任何专业成年人写成神谕者。
7. 不把角色成长写成总结句。
8. S23 TAG 不允许煽情回望，必须直接进入下一项工作。
