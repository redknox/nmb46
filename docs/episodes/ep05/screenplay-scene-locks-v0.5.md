# S11｜LOCKED｜14:30 没有 Done

锁定以下核心顺序与对白：

1. 14:30 `旧礼堂 舞台Ready` 没有 Done；与此同时其他正常项目仍可继续报 Done、被真夏勾掉。
2. 负责学生：`旧礼堂那边，景片还没出去。`
3. 真夏：`还要多久？`
4. 负责学生：`……不知道。`
5. 真夏：`现在也不知道？`
6. 得到`是`后，真夏放下红笔，亲自去旧礼堂。
7. 到现场后：合唱已被挡在外面、设备已停；真夏只用`嗯。`接受现场已经自行执行的状态。
8. 技术事实继续由舞台学生提供，若月只负责安全 / 执行边界。
9. 关于合唱台：

> **真夏**  
> 合唱台呢？
>
> **本校舞台学生**  
> 要让开的话，得全拆。
>
> **真夏**  
> 多久能恢复？
>
> **本校舞台学生**  
> 四十分钟左右。装回来以后还得重新确认。
>
> **真夏**  
> 那不动。
>
> **若月**  
> 嗯。

10. `40分钟`在事故链中只明确说这一次。
11. S11最后一次失败搬运只保留`起 → 转 → 停 → 退`，不再完整重复S08—S10的失败过程。

### 锁定原则

- 真夏真正被击穿的是`不知道`，不是单纯的延迟。
- 真夏到现场不是救世主；现场人员已经在正确地自救。
- `40分钟`的可信度来自观众此前看见13:30—13:54搭完整合唱台，而不是角色追加解释。
- 不恢复`全部？`等观众确认式重复对白。

- 南不承担“治愈新人”的剧情任务，糖只是日常经过未央奈。
- 观众已经能够从S04 / S06 / S12自行连接“特殊开场确认没完成 → 松下回到成熟原版”，不补解释。
