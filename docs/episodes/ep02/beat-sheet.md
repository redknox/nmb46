# 本集核心

EP01 的问题是：

> **怎么进入这所学校？**

EP02 的问题变成：

> **进来以后，每天到底怎么在这里生活？**

因此本集必须让“裙摆”与“学习”属于同一件事：

> 规则不是写在学生手册里供剧情讨论的东西；
>
> 它和晨读、作业、小测、值日一样，是每天重复执行、身体慢慢习惯的学校生活。

本集两个 M：

- 生驹｜“像这里的人”与“属于这里的人”开始拆开；
- 飞鸟｜从旁观式吐槽走到参与式质疑。

---

# 时间位置

**暂定：EP01 入学式的第二天 / 第一个真正进入普通课程节奏的 weekday。**

理由：

- EP01 最后一条黑板通知 `明日　体育館シューズ` 可以自然变成第二天早晨普通学生手里的鞋袋，不做 callback 特写；
- 从“正式典礼日”直接进入“普通上课日”，反差最大；
- 新生第二天就开始试着调整制服穿法非常可信：第一天穿给学校 / 家长看，第二天开始穿给自己生活。

若后续现实流程证明第二天通常仍以说明 / orientation 为主，可以平移到“入学后数日”，不影响本集结构。

# 00:00–03:00｜Cold Open｜制服从典礼服变成日常服

普通早晨。

高三学生经过鞋柜 / 走廊，几个人包里或手里自然带着 `体育館シューズ` 鞋袋。

不解释 EP01 黑板。

一年级洗手间 / 更衣镜附近，两名普通新生整理制服。

其中一人把裙腰向内折一折，裙摆变短一点。

朋友看一眼：

> “会被说吧。”

她：

> “一点点而已。”

不是叛逆宣言。

进入走廊以后，教师经过，只停一拍：

> “裙子。”

女生知道什么意思，把折进去的一层放下来。

教师已经继续走。

TITLE。

**功能：**三分钟内建立：规则存在、学生知道、学校会管，但世界不会为了这件事停下来。

# 03:00–07:00｜3-D 朝HR｜“有意见就写”

新学年例行把《生徒心得》意见 / 疑问收集表发到各班。

不是“校规改革大会”，只是一张学校每年都会收的普通纸。

3-D。

飞鸟看到制服条目。

第一反应不是“我要穿短裙”，而是：

> **为什么膝盖附近？**

若月已经开始填 / 确认提交方式。

飞鸟觉得这种调查未必有用，先留空。

若月不和她辩：

> 有意见就写；没有就交。

南只关心一个非常现实的问题：

> 被老师叫住更麻烦。

**功能：**飞鸟线起点；把规则的制度入口放在所有学生桌上，不让她被剧情特别挑中。

# 07:00–13:00｜晨间学习 / 第一轮课程｜“这里真的要上学”

不做17人 montage。

用一个连续学习 sequence 建立真实学校时间：

### 3-C｜晨间短测 / 国语或古文

武田 / 任课老师正常发题。

- 真夏已经准备好需要的东西；
- 高山边做边对一个措辞产生小反应；
- まあ亚在正式书面语言上真实卡住；
- 西野安静做自己的。

まあ亚不会突然逆袭。

### 3-D｜短插

飞鸟成绩并不差；刚才还在嫌规则，她现在正常低头写题。

南已经开始困。

### 3-B｜极短插

生田很快进入“哪里还不够正确”的学习模式，不把她拍成全能天才秀。

**功能：**第一次让观众真正坐进课堂，而不是把学习当“校园剧默认省略部分”。

---

# 13:00–17:00｜课间｜生驹第一次进入裙摆线

上午课间 / 换教室流动。

Cold Open 中的一年级女生属于 1-A；她认得昨天带班的生驹。

她不是来“挑战学姐”，而是顺着乃木坂的前后辈习惯问一个具体问题：

> 学生手册写“膝部附近”，到底怎样算？

生驹非常熟练地告诉她现行标准。

这一部分必须让生驹**说对**。

问题发生在下一步。

女生再问：

> 稍微短一点真的很奇怪吗？

生驹本能想把“规定”继续扩展成“乃木坂学生应该有的样子”。

这里先不完成争论。

铃响 / 换课把两个人带走。

**功能：**生驹第一次发现，对方问的已经不是“规定是什么”，而是“规定和我有什么关系”。

---

# 17:00–23:00｜正常课堂完整坐一会儿

这一段不推进裙摆主线。

选择一门真正坐得住的课，建议以 3-C 的国文 / 古文为主体，允许武田承担成人课堂重量。

要有：

- 点名回答；
- 背诵；
- 有人答错；
- 老师追问；
- 记笔记；
- 页码翻错；
- 一句很普通的“上次讲过了”；
- 下课铃响以后老师还多讲半分钟。

高山和まあ亚可以形成笑点，但课本身必须真的继续。

**功能：**这是 EP02 的结构宣言：观众不能只在“有剧情的课间”才看见学生。

---

# 23:00–27:00｜午休｜规则暂时输给吃饭

午休不讨论制服大会。

大家首先吃饭。

飞鸟的意见表还夹在文件里，空着。

南问她要不要一起去某处 / 吃什么；飞鸟照常跟着。

生驹也回到自己的普通关系里。

Cold Open 的一年级女生和同学正常吃饭 / 说社团 / 作业，证明她不是为了裙摆存在的议题角色。

生驹如果从远处看见，也只得到一个很轻的信息：

> 她正在非常普通地成为这所学校的一年级学生。

不做“原来她也很认真”的反应特写。

---

# 27:00–33:00｜下午｜学校的尺很多，不只有裙长

用两三个现实学习动作继续建立“被学校测量”的感觉，但不说主题。

可组合：

### 3-C

短测成绩 / 作业返还。

まあ亚真实不好；高山想开玩笑，发现她在认真看自己错在哪里，笑点只停半步。

### 3-B

生田对一个别人觉得已经够好的答案仍继续修正；只照亮高标准，不进入 EP04 的音乐结论。

### 3-D

飞鸟正常答对问题。

她不是“反规则所以成绩差”的类型。

**功能：**学校每天用很多尺量学生；人物对不同尺子的反应不同。

这句话只存在于编剧层，不写进对白。

---

# 33:00–38:00｜3-D HR / 生徒心得说明｜飞鸟真正把问题问出来

下午一个短 Home Room / 规则说明节点。

教师说明：

- 意见表会真的被收集；
- 有疑问可以写具体条目；
- 现行规则在正式修改前仍按现行规则执行。

飞鸟第一次把“裙摆为什么必须到膝部附近”真正问出口。

教师不能回答：

> “因为规定就是规定。”

教师给学校真实相信的理由，例如：

- 指定制服是一套共同的正式服装；
- 学校希望学生在校内外保持一个共同外观基线；
- 这是乃木坂长期礼法 / 对外呈现的一部分。

飞鸟听完仍然不觉得这等于充分理由。

本场**不要求争出胜负**。

若月只确认：

> 那就写到意见表里。

南已经在想下一件生活小事。

**功能：**本集唯一允许稍微抬高的“规则讨论”场，但不变成辩论赛。

---

# 38:00–43:00｜生驹第二次遇见1-A女生｜规则和喜欢可以同时存在

放学前 / 教学楼流动。

一年级女生再次自然碰到生驹，或主动来找昨天认识的学姐。

她现在已经把裙摆恢复到校内规定位置。

她没有因为老师提醒就变成“被压迫者”。

谈话保持普通。

可以让她用很简单的话表达：

> 她其实很喜欢这身制服；
>
> 只是觉得短一点自己更喜欢。

关键不是这句话本身，而是生驹第一次面对：

> **一个人可以同时喜欢乃木坂、也不想把自己完全穿成生驹理解的标准答案。**

生驹仍然可以告诉她：

> 在学校里老师还是会提醒你。

但她不再继续补：

> “因为这样才像乃木坂学生。”

这是她本集真正的行为变化。

---

# 43:00–46:30｜清扫 / 终礼｜学校继续要求很多小事

学生整理教室。

桌椅归位、黑板、提交物、忘带东西。

普通学生与主演一起做。

这时不要再谈大主题。

可以回收 EP01 最后的 `体育館シューズ`：有人把体育馆鞋袋塞回柜子 / 抱怨带了一天，不做 callback 镜头。

教师再发一个非常普通的明日学习提醒，例如：

> 明天有英语单词 / 古文短测。

全班的反应比裙摆规则更统一：烦。

**功能：**把规则重新压回生活尺度。

---

# 46:30–48:30｜飞鸟｜从空白变成一句具体问题

3-D接近放学。

若月收意见表。

飞鸟那张最初是空的。

她没有写“废除校规”。

只写一条非常具体的问题，方向类似：

> **“想知道裙长规定为膝部附近的理由。”**

或者更飞鸟一点，但仍必须是可进入制度流程的具体问题。

她交出去。

没人鼓掌。

没人说“你还是很在意嘛”。

南不揭穿。

**功能：**飞鸟 M 完成：不认同没有消失，退出变成参与。

---

# 48:30–50:00｜Ending｜明天还有别的规则

放学人流。

一年级女生和朋友一起走；校内裙摆保持规定状态。

生驹从另一条路线经过，没有再停下来检查她。

3-D里，若月已经把一叠意见表夹好交走。

飞鸟拿包。

南突然想起：

> “明天是不是还有小测？”

飞鸟：

> “有。”

南：

> “啊……”

两个人继续走。

CUT。

不以“规则终于改变”收尾。

> **今天她们只是第一次认真和规则发生了自己的关系；明天学校照常继续。**

# Gate 4 前必须压力测试的问题

1. **Cold Open 的一年级女生是否太快成为“本集议题角色”？**需要确保她首先是普通学生。
2. **飞鸟 33:00–38:00 的 HR 是否太像作者安排的校规辩论？**需要测试能否更生活化。
3. **生驹两次与同一新生相遇是否过于工整？**第二次最好由新生主动找昨天认识的学姐，或由真实路线制造。
4. **学习线是否仍然像“证明我们很认真”的 checklist？**至少要保留一段真正坐下来的完整课堂。
5. **白石 / 真夏 / 生田等 S 是否有必要进入正片，还是只存在于行为备选？**不能因为矩阵写了 S 就强行给镜头。
6. **Ending 的南“小测”笑点是否太像设计好的收束？**可在 Scene List 前重新判断。
7. **50分钟是否会因为大量普通课堂而失去剧情推进？**目标不是快，而是课堂内部必须有观看任务变化。
8. **“意见表”制度是否过于方便飞鸟成长？**需要检查它是否像学校本来就会有的东西，而不是专门为她制造的装置。
