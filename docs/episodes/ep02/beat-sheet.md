# 本集核心

EP01 的问题是：

> **怎么进入这所学校？**

EP02 的问题变成：

> **进来以后，每天到底怎么在这里生活？**

因此“裙摆”与“学习”不是两条互不相干的 A/B 线。

它们属于同一种学校生活：

> 规则不是写在学生手册里供剧情讨论的东西；
>
> 它和晨间学习、作业、小测、课堂、清扫一样，每天都要重新做一遍。

本集两个 M：

- 生驹｜“像这里的人”与“属于这里的人”开始拆开；
- 飞鸟｜从旁观式吐槽走到参与式质疑。

两人不是正反方辩手，也不需要正面对线。

# 时间位置｜不强行接“入学式第二天”

**锁定：入学式后的数日内，第一个真正进入通常授业节奏的普通 weekday。**

不再强行指定为 EP01 翌日。

原因：现实学校在入学式后常仍有对面式、orientation、身体测定、社团说明等过渡安排；EP02需要的是一整天能真实坐进普通课程的日子，而不是为了回收 EP01 黑板上的 `明日　体育館シューズ` 扭曲校历。

EP01 那条通知完成的首先是“明天还要来”的生活感，不欠 EP02 一个显眼 callback。

# 00:00–03:00｜Cold Open｜制服从典礼服变成日常服

普通早晨。

一年级洗手间 / 镜子附近，两个**普通新生**整理制服。

其中一人把裙腰向内折一层，裙摆短一点。

朋友看一眼：

> “会被说吧。”

她：

> “一点点而已。”

不是叛逆宣言，也不是本集后面生驹线的那名 1-A 女生。

两个人进入走廊。

教师经过，只停半步：

> “裙子。”

女生知道什么意思，把折进去的一层放下来。

教师已经继续走。

TITLE。

**功能：**三分钟内建立：规则存在、学生知道、学校会管，但世界不会为了裙长停下来。

同时锁定：短一点不是“坏学生”标志，而是新生开始把正式制服穿进自己的日常。

# 03:00–06:00｜3-D 朝 HR｜一张很普通的新年度生活调查

3-D。

学校发的是 broader 的：

> `新年度　学校生活アンケート`

内容包括普通学校生活项目，例如：

- 校内生活有没有尚不清楚的地方；
- 设施 / 时间 / 提交方式是否有疑问；
- 《生徒心得》或生活规则里有没有想确认 / 提出的事项；
- 一个很小的自由记述栏。

它不是“裙长改革调查”，也不是学生会为了飞鸟专门准备的制度按钮。

飞鸟扫到规则意见栏。

她想到制服条目，第一反应是：

> **为什么是膝部附近？**

但她很快觉得“写了又怎样”，先留空。

若月正常处理自己的表，不和她进行校规辩论。

如果飞鸟说这种东西有没有用，若月只回到动作：

> 有问题就写；没有就交。

南的尺度更简单：

> 被老师叫住更麻烦。

**功能：**给飞鸟一个学校本来就存在的低重量入口；此时她仍选择退出。

# 12:00–16:00｜课间｜生驹第一次回答“规定是什么”

上午课间 / 换教室流动。

一名 1-A 普通女生认得昨天负责新生案内的生驹。

她不是 Cold Open 的女生，也不是来挑战学姐。

她早上已经被教师很普通地提醒过一次裙长，因此现在有一个实际问题：

> 学生手册写“膝部附近”，到底怎样算？

昨天学校刚刚告诉新生：不懂可以问附近的学姐。

她于是来问一个自己认识的高年级生。

生驹非常准确地告诉她现行标准。

这一部分必须让生驹**说对**。

女生再问得更生活一点：

> “稍微短一点也不行吗？”

生驹的本能答案仍然偏向：

> 既然是乃木坂女学院的制服，在学校里就应该按学校规定穿。

这不是恶意，也不是风纪委员口吻；这是她自己的归属经验。

铃声 / 换课把两个人带走。

**功能：**前半生驹仍然会从“规则是什么”自然延伸到“这身制服应该怎样被穿”。此时不要让她提前悟到任何东西。

# 16:00–24:00｜一堂真的坐得住的课｜学习不是过场

以 3-C 国文 / 古文为主体，允许武田承担成人课堂重量。

这一段是 EP02 最重要的生活时间之一。

不要切成“每个人一个梗”。

课堂本身必须真的继续：

- 点名回答；
- 背诵；
- 有人答错；
- 老师追问；
- 翻页；
- 记笔记；
- 一句很普通的“上次讲过了”；
- 有人短暂走神又回来；
- 下课铃响以后武田还多讲一点。

高山和まあ亚可以产生笑点，但笑点不能终止教学。

**功能：**这是本集真正的结构宣言：观众不只在“有剧情的课间”才看见学生。

Gate 4 锁定：宁可让这一段真正存在，也不要再加第三轮“成绩 / 作业 / 小测” montage 来证明学校严格。

# 24:00–28:00｜午休｜规则暂时输给吃饭

午休不召开制服大会。

大家先吃饭。

飞鸟的生活调查仍夹在文件里，自由记述栏空着。

南照常拉她去吃 / 去某处；飞鸟嘴上嫌一下，身体跟着。

生驹也回到 3-A 的普通关系里。

镜头可以极轻地经过一年级午休：刚才问过生驹的 1-A 女生正在和同学吃饭、讨论社团或作业。

**这不是生驹的主观镜头。**

观众只得到：她首先是一个正常开始学校生活的新生，不是为裙摆存在的议题角色。

# 28:00–33:00｜下午换一种尺｜身体和实际操作

不再安排第二轮“分数 / 作业返还” montage。

让感知输入换掉。

可以使用 3-C 的体育 / 实技类课程，或另一项真实需要身体与现场反应的学校活动。

核心不是“まあ亚虽然笨但其实是天才”的补偿故事。

只需要让同一个早上在书面语言上卡住的人，此时面对动作示范 / 实际操作时学得很快。

高山可以自然跟上；老师继续教其他人。

如果采用体育课，制服暂时从画面里消失，所有人换成运动服——“裙摆问题”也短暂从身体上消失。

不解释这一层。

**功能：**学校衡量人的方式不只有卷面；同时给连续室内课堂一次真正的感官换挡。

# 33:00–37:00｜3-D｜飞鸟终于把“为什么”问给成年人

不是专门召开校规说明会。

一个正常的下午 HR / 收学校生活调查的节点里，担任提醒：

> 今天发的调查别忘了写名字；有需要学校回答的问题就写具体。

飞鸟那张还是空的。

她在交之前，第一次直接问：

> 裙长为什么是“膝部附近”？

教师不能回答“因为规定就是规定”。

她 / 他只给学校真正相信的理由，控制在现实机构语言范围：

- 指定制服是一套共同的正式服装；
- 学校希望校内外保持共同外观基线；
- 这也是长期校风与对外呈现的一部分。

不需要把三点全部讲完。

飞鸟听懂了。

**听懂不等于认同。**

她仍然觉得这没有完全回答自己的问题。

若月不替老师辩，只在之后很轻地回到流程：

> 那就把你还想问的写进去。

南已经开始收别的东西。

**功能：**本集唯一稍微抬高的规则对话，但它发生在普通 HR 内，不升级成辩论场。

# 37:00–42:00｜生驹第二次接触｜这一次是学妹主动来找她

不再安排“又偶然碰到”。

上午的 1-A 女生主动找到生驹。

她不是要继续问规则条文，而是问一个更私人、更像十几岁女生会问的问题：

> “前辈自己觉得，现在这个长度最好看吗？”

生驹可以很自然地回答：

> 她自己喜欢现在这样穿。

女生也很自然：

> 她其实很喜欢乃木坂的制服；只是自己觉得短一点更好看。

这两句话不需要承担价值宣言。

生驹第一次没有办法把：

> 喜欢学校 / 喜欢制服 / 按自己喜欢的方式穿

简单排成同一条直线。

她仍然告诉对方事实：

> 在学校里如果偏离规定，老师还是会提醒。

但她**不再追加**：

> “所以那样才像乃木坂的学生。”

这就是本集需要的行为变化。

不是变成反校规，也不是学姐批准违规。

> **规则说清楚，自己的喜好也说清楚，然后停手。**

3-D。

学校生活调查开始回收。

没人鼓掌。

若月 / 班级负责学生把一叠调查收齐，按普通流程交走。

# Gate 4 压力测试结论

## GREEN｜故事骨架成立

- 制服线与学习线属于同一个“每天重复执行学校生活”的核心，不需要拆成双主线；
- 生驹 / 飞鸟两个 M 处理不同问题，不必正面对线；
- 结尾不要求规则改变，避免高中生一句话改变制度；
- 普通学生继续占据学校，不把 1-A 女生抬成议题角色。

## Gate 4 已解决的 YELLOW

### 1. 学习 checklist 感

第一版存在三次“学习证明”：晨间学习、完整课堂、成绩 / 作业返还。

修订后：

> **晨间短测建立节奏 → 一堂完整课堂承担真正重量 → 下午改用身体 / 实技换挡。**

不再机械证明学校会考试。

### 2. 飞鸟制度入口过于方便

第一版《生徒心得》意见表太像专门为她服务。

修订后改为学校本来会做的 broader `新年度学校生活アンケート`，规则意见只是其中一个普通自由栏。

她不是被制度选中；她只是后来真的用了这个入口。

### 3. 生驹两次相遇过于工整

第一次由既有前后辈案内传统产生：1-A 新生认识昨天的案内学姐，于是来问实际规则。

第二次取消巧遇，由学妹主动回来问**私人看法**，因此第二场获得新的关系动机和新信息。

### 4. 时间位置过度服务 EP01 callback

不再强制“入学式翌日”。

锁定为入学后数日、第一个真正通常授业日，现实优先于回收 `体育館シューズ`。

### 5. S 级人物点名风险

白石、真夏、生田等不因受力矩阵写了 S 就自动获得镜头。

Beat Sheet 只保留当前真正参与结构的人物；其余 S 可在 Scene List / Treatment 有自然理由时出现，否则休息。

### 6. Ending 太像写好的笑点

删除南专门问“明天是不是还有小测？”的尾句设计。

最后让调查表混进普通文件、学校生活继续即可。

# Gate 4 锁定规则

进入 Scene List 后：

1. 不重新把本集写成“守规矩的生驹 vs 反规则的飞鸟”；
2. 不增加大型服装检查事件；
3. 不让学生会获得纪律处分权；
4. 不新增第三轮考试 / 成绩 montage 来证明学校严格；
5. 1-A 女生保持普通学生重量，不命名成议题主角；
6. 飞鸟问到合理制度理由后仍可不认同，但教师不能被写成稻草人；
7. 生驹的变化是**停止扩大解释**，不是批准违规；
8. 本集不解决裙长规则是否修改；
9. 所有时间格都是预算，不因纸面有五分钟就必须把对话拍满；
10. 若 Scene List 需要改动大因果，先重开本文件，不在下游偷偷改骨架。
