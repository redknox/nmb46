# 本集为什么存在

EP01 问：

> **怎么进入这所学校？**

EP02 问：

> **进来以后，每天到底怎么在这里生活？**

“裙摆”与“学习”属于同一件事：制服、晨间学习、作业、小测、课堂、清扫，都是每天重新执行的学校生活。

本集两个 M：

- **生驹**：开始拆开“像这里的人”与“属于这里的人”；
- **飞鸟**：从旁观式吐槽走到参与式质疑。

两人不是校规正反方，也不正面对线。

# 时间位置

**入学式后的数日内，第一个真正进入通常授业节奏的普通 weekday。**

不强制为 EP01 翌日。

EP01 黑板的 `明日　体育館シューズ` 已经完成“明天还要来”的生活功能，EP02 不为回收它扭曲校历。

# 00:00–03:00｜Cold Open｜制服从典礼服变成日常服

两个普通一年级女生在镜子前整理制服，其中一人把裙腰内折一层。

朋友：会被说吧。

她：就一点。

走廊教师经过，只说：

> `裙子。`

女生放下来，跟上朋友。

TITLE。

**功能：**规则存在、学生知道、学校会管，但世界不会为了裙长停下来。

Cold Open 两名女生**不是**后续生驹线的 1-A 女生。

---

# 03:00–06:00｜3-D 朝HR｜学校生活调查

全班拿到 broader 的：

> `新年度　学校生活アンケート`

内容包括设施、时间、提交、生徒心得 / 生活规则等普通项目；规则意见只是一个小自由栏。

飞鸟看到规则栏，但觉得“写了又怎样”，先留空。

若月只把事情推回动作：有就写。

南只关心：被老师提醒更麻烦。

**功能：**飞鸟有一个学校本来就存在的低重量入口，此时仍选择退出。

---

# 06:00–12:00｜晨间学习｜这里真的要上学

3-C 为主：短测、计时、纸笔。

- まあ亚在正式书面语言上真实卡住；
- 高山注意到但不自动救场；
- 真夏准备齐；
- 西野正常做自己的。

3-D 只极短切一次：飞鸟正常答题，南困。

不再追加 3-B / 更多角色“学习展示”。

---

# 12:00–16:00｜1F｜生驹第一次回答“规定是什么”

生驹作为 3-A 学級委員，拿普通班务资料下楼去 1F 职员室。

一名 1-A 女生认出**入学式当天负责本班案内的学姐**，主动叫住她。

她早上被教师普通提醒过裙长，于是问：

> 学生手册写“膝部附近”，到底怎样算？

生驹把现行标准说清楚。

女生：稍微短一点也不行吗？

生驹此时仍自然认为：

> 在学校就按规定穿比较好。毕竟是学校的制服。

双方都有现实任务，谈话自然结束。

**功能：**生驹前半仍会从“规定是什么”自然延伸到“这身制服应该怎样被穿”。

---

# 16:00–25:00｜3-C 国文 / 古文｜一堂真的坐得住的课

武田正常上课，不输出人生演讲。

课堂真实包含：读、答、追问、答错、再读、板书、记笔记、短暂安静、铃响后把当前一句讲完。

まあ亚会把古语 / 正式表达理解错一层；高山本能想接笑但不必每次都救。

普通学生同样承担答对、答一半。

**有效片长锁：约 6–8 分钟即可。**

不为纸面时长增加第二套教学主题 / 金句。

---

# 25:00–30:00｜午休｜规则暂时输给吃饭

不谈制服。

南拉飞鸟去吃饭；生驹回到 3-A 普通班级关系；普通学生大量存在。

不专门切 1-A 女生证明她“也是普通学生”——越证明越会把她抬成议题角色。

有效片长约 3–4 分钟即可。

---

# 30:00–35:00｜3-C 体育｜身体换气

江口带篮球基础练习。

まあ亚看一次就较快抓到上篮步伐，但球可以不进。

江口只反馈动作，不给“原来你很厉害”的角色认证。

体育馆鞋、运动服只是正常课程装备，不作为 EP01 callback。

**功能：**换掉连续纸张 / 教室声音，也让观众看到学校能力尺度不只卷面；这层不说出来。

---

# 35:00–40:00｜3-D 下午HR｜飞鸟真的问“为什么”

普通 HR 已经有其他提交 / 教室 / 部活问题。

老师提醒学校生活调查今天放学前交，需要学校回答的问题写具体。

飞鸟问：

> 裙长为什么是“膝部附近”？

老师区分：

> 你问为什么要统一，还是为什么具体是这个长度？

飞鸟：后者。

老师说明学校确定知道的部分：制服作为正式服装，需要共同穿法。

对于“为什么历史上具体定在膝部附近”，老师不装懂：

> 当前不能替学校乱说；写具体一点，我帮你确认该由谁回答。

飞鸟听懂，但没有被完全说服。

**功能：**她第一次把脑中的吐槽交给真实制度接口。

---

# 40:00–44:00｜终礼 / 清扫｜飞鸟把剩余问题写进去

明日短测、作业、补交、清扫把注意力重新拉回日常。

飞鸟在清扫动作之间拿出早上一直空着的调查表。

她不复读刚才的问题，而是承认已得到的答案：

> 共同穿法的理由明白了；还想知道为什么具体是膝部附近。

表进入一叠普通调查，下一张马上盖上。

她继续清扫。

**飞鸟 M 到这里完成：退出 → 参与。**

---

# 44:00–50:00｜鞋柜 / 主楼出口｜生驹少说半句

放学人流。

上午的 1-A 女生看见生驹，**主动叫住 / 追两步**。

她不再问规则，而是问个人：

> `前辈自己的裙子，从来不折短吗？`

生驹：不折。

女生：因为规定？

生驹第一次把规则与自己分开回答：

> `……我自己也喜欢这样。`

女生：

> `我也很喜欢这身制服。只是我觉得短一点更好看。`

生驹仍然说现实后果：

> `在学校里还是会被老师说的。`

然后停止继续定义对方“应该怎样”。

两人各自回到朋友 / 高三人流，直接 CUT。

有效片长约 3–4 分钟，不硬撑六分钟。

**生驹 M：规则说清楚、自己的喜好也说清楚，然后停手。**

# 情绪曲线

```text
普通制服小提醒
→ 飞鸟暂时不参与
→ 学习时间压下来
→ 生驹按熟悉方式解释规则
→ 真正坐一堂课
→ 午休松开
→ 体育 / 身体换气
→ 飞鸟把问题问给成年人
→ 把剩余问题写进制度
→ 学妹主动问生驹“你自己怎么穿”
→ 生驹停在事实层
→ 人流 CUT
```

# Gate 4 核心锁

1. 不写成“守规矩生驹 vs 反规则飞鸟”；
2. 不使用大型服装检查；
3. 学生会没有纪律处分权；
4. 学习只保留晨间短测 + 一堂完整课 + 体育换气，不再第三轮证明；
5. 学校生活调查不是裙长专用机关；
6. 1-A 女生无名、普通、只有两次短接触；
7. 飞鸟听得懂成人答案，只继续追问没回答的部分；
8. 生驹不是批准违规，而是停止把个人归属经验变成学妹的唯一答案；
9. 本集不解决裙长规则是否修改；
10. 时间格是预算，不是 KPI。

**Gate 4：PASS。**
