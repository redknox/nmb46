# 四、生驹第一次出现在 1F｜PASS

高三教室位于 3F；1-A 与职员室位于 1F。

当前物理理由：

> 生驹作为 3-A 学級委員，手里已有普通班务资料，需要下楼交到 1F 职员室。

不需要新增“为了遇到学妹而被老师派下楼”的独立剧情场。

1-A 女生本来就在 1F 生活，因此双方位置自然交叉。

生驹没有：

- 检查裙长；
- 摸学妹制服；
- 行使纪律权。

她只回答学妹主动提出的规则问题。

# 五、1-A 女生如何认识生驹｜PASS after micro fix

初稿 S04 让她直接叫：

这属于不必要的隐藏信息。

已修为：

# 六、S04 → S10 两次接触｜PASS

- S10：前辈自己怎么穿。

信息没有重复。
