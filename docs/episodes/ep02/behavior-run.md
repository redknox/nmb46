# 一、核心压力不是“守规矩 vs 反叛”

如果把 EP02 写成：

> 生驹 = 守旧派
>
> 飞鸟 = 自由派

这一集会立刻扁平。

她们真正处理的是两个不同问题：

### 生驹

> **“怎样才算真正像这里的人？”**

她会本能地把“制服穿对”理解成成为乃木坂学生的一部分，因为她自己当年就是这样努力进入这套文化的。

### 飞鸟

> **“你要我做，可以；但为什么？”**

她不是想穿短裙，也不一定对裙长本人有强烈欲望。她真正被触发的是“一个规则要求所有人做同一件事，却没人愿意说明理由”。

因此两人不需要正面对线，也不需要互相说服。

同一条规则分别压中她们不同的地方即可。

---

# 二、生驹里奈｜M

## 默认算法

```text
看见学妹不熟悉学校标准
→ 认为“现在轮到我告诉她”
→ 立即给出正确做法
→ 如果对方仍然不标准，会想继续解释 / 示范
```

这与系列级“高年级应帮助低年级”传统完全一致，也正因为一致才危险：

> 她很容易把帮助责任做成“教别人怎样才像这里的人”。

## 裙摆压力进入后

最有效的新生不能是“故意挑战学校的坏学生”。

她应该同时满足：

- 正常上课；
- 会交作业；
- 对老师 / 学姐有基本礼貌；
- 真心喜欢新学校的某些东西；
- 只是觉得裙子短一点更好看 / 更像自己。

这样生驹第一次不能用：

> “她不珍惜这身制服。”

解释眼前的人。

## 第一反应

如果新生问她规定：

> 生驹会非常准确地告诉她学校标准。

这是正确行为，不应为了人物成长故意让她说错。

真正需要被挑战的是下一步：

> 她是否会继续把“你应该按规定穿”扩大成“这样才像乃木坂的人”。

## 本集行为变化

锁定方向：

```text
前段：规则 → 正确穿法 → 想继续教到“像这里”为止

后段：规则 → 把事实与后果说清楚 → 停手
```

她可以仍然认为制服应该按规定穿。

她改变的不是对规则的全部立场，而是：

> **不再把自己的归属经验当成学妹必须复制的路径。**

这足以构成 EP02 的 M，不提前完成整季归属弧。

# 三、斋藤飞鸟｜M

## 默认算法

```text
听见集体规则
→ 先判断有没有意义
→ 觉得理由廉价
→ 吐槽
→ 尽量退出
```

她的问题不是“不守规则”，而是：

> **凡事先要求意义，才肯认真进入。**

EP02 不能让她提前学会“不知道也可以做”。

## 最自然的制度接口

不要让飞鸟突然跑去学生会参加校则委员会。

更自然的是学校本来就存在一个低重量入口，例如：

- 新学年《生徒心得》意见调查；
- Home Room 的规则疑问栏；
- 各班收集需要说明 / 检视的条目。

这让她不需要“被剧情选中”。每个人都拿到同一张东西。

## 前段反应

她很可能：

- 看一眼；
- 觉得这种调查最后也不会改什么；
- 留空；
- 对认真填写的若月说一句风凉话。

## 谁最适合把她留在这条线上

### 若月｜C层摩擦

若月不会和她讨论青春意义，只会问：

> “有意见就写。没有就交。”

这会让飞鸟最烦，因为若月不接她的哲学吐槽，只把参与变成一个具体动作。

### 南｜A层安全区

南不负责说服。

如果飞鸟问：

> “你不觉得很麻烦吗？”

南最可能给出极其生活化的答案：

> “被老师说更麻烦。”

这种回答对飞鸟没有理论说服力，却能让场景回到生活。

## 本集行为变化

结尾方向锁定为：

```text
前段：觉得没意义 → 吐槽 → 留空

后段：仍然觉得有问题 → 把问题真正写进去 / 交出去
```

她没有接受规则。

她只是第一次承认：

> **既然我真的在意，那就不能永远站在制度外面笑。**

这就是 EP02 的 M。

# 四、秋元真夏｜S

同一个规则进入真夏，会立刻被理解成：

> “现行规定是什么？意见收集走哪个流程？谁负责汇总？”

她不应和飞鸟争论裙长美学。

更自然的功能是：

- 知道《生徒心得》意见怎样收；
- 能告诉别人“要问就写具体”；
- 把学生抱怨转换成可处理的文本 / 条目。

喜剧点：

> 飞鸟想讨论“意义”，真夏先问“你到底想改哪一条”。

但真夏不能成为本集问题解决者。

---

# 五、若月佑美｜S

若月的原则不是“规则永远正确”，而是：

> **已经存在的承诺 / 流程，在被正式改变以前就应当先按现行版本执行。**

她可以同时接受：

> “可以提修改意见。”

和：

> “今天规则还没改，所以今天先按现在的来。”

这使她非常适合与飞鸟制造真实 C 层摩擦，却不能写成第二个真夏或风纪委员。

---

# 六、星野南｜S

南不会把制服问题升级成价值观战争。

她最可能关心：

- 会不会被老师叫住；
- 改来改去麻不麻烦；
- 今天热不热；
- 坐下以后裙子舒不舒服；
- 能不能快点去吃饭。

她提供的是：

> **人可以生活在规则里，而不需要每天对规则形成理论。**

这是飞鸟很重要的对照，但不要让南变成“生活哲学导师”。

---

# 七、白石麻衣｜S

制服规范对白石的压力不在“她会不会违规”。

她几乎天然符合学校对外视觉标准。

真正的压力是：

> **别人可能把她当成“标准答案”。**

例如新生讨论裙长时，有人自然看一眼白石的制服；或者有人说“白石前辈就是这样”。

白石本人不需要发表制服理论。

她只要短暂感受到：

> 自己连裙摆长度都可能被别人当成“乃木坂应该长什么样”的证据。

这对 EP07 的“乃木坂之颜”只做 S 级预压，不展开。

---

# 八、生田绘梨花｜S

学习线给生田一个很自然的 S：

> 她会把课堂问题理解成“正确答案在哪里”，并真心困惑为什么别人还没懂。

最适合与まあや形成极短对照。

例如同一题：

- 生田已经算 / 背 / 听懂；
- まあや在一个书面语言节点卡住；
- 生田第一次解释仍然只是把正确步骤说得更快；
- まあや继续一脸空白。

不要在 EP02 完成“生田学会尊重不同学习方式”的大弧。

只让观众第一次具体看到：

> **她的高标准不是恶意，但确实可能让别人喘不过气。**

# 九、和田まあや × 高山一実｜S / S

## まあや

本集必须允许她真实考差 / 听错 / 不会。

不能为了证明“她其实很聪明”安排突然逆袭。

她的优势应该出现在另一种任务里，例如：

- 实际整理；
- 动手；
- 身体模仿；
- 一看就会的现场操作。

不是为了补偿分数，而是提醒：学校测量能力的尺并不只有一种。

## 高山

高山最自然地把まあや的失败变成班级能笑一下、继续上课的空气。

但她不能每一次都救场。

EP02 可以第一次很轻地让她发现：

> まあ亚真的不会时，不是每次都需要立刻把它变笑话。

仍然只是 S，不提前做 EP11 的最终变化。

# 十、制服线中的普通新生｜功能锁

这个新生非常重要，但镜头权必须受控。

她不能成为：

- 第二女主；
- “新时代学生代表”；
- 专门发表自由宣言的人；
- 被一期生教育的议题装置。

她只需要是一个正常的一年级女生：

> **喜欢学校，但也想把制服穿得更像自己。**

她的存在是为了让生驹无法继续把两个事实绑定：

> 穿得标准 = 珍惜学校

而不是为了证明学校错。

---

# 十一、学校 / 教师｜行为锁

教师不能被写成稻草人。

如果飞鸟问“为什么”，学校一侧至少应能给出真实立场，例如：

- 指定制服是共同生活中的正式服装；
- 学校希望不同家庭背景的学生在校内有一个共同外观基线；
- 典礼、校外活动与日常之间保持可识别的一致性；
- 这是学校长期审美 / 礼法的一部分。

飞鸟完全可以继续觉得这些理由不充分。

**冲突来自价值权重不同，不来自成年人不会思考。**

---

# 十二、学习日如何进入人物，而不是 montage 清单

建议把学习压力分散给不同人：

- 晨间小测：まあや / 生田；
- 普通课堂：全班正常上课，飞鸟成绩并不差；
- 作业 / 提交：真夏、若月对流程熟；
- 午后困倦：南；
- 老师拖堂：所有人都烦，名门学生也一样；
- 清扫：普通学生与命名角色共同做。

关键原则：

> **人物不是为了展示设定才学习；她们今天本来就有这些课。**

---

# 十三、Gate 2｜允许进入 Beat Sheet 的因果发动机

以下因果组合符合人物与制度，不是强行剧情：

1. 普通教学日开始；制服规则通过日常生活自然显形；
2. 一名普通一年级女生把裙摆穿得明显短于学校标准，被教师正常提醒；
3. 生驹因前后辈日常接触进入这条线，但没有纪律权；
4. 她发现这个新生并不符合自己预设的“叛逆 / 不珍惜学校”解释；
5. 同期所有班级正常收到新学年《生徒心得》意见 / 疑问收集入口；
6. 飞鸟最初把它当无用流程，后来仍把自己的问题真正写进去；
7. 学习生活不是支线，而是让“规则是每天重复执行的东西”在身体上成立；
8. 本集不必决定裙长规则是否修改。

这套发动机不要求：

- 学生会越权；
- 全校大规模服装检查；
- 新生公开反抗；
- 飞鸟成为改革领袖；
- 生驹公开道歉 / 发表成长演说。

**Gate 2：PASS。**
