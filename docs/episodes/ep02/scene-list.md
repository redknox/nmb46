# 总体连续性原则

> **先让一整天真的过去，再让“规则”从这一天里自己长出来。**

本集禁止形成：

```text
裙长剧情
→ 学习证明
→ 裙长剧情
→ 学习证明
→ 校规辩论
```

正确观看感应更接近：

```text
上学
→ 被提醒一下
→ 朝HR
→ 做题
→ 一个学姐回答实际问题
→ 真的上一堂课
→ 吃饭
→ 动起来
→ 下午HR里终于问一句“为什么”
→ 清扫 / 收表
→ 放学时把另一个问题问完
→ 人流把大家带走
```

生驹与飞鸟两条线不交叉，也不互相代表正反立场。

## S01｜00:00–03:00｜一年级洗手间 / 走廊｜“裙子。”

普通登校后。

一年级洗手间 / 镜子附近，两名普通新生整理制服。

其中一人把裙腰内折一层。

朋友只提醒：可能会被说。

她们出去。

走廊教师经过，低强度一句：

> `「スカート。」`

女生马上知道意思，放下来。

教师不停。

TITLE 压在重新流动的走廊上。

### 连续性

- 两名女生都不是后续生驹线的 1-A 女生；
- 不给姓名，不建立“短裙新生”支线；
- 这是学校里会反复发生的小调整之一。

---

## S02｜03:00–06:00｜3-D 朝HR｜学校生活调查进入桌面

普通朝 HR。

担任发 `新年度 学校生活アンケート`。

表不是裙长专用；版面上制服 / 生徒心得只占一个普通意见栏。

飞鸟扫到该栏，暂时空着。

若月已经正常确认姓名、提交位置和截止方式。

南只从“被老师提醒很麻烦”的生活尺度看规则。

担任继续点其他事项。

### 连续性

调查表进入飞鸟文件夹，此后一直存在到下午回收。

**中间不做“它还在”的提醒插镜。**

## S03｜06:00–12:00｜晨间学习 sequence｜3-C 为主 / 3-D 极短

### 3-C

晨间短测真正开始。

题纸、计时、笔声。

まあ亚在正式书面语言上卡住；高山注意到，但不把每一次不会都做成笑点。

真夏准备齐全；西野安静做自己的。

### 3-D｜极短插

同一学校时间。

飞鸟正常答题。

### 结束

收卷 / 铃声 / 第一轮课程转换。

### 连续性锁

- 不切 3-B 生田；
- 不再追加第三、第四个班证明“大家都在学”；
- 学习 sequence 要让观众经历一点时间，而不是角色点名 montage。

## S04｜12:00–16:00｜1F 职员室附近 / 主走廊｜生驹第一次回答

上午某节课后。

3-A 担任把一份普通班务资料交给学級委員生驹，让她顺路送到 1F 职员室。

这不是剧情任务，只是她作为班级代表会承担的普通琐事。

生驹下楼。

1F 本来就是高一班级、职员室、行政与保健区域混在一起的公共层。

一名 1-A 女生看见昨天案内过自己的生驹，主动叫住她。

她早上已经被教师普通提醒过一次裙长，因此问：

> 学生手册的“膝部附近”实际怎样算？

生驹把现行规则说清楚。

女生再问：稍微短一点也不行吗？

生驹仍会自然回答：既然是学校的制服，在校内就应该按规定穿。

没有争论。

生驹还拿着要交职员室的资料；女生也有自己的下一节课。

双方很自然地结束，继续各自路线。

### 连续性锁

- 1-A 女生问生驹的理由来自 EP01 已建立的“昨天案内 / 不懂可以问学姐”；
- 生驹出现在 1F 的理由来自学級委員普通班务，而不是摄影机把她传送下来；
- 生驹不检查她，不摸裙摆，也不获得纪律权；
- 不单独拍“老师把文件交给生驹”的前置场，必要信息在本场开头一个动作里完成。

## S05｜16:00–25:00｜3-C 国文 / 古文｜一堂真的坐下来的课

本集最长的单一生活 sequence 之一。

武田正常上课。

不是“武田金句时间”。

课堂内部持续发生小变化：

- 点人读 / 答；
- 追问；
- 背诵；
- 答错；
- 翻页；
- 记笔记；
- まあ亚误解一个正式表达；
- 高山本能想接笑，必要时只接半步；
- 普通学生同样会答错、答对、被点名；
- 有人短暂走神再回来。

下课铃响。

武田多讲一点，把最后一句讲完才放人。

### 连续性锁

九分钟只是上限预算。

如果课堂在六七分钟已经读完，**直接下课，不为凑时长新增笑点或第二个教学主题。**

允许真正存在：板书、学生找页、等待回答、安静写字、老师在桌间移动。

核心是课堂持续存在，不是信息密度。

## S06｜25:00–30:00｜午休｜学校先吃饭

四班午休重新混流。

不讨论制服主题。

飞鸟的调查表仍在文件夹里，但不做插镜提醒。

南和飞鸟按原有关系行动；生驹回到 3-A 的普通同学关系。

食堂 / 教室 / 回廊以普通学生承担大量画面。

### Gate 6 减法

**不专门切到那名 1-A 女生证明“她也在普通生活”。**

她的普通性不需要第三次露脸来证明；越证明越会把她抬成议题角色。

## S07｜30:00–35:00｜3-C 体育｜换一种观看任务

下午体育课。

江口正常带课。

学生已经换成运动服，制服 / 裙摆暂时从身体上消失。

本段首先是整个班在上体育课：集合、示范、练习、失败、重来、流汗、有人动作慢一点。

まあ亚在早上的书面题上容易卡住，但这里对动作示范 / 身体模仿进入得很快。

她只需要自然做对一次或比旁边的人更快抓到动作。

**没有：**

- 全班惊讶；
- “原来まあ亚其实很厉害”的补偿台词；
- 江口用她做主题示范；
- 分数反转。

高山和普通同学继续一起上课。

### 连续性

- 运动服、体育馆鞋等作为正常课程装备出现，不标记成 EP01 callback；
- 江口是教师，不承担本集主题解释；
- 虽然 3-C 在本集承担较多“学校生活”画面，但它没有人物 M；M 仍然发生在生驹 / 飞鸟各自的规则关系中。

## S08｜35:00–40:00｜3-D 下午HR｜飞鸟把“为什么”问出口

一天后半。

担任正常处理几项事务。

有人先问别的问题：明天要交什么、某张表写哪里、部活集合是否变化。

其中一项才是：

> 今天的学校生活调查要交；需要学校回答的问题写具体一点。

飞鸟的自由记述栏仍空着。

老师准备进入下一项前，她开口：

> 裙长为什么以“膝部附近”为标准？

担任给本校真正相信的最低限度理由：指定制服作为共同正式服装，需要维持一个共同外观基线；这也是长期校风 / 对外呈现的一部分。

只说够用的一两层。

飞鸟听明白。

**听懂不等于认同。**

她仍然觉得“共同服装”并没有完全回答“为什么具体是膝部附近”。

若月不替教师辩。

老师已经继续下一件事。

### 连续性锁

- HR 不是为飞鸟准备；
- 她的问题发生在其他普通问题之间；
- 教师不成为稻草人；
- 飞鸟不代表全班；
- 不用全班突然安静、齐刷刷看她来抬高戏剧性。

---

## S09｜40:00–44:00｜终礼 / 清扫｜从“问过”走到“写进去”

HR 继续。

明日短测 / 作业 / 提交物等普通通知进入。

随后清扫 / 整理：

- 黑板；
- 桌椅；
- 值日；
- 补交；
- 忘记拿东西；
- 普通学生互相叫人。

飞鸟在这些动作之间把调查表拿出来。

她**不把刚才的问题原样抄一遍**。

最终文字方向应体现她确实听了老师的回答，例如：

> “共同着装的理由明白了。还想知道为什么具体以膝部附近为标准。”

Screenplay 再压成更自然、更飞鸟的句子；这里先锁逻辑。

这比“废除校规”小得多，也比重复问句更具体。

表被若月 / 班级负责学生和其他调查一起收走。

很快就看不出哪张是飞鸟的。

### 连续性锁

飞鸟 M 到这里完成。

> **她不是没听答案；正因为听了，才知道自己还剩哪一部分没被说服。**

后面不再给她意义总结场。

---

## S10｜44:00–50:00｜鞋柜 / 主楼出口 / 放学流｜学妹主动把问题从“规定”问到“你自己”

不同年级以不同速度离校。

鞋柜 / 主楼出口是所有人自然经过的公共节点。

上午那名 1-A 女生先看见生驹。

她主动叫住 / 追两步。

不是为了继续问学生手册。

更生活化的问题锁定为类似：

> “前辈自己的裙子，从来不折短吗？”

这比“你觉得哪个长度最好看”更像十几岁女生真的会问的个人问题。

生驹可以很自然地回答：

> 她自己喜欢现在这样穿。

女生也很自然：

> 她也很喜欢这身制服；只是自己觉得短一点更好看。

生驹仍然把现实后果说清楚：

> 在学校里偏离规定，老师还是会提醒。

然后停。

她不再补：

> “所以那样才像乃木坂学生。”

女生没有得到“可以违规”的许可，也没有被教育成另一种人。

两个人换鞋、拿包，各自回到朋友 / 同学的人流。

摄影机不再另起一个 S11 来说明“学校继续”。

出口、社团方向、走廊仍然有人。

调查表也已经和别的学校文件一起被正常收走。

不拍校方反应，不设计最后一句金句。

人流自然把两条人物线一起吞回学校生活。

CUT。

### 连续性锁

- 第二次见面靠公共出口解决物理位置；
- 真正的主动动作来自学妹叫住生驹；
- 个人问题替代主题问题；
- 生驹的变化通过“少说了后半句”成立；
- 1-A 女生到此为止，不获得名字或独立结尾镜头；
- 结尾不再加一个“学校继续”的解释性 sequence。

# Gate 6 压力测试结论

## GREEN｜连续生活成立

没有发现：

- 人物瞬移；
- 为规则专门召开的剧情会议；
- 学生会越权；
- 1-A 女生突然获得过大剧情重量；
- 学习与制服机械轮流打卡；
- 两个 M 必须正面对线才能成立。

## Gate 6 已解决的 YELLOW

### 1. S04 跨年级相遇的空间理由

第一版只写“换教室流动”，略泛。

现在具体化为：

> **生驹作为3-A学級委員下楼交普通班务资料 → 1F本来就是高一与职员室共同生活层 → 1-A女生看见昨天认识的案内学姐。**

不新增独立前置场。

### 2. S05 九分钟课堂可能被硬填满

锁定：九分钟是上限预算，不是 KPI。

课堂如果六七分钟已经成立就离开，不加第二个知识点 / 第二套笑点填时长。

### 3. S07 まあ亚“补偿式证明”风险

锁定：只让她自然进入动作一次，不让任何人指出“原来你其实很厉害”。

### 4. S08 HR 太像为飞鸟搭台

修正为其他普通问题先存在，生活调查只是其中一项；飞鸟的问题不改变全班运行。

### 5. S08 → S09 信息重复

修正为：

> 老师回答“为什么需要共同制服基线”
>
> → 飞鸟听懂
>
> → 她写下“为什么具体是膝部附近”这一层剩余问题。

因此“问”与“写”是两步，不是复读。

### 6. S10 学妹提问过于主题化

从：

> “前辈觉得哪个长度最好看？”

降为更生活的：

> **“前辈自己的裙子，从来不折短吗？”**

主题由答案之间的差异自己产生。

### 7. 独立 S11 过度收束

删除。

S10 完成以后直接让两人回到普通出口人流，CUT。

### 8. 3-C 画面重量

3-C 承担晨间学习、完整国文课与体育课，纸面比其他班多；但这些段落承担的是**学校生活基线**，不是人物剧情推进。

Treatment 必须继续控制：

- 不让高山 / まあ亚因为镜头多自动变 M；
- 不把每个 3-C 段落都写成她们的角色小品；
- 普通学生与教师持续分担画面。

当前判定可接受。

# Gate 6 锁定规则

进入 Treatment 后：

1. S01 的普通新生不与后续 1-A 女生合并；
2. S04 不增加生驹“检查裙长”的动作；
3. S05 不为片长添加额外知识点 / 金句；
4. S07 不拍成まあ亚能力反转；
5. S08 不用全班反应抬高飞鸟提问；
6. S09 的书面问题必须体现她听过教师回答；
7. S10 的学妹问题保持私人 / 生活化，不替作者问主题；
8. 生驹只完成“停止扩大解释”，不变成反规则；
9. 飞鸟只完成“从退出到参与”，不接受“没有理由也可以”；
10. 规则是否修改继续留到本集之外。

**Gate 6：PASS。**
