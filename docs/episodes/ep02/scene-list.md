# 总体连续性原则

> **先让一整天真的过去，再让“规则”从这一天里自己长出来。**

本集禁止形成：

```text
裙长剧情
→ 学习证明
→ 裙长剧情
→ 学习证明
→ 校规辩论
```

正确观看感应更接近：

```text
上学
→ 被提醒一下
→ 朝HR
→ 做题
→ 换教室
→ 问学姐一个实际问题
→ 真的上一堂课
→ 吃饭
→ 动起来
→ 下午HR里终于问一句“为什么”
→ 清扫 / 收表
→ 放学时把另一个问题问完
→ 人都走了
```

生驹与飞鸟两条线不交叉，也不互相代表正反立场。

## S01｜00:00–03:00｜一年级洗手间 / 走廊｜“裙子。”

普通登校后。

一年级洗手间 / 镜子附近，两名普通新生整理制服。

其中一人把裙腰内折一层。

朋友只提醒：可能会被说。

她们出去。

走廊教师经过，低强度一句：

> `「スカート。」`

女生马上知道意思，放下来。

教师不停。

TITLE 压在重新流动的走廊上。

### 连续性

- 两名女生都不是后续生驹线的 1-A 女生；
- 不给姓名，不建立“短裙新生”支线；
- 这是学校里会反复发生的小调整之一。

---

## S02｜03:00–06:00｜3-D 朝HR｜学校生活调查进入桌面

普通朝 HR。

担任发 `新年度 学校生活アンケート`。

表不是裙长专用；版面上制服 / 生徒心得只占一个普通意见栏。

飞鸟扫到该栏，暂时空着。

若月已经正常确认提交位置 / 姓名。

南只从“被老师提醒很麻烦”的生活尺度看规则。

担任继续点其他事项。

### 连续性

调查表进入飞鸟文件夹，此后必须一直存在，直到下午回收；中间不需要每场提醒观众它还在。

---

## S03｜06:00–12:00｜晨间学习 sequence｜3-C 为主 / 3-D 极短

### 3-C

晨间短测真正开始。

题纸、计时、笔声。

まあ亚在正式书面语言上卡住；高山注意到，但不把每一次不会都做成笑点。

真夏准备齐全；西野安静做自己的。

### 3-D｜极短插

同一学校时间。

飞鸟正常答题。

南开始困。

### 结束

收卷 / 铃声 / 第一节课转换。

### 连续性锁

- 不切 3-B 生田；
- 不再追加第三、第四个班证明“大家都在学”；
- 学习 sequence 要让观众经历一点时间，而不是角色点名 montage。

---

## S04｜12:00–16:00｜换教室流动 / 中央楼梯与走廊｜生驹第一次回答

某节课转换。

高一学生正去特别教室 / 体育设施方向，高三学生也有不同教室流动。

因此不同年级在中央楼梯 / 主走廊自然交叉。

一名 1-A 女生认出昨天案内的生驹，主动叫住她。

她早上被教师普通提醒过一次裙长，因此问：

> 学生手册的“膝部附近”实际怎样算？

生驹把现行规则说清楚。

女生再问：稍微短一点也不行吗？

生驹仍会自然回答：既然是学校的制服，在校内就应该按规定穿。

没有争论。

下一节课铃 / 同伴叫人，双方继续各自路线。

### 连续性锁

- 1-A 女生问生驹的理由来自 EP01 已建立的“昨天案内 / 不懂可以问学姐”；
- 她不是为了见生驹跨三层楼找人；
- 第一次相遇发生在双方本来就需要经过的换教室流线上；
- 生驹不检查她，不摸她的裙摆，也不获得纪律权。

---

## S05｜16:00–25:00｜3-C 国文 / 古文｜一堂真的坐下来的课

本集最长的单一生活 sequence 之一。

武田正常上课。

不是“武田金句时间”。

课堂内部持续发生小变化：

- 点人读 / 答；
- 追问；
- 背诵；
- 答错；
- 翻页；
- 记笔记；
- まあ亚误解一个正式表达；
- 高山本能想接笑，必要时只接半步；
- 普通学生同样会答错、答对、被点名；
- 有人短暂走神再回来。

下课铃响。

武田多讲一点，把最后一句讲完才放人。

### 连续性锁

这九分钟纸面预算不要求全靠对白填满。

允许：板书、学生找页、等待回答、安静写字、老师在桌间移动。

核心是课堂持续存在，不是信息密度。

---

## S06｜25:00–30:00｜午休｜学校先吃饭

四班午休重新混流。

不讨论制服主题。

飞鸟的调查表仍在文件夹里，但不做插镜提醒。

南和飞鸟按原有关系行动；生驹回到 3-A 的普通同学关系。

食堂 / 教室 / 回廊以普通学生承担大量画面。

### Gate 5 减法

**不专门切到那名 1-A 女生证明“她也在普通生活”。**

她的普通性不需要第三次露脸来证明；越证明越会把她抬成议题角色。

---

## S07｜30:00–35:00｜3-C 体育 / 实技｜换一种观看任务

下午某节实技课。

优先方案：3-C 体育课，江口正常带课。

学生换成运动服，制服 / 裙摆暂时从身体上消失。

まあ亚在书面题上容易卡住，但动作示范 / 身体模仿上进入得很快。

不要安排“全班惊讶原来她很厉害”的补偿性高潮。

她只是比刚才在纸面上更顺。

高山和普通同学继续一起上课。

### 连续性

- 运动服、体育馆鞋等作为正常课程装备出现，不标记成 EP01 callback；
- 江口是教师，不承担本集主题解释；
- 这段首先负责身体和声音换气。

---

## S08｜35:00–40:00｜3-D 下午HR｜飞鸟把“为什么”问出口

一天后半。

担任在普通 HR 中收束几项学校事务，其中包括：

> 今天的学校生活调查要交；有需要学校回答的问题，写具体一点。

飞鸟的自由记述栏仍空着。

她没有先写。

而是直接问：

> 裙长为什么以“膝部附近”为标准？

担任给本校真正相信的最低限度理由：共同正式服装 / 共同外观基线 / 校风与对外呈现中的一部分。

只说足够成立的一两层，不列三点论证。

飞鸟听明白，但没有表现“被说服”。

若月不替教师辩，只在后来提醒：

> 如果还想问，就写在表里。

担任已经继续下一项。

### 连续性锁

- 这不是“校规说明会”；
- 飞鸟的问题只占普通 HR 的一小段；
- 教师不成为稻草人；
- 飞鸟不代表全班，其他学生可以有自己的事情要处理。

---

## S09｜40:00–44:00｜终礼 / 清扫｜问题重新掉回日常

HR 继续。

明日短测 / 作业 / 提交物等普通通知进入。

然后清扫 / 整理：

- 黑板；
- 桌椅；
- 值日；
- 补交；
- 忘记拿东西；
- 普通学生互相叫人。

飞鸟在这些动作之间把调查表拿出来。

自由记述栏从空白变成一句具体问题：

> 想知道裙长为什么以膝部附近为标准。

最终文字留到 Screenplay。

表被若月 / 班级负责学生和其他调查一起收走。

很快就看不出哪张是飞鸟的。

### 连续性锁

飞鸟 M 到这里已经完成。

后面不再给她一个“意义总结场”。

---

## S10｜44:00–48:00｜鞋柜 / 放学流｜1-A女生主动叫住生驹

不同年级已经以不同速度离校。

鞋柜 / 主楼出口是所有人都可能自然经过的公共节点。

上午那名 1-A 女生先看见生驹。

这一次不是巧遇以后顺便聊，而是她**主动叫住 / 追两步**：

> 还有一个想问的。

问题从制度变成个人：

> “前辈自己觉得现在这个长度最好看吗？”

生驹可以回答：

> 她自己喜欢这样穿。

女生也很普通地说：

> 她也喜欢乃木坂的制服，只是自己觉得短一点更好看。

生驹仍然把现实后果说清楚：

> 在学校里偏离规定，老师还是会提醒。

然后停。

她不再补“所以那样才像乃木坂学生”。

女生没有得到“可以违规”的许可，也没有被教育成另一种人。

两个人各自继续换鞋 / 离开。

### 连续性锁

- 第二次见面靠公共出口解决物理位置；
- 真正的主动动作来自学妹“叫住”，不是编剧让两人再次随机撞上；
- 这名学生不再进入第三个独立人物场。

---

## S11｜48:00–50:00｜放学整体｜学校没有为了规则停下来

调查表已经随其他学校文件进入正常回收流程。

不用拍“校方收到飞鸟意见”的反应。

鞋柜、主楼出口、社团方向仍有人流。

刚刚与生驹说话的 1-A 女生已经回到自己的朋友流里。

飞鸟也已经是放学人流中的一个普通高三生。

明日短测、作业、社团、忘带东西等声音仍然存在。

不设计最后一句金句。

CUT。

> **规则没有改变；这一天已经完整地过完。**

这句话只存在于编剧层。
