# 一、结论

EP02 的“制服 / 裙摆 + 真正学习生活”现实基础成立。

可以可信地采用：

- 学校明确规定指定制服的穿着方式；
- 裙长可规定在膝部附近；
- 禁止永久改造制服，也可要求不得通过折腰等方式故意改变规定外观；
- 教师在日常生活中进行低强度、持续性的服装提醒；
- 校则需要能够说明教育目的，并应随社会与学生情况持续检视；
- 学生 / 保护者参与校则检视是现实可行且被鼓励的做法；
- 最终制定 / 修改校则的制度责任仍在学校 / 校长，不在学生会；
- 晨间学习、读书、小测、课题学习、6–7节课、终礼、清扫、放课后自习都是真实可用的高中日常。

因此 Gate 1 通过。

# 二、校则与制服｜现实边界

文部科学省当前《生徒指導提要》及校则检视资料的核心方向是：

> 校则应在学校教育目的所必需、合理的范围内制定；社会、学校与学生状况变化后，应持续检视是否仍有必要、能否说明其意义。

同时，校则最终属于学校教育责任范围，但在制定 / 检视时听取学生与保护者意见是现实且被鼓励的做法。

这给本集一个重要边界：

> **可以有严格制服规定；但不能把“因为从以前就是这样”当成学校唯一能说出的制度依据。**

如果飞鸟追问规则理由，成年人必须至少能够说出学校真正相信的理由，哪怕飞鸟仍然不认同。

### 现实参考

现实高中公开规则中确实可见：

- 指定制服；
- 裙长“膝头附近 / 膝盖处”；
- 禁止裁短、改造或改变指定样式；
- 领结 / 领带、校章、外套等具体着装要求。

因此乃木坂女学院可以可信地锁定类似规范：

> **裙摆以膝部附近为标准，制服不得永久加工；穿着时不得故意把裙摆折到明显偏离规定长度。**

精确文字等进入 Scene List / Treatment 后再决定，不需要现在把学生手册写成法律条文。

# 三、谁有权“管裙摆”

这是本集最重要的权限锁。

## 教师 / 学校

可以：

- 日常看到后提醒；
- Home Room 统一说明；
- 必要时由担任 / 生徒指导担当继续处理；
- 对反复违反规定的学生按学校既有流程沟通。

现实学校可见“每天早晨在昇降口进行头发 / 服装声挂け指导”等做法，因此日常提醒比“一年一次大型服装检查大会”更可信。

乃木坂女学院不必照搬门口检查；本校更适合把规范分散在：

> 担任一句提醒、走廊老师一句“裙子”、本人自己放下来、班级里同学已经知道什么意思。

这样既严格，也不把学校拍成纪律主题公园。

## 学生会

学生会**没有一般纪律处分权**。

可以：

- 收集学生对《生徒心得》的意见；
- 参与学校安排的校则检视讨论；
- 代表学生形成意见；
- 协助把已确认规则传达清楚。

不能：

- 站在校门口自行量全校裙长；
- 因为“学生会”身份处罚普通学生；
- 取代教师执行生徒指导。

## 普通高年级 / 生驹

系列级既有锁定继续有效：

> **学姐有帮助责任，没有统治权。**

生驹可以告诉新生：

> “学校规定是这样。”

她不能因为自己珍惜传统，就获得替学妹检查 / 命令 / 处分制服的权力。

这条边界本身正好能给她人物压力。

# 四、校则检视是否可以进入剧情

可以，而且现实上成立。

文科省明确鼓励：

- 校则公开；
- 定期检视；
- 学生有讨论机会；
- 学生 / PTA 等以某种方式参与；
- 通过讨论让学生理解规则、形成主体性。

因此如果 EP02 需要让飞鸟从“吐槽”走到“参与”，可以使用低戏剧强度机制，例如：

- 新学年惯例的《生徒心得》意见征集；
- Home Room 填一张“有疑问的规则”小调查；
- 学生会受学校委托整理学生意见；
- 某条制服规则在班会 / 委员会里被要求说明理由。

不要拍成：

> 飞鸟一句话 → 全校紧急改革裙长规定。

更可信的是：

> **她第一次把吐槽写成一条真正会进入制度流程的问题。**

是否改规则，不必在本集解决。

# 五、“这里真的要上学”｜日常学习现实

现实私立 / 女子学校的公开一日流程可以支持本集需要的节奏：

- 8点前后登校；
- 朝礼 / 朝学習；
- 朝读书、小测、课题学习；
- 上午4节；
- 午休；
- 下午2–3节；
- 终礼；
- 学生清扫；
- 放课后部活 / 补习 / 自习。

部分学校明确把“小测试”放进晨间学习，也有女子校按单元安排确认测试。

因此 EP02 可以自然使用：

- 晨读；
- 英语单词 / 听写小测；
- 古文背诵；
- 数学短测；
- 作业提交；
- 补交；
- 午后困倦；
- 终礼；
- 清扫；
- 放课后自习。

但**不能因为我们终于要证明她们会学习，就在同一天把所有学校生活项目全塞一遍。**

现实基线允许很多东西存在；Beat Sheet 只应选择最能形成节奏的少数几项。

# 七、制服规则的社会温度

本集不能把裙摆写成：

> “短裙 = 坏学生 / 不珍惜学校。”

学校规则讨论的是：

- 指定制服的共同外观；
- 正式场合与日常的秩序；
- 学校对外呈现；
- 长期传统；
- 学生是否理解 / 接受规定。

学生本人仍然可以：

- 真心喜欢学校；
- 成绩很好；
- 对学姐有礼貌；
- 同时觉得裙子短一点更好看。

这点必须成立，否则生驹的压力测试会被写成“好学生教育坏学生”，人物弧立刻失效。

# 九、Gate 1 硬锁

进入人物行为跑测后默认遵守：

1. **制服规则由学校制定 / 教师执行，不把纪律权塞给学生会或学姐。**
2. **学生可以参与校则检视，但参与不等于拥有最终决定权。**
3. **裙摆违规不等于人格 / 归属判断。**
4. **学校严格，但不通过公开羞辱制造戏。**
5. **学习生活必须真实占据时间，但不机械把“晨读、考试、作业、值日”逐项打卡。**
6. **教师若被飞鸟问“为什么”，不能只回答“因为规定就是规定”；至少要有一个本校真正相信的制度理由。**
