# 一、表层发生什么

入学式之后，学校第一次真正进入普通教学日。

新生开始从“穿上乃木坂女学院制服”进入“每天都要穿着它生活”的阶段。有人已经在试着把裙摆折短一点、调整领结、改变穿法；高三学生则早已形成自己的穿衣习惯与对校规的距离。

与此同时，EP02 必须第一次认真拍：

> **这所学校真的要上学。**

晨间学习、古文 / 英语 / 数学、小测、听写、作业、值日、补交、午后犯困、自习、老师拖堂等，不作为背景装饰，而成为整集时间本身。

# 二、这一集真正改变什么

本集不是“制服规定到底正确还是错误”的辩论赛。

真正要推进两件事：

## 1. 生驹｜归属与“像不像这里的人”第一次被拆开

EP01 只让观众看到：三年前的生驹非常怕自己哪里做得不对。

EP02 第一次正面压力测试她的错误信念：

> **“只要足够像乃木坂女学院的学生，才算真正属于这里。”**

当一个新生明显愿意待在这里、也认真过学校生活，却没有把制服穿成生驹心里最标准的样子时，生驹不能继续把“遵守制服外观”与“是否珍惜学校 / 是否属于这里”自动视为同一件事。

本集不要求她完成整季最终认识，但至少必须发生一次行为顺序变化：

> 从“看见不标准 → 想马上教她正确做法”
>
> 走到“先把规则与后果说清楚 → 不再替对方决定她应该成为什么样的人”。

## 2. 飞鸟｜从旁观式吐槽走向参与式质疑

飞鸟不是因为想叛逆才讨厌校规。

她真正无法忍受的是：

> **“为什么必须这样？”得到的回答只是“因为一直这样”。**

EP02 是她长弧的第一处 M：她不会突然接受“没理由也可以遵守”，那属于很后面的成长。

这里真正的变化应是：

> 从“觉得规则没意义 → 吐槽 → 与我无关”
>
> 变成“觉得规则没意义 → 真的去问它为什么存在 / 谁决定 / 能不能改”。

也就是说，她第一次因为不认同而**参与**，而不是因为不认同就退出。

# 三、人物受力｜M / S / L / R

依照季级受力矩阵，本集核心：

### M｜主推进

- **生驹里奈**
- **斋藤飞鸟**

两人不是正反方辩手。

生驹问的是：

> “如果不像这里的人，还算属于这里吗？”

飞鸟问的是：

> “如果一条规则说不清为什么，我为什么要把它当成理所当然？”

### S｜次推进 / 明显受压

- 白石麻衣
- 生田绘梨花
- 秋元真夏
- 星野南
- 和田まあや
- 高山一実
- 若月佑美

这些人物通过“制服规则 + 真正上课”被照亮，但不能抢走生驹 / 飞鸟的 M。

### L / R

其余人物允许只是同学：上课、交作业、吃饭、被老师叫、发呆、借笔、回班、离校。

本集不欠17个人制服立场。

# 四、本集必须建立的学校事实

EP01 建立的是：

> **这是一所漂亮、严整、真的会运转的学校。**

EP02 必须补上：

> **这种严整不是只在典礼和校门口存在，它每天都要通过课程、作业、时间表、校规和身体习惯被重新做一遍。**

因此制服线与学习线必须属于同一个主题，而不是 A/B 两条互不相干的故事：

> 你每天把领结系好、裙摆穿到规定位置；
>
> 也每天坐下、背、写、交、考、重来。

“名门感”不是漂亮布景，是持续的重复劳动。

# 五、本集禁止提前消费

## 生驹

禁止直接完成：

> “我本来就属于这里，学校也因为我改变。”

EP02 只拆开“像这里”与“属于这里”，不完成毕业级归属回收。

## 飞鸟

禁止提前完成：

> “不知道为什么也可以认真做。”

那是 EP08 → EP12 的核心回收。

本集她仍然需要理由；变化只是她愿意进入规则本身，而不是站在外面嘲笑。

## 白石

不再重复“所有人都在看她”的 EP01 笔触；本集只让制服规范轻微压到她作为学校视觉标准的身份，不开启 EP07 的完整弧。

## 生田

不把学习 / 小测再次写成“正确限制她”的完整音乐寓言。她可以认真到过头、标准过高，但 EP04 才处理核心音乐问题。

# 六、结尾需要增加什么，而不是总结什么

本集结束以后，观众应该比开头多知道：

1. 乃木坂女学院的制服不是 cosplay，而是一套每天真实执行的生活规则；
2. 学生并不会因为来自名门家庭就逃过小测、作业、补交和困倦；
3. 生驹非常珍惜“穿得像这里的人”这件事，但开始意识到这和“是不是这里的人”并不完全相同；
4. 飞鸟嘴上最嫌规则麻烦，却第一次因为真的在意而进入规则讨论。

观众不需要得到统一答案：

> “裙摆到底应该多长？”

这一集更重要的是第一次让她们问：

> **这所学校每天要求我们这样做——那我们和这些要求到底是什么关系？**
