# 一、总判定

EP02 当前节奏成立。

它不是事件驱动集，观看动力来自：

> **同一个普通上课日不断换任务，但人物仍在同一套学校规则里生活。**

当前大节奏：

```text
制服 / 走廊（轻）
→ 朝HR / 纸（制度）
→ 晨间短测（安静）
→ 生驹第一次对话（短人物）
→ 长课堂（停下来）
→ 午休（松）
→ 体育（身体 / 声音换气）
→ 飞鸟提问（本集制度峰值）
→ 清扫中写表（降回生活）
→ 鞋柜私人问题（人物收束）
→ 人流 CUT
```

没有需要新增事件的节奏洞。

---

# 二、前 16 分钟｜GREEN

S01–S04 连续使用：

- 规则；
- 表格；
- 小测；
- 学姐回答。

纸面看上去制度密度很高，但感知输入不同：

- S01 站立 / 镜子 / 走廊；
- S02 班级说话；
- S03 安静写题；
- S04 走动中的短对话。

因此不会形成四场“老师讲规则”。

### 硬要求

S02 不因调查表重要就停下来逐项拍内容。

观众一眼知道“这是一张 broader 学校生活调查”以后，马上回人物。

# 三、S05 长课堂｜GREEN with timing ceiling

这是本集最容易被误剪成两种极端的地方：

### 错误 A｜怕闷，剪成 90 秒 montage

会失去 EP02 最重要的承诺：

> **学生真的需要坐下来上课。**

### 错误 B｜因为纸面给九分钟，硬演满九分钟

会从“真实课堂”变成“观众被迫旁听”。

当前最优区间：

> **约 6–8 分钟。**

判断标准不是秒数，而是课堂内部是否仍在变化：

> 读 → 答 → 追问 → 误解 → 再读 → 写 → 再问 → 铃。

一旦最后一次观看任务完成，就下课。

---

# 四、S05 → S06｜最重要换挡之一

武田说完：

> `好。下课。`

椅子声起来。

这里不要急着加过场音乐。

让教室从“老师的空间”一秒变回“学生的空间”，再进入午休。

这本身就是很好的节奏释放。

---

# 五、S06 午休｜不要拍成 EP03 预演

EP01 已经做过一次“午休关系重新混流”。

EP02 不需要再次证明每个人和谁吃饭。

当前 S06 只需要：

- 南拉飞鸟去吃；
- 生驹处理一句普通班务；
- 普通学生吃饭 / 换菜 / 找人。

建议有效片长：

> **约 3–4 分钟。**

纸面五分钟不是 KPI。

# 六、S07 体育｜GREEN

这是全集中段非常必要的感官重置：

- 制服消失；
- 球声；
- 鞋底；
- 身体移动；
- 江口短指令。

它避免 EP02 成为连续三十分钟“坐着说学校规则”。

### 重复风险

まあ亚在 S05 和 S07 都有轻角色动作。

当前可接受，因为：

- S05：正式语言卡住；
- S07：身体步伐进入得快。

但 S07 不得再加第二个まあ亚笑点 / 成功展示，否则会从照亮变成小型人物线。

---

# 七、S08 → S09｜必须当成一口气，不是两场主题戏

纸面编号分成：

- S08 飞鸟问；
- S09 飞鸟写。

但观看上最好是同一个下午释放过程：

```text
普通HR
→ 飞鸟问一句
→ 老师回答部分
→ 英语短测通知立刻抢回注意力
→ 终礼结束
→ 清扫
→ 飞鸟在别人搬桌子时写两行
```

这样“写进去”不会被拍成第二个高潮。

### 禁止

- S08 结束加音乐；
- S09 开场给飞鸟独处；
- 调查表特写停太久；
- 写完以后反应镜头。

---

# 八、S10｜最大时长风险

当前纸面预算约六分钟。

实际不应拍满。

这场真正需要的动作只有：

```text
学妹叫住
→ 问“前辈自己从来不折吗”
→ 生驹说自己喜欢现在这样
→ 学妹说自己也喜欢制服，只是喜欢短一点
→ 生驹只说老师仍会提醒
→ 结束
```

建议有效片长：

> **约 3–4 分钟。**

鞋柜人流可以提供呼吸，但不能用停顿把简单对话拍成“重要人生场”。

### 为什么短反而更好

生驹的变化是：

> **少说一句。**

如果整场拖得很长，观众会本能等待“那句重要的话”，反而破坏设计。

---

# 九、两个 M 的不对称结尾｜GREEN

飞鸟在 S09 已经完成动作变化。

生驹在 S10 后完成。

不需要为了“两个 M 公平”再把飞鸟叫回来。

这种不对称是好的：

- 飞鸟的变化发生在制度内部；
- 生驹的变化发生在私人交谈；
- 两人不共享 climax。

符合本集从一开始就拒绝“正反方辩论”的原则。

# 十、整集重复动作检查

### 看纸 / 写纸

确实很多：

- 调查；
- 短测；
- 课本 / 笔记；
- 调查回收。

但这是本集“真的上学”的物质基础。

通过 S01、S04、S06、S07、S10 的站立 / 行走 / 吃饭 / 体育 / 换鞋足以打断。

当前无需删。

### 老师提醒

- S01 裙摆；
- S05 课堂；
- S08 HR。

功能不同，没有连续训导感。

### 裙摆讨论

只有真正两条：

- S04 规定；
- S10 私人习惯。

S01 是行为，不是讨论。

重复可接受。

# 十一、是否“太正确”｜目前否

当前剧本没有：

- 反校规学生赢得全场；
- 老师被辩倒；
- 生驹公开改变态度；
- 学妹成为自由象征；
- まあ亚突然逆袭；
- 每个角色轮流发表对制服意见。

因此虽然流程很严谨，正片本身还没有明显 QA 机器味。

STEP 15 仍需无工具再确认一次。
