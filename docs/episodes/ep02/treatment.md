# 总纪律

- 不拍成校规主题剧；
- 学校不会因为裙长停摆；
- 课堂不是“我们很写实”的陈列柜；
- 1-A 女生无名、无家庭背景、无独立反应特写；
- 飞鸟的参与必须小到像一张真的会进入学校流程的纸；
- 生驹的变化发生在**停止扩大解释**，不是价值观演讲。

---

# S01｜一年级洗手间 → 走廊

镜区还有其他普通新生：整理头发、找纸巾、系领结。

一个女生把裙腰折短一层；朋友只说可能会被提醒。

教师在走廊看见，只减一点脚步：

> `裙子。`

女生放下来，跟上朋友。

**禁止：**量尺、训话、翻白眼、叛逆宣言。

中景看得懂动作即可，不做裙摆极近特写。

---

# S02｜3-D 朝HR｜学校生活调查

道具：

> `新年度　学校生活アンケート`

版面必须明显包含设施、时间、提交、生活规则等多个普通栏；不要给“裙长”单独 checkbox。

30 人正常处理：写名字、问截止、夹进文件夹。

飞鸟看到规则栏，先空着。

若月不是班干部，只以同班关系说“有的话就写”。

南只在乎被老师提醒更麻烦。

调查此后到 S08 前不再提醒式插镜。

---

# S03｜晨间短测

3-C 为主。

前 20–30 秒允许只剩笔、纸、轻咳和椅子声。

まあ亚卡在正式书面表达；先自己读，不立即求救。

高山看见但继续写。

3-D 极短切一次：飞鸟正常做题，南困。

不要用配乐宣布“学习 montage”。

---

# S04｜1F 职员室附近｜生驹第一次回答

生驹进入本场时手里已经有普通班务资料，作为 3-A 学級委員下楼去职员室。

不另拍“老师派任务”前置场。

1-A 女生本来就在 1F 生活，认出**入学式当天案内过本班的学姐**，叫：

> `前辈。`

她问“膝部附近”实际位置。

生驹只用自己膝部比位置，**不碰对方制服**。

女生问稍微短一点是否不行。

生驹当前可以说：

> 在学校按规定穿比较好。
>
> 毕竟是学校制服。

不要继续说“这样才像乃木坂学生”。

双方都有现实任务，谈话自然结束。

# S05｜3-C 国文 / 古文

课堂任务变化负责撑时间：

```text
读
→ 问句意
→ 普通学生答一部分
→ 武田追问
→ まあ亚误解一个古语 / 正式表达
→ 班里轻笑
→ 高山想接但没抢
→ 板书 / 记
→ 再点普通学生
→ 安静自己看
→ 铃
→ 武田把当前一句讲完
```

まあ亚答错要真实，不设计成爆笑答案。

高山的“没接笑”只需一个极轻动作，不拍成成长特写。

普通学生必须承担答对 / 答一半。

武田不连续输出预告片金句。

**有效片长约 6–8 分钟即可。**

# S06｜午休

只负责换气。

南问飞鸟去不去吃，飞鸟嘴上随便、身体跟上。

生驹回到 3-A 普通同学关系。

普通学生吃、换菜、找朋友。

调查表不出镜；1-A 女生不出镜；生驹不“若有所思”。

有效 3–4 分钟即可。

---

# S07｜3-C 体育

篮球基础练习：两步上篮脚步。

江口先示范：

> 右、左、上。

学生依次练。

まあ亚看一次后脚步较快抓对，但球可以不进。

江口最多普通教学反馈：

> `对，就是那个脚步。`

然后看下一人。

高山可以边走边念脚步，形成动作中的轻笑点。

**禁止：**掌声、全班惊讶、“原来まあ亚很厉害”。

体育馆鞋、运动服只是正常课程装备，不作为 EP01 callback。

---

# S08｜3-D 下午HR｜飞鸟问老师

老师已处理两三个普通问题，再提醒学校生活调查今天放学前交，需要学校回答的地方写具体。

飞鸟最好坐着问：

> 裙长为什么是膝盖附近？

老师先区分：

> 为什么统一，还是为什么具体是这个长度？

飞鸟问后者。

老师说明自己确定知道的部分：

> 制服是学校的正式服装，包括裙长在内会规定共同穿法。

对具体历史理由不装懂：

> 为什么定在膝部附近，我现在不能替学校乱说。你写具体，我帮你确认该由谁回答。

这不是开明教师金句，只是正常事实判断。

全班继续翻纸、记日期，不进入辩论观众席。

若月最多一句：

> `那就写。`

---

# S09｜终礼 / 清扫｜飞鸟写剩余问题

先让老师继续明日短测、作业、补交等普通通知。

清扫开始后，飞鸟在别人搬桌 / 擦黑板的动作中拿出调查。

她站着或半靠桌边写两行，不独处、不配乐。

文字逻辑：

> `制服をそろえて着る理由は分かりました。`
>
> `丈を膝付近とする理由を知りたいです。`

观众只需看懂她写的是刚才剩下的问题；关键词可辨，不做满屏宣言特写。

由普通班级流程回收，若月不承担收表职位。

下一张纸很快盖上。

飞鸟继续清扫。

---

# S10｜鞋柜 / 主楼出口｜生驹少说半句

放学后不同年级都经过鞋柜。

上午 1-A 女生看见生驹，主动叫：

> `前辈。`

并追两步。

问题保持私人：

> `前辈自己的裙子，从来不折短吗？`

生驹：不折。

女生：因为规定？

生驹第一次停一点：

> `……我自己也喜欢这样。`

女生：

> `我也很喜欢这身制服。只是我觉得短一点更好看。`

生驹只把现实后果说清：

> `在学校里还是会被老师说的。`

女生知道。

两人各自换鞋、拿包、回到朋友 / 高三人流。

**不要写 / 演“我学会尊重你了”。**

有效片长 3–4 分钟即可。

S10 人流直接承担 Ending，不再另起“学校继续”场。

# Gate 8 结论

### 可拍性 GREEN

- 学校生活调查是 broader 制度，不是剧情按钮；
- 生驹第一次在 1F 有学級委員班务理由；
- S05 课堂靠任务变化而非笑点密度；
- S07 不构成まあ亚补偿式逆袭；
- S08 教师可诚实说具体历史理由需要确认；
- S08 → S09 是“得到部分答案 → 写剩余问题”；
- S10 学妹主动叫住，且问题是私人穿法，不是主题题。

### 制作硬锁

1. S01 不升级成纪律冲突；
2. S02 道具 broad 但不逐项读；
3. S03 保留真安静；
4. S04 生驹不碰制服；
5. S05 不做反应镜头乒乓；
6. S07 不拍まあ亚能力反转；
7. S08 飞鸟坐着问，老师不装懂；
8. S09 写字可辨但不宣言化；
9. S10 不补主题音乐 / 悟道表情；
10. 本集不出现裙长规则被修改的结果。

**Gate 8：PASS。**
