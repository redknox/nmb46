# Batch 02｜S04–S07｜LOCKED

## S04｜生驹第一次回答

五层：GREEN。

### 人物

生驹说的现行规则是对的。

她的压力不来自“她做错了”，而来自她自然多加的一层：

> `毕竟是学校的制服。`

这符合她自己的归属经验。

### 普通人常识

学妹问的是实际规则，不是向学姐申请违规许可。

生驹也没有纪律权。

### 减法锁

不让生驹碰学妹裙摆，不把这场写成教育 / 被教育。

# Batch 03｜S08–S10｜LOCKED

## S08｜飞鸟问老师

五层：GREEN。

### 人物

飞鸟真正重要的变化不是敢顶撞老师，而是：

> 她把原本只在脑子里嫌弃的问题问给了一个真实制度接口。

### 教师

当前回答锁定：

- 说明学校确实知道的共同制服逻辑；
- 对“为什么具体是膝部附近”不装懂；
- 把问题送回可回答的正式路径。

这既保护现实，也避免把成年人写成稻草人。

### 普通人

其他学生的问题先存在；全班不因飞鸟开口突然进入“辩论观众席”。

## S09｜飞鸟写问题

五层：GREEN。

关键不是写得漂亮，而是：

> **她的书面问题承认自己听见了刚才的答案。**

锁定逻辑：

> `统一穿法的理由明白了 → 仍想知道为什么具体是膝部附近。`

表进入普通调查堆后不再追踪。

### 制作锁

动作必须看得懂；文字不能拍成宣言式大特写。

## S10｜生驹第二次回答 / Ending

五层：GREEN。

### 人物行为

第一次：

> 规则 → 应该按规定穿 → 毕竟是学校制服。

第二次：

> 自己不折 → 自己喜欢这样 → 老师仍会提醒 → 停。

她没有变成反规则。

她只不再把自己的个人答案继续扩展成学妹必须复制的答案。

### 学妹

问的是：

> `前辈自己的裙子，从来不折短吗？`

这是私人好奇，不是作者主题题。

### 表演锁

剧本里的“像是还有半句话”只能理解为极轻的节奏提示。

禁止表演成：

- 恍然大悟；
- 温柔教育完成；
- “我终于学会尊重你”的笑。

如果后续 STEP 14 认为这句舞台说明本身会诱导过演，允许**删除说明文字而不重开场景**。

### Ending

两人散回人流后直接 CUT。

不再增加学校继续 / 规则没变的解释镜头。
