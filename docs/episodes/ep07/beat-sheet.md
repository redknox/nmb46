# EP07《夏天》｜Beat Sheet

> 状态：**LOCKED**
> 流程：STEP 3 / Gate 3 PASS
> 目标时长：约50分钟

## Beat 1｜大巴上的合宿传说 → 江口式反转

**Day 1 上午｜约5–6分钟**

去程大巴上先建立历届合宿传说。学生聊到去年“星座修罗场”：江口用近乎荒唐的住宿分组规则让不少人陷入关系选择与公开尴尬，传说甚至有人哭。

因此全体对今年的江口式分组保持警惕。

抵达设施后，江口却让大家“自由组六人”。关系网迅速自行显形：白石靠近桥本、飞鸟靠近南、西野靠近高山、真夏靠近樱井等。学生逐渐相信今年终于不折腾人。

随后江口让每组六人自行编号，才宣布寝室按编号重新编排。

自由组被重新拆开，全年级哗然。

功能：
- 大巴先铺垫江口式传统，避免分组笑点凭空出现；
- 自由分组展示真实关系，不靠对白解释；
- 寝室反转把安全区拆开，为第一夜混住建立条件。

情绪：期待 → 戒备 → 放松警惕 → 被骗后的热闹。

## Beat 2｜山：白石一直都是那个“多做一点的人”

**Day 1 下午｜约7–8分钟**

午饭、活动说明后登山。采用自由活动组 / 自然流动组合，不让固定六人组一路绑定。

不发生大事故。山路本身把身体差异摊出来：有人快、有人喘、有人后悔、有人突然可靠。

まあ亚、生驹在户外更自在；若月试图维持节奏，但山路和体力差不会服从计划；生田开始注意某些“身体先会”的能力。

白石状态很好：自己不慢，别人慢会等；有人东西多会帮拿；危险动作会直接提醒。重点不是让她累倒，而是反复出现“她总比自己的份额多承担一点”。

本 Beat 只展示既有算法，不推进成长。

情绪：热闹 → 身体吃力 → 山顶小释放。

---

## Beat 3｜第一夜：人被拆开以后，生活重新长出来

**Day 1 晚｜约6–7分钟**

公共浴场、走廊、吹头发、自动贩卖机、住宿区，让“共同生活”真正开始。

重点进入少数寝室，不做全员巡礼。卧谈会是多房间同时发生的夜生活：老师、恋爱、家里、身体、怪谈、食物、无意义闲话并存，不统一主题。

石原以女性成人边界自然出现：巡房、处理小状况、消除尴尬，但不加入学生秘密世界。

飞鸟后来抱着枕头偷偷跑去找南。石原确认人安全后，允许聊天，但要求睡觉回本人寝室。成为轻喜剧。

白石没有桥本，也不在一个围绕她运转的房间里。她洗完澡、头发未完全整理，坐在床边听别人说话、笑、偶尔被问普通问题。第一次出现“这个房间并不需要她负责”的生活事实。

但这还不是成长，只是一种陌生体验。

情绪：喧闹 → 私密 → 夜深仍舍不得睡。

## Beat 4｜上午合作竞赛：第一次不选择“让所有人舒服”

**Day 2 上午｜约10–11分钟**

海边合作综合赛，采用多个 station / 水上与岸上项目并行，满足现实容量，也让不同能力产生价值。

组队采用“抽 / 指定组长 → 组长选人”。友情逻辑第一次被能力逻辑打断：有人被多组争抢；有人默认亲友会选自己却没被优先；真正安全的关系允许对方去别组。

### まあ亚 S

她在前一天和项目准备中已经显出身体模仿、现场判断、绳结 / 协作等优势。真夏或若月最先叫她，另一组也争抢。她最自然的反应是惊讶“我？”。

### 生田 S

她开始具体看到：まあ亚有些事情解释不出来，却就是比她更快掌握。不是受挫，而是第一次清楚看见另一种聪明。

### 若月 S

作为组长或核心执行者认真配置、认真规划，但水、浪、人和失误不断破坏计划。她从“恢复原安排”轻微转向“现在这样，下一步怎么做”。

### 白石 M｜第一次裂缝

白石进入明确胜负状态。她会按能力与项目判断选人，不因为关系亲近就优先选；有人散漫时会直接要求认真。

她做出一个让亲近者有一瞬失落的选择。白石看见了，但没有像过去那样立刻解释、补偿或改口。

比赛继续，事情没有因此坏掉，关系也没有破裂。

上午结束时，白石获得一个事实：

> 我没有照顾所有人的情绪，世界也没有坏。

但她还没有真正接受这个事实。

情绪：兴奋 → 竞争 → 狼狈 → 事实成立后的轻微不安。

## Beat 5｜下午海：从“知道”到“接受”

**Day 2 下午｜约8–9分钟**

上午比赛后不再设置正式任务，进入海边自由活动。本段是全色情感与视觉中心，摄影机可采用高饱和青春MV语法，但人物世界仍然只是普通夏日活动。

白石最初仍站在岸边：看包、毛巾、水和手机，笑着看别人玩。上午事实成立，但旧习惯仍在。

### 契机①｜飞鸟戳破姿态

飞鸟经过时以熟人毒舌轻轻吐槽白石仍在“白石様 / 明星范儿”模式。说完就走，不承担说教功能。

这只是让白石意识到：别人其实看得见她一直站在快乐外面。

### 契机②｜南拿走责任借口

南非常生活化地问她为什么不下来。白石说东西需要看，南直接把东西放好 / 交给旁边人照看，然后自己跑回水里。

南不理解这里有什么人生问题，她只是觉得“放这里不就好了”。

白石没有立刻改变。她站一会儿，陆续看见：上午那个被她没选的人仍然在开心玩；没有谁躲她；别人能照顾自己；没人真的在等她托住现场。

于是关键动作发生：

> **白石自己走下水。**

不是被别人拖进去。

### 契机③｜从参加到主动攻击

最初只是参与。有人泼她，她反击；对方跑，她追。

随后白石的胜负心真正出来：记仇、绕后、追人、抢东西、临时结盟、被攻击后一定要报复回来。

她从“允许自己玩”到“主动玩”，再到“认真地玩”，最终成为：

> **制造混乱的人之一。**

这里要让观众产生：

> “原来白石桑也会玩得这么狼狈、这么开心、这么有攻击性、这么有胜负心。”

但不能把这种狼狈拍成形象崩坏；恰恰要让她在湿头发、奔跑、笑到停不下来、追人报复中仍然非常有魅力。

### 契机④｜西野 × 桥本

西野能很自然地和桥本身体打闹，对白石却仍有一点下意识敬畏距离。

白石看见后不做谈心，也不解释“你可以自然一点”。她主动去找西野麻烦：追、抓、泼、拖入自己的战局。

西野出现真实的“欸？白石？！”式惊讶。

于是白石的变化从“我可以靠近大家”进一步变成：

> **我可以主动要求你别把我放在特殊的位置。**

情绪：安静余波 → 被戳破 → 试探 → 自己下水 → 爆发 → 最明亮的释放。

## Beat 6｜野炊：变化进入普通生活

**Day 2 傍晚｜约6–7分钟**

120人组成约10个12人炊事组。每组事前在“咖喱饭 / 豚汁定食”中二选一。设施统一提供食材与器具。

这不是厨艺比赛。重点是同样的食材经过不同组之后出现不同家庭习惯与生活能力：有人会做、有人只会指挥、有人偷吃、有人生火厉害、有人家庭吃法奇怪。

选择2–3组重点跟随。飞鸟的家庭吃法可在吃饭阶段轻轻出现。

白石仍然认真、可靠，但不再永远多接一份责任。别人说“这个我来”，她可以真的交出去；有人做得不如她漂亮，也不马上抢回。

这段验证：下午不是一次性失控，她依然是白石，只是已经不需要永远站在快乐之外。

情绪：忙乱 → 饭香 → 坐下 → 满足。

---

## Beat 7｜火与烟花：不总结

**Day 2 夜｜约4–5分钟**

篝火作为大集体仪式存在，但不做“谈梦想”“最后一个夏天”“以后会怎样”。

篝火后进入经事前申请的手持烟花时间。120人大集体自然散成小团体：有人吵闹，有人蹲着守线香花火，有人借火、拍照、失败后再点一支。

白石已自然存在于人群中：自己拿烟花、自己去找人、继续笑，不再需要额外剧情证明变化。

情绪：大火 → 小火 → 安静下来。

## Beat 8｜第三天早晨：只是一起住过两夜

**Day 3 上午至返程｜约4–5分钟**

睡不够、乱头发、早餐、找袜子、叠被、扫地、整理寝具、恢复房间、退所检查。

原本被江口强行混住的室友已经自然知道谁的东西在哪里、谁负责拿垃圾、谁忘了什么。没有新关系升级，只有共同生活事实已经发生。

飞鸟重新和南靠在一起。白石重新遇到桥本，桥本不问她“是不是变了”，两人照常相处。

去程大巴很吵，回程明显安静：有人睡着、靠窗、戴耳机、看照片。

结尾不出现毕业感与“舍不得”。大巴离开，合宿结束。

> **这个夏天已经真的发生过。**

# 整集因果线

Day 1：大家自然依赖白石 → 白石也自然多承担一点 → 夜里暂时离开桥本安全区。

Day 2 上午：胜负心逼她第一次按自己的判断做选择 → 没有替所有人的情绪兜底 → 事实证明关系没有坏。

Day 2 下午：旧习惯仍让她站在岸边 → 飞鸟戳破姿态、南拿掉责任借口 → 白石自己下水 → 从参与变成主动攻击与争胜 → 主动拆掉西野对自己的敬畏距离 → 成为制造混乱的人之一。

Day 2 晚：回到普通生活与集体活动 → 白石仍认真可靠，但不再永远多接一份责任。

Day 3：不总结，新行为已自然存在。

# 节奏原则

本集两个最大连续峰值：

- Day 2 上午：关系、判断、胜负造成的戏剧高潮；
- Day 2 下午：身体、光、快乐造成的情感高潮。

后续野炊、篝火、烟花一路回落到生活。

> **本集最重要的转折不是越拍越沉，而是越拍越亮。**
