# RED-01｜S07 沙滩抢旗参赛人数与“部分人员上场”冲突

已锁事实：

1. 第一项大型划桨艇：六组20人全体参加；
2. 第二项木筏：各组派部分人员直接组装 / 下水，其余协助；
3. 第三项沙滩抢旗：也应由各组派部分人员；
4. 抢旗采用1v1，避免多人同抢产生出发位不公平；
5. 当前视觉数字仍写作20→10→5→3。

问题：

如果第三项是六个20人组之间的团队竞赛，而又只有“部分人员”参加，那么总参赛人数直接定为20，会产生无法自然解释的配额：20无法平均分给6组。

这不是对白问题，而是赛制客观矛盾。

### 建议修复（推荐）

将人数改为：

> **24 → 12 → 6 → 3**

即每组派4名代表，共24人：

- 第一轮：12组1v1 → 12人；
- 第二轮：6组1v1 → 6人；
- 第三轮：3组1v1 → 3人；
- 最后三人分别同赛道计时，决出最终名次。

优点：

- 六组配额完全公平；
- 始终1v1；
- 不需要5→3的额外“按前轮成绩选前三”规则；
- 视觉递进仍然清楚；
- 白石第二轮“从对方手里硬抢旗”的核心戏完全不受影响。

这属于连续性硬伤，按工作流允许重开已锁场次。

# YELLOW-01｜S07 “先碰到旗”与白石继续争抢的判定规则需要改一句

当前规则容易被理解为：

> 谁先碰到旗谁就赢。

但白石高光是：对手先碰 / 先抓住软旗，白石随后抓住另一端，把旗硬拽过来并护在身下。

如果“先触旗即胜”，这场动作在规则上已经结束。

### 建议

工作人员规则改成：

> **完全拿到旗、控制住以后才算。**

制作侧安全规则：

- 只能争旗；
- 不允许推、抱、拉人；
- 裁判随时可终止纠缠。

这样白石可以在对手刚抓住旗、尚未形成完全控制时继续抢旗。

不需要增加解释性对白，只需把规则句改准。

# YELLOW-02｜S06 “抢人公式”后台算法需要制作侧写清楚

人数总量最终可以闭合到六组各20人，但当前台词只说明：

- 其他114人按前一天成绩顺序分；
- 每轮每组一人；
- 当前候选可以被抢；
- 抢到后本轮多一人，下一轮整组休息；
- 满20后退出。

成片不必把算法讲清，但现场执行表必须明确：

1. 每位候选原本默认进入哪一组；
2. 被抢后原目标组该轮如何处理；
3. “下一轮休息”具体抵消哪个默认名额；
4. 最后不足20的组如何自动补齐。

建议在制作 / continuity note 中明确：**抢人只改变分配顺序，不改变总人数；最终未满组按原成绩顺序补齐。**

剧本对白无需增加数学解释。
