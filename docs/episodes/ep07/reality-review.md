# EP07《夏天》｜Reality / Institution Review

> 状态：**LOCKED**
> 流程：STEP 1 / Gate 1 PASS

## 结论

总体 GREEN。三天两夜、约120名高三学生、青少年自然教育设施、登山、海上合作活动、公共浴场、野外炊事、篝火、手持烟花与第三日退所整理均现实成立。

## 关键现实锁定

- 住宿设施：昭和时期建成、持续翻修的公共 / 非营利青少年自然教育设施。
- 住宿：六人间，3组上下床；宿舍无独立浴室，住宿区配置公共洗面所 / 厕所，大型公共浴场集中洗浴。
- Day 1 登山：学校与设施预先确认路线、天气、补水与热中症预案；正片无需逐项说明行政流程。
- Day 2 上午海上合作活动：不能让120人同时参与同一船型；采用多个 station / 分批 / 综合竞赛形式，满足容量与安全限制。
- Day 2 下午海边自由活动：仍有指定活动水域、教师 / 设施人员监护、集合时间与救生规则；摄影机不拍管理不等于管理不存在。
- 野外炊事：120人约10组，每组12人；设施统一供给食材与器具。家庭味来自做法、比例、吃法与允许的公共调味料，不默认学生自行从家里携带食材。
- 菜单：每组事前在“咖喱饭 / 豚汁定食”中二选一。
- 成人：学生10个炊事组为正式主流程；教师 / 工作人员另有简餐灶，成人首要职责仍是安全、巡视与管理。
- 篝火：按设施火源管理规则执行。
- 烟花：虚构设施设为“事前申请后，可在指定区域、指定时间进行手持烟花；禁止打上型 / 大型喷射型烟花”。
- 手机：乃校合宿纪律为活动期间原则上不使用；规定自由时间可用；消灯后禁用。非全国统一法规。
- 夜间串寝：学生可以去其他房间聊天，但夜间人数确认与疏散名册要求睡觉回本人寝室；女教师 / 石原夜间巡房负责女生住宿区更自然。
- 石原：作为養護教諭随队合理，负责基础健康判断、热中症、轻伤、经期、过敏、身体不适与必要的外部医疗联络，不写成随队医生。
- Day 3：必须有寝具整理、清扫、恢复房间与退所检查。
