# EP07《夏天》｜Visual Direction

> 状态：**LOCKED**
> 用途：EP07 服装 / 摄影 / 美术视觉锁点
> 核心场景：Day2 下午海边 S08

## 总原则

EP07 的视觉高点不是“泳装展示”，而是一次群像式夏日释放。摄影机可以接近青春 MV 语法，但世界仍然只是普通高中女生的合宿海边活动。

**锁定原则：**

> **海边这场可以漂亮，但不能摆漂亮。**

漂亮来自硬日光、海水、湿发、晒红、奔跑、追逐、衣服吸水后的重量、沙子与真实动作；不能来自角色面对摄影机摆姿势。

本场是 EP07 的“MV视觉终点”。人物仍必须服从既有人设，不把17人设计成17套互不相干的偶像造型，也不使用战队式专属代表色。

---

## Day2 下午海边｜群像视觉系统

17名主要学生分成几个视觉族群，使大远景形成统一而有层次的色块，同时近景仍能看出各自选择方式。

### A｜明亮轻盈

**南、松村、真夏、樱井、中元**

承担画面中的夏日亮色，但不做糖果色偶像制服。

- **南**：浅黄 / 淡蓝 / 白，轻便 rash guard＋运动短裤。看起来像换完衣服就会直接跑进海里。
- **松村**：粉橘 / 珊瑚 / 浅红等偏甜但仍生活化的颜色，可在发圈、毛巾、拉链边等小处有搭配感。
- **真夏**：白＋浅粉 / 淡紫，明显是自己认真挑过、知道会好看的组合；实际玩起来照样全湿。
- **樱井**：奶白＋海军蓝。低调，但面料、剪裁与完成度自然显出家庭条件优渥，不使用明显品牌炫示。
- **中元**：浅蓝 / 薄荷绿，长袖防晒型 rash guard，整体准备充分。

### B｜深色运动

**桥本、飞鸟、若月、卫藤、生驹**

负责压住整体画面，让海滩群像不全部落入浅色与甜色。

- **桥本**：黑灰 / 深海军蓝，长袖 rash guard＋黑色运动短裤；纯功能导向。
- **飞鸟**：黑 / 炭灰，偏宽松的 rash guard 或 T 恤式罩衫＋短裤；最不想显得“为了海边特意打扮”。
- **若月**：深蓝＋白线条，标准运动感，防晒与装备完整。
- **卫藤**：深酒红＋黑 / 深蓝，比同龄人稍成熟、知道自己适合什么，但仍严格保持运动型、不走性感路线。
- **生驹**：海军蓝 / 黑色运动 T＋短裤，最早全身湿透、最不在乎衣服状态。

### C｜低饱和自然色

**西野、深川、万理华、高山**

承担“生活片”气质。

- **西野**：灰蓝、雾紫、米灰；罩衫略宽松，真正开始玩后自然留在岸边。
- **深川**：米白＋浅卡其 / 淡灰，柔和舒服，不争视觉中心。
- **万理华**：复古芥末黄、砖橙、暗青等小面积使用；不是“怪”，而是会自然选别人不先想到的东西。
- **高山**：白 / 灰普通 T＋深色短裤，可带一件明显用了很久的帽子或毛巾；几乎没有造型包袱。

### D｜单独处理

#### 白石

**深海军蓝 / 黑色运动型连体泳装＋白色薄款长袖拉链罩衫＋深色水陆两用短裤。**

前半岸边状态必须天然完整：白罩衫干净、头发整理好、整体构图甚至会自然显得像广告，但角色本人并没有在“拍广告”。

她决定下水时不换造型，只是把现实借口拿掉后直接走进水里。随着玩闹升级，白色罩衫吸水变重、袖口湿、头发散掉、腿上沾沙，最终原本非常“白石”的完整造型被真实生活自然破坏。

**意义不是她换掉了“白石造型”，而是她允许自己的造型被生活弄乱。**

#### 生田

白色运动 T / rash guard＋鲜蓝或绿色运动短裤，可搭一个她自己觉得“这样没问题”的发圈。整体功能正确，但不追求全套审美协调。

一旦进入活动便迅速顾不上造型。

#### まあ亚

短袖 rash guard＋运动短裤＋绑得很牢的头发。颜色可使用明黄＋深蓝或绿色＋黑。

17人中最应该让人一眼感觉“这个人是真的准备下水、跑、跳、搬东西”，身体与行动优先于造型意识。

## 湿发＝第二服装

头发状态必须参与 S08 的视觉推进，不能只把服装当作造型终点。

前半：
- 白石整理完整；
- 真夏会扎得相对可爱；
- 若月实用；
- 飞鸟随手处理；
- 西野较自然；
- 南简单马尾。

中后段后，所有状态逐渐被海水与动作破坏：
- 白石湿发贴脸；
- 南马尾散一半；
- 西野发尾全湿；
- 桥本直接把头发往后一撸；
- 真夏原先完整的发型消失；
- 生驹、生田基本不再管；
- 飞鸟会因为头发贴脸而频繁拨开。

**湿发、晒红、沾沙和衣物吸水后的状态，是本场比“泳装款式”更重要的视觉信息。**

## 群像构图纪律

不要把17人整齐排开，不拍“成员展示”。

画面允许：
- 浅色角色从强光里跑入镜头；
- 深色服装在水面形成稳定块面；
- 低饱和角色蹲在浅水 / 沙滩边；
- 人物跑过镜头遮挡彼此；
- 白石后半段常常只占画面一部分，不再被摄影机特殊照顾。

S08 结尾的大远景要求：

> **观众第一眼看到的是一群女孩在疯玩，第二眼才找到白石。**

这与 Scene List 已锁定的白石动作终点一致：她不再站在快乐旁边，也不再是需要被画面单独照顾的人。

---

## 安全与年龄边界

- 海边服装以运动泳装、rash guard、运动短裤、T恤罩衫、水陆两用服为主体。
- 不使用写真 / gravure 式造型语言。
- 摄影机跟随行动、关系、失控与群体节奏，不以身体局部为观看对象。
- 角色是17岁高中女生；服装和镜头必须保持非性化处理。

## 其他时段服装原则

### Day1 山地定向
学校统一活动安全边界：运动鞋、能活动的运动裤、吸汗上衣；帽子、薄外套自选。可发统一活动背心 / 号码布用于120人识别。

### Day2 上午海上项目
设施安全服装优先：运动T / 长袖速干衣＋运动短裤 / 水陆两用裤＋统一救生衣。cutter 与木筏阶段不穿纯展示性泳装。

### 第一夜
睡衣真正拉开人物私生活差异，但仍以普通高中女生家居服为基准。飞鸟保持“大号T恤＋普通短裤 / 长裤”的低造型意识，使“睡衣 / 装成熟”起哄成立。

### 晚间篝火 / 烟花
换回干爽轻便私服 / 家居感外出服。S10 只做场景与记忆展示，不通过服装新增人物线。

## 成人服装基准

- **江口**：功能型户外短袖 / polo＋速干长裤或短裤＋运动表＋帽子；进入水上项目直接套救生衣。
- **石原**：白天不穿白大褂；轻便长裤＋透气上衣＋腰包 / 小急救包；晚间巡房可披薄针织外套。
- **武田**：严格符合户外要求，但明显不是长期户外型人物；polo＋长裤＋传统遮阳帽，安全、朴素、略显老派。
