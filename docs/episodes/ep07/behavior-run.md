# EP07《夏天》｜Behavior Run

> 状态：**LOCKED**
> 流程：STEP 2 / Gate 2 PASS

## 白石麻衣｜M

### 默认行为顺序

看见问题 → 自己先补上 → 确保别人没受影响 → 再处理自己的感受 → 真撑不住才靠近桥本。

Day 1 登山只展示这一算法：她会等体力慢的人、帮拿东西、直接制止危险动作；她不是被压迫，而是自然地总比自己的份额多做一点。

### Day 2 上午｜第一次偏离

比赛与组选人让白石进入明确的胜负状态。

她会按“怎样赢”选人和判断，不再自动按“怎样让所有人舒服”行动。看见亲近的人有一瞬失落后，她第一次没有立刻解释、补偿或改选。

新事实：她没有照顾所有人的情绪，关系和事情也没有因此坏掉。

### Day 2 下午｜行为顺序真正改变

旧算法仍先启动：她站在岸边看包、毛巾与东西，笑着看别人玩。

飞鸟以熟人毒舌轻轻戳破她仍在“白石様模式”；南则非常生活化地拿掉“东西需要我看”的具体借口。

白石观察到：上午的人际关系没有坏；别人能照顾自己；没有谁真在等她托住现场。

于是新的顺序第一次发生：

看见大家在玩 → 自己也想玩 → **先行动** → 之后才想“这样没关系吗”。

关键必须由白石自己走下水，不由别人拖下去。

她从参与变成主动反击、追人、报复、争胜、临时结盟，最终成为“制造混乱的人之一”。她第一次把原本用于标准与责任的胜负心，用在一件根本不需要负责的事情上。

看到西野与桥本身体打闹得很自然、对白石却仍有敬畏距离后，白石主动去找西野麻烦，用行动拆掉“白石桑”的特殊位置。

### 行为变化摘要

以前：先确认别人没事，再允许自己。

以后：有些时候，她开始允许“我想”先发生。

## 生田绘梨花｜S

默认把问题理解成“哪里还没做好”，继续分析、练习、找正确方法。

合宿中，绳结、桨的配合、平衡、火候等身体 / 生活技能让她第一次清楚遇到“不能靠解释就获得的聪明”。

まあ亚可能一次示范后就会做，却说不清理论。生田不会因此受挫或完成大弧，只会更认真地观察并承认：有些能力不是自己熟悉的正确答案体系。

不重复 EP04 的 free 问题。

## 和田まあ亚｜S

默认反应更接近：先问、先模仿、先动手。

户外环境与她的学习方式高度匹配：绳结、身体协调、船上动作、生火等都可能比课堂更快上手。

Day 2 组选人时，真夏 / 若月等人先发现她的现场价值，多个组长争抢她。她最自然的反应不是得意，而是惊讶：“我？”

本集给她的验证是：学校平时不充分奖励的能力，在这里真的有人需要。

## 若月佑美｜S

默认倾向把“认真”与“秩序应该成立”连接起来。

登山与海上合作不断给出不可控变量：体力差、浪、位置变化、临时失误、时间延迟。

她最初会纠正、重新排、确认规则；第二次或第三次失控后，开始不再执着“恢复原计划”，而是直接处理“现在这样，下一步怎么办”。

不是放弃秩序，只是轻微承认现场有自己的节奏。
