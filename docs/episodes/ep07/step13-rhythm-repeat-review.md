## 结论

整集节奏成立，无需重做结构。

核心节奏链：

1. S01–S03：进入合宿 / 机制 / 第一日任务，信息密度较高；
2. S04–S05：洗澡、吃饭、寝室夜聊，速度降下来；
3. S06：Day2 重组，重新抬起机制感；
4. S07：竞技高潮；
5. S08：从比赛切换为自由玩水，情绪峰值但不是剧情峰值；
6. S09：做饭，把身体活动重新落回生活；
7. S10：纯余韵 / MV；
8. S11–S12：清扫、退房、回家，迅速降落。

整体呈现“紧 → 松 → 再紧 → 放开 → 生活化收束”，没有一直单向升高。

## S02 武田补笔

入口 montage 可以加入，但必须控制在短段落内。

功能：建立武田“小事讲很久”的人格，不建立新喜剧线。

节奏限制：

- 只取 3–4 个经过组的生活提醒；
- 不给每组完整 setup→reaction→punchline；
- 不让南 / 飞鸟再承担吐槽主持；
- 最后以学生继续进入宿舍、武田还在说一句结束即可。

这样不会抢江口公式揭晓，也不会显著增加 S02 时长。

## S01–S03

前轮 audit 已削减南×飞鸟连续互呛和普通学生 punchline。本轮不再继续砍机制必要信息。

S02 新增武田后，严禁再添加新的解释或笑点。

## S04–S05

与前段形成良好降速。

S04 以身体疲劳、洗澡、晚饭为主；S05 是多个寝室的夜间碎片。二者虽都偏生活流，但物理状态和声音环境差异足够，不同质。

## S06–S08

三场看似都是“活动”，功能实际不同：

- S06 = 规则 / 选择；
- S07 = 竞争 / 想赢；
- S08 = 无规则 / 想玩。

因此不属于重复。

S07 必须采用已锁定 6组×4人、24→12→6→3 规则，避免旧的20人数字残留。

S08 保持无计时、无成绩板、无完整胜负结构，这是它与 S07 最大的节奏区别。

## S09–S10

S09 有明确任务（做饭），但开饭后秩序松掉；S10 彻底取消任务，只保留火光、烟花、疲劳和零碎声音。

二者的连续关系是“还有事要做 → 已经什么都不用做”。成立。

S10 不再承担人物弧线解释，不添加成人总结。

## S11–S12

两场都属于离开，但层级不同：

- S11 是“恢复空间 / 找东西 / 点名 / 上车”；
- S12 是“回到学校 / 人群自然散掉”。

通过“充电器”打断 S11 潜在伤感，再让 S12 像普通放学一样结束，避免双重告别。
