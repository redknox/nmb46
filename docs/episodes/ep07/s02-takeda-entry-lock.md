# EP07《夏天》｜S02 武田补笔 LOCK

> 状态：**LOCKED / S02 ADDITIVE NOTE**
>
> 用途：补足武田老师在 EP07 的人物辨识度，不新增故事线，不改变江口分组机关。

## 场景位置

Day1 到达住宿设施、学生完成分组与寝室编号后，学生按组陆续进入住宿楼。

武田站在宿舍入口 / 玄关边，不重新集合全体学生，也不发表完整训话。

## 行为原则

学生一组一组经过时，武田不断顺手提醒生活细节：

- 鞋子不要堵入口；
- 行李不要摊在走廊；
- 室外拖鞋不要直接穿进室内；
- 湿毛巾不要随便搭在木栏；
- 沙子带进走廊最后还是学生自己扫；
- 诸如此类的生活小事。

他的提醒不是一次讲完，而是随着不同组经过不断续上。学生已经开始往里走，他仍可能继续补一句。

可采用轻 montage：

第一组：

**武田**  
鞋子摆里面一点。不要堵门口。

下一组：

**武田**  
行李先拿进房间。走廊不要摊开。

又一组里有人穿错拖鞋。

**武田**  
等一下。那个不是室内拖鞋吧？

学生低头。

**学生**  
……不是。

**武田**  
我就说嘛。

他顺势继续：

**武田**  
这种地方最怕沙子带进去。最后还是你们自己扫。真到晚上脚底全是沙，又要说扎脚——

学生已经开始往里走。

**武田**  
……我还没说完呢。

不必强行把人叫回来；下一组已经经过，他又继续提醒下一件小事。

## 人物功能

这一补笔用于建立武田在 EP07 的前置人格：

> **小事讲很久。**

与 S10 的：

> **武田**  
> 今年也很热啊。

形成轻微反差：真正容易被写成“青春总结”的时刻，他反而只说很短的一句。

禁止：

- 把武田写成主持合宿秩序的人；
- 抢走江口作为活动 / 制度核心成人的位置；
- 让这一段发展成完整喜剧桥段；
- 让学生轮流吐槽武田；
- 在 S10 让武田替观众总结青春、成长、最后一个夏天等意义。
