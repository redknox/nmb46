# 乃木坂女学院｜主教学楼东西端卫生服务区锁定

> 状态：**已锁定 / 3F与全楼服务空间权威补充。**

## 1. 位置与竖向关系

普通卫生服务区设置于端部楼梯亭北侧，并1F—3F垂直叠置：

- 西端：X1—X3 / Y3—Y4；
- 东端：X17—X19 / Y3—Y4。

其工程意义是把给排水、排气、清扫与设备管线集中在端部，不侵入Central或北侧历史房。

## 2. 普通学生卫生间

- 东西端各设 **5个普通学生厕位**；
- 东西分流，不要求学生跨越整层；
- 每端最靠内一间可适度加宽，方便临时行动不便、拄拐或制服整理，但不替代E1无障碍卫生间。

## 3. 西端职员WC

西端服务区另设一间 **独立职员共用单间WC**，从干入口/前室独立进入，不穿越学生隔间区。无障碍需求仍由E1承担。

## 4. 内部组织

空间顺序采用：

> **主走廊 → 视觉缓冲/干入口 → 宽松洗手厅 → 隔间区；清扫、储物、管井集中于服务带。**

洗手区与隔间区避免从主走廊直接可视。每端约4个洗手位，材料耐用、安静、易维护，但不做酒店式炫技。

固定原则：

> **空间等级低，不等于材料与维护等级低。**

## 5. 北立面

端部服务区不照抄普通北侧历史房的4窗节奏，而采用 **3扇高位、较窄的竖向采光窗**：

- 仍维持竖向木窗语言；
- 窗台高于普通北房；
- 可采用下部漫射/隐私玻璃与上部采光；
- 窗头继续尽量服从全楼 +2.925m 水平秩序；
- 排风口优先隐藏于檐口、端墙次要位置或克制格栅中，不让设备百叶成为立面主角。

东西端卫生服务区基本平面与立面原则至此不再开放。下一步进入现代防火分区与避难策略。
