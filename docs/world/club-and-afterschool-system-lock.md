# 乃木坂女学院｜部活、同好会与放学后生态锁定

> 状态：**LOCKED / 已传播到学校世界观、校园空间与课程制度。**
>
> 本文件锁定高等科 360 名学生规模下的部活制度、兼部、引退、主要社团配置与放学后使用原则。各部每届精确人数、普通部员姓名和逐日活动表不在此锁定。

## 一、总原则

乃木坂女学院的大多数学生参加至少一个部活或同好会，没有部活的学生是少数；但学校不把所有放学后活动都组织成部活。

学生也可以：

- 预约练习室进行个人练习；
- 继续完成正式课程作品；
- 参加文化祭等短期项目；
- 在图书馆自习；
- 承担学生会或委员会工作；
- 在食堂、中庭或教室等人、聊天、停留；
- 离校参加私人课程或其他校外活动。

因此：

> **多数学生属于部活，不等于每个人每天放学后都按同一套组织节奏行动。**

乃校放学后的自由来自成熟的预约、场地、顾问与安全制度，不来自学校放弃管理。

## 二、三类学生组织

### 正式部活

具有：

- 稳定跨年级成员；
- 正式顾问；
- 部长、副部长等学生事务职位；
- 年度计划、活动记录与预算；
- 稳定使用的场地或设备；
- 明确的安全和对外活动责任。

### 同好会

- 原则上由五名以上学生提出；
- 必须有教职员顾问；
- 不当然拥有专属房间；
- 预算与设备规模较小；
- 每学年复核活动实绩与成员人数；
- 稳定活动两年以上、成员达到约八至十人后，可以申请升格为正式部活。

“研究会”可以作为同好会名称的一部分，不因此自动等于正式部活。

### 委员会

委员会不属于部活体系。

它包括图书、保健、环境、放送、选举等常设委员会，以及文化祭、体育祭、毕业等活动型执行委员会。委员会工作不计为兼部，但学生仍需现实协调时间。

## 三、兼部

乃校原则上采用：

> **一个主部 + 一个低频部活或同好会。**

固定边界：

- 两个高频正式部活的兼部属于例外，需要双方顾问同意；
- 活动冲突时主部优先；
- 同一学生不能同时担任两个组织的部长、副部长或核心事务职位；
- 学生会、委员会虽不计入兼部数量，但不能被写成没有时间成本；
- 兼部是现实安排，不用于让主要人物任意进入所有场景。

## 四、参与规模

制作容量基线：

- 全校约 80%—85% 的学生至少参加一个正式部活或同好会；
- 无部活学生约 55—70 人，是少数但完全正常；
- 约 10%—15% 的学生存在兼部；
- 各组织合计约 315—325 个登记席位，对应约 290—300 名实际学生。

这些数字用于校验空间与群众规模，不是每学年不可变动的统计表。

### 弓道部

弓道部替代剑道部进入正式部活配置。

当前锁定：

- 大多数部员从高中才开始学习；
- 正常参加地区赛事与段位审查，但不承担热血全国制霸线；
- 活动认真、礼法明确，但不被写成森严或神秘组织；
- 高三按运动部赛程在最后一次主要地区赛事后引退；
- 独立弓道场采用约 28 米近的射程、五人立射位、安土、矢道、弓具库、更衣与安全围挡；
- 弓道场是学校长期为十几名学生保留的一块无法轻易挪作他用的安静土地，本身体现乃校的资源与教育选择。

剧中不使用“弓道像人生”“目标是自己”等解释性台词。弓道首先是学生每天真实进行的练习。

## 七、合唱部｜旗舰社团

乃校合唱部是传统强部，拥有很高的校内外声望和接近青年专业 ensemble 的训练水平。

它的强不依赖全国大会剧情证明。当前锁定：

- 重点是作品、演出、学校仪式、委约与长期校友记忆，不把竞赛升级作为主轴；
- 合唱部具备部长、副部长、学生指挥和 S1 / S2 / A1 / A2 声部长等成熟学生组织；
- 松隆子承担校内长期音乐教育与安全责任；
- 松下洸平等外部专业人士可在具体作品中获得清楚的艺术权限；
- 合唱排练室拥有稳定使用时段、谱库和档案，但不是合唱部可以排斥他人的私人领地；
- 低年级旁听高年级排练、跟随工作语言与纪律，是部内长期学习方式；
- 生田绘梨花作为正式部员承担钢琴伴奏及重要音乐协作，但不是合唱部最高学生职位；
- 中元日芽香是 S2 声部长；堀未央奈是一年级 S1 部员。

EP04—05 的高三 SSAA 文化祭节目来自合唱部，不来自 Eδ「合唱・舞台合奏」课程。

文化祭是多数文化部高三的引退节点，也是合唱部高三最后一次以本届高三为主体完成正式公共演出。剧中不必宣布“最后一场”；演出结束后，低年级自然接手日常训练、行政与空间管理即可。

若某一届确有秋季外部演出，个别高三可以延长参与，但不再继续掌握部内行政。这是现实例外，不改变文化祭后的交接基线。

## 八、文化部与正式课程的边界

正式课程与部活可以重叠使用教师、设备和空间，但不是同一组织。

- Eδ「合唱・舞台合奏」是高三学分课程；合唱部是跨年级长期组织；
- 美术部员可以修视觉课程，但艺术选修生不必加入美术部；
- 伊藤万理华可以在放学后继续课程与文化祭作品，却不因此自动成为美术部员；
- 西野七濑已属于美术部；
- 生田可以在没有合唱全体排练的日子预约琴房；
- 摄影、影像与映画研究可以共享设备，但保持正式部活、课程与同好会的责任区别。

艺术别馆只承接真正需要音乐、美术、摄影、影像设备的活动，不收容所有文化部。茶道、书道、文艺、学生会与委员会各自使用符合现实的其他空间。

## 九、高三引退

- 多数文化部：文化祭后引退；
- 多数运动部：最后一次主要地区赛事后引退；
- 学生会：按学校自治日程另行交接；
- 文化祭实委等活动委员会：项目结算完成后解散；
- 引退不等于学生从此不能进入原有空间，也不等于她们继续指挥下一届。

高三引退首先是学校组织开始不再依赖这一届学生，不拍成每个社团都必须举行一次告别仪式。
