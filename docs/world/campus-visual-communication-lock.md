# 乃木坂女学院｜校园视觉传达规范锁

> 状态：**LOCKED / 项目级世界规则。**
>
> 本文件负责校内正式通知、布告栏、学生自治告知、文化祭事务告知等公共信息在校园中的视觉呈现。其目标不是把学校做成“昂贵装饰很多”的名门，而是让秩序、克制与长期形成的审美习惯自然进入日常环境。

## 一、核心原则

> **乃木坂女学院的高雅，不靠信息抢眼，而靠信息被管理得很好。**

校内公共信息环境应给人以下整体感受：

- 低饱和；
- 整齐；
- 克制；
- 留白充足；
- 行距偏宽；
- 层级清楚；
- 不通过高刺激色彩争夺注意力。

固定美术原则：

> **没有任何一张通知在抢着让人看它。**

## 二、颜色规则

正式校内通知、学生会告知、文化祭执行事务通知等，原则上使用：

- 白；
- 米白；
- 浅灰；
- 灰蓝；
- 灰绿；
- 以及其他接近上述体系的低饱和颜色。

禁止把普通校内通知处理成商业街促销式视觉：

- 不使用大面积高饱和纯红、纯黄、荧光色作为底色；
- 不使用爆炸形 banner / 爆炸框；
- 不使用大量感叹号、夸张斜体、巨大描边字等抢眼手法；
- 不以颜色数量制造“热闹感”。

必要的警示、消防、安全、医疗等法定 / 安全标识可以服从其功能规范，不受“为了好看而降低识别度”的限制。

## 三、版式规则

学校公共通知存在稳定模板与长期形成的排版习惯：

- 纸张规格相对统一；
- 页边距充足；
- 标题、日期、正文、责任部门层级明确；
- 正文行距偏宽，不追求一页塞满；
- 文字与图形严格对齐；
- 装饰元素少；
- 不使用大面积手写爆炸字作为正式通知主体；
- 不为了“年轻”“活泼”而牺牲可读性和整齐度。

具体字体家族不在本轮锁定，但正式信息不得依赖夸张装饰字体制造气氛。

## 四、布告栏管理

校内布告栏不是自由覆盖式海报墙。

固定规则：

- 按区域 / 类别组织；
- 同类通知尽量维持统一规格；
- 纸张端正张贴，不故意歪贴制造手作感；
- 不互相大面积遮盖；
- 过期通知及时撤下；
- 即使文化祭临近、通知数量增加，视觉秩序仍然保持。

因此文化祭临近时，学校环境的变化应表现为：

> **通知变多了，材料变多了，抱东西的人变多了；但墙没有先乱。**

真正的忙乱首先发生在人、时间、空间与任务之间，而不是靠把校园变成高饱和海报海洋来表现。

## 五、学生自治与文化祭告知

学生会、文化祭执行委员会、社团可以制作校内活动告知，并允许在学校规范内保留一定个性，但仍受公共视觉规则约束。

允许：

- 小范围低饱和色差；
- 清楚的社团 / 项目标识；
- 合理的图形或插画；
- 在统一框架中的个性版式。

不允许：

- 商业促销式爆炸 banner；
- 高饱和多色竞争；
- 斜贴、层层覆盖形成的“热闹海报墙”；
- 为了文化祭气氛而让公共信息系统突然失去学校一贯的秩序。

## 六、正式通知与创作作品必须区分

学校视觉克制不等于压制学生创作。

以下空间可以拥有更自由、更强烈的视觉表达：

- 美术作品本身；
- 文化祭正式展陈内部；
- 经批准的舞台 / 展览视觉设计；
- 美术室、工艺工作区等创作过程空间。

固定区分：

> **行政 / 公共信息负责清楚与秩序；创作作品负责表达。**

不能为了证明学校高雅，把所有学生作品也做成统一低饱和；也不能把创作空间的自由视觉反过来扩散成全校公共布告栏的无序。

## 七、摄影与美术执行纪律

拍摄校园公共信息时：

- 不用高饱和海报作为快速制造“青春校园感”的捷径；
- 不把普通文化祭通知拍成插入特写或视觉高潮，除非剧情本身要求人物阅读其中具体信息；
- 普通经过场景中，通知应首先作为环境纹理存在；
- 校园高雅感通过低饱和、统一规格、留白、行距、整齐排列和维护状态体现，而不是通过金边、繁复纹样或“贵族学校”装饰符号硬性说明。

## 八、EP03 S05适用锁

EP03 S05中，生田与万理华前往音乐・美术别馆途中：

- 可以经过抱着文化祭材料的学生；
- 布告栏可以比平时多出几张文化祭相关通知；
- 这些通知必须服从本文件的低饱和、统一规格、克制版式规则；
- 摄影机不得停下来展示“热闹海报墙”，不得以公告栏制造青春MV式文化祭蒙太奇；
- 生田与万理华不特别看这些通知，继续自己的真实目的地。

该规则为项目级世界设定，后续EP04—EP05文化祭逐渐升温时继续有效。
