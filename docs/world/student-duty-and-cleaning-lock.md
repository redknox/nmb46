# 乃木坂女学院｜学生值日与清扫制度锁定

> 状态：**已锁定 / 世界观与学校运营规则。**
>
> 本规则用于解释乃木坂女学院作为资源充足的名门私立女子校，为什么仍然保留学生值日与教室整理。

## 一、核心理解

乃木坂女学院当然拥有专业后勤与清洁人员。

但学校不把“有能力购买服务”理解成“学生不必承担自己使用空间的任何责任”。

固定原则：

> **专业后勤负责专业清洁；学生负责把自己使用过的空间恢复到可继续使用的状态。**

因此学生参与日常整理不是因为学校缺钱，也不是劳动教育式表演，而是学院礼法与共同生活的一部分。

## 二、学生负责的范围

学生轮值的 `日直` / `清掃当番` 可包括：

- 黑板与讲台周边简单整理；
- 课桌椅归位；
- 教室内明显垃圾与纸屑；
- 当天配布物、班级用品的简单确认；
- 教室门前非常有限的共用区域整理；
- 终礼后的简单状态检查。

不把学生写成学校免费保洁工。

## 三、专业后勤负责的范围

专业人员负责：

- 厕所与洗手设施卫生；
- 公共区域深度清洁；
- 地板定期养护、打蜡；
- 高处玻璃、外墙、危险高度区域；
- 食堂专业卫生；
- 实验室、医疗与特殊废弃物；
- 大型活动后深度恢复；
- 旧礼堂、设备间等需要专业维护的空间。

学生不得因“传统”被要求承担具有明显安全风险或专业卫生要求的工作。

## 四、名门校气质

这套制度的教育逻辑不是：

> “你们也要吃苦。”

而是：

> **“不要把维持你舒适生活的人变成看不见的人。”**

学生可以在生活中非常习惯学校资源充足，同时仍然知道：自己制造的混乱至少应先由自己收拾到基本状态。

因此教室里的扫帚、抹布、垃圾分类、值日表可以真实存在，不削弱名门感。

反而能够避免把所谓“贵族学校”误写成所有生活劳动都会自动消失的幻想空间。

## 五、日直与清扫当番分开理解

### 日直

偏班级运转职责：

- 简单通知；
- 配布 / 回收协助；
- 黑板日期或班级记录；
- 终礼辅助；
- 必要时确认门窗、用品等。

### 清扫当番

偏空间恢复：

- 若干人一组轮值；
- 时长短；
- 只做学生可安全完成的轻量整理。

两者不必永远由同一组学生承担。

## 六、戏剧使用原则

1. 不把清扫拍成“大小姐第一次见扫帚”的廉价阶层笑话。
2. 有人擅长、有人马虎、有人嫌麻烦都可以，但所有人对制度本身并不陌生。
3. 普通学生同样承担值日与清扫，不能只让命名角色做。
4. 可以通过细节制造喜剧，例如谁总把桌脚摆歪、谁特别认真擦黑板、谁会把任务切得过细。
5. 清扫可以成为关系发生的空间，但不能自动把主演聚成固定小组。

## 七、现实参照方向

现实日本的历史悠久女子校、私立学校中，学生参与日直、教室清扫或清扫检查并不罕见；名门属性与学生承担轻量日常整理并不矛盾。

因此乃木坂女学院采用“专业后勤 + 学生整理自己使用空间”的混合模式。

固定理解：

> **资源充足，不等于责任外包。**

> **学生不是保洁人员，但也不是自己生活痕迹的旁观者。**
