# 乃木坂女学院财政 / 校友基金会 / 校友网络设定

> 状态：**WORLD CANON / LOCKED**
>
> 本文件定义乃木坂女学院的长期财政基础、校友基金会、奖助学金原则以及校友网络的背景性质。该设定属于世界观底层运行逻辑，不要求在正文明说。

---

## 1. 核心定义

乃木坂女学院不是“靠高学费维持豪华教育”的学校。

它真正的财政底座，是历代校友、校友配偶与相关家族长期积累形成的**乃校校友基金会**及其投资收益。

学校学费名义上处于传统顶级私立女校的高位，但其高教育质量、老建筑维护、艺术教育、奖学金和长期项目，主要依靠以下几类资金共同维持：

1. 学费及正常学校收入；
2. 学校法人依法获得的公共补助；
3. 校友基金会投资收益；
4. 校友、校友配偶、家族与企业的追加捐赠；
5. 特定项目专项基金与遗赠。

其中，第 3 项——**基金会投资收益**——是学校长期“不发愁预算”的真正基础。

---

## 2. 校友基金会

### 2.1 资本来源

基金会资本不是某一年突然形成的，而是经过数十年甚至上百年积累。

主要来源包括：

- 历代校友个人捐赠；
- 校友配偶与家族捐赠；
- 遗赠；
- 某届毕业生纪念基金；
- 企业或家族设立的指定教育基金；
- 早期实业家、财界人士留下的长期资产；
- 基金资产长期投资滚存收益。

一个重要背景原则：

> **前辈留下来的钱，不只服务前辈记得住的人，也服务她们永远不会认识的后来学生。**

基金会不是“学校缺钱时来救火”的临时捐赠池，而是跨世代资本池。

### 2.2 投资管理

基金会由专业管理 / 投资团队进行资产运用。

资产可包括：

- 上市与非上市股权；
- 债券；
- 不动产；
- 长期基金份额；
- 现金与低风险资产；
- 历史形成的少数企业持股或资产管理平台。

不设定为“校董亲自炒股”。

基金会有明确的投资政策、风险边界与年度可支出比例。

### 2.3 资助委员会

基金会另设专门委员会负责：

- 审核年度教育资助；
- 审核奖学金预算；
- 审核校园设施与长期维护项目；
- 审核大型资本性支出；
- 监督基金收益用途是否符合教育目的；
- 防止学校经营失误被无条件以基金兜底。

基金会投资团队负责“把资本继续变成资本”；资助委员会负责“哪些钱值得花”。

## 3. 学费与奖学金原则

### 3.1 名义学费高

乃校属于传统高端私立女子高中，名义学费与设施费处于较高水平。

具体年度数字不必频繁进入剧情，但世界观上可以理解为：

- 学费本身明显高于普通私立高中；
- 音乐、美术、体育、校舍维护、研修活动等成本都不低；
- 家庭若完全自费，整体年度教育支出属于“昂贵但符合名门私校预期”的水平。

### 3.2 奖学金非常优厚

乃校设有制度化、稳定、长期的给付型奖学金与费用减免。

可包括：

- 授业料全额免除；
- 授业料半额免除；
- 授业料 + 设施费减免；
- 必要时的教材、通学、修学旅行等学习生活支援。

核心原则：

> **不得因家庭经济原因，使已经通过乃校选拔、并能够完成学业的学生失去受教育机会。**

这不是临时慈善，而是基金制度的一部分。

### 3.3 奖学金与录取严格分离

乃校入学门槛高，学术与综合选拔标准严格。

**不能通过赞助、捐楼、校友关系或家族地位换取录取资格。**

即使是重要捐赠人的子女，原则上也必须通过相同入学标准。

校内文化对此非常明确：

> 捐赠可以买来一栋楼，买不来一个座位。

更正式的理解是：

> **豪门很多，但豪门不是门票。**

因此桥本这类家庭条件不同的学生，一旦通过选拔进入乃校，其“属于这里”的合法性与樱井、白石等人完全相同。

### 3.4 奖学金原则上保密

奖学金档位、减免比例与家庭经济资料原则上不成为学生社交身份。

同学通常不知道谁全免、谁半免。

老师也只有在履职确有必要时才接触相关信息。

目标是避免把学生固定成“贫困生”角色。

## 4. 乃校为什么能提供优厚教育环境

基金会长期收益，使乃校可以稳定承担普通学校很难长期承担的成本，包括：

- 高质量师资；
- 小班与高师生比；
- 音乐、美术、体育等高成本设施；
- 专业外聘教师与创作协力者；
- 老建筑持续维护；
- 传统校园风貌保存；
- 研修、合宿与大型学生活动；
- 对家庭突发困难学生的快速援助；
- 不因短期招生压力而降低教育与入学标准。

因此乃校的“豪门感”首先体现在学校本身，而不是要求每个学生都来自豪门。

一个编剧室内部可用的理解：

> **乃校真正的豪门感，在资产负债表上。**

## 5. 校友网络：隐形商圈 / 社会资本

### 5.1 非正式、非官方

除正式基金会外，历代乃校校友、配偶、父母、兄弟姐妹、家族成员与长期合作伙伴之间，经过数十年自然形成了一个低可见度、高信任度的人脉网络。

这个网络：

- 不是秘密结社；
- 不是学校官方机构；
- 不是基金会的附属商业平台；
- 不统一行动；
- 不以阴谋方式控制行业。

它更接近一种长期沉淀的**社会资本网络**。

### 5.2 可能覆盖领域

校友及相关人士可能分布在：

- 金融；
- 地产；
- 制造；
- 法律；
- 医疗；
- 教育；
- 文化；
- 出版；
- 媒体；
- 建筑；
- 政府与公共机构；
- 公益组织等。

于是商业机会、人才信息、合作介绍、投资机会与专业资源，会自然在关系网中流动。

编剧室可以把它理解为“乃校毕业生及相关人士形成的隐形商圈”，但正文不直接使用这一说法。

### 5.3 边界

必须保持以下边界：

- 基金会资金不能直接变成校友私人商业利益；
- 校友网络不能干预入学标准；
- 校友关系不能直接换取招生资格；
- 学校不以“培养商业联盟成员”为教育目标。

它只是精英教育长期运行后自然产生的附带社会结构。

### 5.4 正文使用原则

这一层主要作为背景存在，不在正文中解释。

如需自然泄露，可以只出现极轻的信息：

- “那家事务所负责人是学姐。”
- “我母亲认识她。”
- “基金会去年批了修缮预算。”
- “那架琴是某届校友捐的。”

观众只需要感觉：

> **这所学校的人际关系和时间都很深。**

不需要知道完整网络结构。

## 6. 与学生阶层差异的关系

乃校内部并非单一财富阶层。

它可以同时存在：

- 樱井式真正的豪门 / 家族资本；
- 白石式稳定中上层家庭；
- 普通稳定中产；
- 依靠奖学金进入并完成学业的学生；
- 家庭条件后来发生变化、获得临时资助的学生。

学校制度刻意避免把这些差异直接转化成“谁更属于乃校”。

因此阶层差异更适合在**放学以后、假期、进路选择与毕业后**逐渐重新显现。

一个重要世界观判断：

> **学校暂时把不同阶层的人放进了同一张时间表里；毕业以后，这张时间表才重新散开。**

这对 EP09《选择》尤其重要。

## 7. 唐泽寿明的制度位置

唐泽寿明不只是“有钱人代表”，也不是学校的财务反派。

更准确的制度定位为：

> **学校法人理事长代理，同时代表乃校校友基金会参与长期资产与资助监督。**

他不亲自负责日常证券交易，而是代表理事 / 委员会层面：

- 审视基金投资政策；
- 监督年度可支出比例；
- 审核大型资本项目；
- 确认基金收益是否被合理用于教育；
- 防止短期情绪透支长期资本；
- 在学校长期规划中代表“未来几十届学生”的利益。

他的核心不是“省钱”，而是：

> **基金会的钱不是这一届学生的钱。**

换言之：

> **他不是替现在的人省钱，而是替还没入学的人看钱。**

这使他在旧礼堂等重大项目里天然拥有长期视角。

---

## 8. 与其他成人角色的分工

- **天海祐希 / 校长**：学校应该如何教育、什么值得留下、什么必须改变；
- **唐泽寿明 / 学校法人 + 基金会代表**：这件事长期是否可持续，资本如何承担；
- **樱井母亲 / 校董与成熟治理者**：制度、治理与组织判断；
- **学生**：这一届真实感受到什么、愿意代表什么。

四者代表不同时间尺度。

---

## 9. 创作原则

1. 财政结构是世界运行逻辑，不是主线剧情；
2. 不写“神秘财阀操控学校”的阴谋感；
3. 不把豪门学生写成天然有权；
4. 不把奖学生写成“受恩者”；
5. 基金会与校友网络的存在应让学校更可信，而不是更浮夸；
6. 正文只在必要时泄露一角，不做制度说明书；
7. 核心主题始终是：

> **人会毕业，学校继续存在。**

而基金会提供的是这句话在财务与制度层面的物质基础。
