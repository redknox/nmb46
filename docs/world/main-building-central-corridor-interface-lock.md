# 乃木坂女学院｜中央楼梯厅 × 主走廊接口锁定

> 状态：**已锁定 / 权威补充。** 若旧文件仍把该接口列为未决，以本文件为准。

## 一、空间类型

中央楼梯厅与 Y2 主走廊之间不做完全敞开的现代大厅，也不设置整面可关闭大门。

固定理解：

> **老学校长廊走到中央，被深色木质框架轻轻截住；框后突然变亮、变高。中央节点不是大厅插进走廊，而是走廊在这里变厚了。**

## 二、三联式深色实木垛口

接口采用：

> **侧通行口｜中央框景口｜侧通行口**

- 左右通行口各约 **1.50 m**，承担真实人流；
- 中央框景口约 **3.60 m**，面对中央挑空与 X10 光轴，不作为主要通行带；
- 中央下部用深色实木栏杆 / 楼板边缘收住；
- X10 继续保持空轴，不落实体柱。

基本秩序：

> **通行｜观看｜通行。**

## 三、木构与标高

- X9 / X11 加强墙垛继续保留；
- 两侧回梯与中央挑空交界处设置深色硬木立柱 / 大扶手柱，与楼梯栏杆收头一体化；
- 顶部用连续深色实木门楣串联三联接口；
- 门楣下沿约 **+2.925 m**，与普通教学翼高窗窗头建立隐藏的水平秩序；
- 门楣以上继续保留浅色墙带到高天花，不做通顶木饰面；
- 走廊木护墙可自然延续进入垛口。

木材采用深栗色 / 旧欅木方向，允许扶手被摸亮、下部轻微磕碰、转角因长期使用略圆润；它应像原建筑长期使用后的木作，而不是现代酒店木皮。

## 四、视线原则

从东西长廊远望中央，首先看到的是：

> **深木框 + 框后的亮。**

不要求远距离就完整看到楼梯、南窗和正门；接近中央后，X10 光轴与楼梯才逐渐展开。

从楼梯向北回望，木柱会把横向主走廊自然切成几个画幅。人物经过时短暂出现又被墙垛遮住，这是建筑构造自然产生的效果，不另设摄影机关。

## 五、与已锁定楼梯的关系

接口必须服从既有中央主楼梯：3.00 m 中央主跑、2.40 m 半层平台、左右各1.50 m回跑、X10光轴及3F浅弧终点窗。

> **木垛口负责给空间厚度和历史秩序，不能压缩已锁定的交通净宽。**

## 六、下一步

中央楼梯 × Y2 主走廊接口不再是开放问题。下一步转入 **Y3—Y4 北侧历史房间带 / 北立面**，先决定原始2-bay房间的北窗、走廊侧门洞、厚墙与可调整隔墙，再讨论现代电梯和功能回填。
