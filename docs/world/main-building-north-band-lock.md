# 乃木坂女学院｜主教学楼北侧历史房间带锁定

> 状态：**已锁定 / 历史建筑壳体权威补充。** 若旧文件仍把北侧房间、北窗、走廊门洞或中央北室列为未决，以本文件为准。

## 1. 六间翼部历史房间

Y3—Y4 北侧先按 1920 年代原始建筑壳体理解，不按今天的现代功能倒推。

西翼 X3—X9、东翼 X11—X17 均采用 **2 + 2 + 2 bay**：每间约 **7.20 × 7.20 m = 51.8㎡**。六间房原始等级相同，不预设今天用途。

## 2. 北立面普通窗列

普通翼继续采用 **2窗 / 3.60m bay**，但北窗与南窗不同：

- 宽约 **2.25M = 1.0125m**；
- 高约 **4.5M = 2.025m**；
- 窗台 **2M = 0.90m**；
- 窗头仍为 **+2.925m = 6.5M**。

每间 2-bay 房因此有 **4扇北窗**。南北窗尺寸不同，但窗头严格共用 +2.925m 水平线。

单 bay 横向控制：

> **1M墙垛 + 2.25M窗 + 1.5M中墙垛 + 2.25M窗 + 1M墙垛 = 8M。**

## 3. Y3 走廊门洞

每间翼部历史房原则上只设 **一扇约1.05—1.125m单扇高木门 + 上亮子**；门与上亮子上沿继续收在 +2.925m。

门不居中：西翼三间偏东，东翼三间偏西，向中央形成镜像。Y3 走廊墙保持实体厚墙与深色木护墙，不做大面积内窗。

## 4. 原始厚墙

北侧 2-bay 分房线 **X5、X7、X13、X15** 锁为原始厚墙 / 柱墙带；X3、X9、X11、X17 也是重要历史体量边界。

现代小房间优先在单个 7.20 × 7.20m 壳体内部用后期轻隔墙产生，不随意拆除原始厚墙。

## 5. 中央北室

**X9—X11 / Y3—Y4** 设置约 **7.20 × 7.20m 的中央北室（Central North Room）**。它属于中央礼仪体量，不作为第七间普通房理解。

走廊侧：X10 正中设 **约1.50—1.60m双扇深色木门 + 上亮子**，与普通房的偏置单门形成等级差。

北立面：不用普通4窗，而采用 **3扇直窗头高窗**：

> **侧窗｜X10中央窗｜侧窗**

不重复南侧3F浅弧窗。

固定理解：

> **南侧中央轴负责被看见；北侧中央轴只需要让人感觉它一直存在。**

中央北室当前只锁建筑身份，暂不命名为校长室、学年室、进路室等现代用途。

## 6. 对后续改修的约束

- 现代电梯不得默认占据 X10；
- 电梯、无障碍卫生间及3F现代功能必须迁就六间历史房、中央北室和原始厚墙；
- 若冲突，优先使用旧房间边缘、轻隔墙区域或后期服务带。

北侧历史房间带 / 北立面至此不再是开放问题。下一步进入 **现代电梯与无障碍改修插入位置**。
