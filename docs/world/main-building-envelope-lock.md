# 乃木坂女学院｜主教学楼立面与楼梯窗锁定

> 状态：**已锁定 / 结构轴网的权威补充。**
>
> 本文件记录在 `main-building-structural-grid.md` 既有轴网基础上已经达成共识的柱式、南立面窗列、中央光轴与端部楼梯窗规则。若旧文件仍把这些项目列为“下一步”，以本文件为准。

## 一、普通翼实体柱 / 壁柱表达

- X 方向继续使用 3.60 m 标准 bay 节奏；
- Y1 / Y2 / Y3 / Y4 均可形成结构或墙体承重点；
- 普通翼大多数柱应被外墙、教室分隔墙或走廊墙吸收，不表现为连续裸露自由柱；
- 外部每个 3.60 m bay 形成轻微竖向壁柱节奏；
- 中央 X9 / X11 边界明显加强，视觉宽度可按约 1.5M—2M（675—900 mm）级理解；
- **X10 是严格几何 / 礼仪中心线，但不设置阻断视线的实体柱。**

固定理解：

> **中央体量的等级由边界变厚、窗列减速和 X10 空轴共同建立。**

## 二、普通教学翼南立面｜2窗 / bay

普通教学翼正式采用：

> **每个 3.60 m bay = 2 个主要高窗洞。**

不采用 3 窗 / bay。

单个普通窗洞当前控制尺度：

- 宽约 **2.5M = 1.125 m**；
- 高约 **5M = 2.25 m**；
- 窗台约 **1.5M = 0.675 m**；
- 窗顶约位于室内地坪以上 **2.925 m**。

因此每间 10.80 m 宽 Home Room 获得：

> **3 bays × 2窗 = 6扇高窗。**

“2窗 / bay”指两个建筑窗洞，不等于两块现代整幅玻璃。窗洞内部仍可通过上亮子、竖梃、上下分段等细分形成符合年代感的窗框系统。

### 单 bay 横向控制比例

可按以下次级比例理解：

> **225 + 225 + 1125 + 450 + 1125 + 225 + 225 = 3600 mm**

即边界 / 退让、第一窗、中间墙垛、第二窗、退让 / 边界共同形成稳定节奏。

## 三、中央 X9—X11 南立面｜三窗礼仪组

中央体量不复制普通翼的 4 窗，而采用：

> **窄窗｜中央主窗｜窄窗**

控制方向：

- 两侧窄窗约 **1.125 m** 级宽度；
- 中央主窗约 **1.80 m** 宽；
- 中央主窗位于 **X10 光轴**；
- 3F 中央主窗高度可提高到约 **2.70 m**；
- **3F 正中的中央主窗采用浅而克制的弧形 / 段拱上沿。**

弧形只作为最高层中央轴的等级变化，不教堂化、不巴洛克化，也不发展成夸张拱窗体系。

固定理解：

> **整栋楼最重要的轴线上，站着的不是柱子，而是光。**

从 3F 中央楼梯厅沿 X10 南望，应能建立：

> **中庭 → 樱花步道 → 正门**

的连续视觉轴。

## 四、东西端楼梯亭｜立面节奏与楼梯窗差异

东西端楼梯亭继续作为整栋横向建筑的 bookend volume，不把它们当成普通教学翼最后两个 bay。

已锁定：

- 每个端部楼梯亭仍占 2 bays = 7.20 m；
- 南立面不重复普通翼的 2窗 / bay；
- 每个端亭南面采用 **1窗 / bay，共2扇更大的高窗**，增加墙体重量并放慢正立面节奏；
- 真正表达楼梯运行的窗列优先出现在建筑东西端墙；
- 端墙楼梯窗允许按照半层平台标高错开，不与教室标准楼层窗线机械对齐；
- 当前优先发展的原始楼梯形式为 **U形折返楼梯**，西端半层平台靠西端墙，东端半层平台靠东端墙，使端墙高窗与平台直接咬合。

## 五、南立面总体节奏

主楼正立面从西向东形成：

> **2 — 12 — 3 — 12 — 2**

即：

> 西端楼梯亭2窗｜西普通翼12窗｜中央体量3窗｜东普通翼12窗｜东端楼梯亭2窗

建筑节奏因此形成：

- 两端减速、增加重量；
- 普通教学翼进入稳定重复；
- 中央再次减速并升一级；
- 再镜像回去。

## 六、后续设计顺序

在上述内容已经锁定的前提下，下一步继续坚持“建筑优先”：

1. 正式推演 **X9—X11 中央主楼梯的平面与剖面**；
2. 校核中央窗组与每层 / 半层平台的真实标高关系；
3. 完成东西端 U 形楼梯准确梯段、平台与端墙错层高窗；
4. 再处理现代电梯插入位置；
5. 最后才恢复高三现代功能房间排布。
