# 乃木坂女学院｜校园蓝本原则 V1

> 目标：避免“闭门造车”。校园空间要像真实学校一样能够被使用、被走动、被拍摄，并能长期支持人物调度与剧情设计。
>
> 当前状态：**Campus Map V1 已暂定定稿，并成为后续分场与空间设计的基线。** 详细建筑功能与相对位置见 `docs/world/campus-map-v1.md`。

## 一、不是复制现实学校

乃木坂女学院不直接等同于任何现实中的学校。

我们采用“复合参考”原则：

- **空间骨架与名门女子校气质：主要参考学習院女子中・高等科一类历史悠久、校园绿地与多栋建筑并存的学校；**
- **课程流动机制：参考东洋英和女学院等以 Home Room 为基础、学生依选修在不同教室移动的制度；**
- **旧礼堂：完全虚构。**

这样做有两个目的：

1. 获得现实空间逻辑；
2. 避免把虚构中的消防、无障碍、建筑老化等问题影射到某一所现实学校。

## 二、建筑审美方向

建筑整体正式锁定为：**传统大正风，简洁、优雅、克制。**

不采用过强的维多利亚式、巴洛克式或过度教堂化装饰。

视觉特征包括：

- 对称但不过分炫技的立面；
- 白色或浅色墙面；
- 深色木作与护墙；
- 高窗、拱窗等具有时代感但不繁复的细部；
- 深色屋面；
- 长走廊、自然光、木地板；
- 老建筑的沉静与日常使用痕迹并存。

目标不是“豪华”，而是：

> **一眼能看出历史、资源和秩序，却不会因为装饰过多而失去乃木坂式的轻盈与优雅。**

## 三、空间必须服务剧情

校园设计不是美术设定图鉴，而是编剧工具。

每个重要空间都要回答：

- 谁会自然经过这里？
- 从哪里走到这里？
- 多久能到？
- 谁不太可能无缘无故出现？
- 这里能不能被别人看见？
- 是公共空间、半公共空间，还是私人空间？

空间关系将决定人物相遇是否可信。

## 四、Campus Map V1 已锁定的关系

当前概念图已先行固定以下空间骨架：

- 南端正门；
- 正门至主教学楼的中央樱花主轴；
- 主教学楼位于中轴北端；
- 主楼东侧形成学生会、图书馆、档案等“制度与安静”区域；
- 主楼西侧形成食堂、保健室、旧礼堂等“生活与记忆”区域；
- 音乐与美术别馆位于东南；
- 运动场位于西北；
- 旧礼堂位于西南核心生活圈，附近预留未来新礼堂区；
- 西侧设置后勤入口，避免所有物资都从学校正门进入。

这套关系在后续分场中默认保持一致，除非编剧室明确升级 Campus Map 版本。

## 五、必要空间

### 校门

全剧最重要的时间节点。

功能：

- 第一集新生进入；
- 迟到、放学、忘带东西；
- 门卫长期见证；
- 最终回一期生真正离开。

访客与外校联合项目参与者使用真实入校管理：

- 普通来校者在指定入口登记，领取颈挂式 `入校証 / 来校者名札`，离校时返还；
- 事前登记的外校联合项目学生可由学校按名单准备“共同制作・入校証”，卡面标学校、身份与编号，实名留在门卫 / 事务室名单；
- 外校教师使用同系列教职员版本；
- 袖标保留给文化祭执行、引导、警备、摄影许可等具体职务，不代替访客身份；
- 涉及材料搬运时，挂绳使用安全脱离扣，卡片固定在胸前，避免晃动与勾挂。

### 主教学楼

包含主要 Home Room、普通课程教室、教师办公空间等，是学生日常路线核心。

### 学生会室

樱井与真夏的主要制度空间，靠近主楼中枢但略有独立性。

### 图书馆

桥本的重要空间，也适合飞鸟、西野等需要安静的人。应与主楼保持“课间可达、但需要主动去”的距离。

### 音乐与美术别馆

采用两层、音乐西翼 / 美术东翼 / 中央公共区结构。包含音乐教室、六间练习室、合唱 / 器乐空间、Open Studio、美术展示区、材料工作室、摄影、暗房与数码影像空间。

生田日常使用的专业音乐空间与 Fukase 所在的旧礼堂地下创作空间，气质必须明显不同。

内部权威布局、容量、设备和 EP04—05 连续性见 `docs/world/music-and-art-annex-lock.md`。

### 食堂

本剧重要的“共同生活空间”。由于主要成员不全同班，它承担跨班、跨选修路线重新汇合的功能。

### 保健室

学生身份暂时失效、只剩身体状态的空间。

### 校史资料室

偏安静、略离主流动线，适合校史、旧照片、旧礼堂资料和毕业整理。

### 体育设施

西北体育区包括现代体育馆、室外综合运动场、三面硬地网球场，以及靠校园边界设置的独立五人立弓道场。

体育馆包含主竞技场、副馆与镜面多目的练习室，并具备在旧礼堂停止大型使用后承接正式毕业典礼的容量与后勤条件。综合运动场使用约 200—250 米训练环道、短直道与基础田径设施，不设置占地过大的正规 400 米田径场。

田径部完整赛道训练可以使用公共体育设施；校园训练路线可自然通向外围道路。

第8集接力要让校园内部与校外城市空间连成一张青春地理图。

### 旧礼堂

完全虚构。

重要特征：

- 建于1931年，以昭和初期学校近代建筑延续校园大正末期秩序，漂亮但不过分华丽；
- 当前约560席，东侧观众入口与西侧后台物流分离；
- 仍能高质量承担典礼、文化祭、合唱与换场，但已经出现现代公共使用障碍；
- 正门有三级石阶，连续无障碍进入依赖事前安装的模块坡道；
- 具有真实可工作的舞台、侧台、准备区、库房，以及舞台右后方服务翼下的局部地下音乐空间；
- 第10集进入正式评估与改建决策。

完整权威设定见 `docs/world/old-auditorium-space-lock.md`。

### 新礼堂

不是简单“替代品”，而是把部分旧材料重新纳入新建筑。

季末必须看见：

- 无障碍通道；
- 轮椅观众位置；
- 旧舞台木地板等真实材料继续参与新的空间。

## 六、现实参考的使用原则

现实学校给我们：

- 建筑尺度；
- 楼与楼之间的距离感；
- 教学、艺术、体育空间如何分布；
- 老建筑与新设施共存的方式；
- 学生每天实际会怎么移动。

现实学校**不**给我们：

- 虚构剧情中的安全问题；
- 虚构校董冲突；
- 虚构建筑评估结论；
- 虚构角色的家庭与阶层。

## 七、拍摄一致性原则

空间圣经至少持续维护：

- 建筑相对位置；
- 主要入口；
- 楼层；
- 连廊 / 楼梯；
- 从 A 到 B 的典型步行时间；
- 哪些窗户能看见哪些区域；
- 旧礼堂与主教学楼的关系；
- 食堂、图书馆、学生会室的日常动线。

避免出现：

- 上一集图书馆在东侧，下一集突然从西侧出来；
- 一个角色刚在运动场，几十秒后无解释出现在旧礼堂地下；
- 为了对白方便，把任何人随时传送到任何地点。

## 八、下一步

Campus Map V1 之后，空间工作进入第二层：

1. 主教学楼内部楼层与 Home Room 分布；
2. 学生会室、图书馆、艺术别馆之间的步行时间；
3. 雨天路线、连廊、楼梯和视线关系；
4. 运动场到校外的接力路线；
5. 新礼堂内部无障碍与旧材料再利用位置；
6. 在此基础上再正式分配高三班级和主要选修课表。
