# 乃木坂女学院｜3F E2 / E3 Seminar 锁定

> 状态：**已锁定 / `high3-modern-layout-lock.md` 的权威补充。**

## 1. 空间身份

E2 / E3 均为完整约 7.20 × 7.20m 历史房壳体，作为高三讲授、讨论、研究演习与小规模选修空间使用。

两室建筑与设备等级等价，不预先指定固定学科。

> **主楼 Seminar 服务“听讲、讨论、阅读、研究”型课程；音乐、美术、造型等艺术实践课不在主楼进行。**

艺术实践继续使用艺术附楼、音乐室、旧礼堂音乐空间等相应专业场所，不为人物剧情把钢琴、画架或大型艺术设备临时搬入 E2 / E3。

## 2. X15 教学脊柱

E2 与 E3 以 X15 原始厚墙背靠背形成教学面：

- E2 教学面朝东；
- E3 教学面朝西；
- X15 厚墙本体不得因现代设备大面积切削或拆除；
- 线缆、控制与检修从外围木护墙、天花边缘或可逆服务层进入。

每侧设置约 3.60m 级深色木作教学框架。常态首先读成传统哑光书写板；现代显示屏或投影幕可隐藏在滑动板、柜体或上方机构中，需要时才出现。

> **现代教学设备可以很先进，但不应在不用的时候成为房间最显眼的东西。**

## 3. 席位与家具

- 常态 **16席**；
- 必要时可扩至 **20席**；
- 采用 8 张两人用独立木桌作为常态家具，并保留同系列备用桌；
- 椅子与桌子分离，可独立移动、围合、转向；
- 不设固定讲台；教师只使用可移动小桌；
- 家具允许快速形成短讲、U形、讨论围合等不同课堂状态。

不以20席满铺作为日常状态，避免房间退化为普通 Home Room。

## 4. 北窗、储物与设备

四扇原北窗全部保持清爽，不以固定柜体遮挡。

- E2 储物 / 设备家具优先靠 X13 外侧实墙；
- E3 优先靠 X17 外侧实墙；
- 柜体作为高质量后期家具存在，不把整面历史墙装修成现代系统柜；
- 电源、网络主要沿教学墙、外围木护墙及设备柜布置，不在原木地板上成排设置地插。

## 5. 照明与门牌

照明需比 Central 更均匀，但不使用办公室式 LED 平板灯或工业风轨道灯。采用克制的现代灯具与独立教学面补光；北窗遮光设施隐藏整合，不裸露廉价卷帘机构。

走廊门仍保持原历史高木门 + 上亮子。门牌采用克制的小型深色金属 / 黄铜牌，可标为：

> **演習室 一｜演習室 二**

不使用“未来学习空间”等炫耀式现代命名。

E2 / E3 Seminar 家具与教学设备至此不再开放。
