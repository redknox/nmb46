# 下一届学生｜使用原则 V1

> 核心：下一届必须真实存在，但不能把一期生的毕业季抢走。

## 一、原型

可以使用乃木坂46二期生、三期生作为一年级学生的原型与演员来源。

例如堀未央奈可以作为较容易被观众记住的一张新生面孔。

但剧内原则是：

- 不承担独立主线；
- 不设置与一期主角竞争的故事重心；
- 可以有一小段完整、尊重人物尊严的局部闭环；
- 可以不命名，或只在 Staff Roll 中以“一年生A”等形式出现；
- 重点是形成“下一代已经在走廊里”的感觉。

更严格的尺度是：

> **她可以让观众记住，但不能让观众开始期待“下一集她怎么样了”。**

换句话说：

> **有脸、有生活、有尊严，但没有抢戏权。**

## 二、为什么使用后辈成员

普通观众会得到：

> 这些一年级好像经常见到。

熟悉乃木坂的观众会得到：

> 下一代已经来了。

但镜头仍然牢牢跟随一期。

这种“双重阅读”比明确告诉观众“时代交替”更有余味。

## 三、二期 / 三期不必按现实加入顺序分年级

电视剧内部不是乃木坂历史纪录片。

可以把二期、三期成员混合为同一个“一年级世代”，服务一个更抽象的主题：

> 一期即将离开，而之后的人已经开始生活。

不需要为了现实偶像史再设计高二、高一的严格映射。

## 四、使用密度

建议设置 3—4 张会反复出现的熟脸即可。

她们可以出现在：

- EP01 入学；
- EP02 上课、值日、午休；
- EP03—05 文化祭准备与现场；
- EP08 接力赛沿途；
- EP10 旧礼堂 / 新礼堂讨论的背景；
- EP11—12 毕业典礼与校园日常。

但不需要每次都给台词。

## 五、堀未央奈｜一年级生 / 文化祭最终舞台成员

堀未央奈可作为一年级生中最容易被观众记住的一张脸。

她的核心质感：

> **柔弱的坚强。**

表面纤细、认真、容易让人担心，但不是“需要保护”的角色。

她真正的强韧不是永远撑住，而是：

> **承认“现在不行”以后，仍然能够自己决定“再试一次”。**

### 前置存在

她不能在 EP05 为了情绪功能突然出现。

建议轻量铺陈：

- **EP01**：作为新生群体中的熟脸出现。跟随队伍入校、整理领结、找教室；可与生驹产生一次非常短的引导互动。不要与轮椅新生合并为同一角色。
- **EP02**：晨读或课堂中出现。被老师点到时声音不大，但读得清楚、认真。
- **EP03**：文化祭报名或合唱 / 最终舞台报名中出现。旁人问“你要报名？”她只回答“嗯”。
- **EP04**：合唱排练背景。高山可以随口说一句“声音意外挺大的嘛”，她反问“……意外是什么意思？”保持轻。

这些都不能形成独立副线。

### EP05 小闭环

文化祭当天，她已经准备充分，也一直认真配合。

通过短镜头反复表现：

1. 开心换演出鞋；
2. 坐后台等——“再等等。” “好。”
3. 被叫起——“现在吗？” “不，先等等。”
4. 又被叫走，走几步，再被告知“先别去”。

直到她终于很平静地说：

> “对不起，我上不了了。”

这不是“胆小学生害怕舞台”，而是一个一直努力配合的人终于到了极限。

高山、南、深川等人都不能把她“治好”。

- 高山可以先接受：“好，那不上。”
- 南可以递糖；
- 深川可以陪着；
- 没有人要求她证明勇敢。

之后在生田即兴钢琴形成的弹性时间里，她自己站起来：

> “……我再试一次。”

高山只回答：

> “嗯。”

南把剩下的糖塞给她。

不鼓掌，不励志，不总结。

这就是她在全季已经足够的一段空间。

### EP05 之后

她重新退回校园背景。

可以在：

- EP11 毕业典礼一年级席位；
- EP12 校园远景 / 走廊；

自然出现，但不需要继续追踪“她后来怎么样”。

一期与她也不必因此建立长期深交。

她们只是某天下午在她需要的时候陪过她十分钟。

这比“学姐改变了她的一生”更符合本剧关系观。

## 六、轮椅新生

使用轮椅的新生同样属于“一年级世代”中的普通学生，不作为议题角色或固定配角。

第一集：旧礼堂缺乏无障碍通道，她在本人同意下由教职员协助进入。

季末：新礼堂中，她自然通过无障碍通道进入，并停在轮椅观众位置。

不安排解释性对白。

这个回收表达的是：

> 学校真的改变了使用方式，而不是只在理念上完成了一次胜利。

## 七、禁止事项

不要：

- 给堀未央奈等后辈安排“接班人”式明确台词；
- 写成一期学姐逐一把精神传给后辈；
- 用后辈角色解释乃木坂历史；
- 在最后两集突然让某个一年级生成为新主角；
- 让毕业变成“交棒仪式”；
- 因为 EP05 得到一个漂亮小闭环，就继续为堀未央奈追加个人成长线；
- 把一期帮助她写成“改变了她的人生”。

一期离开以后，学校自然继续。

高一学生第二天仍然要上课。

她们甚至未必理解高三学生为什么会对某些普通校园细节如此舍不得。

这才是真正的世代交替：

> **不是正式把什么交给下一代，而是下一代早就已经在这里生活。**
