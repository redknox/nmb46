# 下一届学生｜使用原则 V1

> 核心：下一届必须真实存在，但不能把一期生的毕业季抢走。

## 一、原型

可以使用乃木坂46二期生、三期生作为一年级学生的原型与演员来源。

例如堀未央奈可以作为较容易被观众记住的一张新生面孔。

但剧内原则是：

- 不承担独立人物弧；
- 不设置与一期主角竞争的主线；
- 可以不命名，或只在 Staff Roll 中以“一年生A”等形式出现；
- 重点是形成“下一代已经在走廊里”的感觉。

## 二、为什么使用后辈成员

普通观众会得到：

> 这些一年级好像经常见到。

熟悉乃木坂的观众会得到：

> 下一代已经来了。

但镜头仍然牢牢跟随一期。

这种“双重阅读”比明确告诉观众“时代交替”更有余味。

## 三、二期 / 三期不必按现实加入顺序分年级

电视剧内部不是乃木坂历史纪录片。

可以把二期、三期成员混合为同一个“一年级世代”，服务一个更抽象的主题：

> 一期即将离开，而之后的人已经开始生活。

不需要为了现实偶像史再设计高二、高一的严格映射。

## 四、使用密度

建议设置 3—4 张会反复出现的熟脸即可。

她们可以出现在：

- EP01 入学；
- EP02 上课、值日、午休；
- EP03—05 文化祭准备与现场；
- EP08 接力赛沿途；
- EP10 旧礼堂 / 新礼堂讨论的背景；
- EP11—12 毕业典礼与校园日常。

但不需要每次都给台词。

## 五、轮椅新生

使用轮椅的新生同样属于“一年级世代”中的普通学生，不作为议题角色或固定配角。

第一集：旧礼堂缺乏无障碍通道，她在本人同意下由教职员协助进入。

季末：新礼堂中，她自然通过无障碍通道进入，并停在轮椅观众位置。

不安排解释性对白。

这个回收表达的是：

> 学校真的改变了使用方式，而不是只在理念上完成了一次胜利。

## 六、禁止事项

不要：

- 给堀未央奈等后辈安排“接班人”式明确台词；
- 写成一期学姐逐一把精神传给后辈；
- 用后辈角色解释乃木坂历史；
- 在最后两集突然让某个一年级生成为新主角；
- 让毕业变成“交棒仪式”。

一期离开以后，学校自然继续。

这比正式宣布“接下来交给你们了”更符合本剧气质。
