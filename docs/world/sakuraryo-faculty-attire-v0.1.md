# 榊陵学院｜教职员服装与两校差异 V0.1

> 状态：**工作稿 / 非锁定。**
>
> 目的：在不把榊陵写成“自由先进男校”的前提下，让教师服装与工作方式自然体现两校不同教育文化。

## 一、核心差异

乃木坂女学院与榊陵学院同样是传统名门，也都要求教师整洁、专业、符合场合。

差异不在于：

> 乃校正式，榊陵随便。

而在于两边如何理解“专业成年人应该被学生看见成什么样”。

### 乃木坂女学院

更强调：

> **我进入学校以后，也成为这个共同体视觉秩序的一部分。**

因此教师个人差异受到较强的整体礼仪约束，服装趋于克制、完整、低噪声；状态变化多通过脱外套、换专业工作服等方式完成。

### 榊陵学院

更强调：

> **我需要为自己的判断、知识与言论负责，不需要和同事看起来一样。**

因此同样整洁专业，但允许教师在经典职业服装内部保留更明显的个人选择：

- 单西 / odd jacket 而非总是成套西装；
- 海军蓝 blazer + 灰色长裤；
- tweed、flannel、corduroy 等传统材质；
- Oxford 衬衫；
- knit tie、条纹领带、较有个人长期习惯的领带；
- loafers / derby 等；
- 教学中根据讨论状态脱外套、卷袖、把椅子拉入学生讨论圈，但结束后自己恢复空间。

这不是“不讲礼仪”，而是一种更接近旧式大学、法政、外交与公共教育传统的职业感。

固定对照：

> **乃校的教师像“已经整理好的房间”。**
>
> **榊陵的教师像“正在使用中的书房”。**

两边都高级；一个重秩序完成度，一个重使用痕迹与个人判断。

---

## 二、正式场合

两校在入学式、毕业式、正式家长活动、校际正式会议等场合都回到高正式度。

榊陵不能为了做差异，在典礼上仍然穿松垮单西。

差异只保留在细节：

- 乃校教师群体视觉更统一、色彩更克制；
- 榊陵教师同样穿完整西装，但领带、马甲、面料、鞋等个人差异略更多；
- 两边站在一起时，观众感觉不是“谁更有礼貌”，而是两个机构长期形成的不同审美习惯。

---

## 三、普通教学日的榊陵教师轮廓

榊陵普通教学日允许：

- navy blazer / tweed jacket / dark odd jacket；
- grey / charcoal / brown trousers；
- Oxford 或普通衬衫；
- 领带根据教师习惯与课程场合决定，不要求所有人同一正式度；
- 夏季可以无领带，但仍保持有领上衣与职业鞋履；
- 课堂讨论升温时可自然脱外套、卷袖一到两折；
- 衣服必须干净，卷袖也要像“正在工作”，不是“懒得整理”。

不推荐：

- T 恤 + 牛仔裤成为普通文科教师日常；
- 球鞋 / 运动裤在学术教学楼成为默认穿法；
- 用皱、旧、脏来表达“有思想”；
- 用过度英伦复古把全校教师做成 costume drama。

## 四、山下智久｜英语教师 / 国际交流负责人

核心：**年轻、国际化，但首先是榊陵教师，不是“帅哥老师”。**

推荐基础状态：

> navy blazer + 浅蓝 / 白 Oxford 衬衫 + 灰色长裤 + 简洁皮鞋。

领带：

- 正式交流会议、接待外校、演讲活动时佩戴；
- 普通教学日可用 knit tie；
- 夏季 / 内部课堂可不系领带，但不能靠解很多扣子制造随意感。

他的“年轻”主要来自：

- 面料更轻；
- 动作更快；
- 文件、平板、资料切换效率高；
- 更自然地在课堂中承认“这个我现在不知道，我确认以后再回答”。

### 到乃木坂女学院时

一个非常有价值的小动作：

他从榊陵步行来到乃校参加正式交流会议。

进入乃校行政区域 / 会客空间前，会自然：

> 把 blazer 前襟整理好；如果原本没系领带而场合要求更正式，则提前恢复完整状态。

不是因为“乃校可怕”，而是他知道自己正在进入另一所学校的礼仪语境。

这能显示：

> **真正熟悉两校的人，会自然切换场合语言。**

乃校学生注意到他时，也不需要用“今天特别帅”说明差异；他的轮廓本身就与乃校男教师略有不同。

---

## 五、仲野太贺｜榊陵国语教师

核心：**比武田更像“正在讨论中的老师”，但不是武田的年轻版。**

推荐基础状态：

> tweed / 深色单西 + Oxford / 普通衬衫 + 深色长裤 + 皮鞋。

领带使用比山下更随个人习惯：

- 可以长期偏爱 knit tie / 素色领带；
- 也可以普通教学日不系领带；
- 正式校际活动一定恢复完整。

课堂状态：

- 很可能穿着外套开始；
- 学生开始追问、讨论拉长以后，他会自己把外套脱下来搭在椅背；
- 必要时把袖子规整卷两折；
- 可以把自己的椅子拉到学生讨论圈，但课后自己推回原位。

这与榊陵已锁定的空间气质一致：

> **可以把椅子拉出来和老师认真争十分钟，争完自己推进去。**

他的衣服因此不是性格标签，而是课堂“开始真正发生讨论”的温度计。

### 与武田的视觉差异

武田：

> 外套挂好 → 马甲 + 领带 → 袖カバー → 讲台 / 黑板。

仲野：

> 单西开始 → 讨论升温 → 外套搭椅背 → 袖口卷起 → 和学生一起陷进问题。

两个人都是国语教师，都认真，但“认真”的身体语法不同。

武田更像：

> **我把很多届学生送到这里。**

仲野更像：

> **这个问题我也可以和你们一起重新想。**

## 六、两校教师同框时的视觉目标

当两校教师在联合项目、文化祭、国际交流、公开讲座中同框，服装不应变成阵营制服。

希望观众获得的感觉：

```text
乃木坂女学院教师
整体轮廓更统一、更安静、更“完成”

            ↕

榊陵学院教师
经典职业服内部个人差异更多、更“正在使用”
```

例如：

- 乃校教师会议桌一侧，多数外套、文件、坐姿都有明确位置；
- 榊陵教师一侧有人是完整 suit，有人 navy blazer，有人 tweed；
- 会议开始以后两边都非常认真；
- 真正差异来自谁先发言、谁追问、谁要求形成结论，而不是衣服决定谁“更自由”。

---

## 七、禁区

1. 不把榊陵教师写成“西装不系扣、咖啡杯、卷袖、自由派”的广告模板。
2. 不把乃校教师写成拘谨压抑，把榊陵教师写成先进开放。
3. 不把山下的服装服务于“帅哥出场”。
4. 不把仲野做成故意邋遢的文学青年。
5. 不让两校教师服装差异大到像不同国家或不同年代。
6. 正式场合两边都必须有传统名校应有的完成度。

---

## 八、当前工作结论

暂定最小对照句：

> **乃校要求成年人先把自己整理好，再进入学生的世界。**
>
> **榊陵允许成年人带着自己的工作痕迹进入学生的世界，但必须对它负责。**

本稿暂不锁定；后续可继续加入榊陵其他教师 / 管理者，确认男女教师共同规范、体育教师、理科教师与行政职员如何体现同一套学校文化。
