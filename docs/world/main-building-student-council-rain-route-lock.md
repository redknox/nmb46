# 乃木坂女学院｜学生会连廊雨天路线锁定

> 状态：**已锁定 / 主教学楼2F东端学生会路线权威补充。**

## 1. 连廊类型

主楼2F东端至独立学生会建筑的连接定义为：

> **半外部有顶连廊。**

不是全封闭空调玻璃天桥。普通雨天中央通行带保持干燥，但学生仍能感受到室外的雨声、光线与温度变化。

## 2. 主楼一侧

路线继续服从既有锁定：

> **2F主走廊 → 东端2.70m北侧转换厅 → 连廊 → 学生会建筑。**

2F东转换厅保持纯室内干区，不设置长期伞架、纸箱或学生会杂物。湿区从历史外墙之外、连廊门外开始。

主楼连廊门作为后期现代插入，可采用克制的深色细框玻璃防火门；不伪装成原始1920年代历史门。

## 3. 地面与无障碍

- 主楼老木地板延续到门边；
- 连廊侧立即转换为耐候、防滑地面；
- 无台阶、高差障碍；
- 门外处理刮水、吸水与排水；
- E1电梯 → 2F主走廊 → 东转换厅 → 连廊 → 学生会，保持连续无障碍路线。

## 4. 学生会建筑一侧

连廊进入学生会建筑后，先经过小型入口前厅，再进入主要办公/会议空间。前厅只承担挡风、缓冲、短时放置，不发展成休息室。

## 5. 雨天空间规则

> **主楼和学生会之间不是一段室内走廊，而是一小段被屋顶保护起来的天气。**

主楼2F长廊原则上保持干燥；湿脚印和雨水使用痕迹集中在连廊及两端入口附近，不一路拖回主楼中央。

该雨天路线压力测试通过，至此不再开放。
