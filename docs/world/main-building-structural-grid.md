# 乃木坂女学院｜主教学楼结构轴网

> 状态：**设计原则已锁定，具体轴网逐项确认中。**
>
> 本文件只回答主教学楼作为一栋大正时期名门女学院建筑“本来是怎样建出来的”。现代房间用途、学生动线与剧情使用必须在这套结构上继续设计，而不能反过来为了剧情塑造建筑骨架。

## 一、最高设计原则｜已锁定

主教学楼不是一栋现代学校再套上“大正风”装修，而是一栋真正具有历史连续性的名门女学院主楼。

固定设计顺序：

> **先有柱，再有墙；先有建筑，再有房间；先有历史，再有剧情。**

因此后续平面设计按照以下顺序进行：

1. 先确定基础比例模数；
2. 确定结构柱轴、柱间距、层高与外墙窗列；
3. 确定中央轴、端部楼梯与主要历史空间；
4. 再判断哪些柱网之间适合围合成 Home Room、教师空间、阅览 / 准备空间等原始房间；
5. 最后才把今天需要的進路指导室、面谈室、高三学年室、自习室、Seminar、电梯、卫生间等现代功能嵌入既有结构。

不能为了制造角色相遇、视线或青春片桥段，先设计一个“方便拍戏”的现代校园，再倒推柱网。

## 二、建筑气质｜已锁定

主楼主体建于大正时期，整体采用当时名门教育机构能够承担的高规格尺度，并带有克制的新古典主义秩序感。

关键词：

- 横向展开；
- 严格中央轴；
- 东西对称；
- 横平竖直；
- 明确而重复的柱间节奏；
- 高层高；
- 宽走廊；
- 大教室；
- 规则高窗；
- 中央与端部体量有清楚等级；
- 豪华感主要来自比例、材料与“空间用得起”，而不是后期装饰堆砌。

它可以经过长期现代化改修，但改修的基本态度是：

> **现代功能迁就旧建筑，而不是旧建筑为了现代功能重新长成一栋现代公建。**

电梯、无障碍卫生间、消防分区、空调、电气、网络等必须真实存在，但应尽可能利用既有柱网、次级空间与后期服务带嵌入，不破坏中央历史轴线与主要比例。

## 三、尺度方向｜已锁定

主楼不能按普通青春剧学校的紧凑尺度理解。

固定尺度感：

- 主走廊是明显宽裕的历史校舍长廊，可进入约 3—4 米级别，而不是只够两三人错身的现代最小尺度；
- 主要楼层净高应有约 3.5 米级别的高大感，具体 floor-to-floor 尺寸由比例模数继续推导；
- 南侧 Home Room 为大教室，30 张单人课桌摆入以后仍有明显余量；
- 教室允许长期存在立式钢琴、大型地球仪、地图架、书柜、植物、旧式大型教具等，而不是把所有边角都塞满课桌；
- 门窗、欄间、腰墙、讲台和黑板的比例都应服从高层高，不按普通现代校舍的小尺度直接套用。

固定审美判断：

> **名门感不是“东西更贵”，而是这栋楼从一开始就没有被迫把每一平方米用到极限。**

## 四、柱网 / 比例设计方法｜已锁定

柱、墙、门窗与主要长度使用统一比例语言。

下一阶段先确定一个基础模数 `M`，再用其整数倍组织：

- 可见柱 / 壁柱宽度；
- 主柱间距；
- 教室开间与进深；
- 走廊宽度；
- 楼层层高；
- 窗宽、窗间墙与门洞；
- 中央楼梯厅宽度；
- 东西端楼梯体量。

目前 `M = 450 mm`、主柱间 `8M = 3.60 m` 是下一轮优先检验的候选比例，**尚未在本文件锁死为最终工程尺寸**。

这里的 M 首先是建筑比例模数，不等于所有结构柱在每一层、每一方向上的实际工程截面都必须机械地等于 M；真正结构尺寸以后仍需服从合理工程逻辑。

## 五、对现有 3F 功能稿的影响｜已锁定

`docs/world/high3-floor-layout.md` 中已经确认的以下内容继续有效：

- 高三需要哪些功能；
- 四个 Home Room 的人物分班；
- 3-A / 3-B 位于中央轴西侧、3-C / 3-D 位于中央轴东侧这一大关系；
- 东西端存在可日常使用的安全楼梯；
- 学生会室仍通过 2F 东侧有顶连廊连接；
- 主楼具有完整现代无障碍能力；
- 走廊允许真实停留，但不是为了剧情专门雕刻的青春片式社交节点。

但此前按现代功能直接排列出的：

- 進路指导室 / 面谈室 / 学年室 / 资料室的精确线性门位顺序；
- 自习室 / Seminar 的精确门位顺序；
- 两个特定“休息凹区”的精确位置；
- 电梯与中央历史轴线的精确视觉关系；

**全部需要在结构柱网确定后重新验证。**

这些旧方案可以作为功能邻接需求参考，但不得约束历史建筑骨架。

## 六、下一步

下一轮只画原始结构，不写现代房间名：

1. 确定东西方向主柱间数量；
2. 确定中央楼梯厅占几个柱间；
3. 确定东西端楼梯体量各占几个柱间；
4. 确定南北方向教室带 / 主走廊 / 北侧房间带的结构深度；
5. 得到一张只有柱轴、中央轴、端部楼梯与外墙的“空骨架”三楼平面；
6. 再把 Home Room 和现代功能放回去。
