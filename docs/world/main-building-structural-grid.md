# 乃木坂女学院｜主教学楼结构轴网

> 状态：**结构设计方法与第一版主轴网已锁定。**
>
> 本文件只回答主教学楼作为一栋大正时期名门女学院建筑“本来是怎样建出来的”。现代房间用途、学生动线与剧情使用必须在这套结构上继续设计，而不能反过来为了剧情塑造建筑骨架。

## 一、最高设计原则｜已锁定

主教学楼不是一栋现代学校再套上“大正风”装修，而是一栋真正具有历史连续性的名门女学院主楼。

固定设计顺序：

> **先有柱，再有墙；先有建筑，再有房间；先有历史，再有剧情。**

因此后续平面设计按照以下顺序进行：

1. 先确定基础比例模数；
2. 确定结构柱轴、柱间距、层高与外墙窗列；
3. 确定中央轴、端部楼梯与主要历史空间；
4. 再判断哪些柱网之间适合围合成 Home Room、教师空间、阅览 / 准备空间等原始房间；
5. 最后才把今天需要的進路指导室、面谈室、高三学年室、自习室、Seminar、电梯、卫生间等现代功能嵌入既有结构。

不能为了制造角色相遇、视线或青春片桥段，先设计一个“方便拍戏”的现代校园，再倒推柱网。

## 二、建筑气质｜已锁定

主楼主体建于大正时期，整体采用当时名门教育机构能够承担的高规格尺度，并带有克制的新古典主义秩序感。

关键词：

- 横向展开；
- 严格中央轴；
- 东西对称；
- 横平竖直；
- 明确而重复的柱间节奏；
- 高层高；
- 宽走廊；
- 大教室；
- 规则高窗；
- 中央与端部体量有清楚等级；
- 豪华感主要来自比例、材料与“空间用得起”，而不是后期装饰堆砌。

它可以经过长期现代化改修，但改修的基本态度是：

> **现代功能迁就旧建筑，而不是旧建筑为了现代功能重新长成一栋现代公建。**

电梯、无障碍卫生间、消防分区、空调、电气、网络等必须真实存在，但应尽可能利用既有柱网、次级空间与后期服务带嵌入，不破坏中央历史轴线与主要比例。

## 三、基础比例模数｜已锁定

主楼采用统一比例语言组织柱、墙、窗、门与主要长度。

### 基础模数

- **M = 450 mm**；
- **主柱间 B = 8M = 3.60 m**；
- **标准层 floor-to-floor = 9M = 4.05 m**；
- 主要室内净高目标约 **3.5 m 级别**，具体由梁、楼板与吊顶 / 管线改修继续校核。

`M` 是建筑比例模数，同时也是可见主柱 / 壁柱尺度的重要参考，但不要求所有年代、所有楼层的实际结构柱截面都机械等于 450 × 450 mm。后期加固、包柱、梁深与墙厚仍服从工程合理性。

固定理解：

> **先用一个稳定的比例语法生成建筑，再让工程细节在这个语法里成立。**

## 四、东西方向主轴网｜已锁定

主楼东西方向采用 **18 个标准主柱间**，因此共有 **19 条 X 轴线**。

- 轴线编号：**X1 — X19**；
- 相邻标准轴线间距：**3.60 m**；
- 总结构长度：**18B = 64.80 m**；
- **X10 是整栋建筑的严格东西对称中心线。**

从西向东划分为：

> **西端楼梯亭 2 bay｜西翼 6 bay｜中央轴体量 2 bay｜东翼 6 bay｜东端楼梯亭 2 bay**

即：

> **2 + 6 + 2 + 6 + 2 = 18 bay**

对应轴线范围：

- **X1—X3**：西端楼梯亭，2 bay = 7.20 m；
- **X3—X9**：西翼，6 bay = 21.60 m；
- **X9—X11**：中央楼梯厅 / 中央轴体量，2 bay = 7.20 m；
- **X11—X17**：东翼，6 bay = 21.60 m；
- **X17—X19**：东端楼梯亭，2 bay = 7.20 m。

### 中央轴说明

中央楼梯厅跨 X9—X11，**X10 是几何与礼仪意义上的中心轴，不等于必须在大厅正中央放一根实体柱。**

结构轴线是放样与比例控制系统；具体柱、墙、洞口是否在每一个轴线交点出现，要服从空间等级。中央主轴尤其禁止因为“轴网上有线”就在视线中心机械落柱。

## 五、南北方向主轴网｜已锁定

主楼南北方向先采用 **4 条主要 Y 控制轴**，定义三条不同深度的历史空间带。

方向约定：

- **Y1 = 南立面 / 中庭侧外墙控制轴**；
- **Y4 = 北立面外墙控制轴**。

轴距：

- **Y1—Y2 = 20M = 9.00 m**：南侧大教室带；
- **Y2—Y3 = 8M = 3.60 m**：中央东西向主走廊；
- **Y3—Y4 = 16M = 7.20 m**：北侧原始房间带。

总进深：

> **44M = 19.80 m**

这四条 Y 轴首先是主要结构 / 空间控制线，不意味着9米深教室内部必须再塞入一排破坏使用的自由柱。梁、墙、柱与后续结构校核需在保持大教室完整性的前提下解决跨度。

## 六、正式结构坐标系统｜已锁定

从本轮起，主楼平面采用统一坐标表达：

## 七、四个高三 Home Room 在骨架上的自然落位｜已锁定到轴网级

在不改变既有分班关系的前提下，南侧四个 Home Room 现在可以由历史柱网自然围合，而不是先画四个现代标准教室再拼接建筑。

每间 Home Room 占 **3 个东西标准 bay × 南侧完整9.00 m进深**：

- **3-A：X3—X6 / Y1—Y2**；
- **3-B：X6—X9 / Y1—Y2**；
- **中央楼梯厅：X9—X11，贯穿中央轴体量**；
- **3-C：X11—X14 / Y1—Y2**；
- **3-D：X14—X17 / Y1—Y2**。

单间 Home Room 的主要平面尺度约为：

> **10.80 m × 9.00 m ≈ 97.2 ㎡**

这使30张单人课桌摆入后仍有明显余量，可以长期容纳立式钢琴、书柜、大型地球仪、地图架、植物、储物柜等大型教具与家具。

注意：这不是要求四个班必须摆完全相同的大型物件；只是建筑尺度允许这些东西自然存在。

## 八、北侧原始房间带｜历史结构逻辑已锁定，现代用途未落位

左右两翼各有6个东西标准 bay。

北侧原始房间带优先按 **2 + 2 + 2 bay** 理解，即每翼形成三间比例端正的历史房间：

- 单间原始开间：**7.20 m**；
- 进深：**7.20 m**；
- 单间约：**51.8 ㎡**。

因此整层北侧原始状态可以理解为：

- 西翼：3个约52㎡历史房间；
- 东翼：3个约52㎡历史房间；
- 中央轴、东西端楼梯亭另行处理。

这些房间在建校以来可以多次改变用途。今天的進路指导室、高三学年室、自习室、Seminar、面谈室等，必须从这些既有空间中通过整间使用、轻质分隔、局部开门等方式产生。

固定原则：

> **今天的房间名称是建筑生命史中的一个阶段，不是1920年代建筑师预先知道的功能。**

## 九、东西端楼梯亭｜体量已锁定，梯段细部待设计

东西端楼梯各占 X1—X3 / X17—X19 的2 bay端部体量，并在1F / 2F / 3F垂直叠置。

当前只锁：

- 端部体量位置；
- 7.20 m东西宽度；
- 三层连续；
- 日常可用，同时满足现代疏散要求；
- 建筑外观上作为对称的端部收束体量。

尚未锁：

- 楼梯是双跑、三跑还是围绕平台组织；
- 南北向具体占用深度；
- 是否保留原始楼梯并通过后期防火门 / 加固升级；
- 东端2F学生会连廊如何精确接入而不破坏楼梯结构。

这些都在下一轮结构 / 楼梯细化时处理。

## 十、中央楼梯厅｜轴网体量已锁定，内部构造待设计

中央历史轴体量占 **X9—X11 = 7.20 m**，X10为严格中心线。

它必须继续承担：

- 主入口上方的礼仪轴；
- 三层主楼梯；
- 南向高窗与中庭 / 正门视线；
- 东西长廊的主要空间节点。

但这一轮不提前决定楼梯每一跑的尺寸、平台形状或北侧后期电梯的具体插入方式。

特别是电梯：

> **现代电梯必须在中央历史体量与邻近旧房间的结构条件中重新找位置，不能继续默认“正对中央楼梯、视觉上形成现代双核心”。**

无障碍能力必须保留，但视觉与结构上服从历史主轴。

后续只保留功能邻接需求，再从 X / Y 结构网中重新落位。
