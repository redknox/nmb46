# 乃木坂女学院｜高三三楼平面与动线

> 状态：**逐项锁定中。**
>
> 本文件负责主教学楼 3F 高三区域的具体平面关系与人物日常动线。主楼总体结构仍以 `docs/world/main-building-v1.md` 为准，高三分班以 `docs/world/high3-home-rooms.md` 为准。

## 一、四个 Home Room 左右顺序｜已锁定

三楼南侧四个高三 Home Room 与中央主楼梯采用以下基本关系：

> **西端 ← 3-A ｜ 3-B ｜ 中央楼梯厅 ｜ 3-C ｜ 3-D → 东端**

中央楼梯厅位于 3-B 与 3-C 之间，不把四个班简单排成一条只有同向流动的连续走廊。

对应班级：

- **3-A**：樱井玲香、生驹里奈、松村沙友理、中元日芽香
- **3-B**：白石麻衣、桥本奈奈未、生田绘梨花、卫藤美彩
- **3-C**：秋元真夏、高山一実、和田まあや、西野七濑
- **3-D**：斋藤飞鸟、星野南、伊藤万理华、深川麻衣、若月佑美

这不是为了把人物按气质象征性摆在建筑两端，而是为了让既有分班在真实楼层里形成可持续的移动关系。

## 二、核心动线原则｜已锁定

三楼平面不能只满足“从教室走到楼梯”的最短路径，还必须让学校日常自然产生**交叉行进路线**。

核心原则：

> **空间应该帮助人物面对面遇见，而不是让编剧不断发明理由把已经走过去的人叫回来。**

如果四个教室只沿一条走廊顺序排开，而所有重要目的地都在同一方向，人物之间大量自然相遇会退化为：

- 从背后叫住对方；
- 某人忽然回教室拿东西；
- 为了见某个人刻意逆着人流走；
- 无必要地让角色“正好经过”。

这些手段偶尔可以使用，但不能成为跨班关系的主要空间机制。

因此后续安排進路指导室、自习室、面谈室、电梯、东西安全楼梯及其他支持空间时，应优先创造**不同目的地导致的相向与交叉流线**。

理想状态是：

- 两个人本来各自去不同地方，却迎面碰见；
- 一个人刚从楼梯上来，另一个正准备下楼；
- 不同班学生去自习室、進路室、洗手间、选修教室或东西楼梯时自然交叉；
- 对话结束以后双方继续向各自原本的方向走，不需要解释为什么其中一人折返。

这类十几秒到几十秒的“面对面”场景，是本剧走廊戏的重要基础。

## 三、中央楼梯厅的功能｜已锁定

中央楼梯厅位于 3-B / 3-C 之间，因此天然成为高三年级最容易发生短暂交会的位置之一。

这会产生若干自然效果：

- 3-B 与 3-C 学生出教室后都很容易进入中央区域；
- 从一、二楼上来的学生会先进入 B / C 之间，而不是某一个班门口；
- 正式集体移动、来宾或年级事务使用中央楼梯时，不会让某一班拥有不合理的空间特权；
- 白石、桥本所在 3-B 与真夏、高山所在 3-C 之间可自然产生大量“顺路遇见”，无需额外剧情解释。

中央楼梯很漂亮，但不能因此吞掉所有日常流量。东西安全楼梯、支持空间及后续目的地布局仍必须分担真实学生流动。

## 四、樱井与真夏的空间关系｜已锁定

樱井在 3-A，真夏在 3-C。

两人都是学生会核心，却不会一出教室就自动同行。

她们每天前往学生会室时，应当从各自 Home Room 出发，在不同路径节点自然汇合；这继续强化既有关系原则：

> **学生会是她们主动共同承担的地方，而不是因为本来就是同班好友。**

毕业交接以后，同样的空间关系还能自然表现变化：两个人仍从不同班出来，但已经不再因为学生会事务必然走向同一个地方。

## 五、3-D 位于东端的使用原则｜已锁定

3-D 位于三楼东端。

飞鸟、南、万理华、深川、若月不能因此被拍成象征性的“边缘人班级”。这只是正常建筑分配。

真正可利用的是：东端位置会让她们在去不同目的地时形成与其他班不完全相同的固定路线。后续安排东侧安全楼梯、二楼学生会连廊方向、艺术别馆 / 图书馆 / 食堂的下楼选择时，可以让这种差异自然进入人物生活。

禁止为了象征意味刻意让 3-D 永远远离年级中心。

## 六、3F 房间 / 功能总清单｜已锁定

在决定每个房间具体放在东、西、中央哪一侧之前，先锁定三楼真正需要承担的功能。

### 学生日常核心

- **3-A / 3-B / 3-C / 3-D** 四间 Home Room；
- **自习室** 1 间；
- **Seminar / 选修小教室** 1—2 间；
- **卫生间**；
- **无障碍卫生间**。

### 高三升学 / 毕业事务

- **進路指导室** 1 间；
- **小型面谈室** 2 间；
- **高三资料 / 文件室** 1 间。

進路指导室与面谈室必须功能分开：

- 進路指导室主要承担大学资料、推荐条件、历年去向、申请截止日、奖学金与查询事务；
- 面谈室承担学生 / 担任老师 / 家长之间需要关门进行的小型会谈；
- 两类使用可以同时发生，不能为了省空间合并成一个“万能升学房间”。

### 成人工作点

- **高三学年室** 1 间。

高三学年室是四班担任老师与高三学年主任在三楼的日常工作点，可放置：

- 担任老师工作位；
- 武田铁矢作为高三学年主任的常驻工作位；
- 电话；
- 出勤与年级事务文件；
- 進路 / 毕业材料的临时处理区；
- 小型打印 / 复印设备；
- 文件柜。

它不是第二个完整职员室。

### 明确不设置

三楼**不再设置完整职员室**，主职员室继续位于 1F。

三楼也**不单独设置教师休息室**。教师在三楼出现，是因为教学、担任与年级事务，而不是把高三楼层变成成人专区。

固定制度理解：

> **三楼是学生的日常楼层，加上维持高三现实运转所必需的成人工作点。**

## 七、走廊休息 / 等候区｜已锁定

三楼主走廊与中央楼梯厅附近允许设置少量**开放式休息 / 等候凹区**。

它不是封闭学生休息室，也不是社交 Lounge，而是建筑原本就有的公共停留设施，例如：

- 墙边固定长椅；
- 窗边短凳；
- 柱间或走廊略加宽处的 2—4 人座位；
- 進路 / 面谈区域外的等候座位。

整体质感可以接近维护良好的高档公共建筑：材料克制、比例舒适、不会像临时搬来的折叠椅。

它的现实用途包括：

- 等老师；
- 等面谈；
- 课间短暂停留；
- 把资料放在膝上看两分钟；
- 等同学一起下楼。

编剧上它会自然提供“一个人本来就在这里坐着，另一个人路过看见”的场景，但禁止为了制造重要谈话把所有角色都长期聚集在这里。

固定理解：

> **走廊不是房间之间剩下的空间。走廊本身就是学校生活的一部分。**

## 八、保健室不在 3F｜已锁定

三楼不设置保健室 / 医务室。

乃木坂女学院的**保健室正式位于主教学楼 1F**，并与休息床位、小型诊察空间组成完整健康区域。

现实理由：

- 身体不适的学生不应为了就诊继续爬楼；
- 一楼更方便无障碍到达；
- 体育活动受伤后更容易进入；
- 必要时家长接送、担架或外部医疗转运更合理；
- 也更符合主楼经过现代化改修的设定。

从三楼去保健室需要真实下楼，这个移动过程可以进入表演，但不能为了戏剧效果故意把保健室放远。

保健室在 1F 的具体东 / 西侧位置、最近侧入口与体育场方向的关系，留待主楼一层平面细化时决定。

## 九、竖向交通｜功能已锁定，位置继续细化

三楼具备：

- **中央主楼梯**；
- **东侧安全楼梯**；
- **西侧安全楼梯**；
- **电梯**。

中央主楼梯已经锁定在 3-B / 3-C 之间。

东、西安全楼梯与电梯的具体落点尚未锁定。后续必须同时满足：

- 真实消防 / 无障碍使用逻辑；
- 不让所有学生流量都被中央楼梯吞掉；
- 能和北侧功能房间一起形成相向 / 交叉流线。

## 十、后续仍需决定

三楼“有哪些房间”已经结束讨论。下一轮只处理**这些房间放在哪里**：

- 高三学年室的位置；
- 進路指导室与两间面谈室的位置关系；
- 自习室的位置；
- 高三资料 / 文件室的位置；
- Seminar / 选修小教室 1—2 间的位置；
- 卫生间 / 无障碍卫生间的位置；
- 东、西安全楼梯与电梯的具体位置；
- 走廊休息 / 等候凹区的数量与位置；
- 主走廊长度、窗线及中央楼梯厅开口关系。

判断标准不只是“建筑图画得通”，还要问：

> **这些目的地会让哪些人自然迎面遇见？**

等物理空间稳定以后，再进入午休、放学、跨班寻找与固定路线等高三人物日常动线。
