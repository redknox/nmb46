# 乃木坂女学院｜高三三楼平面与动线

> 状态：**功能需求、人物相对关系与若干动线原则已锁定；现代房间精确门位正在按历史结构轴网重新落位。**
>
> 本文件负责3F今天如何被高三学生使用。主楼原始结构、柱网与建筑比例以 `docs/world/main-building-structural-grid.md` 为上位依据；高三分班以 `docs/world/high3-home-rooms.md` 为准。

## 一、当前设计边界｜已锁定

过去曾按现代办公 / 校园功能直接排列三楼北侧房间。随着主楼改为真正从大正时期历史结构出发设计，这一方法已经被废止。

固定优先级：

> **先服从历史柱网，再安排今天的房间。**

因此：

- 高三“需要哪些功能”继续有效；
- 四个 Home Room 的人物分班与中央轴左右关系继续有效；
- 东西端楼梯、学生会东侧路线、无障碍能力等连续性需求继续有效；
- 但進路指导室、面谈室、资料室、学年室、自习室、Seminar、电梯、卫生间的**精确线性门位顺序全部重新验证**；
- 过去设想的特定“西侧等候凹区 / 东侧休息凹区”不再是建筑先决条件。

Git 历史保留旧方案，但当前文件只回答“现在是什么”。

## 二、四个 Home Room 与中央轴｜已锁定

四班仍维持：

- **3-A**：樱井玲香、生驹里奈、松村沙友理、中元日芽香；
- **3-B**：白石麻衣、桥本奈奈未、生田绘梨花、卫藤美彩；
- **3-C**：秋元真夏、高山一実、和田まあや、西野七濑；
- **3-D**：斋藤飞鸟、星野南、伊藤万理华、深川麻衣、若月佑美。

结构轴网确定后，南侧自然落位为：

> **西端 ← 3-A｜3-B｜中央楼梯厅｜3-C｜3-D → 东端**

轴网坐标：

- **3-A：X3—X6 / Y1—Y2**；
- **3-B：X6—X9 / Y1—Y2**；
- **中央楼梯厅：X9—X11**；
- **3-C：X11—X14 / Y1—Y2**；
- **3-D：X14—X17 / Y1—Y2**。

每间 Home Room 约 **10.80 m × 9.00 m ≈ 97.2㎡**，30张课桌摆入后仍有明显余量。立式钢琴、大型地球仪、地图架、书柜、植物等大型教具可以长期自然存在，不需要为了某场戏临时搬入。

3-D 位于东翼不能被拍成象征性的“边缘班”；这只是历史平面的正常分配。

## 三、3F 今日功能需求｜已锁定

### 学生日常

- 3-A / 3-B / 3-C / 3-D；
- 自习室 1 间；
- Seminar / 选修小教室 2 间；
- 普通卫生间；
- 无障碍卫生间。

### 進路 / 毕业事务

- 進路指导室 1 间；
- 小型面谈室 2 间；
- 高三资料 / 文件室 1 间。

進路指导室和面谈室保持功能分离：前者是资料、查询、推荐条件、申请期限、奖学金等事务空间；后者承担需要关门进行的学生 / 担任老师 / 家长会谈。

### 成人工作点

- 高三学年室 1 间。

高三学年室仍只是四班担任老师与武田铁矢作为高三学年主任在3F的日常工作点，可有电话、文件柜、出勤资料、進路 / 毕业材料处理区和小型打印设备。

三楼**不设置第二个完整职员室，也不设置独立教师休息室。**

固定制度理解：

> **三楼是学生的日常楼层，加上维持高三现实运转所必需的成人工作点。**

## 四、北侧历史房间带｜结构已锁定，现代用途待分配

主楼北侧不是为今天的功能专门生成的现代房间带。

根据历史结构网：

- 西翼 X3—X9 有6个标准 bay；
- 东翼 X11—X17 有6个标准 bay；
- 北侧原始房间带 Y3—Y4 深7.20m；
- 每翼优先按 **2 + 2 + 2 bay** 理解，形成三间约 **7.20m × 7.20m ≈ 51.8㎡** 的原始房间。

今天的進路室、学年室、自习室、Seminar等，要通过“整间继续使用 / 一间旧房后期轻质分隔 / 局部重新开门”等方式产生。

例如两间面谈室可以来自一间约52㎡旧房间的后期分隔；但具体是哪一间，尚未锁定。

## 五、主走廊｜尺度原则已锁定，细部待设计

主走廊位于 **Y2—Y3**，历史结构尺度为：

> **3.60 m 宽**

这是整栋建筑原始比例的一部分，不是为了角色偶遇设计出来的“社交廊道”。

它应当：

- 长；
- 高；
- 横平竖直；
- 保留清楚的重复柱间与门窗节奏；
- 下课时容纳大量学生仍显宽裕；
- 允许学生靠边短暂停留而不阻断主要流线。

走廊不再要求人为雕刻两个戏剧化凹区。若历史窗台、端部平台、旧家具或后期使用自然形成可坐 / 可等的位置，可以使用；但先由建筑决定。

固定原则：

> **不要设计一个方便发生青春片的学校。先设计一所有自己历史的学校，再让青春发生在里面。**

## 六、交叉流线原则｜继续锁定

虽然建筑不再为了剧情塑形，但人物相遇仍必须服从真实目的地。

固定原则：

> **空间应该允许人物面对面遇见，而不是让编剧不断发明理由把已经走过去的人叫回来。**

这条原则现在的含义是：

- 先完成历史建筑与现代功能落位；
- 再观察哪些目的地自然造成东西向、上下楼与跨班交叉；
- 如果某个角色没有理由走那条路，就不为了见另一个人强行安排；
- 长廊允许角色远远看见彼此，但她们不需要隔着几十米喊人；
- 真正的短对话可以在双方自然接近后发生，然后继续各走各的路。

建筑优先，不等于放弃动线；而是让动线成为建筑被真实使用之后的结果。

## 七、东西端楼梯｜位置锁定，细部待结构设计

东、西端楼梯亭分别位于：

- **西端：X1—X3**；
- **东端：X17—X19**。

两者1F / 2F / 3F垂直叠置，既满足现代疏散，也允许学生日常使用。

具体梯段、平台、门、防火分区以及2F东侧学生会连廊如何接入，等待 `main-building-structural-grid.md` 的楼梯细化，不再从现代动线倒推楼梯形状。

## 八、现代电梯 / 无障碍｜能力锁定，精确位置重新验证

主楼必须保持完整现代无障碍能力：

- 电梯三层贯通；
- 各层有无障碍卫生间；
- 轮椅学生进入主楼和日常到达各年级不构成戏剧事件。

但旧方案里“电梯位于中央偏北并与历史大楼梯形成视觉双核心”的精确设置已经撤回。

新原则：

> **电梯要在既有柱网与次级空间里找到合理位置，不能破坏X10中央礼仪轴，也不能为了隐藏设备牺牲真实可达性。**

位置将在中央楼梯厅、邻近北侧旧房间与各层连续条件一起检查后确定。

## 九、学生会方向｜关系继续有效，接口待楼梯细化

学生会室仍位于主楼东侧独立建筑，并通过2F东侧有顶连廊连接。

继续有效的行为关系：

- 樱井从西翼3-A出发前往学生会，不会天然和真夏从同一教室同行；
- 真夏从东翼3-C出发，通常更靠近东侧路线；
- 两人可以在2F东侧某个真实交通节点自然汇合；
- 普通学生没有学生会 / 校务目的，不会无缘无故经过学生会室门口。

但“连廊一定接在某个既定现代转换前厅”的精确门位，需要等东端楼梯亭结构完成后再锁。

学生会交接后的 callback 继续采用行为消失：如果当天没有学生会事务，她们只是不再走那条路线，不做“先走错半步再想起来”的解释性动作。

## 十、保健室｜继续锁定在1F

三楼不设置保健室 / 医务室。

保健室正式位于主教学楼1F，并配休息床位与小型诊察空间。具体1F落位以后也必须服从同一套历史柱网，而不是再按现代健康中心自由塑形。

## 十一、当前未决

这一轮不再讨论“北侧从左到右是什么房间”。下一步按结构顺序处理：

1. X1—X19 / Y1—Y4 上哪些交点真正有实体柱 / 厚墙；
2. X9—X11中央楼梯厅的楼梯跑向与平台；
3. X1—X3 / X17—X19端部楼梯亭的原始楼梯；
4. 每个3.60m外墙 bay 的窗列细分；
5. 原始厚墙与后期可调整轻隔墙的边界；
6. 现代电梯的插入位置；
7. 最后才重新分配進路室、面谈室、学年室、自习室、Seminar与卫生间。

物理空间稳定以后，再进入午休、放学、跨班寻找、座位与固定路线等人物日常动线。
