# 乃木坂女学院｜个别艺术研究指导制度锁定

> 状态：**LOCKED / 已传播到课程制度、成人角色卡与 EP04 边界。**
>
> 本文件锁定乃校在音乐、美术与文学领域为极少数学生单独聘请外部专家的制度，以及该制度与普通选修、社团指导和 EP04 生田线的边界。

## 一、制度定位

乃木坂女学院允许在校内课程无法覆盖某项明确而成熟的个人研究时，为一名学生单独聘请外部专家。

制度正式名称：

> **个别艺术研究指导制度**

“单独聘请”指这位专家在乃校当前只指导这一名学生；不要求专家成为全年全职、每天驻校、只等待一个学生的专任教员。

专家可以每周固定来校一次，也可以每两周进行一次较长指导。她 / 他在校外仍然可以拥有自己的演奏、创作、研究、编辑或教学工作。

## 二、适用领域

当前只适用于：

- 音乐；
- 美术及工艺；
- 文学、翻译与相关文本研究。

这些领域允许一个学生独立形成足够严肃的长期研究，也可能出现校内教师无法覆盖的细分专业，例如罕见乐器、特定材料技法、修复、某一语种文学或特定创作方法。

不把该制度扩张为所有兴趣都可以要求学校配置私人教师的普遍福利。

## 三、启动条件

制度可以由相关学科教师推荐，也允许学生提交计划，但必须经过学科与教务审核。

基本条件：

1. 学生已经提出清楚、持续、可被指导的研究或创作目标；
2. 现有课程和教师确实无法合理覆盖这一专业分支；
3. 外聘专家的工作边界、时间、空间、安全和评价方式明确；
4. 学生保留过程记录，并接受校内负责教师的周期确认；
5. 指导以一学期或一学年为周期复核，不自动延续。

家庭可以提出信息或建议，但不能通过额外缴费直接购买校内“专属老师”。学校是否启动制度，属于教育判断。

## 四、稀缺程度

全校同一时期通常只有一至三名学生接受这种指导，最多不超过三至五名；某些学年可以无人使用。

它的豪华感来自：

> **即使只有一个人，学校仍愿意为一个真实而具体的教育需要启动完整制度。**

剧中不通过学生议论学费、教师自我介绍或校方宣传解释这一点。外部专家按预约进入学校、只等一个学生，已经足够让观众理解。

## 五、与其他外聘工作的区别

| 类型 | 服务对象 | 当前例子 |
|---|---|---|
| 社团 / 作品指导 | 一个部活或一个具体节目 | 松下洸平 |
| 社团专业协力 | 一个部活及其持续实践 | 池松壮亮 |
| 短期项目 / 创作合作 | 一次原创舞台、声音装置或跨学科工作 | Fukase 当前身份 |
| 个别艺术研究指导 | 原则上一名提出明确研究的学生 | 当前未指定主要人物 |

外部专业人士不会因为只和一名学生同场，就自动成为她的个别研究导师。身份取决于学校为什么聘请他、责任持续多久以及是否进入正式教育流程。

## 六、生田绘梨花的边界

生田是乃校学生中音乐能力最强的一层，但仍然是正在接受学校教育的高中生，距离成熟职业演奏家仍有明确差距。

乃校音乐教育本身是全校最强的学术与艺术领域之一，现有课程、教师、合唱体系、练习设施和外部作品合作，仍然能够有效覆盖并继续要求生田。

因此当前锁定：

- 生田不因“很厉害”自动进入个别艺术研究指导制度；
- 她在 EP04 遇见的问题不是学校已经没有能力继续教她；
- 她的问题发生在高水平技巧、准确完成与开放创作之间；
- Fukase 与她的第一次接触不追认成学校为生田配置的专属导师；
- 松隆子联系 Fukase，是一位专业教师根据具体学生和具体问题作出的工作判断，不是启动特殊培养流程；
- 第一季是否在未来把某段持续关系纳入该制度，保持未启用状态，不预先承诺。

## 七、松隆子的能力尺度

松隆子不是“懂一点专业音乐的普通高中教师”，也不是因为无法成为职业演奏家才退回学校。

当前锁定她具备：

- 进入一流职业演奏团体核心席位的演奏能力；
- 可按乐团首席 / 副首席量级理解的专业判断、听觉与完成能力；
- 长期训练高水平学生和成熟 ensemble 的能力；
- 清楚判断校内教育何时足够、何时需要引入另一种专业工作方法的能力。

这里锁定的是能力层级，不锁她的具体主修乐器、是否曾实际担任某一乐团首席、完整学历或职业履历。

她选择在乃木坂女学院工作，应被理解为一项正面的职业选择。她与 Fukase、松下的关系不是“学校老师遇见真正艺术家”，而是不同专业角色之间对彼此边界的准确识别。
