# 乃木坂女学院｜主教学楼无障碍服务核心锁定

> 状态：**已锁定 / 现代改修权威补充。** 若旧文件仍把电梯位置、无障碍卫生间位置或 E1 作为普通完整历史房间使用列为未决，以本文件为准。

## 1. 位置

现代无障碍服务核心固定设置于东翼第一间历史房：

> **E1 = X11—X13 / Y3—Y4，约 7.20 × 7.20 m。**

不占 X10，不侵入中央北室，不外挂北立面，也不塞入东西端楼梯亭。

## 2. 改修原则

E1 被理解为学校后期为了让历史主楼继续服务现代学生而主动牺牲的一间完整历史房壳体。

必须保留：

- X11 / X13 原始厚墙或重要历史边界；
- Y4 北外墙；
- 原有四扇北窗及既定北立面节奏；
- Y3 走廊侧历史偏置门洞及其走廊尺度感。

内部允许完全现代化重组。

固定理解：

> **现代化不通过外挂一个现代盒子证明自己，而通过牺牲一个历史房间，让整栋楼继续保持原来的秩序。**

## 3. 内部功能

E1 三层垂直叠置，统一容纳：

- 约 11 人级无障碍电梯；
- 每层无障碍卫生间；
- 独立乘降前厅；
- 必要的设备、清洁、储物及竖向管线空间。

电梯不直接开向 3.60 m 主走廊，先进入 E1 内部乘降前厅，以避免等候、轮椅回转和陪同行为占用主走廊。

建筑设计阶段给井道保留约 **2.25 × 2.25 m（5M × 5M）级控制盒**；该尺寸是空间预留，不作为具体设备厂家或法规井道尺寸承诺。

## 4. 走廊界面

东翼历史房间原有门向中央偏置，因此 E1 继续利用靠 X11 一侧的历史门洞作为无障碍前厅入口。

从走廊观看时，优先保留老学校高木门 + 上亮子的视觉语言；现代自动开启、五金和无障碍操控应尽量整合在既有门洞体系内，不把不锈钢电梯门直接暴露给主走廊。

## 5. 与学生会连廊的关系

E1 位于东翼中央邻接位置，使无障碍使用者可从主入口 / 中央楼梯附近进入主走廊，经 E1 电梯到达 2F，再沿主走廊前往东端北侧转换厅与学生会连廊。

电梯与连廊形成连续的现代无障碍网络，但两者在建筑上保持独立：电梯不侵入东端 U 形楼梯或其半层窗。

## 6. 对 3F 功能分配的约束

E1 不再作为一间完整约 51.8㎡ 的普通现代教学 / 行政房间名额。

3F 可完整分配的北侧历史壳体变为：

> **W1｜W2｜W3｜Central North Room｜E2｜E3**

E1 剩余边角只承担与服务核心相容的设备、储物、清洁或资料辅助用途，不强求再塞入完整主功能。

## 7. 应急边界

普通学校电梯不作为火灾时行动不便者默认疏散手段。东端 2.70 m 北侧转换厅可在后续消防设计中优先测试为辅助避难等待 / 联系节点，但其具体尺寸、设备与防火分区此时不锁定。

## 8. 下一步

电梯与无障碍核心位置至此不再是开放问题。下一步进入 3F 现代功能重新落位，并在功能落位后继续校核防火分区、避难策略与日常视线。
