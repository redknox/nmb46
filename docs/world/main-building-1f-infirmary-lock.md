# 乃木坂女学院｜1F保健室落位锁定

> 状态：**已锁定 / 主教学楼1F健康区域权威补充。**

## 1. 最终位置

1F保健室健康区域固定设置于东翼：

> **E2 = X13—X15 / Y3—Y4，约7.20 × 7.20m。**

E1无障碍服务核心位于其西侧直接相邻；E3不被保健室吞并，继续作为东端楼梯与健康区域之间的空间缓冲及其他1F功能空间。

## 2. 空间组成

E2完整历史房壳体内部通过后期精致轻隔墙形成：

- 保健教师工作 / 简单处置区；
- 约3床级休息床位区；
- 可关闭的小型诊察 / 健康咨询室；
- 必要的洗手、药品与日常健康用品储存。

走廊原历史门仍是主要入口。开门后首先进入保健教师可直接照看的工作/处置区域，不直接暴露休息床位。

## 3. 与E1关系

E1电梯与无障碍卫生间使行动不便、拄拐或身体不适的学生可在1F快速进入E2保健室，无需穿越长距离主走廊。

普通电梯与保健室的相邻关系属于现代化连续服务网络，但E2仍保持独立历史房间身份，不与E1合并成现代大盒子。

## 4. 位置取舍

虽然运动场位于校园西侧，保健室仍选择东翼E2。其主要服务对象是全校日常的头痛、发热、经期不适、轻伤、低血糖、休息与健康咨询，而不是只服务体育伤害。

东侧方案在无障碍到达、安静程度与全年级日常使用上更完整；较严重体育伤害由学校人员与转运流程处理，不以学生自己少走一段路作为核心设计依据。

## 5. 固定理解

> **保健室每天属于学校生活；校医只在需要时进入其中。**

1F保健室东西位置及E2精确落位至此不再开放。
