# 乃木坂女学院｜3F W1 / W3 内部改修锁定

> 状态：**已锁定 / `high3-modern-layout-lock.md` 的权威补充。** 全部改修服从 `main-building-conservation-renovation-lock.md`。

## W1｜面谈 A + B

W1 = X3—X5 / Y3—Y4，约 7.20 × 7.20m。

- Y3 走廊侧只保留原历史高木门 + 上亮子，不新增走廊门洞；
- 南侧设置 **1.80m 深共享前室**；
- 北侧以 X4 节奏中分为 A / B 两间；
- 每间约 **3.60 × 5.40m = 19.4㎡**，各完整获得两扇既有北窗；
- A / B 为正式隔音面谈空间；共享前室承担隐私、声学与短时等候缓冲；
- 内部新门约 **900mm 级有效通行宽度**、无门槛、实木无玻璃；新木作与历史语言协调但简化一级。

## W3｜高三学年室 + 资料室

W3 = X7—X9 / Y3—Y4，约 7.20 × 7.20m。

- 不对半切房；采用 **完整大房间 + 西南角室中室**；
- 资料 / 文件室约 **3.15 × 4.05m = 12.8㎡**，位于西南角，不占北窗；
- 剩余约 **39㎡** 保持为完整高三学年室；
- 原历史门是唯一走廊入口；进入后仍应首先读到房间纵深与北侧四窗；
- 入口内侧可设约 **1.35—1.50m** 低实木屏柜遮挡桌面文件，不设第二前室或通顶屏风。

## 固定原则

W1 / W3 的现代轻隔墙只存在于历史壳体内部；走廊看不出房间被切开。新隔墙延续深色木护墙 + 浅色抹灰的材料秩序，隔音、防火与管线藏入构造。

> **进入以后看得出是后来认真改过，但仍然属于这栋楼。**

W1 / W3 内部轻分隔至此不再开放。下一步进入 Central 高三閲覧自修室及 E2 / E3 家具设备设计。
