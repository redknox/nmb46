# 乃木坂女学院｜学生制服・生活规则・意见检视锁定

> 状态：**系列级 LOCKED world canon。**
>
> 来源：EP02《裙摆》现实核查与 FINAL 正片。本文描述乃木坂女学院自身制度，不主张为所有日本学校通则。

---

# 一、指定制服与日常穿着

乃木坂女学院使用指定制服，并把正确穿着视为学校日常秩序的一部分。

当前锁定：

- 制服有学校规定的基本穿法；
- 裙长以膝部附近为日常基线；
- 不鼓励 / 不允许通过永久加工或明显折腰等方式故意长期偏离指定外观；
- 正式典礼与普通授业日可以有不同整齐程度，但规则本身不会只在典礼时存在。

制服规则首先是学校生活规则，不是道德等级判断。

> **裙摆短一点 ≠ 坏学生 ≠ 不珍惜学校 ≠ 不属于这里。**

学生可以真心喜欢学校、成绩正常、对老师学姐有礼貌，同时觉得另一种穿法更好看。

---

# 二、学校怎样执行规则

本校的严格感主要来自**低强度、持续、所有人都知道的日常执行**。

典型形式：

- 教师在走廊看见明显偏离时一句短提醒；
- Home Room 统一说明；
- 重复问题由担任 / 生徒指导等既有学校流程继续处理；
- 学生自己知道提醒是什么意思并调整。

不默认使用：

- 校门口每日排队量裙长；
- 公开羞辱；
- 全校大型“服装检查大会”；
- 把制服管理拍成纪律主题公园。

EP02 已建立的最小现实语法：

> 教师：`裙子。`
>
> 学生：知道意思，放下来，继续上课。

---

# 三、学生会与高年级生的权限

## 学校 / 教师

拥有现行校则的教育与执行责任。

## 学生会

可以：

- 协助传达已确认规则；
- 收集学生意见；
- 在学校安排的检视程序里代表学生形成意见。

不能因为“学生会”身份自行获得：

- 全校服装检查权；
- 处分权；
- 任意修改校则的最终决定权。

## 普通高年级生

可以根据前后辈传统解释规则和经验。

没有普遍纪律权。

> **说明规则 ≠ 检查别人 ≠ 命令别人必须复制自己的穿法。**

这一边界与 `docs/series-bible/school-etiquette-senior-guidance-lock.md` 同时适用。

---

# 四、规则必须可以被问“为什么”

乃木坂女学院制度严整，但不把：

> “一直都是这样。”

当作所有规则的最终解释。

学校应能说明现行规则至少服务于什么现实目的，例如：

- 指定制服作为共同正式服装；
- 校内外存在一个共同穿着基线；
- 学校长期校风与对外呈现。

但个别历史细节若当场没有可靠答案，教师可以正常说：

> **“这个我现在不能替学校乱说，需要确认。”**

成年人不知道某个历史细节，不等于制度崩溃。

比起临时编一个漂亮理由，更符合本校的专业感。

---

# 五、学生意见如何进入制度

学校允许学生通过低重量、正常行政渠道提出疑问或意见。

EP02 已建立一种可复用形式：

> `新年度　学校生活アンケート`

它不是校规改革专用表，而是 broader 学校生活调查，可包含：

- 校内生活不明事项；
- 设施；
- 时间；
- 提交；
- 生徒心得 / 生活规则；
- 小型自由记述。

学生可以把具体问题写进去。

之后学校可能：

- 由适当教师 / 部门回答；
- 汇总重复问题；
- 在正常校则检视时参考；
- 判断维持、解释、微调或进一步讨论。

但：

> **学生提出意见 ≠ 规则立刻改变。**

最终制度责任仍属于学校及相应正式权限体系。

---

# 六、EP02 以后飞鸟线的制度前提

飞鸟已经经历：

```text
看到规则意见栏
→ 觉得写了也未必有用
→ 留空
→ 真正问教师
→ 听懂“为什么需要共同穿法”
→ 发现“为什么具体是膝部附近”仍未回答
→ 把剩余问题写具体
→ 交入正常流程
```

因此后续不能再次把她写回：

> “我只会在旁边吐槽，绝不会参与。”

她仍然会质疑意义，也仍可能嫌制度麻烦。

但 EP02 已证明：

> **当她真的在意时，她已经做过一次从吐槽进入真实程序的动作。**

这不是让她相信所有制度，而是她长弧的第一步。

---

# 七、EP02 以后生驹线的制服前提

生驹仍然：

- 真心喜欢乃木坂制服；
- 自己愿意按学校规定穿；
- 认为现行规则存在时应把规则准确告诉学妹。

她的新变化只是：

> **她开始区分“学校怎么规定”“我自己喜欢怎样”“别人怎样才算真正属于这里”。**

因此后续不能为了制造制服冲突，把她重新写成：

> “穿得不标准的人就不是真正乃木坂学生。”

那会直接回滚 EP02。

---

# 八、制作固定理解

以后再出现制服 / 校则场景时，默认：

1. 制服规则是正常生活，不自动升级成事件；
2. 教师可以严格，但不要用羞辱证明严格；
3. 学生可以遵守规则同时不认同全部理由；
4. 学生可以喜欢学校同时对某条规则有不同审美；
5. 意见渠道存在，但不是剧情按钮；
6. “规则有现实理由”与“规则永远不能变”不是同一命题；
7. “传统”只有进入真实生活并允许下一代继续参与，才是本剧意义上的传统。
