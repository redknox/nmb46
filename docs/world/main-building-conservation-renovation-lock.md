# 乃木坂女学院｜主教学楼“修旧如旧”现代化改修原则

> 状态：**已锁定 / 全楼现代化改修权威原则。** 若旧方案为了现代功能破坏历史空间等级、走廊立面或木作语言，以本文件为准。

## 1. 核心态度

> **修旧如旧。现代化可以发生，但不能让现代化成为建筑的主角。**
>
> **现代技术负责工作，建筑负责被看见。**

乃木坂女学院维护传统是一种学校身份上的骄傲。电梯、无障碍、空调、网络、消防和现代教学设备必须真实存在，但不通过裸露设备、廉价材料或现代办公楼式界面证明自己。

## 2. 改修优先级

> **需要改变使用方式时，先问能不能保留房间；需要改变房间时，先问能不能保留墙；需要改变墙时，先问能不能保留走廊看到的样子。**

优先整间历史房继续使用；需要细分时，在历史壳体内部用精致、可逆的后期轻隔墙解决。原始厚墙、重要体量边界、窗列和历史走廊门洞原则上不因现代房间数量增加而改变。

## 3. 材料与细部

现代改修不做廉价“仿古”。预算允许时使用高质量定制木作与相容材料：下部延续深色木护墙比例，上部保持浅色抹灰 / 灰泥质感；新门框、踢脚、压顶服从原建筑木作比例；新门在材种、尺度和色调上协调，但允许被识别为后期制作。隔音、防火和管线隐藏在现代构造内部。

目标是让人感觉：

> **这间房后来被认真改过，但它仍然属于这栋楼。**

## 4. 走廊界面

Y2—Y3 主走廊的历史节奏优先保护。W1、W3 等后期分隔房仍只使用原有历史门洞；不因内部出现两个房间就在走廊新增现代门；不做连续铝框玻璃隔断。门禁、自动开启装置和控制器尽量整合进木作或低反光深色金属 / 黄铜色面板。

## 5. 设备语言

空调优先隐藏，不成排外挂白色家用挂机；风口、检修口、广播、网络和电源尽量进入木作、柜体、天花边缘或服务带。电梯门避免镜面不锈钢成为视觉中心，可用克制的哑光暖灰 / 深色金属并由木作框架纳入空间比例。消防、报警、无障碍装置不得为古风牺牲功能，只要求安装方式克制。

## 6. 卫生间与服务空间

东西端普通卫生服务区可以处于较低建筑等级，但装修品质不降低。

> **空间等级低，不等于材料和维护等级低。**

采用耐用、安静、易维护且与主楼相容的材料，不做网红酒店式炫技，也不做廉价公共设施感。

## 7. 四种历史生命状态

1. **Central North Room**：近乎原状保存，现代化主要藏在设备层；
2. **W2 / E2 / E3**：完整历史房壳体直接承载现代用途；
3. **W1 / W3**：历史壳体内做精致、可逆、走廊侧不可见的现代轻分隔；
4. **E1**：内部彻底现代化为无障碍服务核心，但外墙、北窗、厚墙与走廊历史门洞继续维持。

主楼不是冻结在大正时期，而是在长期使用中持续更新，同时坚持不让更新破坏自身身份。
