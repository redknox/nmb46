# 乃木坂女学院｜课程制度 V1

> 核心原则：**先让学校制度成立，再把人物放进去。**
>
> 乃木坂女学院不设置彼此隔离的“普通科 / 音乐科 / 美术科”式分科。学生首先属于同一所高等科与自己的 Home Room；进入高二、高三后，再通过选修、履修系列与专业程度逐渐分流。

## 一、基本结构

### 高等科统一招生

所有学生进入同一个“高等科”。

她们在行政上首先属于自己的班级，例如 3-A、3-B、3-C，而不是“音乐科三年级”“美术科三年级”。

Home Room 承担：

- 晨会与放学前 HR；
- 班级事务；
- 值日；
- 進路希望調査；
- 班级活动；
- 考试与通知；
- 毕业手续；
- 学級委員等班级职务。

因此即使学生的专业兴趣差异很大，她们仍共享一个稳定的“班级生活”。

## 二、高二以后形成履修系列

高一以共同基础课程为主。

从高二开始，根据升学方向、兴趣和能力逐步增加选修；高三分流最明显。

暂定四类主要履修系列：

### 1. 人文社会系

可能包含：

- 现代文；
- 古典；
- 日本史；
- 世界史；
- 政治经济；
- 社会学类特别课程；
- 文学专题；
- 哲学 / 思想入门。

适合制造桥本、飞鸟、高山等人物与武田铁矢、柄本佑、堺雅人等成人角色的课堂交点。

### 2. 理数自然系

可能包含：

- 高阶数学；
- 物理；
- 化学；
- 生物；
- 实验课程；
- 科学史 / 研究演习。

安田显等理科教师可在这一体系内使用。

### 3. 国际教养系

可能包含：

- 英语表达；
- 英语文学 / 阅读；
- 第二外语；
- 国际文化；
- 比较文化；
- 国际交流项目。

这一系列给隔壁男子校英语教师 / 国际交流负责人等角色提供自然入口，但不承担恋爱功能。

### 4. 艺术表现系

艺术不是一个隔离的“艺术科”，而是一组可以被深入履修的课程。

内部可进一步包括：

- 音乐：器乐、声乐、和声、合唱、音乐史、创作实践；
- 美术：素描、日本画、西洋画、造型、艺术史；
- 工艺 / 设计：平面、材料、服装与空间表达；
- 书道 / 传统艺术；
- 戏剧、影像等短期特别课程。

这让生田、万理华、西野可以在同一所学校里拥有不同程度的艺术训练，却不必被分到完全不同的“科”。

## 三、班级与选修是两套关系网络

这是本剧非常重要的戏剧机制。

学生早晚回自己的 Home Room，但中间会因为选课在校园中流动。

因此：

- 同班，不代表整天一起上课；
- 不同班，也不代表很少见面；
- 课程路线本身会制造人物相遇；
- 高三的分流会让“她们已经开始一点点分开”自然发生。

例如：

- 白石和桥本可以同班，但第三限分别去不同选修；
- 生田从另一班去音乐实践；
- 万理华去美术室；
- 午休大家又在食堂或中庭重新汇合；
- 真夏中途因为学生会事务离开课堂路线。

这比“所有主角都在同一间教室”更符合群像剧，也更符合毕业主题。

## 四、主要人物的课程定位原则

> 这里只写已经明确的人物方向，不在分班前强行决定具体课表。

### 生田绘梨花

正式修正：**不是“音乐科学生”。**

她是普通 Home Room 中的高三学生，但在艺术表现系的音乐方向履修最深，并且从小接受远超校内普通水平的专业训练。

她的问题因此不是“音乐科天才与普通生隔离”，而是：

> 一个在普通校园生活里拥有非常专业技能的人，开始发现专业训练本身也会限制自己。

松隆子是校内音乐教师；Fukase 是校外 / 外聘创作导师，两者从不同角度作用于她。

### 伊藤万理华

艺术表现系中偏美术 / 造型 / 实验性表达方向。

她的核心不是专业成绩，而是“这是我的东西”。

### 西野七濑

可以选修较深的美术课程，但与万理华不同：她不是强烈的创作者自我宣言型人物，更偏观察、判断与私人选择。

### 中元日芽香

可以在音乐、合唱或舞台相关选修中与生田形成“才能与努力”的现实参照。

## 五、为什么不设置正式音乐科 / 美术科

### 戏剧上的理由

如果设置彼此独立的音乐科、美术科：

- 主角群会被行政结构天然拆散；
- 每集需要额外解释她们为什么总能聚在一起；
- 学校会越来越像艺术高中，而不是传统名门综合女校；
- 生田、万理华、西野的差异容易被简化成“专业不同”。

统一高等科 + 深度选修则能保留：

- 名门女校共同体；
- 班级生活；
- 高水平艺术资源；
- 人物在校园里自然流动的可能。

### 主题上的理由

到了高三，她们仍穿同一套制服、属于同一所学校，但每天走的路线已经越来越不同。

这正好成为毕业的前奏：

> 人还在一起，方向已经开始分开。

## 六、下一步

在分配主角班级之前，需要先完成：

1. 确认四类履修系列是否足够；
2. 设计高三一天的典型课表结构；
3. 完成校园空间地图 V1；
4. 再把主角与配角分入不同 Home Room，并配置各自主要选修路线。

顺序固定为：

> **课程制度 → 空间地图 → 班级分配 → 单集分场。**
