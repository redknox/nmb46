# 乃木坂女学院｜课程制度 V2

> 状态：**制度层已锁定。** 高三具体选修 Block、17名主要人物履修路线、典型周课表与制作规则，见 `docs/world/high3-elective-routes-timetable-lock.md`。
>
> 核心原则：**先让学校制度成立，再把人物放进去。**

乃木坂女学院不设置彼此隔离的“普通科 / 音乐科 / 美术科”式分科。学生首先属于同一所高等科与自己的 Home Room；进入高二、高三后，再通过选修、履修领域与专业程度逐渐分流。

## 一、基本结构

### 高等科统一招生

所有学生进入同一个“高等科”。

她们在行政上首先属于自己的班级，例如 3-A、3-B、3-C、3-D，而不是“音乐科三年级”“美术科三年级”。

Home Room 承担：

- 晨会与终礼；
- 班级事务；
- 值日；
- 進路希望調査；
- 班级活动；
- 考试与通知；
- 毕业手续；
- 学級委員等班级职务。

因此即使学生专业兴趣差异很大，她们仍共享稳定的班级生活。

## 二、高二以后形成履修领域

高一以共同基础课程为主；从高二开始，根据升学方向、兴趣和能力逐步增加选修，高三分流最明显。

学校进行履修指导时使用四类主要领域：

### 1. 人文社会

可能包含现代文、古典、日本史、世界史、政治经济、社会学、文学专题、哲学 / 思想等。

武田铁矢、柄本佑、堺雅人等成人角色可从这一领域自然进入课堂。

### 2. 理数自然

可能包含高阶数学、统计、物理、化学、生物、实验、科学史与研究演习等。

安田显等理科教师可在这一体系内使用。

### 3. 国际教养

可能包含英语表达、英语文学 / 阅读、第二外语、国际文化、比较文化、国际交流项目等。

隔壁男子校英语教师 / 国际交流负责人等角色可由此进入学校合作，但不承担恋爱功能。

### 4. 艺术表现

艺术不是隔离的“艺术科”，而是一组可深入履修的课程：

- 音乐：器乐、声乐、和声、合唱、音乐史、创作实践；
- 美术：素描、日本画、西洋画、造型、艺术史；
- 工艺 / 设计：平面、材料、服装与空间表达；
- 书道 / 传统艺术；
- 戏剧、摄影、影像等实践课程。

生田、万理华、西野可以拥有不同程度的艺术训练，却仍首先是各自 Home Room 的普通高三学生。

## 三、四个领域不是四条轨道

“人文社会 / 理数自然 / 国际教养 / 艺术表现”只用于履修指导，不是学生身份标签。

学生可以跨领域组合课程。例如一个学生完全可以同时修文学、英语表达、视觉设计与社会调查，而不需要被定义成“某某系学生”。

因此：

> **课程表不能写成人物性格测验。**

每个主要人物只有少数课程需要承担明确人物意义；其余选修可以只是兴趣、升学需要、教师口碑、朋友推荐、时间安排或单纯觉得有趣。

## 四、班级与选修是两套关系网络

学生早晚回自己的 Home Room，中间会因为选课在校园中流动。

因此：

- 同班，不代表整天一起上课；
- 不同班，也不代表很少见面；
- 课程路线制造接触概率，但不自动制造亲密；
- 同课不等于同组；
- 同课结束不等于一起午饭 / 放学；
- 高三分流让“她们已经开始一点点分开”自然发生。

固定理解：

> **Home Room 是第一张关系网；履修课程是第二张关系网。**

## 五、高三典型课表结构

高三基准为周一至周五、每天6限、每限约50分钟；晨间 HR 与终礼不计入正式6限。

每周30限基准：

- Home Room共同学科：18限；
- 同步选修：8限；
- 体育 / 保健：2限；
- 综合探究：1限；
- LHR / 年级指导：1限。

高三同步选修分为四个 Block：

- `Eα` 学术深化 I：每周两个单限；
- `Eβ` 学术深化 II：每周两个单限；
- `Eγ` 实践深化 I：每周一个连续双限；
- `Eδ` 实践深化 II：每周一个连续双限。

典型星期位置锁定为：

- 周一第3限：Eα；
- 周二第5–6限：Eγ；
- 周三第4限：Eβ，之后直接进入午休；
- 周四第2限：Eα；
- 周五第2限：Eβ；
- 周五第5–6限：Eδ。

Eα / Eβ 以主教学区和短转场空间为主；Eγ / Eδ 才承担艺术别馆、实验设施、音乐空间等明显跨建筑移动。

周五 Eδ 结束后，终礼前必须保留约15分钟归班缓冲，用于收器材、洗手、归还材料和实际返回3F。

## 六、主要人物课程定位

### 生田绘梨花

不是“音乐科学生”。她属于普通 Home Room，但艺术表现中的音乐履修最深，是乃校学生中音乐能力最强的一层。

她仍然是处于学校教育覆盖范围内的高中生，距离成熟职业演奏家有明确差距。乃校音乐教育本身是全校最强的领域之一，现有教师、课程、ensemble、设施与外部作品合作仍然能够继续要求她；不能因为她在学生中突出，就把她写成学校已经无力指导的准职业大师。

已锁定：Eγ「音乐演奏」、Eδ「创作音乐」。

她的问题不是“艺术生与普通生隔离”，而是：

> 一个在普通校园生活里拥有非常专业技能的人，开始发现专业训练本身也会限制自己。

松隆子是具有一流职业演奏团体核心席位能力尺度的校内音乐教师；Fukase 是学校长期外部创作协力者，两者从不同方向作用于她。Fukase 当前不承担定期授课、学生评价或生田的专属导师身份。

### 中元日芽香

已锁定：与生田共享 Eγ「音乐演奏」，Eδ 则进入「合唱・舞台合奏」。

两人共享音乐，但不共享全部音乐路线，使“才能与努力”的比较只发生在真正具有共同评价尺度的场合。

### 伊藤万理华

已锁定艺术史・美学、视觉造型、材料・空间设计等较深艺术履修。

她的核心不是专业成绩，而是“这是我的东西”。

### 西野七濑

已锁定 Eγ「视觉造型」与 Eδ「摄影・影像」。她与万理华共享一个艺术 Block，但之后继续分开。

她不是强烈的创作者宣言型人物，更偏观察、判断与私人选择。

## 七、普通学生与选修连续性

选修课必须继续维持“120名高三学生”的真实感。

Home Room 中已存在的普通同学 X / Y 可以进入选修课，但她们是完整学生，不是主要人物卫星。

原则：

- 一个固定 X / Y 与其关系最紧密的主要人物，原则上只共享0–1个主要选修 Block；
- X / Y 可以在没有对应主要人物的课程里出现；
- 普通学生可以在某些课程里比主要人物更擅长；
- Eα / Eβ 的普通熟脸要重复出现，不能每场重置背景群众；
- 实践课不得因为主要人物是主演就自动把她们编成同一小组。

## 八、为什么不设置正式音乐科 / 美术科

如果设置彼此独立的音乐科、美术科：

- 主角群会被行政结构天然拆散；
- 每集需要额外解释为什么仍总能聚在一起；
- 学校会越来越像艺术高中，而不是传统名门综合女校；
- 生田、万理华、西野的差异容易被简化成“专业不同”。

统一高等科 + 深度选修则能同时保留：

- 名门女校共同体；
- Home Room 日常；
- 高水平艺术 / 学术资源；
- 人物在校园中自然流动的可能。

## 九、主题落点

到了高三，她们仍穿同一套制服、属于同一所学校，但每天走的路线已经越来越不同。

周五双限结束后，学生从音乐、艺术、国际交流、研究空间等不同方向回到主教学楼，重新坐回各自 Home Room 的固定座位。

> **她们每天都回来，所以大家还觉得自己没有分开；但其实她们每天都已经在练习走向不同的地方。**

课程制度与高三履修框架至此完成。

## 十、个别艺术研究指导

乃校允许在音乐、美术与文学领域，为现有课程无法覆盖的一项明确个人研究单独聘请外部专家。该制度极少启动，不等同于普通选修、社团指导或家长购买的校内私教。

生田当前仍由乃校既有音乐教育充分覆盖，不因 EP04 与 Fukase 的一次具体接触自动进入该制度。
