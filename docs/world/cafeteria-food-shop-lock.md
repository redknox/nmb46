# 乃木坂女学院｜食堂棟・食品購買位置锁定

> 状态：**已锁定 / 校园生活区设施权威补充。**

## 1. 基本定位

乃木坂女学院的食品小卖部不设置在主教学楼内部，而设置于主楼西侧生活区的**食堂棟入口区域**，作为食堂设施的一部分。

正式理解：

> **食堂棟附属・食品購買**

它与食堂共享生活人流与后勤，但学生不必进入正式用餐区即可购买轻食后离开。

## 2. 空间关系

当前锁定关系：

> 主教学楼西侧 → 食堂棟入口 / 前厅 → 食品購買 → 食堂大厅 / 正餐区域 → 厨房及后勤

食品購買位于食堂棟入口侧，不藏在打饭窗口或厨房深处。

因此午休会自然形成三类不同人流：

- 自带便当的学生不必前往食堂棟；
- 只购买面包、饭团、饮料、简单便当或甜点的学生进入入口侧食品購買，购买后可直接返回教室或去别处；
- 使用食堂正餐的学生继续进入食堂大厅。

食品購買高峰与食堂正餐人流有关联，但两者不等同。

## 3. 与主楼的动线

高三3-A位于主教学楼3F西翼。学生从3-A前往食品購買时，需真实经过西侧楼梯 / 主楼生活侧出口并进入邻近食堂棟。

EP03《午休》S02的“校内购买区”即指本设施。

该动线不得被理解成主楼3F到1F同栋内部的瞬时移动；同时食堂棟与主楼相邻，不应被夸张成需要数分钟横穿校园的远距离建筑。

## 4. 午休使用逻辑

午休开始后，食品購買会在最初数分钟形成集中队列。

学生可能：

- 边排队边聊天；
- 临时更换想买的商品；
- 买完后直接返回主楼；
- 买完后进入食堂大厅；
- 与从食堂出来或前往其他生活设施的人交叉。

因此这里是低戏剧重量但高生活密度的校园节点，适合自然产生偶遇、闲聊和零碎信息，不应被写成正式“情报交换站”。

## 5. 与一般購買部的区分

本文件只锁定**食品購買**。

学校若另设出售文具、练习册、体育用品、制服配件、校徽、美术用品等的普通購買部，其位置另行决定，不默认与食品購買合并。

## 6. 固定理解

> **主楼负责上课与制度，食堂棟一侧承担吃饭、排队、偶遇和无意义聊天等日常生活。**

> **食品購買属于食堂棟生活区，不属于主楼内部便利设施。**
