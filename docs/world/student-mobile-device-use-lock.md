# 乃木坂女学院｜学生手机与私人摄影设备使用规则锁定

> 状态：**已锁定 / 项目级校园日常规则。**
>
> 本文件回答学生手机能否带入学校、在哪里可以使用、哪些行为算“使用”，以及私人相机与校园摄影如何处理。后续单集默认服从本规则，除非剧情明确发生在经教师或学校批准的特殊情境中。

## 1. 基本原则

乃木坂女学院允许学生携带手机 / 智能手机到校，主要考虑通学、家庭联络、交通异常与紧急情况。

学生不需要每天把手机统一上交，但须自行保管，并遵守校内分区使用规则。

固定理解：

> **可以带到学校，不等于可以在学校任何地方使用。**

## 2. 主教学楼内原则禁止使用

主教学楼内原则禁止学生私人使用手机。

“使用”包括但不限于：

- 通话；
- LINE / 短信 / DM 等传信；
- SNS；
- 浏览网页；
- 游戏；
- 私人音乐 / 视频；
- 使用耳机进行私人娱乐；
- 手机摄影、录像、录音。

因此，“不出声、只在桌下传消息”同样属于违规使用。

固定剧作规则：

> **在主楼里，手机不能替代人物移动。**

需要找同学时，学生必须实际走过去、问人、等人或通过学校允许的正式渠道联系。

## 3. 允许使用区域

学校保留少数明确的私人手机使用区域，主要包括：

- 食堂棟生活区；
- 校园指定室外休息区域；
- 校门外侧及通学转换区域。

这些区域允许学生在休息时间查看或回复家庭 / 私人消息，但仍须服从摄影与隐私规则。

不得把“允许使用区域”扩展理解为整座校园自由使用。

## 4. 严格限制区域

以下区域原则上禁止学生私人使用手机，即使处于课间或午休：

- 图书馆；
- 音乐・美术别馆的教学、练习与制作区域；
- 礼堂及正式典礼 / 排练空间；
- 保健室；
- 校史资料室；
- 学生会办公区域与正式会议空间；
- 其他由学校临时指定的考试、会议、排练、档案或隐私区域。

## 5. 教学用途例外

教师或学校明确许可的教学、记录、研究或活动用途不视为违规。

但本校资源充足，默认优先使用学校提供或登记管理的平板、电脑、录音设备、摄影设备等教学终端，而不是把学生私人手机默认当作课堂工具。

固定理解：

> **私人手机属于学生的校外 / 私人世界；学校设备属于教学系统。**

## 6. 私人相机与摄影

手机摄影服从手机使用区域限制，因此主楼内禁止用手机拍照。

但普通小型数码相机、胶片相机等独立摄影设备可以在普通教室或校园公共区域的休息时间使用，前提是：

- 被摄者知情并同意；
- 不影响课堂、秩序与通行；
- 不进入隐私或正式限制区域；
- 不违反学校关于公开发布照片的其他规定。

以下区域 / 情境原则禁止学生私人摄影：

- 课堂进行中；
- 保健室；
- 图书馆；
- 礼堂正式仪式；
- 正式会议；
- 考试；
- 档案 / 资料限制区域；
- 其他学校明确禁止摄影的场所。

文化祭、典礼、校务记录等需要正式摄影时，可由摄影部、执行委员会登记设备或其他经学校批准的人员承担。

## 7. 对校园关系网络的影响

本规则不是为剧情制造不便，而是学校长期生活方式的一部分。

它会自然产生：

- 跨班找人必须真的跨班；
- 不知道对方在哪里时，需要问人或等待；
- 午休信息通过面对面交谈、路过、社团与班级网络传播；
- “今天去了谁那里”本身具有关系信息；
- 离开主楼 / 离校后，私人数字通信重新进入生活。

因此后续写作不得为了方便而让人物在主楼内用手机解决本应由空间、关系与移动承担的问题。

## 8. EP01已锁定适用例

EP01《入学》3-D“高三第一天照片”发生在普通教室午休时段。

该场允许使用独立小型数码相机；拍照者为普通同学，不使用手机。

这张合照不改变原有行为核心：

> 飞鸟嘴上说不拍 → 没人继续劝 → 真正要拍时她自己走进画面边缘。

摄影设备只负责服从校园规则，不额外承担人物说明。
