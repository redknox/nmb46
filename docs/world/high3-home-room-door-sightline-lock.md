# 乃木坂女学院｜3F Home Room 门制与视线锁定

> 状态：**已锁定 / 3F Home Room 走廊门与门口视线权威补充。**

## 1. 门制

3-A—3-D 每班采用：

> **一樘主门 + 一樘低等级辅助门。**

功能上有两条通路，建筑阅读上仍以主门定义班级门面。

- 3-A、3-B：主门位于靠中央一侧的端 bay，辅助门位于外侧端 bay；
- 3-C、3-D：镜像处理，主门位于靠中央一侧的端 bay，辅助门位于外侧端 bay；
- 两类门都缩回各自 bay 内部，不贴 X6 / X9 / X11 / X14 等重要边界，并保留实体墙垛。

## 2. 门的等级

主门采用较完整的历史木门语言，承担班牌、教师进出与普通上下课的班级门面。

辅助门材料协调但细部简化一级，不与主门形成对称双主门；主要承担换课分流、搬运和第二通路。普通课间大多数学生仍使用主门，辅助门使用量随下一堂课方向变化。

## 3. 视线与冲突校核

- 3-A 主门向中央侧收拢，西侧辅助门自然服务西梯、WC和面谈区；
- 3-B 主门不得与 W3 学年室历史门形成正对，靠中央可直接感知“深木框 + 框后的亮”；西侧辅助门方便前往 W2 進路室；
- 3-C 主门不得与 E1 历史门形成正对，避免无障碍前厅变成班级社交节点；东侧辅助门方便 E2 Seminar；
- 3-D 主门仍朝向全层共同空间，辅助门自然联系 E3、东WC与东梯，因此不形成象征性的“边缘班”。

## 4. 人流结论

四班门口、北侧功能、中央节点和东西端分流均通过压力测试。主门之间保持明显距离；相邻班的主门与辅助门可因课表形成临时交叉流，但不制造固定跨班社交区。

固定理解：

> **功能上两门，建筑阅读上仍然是一门。**

> **空间关系可以随课表改变，但建筑不替人物预先安排相遇。**
