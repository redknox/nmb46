# 高三一月校历与家庭学习期

> 状态：**WORLD CANON / 主创已确认并授权落盘**。
>
> 确认日期：2026-09-30。本文件落实高三统一授课、毕业考查、常规到校结束与家庭学习期的衔接。
>
> **使用 2026 年参考日历，与本轮大学入试资料一致；不据此确定故事绝对年份。** 下表中的校内安排是乃校采用的设定，不是日本高中全国统一规定。若以后更换参考年份，须同时复核星期、节假日及大学入试日期，不直接平移日期。

## 1. 四个明确节点

- **1月15日（四）**：最后一个完整六节课的普通上学日。
- **1月23日（五）**：统一授课结束；此前仍有上午特别课表。
- **1月30日（五）**：返卷、年级说明与班会结束后，结束常规统一到校。
- **2月2日（一）**：正式进入家庭学习期，衔接1月31日、2月1日周末。

结束六节课、结束统一授课、结束常规到校、毕业离校是不同节点。不能把1月15日写成高三此后完全不用返校，也不能把家庭学习期写成已经毕业。

## 3. 考查与校内服务

### 毕业考查

毕业考查是高中课程的最后评价，不另设一场高难度的统一“毕业资格大考”。科目及评价方式依实际修课安排；实技、作品、课堂表现等不必全部转换成这三天的笔试。

未通过或材料不齐的学生，二月仍须按要求返校补考、补交。具体补考日期、科目分配和个别学生情况尚未设置，不从本表推导任何人的不合格支线。

### 家庭学习期

- 图书馆、自习室在指定时段继续开放。
- 进路面谈、琴房与美术教室实行预约，仍受既有场地、教师与使用管理规则约束。
- 生田、万理华等可因备考、练琴、创作或指导来校；不能因此默认主角团每天全部在场。
- 二月及毕业前的指定登校、材料办理、清扫、典礼说明／预行，与普通授课区别处理；具体日期留待后续确认。

## 4. 与大学入试、人物进路的接口

大学出愿、缴费、材料邮寄及考试按各人已确认的进路专项执行，不因校内授课结束而统一推迟。出愿材料办理需要与学校事务窗口衔接。

2026年度国立大学一般选拔出愿期为 **1月26日—2月4日**，与校内考查及家庭学习期衔接。桥本在共通考试自我评分、进路面谈后办理申请；已确认的都立大后期提前出愿安排不变，不能等北大前期放榜后才申请后期。

1月19日安排的是自我评分与资料整理，不是大学正式成绩通知或合格发表。是否参加共通考试、具体应考科目，仍以各人物专项为准；不得把高三全员写成共通考试考生。

## 5. 后半季使用边界

本安排为学校日常成立提供时间条件，不指定必须拍摄的场景，不代替 EP11—12 的分集开发。

- 1月15日以后，不再每天共同待满六节课。
- 1月23日以后，不再统一上课，但月底仍有考查、返卷与班会。
- 1月30日以后，不再每天见面；偶尔来校必须有指定登校、备考或办理事务等具体依据。
- 三月毕业前的返校不再称为“最后几个普通上学日”。

毕业典礼具体日期及 EP12 时长仍待确认。EP11—12现以典礼日中午分界，上午庆祝归EP11、下午班会及离校归EP12；[EP11 STEP0](../episodes/ep11/episode-brief.md)已收口。参见[后半季日历](../structure/ep08-ep12-calendar-lock.md)及[当前桌面](../writers-room/current-desk.md)。本校历具体日期不变，不更改 EP01—EP09 FINAL。
