# 乃木坂女学院

暂定副标题：**《放学后，坡道之上》**

这是一个以乃木坂46一期生为核心的虚构校园群像剧/轻小说企划。舞台是一所真正意义上的名门私立女子学院：制度严整、资源充足、传统深厚，也与普通社会保持一定距离。

## 核心命题

这不是“谁最强”的校园剧，而是关于：

- 谁最像这所学校的人？
- 传统与个人如何共存？
- 已经为你准备好的道路，要不要照着走？
- 明知会离开，为什么还是会舍不得？
- 人会毕业，但学校会继续存在。

一句总原则：

> 乃木坂成员负责青春，外部演员负责时间。

## 当前形式

- 单季 12 集
- 常规集约 50 分钟
- 最终回《放学后》约 90 分钟
- 第一集《入学》已进入 Beat Sheet 阶段

## 创作基调

整体希望具有宫藤官九郎式的节奏：刚让人哭出来就强迫人笑，笑着笑着反而更难受。

名门女校的高雅感是真的，后台的狼狈也是真的；幕布拉开以后，裙摆依然能站成一条线。
